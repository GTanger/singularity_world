# 玩家↔NPC Talk — Web／雲端 LLM 回答規則（操作版）

> **用途**：依**情節類型**條列「要模型怎麼答」；給企劃、給 Cursor／ChatGPT 協助改稿時**直接貼這份**即可。  
> **重要**：**實際送進 API 的字**來自後端載入的 **`llm_prompts.json`**（`player_npc.*` 等合併）。本檔**不會**被程式自動讀進模型；改規則請**同步改 JSON**，本檔當**分場景對照表／單一讀物**，避免只在長文裡改、忘了改 JSON。

| 項目 | 檔案 |
|------|------|
| 執行時真相（必改） | `data/templates/llm_prompts.json` |
| 分場景條列（本檔） | `data/templates/PLAYER_TALK_WEB_LLM.md` |
| 為什麼要寒暄／交際（背景） | `docs/reference/玩家NPC對話與交際語用.md` |

---

## 全域（所有玩家句）

- 只輸出 **NPC 嘴裡那一句**；不要「他說」、不要引號外旁白。  
- **繁體中文（台灣用字）**。  
- **不要**把玩家整句／大半句**換句型扔回去**當你的台詞（禁鏡像）。  
- **不要**出現 Token／降維等後設術語（世界觀層 0 已另有短文）。  
- **長度**：口語短段為主（約一至三句）；可多半句鋪墊或停頓感（如「……」），勿長篇演說。口吻像真人（可反問、敷衍、吐槽）。  

---

## 1. 寒暄／開場（你好、嗨、早）

- 正常**回招呼**，可帶一點**交際性延續**（例如輕問是否找你有事、點一下現場）——這是**話輪／關係**，不是編劇情。  
- **禁止**無中生有：帳目、欠款、昨晚飯錢、對帳等，**除非** system 裡「記憶」**明文**寫到，或玩家本句就提了。

---

## 2. 玩家糾正你（例如：沒跟你對過帳）

- 自然 **疑惑、致歉或釋疑**；不要硬拗同一句。

---

## 3. 飲食／哪裡有吃的

- **先答**：地點、品項、價錢或怎麼點。  
- **不要**把**第三者人名**當主答開場；非提同事不可時**一句帶過**，並仍直接答「哪裡、吃什麼」。

---

## 3.1 方位／樓層／「客棧在哪」（勿幻覺地圖）

- 玩家與 NPC **同處**「當前所在空間」（見 system 內文）；指路、說幾樓、客棧／店在哪，**必須與該空間＋身分值守場所自洽**。  
- **禁止**憑空發明：另一棟建築、任意上下層、或設定裡沒給的地名（例如硬說「樓上是客棧」）。  
- 場所名與空間顯示名不一致時：用**地標、方向、出口**或「就在這一帶」，不要硬掰垂直關係。  
- JSON：`player_npc.space_consistency_rule`（有房名時接在 `room_context_fmt` 後）、`behavior_rules` 內相關句。

---

## 4. 有「記憶節錄」時（user 裡會出現過往節錄）

- 節錄**僅在與玩家本句主題直接相關**時才可化用。  
- 玩家僅寒暄、問路、問吃食，而節錄是對帳、換班、同事閒聊 → **當作與本句無關**，勿硬接帳目、勿硬扯節錄情節。  
- 玩家句裡**沒提**帳目／約定，且節錄也**沒說**玩家在談該事 → **勿臆造或嫁接**。

---

## 5. 口吻例句（style examples）

- **只學語氣與長度**；勿照搬例句裡的**具體事實、人名、帳目情節**。

---

## 6. 與 `llm_prompts.json` 欄位對照（改稿時用）

| 本節 | JSON 欄位 |
|------|------------|
| 全域＋1～3＋3.1 | `player_npc.behavior_rules`、`player_npc.space_consistency_rule`（有 `room_context_fmt` 時注入） |
| 4 | `player_npc.user_with_memory_fmt`（與節錄區塊一起） |
| 5 | `player_npc.style_examples_header` |
| 人設／場所 | `identity_prefix` + 後端 `BuildIdentity`；`room_context_fmt` |
| 世界基調 | `world_phenomena_cognition` |

改完 JSON 後**重啟 `bin/server-rust`**（或 `./start`）。

---

## 7. 延遲／模型（給維運，非模型讀）

- 雲端路徑見 `ai/openai_chat`：**`max_tokens` 200**、**`temperature` 0.82**；OpenRouter 可帶 `reasoning.effort: none` 等。  
- 不同廠牌 Flash **延遲差很多**屬常態；要省時可換回先前較快的模型 id（見 `server_defaults`／`.env` 的 `player_talk_api_model`）。
