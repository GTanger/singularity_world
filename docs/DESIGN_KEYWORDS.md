以下為遊戲核心設計關鍵字，供企劃與開發對齊方向使用。

## 2026-07-16 回文字

- 使用者指出：**「圖像會讓我多一個分心的項目」**，並定案：**「好，回文字」**。
- 文字重新成為正式的主要玩家表面；不再同時維護圖像大地圖與文字兩套
  產品，也不把圖像列成日後必補的欠債。
- GUI 仍是玩家的眼睛與手腳。玩家透過 GUI 行動並活在故事裡，不是閱讀
  預寫故事、長篇場景散文或分支劇情。
- 世界先運作；文字把玩家此刻能感知的人、物、位置、行動、局勢、結果與
  痕跡翻成可讀內容，不能用文字捏造後端不存在的事實。
- 2026-07-13～15 的 2D 大地圖、圓形加一個中文字、固定螢幕尺寸、單擊走、
  雙擊跑、直線移動與撞牆停，全部降為歷史與素材，不再是現行產品或待辦。
- 回文字不自動復活舊方格 MUD、房間清單、九宮格方向鍵、傳統命令列、
  v6 以前的文字 UI 或現行方格 runtime 外觀。
- 2026-07-17，使用者另外定案：玩家用來表達移動的基礎語彙回歸
  **東、西、南、北、上、下、進、出**。這只決定八個移動詞，不決定它們
  是按鈕、可點文字、輸入指令、快捷方式或其他 GUI，也不決定座標與拓撲。
- **白塔半島無縫純符號大地圖與《指尖 MUD》四區融合（2026-10-16 定案）**：以 `2026-07-03` 形象示意圖為唯一基準，將 14 座聚落（2 城 4 鎮 8 村）與 19 處自然獵場直接攤在約 5,000 格無縫純符號大地圖（23 個符號，CSS Grid 固定正方格 100% 對齊）上；融合《指尖 MUD》四區結構（頂欄日晷時間、左欄當前格在場人與物、右上描述＋中央隨時間滾動之動態文字 Log、下方無縫大地圖）。
- **探索（接觸）與環境恢復狀態（2026-10-16 定案）**：日常走路移動不「踩地雷」強制進戰鬥；在野外地形格主動點**【探索】**機率發現採集物、溫馴獵物、巨獸新鮮蹤跡（提示延伸方向可追獵）或驚動護巢猛獸；同一格探索過後一定時間內再次探索，前台呈現「這片林地已仔細翻找過，暫時沒有新的動靜」之自然環境狀態。
- 詳見 [回文字](design/gdd/22-return-to-text.md)。歷史圖像決定見
  [2D 平面大地圖開放世界主畫面](design/gdd/21-2d-open-world-primary-surface.md)。

## 設計核心

**從有限框架延伸出無限可能。**

- **世界架構先於活世界**：使用者在 2026-07-17 定錨「得先把世界架構起來，
  才有辦法讓世界活過來」。先把世界根律、非人／環境壓力、文明支撐、區域
  流動、制度／經濟／普通生活、長壽與歷史累積接成有因果的承重結構，再讓
  人物生活、世界持續運作、玩家接觸與 UI 呈現從中長出。不得先用 NPC 行為、
  故事或介面效果表演「活世界」，再反推世界本身；這條順序不新增世界正典。
- **第一條已接受的環境壓力因果**：2026-07-18 接受白塔半島「高水期與
  通行地帶遷移」。多流域來水重疊會改變低地、舊河道、路段、儲放點與漫流水網
  的當期可用性，並將結果留進資源、人口、公共方法、歷史、現在態與玩家寫回。
  它不等於全半島同步水災，也不定案氣候數值、制度、工具、UI 或程式做法。
- **單一世界時鐘與既定時間流速**：全島共用單一世界時鐘（`game_time_scale = 24`，即 **1 真實小時 ＝ 1 遊戲日**，每日切分為拂曉、晝前、正晝、黃昏、夜段、黎明前六段時辰），不因玩家離線而停止。
- **「世界是動態的」10 條大地圖符號演變鏈（2026-10-16 定案）**：大地圖格子的符號隨玩家與 NPC 的真實行動及自然時序動態改變——包含開山鑿道（`⛰︎`$\rightarrow$`△`）、劈林拓荒（`Φ`$\rightarrow$`𐡚`$\rightarrow$`::`）、開墾農田（`𐡚`/`⋍`/`Φ`$\rightarrow$`≡` 空田壟 $\rightarrow$`▤` 旱田／`▦` 水田／`☷` 藥圃）、架橋渡水（`≈`$\rightarrow$`≍`）、聚落擴建築屋（`𖠿`/`$`/`⚒︎`/`+`/`⌂`/`≠`/`■`）、森林自然演替與荒廢回退、旱澇水位消長、猛獸築巢與山崩阻路。

### 緣起與訴求

- 緣起曾是**將文字 MUD 放在手機上玩**並省略輸入指令；2026-07-16 已正式
  **回文字**。手機 GUI 與輕操作仍保留，但版面、文字入口與是否允許自由輸入
  仍待重新設計。
- 不想讓旅途只是**一長串方向指令**；也不想世界顯得過小，或**大卻空蕩蕩無聊**。
- **萬名以上異步 NPC** 是讓大型城市與世界持續有生命的一個核心支撐：每個人
  有自己的故事，彼此交織，不是萬名以上複製人；但 NPC 數量不能單獨代替地理、
  旅途、物件接觸與搜尋目標。
- **活世界方向已定**：2026-07-16 的「生活的世界尚未定案」只代表當時階段；
  使用者其後明確要求 **「世界架構起來」「人物自主動起來」「整個世界活的」**。
  因此世界先於玩家、無玩家時持續運作、人物有自己的位置／行動／目的／關係／
  記憶／持有物與可追查後果，已是產品要求，不再是候選。
- [Usurper Reborn](https://github.com/binary-knight/usurper-reborn) 採作工程案例：保留
  「人物實體 → 狀態與選擇 → 世界行動 → 資源／關係／家庭／生死後果 → 持久化」
  的完整生命鏈；不直接搬用其 C#／GPL 程式、硬編碼地點表、內容世界觀或 NPC
  專用的第二套行動分派器。奇點的人物與玩家仍必須落在同一份世界規則。
- **非同步 NPC 運算分層與 LLM 邊界（2026-10-16 定案）**：全島 NPC 的移動、採集、開墾、百工打造、買賣定價與戰鬥輸贏，**100% 由後台 Rust 數據與規則引擎驅動（0 LLM 延遲、絕對守衡）**；**LLM 僅用於「近場語言與記憶層」**（當玩家與同格 NPC 深度交談、打聽消息、議價立約或將個人之相著譜定名時，依後台真實數據事實生成台詞），絕不讓 LLM 替後台決定物理結果。
- **「人物因果主幹」是助手在討論中提出的暫用說法，不是使用者定名，也不是
  已接受的系統架構。**
- 「每一格極其值得停留、為某個目標滿世界搜索」是探索密度的**概念要求**，
  不是已定的格子內容配額。不得直接翻譯成每個座標固定掉寶、固定事件、固定
  散文或強迫玩家每步停下；世界密度的確切組合仍待設計。考古證據見
  [世界為何大而不空](design/research/2026-07-16-world-density-archaeology.md)。

**用語**：本文件所稱**離線／下線**，皆指**玩家本身中斷操作角色**（非泛指登出或關閉 app 等）。

## 視角與畫面

- **文字是主要玩家表面**；世界先運作，文字只呈現玩家可感知的局部事實
- **GUI 仍供玩家行動**，不能退化成預寫故事、長篇散文或分支閱讀
- 畫面上出現的**每個東西都是可互動的物件**
- 凡是大於人形體積的固體物件都是**實體、不可穿越**
- **空間呈現已定案（2026-10-16）**：下方【空間導航區】呈現 CSS Grid 固定正方格無縫純符號大地圖（23 個符號，不畫人頭、不搞格子發亮），當前格在場的人物、設施與探索發現物統一列於【左側直列欄】，人物進出與微動作隨時間流逝即時滾動於【中央動態文字 Log】。
- **前端僅是顯示窗口**，全靠後端計算與設計
- **深度沉浸**。**輕操作，才能重體驗**（跟得上直覺的輕操作是因，深度體驗是果）；文字 GUI 呈現玩家可感知的空間、
  人、物、行動、局勢與結果，不靠長篇散文或圖像素材量製造沉浸
- **細膩的世界，但不把遊戲變成勞作（文字版模擬人生生活感，嚴禁勞作，2026-10-19 拍板）**：「我想要一個細膩的世界，但我不想每一次攻擊、每一斧砍樹，都要自己一下一下的點，那叫勞作不叫遊戲。」細膩度放在世界的運作、沉浸生活感與前後因果呈現，不放在要玩家反覆連點的重複操作上。所有日常起居（吃喝、沐浴、更換穿搭、佈置居所）、野外採集開荒（砍樹、挖山、翻墾播種）與戰鬥交鋒皆採單次決策推進過程。
- 文字不是圖像資產的廉價替代，也不是用來講述預寫世界；世界先運作，文字
  顯現玩家此刻能感知的部分，GUI 讓玩家接觸並行動，世界改變後再呈現結果
- 故事可以是玩家與其他人生活、行動、交會後留下的經過與痕跡，不是預先塞給
  玩家閱讀的內容

## 世界

- **奇幻是風格，用字遣詞採現代風（台灣用語）（2026-10-19 使用者最新拍板定調）**：
  - **無火藥熱兵器、無矽晶片網際網路、無近代地球工業套皮**：化學火藥無法穿透高密度巨獸能量甲殼且無法傳導個人之相；隨身工具（鎬、叉、刀、盾、複合獵弩）實為合金礦材與巨獸骨芯加工之「導能器物」。城際大道與平坦陸路暢通（車馬、馱獸大車與商旅正常往來），僅在深入未開發的深山礦脈、密林或泥澤獵場採集狩獵時，才需穿戴現代機能護具徒步進入自然地形。
  - **聚落設施與生活場所（用字遣詞現代台灣用語，淘汰大陸古裝與修仙黑話）**：硬化礦漿、木石複合與高透光晶石玻璃建築，給排水、恆溫與恆光燈火；`⌂` 旅社／旅館（含一樓交誼食堂與二樓獨立客房）、`⚒︎` 鍛造工坊／百工工坊、`+` 脈絡診所／醫館；遠洋馭風大船與跨城聯運車隊；傳訊鐘樓、信使總站與聚落風物刊物；個人之相防偽總商行匯兌（鎂）、器物保險、學院與百工專利制度。
- 能量源頭相同；世界走向個人運用能量的發展，差異在使用方式。
- **萬人萬相**：同一套功法，每個人學起來、用起來都不同。
- 沒有玩家，世界仍是世界；玩家不是世界的主角。
- 世界、人物與物件一旦承擔人口、關係、所有權、資源、傷亡、知識或制度後果，
  就必須保持同一身分與因果；可以後補無關細節，不能等玩家看見才創造原因。
- `世界就一個平面`、`不設室內`、`同服十人`、`數萬 NPC`、`觀測坍縮`、
- **能量無處不在 × 全球皆為生機盎然的「沃土風」（鐵律：嚴禁把這個世界引導成末日廢土，2026-10-17 確認）**：
  - **嚴禁末日廢土調性**：這是一個能量無處不在、萬物繁茂、社會秩序與現代生活品質高度成熟的豐饒世界；嚴禁出現「資源枯竭、文明斷代、末日廢墟、孤城圍城求生、常規道路被荒野吞沒」等廢土引導。
  - **不是只有陸上能量充沛，能量無處不在**：陸地、山脈、海洋、深海、洋流與大氣皆充沛著同源能量，這個前提涵蓋全世界，青籠關以南同樣生機豐饒、絕非資源枯竭。
  - **陸路不難行，是因為青籠關種種險阻而南北難通；也不代表海事就安全（環島順時針洋流因果）**：一般陸路並不難行，南北陸路難通純粹是因為半島南端咽喉「青籠關」（與黑沼林）本身的種種險阻，吃熟人嚮導、大宗商隊難以常態通行；同時大海因能量充沛，同樣遍布深海巨獸與狂暴能量海象，海事絕非安全——半島西海盛行由南往北暖流（南陸船隊北上泊風舶嶼／天然港灣道／風舶角），北出繞過白塔神山後切入青脊山東側由北往南的強勁順風洋流高速南下，使海事風險能靠雙港城市與船隊制度化承擔。
- **同源能量的日常運作、單一貨幣「鎂」與開譜曆四季（2026-10-17 確認）**：日常器物、照明、醫療、鍛造與車船御水皆為透過個人能量引導運轉之導能器物；「鎂」為天然伴生之高純度導能輕金屬結晶（兼具工業基底耗材與烙印個人之「相」防偽雙重價值）；通行開譜曆（春融、夏漲高水期；秋狩、冬凝遠洋勁風期）。
- **兩百壽的追求、外出狩獵／採集取材與「開譜之爭」百年舊帳**：人人平均壽命逾兩百歲，修行不為求長生，而求「成相」（自創技能）、破局謀生與了結百年舊帳（約一百二十年前從舊氏族祕傳壟斷走向文曜公開教法與百工普及的親歷者至今仍活在世上）。人們出城狩獵採集取材回城交由百工鍛造現代導能裝備（工具）、推演功法或跨城行商，串聯五大行當動線。
- **唯一空間基準與白塔山留白（2026-10-16 定案）**：正式鎖定 `2026-07-03` 白塔半島形象示意圖（`initial-map-2026-07-03.png`）重新出發，徹底捨棄 Azgaar 305 區馬鈴薯圖與 37 個 Codex 地形分支。白塔山（神山）為青脊山北端純自然雪峰（非建築，其深層特殊意義保持留白，不強行寫死），聖塔 `∆` 則為雪線下具實體高塔建築之自由派修行聖地。

## 移動與操作

- 遊戲體驗端為**手機**，故需**優化指觸式、點擊，簡化繁瑣指令輸入**（專案無上架計畫，目前從未考慮上架）
- 玩家仍要採取行動並承擔世界結果，不能只按「下一段」閱讀文字。
- 2026-07-13～15 的單擊走、雙擊跑、直線移動、撞牆停與手動點擊繞路是
  2D 大地圖專用操作，已被「回文字」覆蓋，不得帶入現行文字介面。
- 玩家可用的基礎移動語彙已定為：**東、西、南、北、上、下、進、出**。
  這是移動用詞的決定，不是舊方格 MUD、房間制、九宮格方向鍵或命令列的
  整套復活。
- **無縫大地圖移動與「進／出」室內外空間分流（2026-10-16 定案）**：
  - **戶外與公開店堂／旅社一樓交誼大廳**：在無縫純符號大地圖上移動時，踏上公開建築格（`$` 總商行／商行、`⚒︎` 工坊／鍛造坊、`+` 診所／醫館、`⚑` 機構）或旅社 `⌂`，即身處公開店堂或旅社一樓交誼大廳與食堂（不收起下方地圖，可在左欄與駐店員工、匠師、同場複數旅客互動，一樓大廳不擺床）。
  - **獨立私人空間（「進／出」切換）**：在旅社一樓點**「投宿／進客房」**（或進入民宅 `𖠿` 內室、聖塔 `∆` 內部多層結構），則**收起下方大地圖**，切入按角色 ID 隔離的獨立私人空間（有床鋪可歇息養傷、下線託管，解決複數旅客同床問題）；點**「出」**即回到公開大廳或街道並重新展開大地圖。

## 角色與物件

- **遊戲內任一角色都是實體**：玩家與 NPC 碰觸時產生**真實物理現象**——輕則推擠、重則撞開，須謹守；屢次此類行為可能觸發衝突乃至戰鬥。
- **萬人萬相**：沒有任何一個人是一模一樣的。即使同一套功法、同一個老師、同一種訓練，每個人學起來、用起來也不同；可用護法咒作比喻：同一個咒，每個人的護法不同。功法只是共同文本與共同起點，不是把人分類的盒子；制度可以命名、教學、考核，但不能窮盡或凍結一個人的相。這不是反制度或反功法，不是固定路徑分類，也不是換皮特效或外觀隨機化。壓縮句：**同法不同相；制度教法，個體成相**。
- **功法有高下，勝負無定式**：沒有抽象意義上永遠最強的咒語，只有在某個人、某個時刻、某個問題面前最恰當的咒語。功法也許有優劣，但強弱與輸贏不能只看功法；人的相、理解、熟練、臨場判斷、對手、環境、時機、代價承受與恰當使用都會改變結果。制度可以評鑑功法，但排名不等於世界真理。
- **成熟不是只會更強**：功法優劣不只看威力，也看穩、快、省、隱蔽、易教、容錯、後勁、代價與失控風險；相性比等級更活。成熟的能量使用者知道何時不用、少用、慢用、借助器具、順應地形、協同他人，甚至讓對方失去出手條件。恰當性不只服務勝負，也服務救人、封鎖、修復、偵查、搬運、遮蔽、溝通、立信與取證。
- **全物件化、可動作交互**
- **不可僅憑文字創造物件**（不可無中生有）
- **不可無中生有**（前後因果完備）
- **沒有玩家，世界還是世界**：世界不因玩家缺席而失去存在、意義或運轉。
- **玩家不是世界的主角**；玩家只是在世界中生活與行動，創造自己的故事，
  成為**自己故事的主角**。其他人不是為玩家服務的配角。
- **玩家等於 NPC，NPC 等於玩家**
- **既有 NPC 暫存不刪**：目前資料庫／runtime 內已有一批 NPC，先保留作為位置、排程、互動、經濟與 UI 測試載體；之後再「洗白」其人格／記憶／背景，重新灌入新的靈魂資料。清地圖、清 UI、清舊系統時不得把這批 NPC 誤刪。
- 玩家下線後**角色變成在線 NPC**，執行玩家下線前設定的**簡單任務**
- **全身多部位裝備 ＝ 生存與工作工具組（2026-10-16 確認）**：雙手所持（鎬／錘開山、叉／矛穿刺、刀／斧伐木解剖、鋤／鏟開墾）、雙臂手部（複合護臂／手套防反震抓咬）、足部腿部（氣密涉水靴／釘底登山靴應對地形消耗）、軀幹背負（機能獵裝／模組化採集背架與恆溫樣本匣負重守衡）。百工造物由「形制決定邏輯插座 × 部位材質決定後台硬度／韌性／重量／導能率數據」，搭配**工具熟練度**，**無職業綁定**。
