## 一、 技術見解：雙軌導航 (Dual-Track Navigation)
這套架構的核心在於：**NPC 走邏輯路徑（Exits），玩家走感知路徑（Objects）。**

### 1. 邏輯軌道：全連結的 `exits`
在房間的 JSON 格式中，保留完整的 `exits` 清單，包含所有鄰近路段、店鋪與民宅入口 。

- **NPC 行為**：尋路演算法（如 A* 或廣度優先搜尋）會掃描這些 `exits`，將 A 點到 B 點之間的節點串聯起來。
- **屬性隱藏**：在 `exits` 的物件中新增一個欄位 `"ui_hidden": true`。
- **前端過濾**：遊戲前端在渲染下方出口按鈕時，自動跳過所有標記為隱藏的出口，徹底解決按鈕塞滿的問題。
