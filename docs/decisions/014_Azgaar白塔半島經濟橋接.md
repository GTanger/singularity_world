# 決策 014：Azgaar 白塔半島經濟橋接

- 日期：2026-07-21
- 狀態：已採用並通過 runtime／GUI 驗收
- 身分：工程決策，`canon: engineering`
- 完整紀錄：
  [Azgaar 白塔半島經濟橋接](../../../obsidian-vault/wiki/05-專案/Singularity-World/60-工程實作/Azgaar白塔半島經濟橋接.md)

## 決定

完整編譯既有 Azgaar Full JSON 的 71 種商品、54 個市場、3,834 筆報價與 25,808 筆
交易，不自行生成替代資料。來源交易只作 non-canon runtime evidence；人物實際工作與
交易另由 PostgreSQL 原子帳本落地，鎂、物品與有限場所金庫必須守衡。

商品 31 的人身商品及 19 筆關聯來源交易保留作來源證據，但禁止 runtime 買賣。先前
305 個柴枝束／粗礦式 P0 來源保留歷史資料，不再顯示、產生、再生或參與 NPC 決策。

## 驗收

- 54 個市場全部建立工作場所，冷重啟不重填金庫；
- 驗收快照 176 筆實際交易／352 收據、457 筆工作／457 收據，不平衡皆為 0；
- 玩家與 NPC 共用交易、工作規則，NPC 不會借玩家或 `codex` 當假買方；
- 完整 `./start`、283 個 lib 測試、各 bin 測試、Clippy、release 與正式服務通過；
- 人物每步移動會把新位置、剩餘旅程與行動收據放在同一交易；正式重啟後連續 30 次
  runtime 嚴格檢查皆為 0 條無效旅程；
- 桌面／手機 GUI 已目視確認人物工作與交易狀態，遭否定的 P0 資源卡不再出現。
- 最終手機移動目視另抓到登入頁與遊戲頁可能同時排版；已恢復 `.sw-app[hidden]` 契約
  並更新靜態版本。登入前只見登入頁，登入後只見遊戲頁，長地名與移動結果完整。

## 邊界

本決策的驗收數字保存 2026-07-21 早期橋接階段的歷史快照；其後不應拿它判讀目前
runtime。當時尚缺的有限庫存、來源供應、居民消費、跨市場物流與玩家市場成交，已由
[決策 015：白塔半島有限市場閉環](015_白塔半島有限市場閉環.md) 接通。仍未完成的是
完整奇幻現代產業、製造、服務、物件用途與耐久、家庭／組織財務、信用契約、政治與
奇幻能力對日常經濟的影響；後續仍必須接在同一守衡世界上。
