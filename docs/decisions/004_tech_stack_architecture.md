# 決策 004：技術棧與架構

**狀態**：已決斷  
**依據**：主管決斷

> **現況補註（2026）**：執行期**權威持久層**為 **PostgreSQL**；`store` 為讀取快取；`data/**/*.json` 為種子、靜態設定與可選備份——**不以 JSON 為唯一真理**。SQLite 已退出主線。細節見 [`AGENTS.md`](../../AGENTS.md)、[`技術約束規則`](../技術約束規則.md)；歷史遷移脈絡仍可查 [DB轉JSON遷移規劃](../implementation/DB轉JSON遷移規劃.md)（敘事為過渡期文件，現以 PG 為準）。

## 1. 決策內容

### 1.1 伺服器：Rust（現行）

- **遊戲主迴圈**、**NPC 即時行為**（僅視野內）
- **量子坍縮系統**：惰性求值 + 事件日誌
- **經濟／政治／生態引擎**：獨立背景任務，各自 tick rate
- **WebSocket 伺服器**，處理最多 **10 名玩家**連線
- **持久化**：**PostgreSQL 權威**＋記憶體快取；JSON 非執行期唯一來源（見上方現況補註）

### 1.2 前端：網頁（HTML + CSS + JavaScript）

- **WebSocket** 連接伺服器
- **Canvas** 畫 2D 俯視地圖 + 符號移動
- **HTML 原生富文字**處理詞盤系統、對話、敘事
- **不需安裝**，開瀏覽器就玩

### 1.3 資料庫／持久化

- **現況**：遊戲狀態以 **PostgreSQL** 讀寫；`data/` 下 JSON 用於房間種子、設定與備援匯出等，**與「唯一真理在資料庫」並存**，詳見技術約束。
- **歷史**：曾為 SQLite → 過渡期全 JSON 管線 → 現行 **PG 主、雙寫／快取**（本節保留決策骨架，實作細節以現行約束為準）。

---

## 2. 架構核心原則

- **90,000 NPC 平時不跑**：只存狀態 + 上次觀測時間。
- **觀測發生時**：從事件日誌回推算出當前狀態（**延遲坍縮**）。
- **視野內 NPC** 才進入即時模擬（視野＝當前房間，見 [決策 005](005_room_cell_view_scope.md)：一格＝一房＝視線所及）。
- **全域系統**（經濟、政治、生態）持續在背景跑，產出事件流。

---

## 3. 與專案設計對齊

| 設計要點 | 對齊方式 |
| --- | --- |
| 後端唯一真理 | 伺服器為唯一邏輯與狀態來源；前端僅顯示與發送操作 |
| 萬名異步 NPC、觀測與坍縮 | 九萬 NPC 惰性存狀態；觀測時由事件日誌回推（坍縮）；視野內（同房）才即時模擬（決策 005） |
| 同服最多約十人 | WebSocket 最多 10 名玩家連線，與關鍵字一致 |
| 手機、無上架 | 網頁前端，開瀏覽器即玩，無需安裝與上架 |
| 城鎮即大地圖、以字符示意 | Canvas 2D 俯視 + 符號移動；詞盤／對話／敘事用 HTML 富文字 |
