# 決策 013：白塔半島正式活世界啟用

**狀態**：已定案、已部署並完成正式服務驗收  
**日期**：2026-07-20  
**承接**：[決策 011：世界場所與居民位置採單一真相](011_世界場所與居民位置單一真相.md)、[決策 012：Azgaar 完整作者資料作白塔半島底稿](012_Azgaar白塔半島物理地理橋接.md)

> 2026-07-21 補正：本決策的場所、路線、人物遷移與 active 世界仍有效；第 5 節的
> 柴枝束／粗礦式 P0 採集只保留為歷史守衡證據，已由
> [決策 014：Azgaar 白塔半島經濟橋接](014_Azgaar白塔半島經濟橋接.md) 停止顯示、
> 新產生、再生與人物採集。現行人物經濟改由有限市場工作與真實交易帳本承接。

## 問題

決策 011 建立了正確的場所、路線與人物位置權威，卻暫時仍讓 119 個舊格掌管
active 世界；決策 012 完整保留 Azgaar 作者資料，卻只停在非正典作者候選。兩者若
沒有接起來，玩家與居民仍活在舊局部素材裡，白塔半島也仍只是作者包和拓撲骨架。

本決策要同時避免兩個錯誤：不能丟掉 Azgaar 已完成的世界資料後重新手刻；也不能把
生成名稱、政治、文化或精確輪廓直接冒充奇點正典。

## 決策

### 1. 全量作者資料先分類，再編譯成正式執行世界

`white_tower_runtime_v1.json` 由固定 Azgaar package 編譯而成，保留來源檔、雜湊、
commit、seed 與 compiler version。17 個來源層逐一標示為：

- `runtime`：305 個物理區域與 1,644 條有向通行關係，全數啟用；
- `runtime_evidence`：原始格、高度、生態、1,129 條河流、1,666 個聚落、1,244 條
  原生道路、71 種商品、54 個市場與 25,808 筆交易，全數交代並影響區域能力、
  路線成本、資源或後續經濟依據；
- `retained_candidate`：23 個國家、487 個行省、9 種文化、14 種宗教、456 個標記與
  15 個事件／歷史覆蓋層完整保留，等待奇點設定校正；2026-07-21 已修正舊驗證漏算
  marker `id=0` 與 zone `id=0` 的問題，來源包本身沒有重生；
- `rejected_surface`：只拒絕把 Azgaar renderer 當作玩家 UI。

這不是刪資料後另造一張圖，也不是把所有作者內容無條件升格。

### 2. 執行權威與正典權威分開

37 個已接受白塔拓撲節點仍負責正典大地理。305 個低層區域與 1,644 條路線是
`canon=false` 的正式**運作資料**：人物現在能在其中生活與通行，但描述性工作名稱、
精確邊界、政治文化及道路名稱不因此成為正典。

玩家可見地名不得使用工程編號或 `文曜・丘地森林 08` 之類技術標籤。編譯器以既有
白塔錨點、相對方位、地形、水文、聚居和市場資料產生可讀描述；真正需要品味決定的
正典地名仍可日後逐一替換，穩定 `place_id` 不變。

### 3. 舊方格退出 active 世界，所有人物一次遷移

啟用交易會：

1. 先保存每個實體的舊 `place_id`、座標、room、旅程與身分狀態；
2. 依舊格在原範圍內的相對位置，確定性映射到白塔物理區域；
3. 原子更新 `entities.place_id`、相容 room 與旅程；
4. 將舊方格場所與路線標記為 `retired`，使其不能再被玩家或 NPC 尋路採用；
5. 保留 `rollback`，能從逐人備份恢復，不靠重新生成或猜測。

永久角色 `codex` 不被刪除、重建、歸零或當測試 fixture。其舊位置
`legacy:grid:1:-2` 被完整備份，正式映射為 `wt-physical-0254`；後續重啟保持同一
新位置與既有身分狀態。

### 4. 玩家與居民在同一世界規則下生活

玩家八方向移動與 1,553 名 NPC 的自主移動都讀同一份 active PlaceGraph，並走同一
位置交易。居民依場所能力進行移動、找工作、工作、交易、休息與社交；原因、目的地、剩餘
路徑、後果與思考都落入 PostgreSQL。無玩家連線與服務重啟都不會使居民回到舊格、
重擲整段旅程或失去既有思考。

### 5. 世界物質必須守衡（P0 實例已由決策 014 退役）

本決策當日曾以 305 個可回查 P0 來源驗證：採集同時減少來源並增加人物背包、每日
再生受容量上限約束、轉移帳本兩端相等。這個實例現已退役；只保留「文字不能憑空
創造結果」的守衡原則。

這一節記錄 2026-07-20 的守衡驗證方法，不再授權現行白塔採集柴枝束或粗礦。決策
014 沿用「不能無中生有」原則，改以市場有限金庫、人物鎂與物品的工作／交易帳本
承載現行經濟。

### 6. 正式玩家表面是文字 GUI，不是作者地圖或除錯看板

現行玩家表面直接投射權威 view：所在位置、可感知描述、正在生活的人、可接觸物件、
實際出口與行動結果。八方向以可點路線呈現；同方向有多條路時，以道路、野徑、渡船
或距離等真實路線差異區分，不把一條路蓋掉。

玩家移動、工作或交易後看見的是世界事實自然改變，不另加「世界已改變」狀態看板。Azgaar
作者圖不進玩家畫面；本決策也不把目前 CSS 細節升格為不可再改的最終美術定版。

## 操作與回復

```bash
cargo run --bin white-tower-runtime-check
cargo run --bin white-tower-runtime-db -- apply
cargo run --bin white-tower-runtime-db -- check
cargo run --bin white-tower-runtime-db -- rollback
```

`./start` 會在測試與 release 建置前執行 runtime 契約檢查；服務啟動時會冪等確保正式
世界已載入並完成遷移。

## 邊界

- 本決策啟用的是完整可運作的白塔物理底盤，不把所有生成內容變成正典百科。
- 37 個大地理節點、已接受白塔名稱及關係仍是正典；描述性低層名稱可被後續正典命名
  原位替換。
- 國家、行省、文化、宗教、標記與精確物理輪廓仍是保留候選，不因 runtime 使用而
  自動接受。
- 目前 1,553 名 NPC 已證明同一世界上的自主生活鏈；未宣稱已模擬白塔半島全部人口。
- 當前文字 GUI 已是可操作正式表面，不等於所有視覺語言、資訊密度、自由輸入、戰鬥
  與長程旅行表現都已定版。
