# 決策 016：Azgaar 上游供應場所實體化

- 日期：2026-07-24
- 狀態：已採用並通過 runtime 驗收
- 身分：工程決策，`canon: engineering`
- 延伸：決策 014 的作者經濟橋接、決策 015 的有限市場閉環
- 取代：決策 015 中「人物在市場工作時直接新增上游商品」的新寫入路徑
- 完整紀錄：
  [Azgaar 上游供應場所實體化](../../../obsidian-vault/wiki/05-專案/Singularity-World/60-工程實作/Azgaar上游供應場所實體化.md)

## 問題

決策 015 已讓市場庫存、消費、跨市場物流與玩家成交共用同一份有限量，但它把
Azgaar 的 `Burg → Market` 來源關係壓成市場內的供給輪廓：市場工人只要命中來源證據，
商品就直接出現在市場。數量可以守恆，來源地、工作地與移動過程卻被抹掉，因而不能算
完整的世界因果。

## 決定

完整利用現有 Azgaar 作者資料，不另編一份小型來源表：

- 將 4,976 筆允許進入 runtime 的 `Burg → Market` 來源交易逐筆編譯成上游供應輪廓；
- 來源聚落依既有地理映射落在 277 個正式 `world_places`，每個場所建立一個穩定的
  operational「地方供應站」工作場所；
- 供應站與供應輪廓是工程運轉層，不把 Azgaar 聚落名稱、產業或 277 個場所偷升成
  背景正典；
- 真實居民必須先受派到來源地，以「地方供應人員」身分在場工作；目的市場的有限
  金庫支付工資；
- 來源與市場同地時，有限商品直接進入該市場；不同地時，商品先成為
  `origin_kind=producer` 的實體貨運，由同一名工作居民沿 PlaceGraph 承運到市場；
- 市場工作仍可獲得營運工資，但不再自行生成商品。舊直接供應帳本只保留為歷史與
  既有守恆證據，不再新增。

## 資料與身分

| 層 | 數量／規則 | 含義 |
|---|---:|---|
| 來源供應輪廓 | 4,976 | 每筆都可回指一筆允許的 Azgaar `Burg → Market` 交易 |
| 來源實體場所 | 277 | 既有正式場所，不另造地圖節點 |
| 地方供應站 | 277 | 每地一個穩定 operational 工作場所 |
| 全部工作場所 | 331 | 277 個供應站加 54 個市場 |
| 供應人員指派 | 277 | 每個供應站都有一名真實自主居民 |

`world_supply_profiles` 保存來源交易、來源場所、目的市場、商品、來源量與運送成本；
`world_upstream_supply_ledger` 保存實際工作者、工作帳、來源供應輪廓、數量與去向。
遠距供應另進入 `world_market_shipments`，承運人、目前位置、目的地、路徑、滯留與
重派沿用既有物流規則。

## 因果與守恆

一次成功供應必須同時成立：

1. 來源輪廓、來源場所、目的市場與商品都存在；
2. 真實受派居民已抵達來源供應站，沒有另一次在途承運；
3. 目的市場庫存尚未達該來源輪廓的容量；
4. 目的市場金庫足以支付這次工作的工資；
5. 同地商品以同一交易入庫；異地商品以同一交易建立貨運、義務與居民旅程；
6. 工作帳、上游供應帳與市場／在途數量一致提交，任何一步失敗都不留下半套結果。

逐商品守恆把歷史直接供應與新上游供應都算在左側，把市場現存、在途、人物持有及
已消耗算在右側。來源地改為實體化不會重置既有庫存，也不會把舊帳刪掉後假裝從零開始。

## 活世界節拍校正

首次正式等待來源居民自然工作時，驗收發現主迴圈仍保留兩段舊 RoomGraph 時代的全體
寫入：每個遊戲時辰替全部居民重寫同一句時段想法，以及依排程重播離開、抵達與傳聞。
它們既不改變正式位置，也和 PlaceGraph 居民迴圈重複，卻會長時間占住單一世界節拍。
兩段舊寫入已移除；實際排程、PlaceGraph 移動、抵達、工作、事件及人物自己的思考仍在。

另外，跨地來源工作完成裝貨後，承運目的地、可見活動與立即喚醒會在同一次居民節拍
保留下來，不再被通用的「工作抵達」收尾短暫覆寫回供應站。這不是加快背景動畫，而是
讓工作帳、貨物義務、人物意圖與下一步移動從建立當下就指向同一個市場。

## 驗收

- `cargo check --all-targets` 通過；完整 `./start` 通過 Clippy、292 個測試、全部白塔
  檢查、release 建置與正式服務重啟；
- 啟動與資料庫檢查讀回 4,976 筆來源供應輪廓、277 個供應站、331 個工作場所，
  305 個正式場所與 1,644 條路線不變；
- 277 個供應站均有真實居民受派，職業讀回為「地方供應人員」，工作與休息排程使用
  人物當下的正式場所，而非舊方格或全域出生點；
- 正式服務在無玩家介入下等待到工作時段，自然產生 6 筆有工作帳的上游供應：
  2 筆同地入庫、4 筆遠距 producer-origin 貨運；
- 冷重啟後，最新 producer 貨運及承運居民都已從來源
  `wt-physical-0014` 抵達目的市場 `wt-physical-0013`；貨運狀態為 `delivered`，
  人物活動讀回「剛把1份蜂蜜送到市場」，意圖、目的地與人物位置一致；
- 最終 live 讀回 42 筆貨運，其中 4 筆來自地方供應、41 筆已送達、1 筆仍在途、
  0 筆滯留；市場 3,780 筆有限庫存的逐商品守恆差額為 0、錯配商品為 0。

## 未宣稱完成

這次補的是「既有來源資料如何成為世界裡的一次工作與一次移動」，不是完整奇幻現代
產業。Azgaar 的來源交易沒有提供可直接採信的工廠、農場、配方、設備、組織或所有權，
因此本決策不虛構製造鏈，也不把「地方供應站」寫成玩家必看的同名建築。製造、服務業、
物件用途與耐久、企業／家庭財務、契約信用、物流風險及奇幻能力對產業的影響仍是後續
缺口；它們必須接在這條真人、場所、有限金庫、有限物量與實體路徑上。
