# 決策 015：白塔半島有限市場閉環

- 狀態：已採用並通過 runtime／GUI 驗收
- 身分：工程決策，`canon: engineering`
- 延伸：決策 014 的 Azgaar 經濟來源橋接
- 後續校正：決策 016 將上游供應移回來源場所與真人物流
- 完整紀錄：
  [白塔半島有限市場閉環](../../../obsidian-vault/wiki/05-專案/Singularity-World/60-工程實作/白塔半島有限市場閉環.md)

## 決定

不在 Azgaar 來源資料旁另造一套小型經濟。以既有 71 種商品、54 個市場、3,834 筆
報價與 25,808 筆交易為來源，為 70 種允許進入 runtime 的商品建立 54 × 70＝3,780
筆實際有限庫存；數量只在第一次採用時由來源庫存建立，後續啟動只更新來源輪廓與
價格基準，不回填數量。

來源交易導出 1,029 筆市場供給輪廓、935 筆需求輪廓與 478 條跨市場流向。居民消費
只能減少有需求且可消耗的商品；
跨市場調貨必須由真實受派居民承運，先扣起點庫存、沿正式路線移動，再加到終點庫存。
市場成交把買方的鎂轉入市場工作場所金庫，金庫再支付真實工作工資。

2026-07-24 起，決策 016 取代本決策的直接供應新寫入：4,976 筆 `Burg → Market`
來源輪廓已落到 277 個正式來源場所；居民必須在來源地工作，同地才直接入庫，異地則
由該居民承運。市場工作不再因「有來源證據」而自行產貨。舊供應帳不刪除，繼續納入
既有世界的守恆。

## 玩家接縫

- 玩家與市場必須同地；經手者必須是該市場正式受派、存活、在場且未承運中的居民。
- GUI 必須保留至少一名可交易經手者，不得把他折疊進「其餘人影」；點選人物後的
  `交易` 直接讀取當下市場庫存與報價，成交後立即反映鎂、庫存與背包。
- 這是當地世界行動，不新增市場儀表板、經濟狀態看板或後端流水帳。
- 玩家與居民共用同一市場結算；居民購買可消耗品時另寫消耗 sink，不用假買家或
  背景刪除冒充需求。

## 內容邊界

- Azgaar 的人身商品完整保留為來源證據，但不建立 operational 庫存，也不能交易。
- `Coins` 及其 currency 標籤仍留在作者、市場與物流證據中，但不得出現在個人交易
  報價；玩家不會收到「買一份錢幣」的出戲內容。
- 船、火砲、車、貨盤、貨堆等非個人攜帶單位也不進個人報價。
- 舊 `mat_*`、柴枝束與粗礦式 P0 不進現行庫存、報價、供應、消費或物流。

## 驗收

- 完整 `./start` 通過 Clippy、289 個 lib 測試、各 bin、白塔契約、release 建置及
  systemd 重啟；
- 無玩家連線時，供應、消費與居民承運仍持續；冷重啟後 3,780 筆庫存沿用當下數量；
- 閉環驗收窗快照：初始量 110,193、帳本供應 1,269、現存市場量 110,844、在途 0、
  人物持有 0、已消耗 618，逐商品守恆差額 0；557 筆供應、618 筆消費、31 筆已送達
  貨運，沒有滯留貨運；
- 手機 390px GUI 實際由三段正式路線抵達文曜市場，點選真實經手居民，以 3 鎂買到
  1 份肥皂；畫面可見報價、扣款、成交與背包結果。該驗收帳號、交易、事件、記憶與
  關係已精準回收，市場商品與金庫只回復本次交易差額；全庫測試識別掃描為 0；
- 桌面 1440px 與手機皆無橫向溢出、console、page 或 request error；冷重啟後先前
  成交結果仍存在，再於驗收清理階段回收；最終桌面版另以 11 鎂買入 1 份武器並在
  背包讀回，證明 currency 排除後兩種尺寸都走目前程式。
- 驗收曾發現密集市場登入畫面已顯示，但同步寫相遇紀錄仍阻塞後續點擊二十多秒；
  登入後觀測已移到背景 blocking pool。最終紀錄為 20:15:10.229 玩家 ready 並排程
  觀測、20:15:11.218 收到首個點擊，約 0.99 秒內可操作。

## 未宣稱完成

這是可守衡、會自行運轉且玩家可實際接觸的有限市場，不是完整奇幻現代社會。決策 016
已補上來源場所、供應人員及來源到市場的實體移動，但仍缺製造鏈、服務業、物件用途
與耐久、家庭／組織財務、契約與信用、風險物流、
更完整職業與人口、政治及奇幻能力對生產生活的影響。後續只能在同一份有限庫存、人物、
場所、路線與帳本上擴張。
