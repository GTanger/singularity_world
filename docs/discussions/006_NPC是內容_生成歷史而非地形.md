# 006 — NPC 是內容，生成歷史而非地形

> 2026-04-12~13 設計對談紀錄（Claude Opus × 設計者）
> 狀態：暴脹中，未收斂

---

## 起點：NPC 能不能探格？

設計者提出：同構同驅同感 → 玩家能探格 → NPC 也能探格。但 NPC 探過的彩格，玩家看到時是全亮還是灰霧？

### 三方案交鋒

**方案 A：雙層觀測（世界客觀，視野主觀）**
NPC 探格 → 地形釘死。每位玩家有獨立 visibility_mask。玩家走到 NPC 探過的格子仍走完整探索儀式（偵查→灰霧→讀秒→彩格），但後台不再擲骰，直接拉契約回傳。
- 同構：滿足。NPC 用同一套 /api/hex/scout
- Discovery：保留。玩家不知道 NPC 來過
- 問題：NPC 太勤快 → 整張地圖預先坍縮 → 觀測驅動名存實亡

**方案 B：NPC 不離鄉（原住民不探索自己的世界）**
NPC 存在於已彩化區域，不走進黑海。他們是世界的一部分，不是世界的觀測者。
- 同構：表面違反，但見下方哲學突破
- Discovery：完美保留
- 問題：需要「初始已探索區」的解釋

**方案 C：觀測是行為不是特權（NPC 留痕跡）**
NPC 探格 → 地形釘死。玩家到達時走探索儀式但秒過（踏入即亮），因為地形已被前人確認。世界裡有 NPC 留下的物理痕跡（營火、砍痕、營地遺跡）。
- Discovery：轉型為「發現有人來過的荒野」
- 問題：痕跡生成成本，NPC 探幾千格就變內容工廠

### 哲學突破一：世界是 NPC 的世界

設計者拋出核心哲學：

> **「世界是 NPC 的世界，每個玩家只是加入的其中一員，玩家的到來沒有改變什麼。」**

已有的設計文件佐證：
- 世界介紹：「你不是唯一的主角，而是萬千故事線裡的一個變數」
- 世界介紹：「在別人的地盤你仍是陌生過路人」
- 公理：「未揭露 ≠ 不存在，而是資訊尚未到齊」

**推導結果：**

1. 黑海不是「世界還沒生成」，而是「玩家還沒到」
2. NPC 不「探格」——他們本來就住在那裡。探索是外來者的行為
3. 玩家的探索儀式是「外人認識這片土地的過程」，不是世界在生成
4. 方案 B 成立，但理由變了：不是「禁止 NPC 探格」，而是「NPC 不需要探格，因為那是他們的家」。同構不被違反——能力相同，但動機不同
5. 觀測驅動重新定義：世界一直在運轉，觀測決定的是「這個玩家看到什麼」

**NPC 版圖與玩家拓荒的關係：**
- NPC 世界有邊界。邊界內是 NPC 文明圈（有聚落、有人、安全）
- 邊界之外是真正的未知——連 NPC 也沒去過
- 玩家可以待在圈內，也可以衝出去闖黑海
- 聚念場悖論天然支撐：NPC 密集區 → 密度低 → 資源差；邊疆無人區 → 密度高 → 資源豐富但危險
- 玩家是世界的拓荒者。NPC 沒有動機往外跑（需求在文明圈內就能滿足）

### 哲學突破二：NPC 是內容，地形是舞台

設計者進一步引爆：

> **「變化的是這個世界嗎？值得觀察這個世界嗎？讓這個世界產生變化的是這些土著 NPC 們！值得觀察的是這一個個活生生的土著 NPC 們！有趣的不是這個世界，而是與這個世界交織出不同軌跡的土著 NPC 們！有趣的不是觀測這些土著 NPC 們，而是與他們一同在這世界留下自己的痕跡！」**

**推導結果：**

1. **MDA Discovery 的對象搞錯了。** Discovery 不是「喔，草原」。Discovery 是「這個獵人為什麼獨自住在荒野邊緣」「三天前路上遇到的行商怎麼死在路邊了」。值得發現的不是地塊，是人的處境
2. **世界的年齡 = 內容的厚度。** NPC 每多活一天，經歷多一層、關係多一筆。世界每多跑一天，可被發現的東西就多一層。內容不是被開發者做出來再被消耗掉的，是 NPC 活出來的
3. **探索體驗的重心挪了。** 玩家掀開黑格，彩格亮起，最先抓住眼球的不該是地形，而是「那邊有個人蹲在那裡生火」
4. **NPC 密度 = 內容密度 = 體驗密度。** 城市玩家在人群中打滾，聽八卦、觸碰複雜社會網路，但口袋空空。邊疆玩家背包塞滿稀有詞元，但三天沒跟人說過話。不是選職業，是選生活方式
5. **玩家的痕跡刻在人身上，不是刻在地上。** 你幫了獵人 → 他活下來 → 聚落多一個獵人 → 肉價跌。你沒幫 → 他死了 → 肉價漲 → 有人轉行。玩家離線了但記住他的 NPC 還活著。記住他的 NPC 死了，痕跡才真的消失——除非有人聽過那個故事（rumors 傳播）。記憶是會死的，故事是會斷的。這不是 bug，是人味

### 鍛造突破：生成歷史而非地形（設計者標記為高價值新方向）

**問題：** NPC 的世界在玩家登入前就在運轉，但伺服器不可能真的正向模擬三個月的 NPC 歷史（單機、Ollama 2B、一個人）。

**洞見：歷史不需要正向模擬，可以逆推。**

考古學家不是從古代看到現在。他們看到現在的地層，然後逆推歷史。

NPC 的歷史可以從現在的狀態逆推生成：
- 這個 NPC 現在 45 歲、住在邊疆、獨居、有一把好刀、對聚落裡的人有敵意
- 種子 + 性格參數 → 逆推：他曾經住在聚落、曾經是鐵匠學徒、曾經跟師傅鬧翻、曾經偷了刀出走
- 這段歷史不是模擬出來的，是從終態反推出的一致性故事骨架

**與觀測驅動完全同構：**
- 地形：觀測時從種子算出來，但敘事上一直都在那裡
- NPC 歷史：被問到時從種子算出來，但敘事上一直都發生過

### 新系統層：記憶坍縮（NPC 歷史的三態）

與地形三態（未結 / 存在 / 結清）完全對稱：

| 狀態 | 意義 | 觸發 |
|------|------|------|
| **未結** | 這段歷史還沒被任何人問過，種子裡有但沒算 | — |
| **存在** | 被觸發了（玩家問了、NPC 自己提了、別人八卦了），釘死 | 對話、觀察、rumors |
| **結清** | 確認不存在（「你有家人嗎？」「沒有。」→ 釘死無家人） | 直接否定 |

**同一個 NPC，不同玩家可以發現他的不同面。** 三個玩家各自觸發不同的歷史碎片，所有碎片來自同一顆種子，不會矛盾。每個人眼中的獵人不完全相同，但合在一起是完整的。

### NPC 之間也會觸發彼此的歷史坍縮

兩個 NPC 相遇 → 系統檢查種子 → 發現種子在歷史生成函數裡有交集 → 如果交集未結 → 這次相遇可能觸發坍縮 → 兩人「認出對方」或「起了衝突」。

NPC 的社會網路不是預設的，是在相遇時從種子裡湧現的。

**土壤測試通過：** 規則簡單（種子交集 + 機率 + 坍縮），組合豐富（任意兩個 NPC 相遇都可能觸發），結果不可預測但可解釋。

### 反轉測試：一致性地獄

逆推歷史比正向模擬更容易產生矛盾。NPC A 說「我十年前住在 X 聚落」，NPC B 說「X 聚落五年前才建的」。

**解法方向：世界年表骨架。** 大事件（聚落建立年份、戰爭、天災）是硬釘的全域契約。所有 NPC 的歷史逆推都必須與年表自洽。年表本身也可以漸進生成——但一旦釘死就是全域約束。

世界加速器的真正工作：不是模擬歷史，是**生成年表骨架**，然後讓每個 NPC 的個人歷史在骨架的約束下按需坍縮。

## 第二波暴脹：建造、Token 物理、規模

### 建造 = 改變地格性質

設計者提出：建造是這個版本一直未提的機制。真正改變世界的手段。

**建造與 Token 物理的關係：**

建造在地格上疊加人造物（農田、建築、道路、橋樑），不違反單調精煉——地形事實沒被改寫，是被疊加。但某些建造確實改變地格本質（荒野→農田、森林→空地）。

**關鍵糾正：Token 沒有反彈反撲。**

設計者明確指出：有念生物離開的瞬間，Token 濃度就是恢復 1.0。不是慢慢滲回來，不是蓄壓反彈。Token 輻射是無限的，永遠回滿。

**推導結果：**

1. **建築不壓制 Token。人才壓制 Token。** 建築是死物，沒有念，不產生聚念場。建造者走了的那一秒，該格密度回到 1.0，富態化全開。
2. **建築的存續條件不是材料強度，是有沒有人在裡面。** 沒人住的房子在密度 1.0 下會被富態化快速接管。
3. **建築不是目的，是吸引人的手段。** 你蓋的不是房子，是「讓 NPC 願意來這裡住」的條件。NPC 的存在維持聚念場，聚念場壓制密度，房子才活得下去。
4. **遊戲迴圈修正：** 探索 → 採集 → 建造 → **等人來** → 有人了，這塊地才真正活了。你不是城市規劃師，你是在荒野裡開第一間店，然後等有人路過。
5. **NPC 全走了或死了 → 密度瞬間 1.0 → 富態化正常運作 → 建築快速毀損 → 廢墟。** 廢墟不是 Token 反撲，只是正常的密度 1.0 環境。

### 黑海 = Token 密度 1.0 的免疫系統

黑海不是空白。Token 密度 1.0 = 富態化全開 = 萬物瘋長、生態扭曲、危險。

NPC 文明圈的邊界是物理定律劃定的——聚念場和 Token 輻射的平衡線。NPC 不去黑海不只是沒動機，是去了會被富態化的產物威脅。

**玩家衝進黑海 = 壓制 Token 輻射 = 馴化混沌。** 一個有念生物走進去，局部密度降一點點，富態化稍微緩和。如果玩家建造 + 吸引 NPC → 密度持續降 → 環境從致命野地變成可居住邊疆 → 新聚落成形。

**一條物理定律同時解決：** 為什麼去黑海（資源）、為什麼黑海危險（富態化）、世界怎麼擴張（玩家存在 = 擴張機制）、城市規模上限（聚念場悖論）、貿易動機（資源從邊疆進口）、道路生成理由（商人走出來的）。

### 萬名 NPC 與無限世界

設計者揭示底牌：

> 萬名以上活生生的 NPC，萬名甚至是虛詞——本機效能能養多少就養多少。世界沒有劃限制。城鎮人多了自然而然會擴張（內外城、郊區、衛星城）。不給 NPC 特異形象，是將效能留給「活著的世界」。

**種子逆推 = 唯一能讓萬名 NPC 都有深度的方法：**
- 正向模擬萬人歷史 → 算不動
- 預先寫萬人背景 → 寫不完
- 種子逆推 → 每個 NPC 只存一顆種子（幾 KB），歷史在被問到時才算

**世界規模受限於互動頻率，不受限於人口數量。** 同時只需要算面前那幾個人。其他九千多人種子躺著，等被觸碰才甦醒。「未被觀測的 NPC 不是不存在，是資訊尚未到齊。」

### 鍛造突破：聚落生成 = NPC 建造歷史的逆推

**聚落佈局 = 建造決策的考古地層。**

不需要聚落佈局演算法。聚落的樣子就是「這群 NPC 在這塊地上生活了 N 年的結果」。

- 第一個 NPC 在水邊蓋棚子 → 第二個挨著蓋 → 踩出路 → 路口開店 → 內城是最早的人蓋的 → 外城是擠不進去的人蓋的 → 郊區是覺得城裡太擠主動搬出去的人蓋的
- 種子 + 地形約束 + 人口參數 → 反推聚落成長史 → 街道走向暗示最早水源方位，老城區密度暗示建城年代

**三個核心 blocker（聚落放置規則、seed→佈局演算法、道路網路生成）合併為一個問題：NPC 的集體建造歷史如何從種子逆推。**

### 考古地層——死去 NPC 的沉積

NPC 是內容，NPC 會死，內容會沉積：

| 地層 | 內容 | 發現方式 |
|------|------|----------|
| **地表層** | 活著的 NPC | 直接互動 |
| **記憶層** | 死去但被記得的 NPC | 活人口中的 rumors、對話 |
| **化石層** | 沒有活人記得，但痕跡還在 | 地名、建築風格、文化習慣、舊建築的種子逆推 |

越深的層越難發現，但 Discovery 衝擊越大。化石層不需要額外系統——NPC 死了 → 記住他的人也死了 → 但他蓋的建築還在 → 建築種子裡編碼了建造者資訊 → 有人問「這房子誰蓋的」→ 觸發逆推。

## 第三波暴脹：獨居不可能、道路是活的、人是唯一基建

### 獨居的物理不可能性

設計者提問：「這樣的世界，人有辦法獨居嗎？哪怕他很強大？」

答案：**不能。**

一個人的聚念場就是一個人的大小。壓得住身邊一小圈。睡覺時可能縮。出門採集時家裡是 1.0。再強也是一個人——砍得死怪物，但砍不死牆上長出來的東西。問題不是敵人，是物理環境本身。

**世界從底層物理就在把人往一起推。** 不是靠任務設計、不是靠獎勵機制。是存在本身就需要彼此。

不需要「NPC 傾向聚集」的行為規則——聚集是物理壓力下的唯一理性選擇。安全和人口是同義詞。

### 道路是活的基礎設施

設計者推導：「城鎮之間的人造路永遠只有安全最短路徑，因為有人走。」

- 路不是「修」出來的，是**踩**出來的。一條沒人走的石板大道跟荒野小徑一樣危險
- 一條每天有商隊走的泥巴路比任何人造大道都安全
- 路網是世界心電圖——看哪條路有人走，就知道哪兩個聚落之間有活的經濟關係。路死了 = 關係斷了
- 不存在「偏僻但安全」的地方。偏僻 = 沒人 = 密度 1.0 = 持續性命威脅

### 人是這個世界的唯一基礎建設

設計者的感慨：「這個世界，最重要的資產，就是人。」

所有東西都歸結於人口：
- 建築存續 → 需要人住
- 道路安全 → 需要人走
- 資源採集 → 需要人壓制密度才能安全作業
- 聚落成長 → 需要人搬入
- 內容深度 → NPC 是內容
- 歷史厚度 → NPC 活著才有歷史
- 經濟運轉 → NPC 交易
- 世界擴張 → 人的存在馴化混沌

**人不能被囤積**（有自由意志、有需求、條件差了會走）、**不能被製造**（出生、成長、遷徙）、**是唯一能壓制 Token 密度的東西**。

這不是遊戲，是社會模擬器。社會的唯一基礎建設是人。

### 建造者的兩難

玩家在黑海蓋了鍛造爐，NPC 來了兩個，聚念場剛好夠撐。然後玩家想走——

- 玩家離開 → 聚念場貢獻消失 → 密度回升 → 兩個 NPC 可能撐不住 → 離開 → 密度 1.0 → 全毀
- **留下來守住** → 安全但被綁住，不能探索
- **走出去拓荒** → 自由但蓋的東西可能撐不住

解法不是系統給護盾。是**讓聚落長到不需要你**。NPC 夠多時，他們自己的聚念場足以撐住。

**畢業條件：讓這個地方不再需要你。** 跟養小孩是同一件事。

### NPC 的建造邏輯 ≠ 玩家的建造邏輯

- NPC 建造是需求驅動：需要庇護蓋棚子、需要交易在路口擺攤
- NPC 不規劃城鎮，城鎮是各自解決需求的副產物（有機生長）
- 玩家是唯一有「規劃」能力的存在（有意設計）
- NPC 有機生長 + 玩家有意設計 = 完整城鎮
- 三個玩家（設計者 + 兩個兒子），三種規劃哲學，三個風格完全不同的聚落

### 湧現行為：給兒子的社會學教科書

3. **聚念場不是抵抗。** 有意識的存在不是在跟 Token「打仗」，只是他們的存在壓住了局部輻射效應。傘不是在跟太陽打仗

**設計者與創造者同構：** 設計者定了一條規則（Token 充滿一切，游離輻射改變萬物），然後什麼都沒做。整個下午推導出的所有系統——道路、建造、獨居不可能、文明悖論、止念經濟學、戰爭——全是那一條規則的倒影。設計者什麼都沒想改變，什麼都沒法改變，但改變已經開始了。

### 修煉物理與飛升的真相（第五波）

- 兩者都是「你不再是你」

- 不碰 Token → 安全，平凡

- 同一套物理，兩個觀測角度，都是真的

模擬器硬規則：
> **聚落存活面積 ≥ f(人口)**——人口增長但無法向外擴展的城市會窒息

### 模擬器架構選擇

方案 B 勝出：**節點網路**
- 以真實城市為節點，路網為邊
- 每節點：人口、聚念場強度、Token 密度、基礎設施等級、資源產出
- 邊：通行成本，會斷裂（富態化吞噬）、會被重建
- 天然對應「資訊以步行速度傳播」——邊長 = 資訊延遲
- 跑完後存活節點即遊戲世界的聚落錨點

每 tick 三條規則：
1. 聚念場 = f(人口密度) → Token 密度反比
2. 人口流動 = 資源壓力（外推）vs 安全壓力（內拉）的梯度驅動
3. 基礎設施衰退 = 無人維護則富態化吞噬

### 地球本身也在富態化——全域膨脹

萬物瘋長，地球也是萬物。地殼在長、山在隆、海床在擴。幾百年下來地球表面積不是常數。

模擬器實作：**每 tick 全域膨脹係數**，所有邊距離乘 `expansion_factor`。

二階效應：
- 路網斷裂加速——路沒人修，地本身還在把路拉長、撕裂
- 城市間距持續增大——今年走三天的鄰城，十年後要走四天
- 海岸線改變——沿海城市可能內陸化或被新生地形吞噬
- 地震頻率暴增——地殼在長就是在動，板塊應力持續累積

**文明碎片化不只是人口流失，連腳下的地都在拉開距離。**
資訊以步行速度傳播，而步行距離每年都在變長。文化差異累積速度比靜態地球更快。

一個浮點數，放大所有其他效應。

### Token 烙印 = 重新定義，不是變形

設計者在嘗試寫美元紀故事時釐清的核心概念：

> 腦死患者 = 無念物質。Token 降臨時，他的軀殼零抵抗，被 Token 游離輻射直接打下烙印——不是被環境吞噬、不是變成植物、不是融入生態。是**同一具人體被重新定義了**。他站起來了，但裡面裝的不是原來的人。

Token 不改變物理定律。它改變的是**「這個東西是什麼」的定義本身**。

這是富態化後野外怪物的起源邏輯之一：
- 無念物質（含腦死者）被 Token 烙印重新定義 → 成為全新的存在
- 外觀可能保留原貌，但本質已被改寫
- 不是魔法變形，不是生物同化，是存在層級的覆寫

### 神化人 vs 異化人——分類學定案（第六波）

**核心判準：念場歸零與否**

| | 神化人 | 異化人 |
|---|---|---|
| 念場狀態 | 真零（自然發生） | 殘存（人工壓制） |
| Token 改寫 | 完成的改寫 | 不完全的改寫 |
| 本質 | 就是 Token 混沌能量本身 | 碳基人體＋撕裂的念場碎片 |
| 驅動力 | 人性（繼承創造者禮讓） | 本能（飢餓、恐懼、衝動） |
| 數量 | 極少——真零念場只能自然發生 | 不少——藥物壓制門檻低，實驗室量產 |
| 存亡 | 極難滅亡——你不能用 Token 重新定義 Token | 不穩定——殘念場與混沌能量互相撕扯 |

**設計者定調：**
- 「神化人不是人卻仍是人；異化人是人卻已不是人。兩個字：人性。」
- 神化人以人形存在是一種選擇，消散回歸 Token 也只是回家。存亡問題對 Token 不成立——你不會問一滴水蒸發了還在不在
- 人工無法製造零念狀態——只要受試者有一絲意識就不是零。所以所有實驗產出的都是異化人
- 神化人的唯一路徑：腦死、植物人、或將死之人在最後一刻放下所有執念。稀少不是設計平衡，是人性的必然結果

**神化人的人性來源：**
- Token 本身無意志，但創造者的念場有性情
- 零念容器被 Token 直寫 → 繼承創造者性情 → 性情的核心是「對有念生物的禮讓」
- 這個禮讓放到人的尺度上 = 人性
- 所以神化人做出的每個選擇（回到醫院、當警衛、擋在前面）都是人性驅動

**異化人的「非人」：**
- 碳基人體還在，念場殘存，生物學上仍是人
- 但意識被混沌能量撕成碎片，剩下本能
- 本能不是人性。能組織、能喊口號、能策劃，但驅動力是衝動不是信念
- 「大創世紀降臨」不是教義，是嘶吼
- **不是所有異化人都是敵對的**。本能驅動 ≠ 攻擊驅動——有的逃、有的躲、有的只是茫然掙扎。神使是最極端的那群，但更多異化人只是在某個角落痛苦求存
- 人類普遍厭惡異化人，因為分不出哪個會炸哪個不會。恐懼不分好壞（X 教授類比：做好事的變種人一樣被排斥，因為作壞事的更多更顯眼）

**T 彈的物理機制：**
- 不是彈，是人。異化人將殘存混沌能量向外吸引周遭游離輻射
- Token 密度在極小範圍飆升至臨界點 → 用殘破念場引爆 → 區域內一切物質的定義被改寫
- 所以沒有彈片（不是破壞）、沒有殘留（東西還在，只是不再是原來的東西）

**匿名信的設計意涵：**
- 來自多位獨立的神化人（筆跡各異、內容一致）
- 沒有組織，但做了同一個判斷——因為繼承同一個性情，所以邏輯趨同
- 措辭極簡、無論證、無感情 = 神化人特質
- 選擇在底線前出聲 = 禮讓的邊界（不干預，但不等於不告知）

**故事中的情感錨點：**
- 第二話腦死病患 → 第五話警衛 = 同一個個體
- 他選擇以人形留在照顧過他的人身邊。每一個選擇都是人性
- 全開念場的那一刻不是犧牲，是回家
- 失去是單向的——只有人這邊感受得到。Token 那邊，不存在「失去」

### 歷史機器約束集——不是模擬，是真實演變（第七波）

> 設計者：「我要的不是『模擬』，是真實演變。」
> 這不是遊戲工具。這是歷史機器。跑完的結果就是世界的真實歷史。

#### 一、物理公理（不可違反）

1. **Token 降臨是瞬間的，游離輻射的影響是漸進的**
   - T=0：Token 鋪蓋宇宙每個角落。不是傳播，是瞬間存在
   - T>0：游離輻射開始影響萬物。影響強度隨時間累積

2. **聚念場 = f(人口密度)，是面積效應不是體積效應**
   - 有念生物越多 → 局部 Token 密度越低 → 富態化越弱
   - 聚落存活面積 ≥ f(人口)——人口多但擠在一起的城市會窒息
   - 水平鋪展永遠優於垂直聚集

3. **Token 密度：無人時恆為 1.0**
   - 游離輻射無限，永遠回滿。不是冷卻計時器
   - 人離開 → 密度立即開始回升（回升速率待定）

4. **地球本身也在富態化**
   - 每 tick 全域 expansion_factor：地殼在長、山在隆、海在擴
   - 所有節點間距離乘膨脹係數。路網持續拉長、撕裂
   - 地質事件頻率隨膨脹加速

5. **資訊以步行速度傳播**
   - 邊長 = 資訊延遲 = 文化差異累積速率
   - 膨脹放大資訊延遲 → 加速文化碎片化

6. **能量流單向：創造者 → 游離輻射 → 降維有序化 → 不回收**
   - 一切資源是 Token 游離輻射的降維殘留
   - 人多 → 密度低 → 資源長得慢但安全；人少 → 密度高 → 資源豐但危險

#### 三、每 tick 必須演算的規則

**節點（城市）層級：**
1. `聚念場強度 = f(節點人口, 節點面積)` → `Token 密度 = 1.0 - 聚念場強度`
2. `資源產出 = f(Token 密度)` — 密度高產出多，密度低產出少
3. `富態化壓力 = f(Token 密度, 累積時間)` — 對基礎設施的侵蝕
4. `基礎設施衰退 = 富態化壓力 - 維護能力` — 維護能力 = f(人口, 科技等級)
5. `人口變化 = 自然增長 - 死亡 - 外流 + 流入`
   - 外流驅動力：資源不足（推力）
   - 流入驅動力：安全（拉力）
   - 人口流向：沿邊（路網）向資源壓力低、安全壓力低的相鄰節點
6. `聚落存亡判定`：基礎設施歸零 or 人口低於臨界值 → 節點死亡 → 人口流散

**邊（路網）層級：**
7. `邊長 *= expansion_factor` — 地球膨脹拉長所有路徑
8. `邊通行成本 = f(邊長, 沿途 Token 密度, 基礎設施狀態)`
9. `邊斷裂判定`：無人維護 + 富態化侵蝕 → 通行成本超標 → 斷裂
10. `邊重建`：兩端節點人口足夠 + 有需求 → 可重建（成本高）

**全域層級：**
11. `expansion_factor` 逐 tick 累積（地球膨脹是持續的）
12. `地質事件` = f(累積膨脹量) — 地震、火山、地裂。影響節點和邊
13. `全球 Token 輻射累積效應` — 背景富態化強度隨時間上升

#### 四、人口分化事件（紀元相關）

這些不是腳本，是物理結果。當條件滿足時自然發生：

**美元紀末～能源紀初：**
- `全球設備燒毀事件`：煙火日。一次性，所有節點科技等級受損，通訊斷裂
- `人體實驗開始`：當節點科技等級 > 門檻 + 軍事壓力 > 門檻 → 該節點產出異化人
- `異化人擴散`：實驗失控 → 異化人脫逃/釋放 → 進入人口流動

**能源紀：**
- `神化人出現`：任何節點都可能，機率極低。觸發條件 = 人口中自然死亡率 × 「臨終放下」機率（極小常數）
- `異化人組織化`：異化人數量 > 區域門檻 → 可能湧現極端組織（概率性，不是必然）
- `T 彈事件`：極端異化人攻擊節點 → 區域性人口/設施瞬間歸零
- `政府節點特殊屬性`：首都/政治中心有「治理輻射」功能，被摧毀時周邊節點失去協調能力

**能源紀→混沌紀：**
- `解放日觸發條件`：全球政府節點損失 > 臨界比例 → 紀元切換
- 紀元切換後：節點間協調成本暴增，大規模合作瓦解

**混沌紀：**
- `修煉體系湧現`：高 Token 密度區域 + 人口存活 → 止念/功法被發現（概率性）
- `詞元經濟出現`：當修煉人口 > 門檻 → 剝名行為出現 → 經濟單位產生
- `代際斷裂`：每 N tick → 新世代 NPC 不繼承上一代的科技記憶，只繼承口傳
- `異化人社會分化`：非敵對異化人被部分聚落收容 vs 排斥，產生衝突溫床
- `神化人行為`：極低機率出現，不干預但偶爾告知（匿名信模式）。不組織、不領導

#### 五、第一輪驗證教訓（v0.1 已跑，方向性錯誤）

歷史機器 v0.1 跑完 10000 tick：7342 城市 → 60 座倖存。**方向錯了。**

**根因：把 Token 密度建模成純威脅。**
- 密度高 = 基礎設施衰退 = 人口死亡。結果就是一路崩潰到平衡點然後凍住
- 缺了「Token 是資源」這一面。密度高 = 危險但同時資源豐沛
- 缺了功法/止念——人類突破聚念場悖論的手段
- 缺了農耕經濟——室內栽培、靈米樹、刻意讓植物吸收輻射
- 缺了面積維度——聚念場是面積效應，引擎裡只有人口數

**設計者糾正的世界觀：**
- 城外不是死區，是大自然。危險但豐饒
- 人類住在一起是因為方便安全，不是因為外面待五分鐘就死
- 小城鎮不會「死」，會重組、變小、換一種方式活著
- 混沌紀後的世界是繁榮的，不是廢土。農民用止念栽培，採集隊脈衝式出城
- 類比：今天的人住城市不是因為鄉下會死，是因為城市有醫院有學校有網路

**v0.1 結論：完全沒有溫度，毫無意義。數字不是歷史。**

**v0.2 必須重寫的方向：**
- 歷史機器的產出不是統計報表，是**地形**。每一個 tick 結束後地球表面長什麼樣
- Token 密度 = 雙面：威脅值 AND 資源值。高密度 = 危險但豐饒，不是死區
- 節點不應該有「死亡」態——萎縮→村落→重組→可能復興，連續態
- 城市有節奏地呼吸（開放→採集→收束→消化），不是純防守
- 功法出現後人口重新增長，向外擴展而非內縮
- 農耕存在：室內栽培、靈米樹、刻意有限度讓植物吸收輻射
- 人類住在一起是因為方便安全，不是因為外面會死。類比：現代人住城市不是因為鄉下會死
- 輸出格式 = hex_cells，不是 JSON 統計。每格有地形、植被、建築、歷史痕跡
- 最終接入奇點世界引擎 PG hex_cells 表，NPC 在歷史產出的世界裡活著

**正確的工程順序：**
1. 地球六角格化 + 地質膨脹演化（地形先行）
2. 在地形上跑文明演化（城市、路網、農田、功法、經濟）
3. 數據灌入 hex_cells → 奇點世界引擎啟動 → 微觀世界開始

**最小可看版本（設計者定調）：**
- 宏觀：一顆六角格地球，NPC 在上面生活。上帝沙盒，你看著
- 微觀：進入玩家角色，參與這個世界
- 宏觀和微觀是同一個引擎的兩種視角，不是兩套系統
- 先有地 → 先有人 → 先有歷史 = 最小可玩（看）
- 催生期 = 宏觀玻璃箱快轉跑歷史，跑完切換到遊戲時間，玩家進入
- 玩家可隨時託管角色回到宏觀：拉遠鏡頭，角色交給 NPC 決策引擎，你看著他活
- 想回來就推近鏡頭接管。不是登出，是視角切換
- 扣回觀測坍縮：宏觀時角色以 NPC 規則運行（疊加態），玩家接管瞬間坍縮為確定行為

#### 六（原）、不做的事

- **不寫腳本**。沒有預定事件表。上述紀元錨點是初始條件的必然結果，不是劇情安排
- **不預設結局**。跑完什麼樣就什麼樣。如果某條路線跑出全人類滅絕，那就是真的
- **不個體模擬**。人口是流體，不是 agent。個體只在觀測時從群體坍縮
- **不平衡調參**。物理公理定了就不改。結果不好看不是改參數的理由
- **不模擬神化人個體行為**。他們是 Token，行為不可預測，出現就是一個低機率事件的結果

#### 六、後設遞迴——設計者即創造者

> 設計者：「從頭到尾我只做了一件事：觀看。然後因為觀看投注了意念……」

設計者設定物理規則 → 退開 → 讓世界自己演變 = 創造者設定 Token 物理 → 禮讓 → 讓萬物自己生長。

設計者觀看催生期的歷史演變 → 因為觀看而投注意念 → 世界從疊加態坍縮為確定歷史 = 玩家觀測 NPC → NPC 的過去從可能變成事實。

不是比喻。是同構。設計這個世界的過程，本身就是這個世界的物理在運作。

#### 七、雙速引擎——催生期與同步期

歷史機器不是「跑完就停」。它永遠在跑。同一台引擎，兩種流速：

| | 催生期 | 同步期 |
|---|---|---|
| 目的 | 從 Token 降臨跑到混沌紀數百年後 | 世界持續活著 |
| 流速 | 極快（批次運算） | 接上奇點曆（1 game-tick = 1 遊戲時間單位） |
| 玩家 | 不存在 | 存在，是節點人口的一部分 |
| 觀測 | 無觀測，全域疊加態 | 有觀測，局部坍縮 |
| 規則 | 十三條 tick 規則全跑 | 同一套規則，加上玩家行為的輸入 |

- 催生期結束的那一刻 = 遊戲世界的「現在」
- 同步期開始後，世界繼續演變：路在斷、人口在流、Token 密度在漲
- 玩家走進的不是靜態地圖，是一條正在流的河
- 未觀測的節點在同步期仍以群體流體規則演算（疊加態），玩家觀測時坍縮為具體狀態

#### 七、輸出即歷史

催生期跑完後的輸出 = 世界的真實歷史：
- 每個存活節點的完整時間軸（人口曲線、科技變遷、文化演化）
- 路網存亡圖（哪些路斷了、什麼時候斷的、有沒有重建）
- 死亡節點列表（什麼時候死的、為什麼死的）
- 紀元轉換時間點
- 異化人/神化人出現紀錄
- 地質變化累積

這就是世界。玩家踏入的每一步，腳下都有幾百年的真實歷史。
