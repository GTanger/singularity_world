## 一、格式檢查

### 1.1 結構（與 README §5 一致）

- **必要鍵**：`greet.lines`、`idle`（含 `morning` / `noon` / `evening` / `night`）、`talk.lines`；可選 `trade_announce.buy` / `trade_announce.sell`。
- **結果**：18 個檔案中 17 個結構正確；**gatherer.json** 原為 `Morning`/`Noon`/`Evening`/`Night`（大寫），已改為小寫以與其餘檔案及 README 一致。
- **greet/talk 數量**：多數為 48 句；farmer greet 45、mechanic greet 47、drunkard/guard/performer talk 47、blacksmith talk 51、scholar greet 49，皆在合理範圍。

### 1.2 已修正的格式／錯字

| 檔案 | 問題 | 修正 |
|------|------|------|
| gatherer.json | greet 最後一句缺閉合引號 `」`，導致 JSON 解析失敗 | 補上 `」` |
| gatherer.json | idle 時段鍵為 `Morning`/`Noon`/`Evening`/`Night` | 改為小寫 `morning`/`noon`/`evening`/`night` |

## 二、語句與邏輯

- **佔位符**：`【{name}】` 使用一致；`{goods}` 在部分 trade_announce 出現，符合 README。
- **引號**：台詞多用「」、『』，少數用 `"`；語意可讀，無明顯邏輯矛盾。
- **建議**：若後端依「時段」選 idle，請確認只讀小寫 `idle.morning` 等鍵（與 README 一致）。

## 三、與世界觀相符性

以下為**與現有世界觀文檔對照後**的差異或建議，是否修改由主管決斷。

### 3.1 貨幣用詞

- **設定**：經濟與角色模板以 **鎂** 為唯一貨幣（[經濟彙整](../reference/經濟彙整.md)）。
- **現狀**：對話中大量出現 **銅板、銀幣、金幣**，僅少數句使用「鎂」「鎂鈔」「鎂幣」。
- **建議**：  
  - **方案 A**：逐步將對話改為以「鎂」為主，必要處保留「銅板／銀幣／金幣」為市井俗稱並在文檔註明。  
  - **方案 B**：在設計文檔中明訂「對話內可混用俗稱，系統仍以鎂計價」，不再改寫既有句。

### 3.2 酸雨、廢土、末世感

- **設定**：[富態與拉鋸](../reference/世界觀：富態與拉鋸.md)：**無廢土感**；環境是「靜謐豐饒」「東西一直長但沒把自己吃掉」；**危險仍危險**但非「末世」「神蹟」。
- **現狀**：多檔出現 **酸雨**（腐蝕莊稼、防酸雨傘、酸雨水兌酒等）、**廢土**（scout「廢土上前行」「廢土生存指南」「廢土上流浪」）、mechanic「廢土版」、drunkard「廢土風禮帽」。
- **建議**：酸雨／廢土與「無廢土感、靜謐豐饒」相左，建議收斂：  
  - 若保留「惡地仍有危險」，可改為**偶發惡劣天氣**或**游離輻射較強區**的描寫，避免常態化酸雨與廢土語彙。  
  - 或於世界觀附篇明確允許「部分邊緣地帶／拾荒者視角」使用廢土感，與主基調區隔。

### 3.3 修真、修仙、法師、魔法

- **設定**：[Token降維與生命演化](../reference/世界觀：Token降維與生命演化.md) **附錄**：不走**修仙玄幻**；敘事為「宇宙觀測與物理降維」。
- **現狀**：多處出現 **修真者、修真、修仙練道、修真大能、修真門派**；**法師塔、魔法學徒、法杖、微光術卷軸、火球術、元素水晶** 等西幻／法術用語。
- **建議**：  
  - 「修真／修仙」可改為**止念、降維、點火、星盤、修士**等世界觀既有語彙，或改為「上層老爺」「練氣的那幫人」等不直接點名修真。  
  - 「法師塔、魔法」可改為**觀星塔、陣紋塔、靈光陣**或「高塔」「術士」等較中性詞，以符合「無車、電子與精密機械少見」的延伸設定。

### 3.4 靈力晶片、靈力電池、靈力槍、機械寵物

- **設定**：世界觀附篇—**無車**；**電子與精密機械**在人類聚落少見；不走賽博朋克。
- **現狀**：beggar「靈力晶片」、merchant「靈力電池」、scout「靈力槍」「金屬探測器」「機器人殘骸」、performer/guard「機械寵物」等。
- **建議**：若堅持「低精密機械」基調，可改為**玉簡、陣石、靈石**、**舊時代遺物**等不直接指向電子／機械的用語；或限定於**拾荒者／邊緣地帶**口吻，與主城「靜謐豐饒」區隔。

### 3.5 變異物種

- **設定**：富態化下野獸**更強、更致命**，但**危險仍危險**，非「末世變異」。
- **現狀**：「變異野鼠、變異毒蜘蛛、變異獸、變異劍齒虎、變異蹄髈、變異靈果」等大量出現。
- **建議**：可保留「更強的野獸」語意，用詞改為**富態化野獸、兇獸、異獸**等，減少「變異」帶來的廢土聯想；或於世界觀中明訂「變異＝富態化後之生物」為可接受俗稱。
