## 七、觀測與坍縮

**口語說明（缺什麼架構、程式在幹嘛）**

- **觀測**＝「誰被誰看到、什麼時候」。玩家進房或看房間時，同房的 NPC 要被打上「剛剛被這個玩家看到了」的戳記（`last_observed_at`），並記一筆「observed」事件。之後可以做「只有被觀測到的 NPC 才跑即時邏輯」之類的優化或敘事。
- **坍縮**＝「事後用事件日誌把某個 NPC 在過去某個時間點的狀態算回來」。`game.Collapse` 已依 `event.EventsInRange` 重放 TypeVit／TypeMove，回傳 (Character, roomID)；戰鬥結束寫入 TypeVit，敘事／查詢需要時可呼叫 Collapse。

**§七 已實作摘要**：7.1 房間制經 Observer（SetDefaultObserver、sendRoomView 呼叫 OnObserve）；7.2／7.3 進房觀測、離房恢復未觀測；7.4 Collapse 事件重放（vit／move）。

| # | 狀態 | 內容 | 備註 |
|---|------|------|------|
| 7.1 | ✅ | Observer/Observed 結構、OnObserve 經房間制串接 | main 設定 server.SetDefaultObserver(obs)；sendRoomView 對同房 NPC 呼叫 obs.OnObserve(id, c.PlayerID, now)；Observer 介面含 observerID。 |
| 7.2 | ✅ | 進入房間觸發觀測（同房 NPC 列表 → 標記觀測時間） | 經 7.1 Observer 或 fallback game.ObserveRoom；同房 NPC 寫 observed 並更新 last_observed_at |
| 7.3 | ✅ | 離開房間 → NPC 恢復未觀測狀態 | handleMove 取得 oldRoomID 後呼叫 onLeaveRoom；若該房無其他玩家則 db.ClearLastObserved 該房所有 NPC |
| 7.4 | ✅ | 坍縮回推：由事件日誌重建狀態（vit／move 重放） | game.Collapse 依 event.EventsInRange 重放 TypeVit／TypeMove；戰鬥結束寫入 TypeVit；回傳 (Character, roomID, error)。呼叫方可依需求於敘事／查詢時呼叫。 |
