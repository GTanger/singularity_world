奇點世界戰鬥系統概念文件**

**版本：** 1.0
**作者：** 奇點世界 AI 助理
**日期：** 2026.03.19

**1. 前言**

本文件詳細描述奇點世界戰鬥系統的核心概念、公式及設計思路。 該系統旨在為玩家提供策略性、豐富且具有變數的戰鬥體驗，並與遊戲的詞盤系統深度整合。

**2. 核心理念**

*   **半自動，策略性：** 戰鬥介於完全自動與玩家完全控制之間。 玩家需要做出戰術決策，伺服器負責處理細節與平衡。
*   **詞盤驅動：** 戰鬥的進行高度依賴詞盤系統，玩家通過詞元指令與遊戲世界交互。
*   **田忌賽馬：** 戰鬥強調資源的利用和策略的優勢，而非單純的傷害數值比較。
*   **戰鬥與生存：** 戰鬥不僅僅是傷害和死亡，更重要的是生存與反擊。

**3. 戰鬥流程**

1.  **進入戰鬥：** 玩家對怪物或 NPC 說出“攻擊”指令或相關詞元，觸發戰鬥。
2.  **詞盤交互：** 玩家和怪物在詞盤中進行交互，包括攻擊、防禦、技能使用、狀態變化等。
3.  **狀態異常：**  根據攻擊類型和玩家/怪物屬性，觸發狀態異常效果。
4.  **戰鬥結束：** 當一方的生命值降至 0 時，戰鬥結束。

**4. 核心公式**

`最終傷害 = 命中率 * (綜合傷害 - 敵方反擊) + 元素傷害加成 + 狀態效果相互作用 + 環境影響 + 玩家行動 + 怪物行動`

**公式分解：**

*   **命中率 (Hit Chance):**  玩家命中屬性 / 怪物回避屬性
*   **綜合傷害 (Total Damage):** 基礎傷害 + 裝備加成 + 技能加成
*   **敵方反擊加成 (Enemy Counter Attack):** 怪物反擊屬性 / 玩家防禦屬性
*   **元素傷害加成 (Elemental Damage):** 玩家元素屬性 * 怪物元素抗性 (如果怪物有元素弱點則乘以弱點係數)
*   **狀態效果相互作用 (Status Effect Interaction):** 所有施加在玩家和怪物身上的狀態效果對傷害的影響疊加計算
*   **環境影響 (Environment Effect):** 環境屬性 * 環境影響係數
*   **玩家行動 (Player Action):** 玩家選擇的詞元/技能 + 玩家行動技能係數
*   **怪物行動 (Monster Action):** 怪物選擇的詞元/技能 + 怪物行動技能係數

**各項的詳細說明:**

*   **基礎傷害 (Base Damage):** 玩家攻擊屬性 * 武器攻擊屬性
*   **裝備加成 (Equipment Bonus):** 裝備屬性 * 裝備加成係數
*   **技能加成 (Skill Bonus):** 技能屬性 * 技能加成係數
*   **狀態效果 (Status Effects):**  例如：
    *   毒素: 降低生命恢復速度
    *   麻痺: 使怪物無法行動
    *   沉默: 使怪物無法發出聲音（和攻擊）
    *   減速: 降低移動速度
*   **環境因素 (Environmental Factors):**
    *   火焰: 火焰屬性攻擊加成，火焰抗性降低
    *   水域: 水元素攻擊加成，水元素抗性降低

*   **命中率 (Hit Chance):**  決定玩家攻擊是否會對怪物造成傷害，如果命中率小於1，則基礎傷害失效。

**5. 重要注意事項**

*   此公式為核心戰鬥邏輯，需要根據實際遊戲平衡調整各個係數。
*   不同詞元/技能、裝備、怪物、環境因素會影響公式的各種參數。
*   狀態效果相互作用需要仔細設計，確保效果的合理性。

**6. 未來發展**

*   進一步完善狀態效果和技能機制。
*   添加更多的戰鬥變數，例如暴擊、連擊、元素傷害、地形等等。
*   引入更複雜的戰鬥AI，讓怪物可以根據玩家的行動做出更智能的反應。

**7. 附錄** (未來補充詳細數據與參數)

1. 基礎傷害計算 (核心基石)**
   *   `基礎傷害 (Base Damage)` = 玩家攻擊屬性 (Attack Attribute) * 武器攻擊屬性 (Weapon Attack Attribute) = 1
   *   武器攻擊屬性基於武器類型 (劍、盾、弓等) 和等級 (稀有度) 調整。

**2. 防禦影響 (抵消傷害)**
   *   `實際傷害 (Actual Damage)` = 基礎傷害 (Base Damage) - 怪物防禦屬性 (Monster Defense Attribute) = 1

**3. 狀態異常觸發 (戰鬥變數)**
   *   `狀態異常閾值 (Critical Threshold)` = 基礎傷害 * 狀態異常類型係數 (Status Effect Coefficient) = 1 （例如：毒素：0.2, 麻痺：0.15, 沉默：0.1）
   *   狀態異常類型: 毒素、麻痺、沉默、減速、出血、中毒、詛咒等。
   *   狀態異常持續時間根據傷害大小和玩家/怪物抗性決定。

**4. 裝備與技能加成 (強化戰鬥)**
   *   `裝備加成 (Equipment Bonus)` = 裝備屬性 (Equipment Attribute) * 裝備加成係數 (Equipment Bonus Coefficient) = 1
   *   裝備加成係數基於裝備類型（近戰、遠攻、法術）和稀有度調整。
   *   `技能加成 (Skill Bonus)` = 技能屬性 (Skill Attribute) * 技能加成係數 (Skill Bonus Coefficient) = 1
   *   技能加成係數基於技能類型（攻擊、防禦、回復、控制）和等級調整。
   *   技能類型：攻擊技能、防禦技能、控制技能、回復技能、buff技能等。

**5. 命中率 (機率控制)**
   *   `命中率 (Hit Chance)` = 玩家命中屬性 (Player Hit Attribute) / 怪物回避屬性 (Monster Dodge Attribute) = 1 (可能出現0，代表一定會被擊中)

**6. 傷害減免 (敵方反擊)**
   *   `敵方反擊加成 (Enemy Counter Attack)` = 怪物反擊屬性 / 玩家防禦屬性 (Player Defense Attribute) = 1

**7. 暴擊 (高危險)**
   *   `暴擊機率 (Critical Hit Chance)` = 玩家暴擊屬性 (Player Critical Attribute) / 怪物暴擊抵抗 (Monster Critical Resistance) = 1
   *   暴擊傷害 = 基礎傷害 * 暴擊倍數 (Critical Multiplier) = 1

**8. 連擊 (持續傷害)**
   *   `連擊機率 (Combo Chance)` = 玩家連擊屬性 (Player Combo Attribute) / 怪物連擊抵抗 (Monster Combo Resistance) = 1
   *   連擊傷害 = 基礎傷害 * 連擊倍數 (Combo Multiplier) = 1

**9. 元素傷害 (元素弱點)**
   *   `元素傷害加成 (Elemental Damage)` = 玩家元素屬性 (Player Elemental Attribute) * 怪物元素抗性 (Monster Elemental Resistance) = 1 (元素弱點則提高加成)
   *   元素類型：火、水、土、風、雷、光、暗等。

**10. 環境因素 (戰場影響)**
    * `環境影響 (Environment Effect)` = 環境屬性 (Environment Attribute) * 環境影響係數 (Environment Effect Coefficient) = 1 (例如：雨天提高水屬性傷害，火炕)
    * 環境類型：火焰、水域、冰原、黑暗、光明等。

**11. 狀態效果相互作用 (複雜性)**
    *  `狀態效果相互作用 (Status Effect Interaction)` = 狀態效果1影響 + 狀態效果2影響 + … = 1 (例如：中毒+麻痺疊加效果)

**12. 玩家行動 (策略性)**
    *  `玩家行動 (Player Action)` = 玩家選擇的詞元/技能 + 玩家行動技能係數 = 1 (例如：直接攻擊、閃避、迴避、使用技能)

**13. 怪物行動 (戰術性)**
    * `怪物行動 (Monster Action)` = 怪物選擇的詞元/技能 + 怪物行動技能係數 = 1 (例如：直接攻擊、逃跑、使用技能)

**備註：**
*   上述數值均为概念值，实际数值需要根据游戏平衡进行调整。
*   公式之间存在相互影响，需要仔细考虑。
*   可以根据需要添加更多的概念元素，例如生命值、魔法值、技能冷却时间等等。
*   这个框架可以作为构建更复杂、更动态的战斗系统的基础。

这个列表尽可能全面地囊括了现有概念。

1. 基本傷害計算 (基礎傷害)：**

*   `基礎傷害 = 玩家攻擊屬性 * 武器攻擊屬性`

    *   `玩家攻擊屬性`: 玩家在詞盤中選擇的攻擊詞元/技能對應的攻擊屬性值。
    *   `武器攻擊屬性`: 玩家所持武器的攻擊屬性值。
    *   這個公式代表了玩家攻擊的基本傷害值。

**2. 防禦影響：**

*   `實際傷害 = 基礎傷害 - 怪物防禦屬性`

    *   `怪物防禦屬性`: 怪物在詞盤中選擇的防禦詞元/技能對應的防禦屬性值。
    *   這個公式減去怪物防禦，代表了基礎傷害的抵消部分。

**3. 狀態異常觸發 (引入影響)：**

*   **狀態異常閾值 (Critical Threshold - CT):**  定義一個閾值，當傷害值超過該值時，觸發狀態異常。 CT 的值取決於攻擊的類型，例如：
    *   `CT_中毒 = 基礎傷害 * 0.2`
    *   `CT_麻痺 = 基礎傷害 * 0.15`
    *   `CT_沉默 = 基礎傷害 * 0.1`
*   **狀態異常判定:**
    *   `如果 (實際傷害 > CT) 則 觸發狀態異常`

    *   狀態異常的類型和持續時間取決於攻擊的類型。

**4. 裝備與技能加成：**

*   **裝備加成 (Equipment Bonus - EB):** 裝備提供的額外攻擊或防禦屬性加成。
    *   `裝備加成 = 裝備屬性 * 系數 (EB_coefficient)`
    *   `EB_coefficient`: 根據裝備類型調整的係數 (例如，攻擊型裝備的係數更高)。

*   **技能加成 (Skill Bonus - SB):** 技能提供的額外攻擊或防禦屬性加成。
    *   `技能加成 = 技能屬性 * 系數 (SB_coefficient)`
    *   `SB_coefficient`: 根據技能類型調整的係數。

*   **綜合傷害計算：**
    *   `綜合傷害 = 基礎傷害 + 裝備加成 + 技能加成`

**5. 命中率 (命中率的加入)：**

*   `命中率 = 玩家命中屬性 / 怪物回避屬性`

    *   `玩家命中屬性`: 玩家在詞盤中選擇的命中詞元/技能對應的命中屬性值。
    *   `怪物回避屬性`: 怪物在詞盤中選擇的回避詞元/技能對應的回避屬性值。
    *   如果命中率小于1，则实际傷害为0. 如果命中率大于1，则实际伤害为无穷大 (这需要谨慎处理，避免数值过大)。

**6. 傷害減免 (敵方反擊)：**

*   **敵方反擊加成：** 怪物反擊時，可以对玩家造成伤害减免。
    *   `反擊加成 = 怪物反击属性 / 玩家防御属性`
    *   `反击加成` 会用来扣除玩家受到的伤害。
