# 戰鬥公式概念設計：維度共振與數據對撞

本設計旨在提供戰鬥系統的底層邏輯框架。戰鬥結算應在後端一次性完成（或按回合連貫結算），產出完整的文字戰報。

## 1. 核心參數：外顯與內在的結合

### 1.1 外顯三維 (Effective Attributes)
- **有效體質 (EVit)**：生命基礎、減傷底色、抗壓穩定性。
- **有效氣脈 (EQi)**：技能燃料、回復率、意志護盾。
- **有效靈敏 (EDex)**：命中率、閃避率、行動頻率（時脈上限）。

### 1.2 內在三軸係數 (SoulSeed Multipliers)
- **能階係數 (α, Amp)**：暴力增幅、擴張性。影響傷害的「峰值」。
- **時脈係數 (β, Freq)**：節奏控制、收斂性。影響資源的「利用率」與動作的「連貫性」。
- **相位係數 (γ, Phase)**：變異機率、不可測性。影響「意外效果」（暴擊、偏轉、走火入魔）。

---

## 2. 戰鬥時序與行動頻率 (Initiative & Timeline)

專案不採「傳統回合制」，而是「行動槽點數 (Action Meter)」模型。

- **Tick 計算**：戰鬥進程以 100ms 為一一個 Tick。
- **行動蓄積 (AP Accumulation)**：每 Tick 恢復 `EDex * (0.5 + 0.5 * β)`。
    - *β (時脈) 的影響：代表神經反應的平滑度。高 β 者在同樣 EDex 下出手更快。*
- **發動門檻 (Action Threshold)**：
    - **基礎攻擊**：需要 100 AP。
    - **技能攻擊**：需要 `100 + Skill_Complexity_AP`。
    - **連擊 (Combo)**：若連發，下一次門檻增加 20%（直到休息一個 Tick）。

## 3. 衝突結算公式 (Conflict Logic)

當主動方 (Atk) 對 被動方 (Def) 發動動作時：

### 3.1 命中與閃避 (Hit & Evade)
- **判定係數 (K_Hit)** = [(Atk_EDex / (Atk_EDex + Def_EDex))](file:///home/tanger/Projects/singularity_world/world/map.go#42-49)
- **命中機率 (P_Hit)** = `Min(0.95, Max(0.05, K_Hit * 1.2))`
    - *修正：相位 (γ) 的干涉。若 Atk_γ 與技能屬性契合，命中加成 5%。*

### 3.2 原始傷害 (Raw Damage)
- **基礎傷害 (D_Base)** = [(Atk_Power + Atk_Gear) * (Resonance_Multiplier)](file:///home/tanger/Projects/singularity_world/world/map.go#42-49)
    - **Resonance_Multiplier**：
        - 一階（單詞）：1.0
        - 二階（成句）：1.5
        - 三階（純粹）：2.5
- **爆發係數 (D_Impact)** = `D_Base * (0.8 + 0.4 * α)`
    - *α (能階) 的影響：非線性放大。α 越高，傷害浮動的上限越高。*

### 3.3 減傷與修正 (Mitigation & Final)
- **破甲能力 (Pen)** = `Atk_Penetration + (1.0 - Def_β) * Const`
- **生命承壓 (D_Final)** = `D_Impact * [1.0 - (Def_EVit / (Def_EVit + Pen * 20))]`
    - *概念：體質防禦力是非線性的。體質越高，每點體質提供的減傷效率遞減，但能穩定稀釋傷害。*

## 4. 資源代價與穩定度 (Cost & Stability)

- **氣脈消耗 (Qi_Drain)** = `Skill_Cost * (2.0 - β)`
    - *時脈 (β) 代表掌控力。掌控力越高，浪費的游離量越少。*
- **穩定度損耗 (Posture)**：每次受傷會減少「姿態值」。當姿態歸零，下一次 AP 恢復暫停 1 秒（受擊僵直）。
    - *EVit 越高，姿態值上限越高。*

### 第三階段：相位的干涉 (Phase Interference)
在結算最後，引入 **相位 (γ)** 的隨機擾動：
- **熵增觸發**：當 `γ` 極端值（趨近 -1 或 1）時，賦予戰鬥「變數」。
- **正向 (γ > 0)**：高機率轉化為「暴擊 (Critical)」或「破甲 (Armor Break)」。
- **逆向 (γ < 0)**：高機率轉化為「偏轉 (Deflect)」或「反彈 (Reverse)」。

---

## 3. 狀態指標：歸零的語義

- **氣血 (HP) 歸零**：`EVit` 耗盡，身體崩潰。導致「死亡」，需重組。
- **內力 (MP) 歸零**：`EQi` 耗盡，無法發動技能，進入「虛弱」狀態（減傷與命中大幅下降）。
- **體力 (Stamina) 歸零**：動作門檻 AP 恢復停滯，角色進入「僵直」，只能被動挨打。

---

## 4. 文字戰報的編譯範本

基於上述公式，後端產出的 Raw Log 應包含標籤，供前端渲染：
- `[Initiative]`：{name} 捕捉到一線先機...
- `[Action:Skill]`：{name} 發動了「{skill_name}」！
- `[Conflict:Crit]`：(由 γ 觸發) 這一擊角度刁鑽，避無可避！
- `[Result]`：{target} 受到了 {dmg} 點傷害，體質顯得有些渙散。
