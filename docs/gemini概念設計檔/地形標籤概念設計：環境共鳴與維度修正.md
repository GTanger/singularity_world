# 地形標籤概念設計：環境共鳴與維度修正

本設計旨在讓「奇點世界」中的環境標籤（Terrain Tags）超越單純的敘事描述，成為實質影響戰鬥、經濟與 NPC 行為的「維度修正器」。

## 1. 環境共鳴 (Environmental Resonance)

環境不只是背景，它是 Token 游離輻射的特定頻率場。不同的標籤會對角色的「三軸」與「外顯三維」產生干擾或放大。

### 1.1 戰鬥維度修正
- **[靜謐 (Silent)]**：對話與環境的安穩。降低相位隨機性 `γ` 的波動幅度，使戰鬥結果更趨向數據穩定（田忌賽馬的極致展現）。
- **[富態 (Lush)]**：能量滋養過度。提升所有攻擊的能階係數 `α`（傷害放大），但同時也略微提高氣脈消耗。
- **[咬合 (Grip)]**：物質與建築支撐緊密。提供「穩定度」加成，降低因承受重擊而產生的「僵直」機率。
- **[混沌 (Chaos)]**：未經降維區域。大幅提升相位隨機性 `γ`。戰鬥充滿意外（高暴擊、高反彈、甚至概率失效）。

### 1.2 經濟與行為修正
- **[社交 (Social)]**：如街道、客棧。呈指數級降低 NPC 的「社交壓力」。
- **[校正 (Corrective)]**：如城門、行政區。機構力量強大，交易風險降低，利於「乞討 (Beg)」與「求職 (Seek_Job)」。
- **[富饒 (Abundant)]**：如向陽大街、惡地生機處。提升「採集 (Gather)」的產量與獲取高品質詞元的機率。
- **[安全 (Secure)]**：如官署、重兵把守處。NPC 會依此判定為「安定層級」加分項。

---

## 2. 標籤的湧現敘事 (Emergent Narrative)

當標籤組合在一起時，會形成獨特的場域氛圍。

- **[富態] + [靜謐] (如：向陽大街)**：溫良的豐饒。戰鬥穩定且強大，NPC 行為悠閒且富足，採集點遍地。
- **[混沌] + [咬合] (如：惡地深處、飛升者遺址)**：扭曲的穩定。雖然結構不崩潰，但內容隨時可能變異，是高風險高回報的戰鬥區。

---

## 3. NPC 的環境觀測 (NPC Environmental Perception)

NPC 的決策引擎會將地形標籤納入權重：
- **路徑規劃**：生存壓力大的 NPC 會自動向具備 **[校正]** 或 **[社交]** 標籤的房間靠攏。
- **情緒調節**：在具備 **[安穩 (Restful)]** 標籤的房間，NPC 的氣脈恢復速率加快，情緒狀態趨向正面。

## 4. 第一版實作建議策略（僅概念）

後端在執行 `combat.ResolveV2` 或 `economic.Tick` 時，僅需傳入當前房間的 [Tags](file:///home/tanger/Projects/singularity_world/store/store.go#634-647) 列表（**地形 Terrain 已實作**：由 `db.TerrainFromRoom` 依房間 tags/zone 傳入 ResolveV2）：
1. **查表取值**：每個標籤對應一組係數（如 `tag_lush: Alpha +0.1`）。
2. **公式疊加**：在基礎公式結算前，將這些環境修正值進行累加。
3. **戰報生成**：將地形標籤轉化為敘事字眼。例如：`"由於[富態]環境的滋養，這一擊顯得格外沉重。"`
