## 3. 核心系統一：戰鬥公式設計 (Combat Design V2)

### 3.1 核心參數
- **有效體質 (EVit)**：生命基礎、減傷底色、抗壓穩定性。
- **有效氣脈 (EQi)**：技能燃料、回復率、意志護盾。
- **有效靈敏 (EDex)**：命中率、閃避率、行動頻率。
- **能階係數 (α)**：爆發增幅。
- **時脈係數 (β)**：節奏控制與資源利用率。
- **相位係數 (γ)**：意外效果機率。

### 3.2 戰鬥時序 (Initiative & Timeline)
- **行動槽模型**：100ms 一個 Tick。AP 恢復速度 = `EDex * (0.5 + 0.5 * β)`。
- **發動門檻**：基礎攻擊 100 AP；技能攻擊 `100 + Complexity_AP`。

### 3.3 衝突結算公式
- **命中率 (P_Hit)** = `Min(0.95, Max(0.05, (Atk_EDex / (Atk_EDex + Def_EDex)) * 1.2))`。
- **基礎傷害 (D_Base)** = [(Atk_Power + Atk_Gear) * (Resonance_Multiplier)](file:///home/tanger/Projects/singularity_world/world/map.go#42-49)。
- **爆發係數 (D_Impact)** = `D_Base * (0.8 + 0.4 * α)`。
- **最終傷害 (D_Final)** = `D_Impact * [1.0 - (Def_EVit / (Def_EVit + Pen * 20))]`。
- **氣脈消耗** = `Skill_Cost * (2.0 - β)`。
- **姿態 (Posture)**：受傷損耗，歸零則觸發僵直，暫停 AP 恢復。

## 4. 核心系統二：經濟與需求 (Economic & Needs)

### 4.1 市場搏動 (Market Heartbeat)
- **耀變代謝**：NPC 每日消耗鎂 (Mg) 作為續航成本。消耗量 = `Base_Cost * (1 + SoulSeed_Complexity) * Inventory_Load_Factor`。
- **供需湧現**：NPC 依據需求購買詞元或裝備；市場每小時進行宏觀平衡。

### 4.2 需求驅動決策
- **壓力分析**：生存壓力 (Mg < 閾值)、安定壓力 (無指派)、社交壓力 (孤獨)。
- **意圖映射**：壓力過高觸發 `Seek_Job`, `Beg`, `Gather`, `Sell`, `Talk` 等行為。
- **身份湧現**：乞丐與行腳商是行為演化的結果，而非預設標籤。

## 5. 核心系統三：地形標籤 (Terrain Tags)

### 5.1 環境共鳴
- **[靜謐 (Silent)]**：穩定相位 `γ`，戰鬥結果更可預測。
- **[富態 (Lush)]**：提升能階係數 `α` (傷害)，但增加消耗。
- **[咬合 (Grip)]**：提供姿態穩定度加成，降低僵直機率。
- **[混沌 (Chaos)]**：大幅提升相位 `γ` 波動，產生偏轉或暴擊。
- **[社交 (Social)]**：降低 NPC 社交壓力。
- **[校正 (Corrective)]**：利於乞討與求職。

## 6. 核心系統四：詞盤造句與技能編譯 (Skill Compilation)

### 6.1 造句語意
- **共鳴階級**：
  - 一階 (1.0x)：雜亂。
  - 二階 (1.5x)：符合語意模板（主動賓等）。
  - 三階 (2.5x)：純粹屬性組合（真實傷害）。

### 6.2 技能編譯 (The Compiler)
- **自動命名**：系統從敘事中萃取 2~4 字簡名（如【火焚】、【疾風步】）。
- **數值化**：威力根據能階 (α) 放大，消耗根據時脈 (β) 縮小。
- **執行流**：蓄能 (AP) -> 檢核 (Qi) -> 結算 (Formula) -> 回饋 (Log)。
