# 經濟與需求概念設計：市場搏動與自主決策

本設計旨在提供「奇點世界」經濟與 NPC 行為的閉環邏輯，讓即便只有單一玩家的世界也能展現出真實的「活著」的市場感。

## 1. 市場搏動 (Market Heartbeat)

經濟的核心不在於「存錢」，而在於「流動」。我們將其抽象化為一種週期性的「搏動」：

### 1.1 週期性能量代謝 (Magnesium Metabolism)
- **概念**：NPC 的「耀變肉身」每遊戲日需要消耗固定比例的 **鎂 (Mg)** 作為代謝補償（生存成本）。
- **邏輯**：消耗量 = `Base_Cost * (1 + SoulSeed_Complexity) * Inventory_Load_Factor`。
- **效果**：這創造了底層凡人「不得不工作/賺錢」的原始拉動力。

### 1.2 供需湧現 (Emergent Supply & Demand)
- **需求側 (The Sink)**：NPC 為了提升「尊重」層級或備戰，會產生購買高品質詞元或裝備的需求。
- **供給側 (The Source)**：NPC 透過採集、剝名或完成機構任務（如打掃、守衛）來獲得基礎資源或鎂。
- **搏動頻率**：市場每遊戲小時進行一次「宏觀平衡」，根據全服庫存調整 NPC 的「意圖價格範圍」。

## 2. 需求驅動的決策鏈 (Needs-driven Decision Chain)

決策引擎不是在執行「腳本」，而是在「緩解壓力」。

### 2.1 壓力分析器 (Stress Analyzer)
NPC 的當前狀態會轉化為不同維度的「壓力值」：
- **生存壓力**：`Max(0, Survival_Threshold - Current_Mg)`。
- **安定壓力**：若當前無職 (No Assignment)，該值大幅攀升。
- **社交壓力**：與最後一次有效通訊的時間正相關。

### 2.2 意圖映射 (Intent Mapping)
當壓力最高的一項超過閾值時，觸發對應的**行為意圖**：
- **生存壓力高**：優先選擇 `Seek_Job`（長期穩定）或 `Beg/Gather/Sell`（短期變現）。
- **社交壓力高**：觸發 `Move_to_Social_Area` 與 `Talk`。

---

## 3. 「玩家＝NPC」的對等參與

### 3.1 玩家作為市場的擾動者
- 當玩家大量拋售某種詞元時，NPC 的價格敏感度會察覺到供給過剩，從而壓低收購價。
- 玩家下線後，其角色根據設定的「心理門檻」自動執行收購或販售，確保玩家回歸時發現財富或物資發生了變化。

### 3.2 身份的湧現 (Identity Emergence)
- **乞丐**：並不是一種職業，而是「生存壓力極高且無技能/物資」的 NPC 在 gate 區域採取的生存策略。
- **行腳商**：是「背包價值高且具備低買高賣算法」的 NPC 產生的移動行為。

## 4. 閉環的穩定器：機構的看不見之手

為了防止經濟崩潰（通縮或通膨），系統機構（非實體）執行：
- **貨幣注入**：透過動態調整「任務報酬」來補償全伺服器因代謝而損耗的鎂。
- **稅收回收**：對「高位階指派（如掌櫃）」徵收營運稅，回收多餘的流動性。
