# 無法登入／連線異常

## 1. 網址與 WebSocket

- 請用 **`http://localhost:1721/`**（或你 `PORT`／`./start` 設定的埠），**不要**用 `file://` 開本機 HTML。
- 日誌區若出現 **「已連線，請登入」**，再按登入；若只有 **「連線錯誤」** 或立刻 **「連線關閉」**：
  - 確認奇點程序有在聽該埠（`sw.log` 內有 `listening :1721` 等）。
  - 若經 **反向代理**（nginx、Caddy），需轉發 WebSocket：`Upgrade`、`Connection` 標頭與 `/ws` 路徑；否則升級會失敗（伺服器 log 可能出現 `upgrade:` 錯誤）。

## 2. 登入表單錯誤訊息（簡表）

| 訊息 | 可能原因 |
|------|----------|
| 請填寫 ID 與密碼 | 欄位留空 |
| 請稍候連線後再登入 | WebSocket 尚未 `OPEN` 就送出 |
| 角色不存在，請先創角 | ID 打錯，或資料裡沒有該 entity |
| 此 ID 非玩家角色 | 該 ID 是 NPC 等，不能用玩家登入 |
| **此角色尚未設定登入密碼** | 舊資料：entity 有，但 `auth.json` 沒有該 ID 的雜湊 |
| 密碼錯誤 | 密碼與當初創角／重設的不一致 |
| max connections reached | 同時 WebSocket 已達上限（預設 10），請關閉多餘分頁或其它客戶端 |

## 3. 舊角色沒有密碼時怎麼辦

1. **建新角**：畫面上切換 **「建立新角色」**，換一個未被使用的 ID（密碼至少 6 字元）。
2. **沿用舊玩家 ID**：先 **停止** 奇點（避免與執行中的伺服器同時寫檔），在專案根目錄執行：

```bash
go run ./cmd/sw-set-password 你的角色ID 新密碼
```

密碼至少 6 字元；僅限 `kind` 為玩家的 ID。

## 4. 仍無法排除

- 查看 **`sw.log`** 最後幾十行是否有 `upgrade:`、`panic` 或載入 store 失敗。
- 確認 **`data/runtime/auth.json`** 是否存在、且 JSON 有效（異常時可先備份再對照 git／備份還原）。
