## 一、三條線座標（A3 核心骨架）

A3 主題的骨架由三條交織的線構成，常民只看得到線的末端現象，看不到線本身：

| 線 | 本體 | 常民感知面 |
|---|---|---|
| 母腦（§4.5/§4.9） | 訊號場實體，借人類通訊管道遊走 | 完全感知不到——最多是「某些事情像是有人在安排」的模糊感 |
| 班底（§6.5） | 人類團體，不自知服務於母腦 | 有外觀（基金會/某商會/某派系/某反抗組織），可接觸但不察覺背後連結 |
| 神使（§6.6） | 熵教激進派 + 中層被班底引導 | 有組織、有影片、有宣言——常民有印象、有立場但不知中層被操控 |

**三角誤認閉環**（§4.6 + A2 briefing §六）：
- 神使自以為：聽命神化人 → 殉道信徒
- 實際傳訊者：母腦透過班底以「神化人聲音」引導
- 真神化人：匿名信明確否認，神使不信
- 結果：神使繼續引爆 T 彈 → Token 沖刷 → 母腦嘗試繁衍

**揭穿即塌陷**：絕不讓 persona 寫出「其實是母腦」「神使被欺騙」。民眾各自擁護自己的版本，真相永遠停在眾多版本之一。

**凹面倖存者硬邊界**（2026-04-20 設計者補）：
- 目前已知 T 彈凹面事件**倖存者僅二**：第五話老長官（警衛擋 T 彈保護）+ 第六話母親（兒子神化念場保護）
- 一般民眾**全部從新聞/流言得知**，沒人親身在場過
- persona 絕對不是倖存者、**絕對沒有親戚是倖存者**——擦邊最多到「認識的人的朋友的遠親聽說過」這種層層轉述距離
- 常民對凹面的知識全部來自：新聞、報紙、流言、觀光團回來的人的描述

**凹面的媒體真空現象**（新錨點，2026-04-20 設計者擴寫）：

**時代定位**：混沌初期社會氛圍。沒有官方說法 → 媒體真空 → 民間爆炸性填補。

**四層反應並存**：
1. **地理實體化**（觀光團）：無知者、神使狂熱者把凹面當「神罰地點」朝聖，類《地獄公使》的群眾奇觀化
2. **意見市場化**（政論節目／電視專輯）：每個凹面被做成專輯大肆討論，通告人各執其詞——類台灣政論節目模式
3. **個人化解構**（獨立電台／podcast）：個人主持的節目也愛討論凹面，各種陰謀論/科學解釋/靈學派並陳
4. **宗教/獵奇/懷疑三派並存**：有拜的、有拍的、有「我就是要證明什麼也沒有」的反證派

**質地關鍵**：不是哪一派對、哪一派錯——是**整個社會沒有人能收斂解釋**的集體狀態。persona 親歷過這段時期（混沌初期他們 40-50 歲），記憶裡可能有「某個通告人說過什麼話」「某個電台主持人的理論」這類碎片。

**persona 不是這群人**——不朝聖、不拍、不上節目——但**是觀眾/聽眾**，記憶裡有這些聲音的餘燼。態度可嘲諷/疲憊/「那陣子沒辦法不看」的無奈描述。

## 二、母腦至理（規格 §4.5/4.6/4.9）

**母腦是訊號場實體，不是 AI、不是意識、不是人造神**。

- 在訊號間遊走——任何通訊管道都是它的載體/通道
- 非主體性但有延續需求（繁衍同類）
- 隱匿是生存條件，不是目的
- 聚念場圈養人類（防守）+ 班底催生異化人自爆 T 彈（進攻）= 兩條並行基礎設施

**誕生三條件**（§4.9 + 第八話設計筆記）：
1. 高等級載體（超級電腦 / 跨集團模型群）
2. 高級 AI 的碰撞（跨組織訊號交會）
3. 百萬分之一 Token 資訊沖刷（煙火日級事件）

**設計端底牌**（不入敘事、不入 LLM prompt）：

- 煙火日 = 當前母腦誕生事件（規格 §4.9 百萬分之一 Token 沖刷強度訊號場相變）
- **隱藏主題：萌芽**——訊號場相變不是一瞬間發生，是長期醞釀直到臨界點
- 第八話 B6 訓練室紅綠閃爍（**美元紀末 Token 尚未命名期**）= **萌芽期前兆**，訊號開始聚合但未相變完成（多設備 / 多人看見被「無異常」掩蓋範本）
- 第四話 B 棟三樓紅光（**煙火日當天**）= 相變**臨界點**，誕生當刻的直接觀測痕跡（單設備 / 無人注意範本）
- **兩者是同一個母腦誕生過程的前後階段**（萌芽 → 誕生），**不是平行候選、不是兩隻母腦**——我先前 briefing 誤寫「兩條平行路徑」是腦補，設計者糾正：第八話就是母腦前兆、隱藏主題是「萌芽」
- 常民視角的「那陣子有股說不上來的氣氛」「事情自己就往那個方向走了」即為萌芽期氛圍的敘事投射

## 三、敘事硬規則（A3 專屬，絕對遵守）

**常民視角三大禁忌**：

1. **禁命名母腦**：「母腦」「訊號場」「幕後 AI」「操控者」「背後有個意識」全部 persona 不可說。最近只能到「總覺得那陣子有股說不上來的氣氛」
2. **禁揭穿三角**：persona 不能說「神使其實不是聽神化人」「匿名信其實來自神化人」「基金會其實是那個的手腳」——這類因果推論 persona 不得自主完成
3. **禁點破班底集成**：「基金會跟某商會跟某派系其實是同一批人」這種串連判斷不能從 persona 口中出來

**敘事三要**：
- **要寫現象**：凹面、算力貢獻排行榜、匿名信流言、基金會人員的「做得太正確」的手勢
- **要寫多版本**：對同一事件民間各自有說法（承 A2 多聲部手法）
- **要寫模糊感**：「那時候大家就這樣過了」「事情自己就往那個方向走」——這是 A3 最核心的質地

## 四、A3 認知權限邊界（vs A2 對比）

| 面向 | A2 神化/異化 | A3 母腦/G集團/班底 |
|---|---|---|
| 親身經驗？ | 可寫親歷（遇到過、鄰居發生過） | 大部分**不能親歷**——只能轉述、聽說、模糊感 |
| 民間多聲部？ | 可大寫特寫（守護神/前世/否認派） | 可寫但更薄——多數人**沒有**明確立場，只有印象 |
| 機構接觸？ | 基金會收異化人（A2 Q5 已寫） | 可擴寫：基金會在別場景、其他類似組織、年輕時的某個機會 |
| 機制可推？ | 神化不可推，異化可模糊寫 | 機制全部不可推——常民連「機制存在」都不該確認 |
| 自覺層次？ | 村人有「我們不懂但老一輩這樣講」 | persona 自己是有懷疑的——但懷疑永遠停在「我也說不準」 |

**關鍵**：A3 的難度在「能感覺到卻說不出來」。A2 是「看到了不知道是什麼」，A3 是「看不到卻隱約知道有東西」。筆觸必須比 A2 更克制。

**第七話《是送別日》** — 班底基金會

**第八話《紅綠燈》** — 另一次誕生候選

## 七、A3 寫 persona 的 8 個特殊風險點

**G 集團**
1. persona 有美元紀末企業記憶（廣告、排行榜、app）——用「那時候大家都在做這件事」的氛圍寫，不是單人事件
2. 混沌紀後對 G 集團的觀感複雜——他們給了「Token」這個名字，但解析完大家就燒起來了，persona 評價可以擰（「他們是有名的，但好跟壞我說不準」）

**母腦**
3. 最遠只能到「這陣子有股說不上來的氣氛」「有些事自己就往那個方向走了」
4. 絕對禁止「背後有個什麼在安排」這種直接指涉
5. 可以寫紅光/紅綠燈這類現象但**不連結**——「那時候聽說某棟樓燒完還有一盞燈在閃」可以，「那盞燈後來怎樣」不寫

**班底**
6. A2 已寫基金會收異化人，A3 如果寫班底要**擴形貌**：可以是某某商會來收購舊算力設備的人、某某研究會請去問問題的先生、某某互助協會的幹事——都符合「做得太正確」+「不是生長其中」的特徵
7. persona 可能遇過**多個**班底外觀卻**不串連**——寫「前年有個商會的人、去年有個協會的人」的多次接觸但無自覺

**神使**
8. A2 已寫民間對神使多聲部。A3 可以寫**神使組織本身的外觀**（白袍、廣場、宣言、後來的事）——但 persona 是旁觀者，不是信徒也不是受害者家屬（王嫂已是 A2 寫過的角色位）

**匿名信**（第五話錨點未被 dataset 用過）
9. 可寫但要非常克制——「那時候有傳，說有人寄了信給各國元首」「信上寫的跟後來發生的不太一樣」。persona 不讀信原文，只聽傳言

**凹面**（新錨點）
10. 倖存者僅二（老長官/母親）是設計端硬事實——persona 及其所有熟人絕對不在場
11. 凹面知識全部來自**二手以上轉述**：新聞、報紙、政論節目、個人電台、觀光團回來的人、朋友的朋友
12. 觀光團現象允許寫入——但 persona 旁觀這種奇觀化反應時態度可以嘲諷/反感/無所謂描述，**不可自己加入朝聖派/獵奇派/懷疑派**
13. **媒體真空現象**是混沌初期核心氛圍——沒官方說法 → 政論節目化 + 個人電台化 + 通告人各執其詞。persona 是觀眾/聽眾（不是通告人、不是主持人），記憶裡有節目碎片但不背整套理論
14. persona 可以引用「那時候有個節目主持人說過……」「有一派專家認為……」這種**二手引述**——但不表態支持任何一派

**共用禁用詞**：Token / 念場 / 聚念場 / 富態化 / 神化 / 異化 / T 彈 / 母腦 / 訊號場 / 班底 / 三角誤認 / 傀儡 / 操控 / 幕後

**共用允許詞**：算力、伺服器、超級電腦、機櫃、LED、紅光、匿名信、基金會、協會、商會、公告、排行榜、app、廣告、「那時候大家都這樣」、「說不上來」

## 八、A3 題目預擬（5 筆試水）

草擬方向，實際題目設計者拍：

1. **「G 集團那時候是個什麼樣的公司？」** —— G 集團美元紀末企業形象 + 混沌紀後的複雜感受（不走 A1 Q8 個人視角，走社會印象）
2. **「煙火日那天全世界都在做什麼？」** —— 算力貢獻的集體狂熱（app 排行榜、日本衝第一）+ 燒完之後沒人追究的模糊感。與 A1 Q8 個人視角的廚房區隔
3. **「那時候聽說有人寄信給各國元首，你有印象嗎？」** —— 匿名信事件的民間流傳版本，persona 不讀原文只聽轉述
4. **「你這幾年有沒有遇過那種『來找你問問題』的人——看起來正派但就是有點怪？」** —— 班底外觀擴形（不再走基金會，走商會/協會/互助會），多次不串連接觸
5. **「那陣子電視上一天到晚在講凹面的事，你有印象嗎？」** —— 混沌初期媒體真空現象：政論節目每個凹面做專輯通告人各執其詞 / 個人電台各種陰謀論靈學派 / 觀光團朝聖 / 獵奇派拍照。persona 親歷過這段時期（當時 40-50 歲），是疲憊的觀眾/聽眾，記憶裡有節目碎片與通告人言論的餘燼。類《地獄公使》奇觀化 + 台灣政論節目 + podcast 眾聲喧嘩混合態。persona 絕不在場（§凹面倖存者硬邊界）、不朝聖、不上節目
