# 奇點世界 — 文檔索引

本索引已納入專案必讀機制：**根目錄 `.cursorrules`** 規定 AI 須先讀此索引、再依下方「AI 進行專案索引／檢索時必讀」一節所列文件依序閱讀後，才進行索引、檢索或任務。

## AI 進行專案索引／檢索時必讀

**在對本專案進行索引、檢索或開始任何任務前，必須先閱讀本索引，再依序閱讀以下四份文件：**

1. **[協作約定](COLLABORATION.md)** — 主管與 AI 的角色、決策權、協作原則、數據庫角色。
2. **[技術約束規則](技術約束規則.md)** — 語言與技術棧、程式碼風格、檔案結構、協作流程、禁止事項。
3. **[世界觀：Token 降維與生命演化](reference/世界觀：Token降維與生命演化.md)** — 宇宙本體論、Token／止念／降維／飛升者等敘事定調。**撰寫任何劇情、NPC 對白、系統日誌或文檔時須符合此世界觀，不得文不對題或擅自擴充。**
4. **[世界觀：富態與拉鋸](reference/世界觀：富態與拉鋸.md)** — 環境與物質狀態：**沃土風**（反向核心概念，對齊 Token 混沌）、富態生長、平衡拉鋸、無廢土感；**豐饒與危險同向**（更豐饒往往更危險，非安全田園）；**陸域尺度**（全球亞馬遜級基底＋局部超熱點疊加，見該文 §沃土風）。**撰寫房間描述、場景敘事或環境相關文檔時須符合此基調；AI 摘要本專題時不得將本作概括為典型廢土／末世遊戲。**

未讀上述四份文件前，不應假設專案決策權、技術選型、程式風格或敘事基調；讀後再依索引查找設計與規格。

**AI／代理另讀（與上列四份互補，非取代）：** 根目錄 **`AGENTS.md`**（精簡入口）與 **`docs/AGENTS_LEARNED.md`**（累積之使用者偏好與工作區事實全文）。
