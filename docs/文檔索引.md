## 當前主線（2026-07）

- 2026-07-13 奇點停滯後先走概念救援，不再把方法內化或世界細節當成遊戲進度。第一個可執行、可否證的玩家體驗見 [design/concept-rescue-white-tower-2026-07-13.md](design/concept-rescue-white-tower-2026-07-13.md)：白塔半島只作試驗場，候選內容不是正史；通過真實玩家的行動／回訪動機前，不得宣稱原型成立。
- 當前第一權威是 [DESIGN_KEYWORDS.md](DESIGN_KEYWORDS.md)：一切設計、側寫、實作排序都依照關鍵字清單。`物件驅動生活模擬` 只是從「全物件化、後端真理、數據轉文字、模擬/經營/建造、真實經濟、玩家＝NPC」推導出的從屬機制解讀，不是新總目標；舊生活模擬比喻不作壓縮後 routing 錨點。從屬紀錄見 wiki：`05-專案/Singularity-World/10-正典與ADR/物件驅動生活模擬核心玩法定位.md`。
- 2026-06-23 停止線：目前由 Codex 產出的世界重塑稿、World Bible、地圖包、材料包、勢力包、衝突包與視覺地圖，品質未通過玩家審查，**全部暫降為「曾經創作的素材庫」**。它們可被翻查、拆句、抽取靈感或作反面檢查，但不能作正典、不能作 runtime 工單來源，也不能在壓縮後被當成「已接受的世界」續寫。
- 2026-06-24 聯合創作定義：重啟世界本體時，**不得預設「能量充沛」「能量像空氣」「沃土風」或「常理化奇幻＋能量充沛」**。若使用者重新使用「能量充沛」，其窄義是：這個世界會走向**個人運用能量的發展**。它不是環境肥沃、富態生長、人人被動受氣、人人修士、電力供應、接入／斷供或治理模型。
- 2026-06-24 開放式能量框架見 [design/world/open-personal-energy-use-framework-v0.md](design/world/open-personal-energy-use-framework-v0.md)：核心不是能量種類不同，而是**運用能量的方式不同**。後續不得收斂成元素表、咒語決鬥單系統、職業表或「法師 vs 武者」。
- 2026-06-24 萬人萬相補正：此處的「運用方式不同」回到最初奇點世界已定義的 **SoulSeed 萬人萬相**，意思是沒有任何一個人是一模一樣的；同一套功法，學起來、用起來都不同。可用護法咒作比喻：同一個咒，每個人的護法不同。功法只是共同文本與共同起點，不是把人分類的盒子；制度可以命名、教學、考核，但不能窮盡或凍結一個人的相。不得把它過度抽象成反制度、固定路徑表、換皮特效或外觀隨機化。壓縮句：**同法不同相；制度教法，個體成相**。
- 2026-06-24 功法與勝負補正：沒有抽象意義上永遠最強的咒語，只有最恰當的咒語。功法可以有優劣，但強弱與輸贏不能只看功法；人的相、理解、熟練、臨場判斷、對手、環境、時機、代價承受與恰當使用都會改變結果。壓縮句：**功法有高下，勝負無定式**。
- 2026-06-24 恰當性補正：恰當不是沒有強弱，功法優劣也不只看威力；穩、快、省、隱蔽、易教、容錯、後勁、代價、失控風險與複雜環境可用性都是判準。成熟不是只會更強，而是知道何時何法最恰當，包含不用、少用、慢用、借物用、借地用、借人用，甚至讓對方失去出手條件。能量運用也不只服務戰鬥勝負。
- 完整遊戲設計層入口 [design/奇點世界遊戲設計檔.md](design/奇點世界遊戲設計檔.md) 目前只作「素材庫索引與停止線」使用：`0.2 完整設計層落地狀態（2026-06-23）` 已標記本輪設計未完成。後續若要重啟，必須先回到 [DESIGN_KEYWORDS.md](DESIGN_KEYWORDS.md) 與玩家側寫，不得直接承接 [design/world/world-outline-from-zero-v0.md](design/world/world-outline-from-zero-v0.md)、[design/world/world-bible-from-zero-v0.md](design/world/world-bible-from-zero-v0.md)、[design/world/world-map-complete-design-pack-v2.md](design/world/world-map-complete-design-pack-v2.md) 或任何下游包。
- 世界故事稿先讀 [design/world/world-outline-from-zero-v0.md](design/world/world-outline-from-zero-v0.md) 與 [design/world/world-bible-from-zero-v0.md](design/world/world-bible-from-zero-v0.md) 只是在回看「上一輪素材」時使用。它們包含能量像空氣、生命邊界、大回潮、地名、制度、人物與玩家入場等材料，但未被接受為完整世界本體；`world-story-bible-v2.md` v2.5、`world-story-bible-v1.md` v1.4 與既有下游卡組同樣只作素材，不得反過來支配世界。
- 舊世界根文件已降格：能量非電力修正見 [design/world/world-bible-v3.1.md](design/world/world-bible-v3.1.md)，只保留「不是電力/供應/接入/斷供」的修正價值；[design/world/world-bible-v4.md](design/world/world-bible-v4.md) 已降格為治理偏誤稿，不能作完整世界本體入口；舊 [design/world/world-bible-v3.md](design/world/world-bible-v3.md) 已降格為電力化偏誤稿。

- 舊世界特殊設定與舊語義造句系統不是現行實作預設。既有 P0 物質工單只可視為 runtime 層的畫面物件、後端來源、背包、交易、庫存守衡練習；不得反推「常理化奇幻」或「能量充沛」為世界根。
- 現行玩家端是**方格 MUD / 路口形狀 UI / 上中下三區介面**。不要從 Hex、觀景窗、全局圖形地圖、舊 3×3 方向鈕工作單延伸新實作。
- 既有 NPC **暫時保留不刪**，作為移動、排程、互動、經濟與 UI 測試載體；後續等新 NPC 靈魂資料規格定版後，走 migration 洗白人格／記憶／背景並重新灌入。
- `docs/archived/` 是歷史資料；其中內容只有在明確要求回看舊方案時才讀，不作為現行設計依據。
