# 夜鴞巷結構連結與描述檢查報告

## 一、結構連結閉合

- **檢查方式**：腳本 `tools/js/check-yaxiao-structure.js` 掃描全專案 `data/rooms` 取得所有房間 `id`，再對夜鴞巷內每一房的 `exits[].to` 與 `objects[].move_to_room_id` 檢查目標 id 是否存在。
- **結果**：**通過**。夜鴞巷 232 間房、990 處出口／移動目標，全部指向已存在之房間 id；對外連結（如 sunstreet_st8、wustreet_st4、feistreet_st6、lifestreet_st8、yaxiao_st1～st4）皆存在於專案中。

## 三、主體至少 50 字與文筆

- **規範**：房間 description 主體（「可經…」之前）至少 50 字；文筆須台灣暢銷作家筆觸、下筆有神、詞藻如畫。
- **本輪修正（四巷）**：
  - 巷尾灶 04（短廊底前）：主體由 44 字補足（補「沉入磚縫」「灶氣自深處漫來」）。
  - 巷尾灶 05、10：在去重複的同時改寫為更具畫面與動詞的句子（如「收口」「如甕」「光壓極低」「貼地滯留」「攢成一眼」「無風無響」），主體皆 ≥50 字。
  - 長燈棧 13、隱簾閣 07：主體略增數字以達 50 字（「貼地向棧底／簾底延伸」）。
  - 隱簾閣 08、09：主體略增（「簾外巷聲不聞」「室內無雜音」）以達 50 字並稍作區隔。
- **一～三巷主體不足 50 字者**：已於本輪全數補足（共 28 間），補句以「厚牆隔絕巷聲」「極靜」「無雜音」「室內極靜」「水氣略重」「沉入磚縫」「巷聲不聞」等與夜鴞巷語彙一致且不重複之短語為主。執行 `node tools/js/check-yaxiao-structure.js` 現已顯示「主體不足 50 字：無」。
