# 第九話：仗義每多屠蟻輩

> 2026-04-20 設計者概念骨架 × Claude Opus 初稿
> 狀態：待設計者審定
> 時序：混沌紀中後期（解放日後約三十年）
> 場景：某北方內陸小聚集地「下河村」，人口約二百

---

## 設計者概念（原骨架）

- 聚念場內螞蟻無法富態化，遷徙離開聚集地去野外（Token 趨光性，如貓聞貓草、人類臨水）
- 野外螞蟻狗大、群居；看到一隻落單螞蟻 = 引路蟻 = 蟻群在調動，高價值情報
- 聚集地定期探勘、清理周邊裸露蟻穴，防止蟻巢挖穿聚集地地下
- 屠蟻：有軍隊派軍隊、沒軍隊就自己組織；外來人帶訊息對聚集地是恩情
- 獎酬極簡：請吃頓飯、蟻身材料歸他、感謝他——混沌紀經濟不是職業津貼
- 能去野外活著回來的人不靠幸運

---

下河村的鐘掛在村中央一棵老槐樹下。那口鐘是美元紀末留下來的，本來是學校的下課鐘。學校早就沒了，鐘還在。

村裡的規矩：敲一下是晚飯，連敲三下是集合，連敲十下是屠蟻隊出動。十下用得最少，一年到頭有時用兩次，有時一次都不用。

那天傍晚，鐘敲了一下，然後又敲了十下。

---

事情要從傍晚一個外地人到村口說起。

他從北邊來，走了一天。背袋、拄杖，鞋上灰很重。村口值班的小孩先看到他，跑回去通報。吳伯從家裡出來迎接。村裡的規矩是這樣——凡是有外人進村，吳伯都要親自看過。

吳伯七十出頭，美元紀末的時候教過書。現在村裡沒人叫他老師，都叫他吳伯。

「你從哪來？」吳伯問。

「北邊。下一站想去東邊的石窯村，今天走不動了。」

「那你住一晚。」

「麻煩。」

「不麻煩。進來吧。」

---

吳伯家的晚飯是米飯、一盤醃菜、一碗煮野菜。外地人桌邊坐了下來，把背袋放在腳邊，不急著動筷。

「你路上還順嗎？」吳伯問。

「路上還行。只是昨天在北邊的乾河床那邊，看到一隻螞蟻。」

吳伯正要夾菜的手停了一下。

「多大？」

「我比劃不出來。大概——」外地人伸手比了比自己的小腿，從膝蓋到腳踝中間。「這麼長。」

「哪邊的乾河床？」

「再往北走半天，就是那一條。我中午在那邊煮水，坐了一陣。那隻蟻從西邊的岩縫爬出來，往東走，自己一個。」

「自己一個？」

「我看了有一陣子。只看到牠一個。」

吳伯把筷子放下。

「你等一下。」

吳伯起身出門。外地人繼續吃飯。他吃得很慢。

---

外面的鐘敲了三下，停。然後是十下。

下河村的人聽到十下鐘的時候，大部分人沒有說話，就各自放下手裡的事。有幾個婦女把孩子叫進屋，關上門。有幾個男人去倉庫拿工具——鋼矛、鐵鏟、火把，還有幾桶鹽水。

阿祥是屠蟻隊的帶頭。他三十出頭，看過三次蟻穴擴張，手背和左小腿上各有一道疤，是第二次那回留下來的。他到了槐樹下的時候，屠蟻隊已經聚了十六個人。

吳伯在槐樹下等他。

「北邊的乾河床，半天路。西邊岩縫爬出來，往東走。一個。」

阿祥點頭。

「今天晚上走？」

「你自己判斷。」吳伯說。「但是一個的話，越早越好。」

「嗯。」

阿祥轉頭對隊裡的人說：「帶兩天的乾糧。火把多拿一些。」

有個年輕的隊員——大概二十出頭，是第一次跟隊——問：「現在走不會太黑嗎？」

阿祥看了他一眼。

「牠不嫌黑。」

---

屠蟻隊出村的時候，天還沒全暗。吳伯在村口站了一會兒，看著他們消失在北邊的土路盡頭，才回去。

外地人吃完了飯，坐在院子裡抽一根自己捲的菸。吳伯坐到他對面。

「你今天來得正好。」吳伯說。

「嗯？」

「你晚一天走過那段乾河床，就看不到那隻蟻了。再晚三天，你可能連下河村也找不到了。」

外地人沒有接話。他抽完那根菸，把菸灰磕在腳邊。

「我不懂什麼蟻不蟻的。」他說。「我就是覺得那一隻看起來有點怪，自己一個，又那麼大。我路上想了一想，想說進村提一下。」

「你提得對。」

「屠蟻隊幾個人？」

「十七個。」

「會都回來嗎？」

吳伯沒有立刻回答。過了一會兒，他說：

「大部分時候會。」

---

阿祥回來的時候是清晨。屠蟻隊十七個人出去，十六個人回來。少的那一個是第一次跟隊的年輕人。

阿祥跟吳伯報告的時候，外地人也在槐樹下。報告很短。

「北邊乾河床再往西三里。一個小蟻穴，開口大概兩個人合抱。地底下已經挖了有——我估——七八公尺深。我們灌了四桶鹽水，燒了。口封上了。」

「規模？」

「不大。還是初期。如果再給牠半個月，就要吃到下河村地底下了。」

吳伯點頭。

「那一個呢？」

阿祥沒有馬上回答。

「掉到蟻穴裡。我們沒有看到屍體。」

吳伯沉默了一下。

「家裡人我去講。」

---

阿祥轉頭看外地人。

「你就是昨天過來報信的？」

「嗯。」

阿祥走過去，從自己的背袋裡拿出一塊東西——是一段深棕色的、像甲殼的材料，大概一個拳頭大，邊緣還帶著燒過的痕跡。他放在外地人面前的石桌上。

「蟻身的材料。燒過的能用，沒燒過的更好——但那一隻我們沒機會取完整的。這塊給你。」

外地人看著那塊甲殼，沒有立刻拿。

「我沒做什麼。」他說。

「你做了。」阿祥說。

他站直，看了吳伯一眼，就回屠蟻隊那邊去了——還有一個家要去通知。

---

外地人收拾背袋要走的時候，吳伯送他到村口。

「石窯村往東，走兩天路。」吳伯說。「這個季節那邊不難走。到的時候跟那邊的老周講一聲，就說下河村吳伯介紹的。」

「好。」

外地人走了幾步，又停下來。

「吳伯。」

「嗯？」

「昨天那個屠蟻隊——那個年輕人……」

「嗯。」

「你們做這種事——有沒有人說你們划不來？」

吳伯看著他，沒有馬上答。過了一會兒，吳伯說：

「以前有句話，仗義每多屠狗輩。現在我們村裡頭有人寫了一副對聯貼在祠堂門口，把狗字換成蟻字。」

外地人點了點頭。

他繼續往東走。

---

## 設計筆記

### 核心事件
- 一個外來旅人隨口說「路上看到一隻螞蟻」→ 觸發下河村屠蟻隊連夜出動 → 清掉初期蟻穴 → 救了聚集地
- 代價：屠蟻隊去 17 人回 16 人
- 旅人走之前收下蟻身甲殼——混沌紀的感謝儀式不是錢，是物
- 標題出處：吳伯送別旅人時引用，「有人寫了副對聯貼在祠堂門口」——民間自發命名

### 機制錨定（對應設計者原骨架）
- **Token 趨光性** ✓ 未直接命名，但透過「螞蟻從聚念場遷徙去野外」的事實性敘述呈現（螞蟻絕跡於村內是常識，不用解釋）
- **引路蟻** ✓ 旅人看到「自己一個」的螞蟻——吳伯立刻放筷、鐘敲十下。外地人不懂為什麼，村民都懂
- **探勘 > 屠蟻** ✓ 旅人沒參與屠蟻，但他的一句話比屠蟻隊本身更關鍵
- **獎酬極簡** ✓ 阿祥給旅人一塊蟻甲殼，「這塊給你」。沒有錢、沒有場面話
- **能活著回來的人不靠幸運** ✓ 跟隊的年輕人沒回來。阿祥第二次那回留下兩道疤還能帶隊——這是選拔的意思
- **屠蟻隊組織形式** ✓ 沒寫得太細。鐘響就來、自備工具、帶隊就是做過最多次的人——混沌紀的自然選拔

### 風格對齊前八話
- 不用精確數字裝冷感（第八話「八千六百四十七次」那種）
- 不用雙關式民間命名（第八話「想過馬路」的機械式幽默）
- 不用「他從來沒有告訴她為什麼」的克制餘波模板
- 結尾旅人往東走——不回頭、不看一眼、沒有「多年後他還記得那天」
- 對話短、口語、帶日常煩躁或沉默，不戲劇化

### 禁用詞守法
- Token / 富態化 / 念場 / 聚念場 / 神化 / 異化 全未出現
- 螞蟻變大用「這麼長」（比小腿）描述，不用「因為富態化」
- 聚念場邊界用「村裡沒有蟻、村外有」的事實性呈現，不解釋為什麼

### 與前八話的對應
- 第一話動物異常 → 第八話夜鷹變大 → 第九話螞蟻變狗大（同主題的生物富態化層累進）
- 第六話窗口阿姨「是親子日啊」/ 第七話主持人「是送別日啊」/ 第八話工人「跟紅綠燈似的」→ 第九話祠堂對聯「屠狗」→「屠蟻」（民間命名手法的第四次變奏，這次是書面的，對應吳伯「教過書」的背景）
- 第八話軍方對異常「整併歸一」隱藏真相 → 第九話下河村對蟻穴公開處理、老幼皆知——美元紀遺留體制 vs 混沌紀地方聚集地的對照

### 留白清單
- 那個跟隊的年輕人叫什麼名字——不寫
- 他掉進蟻穴的具體過程——不寫（阿祥沒提細節）
- 旅人叫什麼、從哪來、要去哪——不寫（村民都叫他「北邊來的」）
- 下河村之前有沒有失守過——不寫
- 吳伯以前教書時的學校——不寫（一句「學校早就沒了」帶過）

### 與世界觀硬約束的對齊
- 公理 4.1 Token 無意志 ✓ 未涉及
- 公理 4.2 死亡三路徑 ✓ 未涉及（屠蟻隊年輕人的死是被蟻群處理，非 Token 事件）
- 公理 4.3 聚念場屏蔽 ✓ 作為「村內無蟻」這個現象的底層機制，不命名
- 公理 4.9 誕生機制 ✓ 未涉及

### 待設計者決定
- 「下河村」「石窯村」「吳伯」「阿祥」這些名字——任意替換
- 標題若覺得「仗義每多屠蟻輩」在祠堂對聯出現處理得不夠精——可改成老吳自己念一句、或阿祥說一句
- 年輕人死亡要不要寫輕一點（阿祥只說「沒看到屍體」一句而已，已經很輕）——你看節奏
