# 第三話：是芥末日

> 2026-04-13 設計者概念骨架 × Claude Opus 補肉
> 狀態：定稿（原合集檔 `美元紀末日.md` 於 2026-04-17 拆分歸檔）

---

那份文件是在一個禮拜二的下午被上傳的。

沒有人知道是誰傳的，也沒有人能說清楚它最早出現在哪個論壇。等主流媒體反應過來的時候，它已經被備份了幾十萬次，散布在每一個你能想到和想不到的角落。

文件本身不長，二十三頁。但能看的部分大概只有兩頁半。其餘的每一行字都被粗黑的墨條蓋得嚴嚴實實，連頁眉的機構名稱和日期都沒有放過。連頁眉的機構名稱和日期都沒有放過。

沒有人在乎那些塗黑的字。所有人在乎的是最後附的那段影片。

影片長四分十一秒，沒有聲音，只有在第三分鐘的時候，畫面左下角有一條很細的音軌突然出現，持續了大約九秒。

畫面是從一個觀察室拍的。隔著一面厚玻璃，對面是一間白色的實驗室，天花板很高，燈光慘白。實驗室正中央並排著六個金屬莢倉，每個大約一個人的長度，外殼連接著密密麻麻的線纜和管路。莢倉的蓋子是開著的。

前兩分鐘什麼都沒有發生。觀察室裡有人影在走動，但背對鏡頭，看不清面孔。

然後門開了。

不是觀察室的門，是實驗室的門。幾個穿著防護衣的人走進來，身後跟著一列人。

那些人穿著統一的、看不出顏色的連身衣，頭髮剃得很短，赤腳走在地板上。有男有女，走路的姿態各異——有人很鎮定，有人在發抖，有一個人一直在回頭看，被後面的防護衣推了一把。

他們被逐一帶到莢倉旁邊。有人在手臂內側注射了什麼，不到十秒，那些人就軟了下去，被抬進莢倉。蓋子合上。

防護衣退到牆邊。觀察室裡有人坐了下來，面前是一排螢幕，每個螢幕對應一個莢倉的生理數據。心跳、腦波、體溫，六組數字在穩定地跳動。

第三分鐘。

那條音軌出現了。是觀察室裡某個人的聲音，隔著防護面罩，悶悶的，像是在水底說話。

「啟動。」

六個莢倉同時亮起白光。

然後抖了一下。

很輕，像是被人從外面敲了一下。螢幕上的數據開始劇烈波動，心跳從七十幾飆到兩百多，腦波圖變成了一團無法辨識的鋸齒。

持續了大約四秒。

然後六個螢幕同時歸零。不是斷線，不是當機。是所有數值同時、精確地變成了零。心跳零，腦波零，體溫——體溫的讀數在歸零後又跳了一下，顯示了一個不可能的數字。

影片在這裡出現了嚴重的畫面撕裂。

最後半秒，畫面恢復了一瞬間。莢倉的蓋子還是關著的，白光已經熄滅。觀察室裡空無一人，椅子倒了兩把。

然後黑屏。

文件的最後一頁只有兩行字沒被塗掉。

「數量對不上。」

「無一生還。」

網路上炸了一天。陰謀論、外星人、生化武器、政府人體實驗，什麼說法都有。有人做了逐幀分析，有人考證機構代號，有人寫了十萬字的陰謀論長文。

但最被廣泛轉發的不是任何一篇分析。是一個迷因圖，上面寫著：

「世界末日？不，是芥末日——嗆到了但還能吃🌿」

那張圖下面的按讚數比所有正經討論加起來都多。

## 設計筆記

### 第三話核心
- 「數量對不上」：進去做實驗的人數 vs 事後採驗的數量。不說對不上什麼。讀者自己填
- 「無一生還」：不只是莢倉裡的實驗體，是整個設施在場的所有人。觀察室最後一幀空了，椅子倒了
- 刻意採模糊語意——設計者尚未定案細節，開放性比精確更好
- 影片沒有解釋任何事，只留下畫面。沒有旁白、沒有字幕、沒有結論
- 「芥末日」迷因是人類面對未知時的真實反應——不是不怕，是還沒意識到該怕
- 最後那朵花瓣紋路像指紋的花、「六號倉」的回覆——只是網路上的一個噪音，沒有後續，沒有驗證。種下疑點，不收割
