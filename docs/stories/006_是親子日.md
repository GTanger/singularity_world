# 第六話：是親子日

> 2026-04-17 設計者概念骨架 × Claude Opus 潤飾（重潤版）
> 狀態：待設計者審定
> 續五話《美元紀末日》，時序約在混沌紀初期（解放日後數年）

---

## 設計者概念（原骨架）

**主題**：是親子日
**主軸**：貧窮、溫馨
**概念**：母親生日也是兒子生日，母親辛苦拉拔兒子長大，兒子求學時期就開始兼差，成年更身兼多職，只為了讓辛苦的母親過好日子，今天是相約一起過生日的親子日，兒子特別請假帶母親去百貨吃大餐，但多年的勞累讓兒子在餐廳偶發性的腦溢血，急救不及當場死亡，恰巧附近的 T 彈事件，本該受波及的母親，看到兒子睜開了眼……

---

事後的報告裡，「死亡時間」和「目擊時間」被分開記載。這是事故報告標準格式之外的事。承辦的地區員警在備註欄寫了一行：「主訴家屬堅稱死者在宣告後仍曾站立移動」。那行字後來被劃掉了一次，又被補回來。補回來的時候多了一個問號。

然後是關於母親。五十六歲。資源回收工。單身扶養獨子二十九年。她的身分證影本被夾在報告的第一頁。照片裡的她看起來比登錄年齡老十歲。

關於兒子。二十九歲，沒有職銜欄能正確填。白天在某物流公司做排班派遣，晚上在兩家便利商店輪班，週末在某補習班當解答老師，假日幫母親撿回收。他的戶籍地跟母親是同一間樓梯間三樓頂加的鐵皮。郵差偶爾會把別人的信投進去，但沒有人來領過。

那天是他們的生日。同一天。母親生他，生日從此成為同一天。母親五十七歲了。兒子三十歲了。

---

那天兒子特別請了假。

「媽，今天我們不撿東西。」他這麼說。

母親沒有反駁。她換了她那件只有過年才穿的深藍色毛衣，毛衣有一塊領口被漂白劑濺到的痕跡，她挑了一塊別針蓋住。他們搭公車去了這座城市邊緣那棟重新開幕才三週的百貨公司。百貨重新整修是因為前年的一起事件——不大，但那層樓的玻璃全碎了。新裝的玻璃比以前厚。

進到七樓餐廳那層的時候是下午一點多。排隊排了三十七分鐘。母親站到中段的時候腿開始抖，兒子讓她坐到門邊的長椅上，自己繼續站。等到他們被帶入座，服務生送來冰水，先說了一句：

「祝兩位生日快樂。」

兒子事先打過電話說好。服務生離開以後，兒子從外套口袋裡拿出一個盒子推到母親面前。盒子很小，包裝紙皺皺的，看得出來是他自己包的。母親沒有伸手拆，只是用一隻手去摸盒子的邊角。

她說，「你不用這樣。」

兒子笑了。他笑的時候整張臉都在動。他從小就是這樣笑的，跟他父親一個樣子，但母親很少對他講這件事，因為她跟那個人已經二十八年沒聯絡了。

「媽，」兒子說，「這個你一直想要。」

母親最後還是拆了。盒子裡是一副老花眼鏡。架子是金屬的，細邊，很輕。母親戴上的時候手指有點抖。她說，「這個要多少錢？」

兒子沒回答。他推過來菜單。

他們點了套餐。兒子點了比較貴的那個給母親，自己點便宜的。服務生送湯過來的時候，母親已經把老花眼鏡拿下來擦了三次。不是因為髒，是因為沒有別的事可以做。

湯送到第二道的時候，兒子突然說頭暈。

他不是突然倒下的。他先是把湯匙放下，扶住桌角，說，「媽，我好像有點——」，然後身體往前傾，額頭撞到桌面。湯被碰翻了，流過桌布，滴到母親的褲子上。母親一開始沒有反應過來。她伸手過去摸兒子的背，說「怎麼了怎麼了」，然後兒子從椅子上滑下去。

隔壁桌有個穿西裝的男人站起來，走過來，說他是醫生。

母親讓開。

男人蹲下來做 CPR。他做得很穩，很有節奏。餐廳經理已經打了電話叫救護車。店裡其他客人有的站起來，有的繼續吃，有的拿手機錄影。一個小女孩從鄰桌探出頭來看，被她媽媽轉過頭去。

救護車到達需要十四分鐘。後來的通報這樣寫——那一帶的交通在下午開始出現「間歇性阻塞」，具體原因未列明。

做 CPR 的男人在第八分鐘停下來。他跟母親說，「我很抱歉。」

母親沒有說話。她跪在地上，一隻手扶著兒子的頭，把他的頭擺正。兒子的眼睛是半開的。母親把他的眼皮闔上。

這個時候救護車還沒到。

---

然後是外面。

餐廳靠窗那一排客人後來的口供都提到同一件事——窗外的天色突然沉了一下。不是雲遮住太陽的那種沉，是**顏色本身變了**。有一個在靠窗位子的老太太後來跟警方說，她那時候正好在看窗外對面的大樓，她看到那棟大樓的六樓有一面整片的玻璃——

「——變成別的東西了。」老太太這麼講。警方追問是什麼。老太太說，「我不知道，我就是說不上來。它變了。變完還在那裡。」

鑑識人員三天後才上那棟大樓的六樓。他們發現那一層有大約二十公尺寬的範圍變成了一個整齊的凹面。凹面邊緣像被刀切過的豆腐。沒有煙，沒有火，沒有碎片掉下來。凹面裡的辦公桌椅保持著幾秒前的擺設，只是擺設的東西**不再是原來的東西了**——每一樣都變得均勻、光滑、空白，像是物的概念被抽掉了。那棟大樓那時候是午休時間。辦公室裡有多少人，沒有正式數字。

這些都是後來才知道的。

事件發生的那一刻，餐廳裡聽到的是聲音——不是轟然一聲，是悶的，像有人在很遠的地下敲了一面很大的鼓。整間餐廳的杯子同時跳了一下。母親後來說，那個瞬間她感覺自己的頭皮「往上縮了」，但她的手還握著兒子的頭。

監視器的記錄在這個時候出現了色偏。色偏持續了九秒。

母親說不清楚那九秒她在做什麼。她只記得自己一直跪著，一直說話——她說她那時候一直在講兒子小時候的事。

九秒之後，畫面恢復。

然後兒子的眼睛張開了。

---

母親沒有立刻反應。她只是覺得兒子的眼皮在動，她以為那是她自己的手太重，壓到了。她正想把手移開，兒子的眼睛就張開了。

是張著的。

母親看著他。

兒子看著她。

那個瞬間沒有聲音。後來母親跟警方說，那個時候全世界都沒有聲音。她聽得到餐廳裡有人在哭，聽得到服務生跑動的腳步，聽得到遠遠的救護車聲——但那些聲音像是隔著玻璃傳來的。只有她跟兒子之間是安靜的。

她說，「——」

她想叫他的名字。

兒子眨了一下眼睛。

母親後來很多次重新整理那個眨眼。她說那個眨眼**很正常**。太正常。正常到她在那一秒想到的是，這個眨眼跟小時候兒子發燒醒來的時候一模一樣。

然後兒子坐起來。

---

他坐起來的方式不對。

不是一個剛剛宣告死亡的人坐起來的樣子。也不是一個剛醒來的人坐起來的樣子。是**直接的**。像他從來就會坐起來。他坐起來之前沒有停頓。他坐起來之後也沒有表情。

做 CPR 的那個男醫生這時候還站在旁邊——他已經站起來一會兒了，準備去幫母親處理後續。他看到兒子坐起來的時候退了兩步。後來警方的筆錄裡記下了他退這兩步的時間點，因為他退的位置正好有一臺監視器。

兒子站起來。他站起來的速度很慢，但每一個動作都很乾淨。他沒有扶桌子。他沒有看任何人。他走過母親身邊的時候，母親伸手想抓他的袖子。

兒子沒有避開。

但她的手**穿了過去**——不，沒有穿過去，這是她後來修正的說法。是兒子的袖子**已經不在那個位置了**。她抓到的是空氣。

她抬頭，兒子已經走到門邊。

他沒有回頭。

母親爬起來追。她後來說她追出餐廳，到了電扶梯旁邊，兒子已經不見了。她問電扶梯旁邊值班的保安，「剛剛有沒有一個穿灰色外套的年輕人下去？」

保安說，「沒有。」

母親描述了兒子的樣子。保安說，「我這裡沒有看到這個人。」

母親回到餐廳的時候，警方已經到了。她走到原來那張桌子旁邊，站了很久。

那個位置是空的。

桌布上湯的痕跡還在。椅子倒在地上。那杯水還在桌上，沒倒。

只是沒有兒子。

---

事後的鑑識報告對於母親的陳述有一段很短的註記。註記引用了三份文件：一份是百貨大樓六樓凹面事件的初步報告，一份是餐廳入場登記紀錄，一份是當日三點十二分到三點二十一分的監視器截圖。註記寫：

> 家屬陳述存在與物理證據不一致的段落。家屬目前情緒穩定，但建議轉介輔導資源。
>
> 需要留意：目擊證人中有三位（另外兩位坐在靠窗前排）對類似「目擊死者站立移動」的段落作出與家屬相符的陳述。三位目擊證人與家屬互不相識。三位證人的陳述與家屬陳述之間存在不可忽略的重合細節。
>
> 此部分未列入正式報告。

那三位目擊證人中有兩位後來在接受進一步約談時改口，說自己記錯了。另外一位不願意再受訪。

那天下午的餐廳不只母子兩個人。事後的結帳紀錄對照客人名單，有幾項對不上。前排靠窗第二張桌子的中年男客人被列為失蹤——他的外套還掛在椅背上，手機還在桌上，結帳沒有完成。靠牆那一桌的一對夫妻被送醫觀察，後來的紀錄說「意識存在但無應答」，他們被轉到中部某間安養院，再沒有家屬來認領。角落那桌三個年輕人——兩個被列為失蹤，一個後來被醫生判定為「無傷倖存」，三個月後出院，據說他的母親不讓他進家門。

這些都列進那天下午「凹面事件」的名單，用了同一個歸類代碼。代碼是新設的，混沌紀第二年才出現，專門用來處理這一類「波及但無遺體、或有人但失其魂」的名目。

母親那一桌沒有人列進名單。

後來清潔人員整理現場的時候說，她那張桌子的桌布上湯的痕跡還在，但周圍三張桌子的桌布全都像用乾洗機處理過，平整得反常。沒有人對這件事寫進筆錄。

母親的兒子最後被列為那天大樓凹面事件的十四位死亡/失蹤名單之一。他的死亡時間被改成下午三點十七分——也就是凹面事件發生的那一刻。原本在死亡紀錄上寫的「三點○八分」被塗掉了。

凹面事件的失蹤推定不需要遺體——凹面裡的東西「不再是原來的東西」，這是那幾年官方對所有類似事件的默契處理方式。

這樣列，家屬才能領到慰問金。

辦理補助金的窗口阿姨在母親來申請那天，看了一眼資料，說，「是親子日啊。」

母親說，「嗯。」

阿姨嘆了一口氣，沒有再問下去。

---

母親現在還住在那間樓梯間三樓頂加的鐵皮。她沒有搬走。

她每年還是過親子日。她不放蠟燭，不買蛋糕。她只是做一桌菜，擺兩副碗筷，坐下來吃。

鄰居偶爾會看到她一個人走出門，去那間百貨公司的七樓。那間餐廳已經換了名字，也換了經營團隊。但靠窗那一排桌子的位置沒有動。

她會點一杯茶。

坐到他們原本坐的那個位置。

不點餐。

---

## 設計筆記

### 命名邏輯
- 「是親子日」承襲五話戲謔命名傳統（芥末日 / 煙火日 / 是解放日 / 是常態日）
- 這次命名不從網路迷因來，從窗口阿姨的一句嘆息來——命名機制從眾聲喧嘩降格到一個人的私語
- 混沌紀進入第幾年後，事件已不足以成為全國戲謔素材，只剩下當事人自己命名的日子

### 敘事約束守法
- 不命名任何 Token 物理專有詞（Token / 念場 / 富態化 / 神化 / 異化 / T 彈）
- 窗外大樓六樓 T 彈以「凹面」「悶的像地下敲鼓」「監視器色偏九秒」「物的概念被抽掉」描述，不觸動詞
- 兒子的轉化以「睜開眼」「站起來的方式不對」「袖子已經不在那個位置了」現象語帶過
- 末段母親的後續只寫行為（擺兩副碗筷、點一杯茶、不點餐），不寫情緒

### 兒子的轉化路徑
（設計端可見，敘事層永不揭示）
- 兒子腦溢血當場死亡 = 意識比肉體早消亡，肉體仍是新鮮、高度有效的「無念質」載體
- 隔街 T 彈觸發區域性極高 Token 沖刷，**餐廳整個在沖刷範圍內**
- 符合 tribes.toml 三路徑神化修正因子組合：`no_nian_substrate × token_bombing_proximity × extreme_token_saturation` 同時激活
- **關鍵物理澄清**：神化 = **同一具肉體**被 Token 烙印（「肉體修復完美 + 意識格新」），不是「原始屍體留下 + 意識副本分離離開」。兒子站起來走出餐廳 = 原始肉體帶著新意識離去。母親回到現場只能看到空椅和物件殘響，**沒有遺體**——這是神化事件的物理結果，跟五話第二話腦死患者「從窗戶翻出去、警方在地面沒找到任何東西」同機制

### 親子日的世界觀核心：兒子神化瞬間念場保護母親
- 母親本該被 T 彈沖刷波及——屬於三路徑分岔候選：崩解 / 異化 / 神化
- 但**兒子神化的那一瞬間**，新生成的混沌念場自動向母親方向展開保護，對齊五話第五話警衛擋 T 彈機制（「念場只向前，把所有方向都指向前方」，背後留空保護老官員）
- 兒子念場強度有限（剛神化，還未完全成熟），保護範圍只到母親和他自己這張桌子周圍，形成一塊小小的「被保留在原本時間裡」的區域——敘事層以「周圍三張桌子的桌布平整得反常」側寫，不正面描述
- 餐廳其他客人在保護範圍外，依各自個體狀態觸發三路徑分岔：
  - 中年男客人（靠窗第二張椅子）= 崩解，肉體消失，外套/手機/結帳痕跡留下
  - 夫妻（靠牆）= 異化，執念殘體保留肉體輪廓但無靈魂，意識存在但無應答
  - 三個年輕人：兩個崩解、一個異化（醫院三個月後走出來的不是原本那個人，其母不讓他進家門）
- 這是「是親子日」的世界觀核心：**兒子死亡的那一刻保護了母親**。Token 物理對關係盲，但神化人誕生瞬間的念場指向性繼承了死前最後的意向——朝向母親
- 公理 4.4「神化人對被誤讀不響應」的種子埋在這裡：兒子成為神化人後，沒有返回母親身邊，沒有表達感情，只是走出餐廳消失。他死前的意向已經兌現在保護的那一秒，神化後已不是原本的兒子

### 餐廳其他客人命運作為三路徑分岔田野樣本
- 此場景為 L2 死亡三路徑分岔（公理 4.2）的**單點高強度 Token 沖刷下樣本**
- 敘事處理：主敘事線保持母親單一視角，不在事件當下跳開去描寫其他桌；其他桌命運移至事後「鑑識報告 + 歸類代碼」段落作為側寫
- 碼農調整 tribes.toml 修正因子時可參考此場景的分布（崩解多、異化少、神化極罕）

### 三位目擊證人改口
- 未指定原因。可能路過的班底活動、可能神化人訊息、可能單純的社會壓力
- 留白不揭示，符合公理 4.8 不可根除下的世界質感

### 兒子去了哪
- 轉成神化人 → 立刻消失蹤影（公理 4.4）
- 他走出餐廳 → 走到電扶梯 → 保安沒看到 → 從此沒有紀錄
- 可能進入某個「神化人散居的不可辨識狀態」，也可能就是消失
- 保安那句「我這裡沒有看到這個人」是本篇的紅光手法——沒有人看見，或者更精確地說，沒有人注意到

### 與五話的呼應
- 第二話：腦死患者站起，同房老人旁觀，「他的眼睛在看」
- 第六話：兒子站起，母親在場，「那個眨眼很正常。太正常」
- 從陌生人的冷旁觀 → 血親的親眼所見，敘事距離拉近，但 Token 物理對關係是盲的
- 這是世界觀的硬邊界：神化不因母子關係而改變，也不因之而更慈悲或更殘忍

### 疊影 motif：那個時代的每個母親
- 事後側寫中「角落桌第三個年輕人，母親不讓他進家門」——對應本篇母親的處境，兩個都在經歷「兒子還在但不是兒子」
- 這個疊影把「是親子日」從單一悲劇擴展為那個時代所有母親的共同創傷

### 結尾母親的選擇
- 沒有崩潰、沒有尋找、沒有揭露、沒有復仇
- 兩副碗筷 + 不點餐 = 混沌紀普通人的默認姿態
- 這是「五話風格的勝利」——把巨大的形上學事件放進一個母親的日常，事件就被日常收納進去，不是日常被事件粉碎
