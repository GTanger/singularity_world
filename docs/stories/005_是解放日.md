# 第五話：是解放日

> 2026-04-13 設計者概念骨架 × Claude Opus 補肉
> 狀態：定稿（原合集檔 `美元紀末日.md` 於 2026-04-17 拆分歸檔）
> 本話是美元紀→混沌紀的轉折點，後續混沌紀敘事以此為 tick 0 起點

---

那份 A4 紙改變了一切。

準確地說，是那份 A4 紙上寫著的百萬分之一。

煙火日過後不到兩個禮拜，各國政府的反應分成了兩半。對外的那一半是安撫：我們正在評估，我們會重建通訊基礎設施，請民眾不要恐慌。對內的那一半是恐慌：我們什麼都不知道，我們連它是什麼都不知道，而它正在把我們往裡面擠。

那百萬分之一的解析報告從 G 集團的保險櫃裡被影印了出來。影印件被送到十六國的最高機密會議桌上。報告只有一頁 A4，正面。背面是空的。

沒有人公開說過那頁紙上寫了什麼。但之後發生的事情說明了一切。

新一輪軍備競賽在三個月內全面展開。

表面上，它看起來很文明。G 集團的子公司開始向民間發售「第一代 Token 輻射應用設備」——能偵測局部 Token 密度的手持儀器，能在高密度區域提供短暫防護的穿戴裝置，以及幾種語焉不詳的「環境穩定器」。廣告裡依然用那種溫暖的、充滿希望的語氣：「理解它，才能與它共存。」

背地裡，是另一回事。

軍方的預算在那一季翻了四倍。採購清單裡出現了從未在任何公開型錄上見過的品項代號。偏遠地區——那些已經被安全空間邊界排除在外的地帶——開始出現新建的圍牆設施，沒有標誌，沒有門牌，只有全天候的武裝巡邏和往來的無標記車輛。

民間私人實驗室更快。法律還沒來得及監管一種連命名都不到半年的東西，它們就已經在運轉了。有些藏在大學地下室裡，掛著「基礎物理研究」的牌子；有些更直接，設在遠離人煙的廢棄工廠，用現金發放薪資，不留任何紀錄。

各種人體實驗在暗處重新啟動。

比芥末日那份外流文件裡的更大膽。更系統化。更不把人當人。

學術界的反彈來得很快，但去得更快。聯合聲明、公開信、抗議遊行，UNESCO 的特別會議開了三天，最終聲明裡的措辭從「強烈譴責」被改成了「深切關注」。有幾個特別大聲的學者在半年內陸續從公共視野中消失——沒有死亡，沒有醜聞，只是不再發言了。

事情就這樣加速運轉著，直到那個組織出現。

它自稱「神使」。

第一次被公眾注意到是在一支網路影片裡。畫面很粗糙，手機拍的，晃動得厲害。一群人站在某座城市的廣場中央，穿著白色的連身衣——和芥末日影片裡那些實驗體的衣服不一樣，這些是乾淨的，剪裁合身，像制服。他們排成一個圓，中間站著一個人在說話。

「祂們已經行走在我們之間了。祂們不是輻射，不是災難，祂們是新世代的神明。」

「萬物正在被重新定義。這不是毀滅，這是大創世紀。」

「我們是祂們的使者。我們是神使。」

影片傳了幾十萬次。大部分人當笑話看。又一個末日邪教，網路上多的是。

然後他們開始炸東西。

第一次是在某國的國會大廈外面。「爆炸」發生在凌晨，沒有傷亡，但國會大廈面向街道的整面牆上出現了一個完美的圓形凹陷，直徑大約三公尺，深十幾公分。不是被炸的——沒有碎片，沒有焦痕，沒有衝擊波的痕跡。那面牆看起來像是從來就長成那個形狀，只是昨天還不是。

神使在事後發布聲明：「淨化已經開始。大創世紀降臨。」

各國安全部門同步啟動了追查。結果令人不安：沒有炸藥殘留，沒有任何已知武器的特徵，監視器畫面在事發前幾秒出現了和煙火日類似的色偏。最關鍵的是——鑑識人員在現場找不到任何人類的 DNA。不是清理過，是根本沒有。

接下來的幾個月裡，類似的事件在世界各地接連發生。規模越來越大，目標越來越精準——政府設施、軍事基地外圍、國際會議的下榻飯店。每一次都在有人的時候發動，但神使似乎並不在意殺多少人。他們在意的是被看見。

然後有幾次，人消失了。

不是被埋在瓦礫下面。是消失。在場的人、周圍的人，在那個圓形凹陷的範圍內，什麼都不剩。衣服不剩。鞋子不剩。手錶和手機不剩。連他們站過的那塊地板都變得異常乾淨，像剛鑄造出來的。

政府內部開始出現一個詞：T 彈。

公開場合沒有人用這個詞。因為要承認 T 彈的存在，就等於承認有人能用 Token 當武器。而這意味著那份 A4 報告裡的百萬分之一——被人用上了。

大多數政府選擇不信。

他們有自己的理由。第一，他們自己正在開發的東西讓他們對自身的武力有信心。第二，T 彈的概念太離譜——現場沒有彈片，沒有殘骸，沒有任何物理意義上的「彈」。第三，在那些消失事件裡，消失的不只是人，連人存在過的痕跡都沒了。這不像武器，更像魔術，而政府不相信魔術。

然後是匿名信。

同一天，全球十二個國家的元首辦公室各自收到了一封沒有署名的信。信是手寫的，每一封的筆跡都不同，但內容完全一致。

信的內容很短。

「神使組織的成員不是神化人。他們是異化人。
神化人不是他們的主腦，也不是他們的神明。
神化人僅僅是神化人。
他們可能在近期對政府目標發動大規模行動。
以上。」

信沒有說明什麼是「神化人」、什麼是「異化人」。沒有解釋，沒有論證，沒有附上任何佐證資料。

各國情報機構分析了筆跡、紙張、墨水。紙張是普通的影印紙，墨水是普通的原子筆墨水。十二封信的筆跡確實各不相同。唯一的異常是——指紋。每一封信上都有清晰的指紋，但所有指紋都無法在全球任何資料庫中比對到任何人。

有些政府認真看了。有些沒有。

大多數的結論是：已知，但不足以改變現行部署。

---

那天的天氣很好。

那座公立醫院是老醫院了，在這座城市佇立了幾十年。前幾年因為結構安全問題進行了大規模整修擴建，今天是竣工剪綵儀式。規格不小——中央來了幾位高層，主要是因為這間醫院曾經的院長，一個在醫療體系裡服務了一輩子的老官員，今天正式退休。

院方在大門口搭了一個臨時舞台。紅布、花籃、麥克風，一切按照慣例。台下坐了醫院的員工、附近的居民、幾台新聞攝影機。安保規格比平時高一些——畢竟有中央的人來——但也沒有高到誇張的程度。

老官員站在台上，穿著深色西裝，頭髮全白了，但精神很好。他正在跟旁邊的人說笑，那種在某個地方待了幾十年的人才有的自在。他認識這裡的每一面牆。

儀式進行到一半——老官員正拿著剪刀對著紅緞帶，旁邊的人舉起相機——

台下起了騷動。

幾個人從人群裡衝出來。速度很快，動作很利索，不像普通人。他們直撲舞台，見人就推，碰到的東西就掃開。官方的安保人員反應過來時已經被逼退了好幾步——不是打不過，是那幾個人的力量不對。有一個安保人員後來說，他被其中一個人推了一把，感覺像是被車撞的。

場面在三秒內從喜慶變成混亂。台上的人開始往後退，有人喊叫，攝影機倒了一台。

然後有一個人動了。

他穿著院方新發的保全制服，站在舞台側邊，本來只是眾多警衛中不起眼的一個。中等身高，偏瘦，五官平凡，如果不是接下來發生的事，所有人都會忘記他的存在。

他動的方式不對。

不是衝，不是跑，是一種流暢到不像人體能做出的位移——有人後來看監視器回放時說，他「像是被快轉了」。風跟不上他。揚起的灰塵在他已經到達下一個位置之後才落下來。

三個衝上來的襲擊者在不到兩秒內全部倒地。沒有人看清他做了什麼。他們就是倒了——像是被一隻看不見的手精確地按在地上。

警方從兩邊湧上來控制現場。襲擊者被壓制住。舞台上的人還沒來得及從驚嚇中回過神。

老官員從人群後面被護著走出來，看了一眼那個站在台前的警衛。他停了一下。

那個警衛的臉，他見過。

這麼說不準確——他「照顧」過那張臉。好多年。他在這家醫院任職的最後幾年，有一個公益收容的無名氏腦死患者。他每次巡病房都會在那張床邊停一下，不是因為醫囑，是因為習慣。護理師們知道，那個院長對那張床有一種說不上來的、非醫療的在意。

那個腦死患者在某天凌晨消失了。從十三樓。

老官員還沒來得及開口。

幾聲嘶吼同時炸開。

「大——創——世——紀——降——臨！」

不是從被壓制在地上的那幾個人嘴裡喊的。是從更遠的地方——人群外圍，街道對面，甚至頭頂的某個方向。聲音不像是用喉嚨發出來的。

那幾個被壓制的襲擊者開始發生變化。

他們的頭頂上方的空氣開始扭曲。有人說像熱氣蒸騰，有人說像龍捲風的雛形。他們的頭顱泛起一層光，不亮，是那種悶悶的、帶著混濁感的光，像髒了的日光燈管。壓制他們的警察被一股力量彈開——不是被打，是周圍的空氣突然變得非常稠密，人站不住。

那個警衛看見了。

所有的東西他都看見了。

他看見那些人頭頂的氣旋開始加速。他看見光從混濁變得刺目。他知道接下來會發生什麼——不是因為有人告訴他，是因為他的身體裡有一部分跟那些東西是同源的，就像你不需要學習就知道火會燙。

舞台在他身後。老官員在他身後。所有人在他身後。

距離太近了。

他能做的事情只剩一件。

監視器的畫面在這一刻出現了和之前每一次一樣的色偏。但在畫面完全失真之前的最後幾幀裡，能看見這些：

那個警衛走向那些正在發光的襲擊者。不是跑，是走。很穩，很快。他走到他們前面，站定。

然後他張開了什麼。

不是手臂。是他一直在收束的、從未展開過的、他成為「這個東西」以來就本能地壓在身體最深處的——混沌念場。

全開。

像一面牆，像一道浪，像一個巨大的、不可見的罩子，從他的身體裡向前湧出，把那些正在引爆自身的襲擊者全部罩進去。

同時，他的背後——是空的。

念場只向前。他把所有的方向都指向前方，把自己和那些人一起裝進去，把舞台和舞台上的人隔在外面。

監視器畫面完全失真。

一道白光。

不是爆炸的光。是定義被改寫時、物質被重新詮釋時、那個瞬間釋放出來的光。

聲音是悶的，像有人在你耳邊敲了一面巨大的鼓。不是「轟」，是「嗡」。

持續了不到一秒。

然後什麼都沒有了。

舞台前方的空地上，地磚是乾淨的。非常乾淨。那種「剛從工廠出來」的乾淨——沒有灰塵，沒有磨損，沒有任何東西曾經站在上面的痕跡。

警衛不在了。壓制襲擊者的警察不在了。襲擊者不在了。

什麼都不剩。

老官員站在舞台邊緣，扶著倒了一半的花籃，看著那片空地。他的嘴張著，但沒有聲音出來。

他花了很長時間才說出第一句話，對著身邊已經嚇傻的隨從：

「我認識他。」

---

同一天，全球發生了十七起類似事件。

吉隆坡的東協安全峰會，與會的八國代表團全滅。柏林的北約特別會議，整棟建築的三分之一區域變成了光滑的凹面。開羅、墨西哥城、雪梨、新德里——每一座城市都在同一個小時內遭到了襲擊。

神使組織在事後發布了最後一份聲明。只有一行字：

「大創世紀已降臨。舊世界已被解放。」

各地政府在二十四小時內陷入癱瘓。不是因為制度崩潰，是因為人沒了。決策鏈上的關鍵節點——部長、參謀、情報首長——在同一天、同一個小時內，從這個世界上消失了。

那些匿名信的副本在事後被翻出來，攤在倖存的辦公桌上。

信上的每一個字都是對的。

---

事後的分析報告用了一個月才拼湊完成。結論很簡短：

襲擊者是異化人。人體實驗的失敗品——不，不是失敗品，是「不完全的成功」。他們的念場沒有歸零，殘存的意識碎片和 Token 的混沌能量在同一個身體裡互相撕扯，留下的是本能、衝動、以及一種不穩定的、能引發連鎖反應的共振能力。

所謂 T 彈，從來不是彈。

是人。

是異化人將自身殘存的混沌能量瘋狂地向外吸引周遭的游離輻射，讓 Token 密度在極小的範圍內飆升到臨界點，然後用自己殘破的念場去引爆它。引爆的不是炸藥，是「這片區域裡的一切東西是什麼」的定義本身。

所以沒有彈片。因為不是破壞。

所以沒有殘留。因為那些東西還在那裡——只是已經不再是原來的東西了。

而那個警衛。

專家在報告的最後附了一段備註，語氣比正文謹慎得多。他們寫道：該名個體的行為模式與已知的異化人完全不同。異化人的念場是破碎的、外散的、不可控的；該個體展現出的念場是完整的、有方向性的、經過高度收束的。

「如果異化人是失敗的改寫，那麼這個個體可能代表了一種……完成的改寫。」

報告沒有用「神化人」這個詞。那個詞是後來才被人從神使的文宣裡挖出來的。

但所有讀過報告的人心裡都有同一個問題：

如果匿名信是對的，如果神化人不是神使的人，如果神化人「僅僅是神化人」——

那他為什麼會在那裡？

## 設計筆記

### 第五話核心
- 敘事尺度再放大：從個人（降臨/甦醒）→ 單點實驗（芥末日）→ 全球事件（煙火日）→ 文明結構崩潰（解放日）
- 第二話的腦死病患再現——以警衛身份保護曾照顧他的老官員。這是五話中第一個有「選擇」的被觀測角色
- 神化人的本能是不干預（繼承創造者禮讓），但他選擇了干預。代價是自己也消失了
- T 彈的真相：不是武器，是人。異化人 = 不完全改寫 = 殘存念場與混沌能量衝突 → 不穩定共振 → 自爆式引爆區域定義
- 「沒有彈片因為不是破壞」——Token 烙印 = 重新定義，不是變形。T 彈只是把這個效應暴力化
- 匿名信來自神化人。信的措辭極簡、無論證、無感情，符合神化人特質（邏輯、非干預、但選擇在底線前出聲）
- 老官員認出警衛 = 情感錨點。整個故事裡最人性的一刻：他照顧了一個腦死的身體八年，那個身體回來救了他
- 政府忽視匿名信 = 人味檢定通過。真人也會這樣——自認武力夠用、T 彈太離譜、情報不可信
- 解放日的雙重含義：神使認為是「舊世界的解放」，但對讀者而言，被解放的是敘事本身——第一次出現了一個被觀測到的主動行動角色
- 「數人共睹」= 這不是唯一事件，全球同時在發生，有的被拍到有的沒有。每一話的案例都只是被觀測到的那個，不是第一個也不是唯一
