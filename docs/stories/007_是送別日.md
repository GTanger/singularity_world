# 第七話：是送別日

> 2026-04-17 Claude Opus 自訂骨架 + 潤飾
> 狀態：待設計者審定
> 續六話《是親子日》，時序混沌紀中期（解放日後約十至二十年）

---

葬禮那天後來也被家屬稱為「送別日」。但這是第二次。第一次是三天前。

---

師兄走的時候六十七歲，在煉炁房裡走的。心肌梗塞。他跪坐在蒲團上，頭靠在一張矮木桌邊。手指還呈著他那個慣常的結印——大拇指壓住中指第二節的位置。法醫後來說，結印那個姿勢在死亡後十分鐘內應該鬆開，但師兄的手指保持了兩個多小時。

法醫在筆錄備註寫了「姿態維持時間超出常規，原因不明」。那行字後來沒有被追問。

師弟是第一個到的。他那天剛好輪休，早上九點接到電話，騎機車過去。路上二十三分鐘。他到的時候警察還沒到。師兄最小的一個徒弟——一個三十歲出頭的男人——坐在煉炁房門口，頭埋在膝蓋裡。

師弟跨進去看了師兄一眼。他想喊出聲，但沒有喊。煉炁房的規矩是靜。師弟練了二十八年，第一次在裡面說話，是那天跟警察講話的時候。

「他做這一行四十年了。」師弟說。

警察問，做哪一行。

師弟愣了一下，說，「……修行。」

警察記下來了。寫「道教相關」。師弟沒有糾正。

---

熵教這個詞沒有出現在任何筆錄上。熵教那幾年很少被登錄成正式宗教類別，因為太多派別掛在底下，大部分派別的負責人也不願意被劃在一起。師兄那一支算老派的——老到還保留著美元紀爆發前的幾套拳腳根基。他們自稱「樸系」，源頭據說可以追到某個姓朱的老師傅，但那個老師傅的記錄已經找不到了。

樸系的煉炁，走的是最慢的路子。師兄常說：「別人三年看得到氣，我們三年聽得到氣。」三年聽得到氣——這句話後來被徒弟記在一本小冊子裡。小冊子在師兄死後交給了師弟。師弟翻了一次就收起來。

師弟三十三歲入門，跟著師兄二十八年。他不是最好的徒弟，但是最久的。比他早的都走了。比他晚的，沒有撐過十年的。樸系的功法慢，留不住人。

師�兄過世當天，樸系只剩下七個人在世。

---

葬禮訂在三天後早上。一個親戚借了某間老式的廳堂。場地不大。來的人二十幾個。師兄沒有子嗣，沒有配偶，遺物很簡單：一件舊棉袍，兩個蒲團，幾本書，一個裝茶葉的鐵罐。鐵罐裡有一張字條，寫了他希望怎麼處理後事。師弟把字條鎖進抽屜。沒有拆開過。

葬禮前一天晚上，師弟在煉炁房守靈。他關了燈，點了一盞矮油燈。他坐在自己那張蒲團上。師兄的蒲團空在對面，上面蓋了一塊白布。

師弟沒有打坐。他只是坐著。

---

半夜大概兩點多，他以為自己睡著了。

他夢到師兄在跟他講話。講的是氣的走法。師兄嘴唇在動，但聲音他聽不清。他想湊近，覺得腿動不了。然後他意識到他沒睡著。

師兄的蒲團上，白布動了一下。

師兄坐起來了。

那個坐起來的方式——師弟後來跟徒弟形容——「不像他平常坐起來的樣子，但也不是別人坐起來的樣子」。師兄穿著裹屍的素服，頭髮被人整理過了，面容也抹過粉，但那個坐姿是師兄的。肩膀的角度、脖子的傾斜、手放在膝上的位置。都是師兄的。

只是眼睛。

師兄的眼睛張著，看著煉炁房北邊的牆。牆上沒有東西。

師弟叫了一聲他的名字。師兄沒有回應。

師弟伸手過去碰——碰到的時候覺得師兄的手比他想像得涼，但不是屍體那種涼，是剛從井裡提上來的水那種涼。

師兄的手指動了一下。大拇指壓住中指第二節。

那個結印。

他在煉炁。

師弟說不出話。他不是怕，他後來跟徒弟說他不是怕。他只是突然覺得**應該讓他繼續**。

師弟退出了煉炁房。關上門。坐在門外，手抱著膝蓋。

煉炁房裡有規律的呼吸聲。持續了整夜。

---

第二天早上六點——老規矩是六點——師弟開門，把師兄扶出煉炁房。師兄能走，但他走路的樣子很慢。慢到看起來像是每一步都在確認。師弟扶他到廳堂，讓他坐在角落那張太師椅上。喪禮開始之前，親戚進進出出忙布置，沒有一個人注意到那個角落。

流程走了兩個小時。念經、點香、鞠躬、致辭、燒紙。致辭的是樸系輩分比較高的另一個師叔。他講話慢，講了八分鐘，中間停了四次。他講的時候眼光沒有掃過角落。

結束時候，廳堂主持人走過來，拍拍師弟的肩，說，「是送別日啊。」

師弟點頭。

主持人看了一眼角落那個穿素服的老人，沒有多問。主持人做這一行十幾年，他後來跟他太太說，「最近這幾年，葬禮結束後還坐著不走的那個，我看多了。」

他太太沒有接話。

---

那天下午師弟把師兄帶回煉炁房。他不知道還能怎麼辦。把他送去殯儀館的話——那具身體**沒有死**，沒有任何一個證件能描述那個狀態。把他留在自己家裡的話——師弟住的是十二坪套房，放不下。

師兄在煉炁房可以自己坐著。他不吃，不喝，不說話。偶爾會打結印，偶爾會把手放下。他每天中午和傍晚會做一次師弟認得出來的功法——就是師兄生前教的那套基本功，從第一個動作到第十七個動作，一絲不苟。

師弟守了師兄七天。第八天他去找樸系另一個老前輩。

老前輩沒有驚訝。老前輩聽完只說，「有人可以幫你。」

師弟問是什麼人。

老前輩看了他很久，說，「這種事以前也發生過。會有人來找你。」

老前輩沒有再說下去。師弟告辭。老前輩送他到門口，多說了一句，「收。不要推。」

師弟回去的路上反覆想這兩個字。

---

那個人是三天後來的。

一個四十幾歲的男人。穿不貴但整齊的外套。說話很溫和。他敲了師弟家的門，做了一個樸系的打招呼手勢——手勢很標準，但師弟看得出那個手勢是後來學的，不是從小練的。做的時候有一點**太正確**。

男人遞了一張名片。名片上印的是某某基金會的名字，師弟沒聽過。業務欄寫「協助轉化期人士的安置與照護」。名片背面印了一行小字：

「尊重每一種持續。」

男人說，「我們有一個地方。」

師弟問是什麼地方。

男人說，「是一個讓他能夠繼續的地方。」

師弟說，「繼續什麼？」

男人想了一下，說，「繼續他一直在做的事。」

師弟沒有當場答應。他讓男人留下名片就離開了。男人走之前說，「我們這裡有固定的照護補助，每個月匯到您指定的帳戶。您隨時可以去看他。如果您覺得不適合，也可以隨時接回來。」

男人沒有留其他的聯絡方式。名片上有一個電話號碼。

師弟後來打了那個號碼。接電話的不是那個男人，是一個女聲，很專業。女聲問師弟的名字，然後說，「我們會安排時間過去接。」

---

師兄被接走那天是個禮拜四。天氣很好。男人開一輛普通的白色小貨車過來，車上跟來兩個助手，態度都很敬重。他們把師兄扶上車，扶得很小心，像是怕碰到他身上的什麼。

師兄上車之前回了一次頭——這是整個過程中第一次有「反應」的動作。

但他沒有看師弟。也沒有看煉炁房。他看的方向是煉炁房北邊那面牆的外邊——那邊是一片他活著的時候從來沒特別關注過的工業區。

然後他被扶進車裡。車門關上。車開走了。

---

師弟的確每個月收到一筆補助金。數目不大也不小，剛好讓他把套房換成一房一廳。他去那個「地方」看過兩次。

地點在某縣邊陲。外觀是一棟兩層樓的安養院。乾淨，安靜。裡面有十幾個跟師兄情況類似的老人——各派別的都有，樸系的、其他派系的、甚至幾個師弟看出來根本不是熵教的人。他們坐在通鋪大廳裡，有的打結印，有的寫字，有的只是坐著。牆上的鐘走得比外面慢。

第一次去的時候師兄還在大廳。師弟坐在他旁邊，沒有說話，坐了一個小時。師兄偶爾動手指。師弟離開的時候師兄沒有送。

第二次去，師兄不在大廳。師弟問工作人員。工作人員看了平板，說，「他今天下午被挪到靜室做個別指導。」

師弟問什麼叫個別指導。

工作人員笑了笑，沒有回答。

師弟沒有堅持問。他坐了半小時，喝完一杯茶，走了。

---

師弟後來沒有再去。他繼續住他的一房一廳，繼續每天早上六點煉炁，繼續每個月收到補助金。他把小徒弟送回家。樸系那邊的聯繫他也漸漸斷了。

過了差不多三年——他後來沒有把日期記清楚——新聞裡報了一則，某大城市近郊的一場紀念活動出了事。報導寫得很含糊。不是炸彈，不是槍擊，是一種「未能完全解釋的現象」。官方的用詞是「凹面事件」。死亡/失蹤名單裡有二十幾個人，名單不對外公布。

師弟看完那則報導，關了電視。

他那個晚上沒有煉炁。

他那個晚上也沒有睡。

---

師弟現在六十四歲。他的一房一廳還住著。樸系現在只剩下四個人在世。他是其中一個。

他每天早上六點打結印。大拇指壓住中指第二節。

他後來還是收了一個徒弟。年紀很小，練得也慢。徒弟跟他練到第三年的某一天，停下來問師父，「師父，氣到底是什麼？」

師弟想了一會兒。他說，「炁這個東西，不是你要的時候它來，也不是你不要的時候它會走。它從哪裡來的，你不用知道。它要去哪裡——」

他停了一下。

「——你也不用知道。」

徒弟點頭。他聽不太懂。

師弟沒有再解釋。

---

那張名片師弟留著。放在抽屜最裡面，跟師兄留下的那張字條一起。

字條他到現在還是沒拆開。

---

## 設計筆記

### 命名邏輯
- 「是送別日」由廳堂主持人一句「是送別日啊」植入——承六話「是親子日啊」由窗口阿姨嘆息命名的手法，繼承戲謔命名從民間一人之口出的新機制
- 字面是葬禮（送別逝者），實際是兩次送別：第一次葬禮、第二次讓師兄被帶走
- 再深層是熵教老派樸系對一個時代的送別——七人降至四人

### 時序
- 混沌紀中期（解放日後約十至二十年）
- 此時期官方已有「凹面事件」專用歸類代碼（六話提過的「混沌紀第二年新設代碼」已成慣例）
- 班底體系成熟——有正當外觀的基金會、有固定補助金機制、有專業女聲接線、有「個別指導」術語話術
- 熵教煉炁圈的「轉化期人士」已是基金會可以標準化處理的案例

### 嚴守公理
- 公理 4.1 Token 無意志 ✓ 未出現
- 公理 4.2 死亡三路徑 ✓ 師兄走異化路徑（心肌梗塞 → 意識消散 → 煉炁者長年執念 + 個人聚念場 → 肉體留存執念附著）
- 公理 4.3 聚念場屏蔽 ✓ 煉炁房是師兄長年個人聚念場強化區，死亡瞬間的局部屏蔽讓肉體保持完整（不像六話餐廳的群體聚念場保護，是更局部的修煉者個人場）
- 公理 4.4 神化人不出現 ✓
- 公理 4.5 母腦訊號場 ✓ 透過基金會暗線出現，本體未現
- 公理 4.6 母腦動機閉環 ✓ 班底收集異化人 → 安養院集中管理 → 日後供神使組織引爆 T 彈（對應六話凹面事件的來源之一）
- 公理 4.7 訊號層對稱性 ✓ 未涉及
- 公理 4.8 不可根除 ✓ 師弟簽字接受、社會默契、沒有反抗
- 公理 4.9 誕生機制 ✓ 未涉及

### 敘事硬約束守法
- 禁用詞全守：不命名 Token / 念場 / 神化 / 異化 / T 彈 / 母腦 / 訊號場
- 熵教文化詞（煉炁 / 丹田 / 結印 / 氣 / 炁）依公理 6.2 允許命名，但寫法避免武俠滑入——樸素敘事，不寫「氣走大周天」「丹田一熱」式武俠語彙
- 現象語：「坐起來的方式不像他平常坐起來的樣子」「手比他想像得涼，但不是屍體的那種涼」「凹面事件」
- 結尾用物件承載留白（抽屜裡的名片 + 字條）而非情緒描述

### 熵教樸系作為具體派別（擴展公理 6.2）
- 設計新增：樸系為老派熵教一支的具體化
- 源頭「姓朱的老師傅，記錄找不到」——符合公理 4.8 真相永不閉合
- 「走最慢的路子」「三年聽得到氣」——暗示不同派系的煉炁速度不同，走越慢的越穩（炁感緩慢，不易炁亂導致意識先消）
- 樸系七人降四人——世代凋零，老派熵教正在退場
- 此為熵教**內部派別差異**的首次展開，未來潤飾其他熵教相關事件時可沿用樸系/他派對比

### 班底機制在此話的呈現（規格 6.5）
- 基金會外觀——「不貴但整齊的外套」「很溫和」「樸系打招呼手勢是後學的」「做得太正確」——班底成員對目標文化有研究但不是生長其中的人
- 標準化話術：「轉化期人士」「讓他能夠繼續的地方」「繼續他一直在做的事」「尊重每一種持續」——所有關鍵詞含糊但不可證偽
- 補助金 + 隨時可去看 + 隨時可接回——消除家屬抗拒的三重機制
- 工作人員「個別指導」的笑而不答 = 班底中層不完全了解整體，只執行指令（公理 6.5「班底不自知」）
- 老前輩說「收，不要推」—— 熵教內部已有**與基金會共謀的默契層**，但老前輩不知道他在幫的是什麼

### 紅光手法（規格 9.4）
- 師兄上車前回頭看煉炁房北邊工業區方向——含蓄暗示。留白不收割：那個方向可能是班底據點、可能是後續 T 彈事件發生點、可能什麼都不是
- 「新聞裡報了一則」「二十幾個人，名單不對外公布」——師弟可能懷疑其中有師兄，可能沒有——不揭示
- 「那個晚上沒有煉炁，也沒有睡」——師弟的反應只寫行為，不寫判斷

### 師弟的選擇
- 不是反抗，不是合謀，不是麻木
- 是**默契接受**——混沌紀普通人對此類事件的默認姿態
- 每月收補助、住一房一廳、繼續煉炁、收小徒弟——生活在繼續
- 對小徒弟說「炁從哪裡來、要去哪裡，你不用知道」——是師弟自己對這整件事的和解方式
- 繼承五話「沒有人說可怕」「最被廣泛轉發的不是任何一篇分析」的世代延續姿態

### 字條與名片並置
- 結尾「那張名片師弟留著。放在抽屜最裡面，跟師兄留下的那張字條一起。字條他到現在還是沒拆開。」
- 兩張紙：師兄遺願（可能寫了他希望怎麼被處理）+ 基金會名片（他選擇的替代方案）
- 字條沒拆 = 師弟選擇不知道真相
- 兩張並放 = 師弟自己也知道兩者衝突，但不打算解決

### 與六話的呼應
- 六話母親「擺兩副碗筷不點餐」 / 七話師弟「打結印繼續煉炁」——兩個都用日常行為延續一段已中斷的關係
- 六話窗口阿姨「是親子日啊」 / 七話廳堂主持人「是送別日啊」——戲謔命名的民間溫度
- 六話兒子神化後消失（公共場所 + 血親目擊）/ 七話師兄異化後被帶走（私人場所 + 師門處理）
- 六話反諷：Token 物理對親情盲 / 七話反諷：班底利用熵教文化信任網絡
- 兩話的主視角人物（母親、師弟）都在生命中因為一次事件永久改變，但都沒有尋找答案、沒有揭露，只是繼續——這是混沌紀普通人的共同姿態
