# NPC 對話記憶與背版 — 設計

> 對齊：決策 007 §6（背版與記憶）、討論 002（NPC 像真人）、Letta 式記憶架構（blocks ＋ archival）。本設計對齊 [對話記憶系統—彙整與探討](../reference/對話記憶系統—彙整與探討.md) 共識摘要。

---

## 目標

- **每次與 NPC 對話**，都為該 NPC 累積**記憶點**（事實、偏好、發生過的事、對玩家的印象）。
- **背版** = 該 NPC 的動態「背景」：身份 + 人設摘要 + 與玩家的關係；隨對話越長越豐富。
- **整合到遊戲 Talk**：模板或 CallAITalk 時，把「當前背版 + 精選記憶」當 context，使回覆一致、有延續性，NPC 越聊越立體。

---

## 一、概念對照（Letta → 遊戲）

| Letta 概念 | 遊戲內對應 |
|------------|------------|
| **Subject** | 一個 NPC = 一個 subject（`entity_id`）。 |
| **Memory blocks** | 該 NPC 的**背版**：identity、summary、relationship 等命名區塊；可隨對話更新。 |
| **Archival memory** | 該 NPC 的**長期記憶**：具體事件、說過的話、玩家偏好；語意檢索後塞進 prompt。 |
| **每次對話** | 1) 用背版 + 精選記憶當 context 回覆；2) 回合結束後寫入本輪精華 → 背版隨之變豐富。 |

---

## 二、資料流

```
玩家對 NPC 發起 Talk
    ↓
讀取該 NPC 的背版（blocks：身份 + 人設摘要 + 與玩家的關係摘要）
    ↓
（可選）archival 語意搜尋：用「玩家本句或話題」拉出幾條相關記憶
    ↓
組 prompt：背版 + 精選記憶 + 最近幾輪對話 + 玩家本句
    ↓
回覆（模板選句 or CallAITalk）
    ↓
本輪結束後：將「值得長期記的」寫入該 NPC 的 archival（或更新某 block）
    → 下次 Talk 時，背版／檢索結果更豐富 → 越聊越立體
```

---

## 三、背版區塊建議

| 區塊名 | 內容 | 來源／更新 |
|--------|------|------------|
| **identity** | 職業、場所、基本人設（1～3 句） | 來自 archetypes／dialogues／場所；可先固定。 |
| **summary** | 該 NPC 的當前摘要（最近關係、重要事件、個性要點） | 由系統或 LLM 定期整理；或每 N 次對話後更新。 |
| **relationship** | 與**當前玩家**有關的記憶（喜好、做過的事、承諾） | 每次與該玩家對話後可追加或更新。 |

背版總長度需控制（例如每塊數十字～百字），以便塞進小模型 context；archival 則不限條數，用檢索取 top-k。

---

## 四、長期記憶（archival）

- **儲存**：每條記憶 = 內容（文字）+ 可選 tag（如 `fact`、`preference`、`event`、`player_xxx`）+ 時間戳；依 `entity_id` 分區。
- **寫入**：Talk 回合結束後，由規則或 LLM 從本輪對話抽出 1～3 條「值得長期記的」寫入該 NPC 的 archival。
- **檢索**：Talk 前用玩家輸入或最近一句做 query，語意搜尋該 NPC 的 archival，取 top-k（如 3～5 條）併入背版或 prompt。

## 五、與現有設計的接點

| 項目 | 接法 |
|------|------|
| **007 CallAITalk** | 傳入參數增加：`npcBackstory string`、`npcMemorySnippets []string`；組 system 時帶入。 |
| **007 對話池** | 背版／記憶負責「是誰、發生過什麼」；對話池負責口吻範例；兩者一併組 prompt。 |
| **I3 Talk 模板** | 若未來依「情境 key」選句，可依背版或關係摘要決定 key（如熟識 → 多走 talk、少走 greet）。 |
| **三軸性格** | 性格影響選句與決策；記憶負責具體內容與歷史；兩者並存。 |

## 六、實作階段建議

| 階段 | 內容 | 背版效果 |
|------|------|----------|
| **1** | 每個 NPC 有**固定背版**（identity：職業 + 場所 + 1～2 句人設），Talk 時只讀不寫。 | 回覆有人設，背版尚不隨對話成長。 |
| **2** | 為每個 NPC 增加 **archival**：每次 Talk 後將本輪精華寫入；Talk 前語意搜尋拉 3～5 條當 context。 | 背版隨對話累積記憶點，越聊越立體。 |
| **3** | 增加**可更新 block**（summary／relationship）：每 N 次對話或定時，由 LLM 或規則整理 archival 寫回 blocks。 | 背版成為「會長大」的摘要，token 可控、脈絡更清晰。 |

| 依賴 | 說明 |
