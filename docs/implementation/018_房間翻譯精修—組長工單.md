## 背景

017 碼農交付的翻譯品質不合格：
- 34% 名稱含英文殘留（子音群 rkh、nch、ghs 等未處理）
- 漢族地名未還原漢字（Changjiang → `C哈ng吉安g`，應為「長江」）
- 省份 145 筆含英文
- 描述全部是流水帳模板，無場景感
- 描述塞人口數字（「約1777人定居」）——毫無意義，刪除

## 修正範圍

### 1. 名稱修正（275 筆）

目標：所有房間名稱不得殘留英文字母。

#### 漢族（82 筆）、關族（46 筆）

這些是中文羅馬拼音，應**還原為漢字地名**，不是音譯：

| 原文 | 碼農翻譯（錯） | 正確 |
|------|---------------|------|
| Changjiang | C哈ng吉安g | 長江 |
| Binzhou | 比nz霍u | 濱州 |
| Baoqing | 巴o基ng | 寶慶 |
| Fenzhou | 費nz霍u | 汾州 |
| Xiwanding | Xi瓦n迪ng | 西萬頂 |
| Chinghoi | C希ng霍i | 青海 |
| Gonglinghom | 戈ng利ng霍m | 功嶺含 |
| Chikoktong | C希科k托ng | 赤角塘 |

規則：
- 先查是否為真實中文地名（州、城、江、山、關、嶺等後綴）
- 若為 Azgaar 變體，取最接近的漢字組合
- 關族用粵語發音對應漢字

#### 其他文化（147 筆）

音譯為中文，**所有子音群必須拆解為合法中文音節**：

| 子音群 | 處理方式 | 範例 |
|--------|---------|------|
| rkh | 爾赫 | Myanzurkh → 米揚祖爾赫 |
| nch | 恩奇 | Khashinch → 哈辛恩奇 |
| ghs | 格斯 | Baghstan → 巴格斯坦 |
| ngy | 恩吉 | Taishangy → 台山恩吉 |
| dch | 德奇 | Kudch → 庫德奇 |
| gk | 格克 | Buregkher → 布雷格克赫爾 |
| ds | 德斯 | Qidssurda → 奇德斯蘇爾達 |
| fs | 夫斯 | Hafshan → 哈夫山 |

規則：
- 每個音譯結果必須全為中文字，零英文
- 音節斷點要自然（不要切在母音中間）
- 兀魯斯 → 蒙古風格用字（汗、巴、察、格、爾、圖、烏）
- 德蘭尼 → 波斯風格用字（沙、斯坦、巴格、哈、達、拉）
- 卡納提克 → 印度風格用字（達、拉、納、普、提）
- 大和 → 日式用字（川、島、宮、崎、津、濱）
- 高麗 → 韓式用字（城、陽、州、浦、川）
- 柏柏爾 → 北非風格（拉、菲、齊、瓦、達）
- 突厥安 → 突厥風格（巴、庫特、卡、塔、亞茲）

### 2. 省份修正（145 筆）

`meta.province` 欄位，規則同上。漢族/關族還原漢字，其他音譯。

### 3. 描述重寫（全部 694 筆）

#### 禁止事項
- ❌ 不准寫人口數字（「約1777人定居」「14305人聚居」）
- ❌ 不准流水帳列舉設施（「設有廣場、城牆環繞」）
- ❌ 不准把 meta 欄位直接串成句子
- ❌ 不准提及文化名和宗教名（這些是 meta，不是玩家看到的景色）

#### 描述應該是什麼
玩家進入房間時看到的**第一眼景象**。用 2-3 句話畫一個畫面。

依據 tags + biome 組合出場景，不是列清單：

| tags 組合 | 場景方向 |
|-----------|---------|
| city + citadel + walls | 高牆之內的繁華城市，城塞陰影覆蓋石板街 |
| town + port + naval | 碼頭帆檣林立，鹹風夾著魚腥味 |
| village + river | 河畔小村，水聲潺潺 |
| hamlet + 熱帶雨林 | 密林中的幾戶人家，蟲鳴不絕 |
| town + temple | 廟宇鐘聲迴盪的城鎮 |
| town + plaza + walls | 城牆圍繞的市集廣場，人聲嘈雜 |
| village + lake | 湖邊漁村，薄霧籠罩水面 |

#### 範例

**好的描述：**
```
厚重的城牆將風沙擋在外頭，牆內是密密麻麻的屋舍與蜿蜒的窄巷。城塞的塔樓從最高處俯瞰一切，廣場上商販的叫賣聲此起彼落。
```
```
碼頭邊的木棧道被海水浸得發黑，幾艘漁船隨浪搖晃。鹹濕的風穿過掛滿漁網的巷弄，遠處燈塔的光在霧中若隱若現。
```
```
密林裡的小聚落，幾間木屋沿著泥路散落。雨林的樹冠遮蔽了大半天空，空氣濕熱得像蒸籠，蟲鳴從四面八方湧來。
```

**壞的描述（017 的產出）：**
```
阿波，溫帶雨林地帶的大和城鎮，14305人聚居，駐有水師、港口船帆林立、城塞高踞、設有廣場、城牆環繞。居民多信奉彥道。
```
↑ 這是資料表，不是描述。

#### 地標房間（71 筆）

地標有自己的氛圍，不要跟城鎮描述撞風格：

| marker_type | 方向 |
|-------------|------|
| battlefields | 荒涼、殘兵斷甲、野草覆蓋 |
| bridges | 結構描述（石橋/木橋/吊橋）、跨越什麼 |
| brigands | 陰暗、警戒感、路邊可疑痕跡 |
| ruins | 斷壁殘垣、被遺忘的時光 |
| caves | 黑暗、迴音、潮濕 |
| lakes | 水面、岸邊、光線 |

### 4. 出口方向（連動修正）

出口 `direction` 格式為「官道往X」或「小徑往X」，其中 X 是目標房間的 name。
名稱修正後，出口方向必須連動更新。

方法：讀取目標房間（`exit.to`）的 `name` 欄位，重組 direction。

### 5. 驗收標準

```bash
# 零英文殘留檢查（name、province、description、exit direction）
python3 -c "
import json, glob, re
bad = 0
for f in glob.glob('data/rooms/editor/world_*.json'):
    with open(f) as fp:
        r = json.load(fp)
    for field in [r.get('name',''), r.get('description',''), r.get('meta',{}).get('province','')]:
        if re.search(r'[a-zA-Z]{2,}', field):
            bad += 1; break
    for ex in r.get('exits',[]):
        if re.search(r'[a-zA-Z]{2,}', ex.get('direction','')):
            bad += 1; break
print(f'failed: {bad} (must be 0)')
"
```
