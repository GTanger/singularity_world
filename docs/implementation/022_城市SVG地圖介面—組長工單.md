# 022 SVG 地圖介面 — 組長工單

## 目標

兩層地圖都用 SVG 呈現，取代純文字導航：

1. **區域大地圖**（Azgaar 匯出）— 玩家主要導航層，點城市圖標進城
2. **城市地圖**（Watabou 匯出）— 進城後顯示，點 district/建築互動

## 架構

```
第一層：區域大地圖
  Azgaar 匯出 SVG（~39MB 原始，gzip ~4MB）
           ↓
    web/maps/world.svg — pan/zoom，點城市圖標 → 進城或顯示資訊
           ↓
    點城市 → 切換到第二層

第二層：城市地圖
  Watabou 匯出 SVG（~39MB 原始，gzip ~4MB）
           ↓
    web/cities/32.svg — pan/zoom，點 district/建築
           ↓
    點可進入建築 → 切換到文字 MUD 房間
```

## 前置：匯出 SVG

### 區域大地圖（Azgaar）
- **已有**：`docs/map/world/lakes_of_secrets.svg`（38MB）
- 複製或 symlink 到 `web/maps/world.svg`
- 不需要重新匯出

### 城市地圖（Watabou）
1. 開 Watabou MFCG（https://watabou.github.io/city-generator/）
2. 載入宜林 seed（從 `data/cities/32.json` 的 seed 重建）
3. 匯出 → SVG → 存為 `web/cities/32.svg`
4. 預期 30-50MB 原始

### gzip 壓縮（兩張都做）
```bash
gzip -k -9 web/maps/world.svg      # 38MB → 預期 ~4MB gz
gzip -k -9 web/cities/32.svg       # → 32.svg.gz
# tower-http ServeDir 的 precompressed_gzip() 會自動使用 .gz
```

## 實作

### 0. 共用 SVG Pan/Zoom 模組（`web/svg-viewer.js`）

pan/zoom 邏輯世界地圖和城市地圖共用，抽成一個 JS 檔：

```javascript
// svg-viewer.js — 通用 SVG pan/zoom
// 初始化：SvgViewer.init(objectElement, { onClick: callback })
//
// 功能：
// - 滑鼠拖曳平移（修改 SVG viewBox）
// - 滾輪縮放（游標位置不動）
// - 觸控：單指拖曳、雙指縮放
// - 初始 viewBox 自動置中
// - 點擊元素回傳被點擊的 SVG element
```

### 1. 區域大地圖（`web/world_map.html`——覆寫現有的）

```html
<div id="map-container">
  <object id="world-svg" type="image/svg+xml" data="/maps/world.svg"></object>
</div>
<div id="sidebar">
  <h2 id="loc-name"></h2>
  <p id="loc-desc"></p>
  <button id="btn-enter" style="display:none">進城</button>
</div>
```

**Azgaar SVG 結構**（已有 `web/world_map.svg` 可參考）：
- 城市圖標在 `<g>` 群組裡，帶有 `id` 或座標可對應 burg_id
- 現有簡化版 SVG（1MB）有 `id="feature_*"` 等標記

**點擊城市圖標**：
- 找到被點擊元素 → 對應到 burg_id → 側欄顯示城市資訊
- 「進城」按鈕 → 載入城市 SVG 地圖（或切換到文字 MUD 入口房間）

**城市對照表**（hardcode 或從 JSON 載入）：
```json
[
  {"burg_id": 32, "name": "宜林", "svg": "/cities/32.svg", "room_id": "world_lurgash_yilin"}
]
```

### 2. 城市地圖（`web/city_map.html`——覆寫現有的）

```html
<!-- 核心結構 -->
<div id="map-container">
  <object id="city-svg" type="image/svg+xml" data="/cities/32.svg"></object>
</div>
<div id="sidebar">
  <h2 id="loc-name"></h2>
  <p id="loc-desc"></p>
  <div id="loc-npcs"></div>
  <div id="loc-actions"></div>
</div>
```

**SVG pan/zoom**：用原生 JS 實作（不引入新依賴）：
- 滑鼠拖曳平移（修改 SVG viewBox）
- 滾輪縮放（調整 viewBox 寬高，游標位置不動）
- 觸控：單指拖曳、雙指縮放
- 初始 viewBox 置中顯示整座城

**點擊互動**：SVG 載入後，對 `<object>` 內部 DOM 掛事件：
```javascript
var svgDoc = document.getElementById('city-svg').contentDocument;
// Watabou SVG 的 district 區塊通常在 <g> 群組裡
// 建築是 <rect> 或 <polygon>
// 需要根據實際 SVG 結構調整選擇器
svgDoc.querySelectorAll('[data-district]').forEach(function(el) {
  el.style.cursor = 'pointer';
  el.addEventListener('click', function(e) {
    showDistrict(el.dataset.district);
  });
});
```

### 2. SVG 預處理腳本（`tools/prepare_city_svg.py`）

Watabou 原始 SVG 不帶語意標記，需要後處理：

1. 解析 SVG DOM（用 `xml.etree.ElementTree`，Python 標準庫）
2. 對照 GeoJSON 的 district 多邊形，找到 SVG 中對應的 `<path>` 或 `<polygon>`（座標匹配）
3. 為每個 district 元素加上 `data-district="商坊"` 屬性
4. 為可進入建築加上 `data-building="tavern_01"` + `class="enterable"`
5. 加入 CSS 樣式（hover 高亮）：
```xml
<style>
  .enterable:hover { opacity: 0.7; cursor: pointer; }
  [data-district]:hover { fill-opacity: 0.15; fill: gold; }
</style>
```
6. 輸出處理後的 SVG 到 `web/cities/32.svg`

### 3. gzip 壓縮

伺服器已有 `precompressed_gzip()`。只需要：
```bash
gzip -k -9 web/cities/32.svg
# 產出 web/cities/32.svg.gz，tower-http 的 ServeDir 會自動用
```

### 4. 側欄資料來源

點擊 district 或建築後，需要顯示：
- 區域名稱 + 描述
- 該區 NPC 列表
- 可執行動作（進入建築、與 NPC 對話）

資料從 WebSocket 取。點擊時發送：
```json
{"type": "city_click", "city_id": 32, "target": "district:商坊"}
```
後端回傳該區域資訊。（後端 handler 後續再做，先把前端做好。）

### 5. 與 MUD 介面的切換

- 世界地圖（文字 MUD）→ 走進城市入口 → 切換到 SVG 地圖介面
- SVG 地圖 → 點擊可進入建築 → 切換回文字 MUD 介面（室內房間）
- 文字 MUD 室內 → 走出建築 → 切回 SVG 地圖

切換用現有的 WebSocket 訊息控制，前端根據 `room_id` 前綴判斷：
- `world_*` → 文字 MUD
- `city_*_indoor_*` → 文字 MUD
- `city_*` → SVG 地圖

## 不要做的事

- **不要引入 npm 依賴**（無 Leaflet、無 d3、無 svg-pan-zoom lib）
- **不要動後端 Rust 代碼**
- **不要動 `src/city/` 模組**
- **不要改 WebSocket 協議**——前端先做靜態展示，互動訊息格式後續定
- **不要自己渲染 GeoJSON**——用 Watabou 原生 SVG

## 驗收標準

1. `web/city_map.html` 載入 SVG，可拖曳縮放，手機觸控正常
2. hover district 時有視覺回饋（高亮或半透明）
3. 點擊 district 側欄顯示區名（先 hardcode 測試資料）
4. SVG 經 gzip 後傳輸量 < 6MB
5. 首次載入到可互動 < 5 秒（本機測試）

## 優先級

**先完成 SVG viewer + pan/zoom**（步驟 1），這是核心。
預處理腳本（步驟 2）和側欄互動（步驟 4）可以後續迭代。

## 備註

Watabou SVG 內部結構需要實際匯出後才能確認元素選擇器。組長先匯出一份宜林 SVG，觀察 DOM 結構後再決定 `prepare_city_svg.py` 的具體邏輯。
