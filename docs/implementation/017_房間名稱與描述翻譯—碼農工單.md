# 017 房間名稱與描述翻譯 — 碼農工單

## 狀態：待執行

## 目標
將 623 個城鎮房間的 `name`（英文）翻譯為繁體中文，並為全部 694 個房間生成 `description`。
翻譯完成後，更新 exits 的 direction 中引用的城鎮名。

## 輸入
- `tools/rooms_to_translate.json` — 623 個城鎮的 id、name、culture、province、biome、population、tags
- `data/rooms/editor/world_*.json` — 694 個房間 JSON（含 71 個地標已有中文名）

## 輸出
1. `tools/name_translations.json` — 翻譯對照表（見格式）
2. `tools/apply_translations.py` — 套用腳本（僅標準庫）
3. 修改後的 694 個 `data/rooms/editor/world_*.json`

## name_translations.json 格式
```json
{
  "Changsha": {
    "name_zh": "長沙",
    "province_zh": "韶國"
  },
  "Tongzhou": {
    "name_zh": "通州",
    "province_zh": "通州"
  }
}
```
key = 英文原名（唯一），`name_zh` = 城鎮中文名，`province_zh` = 省份中文名。

## 翻譯規則

### 城鎮名（name）
- **漢族/關族文化**（culture = 漢族、關族）：多數是真實中國/粵語地名的羅馬拼音，還原為正體漢字。認不出的音譯，選字要像地名（用山水田城等意象字）。
- **大和文化**：日式地名音譯，選字參考日本漢字風格（如 Awa→阿波、Fuchu→府中）。
- **高麗文化**：韓式地名音譯（如 Gocha→高察、Hongnam→洪南）。
- **兀魯斯/突厥安文化**：蒙古/突厥風音譯（如 Tsagaan→察干、Ayazbaykut→阿亞茲拜庫特）。
- **德蘭尼文化**：波斯風音譯（如 Baghstan→巴格斯坦、Darand→達蘭德）。
- **卡納提克文化**：印度風音譯（如 Kadur→卡杜爾、Natagadati→納塔迦達提）。
- **柏柏爾文化**：北非風音譯（如 Ouramiz→烏拉米茲、Kenibgazer→凱尼布加澤爾）。
- **幼法拉底文化**：美索不達米亞風音譯（如 Der→德爾、Washak→瓦夏克）。
- **越族/毛伊/歐拉比**：對應文化風格音譯。

### 省份名（province）
與城鎮名同規則。同一 province 下的多個城鎮必須用同一譯名。

### 通用原則
- 一律繁體中文（台灣用字）
- 音譯選字避免負面含義（勿用 死、鬼、毒、糞 等）
- 同文化圈的名字風格要一致
- 長名可適度縮短（6字以內為佳）

## 房間描述（description）

根據 meta 欄位組合生成，每個房間 1-2 句，40-80 字。

### 模板邏輯
依 tags 中的規模標籤分層：

**hamlet（聚落，<1000人）**
> {name_zh}，{biome}邊緣的零星聚落。{culture}人在此落腳，{religion_flavor}。

**village（村莊，1000-5000人）**
> {name_zh}，{biome}中的{culture}村落，約{pop}人定居。{tag_flavor}。

**town（城鎮，5000-20000人）**
> {name_zh}，{biome}地帶的{culture}城鎮，{pop}人聚居。{tag_flavor}。{religion_flavor}。

**city（大城，>20000人）**
> {name_zh}是{biome}中的{culture}大城，{pop}人口稠密。{tag_flavor}。{religion_flavor}。

### tag_flavor 組合
- `capital` → 「為{zone_name}的首府」
- `port` → 「港口船帆林立」
- `citadel` → 「城塞高踞」
- `walls` → 「城牆環繞」
- `plaza` → 「設有廣場」
- `temple` → 「建有廟宇」
- `shantytown` → 「城外有棚戶區蔓延」
- `river` → 「依河而建」
- `lake` → 「臨湖而居」
- `naval` → 「駐有水師」

### religion_flavor
宗教名直接引用即可：「居民多信奉{religion}」。

### 地標房間（71 個 marker）
地標已有中文名（古戰場、溫泉、礦脈等），描述根據 marker_type 生成：
- `battlefields` → 「荒草掩蓋的古戰場，殘刃斷矛散落泥土間，據說夜間仍能聽見戰鼓聲。」
- `mines` → 「深入山腹的礦脈入口，黑暗中偶有金屬光澤閃爍。」
- `ruins` → 「傾頹的古代遺跡，石牆上刻有無人能讀的銘文。」
- `hot-springs` → 「地底熱流湧出的溫泉，蒸汽在空氣中繚繞。」
- `caves` → 「幽深的洞穴入口，涼風從黑暗中吹出，深處未知。」
- `volcanoes` → 「遠處可見的火山，山頂時有硫煙升起。」
- `sacred-forests` / `sacred-pineries` → 「古木參天的聖林，光線難以穿透樹冠，林中異常寂靜。」
- `waterfalls` → 「水流從高處傾瀉而下，轟鳴聲震耳欲聾。」
- `bridges` → 「橫跨水面的古橋，石面被歲月磨得光滑。」
- `lighthouses` → 「矗立海岸的燈塔，夜間光柱掃過海面。」
- `brigands` → 「盜賊盤踞的據點，路過此地需格外小心。」
- `dungeons` → 「陰暗的地牢入口，鐵門鏽跡斑斑，空氣中瀰漫腐朽氣味。」
- `inns` → 「路邊的旅店，提供簡陋但足以歇腳的住處。」
- `necropolises` → 「沉寂的亡者之城，墓碑在薄霧中若隱若現。」
- `water-sources` → 「清澈的水源地，溪水從岩縫間汩汩流出。」
- 其他：「{marker_name}，周遭散發著異樣的氣息。」

## exits 的 direction 更新
翻譯完成後，所有 exits 的 direction 需同步更新：
- `"小徑往Changsha"` → `"小徑往長沙"`
- `"官道往Der"` → `"官道往德爾"`
- `"海路往Awa"` → `"海路往阿波"`
- `"返回Changsha"` → `"返回長沙"`
- 地標的 `"返回{burg_name}"` 也要更新

## apply_translations.py 腳本邏輯
```
1. 讀取 name_translations.json
2. 遍歷 data/rooms/editor/world_*.json
3. 若 room.name 在翻譯表中 → 替換 name 為 name_zh
4. 若 meta.province 在翻譯表某筆的原始 province 中 → 替換
5. 遍歷 exits[].direction，用正則取出城鎮名並替換
6. 填入 description（城鎮用模板、地標用固定文案）
7. 寫回 JSON
```
