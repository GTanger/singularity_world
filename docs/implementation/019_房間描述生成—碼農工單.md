# 019 房間描述生成 — 碼農工單

## 狀態：待執行

## 背景

018 組長交付的描述是 42 個模板輪播 694 間房，等於沒寫。需要用 LLM 逐房間生成唯一描述。

## 任務

為 `data/rooms/editor/world_*.json` 中的 **694 個房間**各生成一段唯一的場景描述，寫入 `description` 欄位。

## 描述規格

### 長度
2-3 句，40-80 字。

### 內容 = 第一眼景象
玩家走進這個房間時**看到、聽到、聞到**的東西。

### 禁止事項（硬性）
- ❌ **不准寫人口數字**（「約1777人定居」「14305人聚居」）
- ❌ **不准寫文化名**（「漢族城鎮」「德蘭尼村落」）
- ❌ **不准寫宗教名**（「居民多信奉XX」）
- ❌ **不准列舉設施**（「設有廣場、城牆環繞、港口船帆林立」）
- ❌ **不准重複使用描述**。694 間房 = 694 段不同的描述。容許句式相近，但不容許整段相同
- ❌ **不准用「據說」開頭**
- ❌ **不准提及 meta 欄位名稱**（biome、culture、religion 是資料標籤，不是玩家看到的東西）

### 應該寫什麼
用 `tags` + `biome` 組合推導場景。每個組合畫一幅不同的畫面：

#### 城鎮類（tags 含 town 或 city）
```
厚重的城牆將風沙擋在外頭，牆內是層疊的屋舍與蜿蜒窄巷。塔樓從最高處俯瞰一切，廣場上商販的叫賣聲此起彼落。
```

#### 村落類（tags 含 village 或 hamlet）
```
幾間木屋沿著泥路散落，屋後菜畦整齊。晾衣繩上的布衫隨風搖擺，遠處有人在田裡彎腰。
```

#### 港口類（tags 含 port 或 naval）
```
碼頭邊的木棧道被海水浸得發黑，幾艘漁船隨浪搖晃。鹹濕的風穿過掛滿漁網的巷弄。
```

#### 地標類（marker_type 存在）
根據 marker_type 寫對應氛圍：
- battlefields → 荒涼、殘兵斷甲
- bridges → 結構、跨越
- brigands → 陰暗、警戒
- ruins → 斷壁殘垣
- caves → 黑暗、迴音
- lakes → 水面、光線

### 變化手法
即使是同類型（如 town + plaza + walls），每間房的描述也應該不同。變化手法：
- 換角度（俯瞰 vs 街道 vs 城門口）
- 換時段（晨霧 vs 午後 vs 黃昏 vs 夜晚）
- 換天氣（晴 vs 雨 vs 風 vs 霧）
- 換焦點（人 vs 建築 vs 聲音 vs 氣味）
- 換 biome 帶來的環境差異（溫帶落葉林 vs 熱帶雨林 vs 濕地 vs 北方針葉林）

## 輸入欄位

每個房間 JSON 中可用的資訊：
```json
{
  "tags": ["town", "port", "citadel", "plaza", "walls"],
  "meta": {
    "biome": "溫帶雨林",
    "population": 14305,
    "marker_type": "battlefields"  // 僅地標有此欄位
  }
}
```

**只用 tags + biome + marker_type 來推導場景。** 不要在描述中提及 culture、religion、population。

## 實作方式

### 方法：Gemini API 逐房間生成

```
對每個房間：
1. 讀取 tags、biome、marker_type
2. 組 prompt：「請為以下設定的遊戲房間寫一段場景描述（40-80字，2-3句）。
   環境：{biome}
   設施：{tags}
   要求：寫玩家第一眼看到的畫面。不要提人口、文化、宗教。不要列舉設施。用感官描寫。」
3. 將回傳的描述寫入 description 欄位
4. 確認不與已生成的其他描述完全相同
```

### 去重檢查

生成完後跑去重：
```python
from collections import Counter
descs = [r['description'] for r in all_rooms]
dupes = {d: c for d, c in Counter(descs).items() if c > 1}
assert len(dupes) == 0, f"重複描述: {len(dupes)} 組"
```

如有重複，對重複的房間重新生成（換 prompt 角度）。

## 驗收標準

1. **694 間房全有描述**，無空白
2. **零重複**：唯一描述數 = 694
3. **零英文**：描述中不含英文單詞
4. **零禁止內容**：不含人口數字、文化名（漢族/關族/大和/...）、宗教名
5. **長度合規**：每段 20-100 字

```bash
python3 -c "
import json, glob, re
from collections import Counter

descs = []
issues = []
for f in sorted(glob.glob('data/rooms/editor/world_*.json')):
    with open(f) as fp:
        r = json.load(fp)
    d = r.get('description','')
    descs.append(d)
    if not d.strip():
        issues.append(f'空描述: {r[\"id\"]}')
    if len(d) < 20 or len(d) > 100:
        issues.append(f'長度異常({len(d)}): {r[\"id\"]}')
    if re.search(r'[a-zA-Z]{3,}', d):
        issues.append(f'含英文: {r[\"id\"]}')
    # 禁止內容
    for ban in ['漢族','關族','大和','高麗','兀魯斯','德蘭尼','卡納提克','幼法拉底','柏柏爾','突厥安','毛伊','歐拉比','人定居','人聚居','人口']:
        if ban in d:
            issues.append(f'禁止詞 \"{ban}\": {r[\"id\"]}')

dupes = sum(1 for _,c in Counter(descs).items() if c > 1)
print(f'總房間: {len(descs)}')
print(f'唯一描述: {len(set(descs))}')
print(f'重複組數: {dupes}')
print(f'問題數: {len(issues)}')
for i in issues[:20]: print(f'  {i}')
print('全部通過' if not issues and dupes == 0 else '未通過')
"
```

## 注意事項

- 只改 `description` 欄位，不要動其他任何欄位
- JSON 格式保持 2-space indent、ensure_ascii=False
- `cargo build && cargo clippy -- -D warnings` 通過
