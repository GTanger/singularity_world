## 核心問題：骨架在，但不像人

代碼的因果鏈是通的（需求 → 意圖 → 移動 → 到達 → 效果），但觀測起來 NPC 依然像機器人。原因：

### 1. 每 tick 失憶
每次 `decide()` 都是全新決策，不記得上一秒在做什麼。NPC 上一秒乞討、下一秒採集、再下一秒社交。**缺乏行為連貫性。**

### 2. 無降級鏈
意圖不可行時直接 fallback 到 Wander（閒晃）。不會「求職失敗 → 降級乞討 → 邊走邊討 → 繼續找工作」。**缺乏降級邏輯。**

### 3. 只有兩層需求在真正運作
生存（鎂 < 50）和安定（有無指派）。社交只是一個 urgency 數字，尊重和實現完全未接入。**NPC 行為只有「賺錢」和「找工作」兩種驅動力。**

### 4. 經濟太單薄
物品只有 `wild_herb`。採集→賣草→吃飯→採集，循環太短、太單調。**行為多樣性出不來。**

### 5. 資源點不存在
採集意圖會觸發，但缺乏真實的資源目的地（礦區、農地、水域）。所有 NPC 跑向同類型房間標籤，造成「快閃族」現象。

### 6. Wander 缺乏表現力
Wander 是兜底行為，但目前只是「隨機移動到某個房間」。應該有敘事意義——坐在路邊發呆、抱怨天氣、無目的徘徊——這本身也是角色塑造。
