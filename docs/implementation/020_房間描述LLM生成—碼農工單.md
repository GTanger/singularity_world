## 目標

用本地 Ollama 模型**逐房間**生成 694 筆場景描述。每個房間獨立呼叫一次 LLM，禁止模板、禁止排列組合。

## 技術方案

### 腳本

`tools/generate_descriptions.py`（僅標準庫 + requests）

### 流程

```
for each world_*.json in data/rooms/editor/:
    讀取 name, biome, tags, exits, marker_type
    組裝 prompt
    POST http://localhost:11434/api/generate
    取回 response → 寫入 room["description"]
    print 進度
```

### 模型選擇

指定使用：`gemma3:12b`（8.1GB，中文場景描寫品質最穩）

呼叫方式：
```python
import requests, json

def generate_desc(prompt, model="gemma3:12b"):
    resp = requests.post("http://localhost:11434/api/generate", json={
        "model": model,
        "prompt": prompt,
        "stream": False,
        "options": {"temperature": 0.8, "num_predict": 150}
    })
    return resp.json()["response"].strip()
```

### Prompt 設計

#### 城鎮（有 burg_id）

```
你是奇幻世界的場景描寫師。用繁體中文寫一段 40-60 字的場景描述。

規則：
- 只寫站在此地能看到、聽到、聞到的
- 不提人口數字、不提文化名稱、不提宗教名稱
- 不用「據說」開頭
- 不要解釋、不要列點、只輸出描述本身

地點：{name}
地貌：{biome}
特徵：{tags_zh}
通往：{exit_names}

描述：
```

其中 `tags_zh` 轉換表：
```
port → 有港口
citadel → 建有城塞
plaza → 設有廣場
walls → 城牆環繞
temple → 有寺廟
river → 臨河
lake → 臨湖
naval → 駐有水師
capital → 為首府
coast → 臨海
```

`exit_names` = 出口目標房間名稱，用頓號連接（如「新延、納卡、川基巴」）。

### 品質門檻

每筆生成後立即檢查：
1. 長度：30-80 中文字（`len(re.findall(r'[\u4e00-\u9fff]', desc))`）
2. 禁詞：不含「人口、居民、文化、宗教、據說、作為、位於」
3. 英文：不含連續 2+ 英文字母

不通過 → 重新生成（最多重試 3 次，仍不過則標記跳過）。

### 輸出

- 直接覆寫每個 `world_*.json` 的 `description` 欄位
- 結束時印出統計：成功 / 重試 / 跳過
- 跳過的房間 ID 列表寫入 `tools/desc_gen_skipped.txt`

### 執行

```bash
# 確認模型已載入
curl -s http://localhost:11434/api/tags | python3 -c "import json,sys; [print(m['name']) for m in json.load(sys.stdin)['models']]"

# 執行
python3 tools/generate_descriptions.py

# 驗證
python3 -c "
import json, glob, re
descs = []
issues = []
banned = ['人口','居民','文化','宗教','據說','作為','位於']
for f in sorted(glob.glob('data/rooms/editor/world_*.json')):
    with open(f) as fp:
        r = json.load(fp)
    desc = r.get('description','')
    descs.append(desc)
    zh = len(re.findall(r'[\u4e00-\u9fff]', desc))
    if zh < 30: issues.append(f'短: {r[\"id\"]}')
    for b in banned:
        if b in desc: issues.append(f'禁詞{b}: {r[\"id\"]}')
    if re.search(r'[a-zA-Z]{2,}', desc): issues.append(f'英文: {r[\"id\"]}')
print(f'唯一: {len(set(descs))}/{len(descs)}')
print(f'問題: {len(issues)}')
for i in issues[:20]: print(f'  {i}')
"
```
