# 三軸推導性格 — 實作規劃

> 對齊：人物屬性彙整 §二（SoulSeed → 三軸 → 體敏氣／本源）、討論 002（決策引擎／性格影響行為）

---

## 目標

由**同一個 soul_seed** 已展開的三軸（Amplitude, Frequency, Phase）**不再抽新 RNG**，推導出一組「性格」數值，供 NPC 決策權重、對話語氣、求職偏好使用。與星盤／體敏氣／本源同源，不新增儲存。

---

## 一、資料與 API

### 1.1 性格結構體

在 `db/entity.go`（或新檔 `db/personality.go`）定義：

```go
// Personality 由三軸推導的性格維度，皆 [0,1]。供決策／對話權重使用。
type Personality struct {
    Boldness    float64 // 強勢度／敢衝 ← Amplitude
    Sensitivity float64 // 敏感度／反應 ← Frequency
    Orderliness float64 // 秩序感／守規 ← Phase
}
```

語義與區間對照：

| 軸 | 原始區間 | 性格維度 | 低 (0~0.33) | 中 (0.33~0.66) | 高 (0.66~1) |
|----|-----------|----------|--------------|-----------------|--------------|
| Amplitude | [0.1, 3.0] | Boldness | 保守、忍讓、少議價 | 一般 | 敢衝、愛議價、易換工作 |
| Frequency | [0.5, 2.0] | Sensitivity | 遲鈍、穩定、少反應 | 一般 | 易被情境影響、反應明顯 |
| Phase | [-1.0, 1.0] | Orderliness | 隨性、偏自由業／行腳 | 一般 | 守規、偏固定場所／留任 |

### 1.2 數值區間與閾值（實作用）

以下閾值供分支與權重使用，可改為常數或設定檔：

| 區段 | 範圍 | 用途 |
|------|------|------|
| **低** | [0, 0.33) | 觸發「保守／冷淡／隨性」類行為或權重 |
| **中** | [0.33, 0.66] | 不額外加成，或中性權重 |
| **高** | (0.66, 1] | 觸發「強勢／熱絡／守規」類行為或權重 |

必要時可再細分為「極低／低／中／高／極高」五檔（例如 0~0.2, 0.2~0.4, 0.4~0.6, 0.6~0.8, 0.8~1）。

### 1.3 展開函式

- **`ExpandSoulSeedToPersonality(seed int64) Personality`**：與現有 BaseStats、OriginSentence **同一 RNG 序**，前 3 次 Float64() → amp, freq, phase → 正規化到 [0,1] 回傳。
- **不寫入 DB**：需要時由 `soul_seed` 即時計算；本專案已改 JSON/store，無 DB 表。

## 二、各維度具體行為對照表

以下為**實作時依維度與區段可接的具體效果**；Phase 1 僅實作資料與 API，Phase 2／3 依此表接決策與對話。

### 2.1 Boldness（強勢度）

| 使用處 | 低 (0~0.33) | 中 | 高 (0.66~1) |
|--------|-------------|-----|-------------|
| **Talk 選句** | 偏句池**前半**（較溫和、被動）；固定池見 handler 現有 8 句，前半＝0~3 | 隨機或無偏移 | 偏句池**後半**（較強勢、主動）；後半＝4~7；現有實作 `shift = int(Boldness * 4)` |
| **dialogues 抽句** | 同一 key 內 lines 依 **index 分區**：前半＝溫和、後半＝強勢；權重使選 index 偏向前半 | 均勻權重 | 權重使選 index 偏向後半 |
| **議價／Trade** | 讓步快、接受開價機率高 | 一般 | 堅持開價、議價輪數多、拒絕機率高 |
| **求職／離職** | 少主動離職、偏好穩定報酬 | 一般 | 易考慮離職、偏好高報酬／高風險場所（若場所標記 risk 或報酬階） |

### 2.2 Sensitivity（敏感度）

| 使用處 | 低 (0~0.33) | 中 | 高 (0.66~1) |
|--------|-------------|-----|-------------|
| **Talk 選句** | 偏「冷淡／簡短」句；可實作為同一 key 內**較短句**或**後半較熱絡**時權重降低 | 均勻 | 偏「熱絡／多反應」句；權重提高較長或較有情緒的 line |
| **進房反應** | 較低機率觸發 enter_reaction，或只選較短句 | 一般 | 較高機率觸發、選較有反應的句 |
| **閒置動作** | 較少依「時段／房間人數」切換；idle 種類少 | 一般 | 較多依時段（morning/noon/evening/night）與情境選不同 idle |
| **決策** | 較少因「最近被攻擊／被拒絕」等事件改變行為 | 一般 | 可選：近期事件權重提高（若實作 npc_memory 或事件快取） |

### 2.3 Orderliness（秩序感）

| 使用處 | 低 (0~0.33) | 中 | 高 (0.66~1) |
|--------|-------------|-----|-------------|
| **Talk 選句** | 偏「隨性／口語／短句」；若 lines 有 tag 或 index 分區可對應 | 均勻 | 偏「正式／完整句」 |
| **求職偏好** | 偏好**無固定場所**：行腳商、乞討、賣藝、打零工（討論 002）；留任權重低 | 一般 | 偏好**固定場所**（有 assignment、排班）；留任權重高 |
| **離職意圖** | 較易因「無聊／想換環境」離職（若實作） | 一般 | 較不易離職；留任權重係數 > 1（如 1 + 0.3*(Orderliness-0.5)） |
| **巡邏／移動** | 較常觸發 wander、路徑較不固定 | 一般 | 較常依排班、較少隨機 wander |

## 三、對話（Talk）權重細則

與 I3（Talk 串接 dialogues）、決策 007（AI 提示詞＋fallback）對接時，可依下列方式使用 Personality。

### 3.1 固定句池（現有 8 句）

- **Boldness**：`shift = int(Boldness * (len(responses)/2))`，`idx = (baseIdx + shift) % len(responses)`；高 Boldness → 偏後半（強勢句）。**已實作**（handler buildTalkNarrative）。
- Sensitivity／Orderliness 目前未用；若要加，可改為**加權抽樣**：每句一權重 `w[i] = 1 + k_b*(Boldness-0.5) + k_s*(Sensitivity-0.5) + k_o*(Orderliness-0.5)`，再依權重隨機選（k_b/k_s/k_o 可先取 0.5~1.0 調參）。

### 3.2 dialogues/*.json 抽句（I3 實作時）

- **依 key 抽句**：greet / talk / idle 等依情境選 key；同一 key 內 `lines` 為陣列。
- **Boldness**：將 `lines` 視為「前半＝溫和、後半＝強勢」；選 index 時用加權隨機，權重例如 `w[i] = 1 + (Boldness - 0.5) * (i - mid) / mid`（mid = len/2），使高 Boldness 偏大 index。
- **Sensitivity**：高 Sensitivity 可提高「較長句」或「情緒較多句」的權重（若無 tag，可用 `len(line)` 或預先對每句標 `weight_tier`）。
- **Orderliness**：若未來在 JSON 為每句加選填 `"tone": "formal"|"casual"`，高 Orderliness 偏選 formal；否則可依 index 分區（前半 casual、後半 formal）。

### 3.3 與 AI 提示詞併用（007）

- 送給模型的 system 或 few-shot 例句，可從**同一 dialogue 池**依該 NPC 的 Personality **加權抽 4～6 句**，讓 AI 回覆口吻一致；fallback 時再從同一池用同一套權重抽一句。

## 四、決策引擎使用細則（Phase 2）

討論 002 之求職／留任／離職、場所類型偏好，可依下表接 Personality。

### 4.1 留任權重（是否考慮離職）

- **Orderliness**：留任權重 `stay_weight *= (1 + k_stay * (Orderliness - 0.5))`，k_stay 建議 0.3~0.6；高 Orderliness → 更傾向留任。
- **Boldness**：離職意圖權重 `leave_weight *= (1 + k_leave * (Boldness - 0.5))`，k_leave 建議 0.2~0.5；高 Boldness → 較易考慮離職（若另有「更好機會」或「不滿」觸發）。

### 4.2 求職類型偏好（場所／職業）

- **Orderliness 高**：偏好「有固定場所、排班、assignment」的職缺；篩選時此類場所權重 * (1 + 0.3*(Orderliness - 0.5))。
- **Orderliness 低**：偏好「無固定場所」：行腳商、乞討、賣藝、打零工；此類選項權重提高。
- **Boldness 高**：若場所或職業有「高報酬／高風險」標記，權重提高；反之偏好穩定則權重降低。

### 4.3 閾值常數建議（可抽成 config）

| 常數 | 建議值 | 說明 |
|------|--------|------|
| k_stay | 0.4 | Orderliness 對留任權重係數 |
| k_leave | 0.3 | Boldness 對離職意圖係數 |
| k_orderliness_prefer_fixed_venue | 0.3 | Orderliness 對「固定場所」偏好係數 |
| k_boldness_risk | 0.25 | Boldness 對「高風險高報酬」偏好係數 |
