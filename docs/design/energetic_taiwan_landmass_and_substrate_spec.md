## 第一章：能元台灣全島尺度與統一座標定位契約（正式定案）

### 1.1 全島統一膨脹倍率：`k = 2`（線性 2 倍、面積 4 倍）
1. **物理背景**：吃了能量的星球，地殼、山脈、河谷與地下水脈整體受烙印富態膨脹。為根除不同區塊倍率不一導致正交方格網幾何撕裂（Metric Tearing），**全島嚴格鎖死單一整數線性膨脹倍率 `k = 2`**（開服存檔後永不變更）。
2. **全島宏觀尺寸**：
   - 現實台灣基準：南北長約 `394 km`、東西最寬約 `144 km`、陸地面積約 `36,000 km²`。
   - **能元台灣（`k = 2`）尺寸**：南北長約 **`788 km`（約 `39,400` 格）**、東西最寬約 **`288 km`（約 `14,400` 格）**、陸地總面積約 **`14.4 萬 km²`**（相當於舊台灣的 4 倍大、約英格蘭＋威爾斯規模）。
   - **人口密度對齊**：全島數萬名現代人後裔（約 `4 萬 ～ 6 萬人`）散佈於各流域安全台面與盆地；首塊「北大甲溪～南烏溪」陸塊佔全島面積約 **`0.7%`**（原 `251 km²` $\xrightarrow{k=2}$ 約 **`1,004 km²`**），對應 **`300 ～ 400 名`** 常住居民，比例完全自洽。
3. **為何鎖定整數 `k = 2`**：
   - **對齊官方 `20m` 開放地形圖零取樣鋸齒**：內政部地政司公開之《全臺灣 20 公尺網格數值地形模型（DTM）》原生間距即為 `20m`；採整數 `k = 2` 時，原始 1 點平滑展開為遊戲內 **`2 × 2 = 4` 個 `20m` 正交格**，徹底消除非整數倍率（如 `1.5×`）的四捨五入半格鋸齒。
   - **窄溪不斷流**：原本 `30～50m` 寬之淺溪與台地山澗，於 `k = 2` 下自然展寬為 **`60～100m`（`3～5` 格寬）**，配合四向加厚柵格化，確保水系在正交四連通方格網上穩固連通不漏縫。

### 1.2 全島唯一背後座標定位系（TWD97 平面公尺網格直映）
1. **單一絕對整數格座標 `(gx, gy)`**：
   - 全島永遠共用同一組整數直角座標 `(gx, gy)`（`+X` 向東、`+Y` 向北，固定 **`1 格 = 20m × 20m`**），**嚴禁各陸塊各自將局部中心重設為 `(0, 0)`**。
2. **全島原點 `(0, 0)` 錨定點**：
   - 釘死於首塊開放陸塊之**西麓斷層湧泉中心**（幕後對位台灣大肚台地西麓沙鹿竹林／番婆井清水斷層坡腳折線，TWD97 二度分帶平面座標約 `E₀ = 205,600m, N₀ = 2,681,000m`，海拔基準約 `+65m`）。
3. **全域座標定位公式**：
   現實底圖上任意地點之平面公尺座標 `(E, N)`，映射至《奇點世界》之唯一格座標為：
   $$gx = \text{round}\!\left(\frac{(E - E_0) \times 2}{20}\right) = \text{round}\!\left(\frac{E - E_0}{10}\right), \qquad gy = \text{round}\!\left(\frac{(N - N_0) \times 2}{20}\right) = \text{round}\!\left(\frac{N - N_0}{10}\right)$$
   *(註：幕後以真實台灣地形與水系作精準物理推演底圖；面向玩家之遊戲內文本與地名嚴守世界內生語境，不直接印出「台灣」等現實行政專名。)*

## 第二章：零拼接破口架構與「不等大自然陸塊」切割規範（正式定案）

### 2.1 根治拼接破口：「全島母圖一次算完鎖死，陸塊僅作開放遮罩」
為徹底杜絕「先單獨生成第一塊地形、日後再生成第二塊拼接」必然引發的交界人工斷崖、斷頭河、無主黑洞格與鋸齒空氣牆，確立四道工程鐵律：
1. **全島高程與水系母圖先行凍結**：以全台灣 `20m` DTM 高程與全島連續主支流河網一次建構全島連續底板母圖——大甲溪、烏溪、筏子溪自高山源頭經盆地至出海口，從第 0 秒起即屬同一張連續母圖，交界高程與水脈 100% 天然連貫，**絕不分塊獨立寫死地形函數**。
2. **全域唯一格歸屬（`Cell -> LandmassId`）與河道四連通加厚**：全島每一格 `(gx, gy)` 皆分配唯一 `LandmassId`（零重疊格、零漏格）；所有界河執行**四連通加厚補格**（斜向相接處自動補齊正交水格），杜絕斜線柵格化漏縫。
3. **不等大自然山河切割**：廢除等大棋盤切塊，完全順應**大溪主河道、斷層坡腳線、山脈分水嶺脊線**劃分大小不等之自然地理陸塊（大平原切大片、獨立台地切小片，全島約 `16～20` 片自然陸塊）。
4. **世界內物理邊界取代系統空氣牆**：尚未開放之鄰接陸塊，其對岸地形仍由全島母圖真實呈現於遠眺視野中；在交界淺溪（如東界筏子溪）處，以**「舊世跨溪橋樑斷毀 ＋ 富態水氣下河床暴漲湍急 ＋ 對岸高能濃霧獸威」**形成合理物理阻隔；待鄰塊施工完畢，僅需架通橋樑或開啟渡口即可無縫通行，無須改動任何一格地形。

## 第三章：物理底板（`L0 Bare Substrate`）6-Byte 物理針腳與母圖儲存契約（正式定案）

核心判準：**嚴格區分天生焊死在大地基盤上的「底板物理針腳」與插在槽位裡可拔插替換的「插件」**。拔光地上萬物後依然存在的純自然大地，每格鎖死為 **`6 Bytes` 小端序（Little-Endian）零補位結構**，資料庫零手寫死地名與描述。

### 3.1 `L0Cell` 記憶體與檔案二進位佈局（`6 Bytes / 格`）
為防止 `u8` 在前引發 `u16` 對齊補位膨脹為 `8 Bytes`，強制將 `u16` 置首並由編譯期斷言 `size_of::<L0Cell>() == 6`：

| 順序 | 欄位名稱 | 型別 | 位元組 | 物理定義與邊界規範 |
| :---: | :--- | :---: | :---: | :--- |
| **1** | `elev_raw` | `u16` | `0..2` | **偏移海拔高程（`0.1m` 精度）**：<br>• 公式：`elev_raw = round((h_m + 500.0) * 10.0)`，有效範圍 **`-500.0 m ～ +6,053.4 m`**（完整涵蓋台灣海峽深槽、西濱退潮負高程泥灘 `-2.5m` 至玉山主峰 `+3,952.4m`）；保留 **`0xFFFF (65535)`** 代表無資料（`NODATA`）。<br>• **垂直維持真實海拔（不隨水平 `k = 2` 倍增）**；將 `20m` DTM 1 點展為 `2×2` 格時強制採用**雙線性內插（Bilinear Interpolation）**，消除緩坡平原每兩格跳一階的假台階。<br>• 坡度、坡向與地形凹凸一律由上下左右四鄰格高程差即時推算，不另存檔。 |
| **2** | `landmass_id` | `u8` | `2` | **自然陸塊戶籍號**：`0 = 外海`、`1 = 北大甲溪—南烏溪塊`、`2 = 內陸構造盆地塊`、`3 = 北台地與扇原塊`、`4 = 南長台地與平原塊`……（全島每格唯一歸屬）。 |
| **3** | `substrate_material` | `u8` | `3` | **天然母岩土層（`0..=5`，`255 = 未知`）**：<br>`0 = 潮間淤泥灘` ｜ `1 = 海濱風積砂` ｜ `2 = 平原沖積砂壤（肥沃易耕，淺基承重限 2F）` ｜ `3 = 台地紅土礫石層（透水乾旱，地盤堅實，淺基承重達 3F）` ｜ `4 = 河床石英卵石層` ｜ `5 = 斷層裸岩陡壁`。<br>• **鐵律**：前代人類遺留物（如筏子溪舊世斷橋墩、舊糖鐵台車路基）嚴禁寫入底板土質，一律作為預插於 `U1/U2` 的插件，確保可用同一套規則修復或拆解。 |
| **4** | `water_regime` | `u8` | `4` | **水脈狀態（高 4 位「常態地表水態」＋ 低 4 位「非線性地下水深桶」）**：<br>• **高 4 位（常態地表水態）**：`0 = 無地表水`、`1 = 季節乾溝（雨季由 Field 啟流）`、`2 = 常流山澗（可涉水汲水）`、`3 = 斷層湧泉眼`、`4 = 湍急深溪（無橋船不可徒步渡）`、`5 = 潮間淺海`、`6 = 外海`、`15 = 無資料`。潮汐漲退與暴雨洪峰一律由上層 `Field` 動態覆寫，不改寫靜態底板。<br>• **低 4 位（地下水深桶 `0..=15`）**：依序對應上界 `[0m, 0.3m, 0.5m, 1.0m, 1.5m, 2.0m, 3.0m, 4.0m, 6.0m, 8.0m, 12m, 15m, 20m, 30m, 40m, >40m]`，同時兼顧坡腳湧泉淺水與紅土台地深水。 |

## 第四章：單格立體槽位分割、稀疏覆寫持久化與亭仔腳 `grid_z` 空間契約（正式定案）

### 4.1 底板原生垂直四層槽 ＋ `Field` 場域調變層（嚴格宿主依賴 DAG）
1. **`U2` 深層地基槽（地下 `-1.5m ～ -8m`，1 槽）**：
   - 僅深樁結構使用。若樁深觸及底板淺地下水脈桶（桶碼 `≤ 9`，即水深 `≤ 8m`）且處於活人高頻意識盲區 $\to$ 判定水脈能量與深根頂推歪斜失穩，無須特例即自然淘汰水泥摩天樓。
2. **`U1` 淺層根基槽（地下 `0m ～ -1.5m`，1 互斥主槽；深水格無此槽）**：
   - **互斥擇一**：自然根系（`盤錯莿竹鞭`、`百年樟樹根`、`菅芒宿根`）或開墾根基（`翻耕熟地農壟`、`夯實石板路基`、`淺寬筏式基座`、`舊世斷橋墩`）。
   - **露根投影與連動清槽**：僅當 `U1 = 莿竹鞭` 且 `V1 = 空` 且 `S0 鋪面 ≠ 石板街面` 時，主畫面投影出 `[露土老竹鞭]` 插座（欲掘鞭必先劈除地上竹叢）；掘除竹鞭時自動彈出 `S0` 之活體共生項（`破土莿竹筍`、`竹根木耳`），已落地之乾竹葉、竹籜與營火則保留至翻壟或鋪路時清場。
   - **拉式（Pull）竹潮擴散**：`[劈竹開路]` 僅移除 `V1` 竹叢，`U1` 竹鞭仍在，連續 3 日（雨霧天 2 日）踩踏熱度低於閾值即由 `U1` 重新頂出竹叢；空 `U1` 格於自身觸發 Lazy Roll 時檢查四鄰是否有竹鞭以決定蔓延，不背景寫入未載入鄰格；街屋與農田因 `U1` 已被筏基／農壟佔用，竹潮自然停於街緣外。
3. **`S0` 地表覆面槽（地面 `0m`：1 鋪面槽 ＋ 3 伴生物件槽）**：
   - **鋪面槽（1 槽）**：裸土 ｜ `疏竹踩踏徑（記強型別 pave_heat，220ms/步；僅活人實際踏入刷新，純 Look 觀察不刷新）` ｜ `石板街面（220ms/步）` ｜ `窄軌台車道`。
   - **伴生物件槽（3 槽）**：統一承載竹林採集物（乾竹葉、枯黃竹籜、破土莿竹筍、竹根木耳）、熟地農作三畦（番薯藤畦、耐陰葉菜畦、引水田溝）、街面設施與早夜市攤車，以及 **`竹葉營火`**（正式佔用 1 個 `S0` 伴生槽，槽滿時消耗乾竹葉騰位；建築與石板街禁生野火）。
4. **`V1` 立面主構／林冠槽（地上 `0m ～ +4m`，1 互斥主構槽）**：
   - 插自然林冠（`合抱莿竹叢`、`老樟樹冠`）或建築主構（`綠覆騎樓街屋主體`，需 `U1 = 淺寬筏基` 或合規基礎）。
   - **通用遮雨契約**：營火雨滅條件統一為 `wetting && !v1.provides_rain_cover()`（濃密竹冠與騎樓頂皆提供遮雨護火）；格名、九宮格符號、環境首句與步頻 **100% 由 `L0 + U1 + S0 + V1 + Field` 當下在位插件動態合成**。
5. **`Field` 場域調變層**：
