# 05 角色、工具與成長

## 角色狀態

玩家角色最少需要下列狀態：

| 狀態 | 目的 |
|---|---|
| 姓名 | 自身入口與被世界記住 |
| 位置 | 玩家在世界中的坐標與場所 |
| 鎂 | 可視化經濟錨點 |
| 背包/持物 | 玩家能做什麼的基礎 |
| 工具 | 動作來源與成長路徑 |
| 元素關係 | 角色當下能否利用、避開或處理元素局勢 |
| 傷勢/異常 | 風險後果 |
| 已知人物 | 人際與記憶 |
| 已知地點/路線 | 探索成果 |
| 近期事件 | 世界承認玩家做過什麼 |
| 離線安排 | 世界永遠在線的玩家接口 |

## 工具定位

工具不是數值裝備。工具是玩家能做某些動作的原因。

工具影響：

- 可用動作。
- 成功率或品質。
- 速度或時間成本。
- 風險。
- 元素局勢下的可用/封鎖動詞。
- NPC 評價。
- 可承接工作。
- 場所改造能力。

## 工具類型

第一階段可從少量工具類型開始：

| 類型 | 可支撐玩法 |
|---|---|
| 手工具 | 修補、拆解、整理、簡單建造 |
| 繩/帶/搬運工具 | 搬運、固定、救援、通行 |
| 照明/標記工具 | 探索、夜間路況、危險前兆 |
| 防護工具 | 避險、衝突、危險路線 |
| 記錄/掛牌物 | 經營、委託、交易、名聲 |

## 角色與元素

元素不是角色面板上的屬性條。元素關係只在改變角色可做之事時進入角色設計。

角色與元素的關係來自：

- 手上拿什麼。
- 背包裡有什麼可用工具。
- 曾處理過哪類風險。
- 是否熟悉某條路、某種貨或某個場所。
- 哪些 NPC 因玩家過去處理方式而信任、請託、阻止或求償。
- 角色此刻站在哪個位置，是否能靠近、等待、避開或利用局勢。

合格呈現：

```text
手持：火折。
可用：點燈、示警、烘乾少量物件。
限制：雨中外露會更快耗損；有人守著的倉邊不可隨意點火。
```

不合格呈現：

```text
火元素：17。
水元素：9。
```

## 熟練設計

熟練不是抽象等級條。熟練應改變玩家能讀到或能做到的事情。

熟練回饋：

- 看出物件狀態細節。
- 看出元素局勢如何影響工具、路況、貨物或 NPC 行動。
- 失敗原因更具體。
- 修補結果更穩定。
- 可接更高要求的委託。
- NPC 報價或態度改善。
- 開啟第二層動作。
- 同工具消耗更少或風險更低。

## 成長來源

角色成長來自世界承認：

- 做過某事。
- 某人記得。
- 某物被修好。
- 某路被走熟。
- 某工具被反覆使用。
- 某交易關係穩定。
- 某危險被處理過。
- 某類元素局勢被反覆正確處理，並被 NPC 或場所承認。

不靠職業鎖定，也不靠通用照顧條推動玩家。

## 自身面板設計

自身面板不應是全資料表。它要回答：

- 我現在能做哪些事。
- 我缺什麼。
- 誰認得我。
- 我離線後發生什麼。
- 我接下來可以往哪條路走。
