# 15 元素、奇幻規則與遊戲觀

狀態：細節設計草案，未經使用者拍板前不得視為定案
第一權威：`../../DESIGN_KEYWORDS.md`
上層世界檔：`../world/world-foundation-v0.md`

## 定位

元素不是自然物理現象說明，也不是戰鬥傷害屬性表。

元素在奇點裡的遊戲觀是：讓奇幻世界中的物件、地貌、天候、材料、人物位置與工具，變成玩家可讀、可點、可利用、可避開、可交易、可修補、可承受後果的狀態規則。

因此問「雷怎麼來」時，設計檔不能只回答雲、冰水、電荷。那是支撐資料，不是遊戲設計。遊戲設計要先回答：

- 玩家怎麼知道此地進入雷暴風險。
- 哪些物件、路、工具、人物因此變危險或有用。
- 玩家能做什麼：等、退、收工具、避開高處、找棚、改路、救人、利用焦痕或停渡造成的機會。
- NPC 是否也照同規則行動。
- 雷過後留下什麼可回訪的世界事實。

本章回答元素如何改變世界狀態；元素如何接到玩家角色身份、持物、工具、熟練、關係與世界承認，見 [17-roleplay-elements.md](17-roleplay-elements.md)。

## 元素要提供的玩法

元素至少要承擔七種玩家層功能。

| 功能 | 設計意思 | 玩家層表現 |
|---|---|---|
| 可讀局勢 | 元素讓場景不是散文，而是可判斷狀態 | 霧重、泥深、風亂、渡船停、貨物返潮 |
| 行動動詞 | 元素讓物件產生可用動作 | 點火、熄火、烘乾、沖洗、遮風、避雷、清泥、排水 |
| 行動限制 | 元素讓某些事暫時不能做或代價提高 | 船停、路滑、弓受潮、貨不能久放、金屬工具不宜外露 |
| 準備與工具 | 元素讓工具、材料、熟練度有意義 | 火把、蓑布、乾棚、繩、木盾、金屬器、藥粉、排水溝 |
| 經濟與物流 | 元素讓貨物不是靜態物品 | 濕貨降價、乾貨搶手、腐貨拒收、焦木可作證或燃料 |
| 衝突與戰鬥 | 元素改變開戰前判斷，而不只改傷害數字 | 煙遮視線、泥地難退、潮濕使火弱、雷暴逼停高地通行 |
| 痕跡與回訪 | 元素讓世界自走留下證據 | 焦痕、退水線、泥腳印、乾裂木板、被煙熏黑的牆 |

如果一個元素只增加一段漂亮描述，而不改變上述任何一項，它不是合格的奇點元素設計。

## 元素設計合約

每個元素、派生狀態或元素性物件，都必須能填完下列合約。

```text
名稱：
玩家可讀線索：
它改變的場景狀態：
它改變的物件狀態：
它提供或封鎖的動作：
需要的工具/材料/關係/時間條件：
玩家自身/持物/熟練如何改變選項：
玩家成功後的世界差異：
玩家失敗或不處理的世界差異：
NPC 是否也會使用/避開/處理：
下次回訪可見痕跡：
```

這份合約比元素來源表更重要。來源表回答「它從哪來」；合約回答「玩家玩什麼」。

## 基礎元素的遊戲用途

### 火

火的重點不是「火屬性傷害」，而是熱、乾燥、光、燃燒、煙與失控風險。

| 玩家可讀 | 可做 | 世界差異 |
|---|---|---|
| 火盆、火把、燙鐵、焦味、乾裂、煙 | 點、滅、烘、照、驅、燒、熏 | 物件變乾/焦/壞，霧或黑暗被壓住，煙可能引人注意 |

火應該讓玩家判斷：現在要借光、烘貨、嚇退、製造煙，還是先防火勢失控。

### 水

水的重點不是「水屬性傷害」，而是濕、流動、清洗、保存、腐壞、浮沉與路線阻斷。

| 玩家可讀 | 可做 | 世界差異 |
|---|---|---|
| 河水、雨、潮線、濕布、積水、返潮貨 | 洗、泡、渡、排、接、遮、等退水 | 物件變濕/腐/冷，路變慢或封，貨價和保存期限改變 |

水應該讓玩家判斷：現在能不能走、能不能存、貨要不要先處理、船或路會不會被改變。

### 風

風的重點不是抽象速度，而是流向、聲音、氣味、煙霧、霧、箭矢/投物與消息傳播。

| 玩家可讀 | 可做 | 世界差異 |
|---|---|---|
| 風向、風口、旗布、煙走向、遠聲、草倒 | 避風、順風、放煙、聽、追味、等風停 | 視線、聲音、氣味、射擊與傳聞範圍改變 |

風應該讓玩家判斷：現在該靠近、繞開、跟蹤、喊人、放煙，還是別暴露自己的位置。

### 土

土的重點不是地面背景，而是承載、重量、阻擋、生長、礦、坡、牆與建造。

| 玩家可讀 | 可做 | 世界差異 |
|---|---|---|
| 硬地、鬆土、坡、石、牆、礦脈、根系 | 挖、築、堵、墊、埋、採、修路 | 路可通/不可通，物件被固定，材料可取得，防守或工程狀態改變 |

土應該讓玩家判斷：這裡能不能站、能不能築、能不能搬、能不能藏，或是否需要工具。

## 派生狀態的遊戲用途

派生狀態不是新元素名單，而是世界狀態。

| 狀態 | 遊戲用途 | 合格玩家感 |
|---|---|---|
| 霧 | 限制視線、改變路線、遮蔽人群、延誤交通 | 玩家因此選擇等、問路、靠近、跟人、避開 |
| 泥 | 減速、留痕、污染貨物、使車/腳陷住 | 玩家能用泥判斷誰來過，也會因泥改路或清理 |
| 煙 | 遮蔽、嗆人、警示、吸引注意 | 玩家能借煙避開或示警，也可能被煙逼退 |
| 冰 | 阻路、滑倒、保存、冷害 | 玩家能利用保存或通行，但要承擔滑倒與工具失效 |
| 毒 | 污染、傷口惡化、拒收、醫治需求 | 玩家要辨識、隔離、治療或交易風險 |
| 酸 | 腐蝕、破壞、傷口惡化、加工風險 | 玩家用它處理物件，但會損壞工具或傷人 |
| 蒸氣 | 遮蔽、燙傷、推壓、濕熱 | 玩家可利用遮蔽或動力，也要避免燙傷 |
| 雷 | 天候風險、導體判斷、高地/濕地/金屬工具風險、突發停擺 | 玩家能提前避開、收工具、救援、利用停渡/封路/焦痕 |

## 雷的遊戲觀

雷在奇點裡不是火加風，也不是單純自然科普。雷是「天候把場景中的高處、水邊、金屬工具、人群與路線安排，短時間改寫成風險局勢」。

雷的設計重點：

| 層 | 玩家要玩什麼 |
|---|---|
| 前兆 | 讀出危險快到：風亂、雲低、渡工停船、路人收棚、牲口不安 |
| 立即選擇 | 收金屬工具、離開高處/水邊、躲棚、等、改路、提醒或拉走 NPC |
| NPC 同規則 | 渡工停船、搬運者收棚、牧人牽畜、守路人封路、膽小者躲入低處 |
| 風險 | 被震倒、麻痺、工具脫手、木物起火、貨物受損、路線暫閉 |
| 機會 | 混亂中先成交、救人建立關係、利用焦痕追查、雷後取得特殊損毀物 |
| 回訪痕跡 | 焦黑樹、斷裂繩、停渡記錄、受驚人群、被雨蓋住又殘留的焦味 |

雷的自然成因可以存在於後端與世界常識，但玩家端第一優先是「我現在該怎麼判斷與行動」。

## 元素與 NPC

元素若只影響玩家，不影響 NPC，就會破壞「玩家 = NPC」。

NPC 至少要能：

- 因元素狀態改變路線。
- 因天候或材料狀態改變工作。
- 因玩家處理元素風險而記住玩家。
- 因玩家錯誤使用元素而阻止、責罵、求償或攻擊。
- 先於玩家處理或利用元素狀態。

例：不是「商人輪播台詞說今天霧大」，而是霧大時他改把貨移到棚下、拒收濕貨、壓低報價，或催人先搬容易壞的那批。

## 元素與角色扮演

元素若不能回答「我這個角色因此能做什麼」，就還沒進入角色扮演層。

最低要求：

- 玩家自身或持物能改變元素動詞，例如握持火源、使用油布、拿繩、收起工具、點燈、標記、清障。
- 工具熟練能改變玩家讀到的失敗原因或可用動作。
- NPC 會因玩家處理結果改變信任、報價、委託、阻止或求償。
- 回訪時要看得出這次處理是否留下痕跡。

## 元素與文字

文字要把元素翻成可判讀狀態，不是把狀態包成文學氛圍。

合格：

```text
雨剛停，貨攤前的泥被車輪壓深。收貨牌旁的兩袋乾草已被挪到棚下，攤主只收包好的貨。
```

玩家可判斷：路難走、乾草怕濕、收貨條件改變、可找棚或包材。

不合格：

```text
雨後的空氣潮濕，泥土散出淡淡氣味，遠處的人聲被風吹散。
```

這句可以作氛圍輔助，但若沒有路況、物件、行動或後果，就不是核心內容。

## 元素進 runtime 前的驗收

元素相關內容進入實作前，必須逐條通過：

1. 玩家看得出元素狀態，不需要讀後端欄位。
2. 至少一個可見物件或出口因元素狀態改變。
3. 至少一個玩家動作因元素狀態新增、封鎖、變貴或變危險。
4. 至少一個 NPC 會依同規則行動或留下痕跡。
5. 行動結果會改變世界事實，不只是追加一段文字。
6. 回訪時看得出狀態已持續、衰退、被處理或留下痕跡。
7. 若刪掉元素句後玩家決策完全不變，這個元素內容不合格。

## 禁止方向

- 不把元素寫成自然百科。
- 不把元素只做成傷害顏色或屬性相剋。
- 不把所有 fantasy 名詞升格成元素。
- 不把元素放進玩家面板當四條需求條。
- 不讓元素只影響玩家，不影響 NPC。
- 不用元素描述補救沒有物件、沒有狀態、沒有行動的空場景。
