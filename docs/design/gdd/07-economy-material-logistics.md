# 07 經濟、物資與物流

## 真實經濟的玩家感

真實經濟不是把材料賣給固定板子。玩家要看見世界中有人需要、有人供給、有人搶先、有人壓價、有人缺貨、有人願意相信或不相信玩家。

## 外部研究校準

Raph Koster 對玩家經濟的核心提醒是：重點不是錢本身，而是讓不同玩法在同一個生態裡有用。奇點的經濟設計不能只做採集換錢；採集、搬運、修補、探索、交易、委託、經營都要能互相形成需求。

另一個限制是遊戲性：經濟可以有虧損、錯估與缺貨，但不能讓新玩家只看到會計懲罰。第一階段切片必須保留可理解的起手需求、報酬、失敗原因與下一步準備方向。

## 經濟構件

| 構件 | 設計作用 |
|---|---|
| 鎂 | 玩家可見貨幣錨點 |
| 物資 | 可持有、可消耗、可交易、可修補 |
| 需求 | 由 NPC、場所、組織、修補、建造、風險產生 |
| 供給 | 由採集、製作、交易、回收、NPC 持物產生 |
| 報價 | 由需求、關係、風險、時間、缺貨影響 |
| 物流 | 物資從 A 到 B 的移動與風險 |
| 信用 | 玩家是否被允許先拿、代送、賒欠、承接 |

## 物資進場規則

物資要進核心設計，至少接到一個玩法：

- 工具使用。
- 修補/建造。
- 交易需求。
- NPC 競合。
- 路線風險。
- 人際信用。
- 場所狀態。
- 戰鬥/避險。
- 元素局勢，例如保存、包覆、烘乾、隔離、封路、停渡、通風或清障。

不能只因現實用途多就加入。

## 玩家經濟身份

| 身份 | 玩家行為 | 回訪差異 |
|---|---|---|
| 短工 | 接臨時活、搬運、整理 | 被某些人認得，報價改變 |
| 採集者 | 找來源、看天氣、避風險 | 來源被採空或恢復 |
| 搬運者 | 跑路線、避路況、準時送 | 路線熟悉、信用增加 |
| 修補者 | 用工具和材料改善物件 | 物件狀態保留，NPC 使用 |
| 交易者 | 買低賣高、談價、壓貨 | 缺貨、過剩、關係變化 |
| 委託者 | 花錢讓 NPC 做事 | 離線後有成功/失敗結果 |
| 場所維護者 | 補料、掛牌、佔用、管理 | 場所形成玩家痕跡 |
| 元素處理者 | 用工具處理火、水、風、土、霧、泥、雷等局勢 | 貨況、路況、報價、信用與委託改變 |

## 元素造成的交易差異

元素只在創造取捨時進經濟核心。

| 層 | 玩家感 |
|---|---|
| 保存 | 同一批貨因包覆、通風、烘乾、隔離而有不同收價或拒收結果 |
| 物流 | 雨、霧、泥、風、雷暴會改變路線、時機、停渡、封路和搬運風險 |
| 工具需求 | 玩家需要火源、油布、繩、箱、棚、排水或標記工具才能接某些活 |
| 信用 | 玩家曾正確處理或弄壞元素局勢，會影響 NPC 是否願意交付貨物 |
| 回訪 | 貨被保存、壞掉、被他人先處理、被拒收或改價，回來要看得出 |

## 缺貨與過剩

缺貨要改變：

- 報價。
- NPC 行動。
- 玩家可接工作。
- 路線價值。
- 風險。

過剩要改變：

- 報價下降。
- 收購停止。
- 物件堆積。
- NPC 改做別的事。

## 交易介面設計

玩家交易時要看到：

- 對方是誰或什麼機構。
- 對方需要/出售什麼。
- 玩家持有什麼。
- 價格或交換條件。
- 關係或信用是否影響交易。
- 成交後錢與物怎麼變。

交易失敗也要有原因：錢不足、物不足、對方不信、收滿、時間不對、物件不在場。
