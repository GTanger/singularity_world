## 0. 本檔立場

奇點的戰鬥不是「按攻擊鍵換傷害數字」，也不是把火、水、風、土變成顏色表。

2026-06-23 v3.0 修正：本檔不再以 `world-story-bible-v2.md` 或舊 M4 卡組為正向根。正向重寫從 `world-bible-from-zero-v0.md`、地圖包 v3.1 的 `白潮掛物牆` / `外地人留名處` / `七日回聲草線` / `看診長廊` / `活籬果棚`、物件包 v3.0 的 `白潮不明箱` / `留名紙` / `亮腳草線` / `驗傷杯` / `空果籃`、社會包 v3.0 的 `周澄 / 白潮掛物牆邊的人`、`許央 / 外地人留名處的人`、`林青 / 草線旁守著名單的人`、`杜安 / 長廊裡看診的人`、`季禾 / 果棚裡的人` 開始；舊衝突卡保留為欄位參考。

戰鬥是生活衝突失控後的一種結果。它可以從一把認手刀拒絕陌生手開始，可以從兩方同時認領海送箱開始，可以從錯叫一個名字開始，可以從家戶不准外人拿走家物開始，也可以從查舊事的人和幫人放輕舊痕的人同時拉住一個人開始。

本檔的戰鬥定義：

```text
當人、物、地、名字或舊事被爭奪、阻止、帶走、放走、追索或誤認，
且退讓、交涉、等待、作保、求助仍無法穩住局面時，
身體、工具、地勢、旁人與痕跡一起進入自動結算。
```

玩家好玩的不是每一下手操，而是：

- 讀出衝突為何要發生。
- 在打起來前改變條件。
- 用工具、地勢、關係、名字與物件來避免、制止、引開或承擔。
- 讓戰鬥後的傷、壞物、逃亡、追索、價格、稱呼與回訪文字留在世界裡。

## 1. 立即降格

舊版本保留的價值：

- 把衝突和社會、物件、名字、家戶、路、追索切開。
- 把死亡、拘押、賠償等長期後果當成已完成設計。

## 3. 衝突來源

### 3.1 物件衝突

物件不是乾淨道具，所以戰鬥常從「誰能碰、拿、修、用、藏、賣、歸還」開始。

| 種子 | 玩家看到 | 可避免動詞 | 若升級 |
|---|---|---|---|
| 認手刀拒修 | 修工具的人把刀推回來，前主親友盯著玩家的手 | 查前主、換柄、歸還、請人作保 | 爭刀、奪刀、阻止玩家帶走 |
| 不回箱認領 | 兩方同時按住箱扣，照看回來物的人不願立刻定價 | 掛牌、查扣、等失主、藏起 | 拉箱、推開急著買的人、查舊事的人介入 |
| 家灰罐被拿 | 照看家物的人站在門口，不讓玩家把罐帶走 | 放回、道歉、說明來意、請家戶承認 | 攔路、奪回、家戶排斥玩家 |
| 名帖被改 | 名帖上多出一道新墨，錯人被承認 | 查墨、遮名、找記名字的人 | 撕帖、搶帖、冒名者逃走 |

### 3.2 名字衝突

名字能讓人被認出，也能讓錯的人回頭。戰鬥不一定從武器開始，可能從一句錯稱開始。

| 種子 | 玩家看到 | 可避免動詞 | 若升級 |
|---|---|---|---|
| 同名錯叫 | 三個人同時回頭，其中一個臉色變了 | 改口、澄清、保密、離開 | 被攔、被逼問、有人護住真正目標 |
| 不願應聲 | NPC 被叫名後沉默，旁人也安靜下來 | 換稱呼、請記名字的人、暫不追問 | 查舊事的人逼近，被尋者逃走 |
| 冒名交易 | 買主用錯名領走物件 | 查名帖、阻止交付、找掌簿人 | 搶物、堵路、街區加入 |

### 3.3 路與地方衝突

路是歷史，不是座標線。誰先走、誰等誰、誰能改路，會直接引發衝突。

| 種子 | 玩家看到 | 可避免動詞 | 若升級 |
|---|---|---|---|
| 遠行隊不等人 | 隊伍已整裝，寄物人還沒到 | 等、追路、改路、託別人帶 | 拉人上路、攔隊、寄物被帶走 |
| 舊路帶錯人 | 路物微熱，隊員開始偏離原路 | 叫名、丟下路物、跟路、撤回 | 把人拉回、與帶路人爭執 |
| 不留林追逃 | 一方要帶人進林，一方要把人帶回 | 留名、幫逃、幫追、沉默 | 拉扯、護人、查舊事的人圍上 |

### 3.4 家戶與社會衝突

家戶、修工具桌前的人、照看回來物的人、記名字的人、查舊事的人不是背景派系。他們在場時，戰鬥後果會改變玩家被誰接納、誰防備、誰記住。

| 種子 | 玩家看到 | 可避免動詞 | 若升級 |
|---|---|---|---|
| 外人碰家物 | 屋內某個位置忽然安靜，照看家物的人起身 | 放回、道歉、請求借用 | 推出門外、奪物、家戶拒絕往來 |
| 試手被拒 | 工具不願新手，學徒被前輩叫住 | 多試、換柄、暫不修 | 工具脫手、割傷、桌前的人拒收 |
| 查舊事的人逼近 | 玩家手上物件被認為能找到人 | 交出、藏起、談條件、誤導 | 被跟、被攔、逃亡者被拖回 |

## 4. 戰鬥流程

```text
可讀前兆
-> 局部接近
-> 社會與物件壓力
-> 衝突升級
-> 自動交鋒
-> 傷/壞/逃/制止
-> 後續世界狀態
-> 回訪痕跡
```

| 階段 | 玩家看到 | 玩家能做 | NPC 同規則 |
|---|---|---|---|
| 可讀前兆 | 手按住物件、錯人回頭、隊伍要走、家戶起身、查舊事的人靠近 | 觀察、問、退、等、改稱、請人作保 | NPC 也會觀察、退、叫人、藏物 |
| 局部接近 | 對方靠近、路被卡、物件被守、旁人退開 | 繞、讓、護物、放下、求助 | NPC 也會靠近、堵路、把人拉走 |
| 社會與物件壓力 | 家戶、修工具桌前的人、照看回來物的人、記名字的人或查舊事的人表態 | 道歉、說明、談價、保密、交出 | NPC 也會作保、拒絕、搶先或沉默 |
| 衝突升級 | 推擠、搶奪、威脅、拉人、撕帖 | 制止、退讓、留人、攻擊 | NPC 也會制止、退讓、攻擊或求助 |
| 自動交鋒 | 戰報文字 | 承擔結果，不手操每一下 | 同一套自動結算 |
| 後續狀態 | 傷、壞物、失物、追索、稱呼改變 | 治療、修補、歸還、逃離、和解 | NPC 後續也會修、追、躲、報復或求和 |

## 5. 前兆設計

普通衝突至少要有一個前兆。前兆不是警告標籤，而是玩家可讀狀態。

| 前兆類型 | 合格文字功能 | 可點入口 |
|---|---|---|
| 手勢 | 誰的手已按住物件、門、肩膀或名帖 | 看手、放手、按住、提醒 |
| 站位 | 誰堵住路、誰退開、誰把人護在身後 | 繞開、靠近、退後、請讓 |
| 持物 | 工具、箱、名帖、繩、路物是否被握緊 | 詢問、試手、交出、護住 |
| 稱呼 | 叫名後誰回頭、誰沉默、誰臉色變 | 改口、確認、保密、叫停 |
| 旁人 | 家戶、修工具的人、照看回來物的人、記名字的人、查舊事的人是否表態 | 請作保、請制止、避開 |
| 地勢 | 窄處、坡面、濕地、門前、階旁是否讓人難退 | 移位、等待、扶住、離開 |
| 舊痕 | 物件或路把某段過去推回當下 | 放下、遮住、叫名、跟路 |

若一個設計無法寫出前兆，它不該進戰鬥包。

## 6. 衝突升級公式

公式不是玩家第一層文字，而是後端判定用的秩序。每項 0 到 3 分，前端只顯示狀態。

```text
衝突升級值 =
  物件重要度
+ 人身距離壓力
+ 名字/身份錯認
+ 家戶或群體排斥
+ 追索逼近
+ 退路變差
+ 既有傷怨
- 交涉餘地
- 可作保者在場
- 主動放下或退讓
- 可替代路線
```

| 升級值 | 狀態 | 玩家看到 |
|---:|---|---|
| 0-3 | 可穩住 | 對方警告、暫停、願意等人或願意再問一次 |
| 4-6 | 高壓 | 對方靠近、旁人退開、物件被按住、路被卡住 |
| 7-9 | 失控前 | 推擠、拉扯、搶物、撕帖、有人叫人來 |
| 10+ | 自動交鋒 | 戰鬥發生；戰報必須寫明哪個前兆失控 |

硬規則：主動退讓不等於失敗。退讓可以保住物件、保住名字、保住關係，或讓玩家日後更好追索。

## 7. 參與者狀態

每個參與者可用 0 到 10 的設計值表示。玩家端不顯示數字，只顯示可讀狀態。

| 狀態 | 定義 | 玩家可讀轉譯 |
|---|---|---|
| 身體力 | 推、拉、承重、壓制與抵抗能力 | 壯、虛、被撞退、勉強站住 |
| 穩定 | 站位、重心、被推後是否倒退 | 站得穩、腳下滑、被逼到邊上 |
| 靈敏 | 靠近、閃避、脫離、搶先反應 | 反應快、跟不上、來不及讓開 |
| 耐受 | 受傷後是否還能行動 | 還能動、喘不上、需要扶住 |
| 工具熟悉 | 對手中工具、持物或護物方式的熟悉 | 握得順、手生、工具像在等別人 |
| 判讀 | 讀前兆、地勢、稱呼與對方意圖 | 看出要搶、沒看出錯名 |
| 關係支撐 | 現場是否有人願意幫、攔、保、等 | 有人替玩家說話、旁人退開 |

## 8. 交鋒公式

交鋒只在衝突升級後啟動。它不是每回合手操，而是局部自動結算。

```text
行動壓力 =
  身體力
+ 工具熟悉
+ 站位優勢
+ 先前準備
+ 旁人支撐
+ 物件牽引
- 傷勢
- 地勢阻礙
- 持物不便
- 名字混淆
```

```text
守住能力 =
  穩定
+ 靈敏
+ 判讀
+ 退路
+ 遮擋物
+ 可作保者介入
- 傷勢
- 被前主物牽制
- 家戶或群體排斥
- 追索壓力
```

```text
交鋒差 = 行動壓力 - 守住能力 + 小幅波動
```

小幅波動只用來避免每次完全同結果，不得蓋過準備、前兆、物件、地勢與人際狀態。

## 9. 交鋒結果

| 交鋒差 | 結果 | 世界後果 |
|---:|---|---|
| -8 以下 | 反被壓住 | 發起者失衡、工具脫手、被旁人喝止或被記住粗暴 |
| -7 到 -3 | 未能得手 | 對方守住物件、退到安全處、關係變差 |
| -2 到 2 | 僵持 | 雙方位置、旁人態度、物件狀態或路況改變 |
| 3 到 7 | 逼退/輕傷 | 對方退位、擦傷、掉物、讓路或暫時失去稱呼主導 |
| 8 到 12 | 制住/重傷/奪取 | 物件持有者改變、有人倒下、路線暫時改變 |
| 13 以上 | 決定性後果 | 失去行動能力、被帶走、重大物件損壞或衝突擴散 |

## 10. 傷勢與痕跡

傷勢不是生命條。它是「身體被世界和他人留下了什麼」。

```text
傷勢強度 =
  工具傷力
+ 交鋒差級距
+ 地勢事故
+ 舊傷牽連
- 遮擋
- 退避
- 旁人及時拉開
```

| 強度 | 傷勢 | 玩家看到 |
|---:|---|---|
| 0 | 無明顯傷 | 只被逼退、衣角被扯住或工具被格開 |
| 1-2 | 輕傷 | 擦傷、瘀青、手麻、呼吸亂、站位變差 |
| 3-5 | 中傷 | 流血、跛、手臂無力、工具脫手、需要照看 |
| 6-8 | 重傷 | 難以站穩、需撤離、需醫者或熟人照看 |
| 9+ | 致命風險 | 可能倒地、昏迷或失去行動能力；不得當普通結果濫用 |

戰鬥後至少留下一種痕跡：

- 身體痕跡：傷口、疲弱、舊傷被牽動、行動受限。
- 物件痕跡：刀更拒手、箱扣裂開、名帖撕破、路袋漏砂。
- 地方痕跡：門前被撞歪、階旁有血、路線被踩亂。
- 社會痕跡：某家戶拒絕玩家、某人願意替玩家說話、查舊事的人記住玩家。
- 名字痕跡：玩家被改稱、被錯認、被某街區記住。

## 11. 工具與物件在戰鬥中的角色

工具不是武器欄。物件可以開戰，也可以止戰。

| 類型 | 可做什麼 | 風險 |
|---|---|---|
| 認手刀 | 威嚇、切斷、護身、試手、在前兆階段判斷是否順手 | 拒手、被前主親友認出、讓衝突快速升級 |
| 不回箱 | 成為爭奪物、遮擋物、引出前主或買主 | 箱扣損壞、兩方認領、被追索 |
| 名帖 | 叫停、澄清、保密、冒名、找人 | 錯名讓錯人加入衝突 |
| 路袋 | 比對舊路、引隊、撒砂斷追 | 把人帶偏，或暴露走過的路 |
| 家灰罐 | 證明家戶牽連、迫使人停手 | 被打碎會讓家戶關係惡化 |
| 繩/帶 | 拉人、固定、拖物、制止 | 綁錯人會被視為攻擊 |
| 傘/布 | 遮、擋、包覆、隔開人群 | 被扯破，或引出舊雨牽連 |

## 12. 地勢與現場狀態

地勢不是傷害修正表，而是玩家能不能改變局面的場所條件。

| 現場狀態 | 影響 | 玩家前置選擇 | 後果 |
|---|---|---|---|
| 窄階 | 人不易並行，推擠容易失衡 | 退到旁邊、請人讓路、等一等 | 被逼退、掉物、旁人更容易看清 |
| 濕地 | 腳步與物件痕跡清楚，但不易站穩 | 繞路、扶住、放下重物 | 摔倒、留下腳印、追索更容易 |
| 風口 | 聲音和名字容易被帶歪 | 靠近再說、請記名字的人、改稱 | 叫錯人、旁人誤會、衝突擴大 |
| 門前 | 家戶與街區容易介入 | 道歉、放回、請主人說明 | 被逐出、被接納、門前留下痕跡 |
| 林線 | 查找與淡痕衝突加重 | 留名、跟路、放走、求助 | 人消失、線索變淡、查舊事的人記住 |
| 海岸潮線 | 失物與認領衝突加重 | 掛牌、暫不賣、查扣 | 物件被帶走、失主到場、價格波動 |

## 13. 目擊、人際與經濟後果

戰鬥後果至少要改變一項社會事實。

| 後果 | 觸發 | 玩家看到 |
|---|---|---|
| 被防備 | 在公共場所先動手、亂搶物、亂叫名 | 報價變差、借物被拒、旁人不願作保 |
| 被敬重 | 在可讀風險中制止危險、護住他人或歸還物件 | 有人讓路、請玩家幫忙、願意等玩家 |
| 被求償 | 傷人、壞物、打碎家物、毀壞名帖 | 對方要求賠、修工具桌前的人不願接、家戶排斥 |
| 被記住 | 有旁人承認玩家救人、護物、放走或追索 | 稱呼、通行、信用或追索距離改變 |
| 被尋仇 | 對方熟人、查舊事的人或家戶記住衝突 | 後續 NPC 避開、堵路、跟蹤或不再等玩家 |

## 14. 自動戰報格式

戰報必須說明三件事：

1. 哪個前兆失控。
2. 哪個玩家/NPC 選擇改變了結果。
3. 世界留下什麼後果。

合格：

```text
你先把名帖壓回桌面，沒有再叫那個名字。
急著買的人伸手去扣箱角時，沈鹿從旁邊攔了一下；箱扣仍被扯裂，裡面掉出一截帶鹽的舊繩。
潮線邊的人都看見了，掛物牆今晚不會再讓那只箱子出價。
```

不合格：

```text
你造成 5 點傷害。
戰鬥勝利。
```

## 15. 死亡與長期失敗邊界

死亡不是普通失敗預設。普通戰鬥優先產生：

- 退讓。
- 受傷。
- 失物。
- 被制住。
- 被帶離。
- 被逐出。
- 昏迷。
- 被救。
- 被迫賠付。
- 被某家戶、街區、修工具桌前的人、照看回來物的人或查舊事的人記住。

進入死亡風險需同時滿足多項：

- 已是重傷或失去行動能力。
- 對方仍有明確致命意圖。
- 無旁人制止、無退路、無救援。
- 現場本身有致命地勢或舊痕牽連。
- 玩家或 NPC 沒有可用的停手、投降、拖延、求助條件。

死亡、長期傷勢、昏迷、拘押、療養、賠付與追索後續需要獨立設計包；本檔只定入口。
