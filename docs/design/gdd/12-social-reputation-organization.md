# 12 關係、名聲與組織

## 社會設計定位

社會系統不是先寫國家設定，而是讓玩家在局部互動中被人記住、被規矩限制、被關係影響。

## 關係層級

| 層級 | 玩家可見 |
|---|---|
| 陌生 | 對方不認得玩家 |
| 見過 | 稱呼或態度略變 |
| 有交易 | 報價、信任、拒絕不同 |
| 有幫助 | 願意提供線索或小協助 |
| 有衝突 | 避開、提高價格、阻擋 |
| 有信用 | 可委託、賒欠、先拿後補 |
| 有名聲 | 某地多人對玩家有預期 |

## 名聲來源

名聲不靠任務分數，而靠可追溯事件：

- 修好公共物件。
- 守住貨物。
- 搶先成交。
- 插隊或阻人。
- 救援。
- 失信。
- 長期維護某場所。
- 多次走同一路線。
- 正確處理或誤用某類元素局勢，例如點燈、封路、保存貨、清障、救人、弄壞貨。

## 組織玩家可見面

低/中/高/巨型社會系統先落在玩家可見差異：

| 組織尺度 | 第一版可見面 |
|---|---|
| 小群體 | 幾個人互相認得、共享物件、守同一規矩 |
| 店/工坊/場所 | 報價、委託、工具、維修、信用 |
| 聚落 | 通行、告示、公共物、守路者、風險 |
| 門派/氏族 | 稱呼、規矩、入門要求、衝突 |
| 國家/聯盟 | 幣制、稅、通行、法律、遠期事件 |

先做局部可見，不先做宏大設定。

## 對話與關係

對話要改變或揭露關係：

- 對方是否認得玩家。
- 是否願意說更多。
- 是否願意交易或委託。
- 是否記得舊事。
- 是否因玩家行動改變態度。

沒有關係變化、沒有資訊、沒有行動後果的對話，不是核心內容。

## 元素造成的社會承認

玩家不需要選職業，但世界可以依行動承認玩家的位置。

| 承認 | 玩家可見 |
|---|---|
| 會處理火源 | 守棚人願意讓玩家靠近燈架或請玩家點燈 |
| 懂水路/貨況 | 搬運者願意交付怕壞貨，或報價較好 |
| 熟路況 | 引路人少收費、告知捷徑，或讓玩家先通過 |
| 曾誤用工具 | 某場所提高警戒、要求賠償、拒絕玩家靠近 |
| 救過人/避過險 | NPC 願意作證、跟隨、求助或給新委託 |

## 社會風險

社會也能產生風險：

- 被拒絕。
- 被懷疑。
- 被看見。
- 信用下降。
- 被要求補償。
- 被某群體排斥。
- 被捲入衝突。
