# 22 回文字

狀態：現行主要玩家表面，已由使用者拍板
日期：2026-07-16
第一權威：`../../DESIGN_KEYWORDS.md`

## 來源

使用者重新比較文字與圖像對奇點世界的實際成本後指出：

> 圖像會讓我多一個分心的項目

在確認文字不是敘事型分支遊戲、GUI 仍供玩家行動、圖像不留作並行產品後，
使用者定案：

> 好，回文字

## 已決定

- 奇點世界**回文字**；文字重新成為正式的主要玩家表面。
- 不再同時維護圖像大地圖與文字兩套產品責任，也不把圖像列成日後必補的
  欠債。
- GUI 仍是玩家的眼睛與手腳。玩家要透過 GUI 行動並活在故事裡，不是透過
  GUI 閱讀預寫故事、長篇場景散文或分支劇情。
- 世界先運作；文字再把玩家此刻能感知的人、物、位置、行動、局勢、結果與
  痕跡翻成可讀內容。文字不得捏造後端不存在的人、物或事件。
- 玩家操作必須改變或嘗試改變世界狀態，而不是只讓畫面追加一段文字。

## 移動語彙已定（2026-07-17）

使用者補充並定案：

> 忘了跟你說，我決定移動一樣回歸東西南北上下跟進出

- 玩家用來表達移動的八個基礎詞固定為：**東、西、南、北、上、下、進、出**。
- 這次收斂的是**移動語彙**，也就是玩家用哪些詞表達移動；不是把舊方格
  MUD、房間清單、九宮格方向鍵或傳統命令列整套恢復。
- 手機主操作採直接觸控相鄰目的地；八個詞保留為底層移動語彙，詳細邊界見下節。
- 本決定不選擇座標、格網、房間或其他空間拓撲，也不決定連續／離散移動、
  路徑搜尋、碰撞、旅程時間與移動回饋。
- 「進／出」已是可用移動詞；哪些對象與空間關係允許進出仍待後續設計，
  不得由這兩個詞自行推出室內地圖或進出建築已恢復。

## 手機主操作骨架已定（2026-07-31）

使用者否決把八個移動詞壓成狹窄橫列、再以鍵盤作主要操作的草圖，並在三種
手機操作骨架中選擇：

> 1，就像指尖/指間mud那樣的設計

- 日常移動與常用動作以**直接觸控**為主，不要求玩家每一步叫出鍵盤。
- `指尖／指間 MUD` 是手機操作參照。2016 年原始產品截圖已確認：普通移動區
  不是 D-pad，也不是「方向＋目的地」指令盤；它把目前房間與相鄰房間排成
  一塊局部空間關係圖，玩家直接點相鄰房間名稱移動，方向主要由按鍵相對位置
  表達。大型分類按鍵屬於其他常用操作，不能反推成移動方式。
- 奇點已定的東、西、南、北、上、下、進、出是**世界與輸入語彙**；參照產品
  的「點相鄰目的地」是**手機觸控呈現**。兩層可以並存，但不得再把八個詞
  自動畫成八顆方向鍵，也不得在目的地按鍵上重複拼接方位後冒充參照產品。
- 既有上欄的**日期、中央圓形日晷、時間**必須直接保留，除非使用者日後明確
  改動；參照其他遊戲時不得順手移除或重新解釋這三項。
- 先前把參照縮減成現代 D-pad、同時刪掉日晷的草圖已被使用者否決，不能作為
  後續稿的布局基礎。
- 2026-07-31 的 v4「方向＋地名」按鍵草圖也已被使用者以「指尖不是這樣移動」
  否決；它混淆移動語彙與參照產品的實際操作，不能再作為後續稿的布局基礎。
- 相鄰地點如何排布、上／下／進／出的觸控呈現、操作類別名稱、自由輸入入口與
  正式視覺風格，仍須由實際草圖及手機操作驗收；本節不把任何一張未接受草圖
  升格成定版。

## 世界變化不靠介面宣告

2026-07-17，使用者針對助手製作的「現在／人／物／可去／新痕跡」狀態看板
原型明確校正：

> 世界有沒有在改變是玩家的感受，不是靠設計顯示

- 世界先依規則真的改變；玩家在行動、等待、離開、回訪、錯過與承受後果時
  感到差異。
- 人物離開後不在原處、貨被取走後數量變少、道路損壞後真的難走；這些是新的
  世界事實，不需要 UI 再加「已改變」或「新痕跡」替玩家解說。
- 玩家因為記得先前狀態、原有期待或自己的經歷，才會把眼前差異感成世界正在
  生活；介面不能代替這段經驗。
- 開發／驗收層可以比較狀態、事件與因果，但玩家表面不得因此變成狀態看板、
  debug 面板或模擬證明頁。
- 這不禁止玩家看見世界後果；它禁止的是額外加上一層「這裡變了」的系統標示。

## 這次不是回到舊路

在進一步釐清「回文字」的含義後，使用者指出：

> 你，似乎在走一條前所未有的路

並要求把本次辨別記錄下來。這句話先作**設計觀察**，不是「歷史上從未有人
做過」的事實宣告；外部先例與反證另行研究。

目前確認的辨別是：

- 不是用文字講述一個預先寫好的世界；是一個本來就在運作的世界，透過文字
  顯現玩家此刻能感知的部分。
- 文字不是圖像資產做不起來時的廉價替代，也不是把圖像遊戲降級成文字版。
- GUI 不是故事閱讀器；它讓玩家接觸人、物與環境並採取行動。
- 行動之後不是翻到下一段劇情，而是後端世界真的改變，文字再呈現改變後的
  局部事實。
- 故事不是預先塞給玩家的內容；故事可以是玩家與其他人生活、行動、交會後
  留下的經過與痕跡。
- 不因「文字」直接套用 MUD、互動小說或聊天介面的既有形式，也不因「GUI」
  直接套用地圖、圖像或管理面板的既有形式。

## 不是什麼

- 採用八個移動詞不等於自動復活舊方格 MUD、房間清單、九宮格方向鍵、
  傳統命令列或 v6 以前的文字 UI。
- 舊方格 runtime 已退出 active 世界，只保留遷移回復與歷史證據。
- 不是先寫好故事，再讓玩家閱讀與選分支的敘事型文字遊戲。
- 不是用大量生成散文、氣氛句或 NPC 背景文字冒充世界豐富度。
- 不是用「現在態」、變化標記、事件證據、痕跡計數或人／物／出口分類看板證明
  世界有演算。
- 不是把 2D 大地圖留在 backlog，等待日後補完。

## 覆蓋的圖像決定

本決定覆蓋 `21-2d-open-world-primary-surface.md` 及其 2026-07-13～15 補充：

- 全螢幕、可縮放的 2D 大地圖作主要遊戲表面。
- 所有人形生物以圓形加一個中文字存在地圖上，縮放時維持固定螢幕尺寸。
- 單擊走、雙擊跑、直線移動、撞牆停、玩家自行點擊繞路。
- 將地圖美術、Watabou 風格、圖像資產或程序地圖繼續發展成產品製作線。

上述內容保留為歷史、研究與可回看素材；不是現行玩家表面、實作授權或日後
必補的第二產品。

## 繼續保留

- 白塔半島與已接受的大地理關係。
- 世界中的位置、距離、路線、地形、旅行時間、人物、物件與事件可以繼續是
  後端事實；回文字只改玩家如何感知及操作它們。
- 後端唯一真理、世界永遠在線、玩家與 NPC 同規則、全物件化、不可無中生有
  與守衡。
- 玩家不是世界主角；玩家與別人的接觸是兩段生活交會，不是開啟內容入口。
- 手機 GUI、輕操作與「玩家透過 GUI 活在故事裡」的邊界。
- 「用最簡單的機制，做出最豐富的細節」；回文字不能成為單薄系統或大量
  無差異房間的藉口。

## 2026-07-20 現行可操作表面

決策 013 已把本頁從方向落成可操作版本。現行 PWA 直接顯示後端權威的所在地、
當地描述、正在生活的人、可接觸資源、實際出口與行動結果；東、西、南、北、上、
下、進、出以可點路線出現。同方向有多條路時，依道路、野徑、渡船或距離等真實
路線資料區分，不會因舊單值方向欄位而覆蓋。

玩家移動或採集後，畫面呈現新的實際位置與資源存量，不加「已改變」看板。這是
正式世界的 operational 玩家表面；其版面已通過手機與桌面目視驗收，但 CSS、字體、
最終資訊密度與自由輸入仍可在真實遊玩後調整，不因這次部署升格成永不可改的美術正典。

## 尚未決定

- 現行版面後續是否調整資訊密度、視覺語言、字體與其他操作入口。
- 是否允許自由輸入，以及八個移動詞以外的操作如何和可點 GUI 組合。
- 座標是否及如何投影、長程旅行解析度與跨區路線如何在文字表面呈現。
- 第一個需要以長時間真實遊玩驗證的完整生活／冒險內容。
- 文字主畫面的時間與歷史如何自然存在仍未決定；但把主畫面設計成持續更新的
  「現在態看板」、另用變化標記或歷史證據解說世界演算，已被排除。
- 後續是否出現能推翻第一輪研究的新案例。2026-07-16 的有界外部研究沒有找到
  同時符合全部條件的成熟作品，但這不是「歷史上絕無先例」的證明。

## 外部研究結果（2026-07-16）

- 組成零件各有先例，完整組合在第一輪有界搜尋中沒有成熟同類。
- `Versu` 最接近狀態、GUI action 與動態文字閉環；`Usurper Reborn` 最接近
  持續世界與自主人物；`Talk of the Town` 最接近真相、人物所知與感知分離；
  `Viv` 最接近行動因果、記憶與故事線辨識。
- 研究支持把世界事實、人物／玩家可知、重要性篩選、文字實現、GUI 行動、
  世界裁決與因果痕跡分開；這是候選能力鏈，不是 UI 或技術定案。
- 深模擬不會自動變成可讀體驗；事件 log 不是世界表面；LLM 不應擁有世界
  真理。完整來源、對照矩陣與反證見外部研究報告。

## 玩家表面驗收句

玩家看到的不是一段等他閱讀的故事，也不是一張替模擬作證的狀態看板，而是
一個已經在運作的局部世界：他能辨認自己、所在位置、可感知的人與物及可採取
的行動；行動、等待、離開或回訪後，他從人物、物件、道路、關係與自身處境真的
不同，親自感到世界曾經往前走。
