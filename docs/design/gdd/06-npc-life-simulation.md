# 06 NPC 生活模擬

## NPC 定位

NPC 是世界居民，不是功能按鈕。先設計「人正在過日子」，再從其中產生交易、問答、衝突與合作。

## 外部研究校準

`Generative Agents` 的可取部分不是讓 NPC 亂生成文字，而是把可信行為拆成觀察、記憶、規劃與反思。奇點的文件層只採用玩家可見版本：NPC 要有目的、去處、持物、事件記憶或行動痕跡；若玩家完全看不出這些差異，後端再複雜也不能算 NPC 生活模擬。

## NPC 最低狀態

| 狀態 | 玩家可見方式 |
|---|---|
| 位置 | 在場、缺席、剛走、正在路上 |
| 持物 | 手上、身旁、背著、放下 |
| 鎂/資產 | 交易時可見，不必常駐顯示 |
| 目的 | 行為、動作、詢問後透露 |
| 去處 | 路線、等待、跟隨、缺席痕跡 |
| 關係 | 稱呼、報價、拒絕、幫忙、記得 |
| 事件記憶 | 之後對玩家行動有反應 |

## NPC 行為來源

NPC 行為應來自：

- 工作。
- 等待。
- 搬運。
- 交易。
- 休息。
- 避險。
- 守物。
- 找人。
- 找物。
- 回家或赴約。
- 對玩家過去行動的反應。

## 同規則要求

玩家能做的核心世界動作，NPC 應有同構版本：

| 動作 | NPC 表現 |
|---|---|
| 走 | 自己改變位置並留下缺席/抵達痕跡 |
| 拿/放 | 改變物件與持物狀態 |
| 買/賣 | 改變鎂、物品、需求、價格感 |
| 用/修 | 改變物件狀態 |
| 等 | 在某地佔用時間或隊列位置 |
| 問/說 | 由狀態與關係驅動，不輪播 |
| 避/戰 | 對風險與衝突作反應 |
| 處理元素局勢 | 點燈、收棚、改路、封路、搬貨、清障、拒收或搶先使用工具 |

## NPC 與玩家的競合

NPC 必須能讓玩家感覺世界不是等玩家啟動。

競合例：

- NPC 先買走需要的物品。
- NPC 先完成某個需求。
- NPC 阻擋路線。
- NPC 因玩家讓位而記住玩家。
- NPC 因玩家插手而不信任。
- NPC 對同一物件有使用權或歸屬。
- NPC 因玩家處理或誤用元素局勢而請託、阻止、求償或承認玩家。

## NPC 與元素

NPC 的元素反應必須是行動，不是台詞。

合格表現：

- 雨後有人把貨移到棚下。
- 霧重時引路人提高報價或拒絕帶路。
- 雷暴前渡工停船、守路人封路、搬運者收工具。
- 玩家點亮燈架後，某 NPC 改從暗處經過或允許玩家查看物件。
- 玩家錯用火源後，守倉人要求賠償或不再讓玩家靠近。

不合格表現：

- NPC 隨機說「今天霧很大」但位置、持物、交易、路線與記憶都不變。

## 對話規則

NPC 對話有價值的條件：

- 回應當前狀態。
- 回應玩家關係。
- 提供線索。
- 表達目的。
- 改變後續選項。
- 留下事件記憶。

禁止把 NPC 做成隨機台詞播放器。

## NPC 顯示規則

玩家未知道姓名前，不直接顯示真名。顯示應依觀察層級：

- 陌生人。
- 可觀察身份。
- 已知姓名。
- 與玩家有關係的稱呼。

人群可折疊，但不得顯示精確人數。
