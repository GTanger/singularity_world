# 01 玩家定位與核心回圈

## 玩家定位

玩家是世界中的一個人，不是劇本主角、世界管理員或任務板使用者。玩家應該透過自身狀態、可碰物件、NPC 行動與世界痕跡產生代入。

玩家也不能只是被放進一套日常雜務。奇點的角色扮演必須讓玩家做現實生活中不能、不能安全做、不能長期做、或不能被世界承認的事：住進另一個世界、學會奇幻規則、承擔可控風險、和 NPC 形成關係、改變局部世界並留下痕跡。細節見 [16-player-fantasy-affordances.md](16-player-fantasy-affordances.md)。

奇幻規則與元素要先接到玩家角色本身，而不是只接到場景天候或戰鬥傷害。玩家必須能透過自身、持物、工具、熟練、關係與位置，對元素局勢做出不同選擇。細節見 [17-roleplay-elements.md](17-roleplay-elements.md)。

這件事要先從簡單開始。第一個可玩核心只需要一個狀態、一個入口、一個動作、一個世界差異；複雜的 NPC、經濟、社會、離線安排只能在這個核心成立後再接上。

第一個入口先是玩家自身。玩家必須先能點開自己，知道自己是誰、在哪、有多少錢、手上拿什麼，並做一個會改變自身或世界狀態的簡單動作。場景、NPC、貨物與天候都排在這個代入錨點之後。

## 外部遊戲設計校準

回圈不是完成證明。依 `meaningful play` 與 loop/arc 研究，奇點每個回圈都必須同時回答：

- 動機：玩家為什麼開始這件事。
- 行動：玩家具體點誰、點什麼、去哪裡。
- 回饋：系統如何讓玩家看出結果。
- 整合：結果如何接回錢、物、路、人、時間、風險或長期痕跡。
- 再目標：玩家如何得到下一個想做的事。
- 變化：第二次做為何不是同一件事。

如果一個回圈只是「看場景 -> 點入口 -> 得文字」，那是操作流程，不是遊戲設計。

玩家最少需要知道：

| 問題 | 畫面回答 |
|---|---|
| 我是誰 | 姓名、可點自身入口、近期被世界承認的行動 |
| 我在哪 | 場景名、可感知地標、可走出口 |
| 我有什麼 | 鎂、背包、手持物、工具 |
| 我能做什麼 | 自身動作、當前可點人物、物件、出口 |
| 我會失去什麼 | 錢、物、時間、關係、通行、傷勢、機會 |
| 我為什麼下次回來 | 離線安排、物件狀態、NPC 記憶、交易/路況變化 |

## 一分鐘回圈

目的：讓玩家每次點擊都知道「我剛剛介入了世界」。

流程：

1. 讀取當前場景狀態。
2. 先能點自己；再點人、物或出口。
3. 看可用動作。
4. 選擇一個動作。
5. 看到文字結果與狀態變化。

合格例：

- 點【濕繩圈】後看到它潮濕、磨損、可整理；整理後繩圈狀態改變，某 NPC 之後搬貨較順。
- 點【候船者】後看到他帶著包袱、焦急等船；讓位或插隊會改變隊列、關係或衝突風險。

不合格例：

- 點物件只出一段氛圍文字。
- 點 NPC 只出輪播台詞。
- 點出口只是換地名，沒有路況、時間或風險。

## 十分鐘回圈

目的：讓玩家完成一個短目標。

短目標類型：

| 類型 | 範例 | 結果 |
|---|---|---|
| 賺錢 | 搬、修、送、賣 | 鎂、信用、被認得 |
| 工具 | 借、買、修、練 | 可用動作增加、熟練提升 |
| 元素 | 使用工具處理火、水、風、土、霧、泥、雷等局勢 | 可用動詞、路況、NPC 反應、世界痕跡改變 |
| 人際 | 幫忙、問路、跟隨、避讓 | 關係、線索、稱呼、協助 |
| 探索 | 查路況、走不確定路、等時機 | 已知路線、風險標記 |
| 維護 | 修補、清障、掛牌、補料 | 場所狀態、回訪差異 |

十分鐘回圈必須讓玩家至少得到一種持續性結果：錢、物、路線、人物記憶、工具熟練、物件改善、風險標記。

## 一次登入回圈

登入不應只是重新看到同一段場景。登入時要先回答：我離線後，世界局部發生了什麼。

流程：

1. 顯示自身狀態與上次位置。
2. 顯示 1 到 3 條局部痕跡：NPC 移動、物件狀態、交易結果、天氣/路況、離線安排。
3. 讓玩家選一條今日短路徑。
4. 完成 1 到 3 個小目標。
5. 離線前留下安排：等待、看守、休息、委託、交易、跟隨、留物。

離線安排不得是複雜排程表；玩家只需要選「我下線後大致讓角色做什麼」，世界用同規則推進並回報結果或失敗。

## 長期回圈

長期追逐不是單一路線。奇點應允許玩家形成自己的「生活位置」。

長期位置：

- 某地熟人。
- 某工具熟手。
- 某路線熟客。
- 某 NPC 的可靠對象。
- 某市場的供給者或搬運者。
- 某場所的維護者。
- 某組織的外圍參與者。
- 某危險路段的倖存者或嚮導。

長期設計要求：每條長期位置都要能從玩家短期行為自然累積，不靠創角職業一次選定。
