# 21 2D 平面大地圖開放世界主畫面

狀態：上層方向已由使用者拍板；細節仍待設計
日期：2026-07-13
第一權威：`../../DESIGN_KEYWORDS.md`

## 背景

奇點世界最初已有 Top-down、城鎮與野外同一張大地圖、單一平面、
開放世界與全物件化等方向。2026-04 曾實作全螢幕 Hex Canvas 玩家地圖，
後續才轉向純文字 MUD 主畫面。

2026-07-13，使用者決定重啟最初概念：`2D 平面大地圖，開放世界`。
在「全螢幕可縮放大地圖／較近俯視 RPG／大地圖與區域近景兩層」三種
尺度中，使用者確認「原則上是 A」。

## 已決定

- 主要遊戲畫面是**全螢幕、可縮放的 2D 平面大地圖**。
- 玩家與 NPC 原則上以小型角色或圖標直接存在地圖上。
- 地圖是玩家行走、觀察與介入世界的主要遊戲表面，不是裝飾背景、
  場景插圖或只供查看的世界縮略圖。
- 遊戲維持開放世界；城鎮與野外屬於同一個連續世界，不退回房間清單。
- 操作仍以手機指觸為主，不要求輸入傳統 MUD 指令。
- 文字退到對話、狀態、互動選項、行動結果與必要局勢提示；文字不再負責
  讓玩家自行想像主要空間畫面。

## 繼續保留

- 後端唯一數據真理。
- 玩家與 NPC 使用同一套世界規則。
- 世界永遠在線。
- 全物件化、插頭／插座動作語義、物件不可無中生有。
- 既有世界時間、位置、移動、NPC、物件與互動資料可作新主畫面的底層。
- `白塔半島` 初始地圖繼續作大地理正典，但它不是 runtime 比例尺、
  格網拓撲或美術風格定案。

## 被取代的方向

- 純文字 MUD 不再是主要玩家畫面或產品北極星。
- 現行文字描述主畫面只能作遷移素材、對話／回饋元件來源與歷史證據，
  不能再被當成新 UI 的既定外框。
- `重文字、輕畫面` 不再是現行畫面原則；現行原則是讓 GUI 直接承載空間、
  人物、物件與世界狀態，文字負責其適合承載的資訊。

## 尚未決定

- Hex、方格、向量碰撞或其他地圖拓撲。
- 小型角色採 sprite、符號、字圓或其他表現。
- 美術風格、色彩、材質、動畫密度與資產生成管線。
- 相機縮放範圍、跟隨方式、點地移動或其他精確操作。
- 戰鬥如何在地圖上呈現。
- 採用何種前端／遊戲引擎。

不得把上述未決項目藏進示意圖或原型，冒充使用者已拍板。

## 驗收句

玩家不讀場景散文，也能從 2D 大地圖看見自己在哪、附近有誰與什麼、
哪裡能去、什麼正在改變，並能直接介入世界。
