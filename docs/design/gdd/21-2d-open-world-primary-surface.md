## 2026-07-16 覆蓋

使用者指出「圖像會讓我多一個分心的項目」，並確認「好，回文字」。因此
本頁的 2D 大地圖、人形圓形加中文字、固定螢幕尺寸與點擊移動等決定，自此
只作歷史與素材。白塔半島、地理、位置、距離、路線、地形、人物、物件與
世界持續運作等事實仍保留；舊文字 UI 也不因回文字而自動復活。

## 背景

奇點世界最初已有 Top-down、城鎮與野外同一張大地圖、單一平面、
開放世界與全物件化等方向。2026-04 曾實作全螢幕 Hex Canvas 玩家地圖，
後續才轉向純文字 MUD 主畫面。

2026-07-13，使用者決定重啟最初概念：`2D 平面大地圖，開放世界`。
在「全螢幕可縮放大地圖／較近俯視 RPG／大地圖與區域近景兩層」三種
尺度中，使用者確認「原則上是 A」。

## 已決定

- 主要遊戲畫面是**全螢幕、可縮放的 2D 平面大地圖**。
- 世界所有人形生物（包含玩家與 NPC）均以**一個圓形，圓裡面一個中文字**
  直接存在地圖上。這是正式角色表現，不是等待替換的小人占位符。
- 地圖是玩家行走、觀察與接觸世界的主要遊戲表面，不是裝飾背景、
  場景插圖或只供查看的世界縮略圖。
- 遊戲維持開放世界；城鎮與野外屬於同一個連續世界，不退回房間清單。
- 操作仍以手機指觸為主，不要求輸入傳統 MUD 指令。
- 文字退到對話、狀態、互動選項、行動結果與必要局勢提示；文字不再負責
  讓玩家自行想像主要空間畫面。
- 人物在地圖上的位置與位移是**連續、順暢**的，不以格子為一步頓格跳動。
- **單擊走、雙擊跑**。每次點擊只指定一個目標點，人物由當前真實位置朝
  該點作一段直線移動。
- 直線上沒有阻礙時，人物走的是兩點之間的直接最短路；直線遇到牆或其他
  不可穿越實體時，就停在第一個接觸邊界，不自動繞路，也不自動沿牆滑行。
- 玩家若要繞過障礙，必須看地形再點擊新的中繼位置，從人物實際停下的位置
  重新指定下一段直線。
- 玩家與 NPC 共用相同的連續位移與碰撞物理；差別只在移動目標由玩家點擊
  或 NPC 決策產生，不能讓 NPC 的底層位移偷偷改成另一套穿牆或跳格規則。
- 大地圖可像 Google Maps 一樣放大、縮小；地圖內容隨鏡頭改變顯示比例，
  但**所有人形生物的圓形標記在螢幕上始終保持同樣大小**，包含玩家、
  其他玩家與 NPC。
- 這只是畫面如何畫出角色：角色在世界中的位置、實際碰撞範圍與移動距離
  不會因縮放而一起變大或變小。
- 探索的起點是**接觸**而非預設目的的「介入」：玩家看到有意義的物件，會
  想靠近、摸一下，看看世界是否有反應。這尚未決定接觸距離、手勢、提示、
  動作選單或觸發內容。

## 繼續保留

- 後端唯一數據真理。
- 玩家與 NPC 使用同一套世界規則。
- 世界永遠在線。
- 全物件化、插頭／插座動作語義、物件不可無中生有。
- 既有世界時間、位置、移動、NPC、物件與互動資料可作新主畫面的底層。
- `白塔半島` 初始地圖繼續作大地理正典，但它不是 runtime 比例尺、
  格網拓撲或美術風格定案。

## 被取代的方向

- 純文字 MUD 不再是主要玩家畫面或產品北極星。
- sprite、紙娃娃、具身小人或微浮雕人物等未核准提案，不再是現行角色
  表現方向；若未來重審，必須由新的使用者決定覆蓋本次「圓形＋中文字」。
- 現行文字描述主畫面只能作遷移素材、對話／回饋元件來源與歷史證據，
  不能再被當成新 UI 的既定外框。
- `重文字、輕畫面` 不再是現行畫面原則；現行原則是讓 GUI 直接承載空間、
  人物、物件與世界狀態，文字負責其適合承載的資訊。

## 尚未決定

- 世界位置的權威座標與空間拓撲；本次操作規則不偏向任何座標或分區方式。
- 人形角色圓形標記固定在螢幕上的確切直徑；圓形的線條、顏色、中文字的字義
  映射，以及選取／接觸／遮蔽等狀態如何改變外觀。
- 美術風格、色彩、材質、動畫密度與資產生成管線。
- 相機縮放範圍、跟隨方式、點擊與拖曳的判定門檻、雙擊判定時間。
- 步行／跑步速度、體力或其他代價、地形對速度的影響。
- 點擊正在移動的角色時，是追蹤該角色，還是只前往點擊當下的位置。
- 人物彼此碰撞時，停止、推擠與衝撞的精確結算。
- 戰鬥如何在地圖上呈現。
- 採用何種前端／遊戲引擎。

不得把上述未決項目藏進示意圖或原型，冒充使用者已拍板。

哪裡能去、什麼正在改變，並能直接接觸世界。
