# 14 第一階段可玩切片

## 定位

第一階段可玩切片不是北岸渡口特例，也不是大地圖完成度。它是一個能證明奇點玩法成立的局部世界。

第一階段可玩切片必須通過「玩家角度 × `../../DESIGN_KEYWORDS.md`」雙重驗收。玩家第一眼要能看懂自己是誰、在哪、身上有什麼、能做什麼；每個核心動作都要留下可讀世界差異。若玩家只看到合理設定、漂亮場景或小額跑腿，切片未成立。

## 外部研究校準

第一切片要同時證明十件事：

- UI 能讓玩家快速建立心智模型。
- 玩家第一屏能理解自身、位置、錢/持物/工具、明顯狀態與第一個可做動作。
- 文字是世界狀態的渲染，不是補空氣氛。
- 第一屏先證明一個簡單「非日常可為性」核心：玩家能做現實生活中不能、不能安全做、不能長期做、或不能被世界承認的事，且一個動作就能看見世界差異。
- 若第一屏使用元素，元素必須接到玩家自身、持物、工具、熟練、關係或位置，不能只當天氣/場景描述。
- 物件提供動詞，且 NPC 也能使用或改變。
- NPC 有目的、痕跡或記憶差異，不靠輪播台詞假裝活著。
- 經濟讓至少兩種玩法互相需要，而不是固定收購。
- 玩家每個核心行動都有可辨識且可整合的結果。
- 核心回圈有動機、行動、回饋、再目標與第二次變化。
- 五條起手路徑彼此有取捨，不是同一條賺錢路換皮。
- 玩家能從成功、失敗或錯過中學會世界規則。
- 起手切片至少覆蓋成就、探索、人際、競合/衝突四類 MUD 動機入口。
- 起手切片能反查 `DESIGN_KEYWORDS.md`，不是由局部地名、材料或 NPC 功能硬湊。

## 切片規模

第一版不要用下表要求一次全做。先做一個簡單核心動作；核心成立後，才擴成 3 到 5 場景的小切片。

最小核心：

| 層面 | 數量 | 要求 |
|---|---:|---|
| 自身錨點 | 1 | 玩家能看見自己的姓名/自身入口，並能點開 |
| 場景 | 1 | 玩家能看懂當前狀態，但場景不能取代自身錨點 |
| 核心入口 | 1 | 優先從玩家自身開始；若從場景物件開始，也必須先讓玩家知道自己有什麼 |
| 玩家動作 | 1 | 動作簡單、可理解 |
| 世界差異 | 1 | 錢、物、路、人、風險、關係或痕跡其中之一改變 |
| 回饋 | 1 | 畫面立刻說清楚改變了什麼 |
| 元素關係 | 0 到 1 | 若使用元素，只做一個能被玩家操作的局勢，不做完整元素系統 |

擴展切片：

| 層面 | 數量 | 要求 |
|---|---:|---|
| 場景 | 3 到 5 | 每個至少 2 個可用入口 |
| NPC | 3 到 6 | 至少 2 名可自主推進 |
| 核心物件 | 8 到 12 | 至少 5 個可改變狀態 |
| 工具 | 2 到 3 | 至少 1 個有熟練回饋 |
| 經濟流 | 1 到 2 | 有供需、NPC 參與與缺貨/成交 |
| 路線 | 2 條以上 | 至少 1 條安全、1 條不確定 |
| 風險 | 1 到 2 | 可避開、求援或承擔 |
| 維護物 | 1 到 2 | 可投入後重訪看到差異 |
| 離線安排 | 1 到 2 | 下次登入有結果 |

## 五條起手路徑

五條起手路徑是擴展目標，不是第一個核心動作的前置條件。

第一屏完成簡單核心後，才逐步讓玩家看見五條路：

1. 賺錢：有可理解需求與報酬。
2. 工具：取得或使用工具，打開動作。
3. 人際：某人有目的，可被幫忙、阻擋、跟隨或交易。
4. 探索：有不確定路線或線索。
5. 維護：有可改善的物件或場所。

每條路都要寫出代價：

```text
路徑：
非日常可為性：
立即收益：
立即代價：
可能錯過：
需要的資訊或準備：
第二次再做時的變化：
```

## 切片必備事件

至少要能發生：

- NPC 先玩家一步完成或改變某需求。
- 玩家使用工具讓物件狀態改變。
- 玩家因關係或信用得到不同結果。
- 玩家選擇安全路或風險路。
- 玩家離線安排產生成功或失敗。
- 玩家重訪看到上一輪痕跡。

## 第一屏玩家角度驗收

第一屏不是「把資料列出來」。它要讓玩家自然產生第一個選擇：

| 問題 | 通過標準 |
|---|---|
| 我是誰 | 玩家能看到自身入口，不把自己列成場景人物 |
| 我在哪 | 地點名通俗可懂，場景狀態說明此地正在發生什麼 |
| 我身上有什麼 | 鎂、手持/工具、明顯狀態與可用自身動作可查 |
| 我能做什麼 | 至少一個入口能讓玩家立即做出狀態改變 |
| 我為何要做 | 動作帶來目標、風險、關係、資訊、工具、收益或非日常可為性 |
| 做了差在哪 | 回饋說明哪個世界事實變了，而不只是新增一句 log |
| 世界是否等我 | NPC、時間、天候、路況或物件可在玩家不做時先推進 |
| 我會不會再玩 | 第一動作後出現下一個可理解目標或回訪期待 |
| 關鍵字是否成立 | 能追溯到文字 MUD、輕操作、全物件化、後端真理、NPC 同律、真實經濟、探索/冒險/經營/建造/戰鬥等關鍵字之一 |

## 不合格切片

- 玩家自身只能看見名字，不能點開或不能產生動作。
- 玩家不知道自己有多少錢、手上拿什麼、身上有什麼明顯狀態。
- 一開始就要求多入口、多系統、多回圈，卻沒有一個簡單動作好玩。
- 只有一條跑腿賺錢路。
- 只有採集與交料。
- 只有現實日常瑣事，沒有非日常可為性。
- 只有局部地名或局部場景慣性，看不出世界觀為什麼會生成它。
- 有元素名詞或天候描述，但玩家自身、持物、工具、NPC 與世界結果都沒有因此不同。
- NPC 只是看板或台詞。
- 物件不能被 NPC 使用。
- 沒有工具或熟練。
- 沒有風險。
- 沒有維護/建造。
- 重訪只換場景句。
- 選項沒有取捨。
- 回圈只能描述操作流程，不能解釋玩家為何想再做。
- 只服務賺錢，沒有探索、人際或衝突入口。
- 用沉浸、活世界、氣氛、合理等抽象詞替代玩家實際看到、能點、會變的內容。
