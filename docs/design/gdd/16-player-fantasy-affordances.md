# 16 玩家幻想與非日常可為性

狀態：細節設計草案，未經使用者拍板前不得視為定案
第一權威：`../../DESIGN_KEYWORDS.md`
研究對接：`../research/2026-06-19-player-fantasy-affordance-research.md`

## 定位

奇點不能只讓玩家做現實生活也能做、而且更瑣碎的事。

玩家進遊戲，是為了在另一個世界裡得到現實缺少的可為性：成為另一種身份、承擔可控風險、學會現實沒有的規則、改變局部世界、被 NPC 記住、留下痕跡、經營或建造現實中無法維持的東西。

這不是把玩家做成主角、救世主、超人或上帝。奇點的玩家仍是世界中的一個人，與 NPC 同規則。但這個「人」必須能做出現實生活缺少的事，否則玩家沒有進入奇幻世界的理由。

## 核心原則

> 奇點的遊戲吸引力來自非日常可為性，而不是日常事務模擬。

但非日常不等於複雜。第一版要先把非日常壓成一個簡單可玩動作：

```text
玩家看見一個狀態。
玩家點一個入口。
玩家做一個動作。
世界改變一個事實。
畫面回饋這個改變。
```

如果這個最小單位不好玩，往上堆 NPC、經濟、天候、材料、關係、離線安排，只會變成更大的無感。複雜只能從簡單核心長出來；不能用複雜掩蓋簡單核心不存在。

第一個簡單核心應優先從玩家自身開始，而不是從場景、NPC、貨物或天候開始。

```text
玩家看見自己的姓名/自身入口。
玩家點自己。
玩家看到：我在哪、我有多少錢、手上拿什麼、身上有什麼明顯狀態。
玩家做一個自身動作，例如握持、收起、整理、休息、等待、設定離線安排。
世界改變一個和玩家有關的事實，例如手持物、可用動作、時間、近期事件或離線狀態。
畫面回饋這個改變。
```

如果玩家連自己都不能先被看見、被點開、被操作，後面的場景再有氣氛也沒有代入錨點。

非日常可為性有四個必要條件：

1. **非日常**：現實不能做、不能安全做、不能長期做、不能被世界承認，或只能在極少數人生情境中做。
2. **可操作**：玩家用點擊、選擇、等待、使用工具、移動或交互親手做，不只是讀到。
3. **有規則**：不是任意許願；要受世界規則、工具、時間、風險、關係、材料與 NPC 反應約束。
4. **有後果**：錢、物、路、人、場所、關係、風險、知識或痕跡要改變。

## 奇點的玩家幻想不是什麼

- 不是玩家一出生就是英雄。
- 不是所有 NPC 都圍著玩家轉。
- 不是讓玩家隨口創造物件或技能。
- 不是把奇幻名詞塞進日常雜務。
- 不是純搬貨、純排隊、純買賣、純等船。
- 不是現實生活的低效版本。
- 不是只有「世界很活」但玩家做不了有趣的事。

## 奇點的玩家幻想是什麼

| 幻想類型 | 玩家得到什麼 | 必須落成的可玩行為 |
|---|---|---|
| 住進另一個世界 | 我不是讀者，是有位置的人 | 自身狀態、持物、錢、信用、稱呼、被記住 |
| 掌握奇幻規則 | 我能理解並利用現實沒有的物候/元素/材料 | 讀霧、避雷、烘乾、封路、處理異常材料、使用工具 |
| 介入活人社會 | 我能和不是任務機器人的人形成關係 | 讓位、阻止、幫忙、跟隨、交易、欠帳、被拒絕 |
| 改變世界物件 | 我能碰到的東西真的能被改變 | 拿、放、修、搬、堵、掛牌、佔用、破壞、保管 |
| 承擔可控風險 | 我能去現實不會去的危險處 | 冒險、避險、求援、撤退、救人、趁亂、承擔傷害 |
| 留下長期痕跡 | 我的行為下次還存在或被他人接手 | 路被修過、貨被拿走、NPC 記得、場所可用性改變 |
| 離線仍在世界裡 | 我不操作時角色也有世界位置 | 離線安排、錯過、回來看到結果或失敗 |
| 不是職業鎖死 | 我能靠工具、熟練與關係形成位置 | 不選職業也能成為熟路人、修具者、供貨者、引路者 |

## 第一屏吸引力門檻

第一屏先證明一個非日常可為性的簡單核心。

不是兩句設定，也不是一組大系統，而是一個玩家能立刻理解、立刻操作、立刻看到差異的入口。

這個入口的優先候選是玩家自身。

若這個核心使用元素，元素必須讓玩家得到現實生活缺少的角色可為性：以工具處理局勢、讓 NPC 承認、改變路況/貨況/場所、或留下回訪痕跡。只把元素寫成天氣、傷害顏色或身體感覺，不算非日常可為性。

```text
入口：
玩家平常做不到什麼：
玩家現在能做什麼：
需要什麼條件：
成功後世界哪裡變：
失敗/不做/被 NPC 搶先時哪裡變：
下次回來看見什麼：
```

第一個核心成立後，才往旁邊長出第二入口、NPC 競合、經濟流、離線安排或長期痕跡。順序不能反過來。

如果第一屏只有：

- 看場景。
- 等交通。
- 問價。
- 搬貨。
- 交材料。

那它仍然可能合理，但不夠吸引。它必須至少補上：

- 一個奇幻規則可被玩家利用。
- 或一個物件會被玩家改變。
- 或一個風險可以被讀出、避開或承擔。
- 或一個 NPC 會依同規則回應玩家。
- 或一個玩家痕跡會被世界保留下來。

第一版只需要先做成其中一個。不要一開始就要求全都成立。

自身起手的合格例：

```text
入口：姓名/自身入口
玩家平常做不到什麼：成為另一個世界裡有位置、有錢、有持物、會被世界時間承認的人
玩家現在能做什麼：查看自己，收起外露工具，改成空手/握持工具，或設定下線後先等候/休息
需要什麼條件：玩家確實有該持物或所在場所允許該安排
成功後世界哪裡變：手持物、可用動作、近期事件、離線安排或時間狀態改變
失敗/不做/被 NPC 搶先時哪裡變：工具不足、時間推進、錯過、人群或 NPC 先改變局勢
下次回來看見什麼：自身狀態、安排結果、錯過或新的可用動作
```

## 不同玩法的非日常承諾

### 探索

不是多走幾格，而是進入現實中不存在的規則未知區。

合格承諾：

- 玩家讀出某種霧、潮、風、獸徑、燈號或路標代表的規矩。
- 玩家靠地方知識找到安全路、捷徑、危險前兆或可交易消息。
- 第二次來時，玩家因已知規則而能做不同選擇。

### 冒險

不是去遠處看描述，而是進入平常不敢進的危險局勢。

合格承諾：

- 玩家能在前兆階段選擇準備、撤退、求援、跟隨或冒進。
- 危險不只扣血，也會改路、壞貨、失信、受傷、惹人、錯過。
- 冒險後玩家帶回錢、物、線索、傷痕、名聲或新的通行可能。

### 經營

不是把材料賣給固定板子，而是掌握現實難以掌握的供需與秩序。

合格承諾：

- 玩家能看出哪批貨短命、誰需要、誰先搶、哪條路能運。
- 玩家能用保存、加工、信用、委託、時間差賺到位置。
- NPC 也能成交、壓價、缺貨、爽約或搶先。

### 建造/維護

不是放建築格，而是讓世界承認玩家建立了可維持之物。

合格承諾：

- 玩家能修一段路、補一盞燈、掛一塊牌、整理一個泊位、清一條排水。
- 世界時間會磨損它，NPC 會使用或破壞它。
- 玩家回訪看到它被使用、變壞、被感謝、被佔用或被爭奪。

### 戰鬥/衝突

不是按攻擊鍵，而是承擔現實不能承擔的衝突風險。

合格承諾：

- 玩家能在戰鬥前看見前兆與選擇。
- 避戰、交涉、阻擋、求援、偷跑、先手準備都算玩法。
- 戰鬥後留下傷勢、目擊者、關係、物件、路線或組織後果。

### 社會

不是聊天，而是得到現實中很難快速形成的地方位置。

合格承諾：

- 玩家能從陌生人變成熟臉、可靠者、危險者、欠帳者或被防備的人。
- 稱呼、報價、通行、協助、拒絕與傳聞會變。
- NPC 不是服務點，而是也在維持自己的位置。

## 對北岸類場景的最低修正方向

北岸渡口這類場景若只剩候船、攤棚、搬貨、問價，就太日常。

它要成立，至少必須讓玩家看見類似下列非日常入口：

| 入口方向 | 非日常可為性 | 玩家動詞 |
|---|---|---|
| 雷暴/河霧前兆 | 讀出奇幻物候並改變交通/人群/貨物風險 | 看、問、等、改路、提醒、收工具、幫忙 |
| 活 NPC 競合 | NPC 不是等玩家點，而是會搶先成交、撤貨、停船、封路 | 讓位、插手、跟隨、阻止、求助 |
| 可改變物件 | 渡口物件不是背景，能改變局勢 | 整繩、遮貨、掛牌、清泥、搬開、修補 |
| 地方信用 | 玩家不是完成任務，而是被某些人記住 | 幫、拒、欠、賒、保證、被稱呼 |
| 離線安排 | 玩家下線後仍在世界裡 | 留守、等船、託運、看貨、休息、跟隊 |

這些不是要全部同時做，而是提醒：第一屏不能只問「這裡有什麼」，要問「玩家在這裡做了什麼現實做不到、且世界承認的事」。

北岸若要做第一個簡單核心，可以先只做一件：

```text
玩家看見雷暴前兆或濃霧壓岸。
玩家點一件可理解物件，例如鐵器、船繩、遮貨布、棚下乾處。
玩家選一個動作，例如收起、遮住、固定、等風、提醒。
世界只改一個事實，例如工具不再外露、貨不再受潮、船暫停、某 NPC 記住玩家提醒。
畫面明確回饋這個改變。
```

這比一次設計完整天候、經濟、人情、渡口秩序更重要。

## 寫作與設計禁區

- 不再把「常理化」寫成日常瑣事。
- 不再把奇幻壓成自然物理科普。
- 不再用搬貨小循環假裝經濟玩法。
- 不再用地名、攤名、材料名填補玩家幻想。
- 不再讓第一屏只服務一條賺錢路。
- 不再用大量入口、表格與系統要求掩蓋一個簡單動作不好玩。
- 不再用「世界在動」這種抽象話替代玩家可做的非日常行為。

## Runtime 前驗收

任何場景/切片進 runtime 前，至少要列出：

1. 本場景提供哪些非日常可為性。
2. 每個非日常入口對應哪個玩家動詞。
3. 哪些現實日常行為被轉成遊戲內有趣問題，而不是照搬瑣事。
4. 哪些 NPC 會同規則行動。
5. 玩家做或不做後，哪個世界事實改變。
6. 回訪時可見什麼差異。

若只答得出「這裡很合理」「這裡有生活感」「這裡有人群」，還不能進實作。
