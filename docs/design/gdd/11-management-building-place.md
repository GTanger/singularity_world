# 11 經營、建造與場所

## 經營定位

經營是讓某個人、物、地點、交易或路線持續運作。它不是單次交料，也不是開一個抽象面板。

## 經營行為

| 行為 | 玩家做什麼 | 世界改變 |
|---|---|---|
| 補料 | 把物資投入物件或場所 | 可用性、報價、NPC 行為 |
| 維修 | 用工具與材料改善狀態 | 場所功能、名聲、通行 |
| 掛牌 | 留下可被他人讀到的訊息/需求 | 委託、交易、秩序 |
| 佔用 | 暫時把物件/角落/路線作為用途 | 權限、責任、衝突 |
| 委託 | 讓 NPC 或離線角色做事 | 成功/失敗痕跡 |
| 守護 | 保護物件、人物或路線 | 風險、關係、報酬 |
| 分配 | 把工具、貨物、任務交給人 | 物流、信用、效率 |
| 處理元素局勢 | 點燈、排水、遮風、封路、清泥、收棚、隔離貨物 | 通行、保存、NPC 行為、報價、場所安全 |

## 建造定位

建造是世界狀態持續改變，不一定從房屋開始。第一階段應從小物件與場所功能開始。

可建造/改善：

- 路牌。
- 燈。
- 箱。
- 棚。
- 踏板。
- 門閂。
- 工具架。
- 告示。
- 臨時座位。
- 清出的通道。
- 燈架、排水溝、遮雨棚、標記樁、隔離箱、避險繩線。

## 場所設計

場所不是地名。場所是一組可持續狀態：

- 可用物件。
- 常來 NPC。
- 可發生的行為。
- 可維護項目。
- 歸屬與規矩。
- 風險。
- 經濟功能。
- 玩家過去痕跡。

## 維護週期

維護不應變成煩人日課。維護要提供選擇：

- 立即修：消耗物資，穩定效果。
- 暫時撐：便宜但有風險。
- 委託他人：花錢或人情。
- 放任：可能失去通行、信用或收益。

## 回訪差異

經營/建造最重要的是回訪看得出：

- 物件還在。
- 被人使用。
- 壞得更嚴重。
- 被修好。
- 有人留下反應。
- 產生新需求。
- 引發衝突或收益。

元素相關經營必須避免變成無聊日課。它只有在玩家能選擇立即修、暫時撐、委託、放任、利用或轉賣時才進核心。
