# 資源點與採集：框架連續與質變實作規範 v1.4

> **定位**：定義基於環境框架與質變分流的資源產出邏輯。
> **具名修訂**：Gemini (2026-04-08 物質質變與差異放大對齊版)。
> **核心準則**：原本怎麼長，仍舊怎麼長；但原本的差異將在富態化下被放大到極限。

---

## 一、 世界觀物理：多樣性分流與差異放大

### 1.1 從量變到質變 (Beyond Size)
*   **非單一巨型化**：富態化主視覺雖以體型突破為主，但不排除 **繁殖策略、防禦機制、壽命、共生** 等演化路徑。
*   **物質性狀重塑**：
    *   **植物類**：從纖維質向「肉質感 (Fleshy)」或「高能漿液」轉化。
    *   **礦物類**：從岩石態向「玉質化」、「琉璃化」或「金屬滲流」質變。
*   **觸感基調**：溫潤、飽滿、略帶黏滯、充滿張力。

### 1.2 框架連續性：水稻仍是水稻
*   **原本怎麼長，仍舊怎麼長**：物種的基礎適應性（如水稻需水、旱稻耐旱）保持不變。
*   **差異放大 (Diversity Amplification)**：富態化會將物種間原本細微的差異推向極端。水稻與旱稻的區分在富態化後將表現為完全不同的「物理質地」與「應用場景」。

## 二、 PostgreSQL 資料架構 (Single Source of Truth)

### 2.1 `resource_pools` (性狀分流與路徑)
```sql
CREATE TABLE resource_pools (
    id SERIAL PRIMARY KEY,
    key VARCHAR(50) UNIQUE NOT NULL,      -- 如 'wetland_fleshy_rice'
    kind VARCHAR(20) NOT NULL,            -- crop, ore, herb
    required_terrain VARCHAR(20),         -- 地形掛鉤
    phenotype_path VARCHAR(20),           -- 演化路徑: giant, jade, fleshy, liquid
    entries JSONB NOT NULL                -- [{"item_id": "spirit_paddy_rice", "weight": 100}]
);
```

### 2.2 `resource_nodes` (地圖資源節點)
*   保持電荷 (`charge_level`) 與環境危險度 (`danger_level`) 配置。
*   電荷 1.0 時，產物將展現最極端的「質變性狀」。

## 三、 採集體驗與產物

1.  **採集物之實體特徵**：
    *   採集獲得的是受 Token 滋養、性狀異化後的 **物種實體 (Luxuriant Specific Matter)**。
    *   **具象描述**：採集日誌應反映出該物種的「質地」變化，而不僅僅是數量。
2.  **剝名的定位**：
    *   對具有「特定性狀」的富態實體進行有序提煉。
    *   **混沌繼承**：產物的性狀（肉質、玉質等）會影響剝名時詞元傾向的生成（此處僅為機率偏向，仍遵循混沌烙印法則）。

## 四、 開發約束

*   **禁止通用材料化**：產物名稱必須反映其物種與性狀（如：`肉質靈米稻桿`，而非 `通用植物纖維`）。
*   **保持環境敏感**：資源點分布必須嚴格對齊地圖生成的植被與地質邏輯。
