## 一、 世界觀物理：聚念場悖論與脈衝收割

### 1.1 同頻相斥的力量
*   **Token 密度**：無人地帶 Token 輻射恆為 **1.0**。
*   **有念抑制**：有念生物存在的地格，其頻率磁場會物理性地排開 Token 輻射。人數越多，密度越低（`Density = 1.0 - (N * 0.1)`）。
*   **富態化累積**：物資的「增生」僅在 Token 密集（無人干擾）時發生。

### 1.2 採集策略：脈衝 (Pulse)
*   **積累期**：地格無人，`charge_level` 隨時間恢復至 1.0（富態過飽和）。
*   **收割期**：採集者進入。
    *   初入瞬間：密度高 + 電荷滿 = **爆發式產出**。
    *   持續停留：人體磁場排開 Token -> 密度觸底 -> 增生停止 -> **產量歸零**。
*   **撤離回填**：採集者必須離開，讓地格回歸無人狀態，Token 密度才能瞬間恢復至 1.0 重新開始增生。

## 二、 PostgreSQL 資料架構 (Single Source of Truth)

### 2.1 `resource_pools` (產出池)
定義 Token 烙印的混沌權重。
```sql
CREATE TABLE resource_pools (
    id SERIAL PRIMARY KEY,
    key VARCHAR(50) UNIQUE NOT NULL,      -- 如 'grassland_wild_herb'
    kind VARCHAR(20) NOT NULL,            -- mine, gather, liquid
    entries JSONB NOT NULL                -- [{"id": "raw_herb", "weight": 100}]
);
```

### 2.2 `resource_nodes` (地圖資源節點)
實體位置與電荷狀態。
```sql
CREATE TABLE resource_nodes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    hex_q INTEGER NOT NULL,
    hex_r INTEGER NOT NULL,
    pool_id INTEGER REFERENCES resource_pools(id),
    charge_level REAL DEFAULT 1.0,        -- 電荷量 (富態化程度)
    danger_level REAL DEFAULT 0.0,        -- 環境原生危險度
    active BOOLEAN DEFAULT TRUE,
    UNIQUE(hex_q, hex_r)
);
```

## 三、 採集行為定義

1.  **被動放置 (Gathering State)**：
    *   行為不是「挖掘動作」，而是實體插進地格中，成為 Token 坍縮的受體。
    *   消耗：持續消耗「念 (Magnesium/Mental Energy)」以維持坍縮場。
2.  **產出結算**：
    *   `Yield = charge_level * current_density`。
    *   每提取一次物資，`charge_level` 降低。
3.  **剝名接口**：
    *   採集物為 **材料 (Raw Tokenized Matter)**。
    *   **無定性**：屬性在「剝名」完成前不存在。禁止在採集階段預設材質標籤影響後續功能。

## 四、 嚴禁事項

*   **嚴禁 JSON 更新**：資源點的新增／修改必須透過 SQL 執行，嚴禁編輯 `data/*.json`。
*   **嚴禁實體累積**：資源點不應在地圖上顯示「生長動畫」或「倒數計時」；它是一個隱形的「電荷強度」。
