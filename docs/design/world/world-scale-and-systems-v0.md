## 本檔要修正的錯誤

先前內容過度圍繞單一局部場景。那會讓地圖像無根浮萍：有地名、有物件、有 NPC，卻看不出它為什麼必然從奇點世界長出來。

本檔規定：地圖不得從某個漂亮地名、某張場景卡、某個交易點往外補。地圖必須從世界觀生成：

```text
DESIGN_KEYWORDS.md
-> world-foundation-v0.md
-> world-energy-evolution-root-v0.md
-> world-bible-v3.md
-> 時間/歷史/沿革/變遷形成的現在態
-> M0/M1/M2 世界尺度與地帶
-> M3 人類活動與秩序區
-> M4 玩家站入場景
-> 玩家畫面上的人、物、路、狀態、可做事
```

`world-bible-v3.md` 是當前世界本體入口；`world-bible-v1.md` / `world-bible-v2.md` 只作舊素材與反面檢查；`world-content-bible-v1.md` 只能作為局部內容樣本，不得作為地圖生成根。任何後續地圖、命名、場景、NPC、物件，都要先通過 v3 的能量地質、公共節點、生活密度、事故歷史、生態能流、社會排除與本檔的世界根追溯。

## 背景設計門檻

地圖生成前必須先通過背景設計門檻。這不是新增流程，而是防止把局部素材誤當世界根。

任一 M1/M2/M3/M4 若缺下列背景輸入，不得進一步命名、寫場景卡或進 runtime：

| 背景輸入 | 必須回答 | 失敗症狀 |
| --- | --- | --- |
| 世界本體 | 這個地方如何來自 `world-bible-v3.md` 的衡界、普供時代、深時演化、主供環/低供帶/封存谷/聚能林/散能海岸/斷流高地、公共系統、制度矛盾與玩家身份 | 地點像現實鄉鎮加氣氛詞，或退回舊中河/北岸局部素材 |
| 世界根命題 | 這個地方如何來自生機過剩的常理化奇幻世界 | 地點只有功能，沒有世界本體來源 |
| 元素/材料規則 | 哪些元素狀態、材料族群或物候會改變路、貨、工具、人或戰鬥前判斷 | 奇幻只剩描述，玩家不能做現實做不到的事 |
| 深時與地貌 | 地形、水系、礦脈、草場、潮線或林澤如何形成這個位置 | 地圖名只是作者覺得好聽 |
| 生態與過剩 | 哪種生機正在越界，若無人維持先壞什麼 | 場景沒有壓力，也沒有維持理由 |
| 文明沿革 | 人群如何把此地壓成可站、可過、可存、可交易的秩序 | NPC 變成站樁或商店 |
| 近期/即時歷史 | 今天、上一 tick、上一動作讓人、物、路、價、規矩變成什麼狀態 | 場景像靜態房間，回訪沒有差異 |
| 物資流 | 哪些物進來、停留、變質、加工、被承認價格、離開 | 交易變成收購表或材料百科 |
| NPC 在場理由 | NPC 在維持什麼邊界、帶著什麼責任、玩家不介入時下一步做什麼 | NPC 只會隨機台詞或等玩家點 Talk |
| 玩家第一動詞 | 玩家用自身、工具、錢、時間、關係或風險能先改變哪個世界事實 | 玩家讀得到世界，卻不知道玩什麼 |
| 非日常可為性 | 玩家在現實不能、不能安全、不能長期、或不能被世界承認地做什麼 | 內容合理但無聊，只是在替 NPC 排班 |

若背景輸入不足，正確處理是退回 `world-foundation-v0.md` 補背景，不是補幾句場景描述。

### 背景到地圖的推導式

合格地圖節點應能用下列句式寫出：

```text
因為這個世界的 [世界屬性/元素狀態]，
在 [深時地貌/生態過剩] 中形成 [地貌或材料條件]；
人群為了 [站住/通行/保存/交易/避險]，
沿革出 [邊界/工序/制度/職業/物件]；
今天因 [近期事件/天候/上一動作/NPC 行動]，
此地呈現 [現在態]；
玩家可先 [動詞]，
改變 [人/物/路/錢/信用/風險/時間]，
並在回訪時看到 [持續/衰退/被處理/新風險]。
```

寫不出這段，該節點只能留在素材池。命名、路線、NPC、交易與物件都不能先行。

## 玩家層目標

玩家不需要知道設計表，也不需要讀背景年表。但玩家踏入任一地點時，畫面上的土地、路、人、物、規矩與可做事必須是世界時間演算到此刻的現在態，而不是硬放上去的房間：

- 這裡屬於某種大尺度地帶。
- 這裡的地貌、道路、人群與制度是如何沿革到今天這個狀態。
- 這裡正在維持一條邊界。
- 這裡有某種過剩生機、物候、材料或人群壓力。
- 這裡的人不是等玩家點擊，而是在處理自己站住此地的理由。
- 玩家可以用自身、工具、金錢、關係、時間或風險，改變一個局部事實。

如果玩家只能讀到地名和功能，地圖不合格。
如果歷史只是一段背景說明，不能推導當前地面狀態、NPC 行程、物件狀態、路況、價格、規矩或下一次觀測差異，地圖也不合格。

## 生成順序

### 0. 不從地名開始

不得先問：

- 下一張地圖叫什麼。
- 玩家下一步去哪個場景。
- 這裡要放哪個商人。
- 這裡缺什麼材料。

必須先問：

- 這個地點由哪個世界屬性生成。
- 這個地點的現在態由哪幾層時間鏈推到此刻。
- 它屬於哪個大尺度地帶。
- 它維持什麼邊界。
- 它讓什麼人、物、錢、消息、工具或風險流動。
- 玩家站進去後能改變什麼。

### 3. M2：局部秩序區

M2 是人把大地壓成可用秩序的範圍。每個 M2 必須回答：

| 欄位 | 必填內容 |
|---|---|
| 所屬 M1 | 來自哪一個或哪幾個大尺度地帶 |
| 維持對象 | 路、泊位、倉、田、渠、門、棚、路標、工作面、熟臉秩序中的哪一項 |
| 壞掉順序 | 無人維持時，先壞視線、通行、保存、價格、工具、信用還是安全 |
| 主要人群 | 誰每天來，誰偶爾來，誰會被排除在外 |
| 物資流 | 哪些物品進來、停留、變質、加工、離開 |
| 玩家入口 | 玩家作為外人能先被允許碰哪件事 |
| 時間鏈 | 此地今日狀態由深時、生態、文明、近期、即時哪幾層變化造成；即時層要能回答前一秒、上一 tick 或上一動作改變了什麼；不介入時下一步怎麼變 |

### 3.1 M2 代表秩序區骨架

### 4. M3：人類活動帶

M3 是一組職責相連的活動，而不是一張玩家房間。

M3 的命名應該用尺度指標，不用奇怪縮寫詞。命名原則：

- 說清它是哪種活動帶：渡口、稻地、礦場、工坊、牧地、倉場、城門、驛道、港口。
- 說清它的相對位置或地貌：北岸、東湖、南城外、西坡、河口。
- 不使用半文半白、功能壓縮、只有作者懂的詞。
- 名稱會引導後續設計；尷尬名稱會長出尷尬玩法。

### 5. M4：玩家站入場景

M4 是玩家讀到、點到、移動到的場景卡。M4 必須填完：

| 欄位 | 驗收問題 |
|---|---|
| 玩家視角名稱 | 玩家能不能一眼理解自己站在哪 |
| 所屬 M1/M2/M3 | 能否回追到世界帶與秩序區 |
| 靜態骨架 | 地貌、建物、路、工作面中哪些是穩定存在 |
| 動態狀態 | 今天的天候、物候、人流、貨況、路況、缺席或痕跡是什麼 |
| 時間/歷史現在態 | 造成當前狀態的時間鏈是什麼：深時、生態、文明、近期、即時各取必要者；即時層必須能接上一秒、上一 tick 或上一動作；歷史不是殘留物，而是此刻人、物、路、價、規矩與動詞成立的成因 |
| 正在延續的變化 | 玩家不介入時，哪個人、物、路、價格、風險、天候或規矩會繼續往下變 |
| 在場人物 | 這些人為什麼在這裡，不點玩家時他們會做什麼 |
| 核心物件 | 哪些東西不是裝飾，而能被看、拿、用、修、交易、阻擋或避開 |
| 出口 | 出口為什麼存在，路況或條件是什麼 |
| 玩家第一動詞 | 玩家可先做的一件簡單事是什麼 |
| 世界事實變化 | 做了之後哪個物件、路、人、錢、信用、時間或風險改變 |
| 回訪差異 | 下次回來能看到什麼持續、衰退、被他人處理或新風險 |
| 關鍵字追溯 | 對應 `DESIGN_KEYWORDS.md` 哪些關鍵字簇 |

缺任一項，不得稱為完成的可玩場景。

## 地圖節點驗收清單

任一新地圖節點、命名提案、場景卡、路線或具名內容包必須先過以下檢查：

1. 能追溯到 `DESIGN_KEYWORDS.md` 的具體關鍵字，不只寫「深度沉浸」。
2. 能追溯到 `world-foundation-v0.md` 的至少一個世界屬性。
3. 能標明 M1 地帶，若跨地帶，說明交界張力。
4. 能說出它維持哪條邊界，以及邊界失守時先壞什麼。
5. 能說出當前狀態由哪幾層時間鏈生成：深時、生態、文明、近期、即時，不需五層全滿，但不能沒有時間成因；若是玩家可站入 M4，必須回答上一秒、上一 tick 或上一動作留下什麼事實。
6. 能說出至少一種物資、工具、消息、人群或風險流過。
7. 能說出至少一個 NPC 為什麼在場，以及玩家不介入時他會怎樣。
8. 能說出至少一個核心物件的狀態、動詞、成功、失敗與回訪差異。
9. 能說出玩家第一個簡單可點動詞，以及它改變的世界事實。
10. 能說出非日常可為性：玩家在現實不能、安全上不會、或無法被世界承認地做到什麼。
11. 命名通俗、可定位、符合玩家視角，不靠怪詞硬撐。

未通過者只能放在素材池，不得進入玩家可玩地圖。

## 既有地圖清冊的降格與重審

`../奇點世界場景骨架清冊.md` 目前是已落地或曾驗收的場景庫與工程進度清冊，不等於世界觀生成後的合格地圖正典。

它的 119 個可站入目標需要重新做三層標註：

| 標註 | 意義 | 後續處理 |
|---|---|---|
| 可保留 | 能追溯世界屬性、M1 地帶、邊界、NPC 工作、物件動詞與回訪差異 | 保留並補足缺欄 |
| 待重命名 | 地點功能可保留，但名稱半文半白、壓縮或玩家視角不明 | 先改名再補場景卡 |
| 降為路骨/素材 | 只有連接、散文或功能，缺可玩世界事實 | 不當作完成地圖 |

重審前，不得把「已經有很多格」等同於「地圖已完善」。數量不是地圖根性，世界觀追溯才是。

## 與北岸內容包的關係

`world-content-bible-v1.md` 保留為第一個局部內容包範例，但必須服從 `world-bible-v3.md` 與本檔：

- 它不能再往外推導整張地圖。
- 它不能證明世界已經成立。
- 它只示範一個 M4/M3 切片如何長肉。
- 若北岸相關名稱、物件、交易或路線無法通過 v3 驗收表與本檔驗收，仍要改名、降格或重寫。

北岸可以是一個例子，但不能是世界的根。

## 後續拆工方向

完整世界地圖 v1 已降格為舊包素材。`world-map-complete-design-pack-v2.md` 已依 `world-bible-v3.md` 建立；本檔仍保留地圖生成驗收方式，但不得繞過 v3/v2 直接拆舊包。

1. 從 `world-map-complete-design-pack-v2.md` 選一個主供、低供、封存、聚能、散能或斷流地帶，拆成可審查種子資料。
