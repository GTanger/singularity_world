# 開放式個人能量運用框架 v0

狀態：2026-06-24 聯合創作收斂紀錄。這不是 runtime 規格，也不是完整世界聖經；用途是防止後續把「能量充沛」誤收斂成元素表、咒語表、職業表或單一戰鬥體系。

## 已收斂

- 之前由 Codex 產出的世界稿、地圖包、材料包、勢力包與衝突包仍只作素材庫，不作現行正典或續寫入口。
- 若使用「能量充沛」，窄義是：這個世界會走向**個人運用能量的發展**。
- 這裡的核心不是「能量種類不同」，而是**運用能量的方式不同**。
- 2026-06-24 補正：這個核心要回到最初奇點世界的 **萬人萬相**。簡單說就是沒有任何一個人是一模一樣的；同一套功法，學起來、用起來都不同。可用《哈利波特》護法咒作比喻：同一個咒，但每個人的護法不同。這不是要建立新分類表。
- 2026-06-24 補充：功法不是把人分類的盒子，而是共同文本與共同起點；萬人萬相不是換特效、外觀隨機化或同招改色，而是個體底層差異會滲進理解、訓練、出手與結果。制度可以命名、教學、考核與粗略歸類，但不能窮盡或凍結一個人的相。可壓縮成：**同法不同相；制度教法，個體成相**。
- 2026-06-24 勝負補充：沒有抽象意義上永遠最強的咒語，只有在某個人、某個時刻、某個問題面前最恰當的咒語。功法也許有優劣，但決定強弱甚至輸贏的不是只看功法；人的相、理解、熟練、臨場判斷、對手、環境、時機、代價承受與是否用在恰當之處，都會改變結果。可壓縮成：**功法有高下，勝負無定式**。
- 2026-06-24 恰當性補充：恰當不是沒有強弱，功法優劣也不只看威力。穩、快、省、隱蔽、易教、容錯、後勁、代價、失控風險與能否在複雜環境維持作用，都可以是優劣。相性比等級更活：人與功法、人與情境、功法與目的都可能相合或相斥。成熟不是只會更強，而是知道何時不用、少用、慢用、借物用、借地用、借人用，甚至讓對方失去出手條件。
- 2026-07-03 尺度補充：這個世界的修行修煉不是那種動輒毀天滅地的類型。這不是把修行寫弱，也不是禁止強者、危險能力或重大事故；而是後續不能把修行價值預設成破壞規模、破壞範圍、天地異象或壓倒性戰力。修行的核心仍回到個人如何更恰當、更精準、更穩定、更能承擔代價地運用能量。
- 2026-07-03 衝突來源補充：這個世界不是只有人跟人的戰鬥。人對人只是其中一種情況；世界本身、環境、危地、非人對象、物件狀態、事故與能量作用，都可以形成玩家或 NPC 需要處理的衝突。
- 2026-07-03 壽命補充：無修行的人平均壽命就超過兩百壽。這是世界的基本壽命尺度，不是修行者專屬福利；修行不能被寫成單純求長生，也不能回到「無修行者短命、修行者長生」的套路。
- 不建立單一大體系來限制世界。後續不能把奇點世界壓成一張元素克制表、一套咒語決鬥文化、一組職業分類，或「法師 vs 武者」的粗分。
- 「武者」暫不作正向用語，因為它容易把非咒語型能量運用誤讀成蠻力。
- 參考作品只作功能參照，不作模板：
  - 《哈利波特》可參考的不是元素魔法，而是個人能力如何變成教育、法律、工具、考試、職業、禁忌、黑市與社會承認。
  - 《魔戒》此處可參考的不是魔法世界，而是權柄：合法性、腐化、負擔、承認與支配。
  - 《杖與劍》可參考的是主流能量能力被制度化後，如何排除不合主流的人；不可簡化成劍是蠻力、杖是魔法。

## 開放框架

同一個世界、同一種可被運用的能量，因為每個人都不一樣，所以同一套功法、同一個老師、同一種訓練，落到不同人身上也會學成、用成不同樣子。

後續討論可以有功法、學院、門派、考試、標準教材與制度命名；但這些只是共同文本、外部整理與教學管理，不是抹平個體差異的世界真理。不要把萬人萬相拆成器物路徑、語言路徑、場所路徑等路徑表，也不要把它做成換皮特效或外觀隨機化。

功法與能力可以被評鑑、比較與排名，但排名只能提供制度上的參考，不等於世界真理或勝負保證。高等功法可以帶來優勢，不能保證勝利；普通功法在正確的人與情境裡，也可能比名門大法更恰當。

能量運用也不只服務戰鬥。同一套能力可能用於攻擊、防守、救人、封鎖、修復、偵查、搬運、遮蔽、溝通、立信或取證。很多時候恰當性不是「贏」，而是達成目的且代價可承受。

戰鬥與衝突不只來自人跟人。人與人、非人對象、環境、危地、物件狀態、事故與能量作用都可以形成衝突；但這裡不建立完整分類表，也不把非人衝突收斂成怪物狩獵或刷怪掉寶。

修行修煉不是以毀滅規模證明境界。更強不等於更像天災；更成熟往往是更穩、更準、更省、更能控制代價，也更知道什麼時候不該出手。

無修行者平均壽命已超過兩百壽，所以修行不是單純求長生。長壽是世界常態之一，修行要處理的是如何運用能量、如何成相、如何承擔代價，而不是讓短命者第一次接近長生。

## 禁止回退

- 不把「能量充沛」寫成環境肥沃、富態生長、能量像空氣、人人被動受氣或人人修士。
- 不把能量寫成電力、供應、接入、斷供或治理資源。
- 不把開放式能量運用壓成常見元素系統。
- 不把衝突預設成咒語對決。
- 不把戰鬥寫成只有人與人的決鬥、PvP、NPC 互打或咒語對轟。
- 不把非人衝突直接收斂成怪物狩獵、刷怪、掉寶或副本。
- 不把非咒語型路徑命名成武者或蠻力職業。
- 不把萬人萬相解讀成反制度、反功法、人人獨創路徑，或可列舉的運用方式分類。
- 不把萬人萬相寫成換皮特效、外觀隨機化，或一組可預先列完的人格／能力模板。
- 不把功法排行、咒語強度或稀有度寫成唯一勝負因子。
- 不把恰當性寫成所有功法平等、低階必然逆天，或一切能量運用都導向戰鬥勝負。
- 不把修行修煉寫成動輒毀天滅地、只看大招、戰力膨脹或以破壞規模證明境界。
- 不把修行寫成「無修行者短命、修行者長生」的套路。

- 同一套功法在不同人身上，哪些差異應該可被玩家/NPC 觀察到？
- 制度、學院、門派或考試如何教同一套東西，卻仍承認或誤判人的不同相？
- 玩家/NPC 的 SoulSeed、體質、經歷、理解、習慣與情緒，哪些會影響同法異相？
- 玩家如何看出一個人不是只會大招，而是懂得何時何法最恰當？
