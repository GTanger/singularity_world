## 本檔定位

本檔曾用來補「完整可讀、禁得起檢驗的奇幻世界」這個缺口，但後續審查指出：它的年代感與語彙仍偏原始/低技術，且沒有把「能量充沛」設計成貫穿演化史與文明井噴的世界根。因此本檔現在只保留為舊素材與反面檢查；當前世界本體入口已改為 `world-bible-v3.md`。

本檔不是小說正文，也不是分類框架。它必須做到：

- 讀者能知道這個世界大致長什麼樣。
- 任一具名土地、制度、材料、勢力、人物原型都能追問「為什麼」。
- 奇幻元素不是氣氛，而是改變文明、職業、交通、交易、戰鬥、建造與角色扮演的世界事實。
- 玩家不需要讀本檔，但玩家踏入任何地點時，能從地名、物件、路況、NPC、價格、禁忌與回訪差異讀到本檔的存在。

## 世界名稱與尺度

遊戲外名稱是「奇點世界」。遊戲內一般人不會把世界稱為奇點；玩家第一版能接觸的可讀世界稱為「中河諸帶」。

| 層級 | 名稱 | 定義 |
|---|---|---|
| 世界本體 | 已知世界 | 人們知道自己活在同一片大地、河海與遠方互通的世界裡，但沒有人掌握全貌 |
| 第一版可讀世界 | 中河諸帶 | 以中河為骨架，連接北岸渡口、東湖水倉、西坡礦場、中鎮、南城、石門城邦、北驛長路與海門港 |
| 核心地理動脈 | 中河 | 從西北坡地與北林水網匯下，穿過中鎮與南城外田渠，最後在海門入潮 |
| 遠方邊界 | 潮外、北林深處、西坡高脊、南城內圈以南 | 可被傳聞、票據、外地客與路隊帶進玩家世界，但第一版不必全域可走 |

「中河諸帶」不是小村，也不是一張局部地圖。它是玩家能讀懂的第一個世界尺度：河流、沃野、礦坡、林澤、城鎮、遠路、海口七種地帶互相咬合，任何一帶出問題都會改變另一帶的路、價、人和風險。

## 創世與自然根

這個世界沒有統一的創世教條。不同地方有不同說法，但所有說法都承認一件事：世界不是空地等人居住，而是一片過旺的活地。

世界底層有四種常理化元素性：火、水、風、土。它們不是神名，也不是職業系。它們是世界物質被人理解、加工、避讓和利用的方式。

| 元素性 | 世界事實 | 文明後果 |
|---|---|---|
| 火 | 乾燥、燃燒、焦化、鍛造、驅霧、失控 | 火帶、守夜、工坊、鍛爐、燈架、焦痕責任 |
| 水 | 河流、潮線、霧、濕貨、返潮、腐壞、保存 | 渡船、水倉、田渠、濕貨棚、鹽包、候潮規矩 |
| 風 | 聲音、氣味、霧散、火勢、路訊、遠行前兆 | 路旗、守夜聲號、船期判斷、林澤導引、傳聞擴散 |
| 土 | 承載、礦脈、坡、牆、泥、根系、坍塌 | 礦場、城門、田埂、排水、倉基、標記樁 |

四種元素性彼此牽扯，造成「生機過剩」的世界基線。草木長得快，水氣回來得快，路會被泥、根、獸徑和人群重新寫掉；礦坡給工具材料，也吞工具與人；港口帶來外貨，也帶來語言、匯差和封條。

人類文明不是征服世界，而是每天把世界暫時壓成可走、可住、可存、可交易、可相信的狀態。

## 大地貌

### 中河

中河是中河諸帶的脊骨。它不是單純水道，而是通行、濕貨、船序、傳聞和規矩的瓶口。中河水氣重，入夜和清晨常有河霧；霧不是美術氣氛，而會改變誰能看見船、誰能辨牌、誰敢下踏板。

中河為什麼重要：橋梁不是預設答案。水位、霧、貨壓、維護成本與船戶規矩讓渡船和泊位長期存在。只要中河船序變動，東湖水倉、北岸渡口、中鎮倉井和南城外田渠都會收到波動。

### 東湖與霧草澤

東湖在中河東側，是水網、魚貨、蘆草和濕路的交界。東湖邊的蘆草不是「雜草材料」，而是乾棚、包貨、遮棚、箭桿、墊材和水邊生活的基礎。霧草澤更深，路會被水、根和獸徑改寫；沒有引路人、火帶、導引繩或路標，玩家不該把它當普通野外格。

東湖為什麼有水倉：魚貨與蘆草都短命，必須分揀、曬、封、寄放，才會變成能去中鎮或南城的貨。水倉不是倉庫貼圖，而是讓濕東西被世界承認的門。

### 西坡與山陰道

西坡是礦脈露頭與坡道交疊的地貌。石料、粗鐵、銅礦、錫砂、石灰石從這裡進入工具與城鎮建造；但西坡的粉塵、坍塌、裂柄工具和裝車線堵塞，讓每一批粗料都帶責任。

西坡為什麼不是採集點：人必須支柱、洗礦、分選、標記、裝車、修具，才能把山體變成材料。玩家不能只「挖礦」，而是碰到工具、信用、危險和交付責任。

### 南城平野

南城外是灌渠、稻地、草場、穀場與畜路。平野看似開闊，實際上由水權、田埂、草場界、畜欄和季節工序切成許多細邊界。水閘開錯時段，不只是田濕一點，而會改變穀價、畜力、草料和倉場排程。

南城為什麼能大：不是因為它神聖，而是它能吞吐糧、工具、人力、倉票與外來貨。南城越大，外人越容易被規矩分流，也越難直接碰到核心制度。

### 中鎮

中鎮不是英雄城，也不是新手村。它是中河諸帶的緩衝器：渡口壓力、礦坡粗料、東湖濕貨、南城糧流、遠路消息都會在井、倉、工坊、告示和街線上被重新承認。

中鎮為什麼重要：它把「能不能用」變成「誰承認可用」。修具、寄放、問人、掛牌、找保證，都在這裡變成玩家能理解的社會操作。

### 石門城邦

西部城邦的玩家可讀名是「石門」。石門不是王都，而是一座把坡道、遠路、粗料、通行牌和申訴制度壓成短規矩的城邦。它的城門、券道、兌牌桌和議棚前階，讓外人一入境就知道自己被放在哪條線。

石門為什麼存在：西坡材料和遠路通行都需要硬規矩，否則粗料不進工坊，路隊不敢承擔，礦場事故無人負責。石門因此成為礦坡、遠路和中鎮之間的制度鉸鏈。

### 北驛長路

北驛長路不是連接線。它由驛棚、水袋架、路旗、夜宿點、巡路班、車轍和商隊時刻組成。離開熟地後，玩家玩的是補給、同行、錯過、封路和局部知識。

北驛為什麼吸引玩家：在現實不會長期徒步冒險的人，可以在這裡成為守夜者、熟路人、報信者、跟隊者或風險處理者，並被世界承認。

### 海門港與潮外

中河入海處稱「海門」。海門不是異國風情背景，而是潮線、稅棚、翻譯桌、船行、外貨箱、匯兌屋和封條共同形成的門。外地規矩從潮外進來，先改變的不是世界觀名詞，而是玩家眼前的一批貨能不能放行、誰願意翻譯、哪張票據不被收。

潮外目前只作遠方邊界。玩家可以聽見潮外商、看見外貨、碰到語言和票據，但第一版不需要讓玩家航向整個外海。

## 文明源流與歷史分期

### 1. 無樁期

最早的人群沒有城，也沒有穩定路。他們只在水退、霧散、草勢低、獸徑安靜的時候短暫通過。這一段留下的不是遺跡，而是後來所有禁忌的根：不要相信無人維持的路。

現在狀態：野外舊路、林澤標記、巡路規矩都把「路會消失」當成常識。

### 2. 立樁期

人們開始在河邊、田渠、霧草澤和坡道立樁。樁不只是木頭，而是告訴別人這裡有人維持、有人負責、有人會追究。立樁期出現守夜、火帶、導引繩、乾棚、田埂和簡單水閘。

具名事件：第一次中河退樁。三日霧後，北岸一排舊樁被水草和泥整排吞掉，後來船戶行規定霧季樁位必須有人認領，不認領的泊位不得排船。

現在狀態：渡口泊位、水位牌、路標樁、草場界樁都帶有責任，不是可隨意挪動的場景物。

### 3. 路倉期

道路和倉場讓短命材料變成可交易貨。人們學會分選、封條、寄放、作保、承擔損耗。中鎮在此期成形，因為它正好能把河、湖、坡、田、路的貨集中重新承認。

具名事件：中鎮開倉。當年東湖魚貨與南城濕穀同時壓到中河，單靠口頭承認已經不夠，第一批外秤、封條、寄放位和倉保人因此出現。

現在狀態：倉場聯保能改變報價、通行與信用；貨物不只是背包物品，而是帶來源、封條和責任。

### 4. 石門成律期

西坡事故頻發，路隊與礦作互相推責，石門城邦把通行牌、券道、兌牌桌、議棚申訴和礦坡責任寫成短規矩。石門的規矩不一定溫和，但能讓礦料、工具、路隊與補給不至於每次都從頭吵起。

具名事件：七梁斷年。西坡坑口七段支梁在一個雨後月內連續斷裂，粗料倉拒收未標記礦料。此後西坡粗料必須有來源標記，修具棚能拒絕來路不明的裂柄工具。

現在狀態：玩家在西坡、石門和工坊街會遇到標記、支柱、裂柄、責任與保證，不會只遇到礦石採集。

### 5. 海門開潮期

海門港讓潮外貨進入中河諸帶，也帶來語言、匯兌、稅、封條和外地保證。海門沒有統治整個世界，但它讓中河諸帶知道「外面有別的規矩」。

具名事件：空箱封潮。一批潮外箱在無翻譯保證下被放入遠洋倉門，開箱時只有濕木和石粉。此後海門稅棚要求貨樣、翻譯與匯兌記錄相互作證。

現在狀態：海門港的一切外貨、票據、翻譯與稅棚扣貨都不是裝飾；玩家可以被語言、票據或封條擋住，也可以在其中作保、辨貨、翻譯或搬運。

### 6. 維持期

現在的中河諸帶不是完成世界，而是每天正在維持的世界。沒有最終安全區，只有暫時被守住的路、門、倉、價、信用和人際位置。

現在壓力：

- 東湖返潮早於常年，乾棚位置開始不夠。
- 西坡粗鐵含雜增加，工坊街修具排程延誤。
- 南城外田渠爭水，使糧車與草料價都在變。
- 北驛長路有一段路旗被改向，巡路班與引路人互相指責。
- 海門稅棚扣下一批潮外箱，南城商會急著找保證。

這些不是任務清單，而是現代局勢。玩家站入任何一處，都可能撞到其中一條壓力的末端。

| 潮外 | 遠方 | 外貨和外地規矩來源，第一版只需傳聞與貨物接觸 | 外地客、票據、貨樣、翻譯需求 |

## 族群、語言與稱呼

本作第一版不先做複雜種族表。人群差異先從土地、工作、語言習慣、信用圈和禁忌長出來。

| 群體 | 來源 | 他們如何被玩家讀到 |
|---|---|---|
| 河岸人 | 中河兩岸 | 看水位、認船戶、在霧裡說話短，對亂碰繩牌很敏感 |
| 澤路人 | 東湖、霧草澤、北林舊路 | 會看返潮、路標和獸徑，不輕易保證「這條路一定能走」 |
| 坡作人 | 西坡礦場與粗料倉 | 重視標記、支柱、工具狀態，不信漂亮承諾 |
| 田渠戶 | 南城外田渠與草場 | 以水時、草界、畜牌與季節工序判斷外人 |
| 城倉人 | 中鎮、南城、石門 | 認封條、外秤、票據、保證人和排隊位置 |
| 遠路人 | 北驛長路、邊鎮、商隊泊位 | 重視水袋、路旗、守夜、同行信用 |
| 海門人 | 河口、港口、遠洋倉門 | 習慣票據、翻譯、稅棚、外貨樣和匯差 |
| 潮外客 | 外海與遠方 | 語速、票據格式、貨樣習慣不同，常需要本地保證 |

通用交易語可暫稱「河話」。河話不是文化總稱，而是中河諸帶貨物、路隊、倉場、稅棚都能勉強使用的低歧義口語。石門券文、海門票語、澤路標記歌、田渠水時名，是玩家後續探索時能逐步碰到的局部語言。

玩家不需要先學語言表；玩家先在畫面上遇到「聽不懂某個票據」「某句路歌只被澤路人承認」「石門兌牌人不接受口頭保證」。

## 信仰、傳說與禁忌

信仰先以地方常識呈現，不先做神殿職業。

| 信仰/傳說 | 內容 | 玩家可見結果 |
|---|---|---|
| 守界說 | 人活著就是守住一條會被世界磨掉的界線 | 路標、門線、火帶、乾棚、倉封都帶半宗教式責任 |
| 四勢說 | 火、水、風、土不是神，而是世界最常被人理解的四種勢 | 工坊、田渠、渡口、礦坡各有避忌和工具習慣 |
| 退樁故事 | 第一批河樁被水草吞掉，教訓是無人認領的邊界不算邊界 | 泊位、樁、繩、牌都必須有人認責 |
| 七梁斷年 | 西坡支梁連斷，讓礦作和工坊不再相信無標記粗料 | 粗料標記、裂柄工具、支柱檢查成為玩家可見制度 |
| 空箱封潮 | 海門曾放行無保證外箱，造成匯兌與稅棚改革 | 外貨需要貨樣、翻譯、匯兌記錄與封條互相支撐 |
| 不說滿路 | 遠路人忌說「路一定安全」 | NPC 給路訊會附時段、天候與責任邊界 |

禁忌不是道德說教，而是會擋玩家、改價格、改關係或觸發衝突的世界規矩。

| 禁忌 | 為什麼存在 | 犯了會怎樣 |
|---|---|---|
| 霧季亂挪河樁 | 河樁代表船序與責任 | 被船戶行防備，嚴重時停渡或求償 |
| 不問就碰封條 | 封條固定貨權與責任 | 倉場拒收、保證人撤回、守門人記臉 |
| 乾棚火帶內亂堆貨 | 乾棚同時要防返潮和防火 | 乾棚看管趕人、材料降價、火險升級 |
| 水時私開田閘 | 灌溉時段影響上下游 | 田渠戶盟追責，糧價和熟臉受影響 |
| 無標記粗料進工坊 | 粗料可能含雜或來路不明 | 工坊街拒料，西坡礦作和倉場互相追責 |
| 雷暴時持金屬工具上高處 | 雷暴會改寫高處、水邊與工具風險 | NPC 制止，強行會造成傷勢或目擊後果 |
| 遠路不守夜卻求同行 | 守夜是路隊互保的一部分 | 路隊不帶，或只以更高代價接納 |
| 海門不經翻譯替外貨作保 | 外貨語言與票據風險高 | 匯兌屋拒票，稅棚扣貨，玩家背信用債 |

## 重大矛盾

## 玩家進入世界的理由

玩家不必是命定英雄。第一版最穩的入口是：玩家是一個剛被中河諸帶承認為可行動的人，帶著少量鎂、最基本持物與不完整關係進入地方秩序。

玩家為什麼能介入：因為這個世界有大量維持中的邊界，而邊界需要人手、工具、保證、消息與風險承擔。玩家不是被世界等待，而是剛好站到某個缺口旁。

玩家初始可被世界承認的路徑：

| 路徑 | 初始可見身份 | 第一個世界承認 |
|---|---|---|
| 過路人 | 有錢、有腳、有去處，但缺熟臉 | 能排隊、問路、買小物、被拒絕 |
| 可使喚的人 | 願意讓路、搬一下、扶一下、守一下 | 被 NPC 短暫記住，可能被再次叫住 |
| 持工具的人 | 手上有火折、短繩、油布、水袋或舊工具 | 世界開始對玩家提出工具相關期待 |
| 求位置的人 | 想寄放、跟隊、找保證或換路 | 玩家要用鎂、信用或行動換地方承認 |

硬規則：玩家起點不是世界主角起點。玩家一開始最重要的不是史詩使命，而是自己是否被某個地方、某個人、某個工具、某筆錢、某個承諾承認。

## 現代局勢首頁

如果要把中河諸帶寫成可讀世界，任何時候都應能列出「今天世界正在被哪些矛盾推動」。第一版現代局勢如下：

1. 東湖返潮提前：乾棚滿、蘆草與魚貨更難保價，水倉會和乾棚看管互相推責。
2. 西坡粗料含雜：工坊街缺合格粗鐵，西坡礦作認為是倉場壓價，石門議棚準備插手。
3. 南城水時緊：南城外田渠戶盟和草場牧戶爭水，糧車、畜力與草料價開始浮動。
4. 北驛路旗被改：巡路班說是霧草澤的人亂標，引路人圈說巡路班沒守夜。
5. 海門扣外貨：稅棚扣下一批潮外箱，南城商會需要翻譯、票據與本地保證才能趕交期。
6. 中鎮倉位短：濕貨、粗料、糧袋同時擠到中鎮，倉場聯保開始挑人挑貨，外人更容易被拒。

這六條局勢足以自然長出第一批可玩內容：問路、包貨、分選、守夜、作保、翻譯、修具、讓船、清渠、扶標、報信、避戰或制止衝突。

## 世界可讀性驗收表

任一地名、材料、勢力、NPC、衝突若不能填完下表，不得宣稱已進世界正典。

| 驗收項 | 必須回答 |
|---|---|
| 來源 | 它從哪個地貌、元素性、歷史事件、制度或職責長出來 |
| 現在狀態 | 玩家此刻看到它時，它正在維持、失守、變質、等待、被爭奪還是被承認 |
| 玩家看到什麼 | 不是抽象設定，而是門、牌、繩、貨、痕跡、人、稱呼、價、路況、戰報 |
| 玩家能做什麼 | 至少一個簡單動詞會改變錢、物、路、人、時間、信用、風險或關係 |
| NPC 同規則 | NPC 也會受它影響、利用它、拒絕它、搶先、失敗、求援或追責 |
| 失敗/錯過 | 玩家不做、做錯、做晚，會留下什麼可讀結果 |
| 回訪差異 | 下次回來如何看出世界沒有停在文案裡 |
| 為什麼 | 被追問「為什麼存在」時，能接回世界根律與歷史，而不是作者喜好 |
| 非日常可為性 | 玩家在現實不能、安全上不會、無法長期或無法被承認地做到什麼 |

## 禁止方向

- 不把本檔退化成文學散文；所有內容都要能被地圖、物件、NPC、交易、戰鬥或玩家動詞使用。
- 不從北岸渡口或任一局部場景反推世界。

- 不接回舊世界特殊設定。
- 不把奇幻寫成酒館、公會、任務板、命定英雄或固定職業模板。
