## 本檔定位

本檔補「完整材料百科」缺口。材料在奇點裡不是名詞清單，也不是採集後賣錢的表。材料必須是世界物件與機制來源：有來源、狀態、保存、搬運、用途、價格承認、失敗成本、NPC 同規則與回訪痕跡。

本檔分四層：

1. 原始材料：直接來自地貌、生態、礦脈、生物、天候或水體。
2. 加工材料：經分選、乾燥、熔煉、編織、熟化、封存、切削等工序後進入經濟。
3. 工具/器物：材料變成玩家與 NPC 的動詞來源。
4. 可交易物：因需求、保存、地點、信用與時機被承認價格。

## 材料狀態軸

任何材料不只是一個名字，至少有以下狀態軸：

| 狀態軸 | 可能狀態 | 玩家可見 | 玩法作用 |
|---|---|---|---|
| 乾濕 | 乾、半濕、受潮、浸水 | 顏色、重量、氣味、包裝變化 | 保存、報價、點火、腐壞、滑落 |
| 新舊 | 新鮮、可用、將壞、腐敗、裂損 | 邊角、味道、裂痕、蟲痕 | 報價、拒收、醫治/污染、工具耐用 |
| 粗精 | 原粗、分選、加工、精整 | 顆粒、切面、標記、包裝 | 可否被作坊收、能否當工具材料 |
| 所有權 | 無主、公共、私有、寄放、查封 | 標牌、封條、旁人反應 | 可否拿、偷、借、買、被阻止 |
| 元素性 | 熱、濕、焦、泥、帶雷痕、毒腐、酸蝕 | 可讀線索 | 增減動詞、戰前判斷、保存難度 |
| 包裝 | 裸露、包覆、封箱、繫牌、散落 | 是否有油布、繩、箱、標記 | 搬運、保價、丟失、被錯拿 |

## 可交易物與價格承認

交易不以「材料價」單獨決定。價格由基礎價、狀態、需求、風險、關係與地點承認共同決定。

```text
承認價格 = 基礎價
        + 需求修正
        + 保存修正
        + 路線風險修正
        + 關係/信用修正
        - 損壞/污染/來路不明修正
```

## 玩家看到什麼

材料在玩家畫面上不得只顯示名稱，至少要露出一個可判斷狀態：

```text
【乾蘆束】束口還緊，但外層有返潮痕。
【油布包】油面完整，折角沾了泥。
【粗鐵料】標記牌寫著西坡，碎粉仍黏在袋口。
```

這些句子讓玩家知道：

- 能不能交易。
- 需不需要先處理。
- 誰可能承認它。
- NPC 是否會搶先或拒收。

## 玩家能做什麼

材料相關動詞分為八類：

| 類別 | 動詞 | 改變 |
|---|---|---|
| 取得 | 採、買、借、撿、分得、承接 | 物件位置、歸屬、信用 |
| 處理 | 曬、洗、分選、包覆、封存、熬、燒、磨 | 品質、狀態、用途 |
| 搬運 | 拿、背、拖、裝箱、上車、上船 | 位置、時間、風險 |
| 使用 | 點、綁、修、墊、堵、遮、治、標記 | 場景狀態、路況、傷勢 |
| 交易 | 買、賣、換、賒、寄放、作保 | 鎂、物、信用、需求 |
| 維護 | 補料、修補、替換、看守 | 場所可用性、回訪痕跡 |
| 失敗 | 弄濕、弄裂、錯包、丟失、污染 | 報價、關係、風險 |
| 放棄 | 丟、拒收、放任、讓 NPC 處理 | 錯過、被搶先、路況變化 |

## 玩家層驗收回答

| 問題 | 本包回答 |
|---|---|
| 玩家看到什麼 | 材料名稱旁必須露出狀態、包裝、來源或承認線索，例如返潮、裂角、封條、標記牌、油布、泥痕 |
| 玩家能做什麼 | 採、買、借、曬、洗、分選、包覆、封存、搬、裝、點、綁、修、交易、寄放、作保、補料或放棄 |
| NPC 是否同規則 | NPC 也會採集、曬乾、搶用乾棚、拒收、壓價、加工、借還工具、弄壞或搬走材料 |
| 物件/金錢/時間/關係如何改變 | 材料狀態、位置、歸屬、品質、需求與保存時間改變；報價、信用、寄放責任與作坊/倉場態度隨之改變 |
| 失敗/錯過怎麼呈現 | 受潮、腐敗、斷裂、錯包、污染、被拒收、被搶先、降價、招蟲、壞倉或讓場景路況惡化 |
| 回訪有何差異 | 玩家曬過、封過、修過、寄放或放任的材料會變成乾、濕、爛、售出、被取走、被查封或留下信用痕跡 |
| 好玩在哪 | 材料不是撿來賣，而是讓玩家在保存、風險、搬運、信用、工具用途與時機之間做取捨 |

## 可交給實作清單

- 材料資料模板：來源地帶、取得方式、狀態軸、用途、需求者、拒收理由、回訪差異。
- 第一批原始材料：本檔列出的 32 種原始材料。
- 第一批加工材料：本檔列出的 18 種加工材料。
- 第一批工具/器物：本檔列出的 13 種工具與器物。
- 價格承認模型：基礎價 + 需求 + 保存 + 路線風險 + 信用 - 損壞/污染。
- 交易文案規格：材料名必須附可判斷狀態，不只顯示數量。

## 仍需設計缺口

- 每種材料的精確數值、重量、堆疊、體積與資料欄位不在本檔。
- 食物、藥、武器、建材、衣物的完整二級加工鏈還需後續分冊。
- 每個 M3 的材料供需曲線需接世界地圖與勢力史。
- 材料與戰鬥公式的數值平衡需在戰鬥設計包和 runtime 工單中處理。

## 禁止方向

- 只列材料名與用途百科。
- 用材料數量冒充經濟深度。
- 材料憑空出現在背包或商店。
- NPC 不受材料狀態影響，只讓玩家處理。
- 所有材料都變成採集交付拿錢。
- 把材料狀態做成玩家需要照顧的通用生存條。
