## 世界大綱總覽

### 這個世界是什麼

奇點不是現實地球加一層魔法特效，也不是一套能量管理制度。它是一顆能量像空氣一樣存在於萬物中的平行地球：水、土、風、光、聲音、身體、食物、工具、房屋、道路、名字、情緒與死亡都含有能量。

人不需要取得能量，也沒有人能把能量當成總開關。活著本身就是交換：呼吸交換地方，觸碰交換痕跡，使用交換習慣，稱呼交換身份，同行交換過去，衝突交換傷口，死亡交換最後的來處。

### 這個世界的故事問題

奇點的故事問題不是「誰能使用能量」，也不是「誰能管理能量」。

```text
世界太容易交換，也太容易記住。
人想自由生活，卻一直踩在自己、他人與前人留下的痕跡上。
```

這是後續所有內容的故事根：

- 物件不是空白道具，可能帶著前主、使用史、借出、修補、失手、歸還或死亡。
- 道路不是座標線，可能帶著腳步、逃亡、失約、熟悉、追蹤或重訪。
- 名字不是裝飾字串，可能帶來信任、誤認、保護、排斥或舊事回頭。
- 城市不是功能集合，而是人、物、地、稱呼與過去高密度擠壓的生活面。

### 世界史最小骨架

| 階段 | 世界意義 | 現在會留下什麼 |
|---|---|---|
| 初息時代 | 能量與空氣、水、土、風、光、聲音一起成為存在條件。 | 地理、材料、生態與生命都不是普通地球套皮。 |
| 萬生交換期 | 生命在過度交換中學會保持自己。 | 荒野是豐饒又危險的生命互讀場，不是資源空地。 |
| 呼名期 | 人用語言、名字、工具、葬禮把流動世界暫時叫住。 | 稱呼、地名、物件舊稱與死者記憶都有社會重量。 |
| 共居期 | 家、路、門派、行隊、城市從共同生活與照看長出。 | 社會不是服務點，而是人如何處理彼此痕跡的生活形式。 |
| 大回潮 | 世界把過度累積的舊物、舊名、舊路、舊債與舊死推回現在。 | 當代所有價格、路況、關係、醫療、交易與衝突都有歷史壓力。 |
| 回潮後當代 | 文明沒有倒退，而是成熟到必須處理過多痕跡。 | 玩家進入高密度、成熟、奇幻日常化，但不安全的當代世界。 |

### 作品級故事大綱

`world-outline-from-zero-v0.md` 的主幹不是「能量如何被管理」，也不是「v2.5 的卡組如何續寫」，而是：

```text
一顆能量充沛的平行地球，從星球形成、生命演化到文明成熟，都活在過於容易交換的世界裡。
生命不是使用能量，而是在過盛交換中建立自己的邊界。
人類用名字、工具、道路、家戶、門派、城市、教育、醫療與故事建立第二層邊界。
文明越成熟，留下的人、物、名、路、傷、愛、債、死越多。
大回潮後，過去不再安靜待在過去，而是以人能碰到的形式回到當代生活。
玩家是一個名字還很輕的外地遠行者，第一次用小動作讓局部世界承認自己。
```

當代三個核心矛盾：

- 該記住什麼：過去全留下會壓垮人，太快淡掉又會失去根。
- 誰能承擔什麼：拿物、作保、叫名、走路都可能把別人的事接到身上。
- 外地人如何被承認：玩家沒有本地熟臉與熟路，但正因名字很輕，能鑽進別人不願碰的空隙。

第一版大世界從八個故事功能區起頭：`長息諸城`、`沉物海岸`、`回潮原`、`不留林`、`靜火列島`、`遠行脊路`、`淡痕盆地`、`暖生南域`。這些是世界大綱區，不是 M4 場景，也不是可直接實作地圖。

v2.3 已把社會層從類型表推進到第一批具名生活共同體：`長息聯城`、`沉物歸還約`、`遠行路誓`、`淡痕照身院`、`靜火承手門`、`不留林邊社`、`暖生共棲族群`、`回潮原守路會`。它們不是誰控制能量的勢力，而是人如何處理名字、持物、路、療傷、工具、藏匿、共棲與舊路的生活方法。

v2.4 進一步補上具名歷史牽連：`第一唱名`、`三街同名夜`、`沉物三潮`、`長路失約`、`淡痕停葬`、`不留林白日`、`靜火斷手日`。這些事件不是背景年表，而是用來回答今天的稱呼、物價、路況、歸還、療傷、追索、工具拒手與人物舊怨為什麼存在。

`world-story-bible-v2.md` v2.5 的歷史事件落地矩陣現在降格為上一輪素材。後續不能只沿用卡名，必須先通過 `world-outline-from-zero-v0.md` 的世界根檢查：萬物含能、生命建立邊界、人類用名字/工具/道路/共同生活維持邊界、大回潮把過去推回現在、玩家以小動作改變局部事實。

### 玩家為什麼想進入

玩家不是去管理系統，也不是被任務叫去救世界。玩家想進入，是因為這個世界讓玩家能做現實做不到的事：

- 讀出一件物的前主、來處、使用史或不願離開的理由。
- 因身上帶著某物，使一段舊路短暫出現或拒絕讓玩家通過。
- 叫出一個名字，讓正確的人、錯的人或不該回頭的人回頭。
- 把一件物使用、交易、藏起、歸還、改名或長期帶在身上，讓後來的人讀到差異。
- 幫某人被記住，或幫某段太重的過去變淡。
- 在自己下線後，角色與 NPC 仍被世界時間推著走，並留下玩家日後撞見的局部結果。

### 設計生成順序

任何新地點、物件、NPC、勢力、材料或衝突，都必須照此順序生成：

```text
故事根
-> 曾經發生過什麼
-> 現在留下什麼人/物/地/稱呼/路況/價格/禁忌
-> 玩家看見什麼
-> 玩家能碰什麼
-> 玩家做了會留下什麼新痕跡
-> NPC 是否同規則
-> 回訪時差異如何被讀到
```

若某個設計只能回答「它合理」「它漂亮」「它在表格裡」，卻回答不了玩家能碰什麼、改變什麼、留下什麼，它就還不是奇點世界內容。

## 立即降格

`world-bible-v4.md` 不再視為完整世界本體正典。它保留的唯一價值是反面教材：

- 它確認了能量不是電力。
- 但它仍把能量寫成需要被讀標、作證、禁線、工具封記、事故責任處理的治理對象。
- 它把奇幻世界推成行政工程世界，缺少故事、神秘感、角色扮演吸引力與非日常可為性。

後續不得從 v4 的 `讀標制度`、`作證制度`、`禁線制度`、`三城誤衡`、`臨務人`、`熟用紀` 直接續寫世界。

## 一句話世界大綱

奇點世界是一顆能量充沛的平行地球：空氣、水、土、光、聲音、血肉、呼吸、情緒、食物、物件、土地與死亡都含有能量；生命不是使用能量，而是在每一次呼吸、觸碰、行走、爭鬥、製作、承諾與死亡中與世界交換能量，並把痕跡留給人、物、地方和故事。

## 世界根

### 1. 萬物含能

能量不是資源，也不是人類後來發現的技術。它是存在本身的一部分。

在奇點世界裡：

- 空氣裡有能量，所以呼吸不是單純換氣。
- 水裡有能量，所以河流不是背景線。
- 土裡有能量，所以土地不是地圖底色。
- 光與聲音裡有能量，所以看見、聽見、呼喊與歌唱都可能留下影響。
- 血肉裡有能量，所以受傷、疲憊、病痛、睡眠與死亡都不只是數值變化。
- 物件裡有能量，所以被長期使用的工具不是空白道具。

玩家層意義：玩家不是找能量，而是進入一個每個可見物都可能已經被人、地、時間和事件改變過的世界。

### 2. 生命是交換

生命不只是擁有能量。生命活著，就是和世界交換能量。

呼吸會帶入環境，也會把自己帶出去。腳步會壓過土地，土地也會回到身上。手碰過物件，物件也會在手上留下細小的改變。人與人靠近、爭吵、交易、照看、戰鬥，都不是無痕事件。

玩家層意義：玩家的行動不能只是 `使用物件 -> 得到結果`。更好的奇點行動應該是 `接觸世界 -> 交換 -> 留下痕跡 -> 被後續讀到或承受`。

### 3. 觸碰留痕

奇點世界的奇幻感來自「世界會記住」。不是所有記憶都像人類記憶，也不是每個物件都會說話；但長期接觸、強烈情緒、死亡、誓言、戰鬥、救援、打造、陪伴，都可能讓某個物、地方或人帶上可被感知的痕跡。

痕跡可以很小：

- 一把常用刀比較願意順著某個人的手。
- 一段路讓熟人走起來比較不費力。
- 一件衣物殘留前主人的急促呼吸。
- 一間屋子讓陌生人覺得被排斥。
- 一片林地在有人死後多年仍讓鳥群避開。

玩家層意義：物件、地點、NPC 不是背景清單。每個重要東西都應該能問：誰碰過它，發生過什麼，它現在因此如何不同。

### 4. 世界會回應，但不替玩家演戲

世界不是舞台，也不是為玩家表演。未被玩家看見的人、物、地方仍在變化。玩家只是在某一刻撞進局部事實。

世界的回應不必誇張。它可以是一個 NPC 改路，一件工具拒手，一段舊路忽然變得好走，一個名字讓某人沉默，一間屋子在夜裡不肯留住火光。

玩家層意義：活世界不是全世界動給玩家看，而是局部碰撞有因有果；玩家可以錯過，也可以留下被別人碰到的痕跡。

### 5. 人不是例外

玩家、NPC、人形居民、動物、植物與物件都在同一世界裡。人類比較擅長把經驗變成語言、工具、儀式、技藝、故事、交易與社會，但人不是能量的主人。

玩家層意義：玩家可以做 NPC 能做的事，也會承受 NPC 會承受的後果。好玩不來自主角光環，而來自玩家能在同規則世界裡留下自己的痕跡。

## 世界故事根

### 初息

奇點地球形成時，能量不是覆蓋在星球表面的魔法，而是與空氣、水、土、火光、潮汐、聲音和生命前身一起存在。

最早的生命不是學會利用能量，而是學會在過於豐盛的交換中保持自己不被沖散。某些生命靠沉默活下來，某些靠群聚，某些靠模仿環境，某些靠把接觸過的事物留在身體裡。

現在的世界因此不是荒蕪求生，而是沃土風：生命濃密、豐饒、危險，越充沛越不安全。

### 有形者

生命越來越複雜後，世界開始出現「痕跡」。獸群會避開死過同伴的谷地。植物會沿著常有人走的路生長得不同。水源會因長期飲用者而帶上地方性。物件還不存在，但世界已經不是空白。

這一時期留下的現在狀態：

- 荒野不是資源區，而是充滿舊痕跡與生命反應的地方。
- 地方不只因地形不同，也因曾經發生過什麼而不同。
- 探索不是揭地圖黑霧，而是理解「這裡為什麼這樣」。

### 人與名字

人類出現後，最重要的不是發明王權、貨幣或制度，而是發現語言和名字能讓流動的世界暫時穩住。

給人取名，是讓一個生命在變化中被認出。給地方取名，是把一片土地和過去的經歷綁在一起。給工具取名，是承認它不只是材料。發誓、唱歌、呼喊、哀悼、祝福，都是人類把內在能量送進世界的方式。

這不是舊特殊設定。名字不是可被剝奪的系統資源，而是角色扮演與故事重量：玩家的名字、NPC 的稱呼、地方的俗名、物件的舊稱，會影響人如何看待它們。

### 火旁年代

早期文明不是從城牆和市集開始，而是從能一起呼吸、取暖、記路、養傷、分食、守夜、唱名和埋葬的地方開始。

人們圍著火，不只是為了熱，而是為了讓一群人的呼吸、故事和記憶暫時聚在一起。這讓家戶、氏族、師徒、門派、行隊和城鎮有了故事根。

現在的世界因此保留：

- 家不是室內地圖，而是被人反覆生活過的物件群與地方痕跡。
- 路不是線，而是被腳步、傳聞、危險、照看和交易反覆踩出的關係。
- 門派不是技能商店，而是一群人如何呼吸、使用工具、看待身體與世界的傳承。

### 大回潮

歷史上的大事件暫定為 `大回潮`。

它不是停電，不是能源事故，不是制度崩壞。它是某一時代的人類過度集中建城、交易、戰爭、誓言與製造後，引發整片大地把人類留在世界裡的痕跡一次性回推。

結果不是世界毀滅，而是所有人突然明白：世界會記得太多。舊戰場、舊城、舊誓、舊工具、舊名字、舊債、舊愛與舊死，都可能在某些條件下重新影響現在。

現在的世界因此有三個底層矛盾：

- 人想留下痕跡，但不想被所有舊痕跡拖住。
- 人想繼承力量，但繼承也會繼承傷口。
- 人想探索遠方，但遠方不只是未知，也可能是被世界保存太久的過去。

### 近世

當代奇點不是古代，也不是現代地球。它是奇幻已深入日常的高密度世界。

普通人知道呼吸、食物、睡眠、情緒、稱呼、工具、路、屋、衣物與墓地都有講究。小孩學會不要亂碰陌生物件，不是因為法律，而是因為物件可能帶著前人的痕跡。商人重視貨物來源，不是只因價格，而是因為貨物可能沾著地方、前主、死亡或祝福。醫者看傷口，也看一個生命是否還願意留在身體裡。

這個世界有城市、國家、聯盟、門派、氏族、種族與遠行者，但它們的故事根不是誰控制能量，而是誰能讓人、物、地與過去形成可持續的生活方式。

| `織南` | 長息城的唱名師，為新生兒、遠行隊、門派工具和亡者唱名。 | 名字、稱呼、身份、NPC 關係與玩家自我定位的入口。 |
| `梁折` | 不留林附近的失蹤案追索者，痛恨世界讓某些痕跡消失。 | 探索、追蹤、調查、戰鬥前置和道德選擇的入口。 |
| `南枝` | 長息聯城的外客名階學徒，負責讓外地人的稱呼先被城市聽見。 | 玩家第一次說出自己的名字時，她會判斷名字、持物與作保關係。 |
| `柏行` | 遠行路誓的暫持人，替行隊保管路袋與口信，也承擔失約壓力。 | 玩家可暫放一件物；回來太晚時，物可能已按路誓轉交。 |
| `溫引` | 淡痕照身院的療傷者，知道淡去痛苦也可能淡去證據。 | 玩家必須在保留來處與先讓人活下去之間選擇。 |

### 代表場面

這些場面要能讓玩家感覺「這不是現實可做的事」。

1. 玩家撿起一把舊傘，傘面短暫滴下不是今天的雨；附近 NPC 認出那場雨屬於多年前的某個夜晚。
2. 玩家在同名街叫錯一個名字，三個人同時回頭，其中一個不是活人，但只有玩家身上的某件物件知道。
3. 玩家走過回潮原，一段本來不存在的路因玩家身上帶著某人的舊物而短暫出現。
4. 一名 NPC 離線式地繼續自己的生活，玩家數日後回來，只看見他曾坐過的石階比旁邊溫一些。
5. 一件工具被玩家長期使用後，不是加數值，而是開始在某些動作中更願意順手，也更不願被陌生人拿走。

## 玩家在玩什麼

玩家不是管理能量，也不是替世界做檢查。

玩家在玩：

- 在一個萬物含能的世界裡認出自己能碰什麼。
- 用身體、名字、工具、物件和關係進入地方故事。
- 把 NPC、物件、地方和自己之間的痕跡變成可見後果。
- 在不當主角的前提下，讓世界某一小塊因自己而不同。

最小可玩單位應改成：

```text
看見一個帶痕跡的人/物/地
-> 點擊接觸
-> 做一個很小但現實做不到的動作
-> 人/物/地/玩家自身留下一個新痕跡
-> 下次回訪或他人接觸時讀到差異
```

## 與關鍵字清單對齊

| 關鍵字 | 重塑後落點 |
|---|---|
| 文字 MUD、重文字 | 世界靠文字讀出呼吸、觸碰、痕跡、稱呼、物件前史與地方反應。 |
| 輕操作、重體驗 | 玩家少量點擊，但每次接觸可能改變人、物、地、關係或回訪痕跡。 |
| 全物件化 | 物件不是道具名，而是帶使用史、前主、脾性和可被改變的世界實體。 |
| 不可無中生有 | 新事件必須從已有的人、物、地方、痕跡和世界時間長出。 |
| 玩家 = NPC | NPC 也會留下痕跡、被物件記住、被地方排斥、被名字牽動、被過去追上。 |
| 世界永遠在線 | 玩家不在時，NPC 仍生活，物件被使用，地方累積或淡去痕跡。 |
| 真實經濟 | 價格不只來自供需，還來自物件前史、地方痕跡、可信任程度、是否願意被轉手。 |
| 探索/冒險 | 探索是追問地方與物件為什麼如此；冒險是進入會回應你的未知。 |
| 經營/模擬/建造 | 經營與建造是長期照看人、物、地與痕跡，使它們形成可持續生活。 |
| 戰鬥 | 戰鬥是身體、工具、地勢、情緒、舊痕跡與關係的衝突，不先從傷害公式起頭。 |

## 禁止方向

- 不再把能量寫成供應、接入、斷供、配給、電網、管線或能源節點。
- 不再把能量寫成讀標、作證、禁線、工具封記、事故責任優先的治理世界。
- 不再從北岸、渡口、材料表、勢力表或地圖數量反推世界。
- 不回收舊特殊設定。
- 不導入飽腹、精力、舒適等通用生活條。
- 不把奇幻寫成遠古、中古、酒館、公會、村落手工業、低生活密度。
- 不把 NPC 寫成商人、任務板、聊天端點。
