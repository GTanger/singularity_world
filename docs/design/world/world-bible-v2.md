## 本檔定位

`world-bible-v1.md` 已把世界本體從空白表格推到可拆工狀態：中河諸帶、世界根律、地貌、制度、材料、勢力、人物原型與現代局勢都有入口。但 v1 仍偏「能拆工的資料包」，深度不足。

本檔補 v1 缺的縱深。它不是再列更多地名，也不是把表格寫長，而是讓核心土地、制度、材料、勢力與人物牽連能被追問：

- 它從哪裡來。
- 它曾經受過什麼傷。
- 今天誰靠它活、誰被它擋、誰想改它。
- 人們怎麼稱呼、傳說、忌諱或誤解它。
- 玩家碰到它時，看到的是一段正在延續的世界關係，而不是一個功能點。

v2 的責任不是取代 v1 的骨架，而是在 v1 骨架內長出歷史、文化、舊怨、家系、口語、禁忌由來與可玩的現在態。

## 深度寫法

本檔所有內容都用同一個深度判準：一個設計單元至少要同時有五層。

| 層 | 問題 | 不合格樣貌 |
|---|---|---|
| 遠因 | 它為什麼從這個世界自然長出來 | 作者覺得需要一個地點、材料、勢力 |
| 歷史 | 它曾經發生過什麼，今天還在留下什麼結果 | 年表事件和現在畫面無關 |
| 現在 | 今天誰靠它維持生活，誰被排除，誰在爭 | 只有背景設定，沒有利益與衝突 |
| 文化 | 人們怎麼稱呼、忌諱、傳說、罵它 | 只有正式名，沒有地方口感 |
| 玩家 | 玩家看到、碰到、錯過、介入後，哪個世界事實改變 | 只能閱讀，不能造成狀態差異 |

## 世界深層命題

中河諸帶不是一個剛被命名的遊戲地區。它是許多代人把一片生機過剩的大地壓成「暫時可走、可住、可存貨、可相信」的結果。

這裡的奇幻不靠遠古神名撐場，也不靠固定職業、任務板或主角宿命。奇幻在於：土地本身太旺，水、霧、草、泥、礦、獸、潮、雷、腐壞與生長都會把人的秩序推回混沌；文明每天都要用樁、路、棚、倉、封條、火帶、票據、工具、人情與責任，把世界重新壓成可讀狀態。

所以中河諸帶的人不會說「世界安全了」。他們只會說「今天這條線還有人認」。

這句話是 v2 的世界口感：路、價、門、貨、人、規矩都不是永久存在，而是今天被某些人、某些工具、某些制度暫時承認。

## 年代感邊界

奇點是奇幻世界，但不得把「奇幻」自動寫成遠古、中古、封建、酒館任務、公會櫃台、騎士城堡、純手工業村鎮或前現代水路倉場。這是本檔目前最需要修正的偏誤：v2 中的樁、船、倉、稅棚、路隊、作坊、田渠等內容只能作為「某些地方的制度形態」，不得代表整個奇點的年代上限。

更嚴重的是語彙會製造年代。若文件反覆使用樁、棚、草束、裂木、火帶、手工坊、舊路、守夜、引路人、船戶、倉場、田渠這類詞，讀者會自然感覺世界停在「茹毛飲血好一點」的低技術階段。這不是使用者要的奇點。這類詞不得作為奇點的預設語彙，只能在特定地貌、特定地方文化、特定玩法鏈裡被審核使用。

奇點的時代感應由世界規則與玩家可見生活推導，而不是由傳統 fantasy 模板決定。它可以有成熟城市、大型機構、標準化工具、票據/信用網、遠距消息、複雜交通、公共設施、工程維護、量測制度與高度分工；只要這些事物能被 `DESIGN_KEYWORDS.md` 的後端真理、全物件化、世界永遠在線、真實經濟、玩家與 NPC 同律支撐，就不應被排除。

反過來，奇點也不是現代地球換皮。不能直接搬現代科技名詞、現代行政單位或現實都市日常來填空。正確方向是：先定奇點自身的生活技術層，再讓地圖、材料、制度和人物從這個技術層長出來。

因此後續任何地點與制度都要額外回答：

| 檢查項 | 必須回答 |
|---|---|
| 時代感來源 | 這個地方/制度為何是奇點自身技術與生活條件的結果，而不是遠古/中古模板 |
| 技術層 | 它有哪些工具、量測、交通、通信、保存、能源、工程或公共設施支撐 |
| 生活密度 | 普通人每天如何使用這些技術或制度，而不只是背景設定 |
| 玩家表層 | 玩家會看到哪些非前現代模板的物件、標記、設備、流程或文字 |
| 禁止退化 | 它是否又滑回酒館、城門、作坊、船戶、倉場等單一年代感 |

### 語彙紅線

下列不是永久禁詞，但不得無審核地作為奇點預設用詞。若使用，必須說明它為什麼不是原始化、土法化或低生活密度的慣性。

| 語彙傾向 | 問題 | 替代方向 |
|---|---|---|
| 樁、草束、裂木牌、舊布、火帶 | 使制度感掉回粗糙邊界標記 | 標準化標記、認證件、量測點、可讀設備、公共維護物 |
| 船戶、倉場、作坊、田渠、引路人 | 讓世界像前現代手工業社會 | 機構、服務網、維護單位、專業行業、公共系統、信用節點 |
| 守夜、舊路、低牆、驛棚 | 讓交通像荒路求生 | 路網節點、通行服務、風險監控、遠距通知、交通維護 |
| 留白帶、路歌、口頭保證 | 容易變成民俗感過重 | 可讀規程、地方協議、公共記錄、可驗證線索 |
| 潮前荒生、第一立樁 | 聽感接近史前/部落起源 | 技術層演進、城市化節點、制度化轉折、網路化承認 |

本檔既有內容中凡使用這些語彙，後續必須重審。它們可以暫時保留為「偏誤樣本與局部素材」，不得直接進玩家可見文案或 runtime。

## 世界憑依層缺口

本檔目前更根本的問題，是沒有設計出奇點自己的世界憑依層。

現實世界因電的出現與普及，城市、工業、通信、夜生活、家庭設備、交通控制、資訊流通與社會組織都發生井噴式重組。哈利波特世界能靠一個魔力設定支撐學校、政府、交通、貨幣、日常工具、醫療、戰鬥、娛樂、血統、禁忌與無數同人延伸。奇點世界既然是能量充沛的世界，就不能只把能量寫成植物更旺、礦物更肥、野獸更強。

能量充沛必須成為奇點的普及性根基：普通人如何感知、取得、轉換、儲存、分配、量測、交易、濫用、限制、教育與制度化這種能量。若這一層沒有設計，所有地圖、材料、制度、勢力與人物都只是在表面補世界。

因此，在補完世界憑依層前，v1/v2 中的多數土地、材料、制度與勢力只能視為局部素材或偏誤樣本，不得宣稱已是完整世界深度。

### 能量憑依層最低問題

| 層面 | 必須回答 |
|---|---|
| 本質 | 奇點的充沛能量是什麼：自然背景、可操作資源、生命條件、材料性質、文明基礎，或以上如何分層 |
| 普及 | 普通人如何日常使用它，而不是只有術士、貴族、天才或特定職業能碰 |
| 轉換 | 它如何轉成光、熱、動力、保存、通信、加工、交通、防護、醫療或戰鬥 |
| 儲存 | 它附著在哪些材料、裝置、場所、身體狀態或公共設施上 |
| 分配 | 它如何形成城市、路網、住宅、產業、公共服務、荒野邊界與遠地差異 |
| 量測 | 世界如何測量、標準化、收費、保證、驗證、造假與追責 |
| 制度 | 哪些機構、學校、行會、公共系統、法律、禁忌或黑市圍繞它形成 |
| 生活 | 家庭、街道、工作、娛樂、夜晚、醫療、飲食、清潔、學習因它如何不同 |
| 玩法 | 玩家如何看見、觸碰、利用、破壞、修復、交易、學習或冒險介入它 |
| 限制 | 為什麼它不是萬能；什麼成本、風險、污染、失控、稀釋、壟斷或倫理問題限制它 |

### 與既有 v2 的關係

v2 現有的河、湖、礦、港、倉、路、作坊等內容，若保留，必須被重新放到能量憑依層之下。例如：

- 城市不是因人用樁和棚維持秩序而成熟，而是因能量的取得、分配、標準化與公共服務形成生活密度。
- 材料不是因手工處理才有價，而是因承載、導引、儲存、轉換或隔絕能量而有文明地位。
- 交通不是遠路守夜，而是能量普及後的通行網、風險監控、節點服務與荒野邊界。
- 勢力不是船戶、倉場、作坊這些低技術職群，而是控制能量標準、設施、教育、維護、流通、監管與黑市的制度體。
- 玩家不是在粗糙邊界旁幫忙，而是在一個成熟能量文明中取得位置、工具、信用、知識、風險與可被承認的行動權。

本檔不應再繼續加地名或材料。當前 World Bible 已依 `world-energy-evolution-root-v0.md` 重寫成 `world-bible-v3.md`：先確定能量貫穿演化鏈、普供時代、材料功能族、公共供能制度、生活密度與玩家動詞，再回頭重寫地圖、材料、勢力與人物。

## 歷史縱深

v1 的歷史分期可以支撐推導，但還太像年表。v2 將歷史寫成今天仍在咬人的舊事。

### 潮前荒生

中河諸帶最早沒有「路」這個概念，只有可趁的空隙。水退時能過，霧開時能看，獸群換徑時能走。最早的人群不說自己住在哪裡，只說自己「借哪一段地過夜」。

這一時期留下的不是古城，而是地方人格。河岸人不信永久橋，澤路人不信直路，坡作人不信平地，遠路人不信滿口保證。玩家今天在任何地方聽到「昨夜還能走」而不是「一定能走」，源頭就在這裡。

玩家可見：問路時 NPC 常附帶時間、天候、誰剛走過、誰要負責；路訊本身不是免費真理。

### 第一立樁

第一批樁不是地產界線，而是「有人認這裡」的承諾。樁上綁的是草束、舊布、裂木牌或一截繩，不是裝飾。人們開始把泊位、火帶、田埂、乾棚線、礦坡危線和路旗視為可追責的世界邊界。

第一立樁後，世界第一次出現「亂碰別人的線」這種罪名。這不是法律先行，而是活下去的辦法：沒有線，倉不敢收貨；沒有線，船不敢靠；沒有線，夜路無人等人。

玩家可見：樁、繩、牌、封條、火帶、候檢線都可能擋路或觸發 NPC 制止。玩家不是不能碰，而是碰了要承擔「你憑什麼碰」。

### 三霧退樁

三霧退樁是中河最常被老人提起的舊事。連續三夜河霧壓岸，舊泊位樁被水草和泥推得整排偏移。第四天兩條船同時認同一個泊位，一船濕貨爛在等候線外，一個少年渡工被夾在船身與岸樁之間。

何家船樁從那年起不再只憑年資認位，而要每日看水痕、重綁繩、在樁頭刻當日短記。船戶行最討厭外人亂挪樁，不是因為保守，而是因為他們見過「樁錯，人就被世界吃掉」。

玩家可見：霧季時泊位更嚴格；渡工會先看樁痕再理人；玩家若幫忙重綁繩，能得到短暫信任；若亂動，可能造成停渡、求償或人際記錄。

### 中鎮開倉

中鎮不是因為地理中心而成為中鎮，而是因為一次失敗讓人知道「口頭承認不夠」。

那年東湖魚貨與南城濕穀同日壓到中河，雨後倉門前一片濕氣。兩批貨都說自己先到，保人互相作證，結果倉內混放，魚腥串進穀袋，南城糧戶拒收，中鎮三家保人賠到家戶拆梁。

之後中鎮出現外秤、寄放位、封條色、倉保人簿記與「濕貨不得貼穀」的倉場規矩。曹家倉保一脈就是從那場賠償後起來的。他們被需要，也被討厭，因為他們把人情變成能拒收人的門。

玩家可見：中鎮倉場先問封條與保證，不先問玩家想賣什麼；同一批貨若少了來源與保存狀態，可能從貨物變成麻煩。

### 七梁斷年

七梁斷年發生在西坡。七段坑口支梁在一個雨後月內接連斷裂，工坊說礦作偷省料，礦作說工坊修柄不承重，路隊說石門通行牌催得太急。最後查出不是單一人的錯，而是粗料含雜、支梁標記混亂、雨後泥坡滑移與趕交期一起把事故推成了連鎖。

從那以後，西坡不再相信漂亮石塊，工坊不再相信無標記粗料，石門不再相信「我做了很多年」這種口頭話。裂柄工具成為一種不祥物：它可能代表差料、趕工、撒謊或剛死過人。

玩家可見：裂柄不是普通損壞狀態，而會讓工坊追問來源；玩家拿著裂柄上西坡，可能被當成證人、嫌疑人、求修者或倒霉人。

### 水時爭年

南城外平野不是和平田園。最早的田渠靠熟人輪水，後來糧車、草場、畜力、倉場排程與南城商會都開始插手。水時爭年中，上游私開閘救了自己一片田，下游三個家戶失收，草場牧戶又因缺草料把畜群趕上田埂，衝突一路燒到南城外圈。

田渠戶盟從那年後強制刻水時木牌，水牌掛在哪一道渠口，誰能開、開多久、誰作證，都不再只是家戶私事。

玩家可見：水閘不是背景；玩家可以看水牌、問水時、幫清渠、作證、被要求不要站在閘口，甚至因延誤讓某一方記住。

### 空箱封潮

海門開潮後，最大的羞辱不是被騙錢，而是讓「外面來的信用」變成笑話。空箱封潮那年，一批潮外箱由翻譯、匯兌屋與稅棚三方放行，進南城後才發現箱中只有濕木、石粉與幾張不被任何人承認的外票。

宋家翻譯因此分裂。一支主張外語不可輕信，另一支主張海門若只會拒絕，就永遠只是河口。匯兌屋從此要求貨樣、翻譯、匯票、封條互相作證。海門人被外地客嫌慢，被內地人嫌貪，被自己人嫌膽小。

玩家可見：外貨不是高價商品而已；玩家可能需要找翻譯、辨貨樣、補封條、承擔匯差，或看到一批貨因無人敢作保而卡在稅棚。

## 核心土地縱深

### 中河

遠因：中河不是水道，是整個中河諸帶的承認軸。濕貨、渡船、消息、票據、求援與逃路都沿著它移動。

歷史傷痕：三霧退樁讓船戶行把泊位視為責任，不再只是排隊位置。老渡工說「水會偷線」，意思是河水會把人的承諾搬走。

現在矛盾：濕貨想先過，過路人想公平，船戶想守序，水倉想保價，南城想準時。中河每一次停渡都會讓別處的價和人情變動。

文化口感：河岸人把不懂水位的人叫「乾腳」，不是罵人窮，而是說他腳沒被中河教過。

玩家可見：水位牌、樁痕、泊位線、被擠退的人、渡工先看河不看人。玩家可讓船、幫繫繩、攔亂挪樁的人、替濕貨包護，或錯過船序。

### 東湖與霧草澤

遠因：東湖是水、草、魚與濕路互相纏住的地方。霧草澤更深，地貌會自己改寫路。

歷史傷痕：霧草吃標的舊事讓澤路人不願保證永久路線。曾有一隊採草人照著舊標進澤，三天後從另一條水口被帶出來，少了兩捆貨和一個人。

現在矛盾：東湖返潮提前，乾棚不夠。水倉會要貨快進倉，乾棚看管要先乾後收，割草人要保價，船戶不想載會滴水的貨。

文化口感：澤路人說「路在草下醒著」，意思不是路固定在那裡，而是懂的人知道今天能不能喚出它。

玩家可見：被潮氣壓低的蘆束、火帶邊爭位、導引繩被人重新綁過、有人拒絕說滿路。玩家可割蘆、曬草、借棚、買路訊、跟引路人、扶回被水改向的標。

### 西坡與山陰道

遠因：西坡讓山體變成工具材料，但每一步都在借危險。礦脈、坡道、泥、支梁與車轍一起決定材料能不能出山。

歷史傷痕：七梁斷年讓西坡人相信所有漂亮粗料都可能藏著別人的死。支梁名、坑口標記、洗礦溝記號都不是繁文縟節。

現在矛盾：粗鐵含雜增加，工坊缺料，礦作不認為自己該被壓價，石門想插手標準，中鎮修具人被兩邊催。

文化口感：坡作人說「亮石不算鐵」，意思是看起來能用的東西還沒有被工序承認。

玩家可見：裂柄工具、標記不全的粗料、被擋在粗料倉外的人、雨後封坡。玩家可分選、修具、扶支梁、作證、拒收可疑料，或因貪快帶出含雜貨。

### 南城平野

遠因：平野能養大城，但水時、田埂、草場、畜路、穀場和倉車把它切成許多看不見的邊界。

歷史傷痕：水時爭年讓南城外所有渠口都變成政治。水牌一旦被私動，不是小偷水，而是有人把一整串家戶的來年推向風險。

現在矛盾：南城需要穩定糧流，田渠戶盟需要按時用水，草場牧戶需要畜力，商會需要交期。水少時，每個人都說自己只是先救眼前。

文化口感：田渠戶說「水先認牌，再認人」。熟臉可以求情，但水牌錯了，熟臉也不能讓下游不失收。

玩家可見：水牌、渠口、草料價、糧車排程、站在水閘旁互相瞪的人。玩家可清渠、守牌、作證、送信、幫搬草料，或因晚到讓一批糧車改價。

### 中鎮

遠因：中鎮是多條世界鏈互相承認的地方。它不是新手村，而是把貨、人、路訊、票據、工具與信用轉成可用狀態的緩衝器。

歷史傷痕：中鎮開倉後，倉保人失去「只靠人情」的自由，也取得拒絕人的權力。這讓中鎮同時像救命地與冷臉門。

現在矛盾：倉位短，濕貨、粗料、糧袋和外貨都想進來。曹家倉保被說成只認封條不認人，工坊街又罵倉場把壞料推給修具人。

文化口感：中鎮人說「能用不算，能被認才算」。這句話也是中鎮的殘酷。

玩家可見：外秤、封條色、寄放位、修具排隊、告示被人撕角。玩家可寄放、作保、找熟臉、修工具、幫分選，或被拒收後只能改找更差的門。

### 石門

遠因：石門生在坡道與遠路之間。沒有短規矩，礦料、路隊、申訴、通行牌都會在每次事故後重新吵死一次。

歷史傷痕：七梁斷年後，石門議棚第一次把礦坡責任寫入通行規矩。從此石門被人需要，也被人罵成不講人情。

現在矛盾：石門想把粗料標準壓進中鎮，中鎮倉場不想被石門規矩接管，西坡礦作又覺得石門只會坐在門內寫牌。

文化口感：石門人說「多話成證」。所以趙枚這類兌牌人說話短，不是冷淡，而是每一句都可能被拿去申訴。

玩家可見：候檢線、兌牌桌、議棚前階、被退牌的人。玩家可申訴、兌牌、找保證、替裂柄工具說明來源，或因一句話被寫進短記。

### 北驛長路與邊鎮低牆

遠因：遠路不是空間連接，而是補給、守夜、同行、路旗、驛棚與信任組成的臨時社會。

歷史傷痕：不說滿路的禁忌來自一次「滿路話」事故。一名引路人收錢後保證安全，結果雨夜路旗被風改向，商隊在低牆外繞到水盡。後來遠路人不再說保證，只說最後一次有人走過是什麼時候。

現在矛盾：北驛路旗被改，巡路班說引路人亂收錢，引路人說巡路班沒有守夜，商隊只想知道何時能走。

文化口感：遠路人說「話說滿，水袋空」。意思是敢保證的人常常不是要陪你走到底的人。

玩家可見：水袋架、路旗、驛棚空位、夜宿名牌、被改向的旗。玩家可補水、守夜、報信、跟隊、扶標、買半舊路訊，或因不守夜被拒絕同行。

### 海門港與潮外

遠因：海門是中河與潮外規矩互相翻譯的地方。它把陌生貨、陌生語、陌生票據和本地責任壓成可通行或可拒絕的狀態。

歷史傷痕：空箱封潮讓海門永遠怕兩種錯：太信外人，被內地人笑；太怕外人，讓自己變成只會扣貨的河口。

現在矛盾：海門扣外貨，南城商會催交，翻譯怕背責任，匯兌屋怕假票，稅棚怕放錯貨。潮外客則覺得中河諸帶所有人都慢。

文化口感：海門人說「箱會說謊，封條也會」。所以他們要貨樣、翻譯、票據與人證互相咬住。

玩家可見：稅棚、翻譯桌、候泊線、遠洋倉門、外地票據、無人敢作保的箱。玩家可搬貨、找翻譯、補件、辨貨樣、承擔匯差，或讓一批貨繼續卡著。

## 核心制度縱深

| 制度 | 誰創立/成形 | 誰受益 | 誰被排除 | 誰在反抗 | 玩家如何碰到 |
|---|---|---|---|---|---|
| 家戶 | 潮前荒生後的共睡、共火、共工具關係 | 有熟臉、有工具、有小倉的人 | 外來者、欠過不還的人、無人作證者 | 年輕路人不想被家戶責任綁住 | 借工具、被留位、欠人情、被問「誰帶你來」 |
| 作坊 | 中鎮開倉後，材料需要被加工與承認 | 會手法的人、能供穩料的倉場 | 來路不明材料、急著只求便宜的人 | 無牌散工與被拒收的坡作人 | 修具、訂件、送料、學手法、被拒絕修裂柄 |
| 倉場 | 中鎮混貨賠償後形成 | 貨主、保人、能提供封條與寄放費的人 | 無封條、無來源、濕壞、混味、無熟臉的貨 | 水倉會、散戶、走急貨的人 | 寄放、分選、作保、被挑貨、看價變 |

制度的深度不是有名字，而是它們都有權力副作用。它們保護某些人，也排除某些人；玩家碰制度時，應該能感覺自己不是在開功能選單，而是在被某種地方秩序判斷。

## 核心材料縱深

### 蘆草

生態來源：蘆草長在東湖與霧草澤的水線邊，根系能抓泥，也會把舊路標、淺木樁和小獸徑慢慢吞住。蘆草不是雜草，是水邊文明的臨時骨架。

採取文化：割蘆人不割帶穗母叢，因為那是明年穩岸的根。澤路人用「留白帶」標記哪一片不能割，新手看起來像浪費，老手知道那是在留路。

加工知識：蘆草可曬成墊材、包貨襯、棚面、臨時繩芯、浮標束、路標草結、箭桿粗坯、濕貨隔層。未乾的蘆草便宜但會返潮，過乾的蘆草易裂，煙燻過的蘆草能防一段霉味但會讓魚貨串煙。

交易路徑：東湖割取，霧草乾棚初曬，東湖水倉分級，中鎮倉場承認，南城與海門大量消耗。

禁忌/傳說：亂割留白帶會被說成「削岸」。傳說有一年外來割草隊削完一片留白，隔月小水一推，兩個舊路口從此不再醒。

玩家可介入：割、曬、包、借棚、修浮標、做路標草結、替濕貨墊層、因錯割被澤路人防備。蘆草如果只做低價材料，不合格；它必須是玩家接入水邊秩序的工具。

### 河魚與鹽魚

生態來源：中河與東湖交界魚群豐，但水溫、霧、返潮和船序會讓魚貨壽命很短。

採取文化：魚戶不只捕魚，也看水色、分活魚、快死魚、可鹽魚、不可混倉魚。魚腥是倉場最怕的氣味之一，因為它會讓其他貨降價。

加工知識：活魚值路程，鮮魚值時辰，鹽魚值保存，壞魚值麻煩。鹽包不夠時，魚貨會從商品變成需要快處理的事故。

交易路徑：東湖短船到中河，能進水倉者往中鎮，壞得快者在近岸處理或壓價。

禁忌/傳說：魚貨不得貼穀袋是中鎮開倉後留下的硬規矩。老倉人說「魚味進穀，保人拆屋」。

玩家可介入：分揀、加鹽、換包材、爭船序、幫移到陰影、拒絕混放、承擔壞貨損失。

### 麻莖與麻繩

生態來源：麻地多在南城外與中鎮邊緣乾地，靠水但不能太濕。它是把鬆散物品變成可運輸狀態的材料。

採取文化：麻莖切後要漚、剝、曬、搓。麻繩匠看不起只會買成繩的人，因為繩的強弱藏在纖維處理裡。

加工知識：細繩用於綁封條和小貨，粗繩用於船、車與支梁，油浸繩耐水但難寫標記，乾繩好寫但怕潮。

交易路徑：南城外麻地到中鎮繩鋪，再往渡口、礦坡、海門。

禁忌/傳說：船戶不收無名繩。因為三霧退樁後曾有一批廉繩斷在霧夜，沒人認責。

玩家可介入：買繩、驗繩、補繩、用繩固定貨、綁路標、因用錯繩導致貨移位或被人追責。

### 粗鐵

生態來源：西坡礦脈露頭，含雜程度受雨、泥、礦層與分選影響。

採取文化：坡作人認坑口、支梁、洗礦溝與標記。沒有標記的粗鐵在他們眼裡不是自由貨，而是沒人敢承擔的麻煩。

加工知識：粗鐵要分選、洗、標、初鍛，再由工坊判斷能不能進工具。含雜粗鐵可便宜，但會讓柄、扣、刃在不該裂時裂。

交易路徑：西坡礦場到粗料倉，經石門或中鎮承認後進工坊。

禁忌/傳說：七梁斷年後，粗鐵若無坑口記號，很多工坊會直接拒收。

玩家可介入：分選、搬料、查標記、送工坊、替一批料作證、因貪便宜使用含雜料而留下裂具。

### 石灰石

生態來源：西坡與南城外緩坡皆有石灰石。它不是華麗材料，而是牆、倉基、排水、火帶與防潮的底層材料。

採取文化：石灰匠不愛被叫搬石人，因為灰的好壞決定牆能不能撐過返潮。

加工知識：燒灰需要火帶、風向與水量。灰太生不黏，灰太烈傷手，遇潮後會結塊。

交易路徑：西坡採石，近地燒灰，中鎮與南城消耗最大，海門用於潮濕倉基修補。

禁忌/傳說：乾棚火帶附近不可亂堆石灰袋，因為潮灰遇水結塊，會壓壞棚角。

玩家可介入：搬石、燒灰、補牆、修排水、替倉基加固、因保存不當讓灰袋變成廢重物。

### 鹽晶與鹽包

生態來源：海門潮線與潮外貨路帶來鹽晶。鹽是保存技術，也是港口信用的一部分。

採取文化：海門鹽戶看鹽色、潮味、結晶粗細與混沙程度。中鎮人常只看重不重量，被海門人笑成買白石。

加工知識：鹽可保存魚肉、壓制腐壞、清洗某些傷口，也會毀掉部分皮革與金屬件。

交易路徑：海門入岸，經稅棚與匯兌屋承認，往東湖、中鎮、南城。

禁忌/傳說：空箱封潮後，無貨樣鹽包常被懷疑混沙。海門有句話：「白的不一定能救魚。」

玩家可介入：買鹽、驗鹽、加鹽保存、分辨混沙、因用假鹽讓魚貨壞掉。

### 皮革與獸筋

生態來源：南城草場、北驛遠路與林澤邊緣都有獸群。皮革與獸筋是工具、背負、護具、繩扣與水袋的重要來源。

採取文化：牧戶重視畜牌，獵路人重視獵痕。來路不明的皮不是便宜貨，而可能代表偷獵、病獸或不被承認的衝突。

加工知識：皮要刮、曬、油、縫；獸筋可做弓弦、縛帶、修扣。潮氣會讓皮發霉，火太急會讓皮脆。

交易路徑：草場與遠路進中鎮工坊，部分往石門作護具和工具扣件。

禁忌/傳說：不問畜牌就收皮，會被草場牧戶視為幫偷。

玩家可介入：補水袋、修扣、辨皮、買護具、替牧戶找走失畜，或因收來路不明皮被牽連。

### 油布

生態來源：油布由麻布、草纖維、獸脂或植物油處理而來，是水邊、遠路、港口共同需要的防護材料。

採取文化：做油布的人常被嫌味重，但沒有人敢在霧季輕看它。船戶、水倉、路隊都認好油布。

加工知識：油布能包貨、防潮、遮棚、墊地、暫封裂縫；但靠近火帶會增加火險，遇熱會散味。

交易路徑：中鎮工坊與南城外布坊產出，渡口、水倉、海門大量消耗。

禁忌/傳說：乾棚內亂攤油布會被趕，因為它救濕貨，也招火。

玩家可介入：包貨、補棚、借布、交換油布、因亂放油布造成火險或被林素這類看管人記住。

### 霧草藥與腐水

生態來源：霧草澤裡有能清熱、止血、壓腐味的草藥，也有腐水、爛泥與有害菌群。兩者常在相近地方出現，外人容易混淆。

採取文化：澤路採藥人不教全路，只教「看到哪種草不要踩」。因為完整路線一旦外傳，採藥點會被踩壞。

加工知識：霧草藥需陰乾，不能急火；腐水可作少量防鼠、驅蟲或清洗某些工具上的腐味，但多了會污染貨物。

交易路徑：霧草澤採取，乾棚初處理，中鎮藥鋪或路隊買走。

禁忌/傳說：霧草藥不可和魚貨同棚，因為藥味被魚腥壓過後難辨真假。

玩家可介入：採藥、辨草、借陰棚、交給藥鋪、救急傷，也可能採錯把有害腐水當藥帶回。

## 人物家系與牽連

### 何家船樁

何栓是老渡工，何家三代認樁。三霧退樁時死去的少年渡工是何栓的叔父輩，何家因此把泊位視為家恥與家責。何栓不喜歡水倉會催急貨，因為他認為水倉的人只看貨壞不壞，不看人會不會被船夾死。

現在牽連：何栓與東湖短船戶阿澤互相需要，也互相嫌。阿澤嫌何栓守序太慢，何栓嫌阿澤把快壞魚籃推到船序前。

玩家可見：何栓先看水位和樁痕；阿澤會在不問玩家前拖貨。玩家若替阿澤保魚貨，可能被何栓防備；若替何栓守線，可能錯過水倉保價。

### 林家乾棚

林素的母親曾在紅棚火中失去一隻手。那場火不是大災，是一捆亂放油布、一段沒清乾的蘆束、一個想搶棚位的人一起造成的小事故。林素因此把火帶看得比人情重。

現在牽連：林素和水倉會關係緊張。水倉想多收濕貨，林素拒絕讓未乾草束越線。她被割草人罵冷，被船戶罵慢，但火帶沒出事時也沒人謝她。

玩家可見：林素踢出濕蘆束、要求誰背火險、拒絕油布靠火帶。玩家幫她守棚會得罪急貨人，幫急貨人搶棚位會被林素記住。

### 曹家倉保

曹印家族因中鎮開倉後的大賠償起家。他們不是天生富有，而是有人願意替混貨賠到底，才換來後來的倉場權。曹家家訓是「封條不替人說謊」。

現在牽連：曹印被散戶說無情，被南城商會說太慢，被水倉會說挑貨。他真正怕的是再發生一次魚味進穀，讓曹家名聲被拆掉。

玩家可見：曹印不急著收貨，先看誰跟玩家一起來。玩家若替一批貨作保，曹印可能記住；若貨壞，曹印也會記住。

### 趙門兌牌

趙枚出身石門兌牌家。她父親曾因多說一句「這人看起來可信」被申訴牽連，賠了一季牌桌收入。趙枚學到的是：話說短，責任才清。

現在牽連：趙枚不喜歡中鎮人情單，也不完全相信石門議棚。她知道硬規矩保護人，也會把無路的人排在門外。

玩家可見：趙枚把話切短，要求物、牌、證人對上。玩家可以補證、找保證、排隊等牌，也可能因答太多讓自己成為證詞的一部分。

### 宋家翻譯

宋鹿的祖父捲入空箱封潮。宋家一支被罵成放箱的人，另一支被罵成怕海的人。宋鹿站在中間，他知道潮外客不是都騙人，也知道聽錯一句話會讓本地人背債。

現在牽連：宋鹿常被稅棚、匯兌屋、南城商會同時催。每個人都要他快，但出了事第一個被指的人也是翻譯。

玩家可見：宋鹿聽完半句外語，先問誰願意替這句話負責。玩家可替他找貨樣、請人作保、搬扣貨，也可能被捲進匯差與假票。

### 周家修具

周衡的師父在七梁斷年後拒修一批裂柄，被人罵成見死不救；後來證明那些裂柄用了含雜粗鐵，若修回坑口會再斷。周衡繼承這個名聲：手藝好，但難說話。

現在牽連：周衡夾在西坡礦作和中鎮倉場之間。礦作要他承認料能用，倉場要他指出料有問題，他只看工具裂痕。

玩家可見：周衡看到裂柄先看裂紋，不先報價。玩家可請他修、請他判料、把結果帶回西坡或倉場，造成某一方不滿。

## 現代矛盾深水層

v1 的六條現代局勢可做第一批 runtime 內容，但 v2 要補出它們背後的人。

### 東湖返潮提前

表面是乾棚不夠，深層是水倉會、乾棚圈、割蘆人、船戶行對「誰承擔變壞」的爭奪。水倉會想先收進倉，乾棚圈怕火帶失控，割蘆人怕保價被壓，船戶行怕滴水貨污染船板。

玩家看到的不該是「返潮事件」，而是：一束被踢出棚線的濕蘆、一個急著改價的人、一條不願載貨的短船、一個要玩家背火險的看管人。

### 西坡粗料含雜

表面是工坊缺合格粗鐵，深層是七梁斷年後未完的責任戰。西坡說雨後礦層變了，中鎮說西坡想用舊標記混新料，石門說沒有硬規矩就沒人負責。

玩家看到的不該是「礦石品質下降」，而是：裂柄工具被擺在修具桌上、周衡拒絕報價、粗料倉前有人吵標記、趙枚手裡多了一張申訴短記。

### 南城水時緊

表面是田渠爭水，深層是大城吞吐與家戶生計互相擠壓。商會催交期，田渠戶盟守水牌，草場牧戶怕畜力掉，倉場怕糧袋延誤。

玩家看到的不該是「水資源事件」，而是：一塊被翻面的水牌、一輛被迫改時辰的糧車、渠口旁不肯讓路的人。

### 北驛路旗被改

表面是路旗方向錯，深層是巡路班與引路人圈的信用戰。巡路班想收回路訊權，引路人圈認為巡路班只會封路不會走路，商隊只要今天能過。

玩家看到的不該是「道路異常」，而是：兩面互相矛盾的旗、一個不願說滿路的祁路、一隊水袋已經半空的商隊。

### 海門扣外貨

表面是稅棚扣貨，深層是空箱封潮留下的創傷。海門害怕再放錯，南城害怕交期斷，潮外客害怕本地人永遠不懂外票。

玩家看到的不該是「港口任務」，而是：一口白封箱、一張不被匯兌屋認的外票、宋鹿問誰願意替一句翻譯負責。

### 中鎮倉位短

表面是倉不夠，深層是中鎮作為承認機器的負荷上限。倉場挑貨不是只為賺錢，而是怕一次錯收讓所有保人背債；散戶罵它冷，是因為被拒後貨物真的會壞。

玩家看到的不該是「倉庫滿」，而是：曹印把某批貨推回門外、濕貨滴到地上、工坊等不到料、有人求玩家幫忙找另一個保人。

## 玩家介入原則

玩家不是救世主，所以 v2 不設計「解決整個中河諸帶」的路線。玩家能做的是在一條具體世界關係中留下可被承認的事實。

合格介入示例：

- 幫何栓重綁一段樁繩，讓某船可以靠，但也讓急貨船晚一輪。
- 替林素把油布搬出火帶，保住乾棚秩序，但得罪想搶棚位的割蘆人。
- 替周衡把裂柄來源帶回西坡，使一批粗料被拒，也讓某個礦作人對玩家不滿。
- 幫宋鹿找足貨樣與人證，讓一批外貨放行，但玩家名字進入匯兌屋記錄。
- 在水時爭議中作證，讓下游保住水，也讓上游家戶記住玩家站在哪邊。

不合格介入：

- 只收集材料換固定錢。
- 只替 NPC 跑腿而沒有改變人、物、路、價、信用或痕跡。
- 一次點擊讓問題消失，世界不承擔後果。
- 所有勢力都感謝玩家。

## 仍然只是資料表的部分

v2 已把第一批核心土地、制度、材料、勢力與人物牽連深化，但下列內容仍不能宣稱有完整世界深度：

- 材料百科中尚未進入本檔的二級加工品、獸類細分、遠方外貨，仍多半只有用途與價格，需要各自補生態、文化與衝突。
- 完整日曆、季節名、節期與月份口語仍缺，現有時間只能支撐局部事件。
- 貨幣鎂的歷史、鑄造權、假幣、匯兌與信用史仍薄，不能直接做完整金融玩法。
- 種族、語言與遠方潮外文化仍是玩家接觸層，不是完整文明百科。
- 醫療、拘押、賠償、死亡後社會處理仍不足以支撐完整戰鬥長線。
- 門派、氏族、國家等高層社會系統仍只有關鍵字權威，尚未長出現行世界深度。

本節原本列出 v2 可拆的 runtime 鏈條；在能量根與 `world-bible-v3.md` 補完後，這些鏈條全部暫停直接進 runtime。它們只能作為舊素材，等待材料、勢力、地圖依 v3 重寫。

舊鏈條暫存：

1. 中河認樁鏈：中河 -> 船戶行 -> 何家船樁 -> 麻繩/蘆束 -> 霧季泊位 -> 玩家繫繩/讓船/亂碰後果。
2. 東湖乾棚鏈：東湖/霧草澤 -> 霧草乾棚圈 -> 林家火帶 -> 蘆草/油布 -> 返潮保價 -> 玩家借棚/搬油布/包貨。
3. 西坡裂柄鏈：西坡 -> 西坡礦作/中鎮工坊 -> 七梁斷年 -> 粗鐵/裂柄工具 -> 玩家分選/送修/作證。
4. 中鎮倉保鏈：中鎮 -> 倉場聯保 -> 曹家倉保 -> 河魚/濕穀/封條 -> 玩家寄放/作保/被拒收。
5. 海門白封鏈：海門 -> 稅棚/匯兌屋/宋家翻譯 -> 空箱封潮 -> 外貨/鹽包/白封 -> 玩家找翻譯/補貨樣/承擔匯差。

若繼續世界補完，優先順序是：

1. 鎂與信用史。
2. 季節、曆法與地方節期。
3. 高層政體：南城、石門、海門、潮外與未來國家/聯盟/門派如何互相承認。
4. 完整醫療、賠償、拘押與死亡後果。
5. 玩家初始身份來源與多起點如何被世界承認。

## 禁止方向

- 不把 v2 深度寫成小說散文後不回玩家可見狀態。
- 不用更多專名掩蓋缺乏因果。
- 不把蘆草、魚貨、粗鐵、封條、路旗等物件只當交易材料。
- 不讓所有事件都等玩家主動接任務才發生。
- 不把 NPC 寫成商人、任務板、聊天端點或隨機台詞。
- 不讓玩家一次修好整個制度。
- 不把奇幻自動寫成遠古/中古年代感；船戶、倉場、作坊、田渠、城邦等只能是局部制度素材，不能變成整個世界的時代模板。
- 不使用會讓世界顯得原始、土法、低技術、低生活密度的粗糙語彙作為預設風格；本檔既有相關語彙須在下一輪重寫。
- 不把能量充沛只寫成生態富態、天候現象、材料質感或危險變強；必須設計成可普及、可轉換、可儲存、可制度化、可被普通人日常使用的世界憑依層。
- 不回收舊世界特殊設定。
- 不導入通用生存條。
