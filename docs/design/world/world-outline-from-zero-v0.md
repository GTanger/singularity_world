## 0. 本檔定位

本檔先回答「這是一個什麼世界」，再讓遊戲內容往下長。它不是材料包、地圖包、勢力表、戰鬥公式，也不是把舊稿改順。

奇點目前最需要的不是更多地名或卡片，而是一個能承受追問的故事根：

- 為什麼這個世界是奇幻世界。
- 為什麼普通人會這樣生活。
- 為什麼城市、道路、工具、名字、交易、戰鬥和死亡會長成現在樣子。
- 為什麼玩家進入後會想碰、想查、想承擔、想回訪。

本檔是「世界大綱」，不是完整 World Bible。後續完整世界聖經必須從本檔擴寫，而不是回到 v4、v2.5 或局部第一季卡名續寫。

## 1. 一句話世界

奇點是一顆能量充沛的平行地球：能量不在某個裝置、礦物、法術槽或管理系統裡，而是像空氣一樣存在於水、土、光、聲音、血肉、食物、植物、物件、名字、情緒、死亡與回憶裡；生命不是取得能量，而是在每一次呼吸、觸碰、行走、稱呼、交易、製作、戰鬥、照顧與埋葬中和世界交換。

這個世界的核心不是「誰掌握能量」，而是：

```text
萬物都太容易互相影響，生命必須學會建立自己的邊界。
```

這句話是後續世界、文明、地圖、物件、NPC、經濟、戰鬥和玩家動詞的根。

## 2. 禁止誤讀

以下方向會把奇點寫歪：

- 能量不是電力、燃料、法力條、特殊礦產、公共資源或可被誰總控的基礎設施。
- 能量無處不在，不代表所有東西都要被寫成工程、標準、事故、責任或行政問題。
- 平行地球不等於復刻現實地球；地球史只可作分歧校準。
- 奇幻不等於遠古、中古、封建、村落手工業、酒館公會或低生活密度。
- 深度不等於詞彙複雜，也不等於把每個物理現象都寫成設定表。
- 活世界不是全世界為玩家表演，而是玩家撞進局部事實，並留下能被後來讀到的差異。

## 3. 世界根規則

### 3.1 萬物含能

空氣有能量，所以呼吸不是單純換氣。水有能量，所以河海不是背景。土有能量，所以土地不是地圖底色。聲音有能量，所以稱呼、歌、哭喊、傳聞和沉默都不是純文字。血肉有能量，所以傷口、病、疲乏、死亡和照顧不是單純數值。物件有能量，所以長期使用過的工具不是空白道具。

玩家意義：玩家不是尋找能量，而是進入一個每個可見東西都可能已經被生命、地方、時間和事件改變過的世界。

### 3.2 生命是邊界

在奇點，生命最早面對的不是缺乏，而是過盛。世界太容易交換，生命如果沒有邊界，就會被環境、群體、獵物、獵者、聲音、記憶和死亡沖散。

因此生命演化出的不是「使用魔法」能力，而是各種邊界：

- 皮膚、殼、毛、葉面、氣味、毒、光澤。
- 巢、領地、遷徙、群居、求偶、葬行、共生。
- 模仿、偽裝、忘卻、記路、認人、避讓。

玩家意義：荒野不是採集場。每片林、岸、原、潮、霧、光，都在處理「誰能接近、誰被排斥、誰被記住、誰被吞沒」。

### 3.3 人類用名字建立第二層邊界

人類不是能量的主人。人類厲害之處，是把邊界變成語言、名字、工具、住所、路、禮、故事、託付、交易、醫療、教育和法律。

名字不是舊特殊系統，也不是可被拿走的資源。名字是人類對流動世界說「這個人、這個地方、這件物、這段事，暫時如此被認出」。

玩家意義：角色名字、NPC 稱呼、地名、物件舊稱、傳聞中的外號，都不是裝飾。它們會影響誰信任玩家、誰誤認玩家、誰願意幫忙、誰避開玩家、哪件物願意被拿起。

### 3.4 工具是長期接觸形成的第三層邊界

工具不是單純材料加工品。工具是人把身體、習慣、技藝和世界反覆磨合後留下的邊界。

同一把刀，生手拿起只是利器；熟手拿起是延伸；前主剛死時被拿起，可能帶著不合手的抗拒；被錯誤修補後再使用，可能把錯誤傳給下一個人。

玩家意義：裝備等於工具。玩家拿起工具，不只是加數值，而是取得某些可做動詞，也接上工具的前史、熟練、風險與社會看法。

### 3.5 文明是共同維持邊界的方法

家戶維持人和物的邊界。街區維持鄰里和陌生人的邊界。門派維持技藝和傳承的邊界。城市維持人流、物流、名字、消息、傷病、教育與娛樂的邊界。國家和聯盟維持大尺度通行、衝突和承認。

文明不是壓在世界上的管理表，而是人類在能量充沛、生命濃密、牽連太多的世界裡，為了能繼續生活而長出的共同方法。

玩家意義：NPC 不是服務點。每個居民都在某些邊界裡生活、維護、逃避、破壞或鑽縫。

## 4. 世界史大綱

### 4.1 含能成星

奇點地球形成時，能量已經和空氣、水、土、光、聲音、礦層、潮汐與生命前物質一起存在。這顆星球從來沒有「無魔時代」。

現在結果：

- 地貌不是普通地貌換名。
- 氣候不是單純天氣。
- 材料不是自然物名單。
- 聲音、光、雨、潮、風、土壤都可能影響生命和文明。

### 4.2 萬生立界

生命在過盛交換中演化。活下來的生命不是最會吸收者，而是最能保持自己、選擇接觸、避免被錯誤牽連者。

現在結果：

- 生態高度繁盛，但豐饒不等於安全。
- 危險不只來自怪物，也來自誤觸、誤認、誤入、誤帶。
- 探索的核心不是拿素材，而是讀懂生命如何劃界。

### 4.3 呼名成人

人類發現聲音與名字能讓流動世界暫時被認出。最早的文明不是城牆，而是叫名、守夜、分食、記路、照看傷者、埋葬死者與傳述舊事。

現在結果：

- 名字有角色扮演重量。
- 葬禮、醫療、教育、路標、交易、門派傳承都從呼名與承認長出。
- 外地人不是沒有名字，而是名字尚未被地方接住。

### 4.4 工具與長居

人反覆使用工具、反覆走路、反覆回家、反覆照看同一群人後，世界開始承認那些長期邊界。工具、家、路、街、城不再只是物理結構，而是大量接觸與記憶的結晶。

現在結果：

- 工具可能認手或拒手。
- 熟路比新路更可靠，但也可能把人帶回舊事。
- 城市密度高，因為人需要在高牽連世界中靠近彼此又保持可生活距離。

### 4.5 連城井噴

能量充沛讓文明不是停在低技術時代。奇點當代應是成熟而陌生的奇幻當代：城市高密、交通成熟、遠行常見、教育普及、醫療發達、娛樂豐富、交易活躍、消息流動快，但這些都不是現代地球科技換皮。

現在結果：

- 生活密度高，不是原始村落。
- 普通人會讀一些名字、物件、路況和身體邊界的日常知識。
- 專門者不是因為壟斷能量而高人一等，而是更懂如何處理複雜邊界。

### 4.6 大回潮

文明累積太多接觸、交易、死亡、遷徙、戰鬥、愛恨、名字和物件前史後，世界曾發生一次大回潮：過去不再安靜待在過去，而是以人能碰到、走到、聽到、拿起、認錯或被牽連的形式回到現在。

大回潮不是災難片，不是世界末日，也不是能源事故。它是奇點文明第一次明白：世界記得太多，而文明越成熟，過去越重。

現在結果：

- 舊物可能回到現在。
- 舊路可能短暫浮現。
- 舊名可能讓錯的人回頭。
- 舊傷可能影響醫療與證詞。
- 舊承諾可能壓到今天的交易與人際。

### 4.7 回潮後當代

當代奇點不是倒退社會。它是成熟文明學會和過多牽連共處後的時代。

當代人最常面對三個問題：

1. 什麼應該被記住，什麼應該淡去。
2. 誰能承擔一件物、一段路、一個名字、一個承諾或一場傷害。
3. 外地人如何被地方承認，又如何利用自己尚未被綁死的位置。

## 5. 當代生活大綱

### 5.1 普通人如何生活

普通人不會每天驚訝世界含能，就像現實人不會每天驚訝空氣存在。他們真正熟悉的是邊界日常：

- 出門前確認身上帶的物是否合適。
- 到陌生街區先用被接受的稱呼開口。
- 借物時說清使用者、去處、歸還時點和可承擔的錯。
- 醫療不只處理身體，也處理傷口留下的牽連。
- 遠行不是單純移動，而是讓名字、物、消息、承諾跨地方。
- 娛樂、演出、故事和歌能讓共同記憶被整理，不只是消遣。

### 5.2 社會層

奇點的社會層從共同維持邊界長出：

| 層級 | 存在理由 | 玩家會碰到什麼 |
|---|---|---|
| 家戶 | 維持人、物、名字與照看的最小穩定圈 | 借物、作保、歸還、拒見、家物前史 |
| 街群 | 在陌生人與熟人之間建立日常承認 | 問路、稱呼、交易、看守、傳聞 |
| 門派/行 | 把工具、身體和技藝的邊界傳下去 | 學技、試手、修補、被拒、被承認 |
| 城市 | 容納高密度人流、物件、教育、醫療、娛樂和遠行 | 初入、登名、找人、交易、衝突、求助 |
| 國家/聯盟 | 處理長距離通行、爭端、共同風險與大尺度承認 | 身份、通行、遠路委託、跨城追索 |
| 種族/人形群體 | 不同生命邊界與文明方法的長期差異 | 互讀錯誤、共居規矩、不同身體與稱呼 |

### 5.3 當代語彙方向

奇點要有自己的時代感。語彙應偏向成熟、城市、高密、可生活、奇幻日常，而不是粗糙低技術。

可用方向：

- 廊、站、所、院、行、聯城、街群、遠路、照看、修物、叫名、試手、暫持、歸還、淡痕、回潮。

命名先求普通可讀，再求世界味。若一個詞只是職能、位置或行為，優先寫成「某處的人」「正在做某事的人」，不要立刻升成稱號、階級或組織。`某某者`、`某某師`、`某某階`、`某某人群` 只有在世界內真的有人如此稱呼、且玩家能從畫面理解時才可保留。

需警惕方向：

- 用村莊、酒館、公會、渡口、倉庫、木棚、粗布、手工小作坊等詞彙當世界預設。

這些詞不是永遠禁用，但只能是局部地貌或地方特色，不能成為奇點整體年代感。

## 6. 大地理大綱

第一版大地理不是 M4 場景，不能直接實作。它們只是世界故事功能區。

| 大區 | 世界功能 | 玩家第一層吸引力 |
|---|---|---|
| 長息聯城帶 | 高密度城市群，人流、名字、教育、醫療、演出、交易和遠行交疊 | 玩家學會自己如何被地方承認，名字與持物如何改變待遇 |
| 回潮原 | 大回潮最厚的開闊地，舊路、舊戰鬥、舊聲偶爾回到現在 | 探路、避路、救人、追查、利用短暫舊路或承擔帶回的麻煩 |
| 沉物海岸 | 海岸常把不該只是貨物的東西送回來 | 暫持、歸還、藏起、改用、交易、被追討 |
| 不留林 | 有些行動在其中留不下來，吸引逃亡的人、療傷的人、找人的人和想忘事的人 | 尋人、藏物、放下、追不回、決定誰有權消失 |
| 靜火列島 | 火與工藝長久保留使用、誓言、修補與失手 | 修物、試手、學技、處理工具抗拒與前主牽連 |

| 遠行脊路 | 長距離通行由反覆遠行、託付、失約和消息建立 | 跟隊、託付、改路、等待、錯過、離線安排 |

## 7. 玩家入場

玩家第一身份暫定為 `外地遠行的人`。這不是職業，也不是主角光環。

玩家一開始的核心問題：

```text
我叫什麼？
這裡是否承認我？
我身上有什麼？
我能碰什麼？
我碰了會把什麼事接到身上？
我離開後，這件事會如何繼續？
```

玩家好玩的地方不在於被世界選中，而在於：

- 本地人被家戶、熟路、舊名、舊物和舊怨綁得太緊。
- 玩家名字還輕，反而能進入縫隙。
- 玩家能碰別人不願碰、不敢碰、不能碰、碰了代價太高的事。
- 玩家做的小動作會被世界承認，而不是被任務腳本吃掉。

## 8. 第一季故事大綱

第一季不救世界。第一季要證明：奇點是可玩的活世界，而不是背景散文。

```text
外地遠行的人抵達長息聯城邊緣
-> 名字尚未被地方完整承認
-> 身上或腳邊出現一件有前史的物
-> 玩家必須選擇暫持、歸還、藏起、改用、追查、交易或作保
-> NPC 不等玩家點對話，他們也會搶先、懷疑、幫忙、避開、出價、追討或誤認
-> 玩家離開或下線後，物、人、路、價格、傳聞與關係繼續推進
-> 回訪時，畫面用局部狀態證明玩家的行動沒有消失
```

第一季驗收不是任務完成，而是玩家能讀到：

- 我的名字比剛來時更重或更麻煩。
- 我帶過的物不再是空白道具。
- 某個 NPC 因我的選擇改了去處、態度或手上持物。
- 某條路、某個價、某句傳聞、某個入口因我而不同。
- 我沒做的事也繼續發生了。

## 9. 玩家動詞

奇點第一批可玩動詞應從世界根長出，而不是從 UI 按鈕倒推。

| 動詞 | 世界根 | 可見後果 |
|---|---|---|
| 看 | 世界狀態可被讀，但不全為玩家展開 | 看見物件前史線索、NPC 避開、路況變化 |
| 問 | 名字、稱呼、傳聞會改變承認 | 被回答、被拒、被誤認、牽出另一人 |
| 碰 | 接觸會交換 | 物件順手、抗拒、沾上玩家痕跡 |
| 拿 | 持物等於承擔部分前史 | 前主、旁人、場所或追討者反應 |
| 暫持 | 不立刻占有，也不立刻歸還 | 物件與相關 NPC 在時間中推進 |
| 歸還 | 承認來處 | 信任、報價、關係、傳聞改變 |
| 藏起 | 嘗試切斷可見牽連 | 追查困難、關係受損、回訪留缺口 |
| 改用 | 讓物件離開原本用途 | 工具拒手、失手、學技、被人評價 |
| 作保 | 用自己的名字承擔他人或物件 | 信用變重，也可能背上錯 |
| 修補 | 修的是物與前史，不只是耐久 | 恢復、改變、失真、被拒修 |
| 交易 | 交換物，也交換來處和信用 | 價格、追討、缺貨、轉手痕跡 |
| 戰鬥 | 邊界被強行改寫 | 傷、物損、目擊、關係、地方記憶 |
| 離開 | 不等於事情停止 | 錯過、被搶先、回訪差異 |

## 10. 從大綱到內容的生成令

任何地點、物件、NPC、材料、勢力、衝突或玩法，必須先回答：

1. 它來自萬物含能、生命邊界、人類命名、工具接觸、共同生活或大回潮中的哪一層。
2. 它現在如何影響普通人的日常。
3. 玩家第一眼看見什麼。
4. 玩家第一個能做的動詞是什麼。
5. NPC 不被玩家接觸時會如何繼續。
6. 玩家介入後，哪個人、物、路、錢、名字、風險、關係或回訪文字會改變。
7. 這件事有什麼現實做不到、但在奇點可被承認的非日常可為性。

答不出，就不能進下游包，更不能進 runtime。

保留為上一輪故事重塑材料。它有可取的「萬物含能、接觸留痕、大回潮、外地遠行的人」方向，但目前過早把內容拆到具名地點、物件、NPC 和卡組，容易讓局部卡名反過來綁住世界。

處理方式：降格為素材，後續只能逐段通過本檔的世界根與玩家動詞驗收後抽取。

### `world-bible-v4.md`

保留為反面教材。它修正了能量不是電力，但仍把世界推成治理、標準、事故和責任問題，失去奇幻作品的故事吸引力。

處理方式：不得作世界入口。

### 下游地圖/材料/勢力/戰鬥包

全部暫停正向續寫。等本檔被審過並擴成完整 World Bible 後，再從新世界根重寫。
