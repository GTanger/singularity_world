## 0. 本檔要修正什麼

v4 的錯不只是用詞。它把「能量像空氣一樣無處不在」寫成制度、標準、事故、責任與管理問題，結果世界沒有故事吸引力，玩家也不會想進入。

本檔重頭回答：

- 這個世界是什麼。
- 它為什麼是奇幻世界。
- 它的歷史為什麼會造成現在狀態。
- 普通人如何在其中生活。
- 玩家為什麼想進入。
- 地圖、物件、NPC、交易、衝突和回訪差異如何自然長出。

本檔不是材料表、勢力表、地圖表或戰鬥公式。它是世界本體的大綱正典。下游包只能從本檔推導，不能反過來支配本檔。

## 0.1 從零世界大綱

本檔不是把 v4 改好，也不是把 v1.4 加厚。奇點必須先像一個能被閱讀與追問的世界成立，才有資格長出遊戲。

### 世界名稱與本體

世界名暫定：`奇點地球`。對居民而言，它不是「另一個有魔法的地球」，而是他們唯一知道的世界。

它是一顆能量無處不在的平行地球。能量存在於空氣、水、土、光、聲音、血肉、食物、工具、屋面、道路、名字、承諾、傷口、死亡與回憶裡。人不去找能量，也不把能量當燃料；活著本身就是和世界交換。

### 世界承諾

玩家進入奇點，不是為了管理一套系統，也不是為了讀一段背景設定。玩家進入，是為了在一個會留下痕跡的世界裡做決定。

最低承諾：

- 每個重要物件都不只是道具，至少能追問前主、來處、使用史、願不願被轉手。
- 每個重要地點都不只是座標，至少能追問曾經發生什麼、現在因此如何不同。
- 每個重要 NPC 都不只是功能入口，至少有今日去處、持物、關係、未被玩家接觸時的推進。
- 每個玩家動作都不只是按鈕結果，至少會改變一個人、物、路、錢、稱呼、風險或回訪文字。

### 世界故事引擎

奇點的故事不是「某人擁有力量」。故事引擎是：

```text
接觸 -> 交換 -> 留痕 -> 被讀到 -> 被承擔或改寫
```

這條鏈必須支撐所有內容：

- 呼吸讓人帶著地方。
- 觸碰讓物件認手或拒手。
- 稱呼讓人、地、物或舊事被叫起。
- 道路記住反覆腳步，也可能拒絕陌生持物。
- 交易不是貨幣換物，而是來處、信用、保存、前主和追討一起交換。
- 戰鬥不是傷害數字先行，而是身體、工具、地勢、目擊者與舊痕一起變成後果。

### 世界史總線

1. **含能成星**：空氣、水、土、光、聲音與生命前身一起成為含能世界，不存在「後來被發明的魔法層」。
2. **萬生過盛**：生命面對的不是缺能，而是交換過多；能保持自身、遮蔽、模仿、共存者活下來。
3. **呼名成人**：人類用名字、工具、葬禮、道路和家戶把流動世界暫時穩住。
4. **共居成城**：城市、門派、氏族、國家與聯盟從照看人、物、路、傷病、遠行與舊事的需求長出。
5. **大回潮**：文明累積太多失物、誓言、戰鬥、交易、死亡、愛恨與未完之事，世界把過去推回現在。
6. **回潮後當代**：文明沒有退回古代，而是變成高密、成熟、奇幻日常化的當代世界；普通人生活在大量可讀、可誤讀、可承擔的痕跡裡。

### 當代時代感

奇點當代必須避開兩種錯誤：不能變成現代地球換皮，也不能退成古代或中古。它應是成熟但陌生的當代奇幻：

- 城市密度高，街區、人群、學習、醫療、娛樂、交通、交易與遠行消息成熟。
- 物件密度高，工具、衣物、容器、路牌、票據、家物都可能帶著前主與使用史。
- 社會密度高，家戶、門派、氏族、城市、國家、聯盟與人形群體並存。
- 歷史密度高，上一秒、上一場雨、上一個使用者、上一場衝突都可能成為現在狀態原因。
- 奇幻日常化，普通人不驚訝萬物含能，但會敬畏亂碰、亂叫名、亂轉手、亂承諾。

### 玩家入場大綱

玩家第一身份暫定為 `外地遠行者`，不是職業，也不是主角標記。

玩家一開始應面對六個問題：

```text
我在哪裡
我叫什麼
我身上有什麼
誰看見我
我能碰什麼
我碰了會留下什麼
```

第一季不需要救世界。它需要一件小到可操作、但足以證明世界不同的事：一個名字還很輕的外地人，碰到一件不該只是道具的物，並選擇暫持、歸還、藏起、改用、交易、追查或作保。下一次回訪時，世界必須讓玩家看見這件事造成的局部差異。

## 0.2 作品級世界大綱 v2.2

v2.1 仍偏向「機制命題」。v2.2 先把世界寫成可閱讀的大綱，再讓機制從故事長出。

### 故事總題

奇點地球是一顆能量充沛的平行地球。能量不是電，不是燃料，不是被某個機構管理的東西；它像空氣一樣在每一次呼吸裡，也像水、土、光、聲音、血肉、工具、道路、名字和死亡一樣，天然屬於世界。

這個世界的故事，不是人類如何發明魔法，而是生命如何在過於豐盛的世界裡保持自己。活著會交換，交換會留下東西；人越會生活，世界就越記得他們。文明因此變得繁盛，也因此變得沉重。

當代奇點的核心故事是：

```text
人類已經建立成熟文明，卻無法把過去留在過去。
舊物、舊名、舊路、舊傷、舊愛、舊死，仍會以人能碰到的形式回到現在。
玩家是一個名字還很輕的外地遠行者，第一次學會：在這個世界裡，小動作也會被世界承認。
```

### 世界史主幹

| 時代 | 故事意義 | 現在留下的可玩結果 |
|---|---|---|
| 初息時代 | 星球形成時，空氣、水、土、光、聲音與生命前身就都帶著能量；世界從一開始就不是無魔地球。 | 每一種地貌都能保存、淡化或扭曲人和物留下的狀態；地圖不能只是地形表。 |
| 萬生時代 | 生命面對的不是缺乏，而是過盛；活下來的生命學會成形、遮蔽、模仿、排出與共存。 | 荒野不是素材採集場，而是生命互讀、避讓、吞食、借用與偽裝的地方。 |
| 呼名時代 | 人類發現名字、歌、工具、火旁故事與葬禮能讓流動世界暫時穩住。 | 玩家姓名、NPC 稱呼、地名、物件舊稱、死亡處理都具有角色扮演重量。 |
| 長路時代 | 人開始反覆走同一條路、使用同一件物、聚居同一片地方；家戶、行隊、門派、城市由此長出。 | 路會變熟，工具會認手，街區會認人；交易、學習、修物、問路都有歷史。 |
| 大回潮 | 文明累積太多失物、誓言、戰鬥、遷徙、死亡與未完之事，世界把過去壓回現在。 | 舊路浮現、失物回岸、錯名牽連、工具拒手、死者舊事重新牽動活人。 |
| 回潮後當代 | 文明沒有倒退，而是發展成能和「回來的過去」共處的高密度奇幻當代。 | 城市、醫療、教育、娛樂、遠行、交易成熟；玩家進入的是生活密度高的世界，不是原始村落。 |

### 當代矛盾

當代人不是每天驚呼世界有能量。他們早已習慣世界含能，就像現實人習慣空氣存在。真正困擾他們的是三件事：

1. **該記住什麼**：舊物、舊名、舊債、舊死如果全被保存，人會被過去拖垮；如果太快淡掉，人又會失去根。
2. **誰能承擔什麼**：拿起一件物、替一個人作保、走上一段路、叫出一個名字，都可能把別人的事接到自己身上。
3. **外地人如何被承認**：玩家一開始沒有本地家戶、門派、熟路和熟臉，名字很輕；但正因如此，也能進入別人不願碰的空隙。

這三個矛盾必須比任何王國年表更優先，因為它們會直接生成玩家可玩內容。

### 大世界輪廓

第一版世界不從北岸、渡口、小市起頭，而從能支撐故事的大片區起頭：

| 大區 | 讀者先讀到的故事 | 玩家第一層可玩性 |
|---|---|---|
| 長息諸城 | 高密度城市群，人群、聲音、名字、工具、醫療、學習和演出讓生活像潮水一樣擁擠。 | 玩家學會自己是誰、身上有什麼、誰看見自己、名字如何被承認。 |
| 沉物海岸 | 海會把不該只是貨物的東西送回來，失物、前主、追討者與買手在岸上相撞。 | 撿拾、辨認、暫持、歸還、藏起、交易、被追討。 |
| 回潮原 | 大回潮最厚的地方，舊腳步、舊戰鬥、舊路和舊聲偶爾回到地表。 | 探路、避路、救人、找失物、利用短暫出現的舊路，也可能帶回麻煩。 |
| 不留林 | 有些行動在林中留不下來，因此吸引逃亡者、療傷者、追索者和想忘事的人。 | 追蹤失敗、藏物、放下、尋人、面對該忘或不該忘的事。 |
| 靜火列島 | 火長時間保留烹煮、誓言、工藝、祭儀與戰鬥留下的狀態。 | 修物、學技、辨火、處理工具與誓言的後果。 |
| 遠行脊路 | 長距離道路不是交通線，而是由遠行者、行隊、失蹤者和門派踩出的關係網。 | 跟隊、託付、護物、改路、錯過、離線安排。 |
| 淡痕盆地 | 某些過去會在此慢慢變淡，療傷、葬禮、告別和犯罪都可能靠近它。 | 療傷、放下、讓一段牽連變淡，也可能失去重要線索。 |
| 暖生南域 | 生命濃度最高的沃土帶，豐饒不是安全，而是所有生命都更會爭奪、模仿與吞食。 | 採集不是割草，探索要讀生物、路、缺席與被偽裝的危險。 |

### 第一季故事大綱

第一季不是宏大戰爭，也不是新手村跑腿。它只要證明一件事：奇點世界可以被玩家用小動作改變。

```text
外地遠行者入城
-> 名字還不被地方承認
-> 碰到一件從海岸回來、帶有前主和追討壓力的物
-> 玩家選擇暫持、歸還、藏起、改用、交易或作保
-> NPC 依同一世界規則搶先、懷疑、幫忙、拒絕或追討
-> 路線、價格、關係、物件狀態和回訪文字改變
```

第一季的故事重點不是任務獎勵，而是玩家第一次明白：

- 我的名字在這裡有重量差異。
- 我手上的東西不是空白道具。
- NPC 不是等我問話的人，他們也會在我不碰時行動。
- 我下線或離開後，這件物和相關的人仍會往下走。
- 我回來時，世界會以局部狀態告訴我：之前那一步沒有消失。

### 下游寫作紅線

後續任何地圖、物件、NPC、勢力、材料或戰鬥，都要先能被放回上面這條故事：

```text
這是能量充沛平行地球的哪種自然/生命/文明結果？
它和大回潮或當代生活有什麼關係？
它讓普通人如何生活？
它讓玩家做了哪個現實做不到的決定？
它會讓人、物、路、名字、錢、關係或回訪文字如何不同？
```

答不出這五題，就不是世界大綱長出的內容。

## 1. 外部校準

本檔只取外部研究的校準判準，不照抄任何作品模板。

| 校準來源 | 取用判準 | 回落到奇點 |
|---|---|---|
| 奇幻魔法系統寫作經驗 | 奇幻力量有趣之處常來自限制、代價與不能做什麼，而不是能力清單 | 奇點能量無處不在，但玩家不能靠它許願；接觸會交換，交換會留痕，留痕會成為後果 |
| 文字 MUD 與持續世界 | 文字世界的深度來自持續存在、角色歷史、社群、經濟、政治與長期累積 | 奇點的文字不是散文，而是顯示人、物、路、名字與過去累積到現在的狀態 |
| 深度 RPG 敘事設計 | 小地圖也能有厚度，關鍵在人物、地方、歷史與世界觀彼此牽連 | 奇點不靠大而空的地圖吸引玩家，而靠每個可觸碰物都能追問來處、牽連與後果 |

校準後的結論：

```text
奇點不是能量管理世界。
奇點是萬物含能、接觸留痕、歷史回到現在、玩家能用小動作改變局部事實的文字奇幻世界。
```

## 1.1 具名歷史牽連 v2.4

v2.3 已經把世界根、故事總題、大區、生活共同體與代表人物立住，但它仍有一個缺口：讀者知道「大回潮」重要，卻還不一定能感到這個世界真的曾經活過。

v2.4 補的是故事骨架的中段：哪些事真的發生過，誰因此得利或受傷，今天的城市、道路、物件、群體和人物為什麼會是現在這個樣子。

### 三條長歷史線

奇點當代所有局部故事，都應至少能接回三條長線之一。

1. `名字線`：人類用名字讓流動世界暫時穩住；後來名字也會誤認、排斥、保護、牽連和叫回舊事。
2. `持物線`：工具、家物、失物和交易物不是空白道具；長期使用、死亡、修補、轉手和歸還都會留在物上。
3. `路與去處線`：路不是交通背景；反覆腳步、失約、逃亡、跟隊、救援和錯過，會讓路變成熟路、重路、岔路或回潮路。

這三條線不是新系統名，而是寫作檢查。若一個地名、物件、NPC 或衝突接不上任一長線，它多半只是漂亮名詞。

### 具名歷史事件

以下事件不是年表裝飾。每一件都必須能解釋今天的人、物、路、價、稱呼、禁忌或玩家動詞。

#### 第一唱名

最早的高密聚居時代，人群發現：在多人同住、同工、同葬、同路的地方，單靠面貌和親族不足以讓一個人穩住自己。於是有了公開唱名：孩子出生、遠行隊出發、工具交給新手、死者入葬，都有人在眾人面前叫出名字。

這件事沒有讓人類掌握世界，只讓人類學會用聲音和共同見證把流動的人暫時叫住。

現在留下：

- `長息聯城` 的外客名階從此而來，外地人進入城市生活時先處理稱呼，而不是先選職業。
- `織南` 所屬的唱名師不是宗教裝飾，而是普通人生活中的身份維護者。
- 玩家第一次說自己的名字時，城市不是彈出角色名欄，而是有人、物、街區開始用不同方式承認或誤認玩家。

#### 三街同名夜

長息諸城擴大後，許多街區沿用相同俗名。某一夜，三座城市的同名街同時有人叫出同一個舊稱，結果三地都有人回頭：活人、死者的持物、失蹤者留下的路口，短暫把彼此拉到同一件舊事裡。

這不是災難，卻讓所有城市明白：名字可以保護人，也可以害人。

現在留下：

- `同名街群` 的誤認、冒名、保護真名與錯名牽連由此成為日常危險。
- `南枝` 的工作不是行政登記，而是在外地人還沒被城市誤吞進同名關係前，替他們找到一個暫時可用的稱呼位置。
- 玩家在同名街叫錯人時，後果不能只是 NPC 生氣；可能是錯人回頭、物件應聲、傳聞改道或另一名 NPC 被牽連。

#### 沉物三潮

大回潮前的海岸曾連續三次退潮。第一次送回失蹤者的日常物，第二次送回無人敢認的工具，第三次送回一些明明已被出售、埋葬或銷毀的東西。

人們原本把海岸當交易與遠行邊界；三潮之後，海岸變成現在與過去互相歸還的地方。拾物人、買手、親族、修物人和藏物者開始在潮線旁形成衝突。

現在留下：

- `沉物歸還約` 不是物權機構，而是一群人為了避免回岸物被立刻當貨物吞掉，形成的生活約定。
- `沈鹿` 相信回岸物先有來處，後有價格；因此她面對玩家時不會先開價。
- 玩家在海岸得到物件時，第一個好玩的點不是賣多少錢，而是要暫持、歸還、藏起、改用、放回潮線，或承認自己看不懂它。

#### 長路失約

遠行脊路上的一次大隊行走中，整支行隊沒有按約定抵達。多年後，同一段路上反覆出現他們的腳步、鈴聲、交付口信和未送達物，但沒有人能證明他們到底死了、迷路了，還是被路留在另一種時間裡。

遠行者從此不再把「送到」視為單純移動結果。託付、等候、逾時、轉交和回訪都成為遠行生活的一部分。

現在留下：

- `遠行路誓` 把守約、轉交、逾時處理和失約承擔變成遠行規矩。
- `柏行` 的暫持不是保管箱功能；他每天都可能在準時、錯人、逾時、轉交之間替人承擔後果。
- 玩家可以把物或話交給人與路，但必須接受：離開或下線後，事情仍會推進，準時回來不一定代表一切正確。

#### 淡痕停葬

大回潮後，許多家庭無法承受死者和傷者留下的牽連，湧向淡痕盆地，希望讓痛苦變淡。某一年，盆地連續數十日停止葬禮，因為人們發現：痛苦被淡去時，證據、誓言、罪行和愛也可能一起變淡。

從那以後，淡痕不再只是療傷之地。它成了「該保留多少痛」的爭執中心。

現在留下：

- `淡痕照身院` 既救人，也被懷疑替人抹掉真相。
- `溫引` 的醫療選擇不是回復數值；他要問玩家保留來處，還是先讓人活下去。
- 玩家帶傷、舊物或證據前往淡痕時，應面對一個實際選擇：傷口變輕，但某條追查線可能也變淡。

#### 不留林白日

有一日，不留林邊緣整片白亮，許多人走入林中後沒有留下腳步、氣息、聲音或持物來處。有人藉此逃走，有人藉此活下來，也有人藉此讓罪行失去追索路徑。

不留林從此不是荒野地形，而是一個讓人害怕也讓人需要的地方。

現在留下：

- `不留林邊社` 的內部矛盾來自同一件事：消失是自由、救命、犯罪，還是背叛？
- `梁折` 痛恨林子遮罪，卻曾靠它忘掉自己的失敗，因此他不是單純追捕者。
- 玩家跟人進林時，好玩的點不是追蹤檢定成功或失敗，而是選擇要把某人追回生活裡，還是承認某些人需要不被找到。

#### 靜火斷手日

靜火列島曾有一批新手把前主剛死的工具直接改用。工具能用，工也完成了，但後來多名使用者在同一類動作上反覆失手，像是手不再完全屬於自己。

此後，靜火技藝不再只教如何做得更快更好，而是教人如何承認工具曾經屬於誰、如何把前主的習慣和新使用者的手慢慢接上。

現在留下：

- `靜火承手門` 的保守不是守舊，而是怕人把工具當空白物。
- `聞秋` 拒修來路太急的物，不是刁難玩家，而是她知道改用失敗會傷人。
- 玩家拿起工具時，順手、拒手、改用、修補與訓練都應是可玩的，而不是單純裝備數值。

### 代表人物的舊怨與當代牽連

代表人物不能只是世界制度的窗口。他們必須各自被歷史咬住。

| 人物 | 舊怨/舊事 | 現在牽連 | 玩家可介入 |
|---|---|---|---|
| `南枝` | 她家曾有人在同名街被錯稱帶走，最後只回來一件外衣。 | 她對外地人特別謹慎，怕輕率稱呼把人推入錯誤關係。 | 玩家可接受她的保守登記，也可急著使用某個稱呼，造成後續誤認。 |
| `沈鹿` | 她第一次拾到的回岸物被買手當日轉賣，隔天失主親族找到潮牆前，只剩空位。 | 她寧願得罪買手，也要先問物件還牽著誰。 | 玩家可幫她查來處，也可繞過她賣掉物件並承擔追討。 |
| `柏行` | 他曾準時轉交一只路袋，卻送到同名錯人的手上。 | 他現在更怕「準時但錯人」勝過「逾時」。 | 玩家可催他、作保、換收件人，或在回訪時讀到轉交後果。 |
| `聞秋` | 她年少時急著修好一件前主剛死的工具，害第二名使用者失手。 | 她把拒修當成責任，不當成服務態度。 | 玩家可說服她改用、先查前主、或找別人粗暴修理。 |
| `白止` | 他在回潮原走出來時，身上多了一段失蹤行隊的腳步。 | 他常被舊路借走，連自己的約定都不能完全保證。 | 玩家可等他、跟他、替他帶回路鈴，或錯過他留下的聲音。 |
| `織南` | 她曾在葬禮上唱錯一個字，讓死者舊稱在另一戶人家門口回聲數日。 | 她知道名字能照看人，也能讓無辜者被舊事碰到。 | 玩家可請她唱名、改稱、壓低真名，或拒絕讓自己被城市叫住。 |
| `梁折` | 他追的人進不留林後消失；同一天，他自己也在林中忘掉一段失敗。 | 他反對濫用不留林，卻無法否認它救過自己。 | 玩家可和他追人、騙他、把人交出去，或替某人爭取消失。 |
| `溫引` | 他曾讓一名傷者活下來，但傷痕變淡後，傷者無法指認加害者。 | 他把每次療傷都看成救命與留證之間的選擇。 | 玩家可要求保留痛的來處、要求先止痛，或把此事變成後續追查缺口。 |

### v2.4 的故事驗收

任何新故事單元至少回答：

```text
它接到名字線、持物線、路與去處線中的哪一條？
它曾經真的發生過什麼？
誰因此受益，誰因此受傷？
今天哪個人、物、路、地名、價格、禁忌或稱呼因此不同？
玩家第一次會怎麼碰到它？
玩家不碰時，NPC 或世界會如何繼續？
```

答不出，代表它仍是設定，不是故事。

## 1.2 歷史事件落地矩陣 v2.5

v2.4 讓世界有「曾經真的發生過」的事件；v2.5 要求這些事件能繼續往下長成可站入內容。每個事件至少要落到五種現在狀態：

- 地點：玩家能站在哪裡讀到這件事的後果。
- 物件：哪個可碰物仍帶著事件的壓力。
- NPC 行程：哪個人今天會因這件事去哪裡、拿什麼、避開什麼。
- 跨群體衝突：哪兩種生活方法因此互相卡住。
- 第一季卡組：能不能生成場景、物件、NPC、衝突與回訪文字。

### 跨群體衝突種子

這些衝突不是陣營戰。它們是兩種生活方法都合理，但不能同時滿足。

| 衝突 | 兩方 | 玩家可介入點 | 可能回訪差異 |
|---|---|---|---|
| `錯名承認` | 長息聯城外客名階 vs 同名街戶 | 接受暫稱、堅持自名、替人作保、請織南壓名 | 玩家被城市叫住的方式改變；某 NPC 因錯名避開或靠近玩家。 |
| `回岸物去向` | 沉物歸還約 vs 買手/急用者/失主親族 | 查來處、暫持、不賣、賣掉、放回潮線 | 物件價格、沈鹿態度、親族追討與後續潮牆文字不同。 |
| `逾時轉交` | 遠行路誓守約者 vs 失蹤者家屬/探路者 | 催柏行、替人等、改收件人、跟白止走一段路 | 暫持物去向、路鈴聲、等候者位置與玩家信用改變。 |
| `留痛或淡去` | 淡痕照身院 vs 追索者/親族 | 要求保留痛的來處、先止痛、藏證、作保 | 傷者狀態、證據清晰度、溫引態度與後續追查不同。 |
| `消失是否被允許` | 不留林邊社藏匿者 vs 梁折等追索者 | 帶路、誤導、藏物、交人、讓人離開 | 失蹤名串、林口路況、梁折信任與藏身者回訪狀態不同。 |
| `工具是否可急用` | 靜火承手門 vs 實用派/急用者 | 查前主、試手、勸聞秋改用、找旁人粗修 | 工具順手度、拒手風險、聞秋態度與旁人受傷可能不同。 |

### v2.5 對下游包的命令

下游地圖、物件、NPC 與衝突包不得再只從五張第一季卡名續寫。每張卡至少標出：

```text
所屬歷史線：
所屬具名事件：
所在地盤：
核心物件：
在場 NPC 今日行程：
跨群體衝突：
玩家第一個可做動詞：
```

## 2. 一句話世界定義

奇點是一顆能量像空氣一樣存在於萬物中的平行地球。生命不是「取得能量」或「使用能量」，而是在呼吸、觸碰、行走、命名、製作、交易、戰鬥、陪伴與死亡中和世界交換，並把痕跡留在人、物、土地、名字、道路與故事裡。

這句話是世界根，不是文案。

如果一件設計不能回答「它留下了什麼痕跡、誰會讀到、玩家能如何改變」，它就還不是奇點內容。

## 3. 世界核心命題

奇點的故事問題不是誰掌握力量，也不是誰管理世界。

核心命題是：

```text
世界太容易交換，也太容易記住。
文明越成熟，留下的痕跡越多。
人想活得自由，卻一直踩在自己、他人與前人留下的東西上。
```

這個命題必須長出所有玩法：

- 探索：不是揭黑霧，而是讀懂一地為什麼變成現在這樣。
- 冒險：不是接任務，而是進入過去仍在作用的地方。
- 經營：不是收購倒賣，而是處理物件來處、信任、前主、保存、轉手與名聲。
- 模擬：不是狀態條，而是 NPC 和玩家都被持物、道路、時間、關係與舊事牽動。
- 建造：不是放建築，而是讓一地獲得新用途、新名字、新路徑或新記憶。
- 戰鬥：不是傷害公式先行，而是身體、工具、地勢、目擊者、舊痕與關係一起爆開。

## 4. 世界不是什麼

以下方向不得作為世界根：

- 不是電力文明：能量不是電、不是資源、不是供應、不是接入、不是斷供。
- 不是治理世界：制度可以存在，但不是吸引力核心。
- 不是中古模板：不預設酒館、公會、渡口、倉庫、村落手工業、木牌市集。
- 不是材料百科：材料若不能長出玩家動詞、NPC 行動、交易後果與地方故事，就只是名詞。
- 不是元素傷害表：元素若出現，必須先成為地方狀態、工具用途、生活習慣或冒險風險。
- 不是任務板 RPG：NPC 不是商人、任務端點或台詞輪播器。
- 不是玩家主角劇場：世界不為玩家表演；玩家只是撞進局部事實，並留下新事實。

## 5. 星球根

奇點地球與現實地球的分歧不是「後來出現魔法」。分歧從成星開始。

### 5.1 空氣

空氣含能，所以呼吸不是無痕換氣。

人會把地方吸入身體，也把自己留在地方。長久居住的人會帶著地方氣息；遠行者身上會混著多地痕跡；病弱者、老人、戰後者與遠行者的呼吸會被懂行的人讀出變化。

玩家可見結果：

- NPC 可能從玩家身上的外地氣息判斷他不是本地人。
- 某些地方讓玩家一進入就覺得順或逆，不靠數值條呈現，而由文字、NPC 反應、工具順手度顯示。
- 追蹤不只看腳印，也看一地還留著誰的呼吸。

### 5.2 水

水含能，所以水不只是通行或景觀。海、雨、河、霧、露、汗、血都能包裹、磨淡、帶走或送回痕跡。

玩家可見結果：

- 海岸會送回帶有前主痕跡的物件。
- 雨能讓某些舊痕變淡，也能讓某些舊聲變清楚。
- 河流不是地圖邊界，而是物件、消息、屍骨、交易與傳聞的移動方式。

### 5.3 土

土含能，所以土地不是底色。腳步、居住、戰鬥、種植、修路、埋葬、演出與等待都會讓土地變得不同。

玩家可見結果：

- 熟路不是單純縮短時間，而是路願不願意讓你順著它走。
- 舊戰地不是怪物刷新點，而是身體和工具都會受舊衝突影響的地方。
- 建造不是放物件，而是把新用途和新記憶壓進一地。

### 5.4 光與聲音

光與聲音含能，所以看見、呼喊、歌唱、哭聲、叫名、誓言與謊言不一定立刻消散。

玩家可見結果：

- 名字有重量，但不是舊世界特殊設定；它是社會、記憶與角色扮演的共同入口。
- 某些街區的聲音會把人帶回舊事。
- 演出、公告、唱名、悼念和謠言都可能改變一地的關係狀態。

### 5.5 血肉

血肉含能，所以受傷、療養、疲憊、死亡、陪伴、訓練與熟練不只是數值。

玩家可見結果：

- 工具熟練度不是單純加成，而是手、工具與動作長期交換後變得更合。
- 傷口可能帶著造成它的地方、工具或人的殘留。
- 死亡不是怪物掉落機制，而是對人、物、地和關係的重大留痕事件。

## 6. 生命演化根

能量充沛不等於生命輕鬆。早期生命最大的問題不是缺能，而是交換太多，自己容易被世界沖散。

生命因此演化出五類基本能力：

| 能力 | 生物意義 | 玩家世界結果 |
|---|---|---|
| 成形 | 保持自己不被周遭痕跡沖散 | 生物有領域、殼、皮、群體、巢穴與習慣 |
| 遮蔽 | 不讓自己被過度讀取 | 有些獸路、林地、人物會讓追蹤失效 |
| 模仿 | 借周遭痕跡生存 | 偽裝、擬態、寄居、借名、借物有生態根 |
| 排出 | 把不合自己的影響推出去 | 療傷、清理、沉澱、放下、葬禮都有世界根 |
| 共存 | 與群體、工具、路、巢穴形成穩定交換 | 家戶、門派、城市、職業和長期物件關係成立 |

荒野因此不是採集區。荒野是生命互相讀取、遮蔽、模仿、吞食、回避與留痕的地方。

## 7. 人類文明根

人類不是能量的主人。人類特殊之處，是能把交換整理成可傳承的生活形式。

人類最早穩住世界的方法：

| 方法 | 世界意義 | 現在如何可見 |
|---|---|---|
| 名字 | 讓變動的人、地、物被認出 | 身份、稱呼、地名、舊稱、誤認、保護與排斥 |
| 工具 | 讓手的習慣延伸到物 | 裝備等於工具；熟練來自長期使用 |
| 葬禮 | 承認死者仍影響活人 | 墓地、禁忌、家族、舊物歸還、戰後地 |
| 道路 | 把重複腳步變成可被後人信任的去處 | 路況、熟路、迷路、遠行隊、消息流 |
| 家戶 | 讓人、物、孩子、老人、死者與日常互相照看 | 居住、保管、傳承、欠情、社會位置 |
| 門派 | 把身體、工具、世界與他人的方法傳下去 | 技藝、訓練、工具風格、規矩、同門關係 |
| 城市 | 高密度整理人、物、名字、交易、傷病、娛樂與遠行消息 | 街區、社群、交易、演出、醫療、治安、謠言 |

文明井噴不是因為人控制能量，而是因為人發明了讓普通人能辨認、繼承、淡化、轉交、修補與承擔痕跡的方法。

## 8. 世界史骨架

### 8.1 初息期

星球、海洋、大氣與生命前身形成。能量作為存在條件滲在空氣、水、土、光、聲音與血肉裡。

現在結果：

- 地理不是普通地球套皮。
- 每種地貌都有自己的痕跡保存方式。
- 普通自然現象都可能帶來可玩差異。

### 8.2 萬生期

生命大量繁盛。生命彼此讀取、遮蔽、模仿與吞食，形成豐饒但危險的生態。

現在結果：

- 荒野有高密生命與舊痕交疊。
- 探索需要讀地、讀物、讀獸群與讀缺席。
- 採集、狩獵、救援、追蹤都有代價。

### 8.3 呼名期

人類發現名字、歌、工具、火、葬禮能讓流動世界暫時穩住。

現在結果：

- 名字、稱呼、俗名、地名、舊稱都有社會重量。
- 角色扮演不是職業選單，而是玩家如何被世界認出。
- 第一屏必須讓玩家看見自己，不只是看見場景。

### 8.4 共居期

家戶、氏族、行隊、門派、城鎮出現。人開始用共同生活處理痕跡。

現在結果：

- NPC 是居民，不是功能端點。
- 家、路、工具、工作、學習、娛樂、照看都能變成玩法。
- 社會組織先從生活方法長出，再長成勢力。

### 8.5 大回潮

某一歷史時期，文明累積的戰爭、交易、失物、死亡、遷徙、誓言、欺瞞、愛與未完之事太多，世界把過去壓回現在。

大回潮不是能源事故，也不是世界毀滅。它讓所有人明白：世界真的會記得太多。

現在結果：

- 海岸送回不該再回來的物。
- 舊路在無人處短暫出現。
- 名字叫回錯人或舊事。
- 房屋、工具、街區拒絕某些新使用者。
- 有些人身上帶著不屬於自己的腳步、夢、傷口或稱呼。

### 8.6 回潮後當代

當代奇點沒有退回古代。它是高密、成熟、日常奇幻化的世界。

普通人不需要懂宇宙學，但知道：

- 不亂碰陌生物。
- 不亂叫陌生名字。
- 買物要問來處。
- 遠行要問路的脾氣，不只問距離。
- 傷病有身體原因，也可能有物、地、人、舊事原因。
- 死者、失物、舊屋、舊路有時仍在生活裡。

## 9. 當代年代感

奇點當代不是現代地球，也不是中古奇幻。

它應該呈現為：

- 生活密度高：城市、街區、學習、醫療、娛樂、交通、交易、遠行消息都成熟。
- 物件密度高：每個核心物件都可能有前主、使用史、歸還壓力、修補痕跡。
- 社會密度高：家戶、社群、門派、氏族、國家、聯盟並存。
- 歷史密度高：昨天、上一秒、上一個使用者、上一場雨、上一場戰鬥都可能成為現在狀態的原因。
- 奇幻日常化：普通人不驚訝世界含能，但仍會敬畏、避諱、利用、誤判或濫用。

語彙方向：

- 可用：遠行、持物、歸還、改用、留痕、淡痕、舊路、稱呼、熟路、舊雨、回聲、前主、同名、失物、照看、放下、拒手。
- 慎用：港口、倉庫、工坊、市集、木牌、渡口、酒館、公會、村落手工業。
- 禁用作世界根：供應、接入、斷供、主供、低供、配給、電網、管線、讀標、作證、禁線、工具封記、事故責任。

## 10. 地理大綱

以下是世界大綱級地理，不是完整地圖包。

### 10.1 長息諸城

高密度城市群。風穿過街區、屋面、橋、塔與廣場，居民相信一座城的呼吸能透露它的健康。

故事功能：

- 教玩家讀普通人的日常。
- 呈現名字、呼吸、交易、演出、醫療、學習如何成為當代生活。
- 讓玩家不是從荒野開始，而是從人群密度和自我身份開始。

玩家可做：

- 登記稱呼、買賣持物、問路、修工具、看演出、找人、追失物、被誤認、建立熟臉。

### 10.2 沉物海岸

海潮會送回帶有強烈前主痕跡的物。它不一定送回寶物，也可能送回麻煩、舊債、失蹤者線索、錯誤記憶或不該被轉手的器物。

故事功能：

- 讓物件成為劇情和玩法中心。
- 讓交易、歸還、藏匿、改用與冒險接在一起。

玩家可做：

- 拾物、辨認、歸還、暫持、藏起、修補、交易、被追討、作出物件去向選擇。

### 10.3 回潮原

大回潮留下最厚的地方之一。舊腳步、舊聲音、舊戰鬥、舊路偶爾短暫浮回。

故事功能：

- 承擔探索與冒險。
- 讓玩家明白歷史不是背景，而是現在狀態。

玩家可做：

- 跟路、避路、找失落物、救人、記錄變化、被舊戰場捲入、帶回不該帶回的東西。

### 10.4 不留林

某些行動在林中留不下痕跡。逃亡者、修行者、失物者、追索者都被它吸引。

故事功能：

- 讓「世界會記住」出現反面：有些地方拒絕記住。
- 形成追蹤、逃避、遺忘、放下與犯罪的故事。

玩家可做：

- 追蹤失敗、藏物、尋人、消除某些痕跡、面對自己想忘掉或不該忘掉的事。

### 10.5 同名街群

多座城市都有同名街。人、店、物件、家族、傳說共享相同俗名，使名字的重量變成日常混淆與奇幻危險。

故事功能：

- 承擔名字、身份、角色扮演、誤認、保護與欺瞞。

玩家可做：

- 改稱呼、確認身份、處理誤認、冒名風險、保護真名、追查同名物。

### 10.6 遠行脊路

跨越山地、高原、濕地、城市邊緣與荒野的長距離道路群。它不是公路，而是被無數遠行者、失蹤者、商隊、門派與逃亡者踩出的關係網。

故事功能：

- 承擔移動、遠行、物流、風險、離線安排與玩家長期目標。

玩家可做：

- 跟隊、護物、帶信、改路、等待、錯過、離線託付、回訪遠行結果。

### 10.7 靜火列島

火在這裡不只是燃燒，而是長時間保留某些誓言、烹煮、祭祀、工藝與戰鬥的痕跡。

故事功能：

- 承擔工藝、食物、技藝、門派、戰鬥與傳承。

玩家可做：

- 學技、修物、烹製、辨火、處理武器與誓言留下的後果。

### 10.8 淡痕盆地

某些痕跡在此會慢慢變淡。許多人到這裡療傷、放下舊物、處理死者與舊名。

故事功能：

- 承擔醫療、葬禮、放下、社會修復與長期角色變化。

玩家可做：

- 療傷、放下物件、幫人告別、讓某段過去變淡，也可能讓某段重要記憶失去力量。

## 11. 社會大綱

奇點的社會不是先有職業和勢力，再把 NPC 塞進去。社會從生活問題長出。

| 社會形態 | 來源問題 | 玩家可見 |
|---|---|---|
| 家戶 | 誰照看孩子、老人、死者、持物與日常痕跡 | 居住、保管、欠情、熟臉、家物、家名 |
| 行隊 | 人與物如何跨地移動且不丟失自身 | 遠行、護物、消息、離線安排、錯過 |
| 門派 | 身體、工具、世界與人的方法如何傳承 | 學習、工具熟練、規矩、同門、技藝衝突 |
| 氏族 | 血脈、地名、舊怨、葬禮和家物如何延續 | 舊物歸還、家族名聲、繼承、排斥 |
| 城市 | 高密生活如何整理人、物、名、病、娛樂和交易 | 街區、演出、醫療、交易、人群、流言 |
| 國家 | 大尺度路、災後秩序、跨城爭端如何處理 | 法、兵、稅、公共工程、邊界與遠方壓力 |
| 聯盟 | 多地無法單獨處理的回潮後果如何協商 | 使者、協議、背叛、救援、共同遠行 |
| 種族/人形群體 | 不同生命如何以不同方式和世界交換 | 身體差異、文化差異、誤解、共居與衝突 |

NPC 必須先是居民：

- 他有持物。
- 他有去處。
- 他有今日要處理的事。
- 他有不在玩家面前時仍會推進的生活。
- 他和物、路、家、名字、地方有牽連。

### 11.1 具名社會與代表人物骨架 v2.3

本節不是勢力表。奇點的國家、聯盟、門派、氏族與人形群體，必須先回答「一群人如何生活」，再回答他們有多少地盤或力量。

| 具名群體 | 從哪個生活問題長出 | 內部矛盾 | 玩家第一次怎麼碰到 |
|---|---|---|---|
| `長息聯城` | 長息諸城的人口密度太高，人們需要共同處理稱呼、居住、演出、傷病、持物與外地人承認。 | 城市想保留每個名字的來處，街區居民卻希望某些舊事不要一直被叫起。 | 玩家入城時先被問「怎麼稱呼」，不是被問職業；錯稱、重名、外地口音會影響第一批 NPC 態度。 |
| `沉物歸還約` | 沉物海岸長年送回失物，需要有人判斷物件應歸還、暫持、改用、放回潮線或拒絕交易。 | 拾物人重視前主和歸還，買手和改用者認為物件既然回到岸上，就已重新進入生活。 | 玩家碰到第一件回岸物時，會同時遇到拾物人、疑似失主親族、買手或急需工具的人。 |
| `遠行路誓` | 遠行脊路太長，單人記路與護物不足以穿過多地舊痕，需要行隊、託付、路鈴與回訪紀錄。 | 老行隊重視守約，年輕遠行者想更自由改路；失約者可能不是背叛，而是被舊路留住。 | 玩家可把物或話託給一段路，也可能在回訪時發現自己錯過了應接的人。 |
| `淡痕照身院` | 大回潮後，許多人被舊傷、舊名、舊物牽住，需要療傷、放下、葬禮、告別與重新生活的方法。 | 有人認為淡去舊痕是救人，也有人認為這是在抹掉死者和失敗者。 | 玩家可請人處理一件太重的持物，代價是某條線索、某段關係或某個稱呼可能變淡。 |
| `靜火承手門` | 靜火列島的火會留住誓言、烹煮、工藝與戰鬥痕跡，技藝必須教人如何承受工具和火的舊事。 | 師承者認為工具要先問舊手，實用派認為能用就該用；兩者常在改用物件上衝突。 | 玩家拿起試手工具時，可能被工具拒手、被師承者阻止，或被要求先知道前主如何失手。 |
| `不留林邊社` | 不留林會讓某些痕跡留不下來，邊境居民需要在藏匿、追索、療傷、犯罪與放下之間找界線。 | 逃亡者把林看成自由，追索者把林看成遮罪；療傷者則怕自己連重要的人也忘掉。 | 玩家跟蹤某人進林時，可能失去路、失去物的來處，或被迫選擇要追真相還是讓人離開。 |
| `暖生共棲族群` | 暖生南域生命過盛，居住者不能只採集或耕作，必須和高密植物、獸群、寄居物與偽裝生物共住。 | 共棲派認為人只是眾多生命之一，擴居派認為成熟文明不能永遠讓地讓路。 | 玩家進入暖生地帶時，最先學到的是「缺席也可能是生物造成的狀態」，不是哪裡有材料。 |
| `回潮原守路會` | 回潮原不時浮回舊路、舊戰鬥和舊腳步，需要有人記錄哪些路能走，哪些路只是過去伸手。 | 守路者想保護遠行人，探路者想利用浮回舊路；失蹤者家屬常反對封路。 | 玩家可跟一段短暫出現的舊路，也可能被要求把某個失蹤者最後的路帶回來。 |

第一批代表人物不是主角團。他們的功能是讓玩家能用具體的人讀到世界制度。

| 人物 | 所屬/牽連 | 他/她身上的世界問題 | 玩家可碰到的第一件事 |
|---|---|---|---|
| `南枝` | 長息聯城、外客名階 | 她每天替外地人的名字進入城市生活，但也看見很多人被錯名、重名或輕名排斥。 | 玩家第一次被登記稱呼時，南枝會看玩家怎麼說自己的名字，以及身上是否有替別人作保的物。 |
| `沈鹿` | 沉物歸還約、潮牆拾物行 | 她相信回岸物不是貨架物；每次交易前都要先確認它還牽著誰。 | 玩家碰到 `不回箱` 時，沈鹿不會先開價，而會問玩家是想暫持、歸還、看來處，還是讓潮線再帶它一次。 |
| `柏行` | 遠行路誓、暫持架前 | 他替行隊暫持路袋和口信，也常替失約者背鍋；他最怕東西被準時送達，卻送到錯的人手上。 | 玩家可把一件物暫放給柏行，但若回來太晚，物可能已按路誓轉交。 |
| `聞秋` | 靜火承手門、改用階 | 她能修工具，卻討厭把前主痕跡磨得像從未存在；她常拒修來路太急的物。 | 玩家拿試手柄請她改用時，她會先讓玩家摸一摸工具是否拒手，再決定修、拒或要求查前主。 |
| `白止` | 遠行脊路、回潮原守路會 | 他身上帶著一段不屬於自己的舊腳步，走路時常被舊路借走。 | 玩家在回路口等他時，可能等到人、等到鈴、等到舊路留下的聲音，或什麼都錯過。 |
| `織南` | 長息聯城、唱名師 | 她替新生兒、遠行隊、亡者和工具唱名；她知道名字能保護人，也能害人。 | 玩家若在同名街叫錯稱呼，織南可能提醒玩家：不是每個回頭的人都該被叫住。 |
| `梁折` | 不留林邊社、追索者 | 他痛恨不留林讓人和罪行消失，卻也曾靠那片林忘掉自己的失敗。 | 玩家若替人藏物或跟蹤進林，梁折可能要求玩家選邊：追出真相，或承認有人需要消失。 |
| `溫引` | 淡痕照身院 | 他替傷者處理太重的舊痕；他知道淡去痛苦有時也會淡去證據。 | 玩家帶著傷、舊物或他人託付來找他時，必須決定要保留痛的來處，還是先讓人活下去。 |

每名代表人物進一步寫成 NPC 卡時，至少要保留五個欄位：

- 今日持物：他/她今天身上或手邊有什麼，不能只寫職稱。
- 今日去處：玩家不接觸時，他/她會去哪裡。
- 不接觸推進：玩家不點他/她，世界仍會發生什麼。
- 可被玩家改變的事：玩家能改變哪個物、路、人、稱呼、價格或回訪文字。
- NPC 同規則：他/她是否也會錯過、暫持、歸還、改用、藏起、作保或制止。

## 12. 普通人的日常

普通人不是背景。

### 12.1 住

住處不是室內地圖，而是一組物件、關係、習慣、稱呼和地方痕跡。

玩家可見：

- 某戶人家的門口讓熟人停留，讓陌生人不自在。
- 一件家物不願被拿去遠方。
- 家戶因玩家保管或歸還某物而改變態度。

### 12.2 行

移動不是方向鍵總和，而是路對人的承認程度、同行者、持物、時間和地方狀態共同作用。

玩家可見：

- 熟路變短，陌路變重。
- 跟隊比獨行安全，但要承擔隊伍的時間與麻煩。
- 玩家離線安排可交給人、物或路，而不是角色消失。

### 12.3 學

學習不是技能樹點亮，而是身體、工具、師承和地方反覆交換。

玩家可見：

- 工具越用越順，也越像玩家。
- 某門派不教技能名稱，而教如何握、如何等、如何避、如何放下。
- NPC 會從玩家使用物件的方式判斷來歷。

### 12.4 交易

交易不是固定價格。價格來自物件前主、來處、保存狀態、是否願意轉手、誰作保、誰會追討。

玩家可見：

- 同一物在不同人手上價值不同。
- 來路不明的物可能賣不掉，或賣掉後引來追討。
- 歸還有時比出售更有價值。

### 12.5 娛樂

娛樂不是 UI 裝飾。歌、戲、競技、說書、祭會、遊行、悼念都會改變群眾的共同記憶。

玩家可見：

- 一場演出讓某個名字重新被叫起。
- 一場競技改變工具和身體的名聲。
- 玩家可以參與，也可以被群眾記住或誤記。

### 12.6 醫療與葬禮

醫療不只是回血。葬禮不只是死亡後流程。

玩家可見：

- 傷勢可能牽著造成它的人、地、工具或事件。
- 某些病需要離開某地，某些病需要回到某地。
- 葬禮能讓死者對活人的牽動變淡，也可能讓某件事正式被記住。

## 13. 玩家身份與入場

玩家的第一身份暫定為：`外地遠行者`。

這不是職業，也不是主角標記。它只表示：

- 玩家不是本地關係網的一員。
- 玩家有自己的名字，但在許多地方還很輕。
- 玩家有身體、有持物、有錢、有去處，和 NPC 同規則。
- 玩家能被誤認、被忽略、被利用、被信任、被委託、被拒絕。

第一屏的設計根應該是：

```text
我在哪裡
我叫什麼
我身上有什麼
誰看見我
我能碰什麼
我碰了會留下什麼
```

玩家初期不該接「救世界」任務。初期應該碰到一件物、一個名字、一段路或一個人，讓玩家用很小的動作看見世界真的不同。

## 14. 第一季故事骨架

第一季不是教學任務，而是讓玩家第一次讀懂奇點。

### 14.1 主題

```text
一件不該只是道具的物，讓一個名字很輕的外地人被世界記住。
```

### 14.2 流程

1. 玩家以外地遠行者身份進入高密生活區。
2. 玩家處理自己的名字、持物、少量金錢與第一個去處。
3. 玩家碰到一件被海或人群送回的物。
4. 玩家可以歸還、暫持、改用、藏起、交易或求助。
5. 不同選擇改變 NPC 態度、物件狀態、路線、價格、追討與回訪文字。
6. 玩家下線後，角色與相關 NPC 仍在世界時間中推進。
7. 玩家回訪時讀到自己造成或錯過的差異。

### 14.3 第一季需要的卡

| 卡型 | 最低數量 | 內容要求 |
|---|---:|---|
| M4 場景卡 | 5 | 自身入場、暫持點、拾物點、改用點、回路點 |
| 核心物件卡 | 5 | 身份/稱呼物、暫持物、失物、試用工具、提醒物 |
| NPC 卡 | 5 | 登記/唱名、看物、拾物、修物、遠行 |
| 衝突卡 | 5 | 錯名、逾時、兩方認領、拒手、失約 |
| 回訪文案 | 每卡至少 3 | 成功、錯過、未介入或 NPC 搶先 |

## 15. 玩家可做的非日常動詞

奇點不能只讓玩家做現實瑣事。每個核心動詞都要有現實做不到或無法安全承擔的面。

| 動詞 | 非日常可為性 | 世界後果 |
|---|---|---|
| 觸碰 | 讀到物、地、人殘留的來處或抗拒 | 物件認手、拒手、轉手記錄 |
| 稱呼 | 讓人、地、物或舊事被叫起 | 誤認、信任、排斥、舊事回頭 |
| 暫持 | 承擔不屬於自己的物的短期牽連 | 追討、信任、價格、路線變化 |
| 歸還 | 讓物回到人、地或死者關係中 | 關係改善、舊事變淡或變重 |
| 改用 | 把前主痕跡和玩家習慣接在一起 | 工具順手、拒絕、旁人反感 |
| 藏起 | 不讓某段痕跡被正確讀到 | 搜尋、懷疑、誤會、後患 |
| 放下 | 讓某件事不再牽著自己或他人 | 記憶淡化、機會消失、傷口收口 |
| 跟路 | 讓路帶著玩家，或被玩家帶偏 | 迷路、捷徑、舊路浮回、NPC 改道 |
| 作保 | 用自己的名字和關係承擔別人的物或話 | 信用、債、牽連、被利用 |
| 制止 | 在戰鬥前改變人、物、站位或稱呼 | 避戰、升級、目擊、關係變化 |

## 16. 世界可讀性驗收

任一新設定都要回答：

| 問題 | 不合格答案 | 合格答案 |
|---|---|---|
| 它從哪裡來 | 因為需要一個地點/材料/NPC | 從空氣/水/土/聲/血肉、生命交換、人類生活或大回潮後果長出 |
| 它現在是什麼狀態 | 名詞與用途 | 玩家看得見的人、物、路、稱呼、價格、缺席、痕跡 |
| 玩家能做什麼 | 看、買、接任務 | 觸碰、稱呼、暫持、歸還、改用、藏起、跟路、作保、制止等 |
| NPC 是否同規則 | NPC 在旁邊說話 | NPC 也會拿、藏、歸還、拒絕、搶先、錯過、承擔 |
| 錢/物/路/人如何變 | 得到獎勵 | 物件狀態、價格、路況、關係、信用、追討、回訪文字改變 |
| 回訪有何差異 | 換一句描述 | 玩家離開後仍有 NPC 推進、物件去向、路況變化、傳聞轉移 |
| 好玩在哪 | 合理、有氛圍 | 玩家做了現實做不到的事，並看到局部世界承認後果 |

## 17. 下游生成令

所有下游設計必須照這個順序：

```text
世界根
-> 生命交換方式
-> 人類如何整理成生活
-> 歷史或大回潮如何壓成現在狀態
-> 玩家看到哪個人/物/地/名字/路況
-> 玩家和 NPC 能做哪個動詞
-> 哪個世界事實被改變
-> 回訪如何讀到差異
```

禁止直接從地名、材料名、勢力名、職業名、戰鬥公式或氣氛描述起頭。
