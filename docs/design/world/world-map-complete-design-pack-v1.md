## 本檔定位

本檔補「完整世界地圖」這個缺口。它不是座標表，也不是把場景數量湊滿；它是能生成玩家可走世界的地圖正典。

完整世界地圖在奇點裡指：

- M0 到 M4 的尺度完整。
- 每個大地帶都有地貌、文明沿革、物資流、NPC 在場理由與玩家動詞。
- 地名從尺度、地貌、用途與歷史現在態長出來。
- 玩家進入任何地點時，看見的是人、物、路、規矩與正在變動的狀態，不是功能房間。

本檔新增具名世界骨架，但不把所有 M4 場景一次寫完。M4 場景仍需依 `world-scale-and-systems-v0.md` 與 `../gdd/13-content-authoring-validation.md` 拆卡。

## M0 世界總體

世界層名：已知世界。第一版玩家可讀區域：中河諸帶。世界本體見 `world-bible-v1.md`；世界深度見 `world-bible-v2.md`。

M0 根命題：這是一片生機過剩的常理化奇幻大地。水、草、獸、根、蟲菌、霧、潮、礦脈、熱風與人群都會把穩定邊界推回混亂；文明不是蓋在空地上的建築，而是持續維持路、棚、倉、門、渠、泊位、秤、牌、信用和通行的工作。

玩家看到的 M0 不應是一張世界全圖，而是每個局部場景都能透露：

- 這裡靠什麼壓住過剩生機。
- 無人維持時先壞什麼。
- 哪些物、路、人、價和規矩正在變。
- 玩家能改變哪個局部事實。

| 船港修架 | 船港修架秩序區 | 船不只是交通物，也需要材料與修補秩序 | 修架、帆布、補給、船戶街 | 修船架、帆布曬場、補給倉、船戶街口 |

## M4 場景卡生成規則

任一 M4 必須先填下列最小設計，不得只寫場景文案：

```text
M4 名稱：
所屬 M1/M2/M3：
靜態骨架：
動態狀態：
時間鏈：
在場人物：
核心物件：
玩家第一動詞：
NPC 不被點時會做什麼：
成功後世界事實：
失敗/錯過：
回訪差異：
關鍵字追溯：
```

M4 完整包拆分優先順序：

1. 每個 M1 先做 1 個代表 M3 的 3 張 M4。
2. 每張 M4 至少 2 個核心物件、1 個 NPC 自走行為、1 個可失敗動作。
3. 第二批再補跨地帶交界 M3，例如河口潮線貨場、商隊泊位、北麓穀倉。

## 地圖命名規則

地名命名由四層組成：

```text
位置或地貌 + 活動或秩序 + 必要尺度詞
```

合格：

- 北岸渡口：位置 + 活動，玩家一眼知道站在完整渡口。
- 東湖水倉：地貌 + 倉儲秩序。
- 西坡礦場：位置 + 地貌/工序。
- 霧草乾棚：物候/材料 + 維持物。
- 南方大城外圈：大城尺度 + 玩家可進入邊界。

不合格：

- 只有作者懂的縮寫。
- 半文半白壓縮詞。
- 把功能備註當地名。
- 用單一局部場景反推整個地區。
- 玩家視角無法判斷尺度。

## 玩家可進入區

第一版世界不是全域開放每一寸地，而是每個 M1 都要有可進入入口與可擴張邊界。

| 可進入等級 | 定義 | 第一版範圍 |
|---|---|---|
| A 可玩 M4 | 有完整場景卡、核心物件、NPC、自走、回訪 | 北岸渡口內容包、每個 M1 的代表 3 張 M4 |
| B 可探索 M3 | 有 M3 設計與至少一個 M4 入口，但未完整拆卡 | 東湖水倉、西坡礦場、中鎮井巷、北驛補給站等 |
| C 傳聞/路骨 | 可被 NPC、價牌、告示、票據提及，尚不可站入 | 遠洋航線、未展開城邦、外地商館 |
| D 背景封存 | 只作世界邊界或遠景，不進玩家層 | 未命名遠地、未定族群與政體 |

## 玩家層驗收回答

| 問題 | 本包回答 |
|---|---|
| 玩家看到什麼 | 不是全圖表格，而是每個 M4 露出的地貌、路況、在場人、核心物件、地方規矩、物資流與可進出口 |
| 玩家能做什麼 | 等、問、渡、跟隊、清障、標記、作保、寄放、搬運、修補、避險、申訴、報關、守夜或求援 |

| 好玩在哪 | 地圖不是走格，而是讓玩家在不同秩序中取得資訊、承擔風險、改變人貨流向，從外人逐步變成能被地方承認的人 |

## 可交給實作清單

- 地圖節點資料模板：M1、M2、M3、M4、命名、地貌、邊界、物資流、NPC 群、玩家第一動詞。
- M1/M2/M3 seed data：本檔列出的 7 個 M1、21 個 M2、21 個 M3。
- M4 拆卡工單：每個代表 M3 先拆 3 張 M4。
- 命名驗收器：禁止功能壓縮名、作者備註名、局部反推名。
- 地圖進度標註：A 可玩、B 可探索、C 傳聞/路骨、D 背景封存。

## 仍需設計缺口

- 每個 M3 的完整 M4 場景卡尚未全部撰寫。
- 地圖座標、相鄰關係、路徑成本與後端資料欄位不在本檔。
- 遠方大尺度區域仍只作傳聞/路骨，未完整具名。
- 每個地帶的長期事件排程仍需和勢力史、材料百科接線。

## 禁止方向

- 用地圖數量冒充世界完善。
- 用北岸內容包反推整張世界。
- 用奇怪地名讓後續設計越長越尷尬。
- 只做路線出口，不設計人、物、風險、物資流與回訪差異。
- 把城鎮做成商店/旅店/任務點列表。
