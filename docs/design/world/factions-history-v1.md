## 本檔定位

本檔補「完整勢力史」缺口。勢力史不是遠古散文，也不是王國年表。勢力史在奇點裡必須成為現在狀態：今天誰能開門、誰能收貨、誰能作保、誰能封路、誰能承認價格、誰能拒絕玩家靠近某物。

勢力在本檔中包含：

- 家戶：維持睡處、工具、親緣、熟臉。
- 作坊：把材料變成工具與器物。
- 倉場：承認貨權、保存、分選、價格。
- 路隊：承擔跨地帶搬運與同行風險。
- 行會/職群：渡工、巡路人、引路人、礦工、船工等共同規矩。
- 聚落/城邦/大城/港口：把門、稅、倉、秩序、申訴制度化。

## 歷史五段

勢力史用五段生成現在態，不寫成玩家必讀年表。

| 歷史段 | 發生了什麼 | 現在留下什麼 | 玩家可碰到什麼 |
|---|---|---|---|
| 過剩大地期 | 水、草、林澤、礦坡、獸徑、潮線先於人群 | 沒有真正空地，所有邊界都會磨損 | 玩家看到路、倉、門、棚都需要維持 |
| 站住期 | 早期人群用樁、渠、火帶、乾棚、守夜、分選、記路站住 | 職業從維持成本長出來 | 渡工、管水人、巡路人、乾棚看管、守倉人 |
| 路倉期 | 道路、船路、倉場、秤、牌、保證讓物資能流動 | 貨權、價格、路費、寄放、作保成為秩序 | 玩家可寄放、搬運、作保、被拒收 |
| 多中心期 | 城邦、大城、港口、路隊、作坊各有規矩，無單一全知權力 | 規矩互撞，外人位置不穩 | 玩家會遇到通行、稅、翻譯、作保、門禁衝突 |
| 維持期 | 現代不是完成世界，而是每天仍在維持 | 每個 NPC 的當前位置、持物、義務都是歷史結果 | 玩家每次行動都會進入下一次現在態 |

## 勢力層級

| 層級 | 控制什麼 | 玩家看到 | 玩家能做 |
|---|---|---|---|
| 家戶 | 工具、睡處、小倉、熟臉、親緣義務 | 某人是否願意借工具、留位、作證 | 幫忙、借還、得罪、成為熟臉 |
| 作坊 | 工序、材料品質、工具修補、學徒責任 | 工具能不能修、材料收不收 | 修、訂、送料、作保、被要求賠 |
| 倉場 | 貨權、保存、分選、價格、封條 | 貨能不能入倉、能不能取走 | 寄放、搬運、分選、保證、被拒 |
| 路隊 | 路況知識、同行、補給、護送信用 | 哪段路能不能跟、價多少 | 跟隊、守夜、補水、作保、求援 |
| 行會/職群 | 職業規矩與工具權 | 誰能翻牌、開閘、封路、收船 | 問、請、幫、違規、被記住 |
| 聚落 | 門、井、街線、告示、巡街、熟臉秩序 | 外人被放在哪一層 | 候檢、掛牌、租位、承接小事 |

| 港口 | 潮線、船期、外貨、語言、匯兌 | 外地規矩壓進本地 | 翻譯、報關、兌票、作保 |

## 任務來源不叫任務板

奇點的任務來源是現在狀態，不是 NPC 發布固定任務。

| 來源狀態 | 玩家看到 | 可做 | 完成後 |
|---|---|---|---|
| 門口排隊停住 | 守門人看牌不放行 | 作保、找人、等、退 | 通行或被記住 |
| 貨被拒收 | 價牌翻面、貨主焦急 | 包貨、分選、找保證 | 報價、信用、貨權改變 |
| 路標倒了 | 人群不敢走，巡路人未到 | 扶正、標記、問路 | 路線可辨或被責備 |
| 工具裂柄 | 工坊停工，修具棚缺料 | 找料、修、借工具 | 工序恢復、熟臉 |
| 稅棚扣貨 | 封條與票據卡住 | 翻譯、作保、補件 | 貨權與信用改變 |

## 玩家身份路徑

玩家不選職業，但可被勢力逐步承認：

| 路徑 | 初始行為 | 中期承認 | 長期位置 |
|---|---|---|---|
| 熟路人 | 問路、跟隊、標記、守夜 | 巡路班願意透露封路原因 | 可帶人、作保某段路 |
| 修具者 | 修燈、補繩、換柄 | 工坊願意收玩家送來的料 | 可承接工具維護 |
| 供貨者 | 採、曬、包、運 | 倉場/作坊願意先看玩家貨 | 可賒欠或寄放 |
| 仲介者 | 傳話、作證、翻譯、作保 | 兩方願意讓玩家轉述 | 可調停小衝突 |
| 風險處理者 | 避雷、封路、救人、清障 | NPC 在前兆時會看玩家反應 | 可被請託處理危險 |

## 玩家層驗收回答

| 問題 | 本包回答 |
|---|---|
| 玩家看到什麼 | 玩家看見的是門線、封條、價牌、倉位、稱呼、候檢、作保、拒收、路旗、申訴桌，不是勢力年表 |
| 玩家能做什麼 | 候檢、問路、幫忙、阻止、作保、寄放、分選、申訴、報關、翻譯、守夜、求援、繞開或得罪某方 |
| NPC 是否同規則 | NPC 也受勢力規矩限制，也會利用熟臉、作保、封路、拒收、傳話、違規、求援或被追責 |
| 物件/金錢/時間/關係如何改變 | 門、路、倉、稅、工具、貨權與消息被勢力控制；鎂、通行時間、報價、信用、稱呼與後續接近權會改變 |
| 失敗/錯過怎麼呈現 | 玩家可能被拒入、錯過船/隊、被扣貨、被要求賠、失去保證人、被勢力記住或讓衝突升級 |
| 回訪有何差異 | 曾幫忙、作保、壞規矩或欠帳的玩家，回訪時會看到稱呼、排隊位置、報價、守門態度、倉位與消息來源不同 |
| 好玩在哪 | 勢力史把歷史壓成眼前可操作的社會位置，讓玩家不是接任務，而是在門、路、倉、價、信用和衝突中找自己的立足點 |

## 可交給實作清單

- 勢力資料模板：層級、控制對象、主要地帶、現在態、玩家入口、衝突來源。
- 第一批 15 個勢力/職群 seed。
- 勢力控制項表：土地、門、路、倉、礦、田、稅、工具、消息、信用。
- 勢力衝突事件模板：涉及勢力、玩家可見、介入方式、後果。
- 玩家身份路徑標籤：熟路人、修具者、供貨者、仲介者、風險處理者。

## 仍需設計缺口

- 每個勢力的具名領袖、家戶網、長期排程與資料欄位未定。
- 城邦、大城、港口的更高層政治仍只保留玩家可見面，不寫完整統治史。
- 族群、宗教、語言文字尚未進正典。
- 玩家初始身份來源仍需獨立設計。

## 禁止方向

- 把勢力史寫成玩家必讀年表。
- 只做國家/門派名稱，不推導門、路、倉、價、NPC 行程。
- 所有 NPC 圍著玩家給任務。
- 用遠古大事件代替今日狀態。
- 讓勢力只在背景中存在，玩家看不到它控制什麼。

## 驗收表

| 檢查 | 通過標準 |
|---|---|
| 現在態 | 勢力史能說明今天某個門、路、倉、價或 NPC 行程為何如此 |
| 玩家可見 | 玩家不讀年表也能從牌、線、封條、稱呼、報價看出勢力 |
| 玩家可做 | 玩家至少能問、幫、阻止、作保、繞開、申訴或承接 |
| NPC 同律 | NPC 也受勢力規矩限制，也會利用或違反 |
| 經濟 | 勢力會改變價格、貨權、通行、保證或信用 |
| 衝突 | 至少一種勢力衝突能進戰鬥前置或非戰鬥風險 |
| 回訪 | 玩家介入後，稱呼、報價、通行、倉位、路況或目擊者會不同 |
