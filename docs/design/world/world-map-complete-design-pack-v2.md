## 0. 本檔回答什麼

本檔把新的 World Bible 落成第一版地理正典。它不是地名表，也不是 M4 場景卡堆疊。

它要回答：

- 世界根如何長成土地。
- 每個大區為什麼存在於現在。
- 人、物、路、交易、衝突和回訪差異為什麼會集中在某些地方。
- 玩家站到某地時，第一眼能看見什麼，第一個能做的動詞是什麼。
- NPC 不被玩家接觸時，為什麼仍會在地圖上推進。

本檔保留 M0/M1/M2/M3/M4 的尺度，但全部從 `world-bible-from-zero-v0.md` 重推，不沿用舊 v2.5 卡組作正向根。

## 0.1 外部校準如何回落奇點

外部資料只作地圖設計校準，不覆蓋 `DESIGN_KEYWORDS.md`。

| 校準來源 | 可取判準 | 奇點轉譯 |
|---|---|---|
| Game Developer `Living Worlds: The Ecology of Game Design` | NPC 與生物不應憑空站在場景裡；它們要像屬於環境，也會改變環境 | 每個 NPC 在場都要有地方理由、持物理由、未介入行動與回訪痕跡 |
| Springer 2025 game maps paper | 遊戲地圖不是單純靜態圖；它同時是導航、策略、符號與經驗介面 | 奇點地圖文字要讓玩家判斷路、人、物、風險、關係與記憶，不只知道東西在哪 |
| Worldbuilding Workshop `Trade Routes` | 路線移動貨物，也移動人、消息、觀念與衝突；路線改變會改變地方命運 | 遠行路、海岸回物流、城市街區與荒野邊界必須讓物價、NPC 行程、傳聞和追索改變 |
| 80.lv / Nathan Cheever world-map interview | 好地圖讓玩家想戳世界，看世界如何回戳；路徑和熱點比完整地名更重要 | 每個 M3/M4 都要有可點入口與世界回應，不能只給美術式地名 |

## 1. 從世界根到地理

奇點地理不是「自然地形 + 城鎮」。地理是四層邊界疊在同一片土地上：

1. 自然邊界：空氣、水、土、光、聲音如何保留、搬運、淡化或扭曲接觸。
2. 生命邊界：生物如何厚界、變界、共界、斷界。
3. 人類邊界：名字、工具、家戶、道路、教育、醫療、交易如何讓人可生活。
4. 回潮邊界：過去如何以物、路、聲、傷、稱呼、失約和傳聞回到現在。

任何地名若不能指出這四層之一，就只是空名。

### 1.1 尺度定義

| 尺度 | 定義 | 必須回答 |
|---|---|---|
| M0 | 第一階段已知世界圈 | 這一整片世界靠什麼故事根成立 |
| M1 | 大地理帶 | 此地如何處理一種核心邊界問題 |
| M2 | 區域 | 人類如何在此形成生活方式、道路與場所 |
| M3 | 活動帶 | 玩家可進入、看見 NPC 與物件正在運作的地帶 |
| M4 | 場景卡 | 玩家當下站入的一段可讀狀態，有物、有路、有人、有動詞、有後果 |

### 1.2 命名規則

地名要能被居民說出口。名稱可以有奇幻感，但不能像設計表縮寫。

合格地名應符合至少兩項：

- 指出地方狀態，例如 `回潮原`、`舊傷盆地`。
- 指出居民生活方法，例如 `聯城帶`、`遠行脊路`。
- 指出玩家可感的行為或風險，例如 `外地人留名處`、`回海石階`。
- 指出歷史壓到現在的結果，例如 `七日回聲原`、`失約岔嶺`。

禁止用尷尬短詞或局部生硬詞反推世界。若一個地名只有作者知道意思，居民不會使用，玩家也不想點，它就不進正典。

本節是命名降噪結果，不是完整地圖完成宣告。每個名稱先判斷「玩家第一眼是否看得懂」，再判斷是否有世界味。

### 1.4 新名讀感樣本

本節只測「把名字放進場景後，玩家是否能自然讀懂」。若一個名字只能在表格裡成立，進正文就像術語，必須再改。

| 新名 | 場景讀感樣本 | 判定 |
|---|---|---|
| `白脊列島` | 海面外露出一列列白色山脊，長橋把幾座島接成修物人的通行線。玩家一上岸先看到的是排隊試手的人，而不是城門、門派牌或神秘儀式。 | 保留。它先給地貌，再承載工具與試手。 |
| `夜作灣` | 夜作灣沒有完全安靜。灣口一排修物台還開著，剛退熱的工具柄放在冷槽旁，前手記壓在桌面上，表示這件物今晚不能直接帶走。 | 保留。它像一個能進入的場所，不像 `夜作帶` 那種分類。 |
| `舊傷盆地` | 從坡道下去，等診的人不只等止痛。有人抱著染痕外衣，有人只想把舊傷說清楚一次，有人希望證據在天亮前變淡。 | 保留，但正文要避免把它寫成醫療城或任務醫院。 |
| `見證丘` | 丘路上沒有人高聲喊冤。願意說證的人把手放在見證石旁，記錄的人問的是「哪一句要留下」，不是「誰贏了」。 | 保留。它讓玩家知道這裡處理證詞，而非抽象 `淡證` 狀態。 |
| `送別園路` | 園路旁放著一件家物，等一名遠行的人決定帶走、留下，或承認自己不能替死者完成那個承諾。 | 保留。語氣比 `後事園路` 自然，但後續場景要避免過度殯葬化。 |

讀感結果：這五個新名目前可以留在正向地理稿；下一步不再補地名，而是用完整 M4 場景卡繼續測它們能否支撐玩家動詞、NPC 同規則、物件狀態與回訪差異。

## 2. M0：東陸與周海

第一階段已知世界圈暫名：`東陸與周海`。

它不是整顆奇點地球，而是玩家第一階段能理解、能遠行、能回訪的一大片陸海弧。它包括一串高密城市、一片回潮厚地、一段會送回舊物的海岸、一座不替人久留痕跡的林域、一組工藝列島、一個處理傷痛與證據的盆地、一片生命過盛的南域，以及穿過它們的長路。

M0 核心問題：

```text
在一個萬物太容易互相影響的世界裡，人如何走遠、帶物、叫名、求助、交易、治傷、放下舊事，又不被過去壓垮？
```

M0 玩家第一層吸引力：

- 我不是看一張地圖，我是在選擇把自己的名字、手上的物、遇到的人和未完的事帶去哪裡。
- 我走過的路、交給別人的物、叫錯的名字、救下或放走的人，會在重訪時改變局部世界。
- 每個大區不是景點，而是不同玩法入口：登名、追物、尋路、藏人、試手、療傷、共處、託付。

## 3. M1 大地理帶

### 3.1 聯城帶

起源：多群人形生命在高密人流、聲音、名字與遠行需求中，發展出連續城市生活。城市不是牆內安全區，而是讓陌生人也能被暫時辨認、交易、求助、學習、治傷和離開的密集方法。

現在狀態：名字、持物、去處、作保、醫療、修物、演出和消息交錯。外地人很快被看見，但不一定被承認。

玩家看到：

- 人群不是背景；每個人都可能在等名、找物、送人、帶消息或避開某個稱呼。
- 同一件物在不同街區會有不同價格與風險。
- 玩家名字越被地方接住，能走的門越多，也越難假裝無關。

玩家能做：說名、請人作保、問路、找人、修物、交易、旁聽、插手一場誤認、等候一個未到的人。

NPC 同規則：NPC 也會登名、被拒、被誤認、找保人、趕路、藏物、帶人離開。

好玩入口：玩家能利用「外地名字還輕」進入本地人被舊關係卡住的縫隙。

### 3.2 回潮原

起源：大回潮最早被大量記錄的開闊地之一。這裡的土和風容易把舊路、舊聲、舊戰鬥、舊約定推回現在。

現在狀態：不是荒地，也不是遺跡公園。有人耕作、通行、守望、調查、避險和做遠路生意，但所有人都知道今天的路不一定只屬於今天。

玩家看到：

- 草線忽然亮出不屬於現在的腳步。
- 遠行隊在開闊地等一段路穩定下來。
- 有些人不是迷路，而是被舊聲叫走。

玩家能做：跟路、等路、拉住人、留下記號、遮掩痕跡、查舊戰、救被牽走者、把物送回該在的位置。

NPC 同規則：守著名單的人、遠行的人、找人的人會自己判斷路況，也會搶先走、折返、失蹤或等錯人。

好玩入口：地圖不是固定連線；玩家能短暫利用舊路，但必須承擔它把什麼帶回來。

### 3.3 沉物海岸

起源：水擅長搬運與回帶。大回潮後，某些海岸會把不該只是貨物的東西送回來：工具、箱、衣物、名帖、欠約、罪證、祝福和未完成的託付。

現在狀態：海岸交易活躍，但最重要的不是買賣，而是判斷一件物該被歸還、暫放、改用、放回海裡，或根本不該被碰。

玩家看到：

- 牆上掛著剛被海送回的物，水還在滴。
- 急著買的人想快成交，牆邊的人先問來處。
- 有人等失主，有人希望失主永遠別來。

玩家能做：帶回、詢問來處、掛牌、等人、交易、藏起、歸還、放回、作保。

NPC 同規則：照看回來物的人、急著買的人、失主家人、遠行的人都會移動物件，玩家不介入也會有下一步。

好玩入口：同一件物不是寶箱掉落，而是能讓玩家被信任、被追索、被壓價、被誤認或被請託。

### 3.4 不留林

起源：某些林域不願長久保存痕跡。腳步、氣味、稱呼、傷、舊怨和承諾在其中容易變淡。

現在狀態：它不是神秘森林模板。它是一種社會邊緣：有人進去療傷，有人藏物，有人逃避追索，有人守在林外等對方願不願回來。

玩家看到：

- 林前有人把名字或物件留在樹列下。
- 查舊事的人和想放走的人在同一片清地等不同結果。
- 進林後，玩家留下的記號不一定可靠。

玩家能做：留名、寄物、追人、藏人、放走、留下只有自己懂的記號、承認追不回。

NPC 同規則：逃離的人會選擇路線，查舊事的人會錯過，照看的人會攔人，林邊居民會拒絕回答。

好玩入口：玩家可以選擇讓一件事被找回，也可以選擇讓它變輕，但重訪時可能再也找不到。

### 3.5 白脊列島

起源：火、礦、海風與長期手藝在列島上形成穩定的修物與試手文化。這裡處理的不是控制力量，而是工具和身體如何安全地再次磨合。

現在狀態：成熟工藝城市和學習場所集中。工具前史、前主失手、修補習慣、改用責任和試手結果會被長期記錄。

玩家看到：

- 同一件工具在不同手裡反應不同。
- 修工具的人先問它被誰用過，而不是先談價。
- 學徒和遠行的人都在排隊試手。

玩家能做：試手、請修、改用、查前主、放棄、學一種工具動作、承擔失手。

NPC 同規則：修工具的人會拒絕，學做工具的人會失手，遠行的人會趕時間，前主相關的人會找上門。

好玩入口：裝備不是加數值；玩家拿起工具，就是接上它的前史與可做動詞。

### 3.6 舊傷盆地

起源：盆地土壤、濕氣和長期照看文化讓傷、痛、證據、愛恨與舊案在此更容易被保存、整理或淡去。

現在狀態：醫療、療養、葬禮、見證、舊案追查與照看教育集中。救人和留證常常互相衝突。

玩家看到：

- 傷者被問的不是「扣了多少血」，而是傷從哪裡來、要不要留下可追查的痕跡。
- 家人希望人活下來，查舊事的人希望證據不要太快變淡。
- 醫者不是補血服務點，而是有立場的人。

玩家能做：求診、救人、留證、淡去、查傷由、幫忙照看、拒絕說明、替人作保。

NPC 同規則：醫者會先救命或先留證，家人會阻擋，查舊事的人會催促，傷者可能拒絕被記住。

好玩入口：玩家能決定一場傷害在世界裡留下多重痕跡，這會改變關係與後續追索。

### 3.7 暖生南域

起源：生命密度最高的沃土帶。這裡的空氣、水、土和活物都太容易互相影響，植物、微生物、昆蟲、人形群體和共處方法高度發展。

現在狀態：豐饒但不安全。採集不是拿素材，食物不是生活條，玩家要讀懂誰可接近、誰被排斥、哪種物已被共居關係包住。

玩家看到：

- 作物、藥材、巢域、聲音和氣味都很密。
- 居民先看玩家如何靠近，再決定是否讓玩家拿。
- 生命群可能模仿、避讓、依附或拒絕玩家。

玩家能做：詢問、避讓、共採、撤退、救援、交換、帶回樣本、破壞或修復一段共處關係。

NPC 同規則：採集者也會被拒絕，醫者會挑來源，居民會因外地人冒失而改變態度。

好玩入口：玩家不是割草，而是進入一個太活的地方，學會以最小動作改變生命關係。

### 3.8 遠行脊路

起源：第一長路以後，反覆遠行、託付、同行、失約、找人和送物讓山脊、谷線、照看點與城市形成長距離路網。

現在狀態：路不是線。路是共同承擔。每一段路都有等人、錯過、寄物、改路、追人、同行、離線安排與回訪差異。

玩家看到：

- 路站有人等一支未到的隊。
- 寄放物按隊名、去處和承擔者排著。
- 某條岔路被人改過稱呼，讓下一隊人可能走錯。

玩家能做：跟隊、寄物、帶信、等候、改路、拒託、追人、安排離線時角色做的事。

NPC 同規則：遠行的人會先走、等錯、失約、轉交、受傷、改路或請玩家承擔。

好玩入口：玩家離線不是世界停止；玩家的角色和託付仍在路上留下結果。

## 6. 第一輪 M4 種子

這些是能展開成完整場景卡的 M4 種子。每張都只能在物件/NPC/衝突包同步後進一步細寫。

### 6.1 外地人留名處

玩家看見：

```text
留名處裡沒有誰真正閒著。
有人把自己的名字說得很輕，像怕被地方接錯；有人扶著路袋，等保人先開口。
一張未乾名紙壓在桌邊，空著的一格剛好能寫下你的稱呼。
許央抬頭看你，先聽你怎麼叫自己，再看你身上帶了誰的路氣。
```

核心物件：未乾名紙、保人牌、路袋、候名座。

在場 NPC：許央、等保人的人、遠行的人、找人的人。

玩家動詞：說名、等候、請保、改稱、急用稱呼、離開。

回訪差異：玩家被某種稱呼記住、被誤稱、被避開、被邀請作保，或因沒登名而在下一地被追問。

### 6.2 七日回聲草線

玩家看見：

```text
草面在風裡分開，一串腳步亮得不像今天留下。
守著名單的人沒有立刻追，只把手按在低聲名單上。
遠處有人聽見自己的舊稱呼，往草線前挪了一步，又像突然不記得自己要去哪裡。
```

核心物件：低聲名單、亮腳草線、舊鞋痕、守望繩。

在場 NPC：守著名單的人、被舊聲牽住的人、遠行隊員。

玩家動詞：叫名、拉住、跟路、留記、折返、詢問。

回訪差異：草線消失、延伸到新方向、帶回失物，或被 NPC 搶先跟走。

### 6.3 白潮掛物牆

玩家看見：

```text
潮水退得很慢，牆上的東西還在滴。
一只不明箱掛在尋主牌下，箱扣被同一隻手磨得發亮。
急著買的人站得近，周澄站得更近；兩人都沒有先問價，先看誰敢碰。
```

核心物件：不明箱、尋主牌、濕繩、潮痕。

在場 NPC：周澄、急著買的人、來認物的失主家人可能到場。

玩家動詞：看、碰、問來處、掛牌、等人、交易、放回。

回訪差異：箱被領走、被買走、放回潮線、裂扣，或引來兩方認領。

### 6.4 林前寄名樹列

玩家看見：

```text
樹列下掛著幾枚名牌，有些字還清楚，有些已經淡得像霧。
一個人把包裹放下，卻沒有把名字留下。
追來的人站在樹外，沒有進林；照看樹列的人只問你是要找人，還是要讓人暫時不被找到。
```

核心物件：名牌、寄物袋、林前繩、淡字木片。

在場 NPC：追來的人、照看樹列的人、入林的人。

玩家動詞：留名、寄物、問去向、追入、放手、替人說明。

回訪差異：名牌變淡、被叫回、被取走，或某人從林中回來但拒絕舊稱呼。

### 6.5 試手長廊

玩家看見：

```text
長廊裡沒有人催快。
工具一件件放在試手台上，旁觀者看的是手，不是價錢。
一名遠行的人想立刻帶走修好的柄，看試手的人卻把前手記壓在桌面，示意他先等。
```

核心物件：試手台、前手記、熱柄、工具架。

在場 NPC：看試手的人、學做工具的人、遠行的人、替前主來問的人。

玩家動詞：試手、請修、查前手、改用、放棄、替人作保。

回訪差異：工具順手、拒手、傷人、被暫扣，或有前主相關者找上玩家。

### 6.6 看診長廊

玩家看見：

```text
看診長廊的等候聲很低。
看診的人把驗傷杯放在傷者旁邊，先問傷從哪條路來。
家人想讓人快點止痛，問傷從哪來的人卻盯著那件染痕外衣，像怕證據比人先淡去。
```

核心物件：驗傷杯、傷布、傷衣、見證匣。

在場 NPC：看診的人、傷者、家人、問傷從哪來的人。

玩家動詞：求診、留證、淡去、查傷由、送物、制止爭執。

回訪差異：傷勢轉好、證據留下或淡去、家人信任玩家，或問傷從哪來的人把玩家列入證詞。

### 6.7 活籬果棚

玩家看見：

```text
活籬果棚不是菜地。
活籬裡的葉面朝不同方向轉動，像在分辨每一個靠近的人。
住在園裡的人把空果籃遞給你，沒有說能摘多少，只說先看哪一列願意讓路。
```

核心物件：空果籃、活籬、避讓牌、葉鈴。

在場 NPC：住在園裡的人、外地摘果的人、看診的人或病人家屬。

玩家動詞：詢問、讓路、摘果、撤退、送食、安撫。

回訪差異：某列活籬允許玩家靠近、拒絕玩家、被他人破壞，或食物被送到看診院。

### 6.8 失約岔前

玩家看見：

```text
岔路牌被改過，舊字沒有全刮乾淨。
一隊遠行的人還沒到，等他們的人已經把路袋抱得太緊。
記路人看向你手上的空位牌，問你是要等，還是要承認他們可能已經走錯。
```

核心物件：改名牌、路袋、空位牌、舊信。

在場 NPC：記路的人、等隊伍的人、追人的人、帶路的人。

玩家動詞：等候、改路、追人、留下說明、接託、拒託。

回訪差異：隊伍找回、誤會擴大、物被錯寄、有人把失約算到玩家名下。

## 8. NPC 與物件放置規則

### 8.1 NPC 在場理由

每個 M3/M4 在場 NPC 至少符合一項：

- 正在維持地方邊界：叫名、看守、修物、醫療、照看、記路、共處。
- 正在利用地方邊界：交易、借路、藏物、等人、摘果、試手。
- 正在破壞或逃離地方邊界：冒名、搶先、改路、藏人、洗掉來處。
- 被地方邊界咬住：誤認、失約、舊傷、前主物、舊聲、林中淡去。

若 NPC 只是在等待玩家點對話，該場景不通過。

### 8.2 物件在場理由

核心物件至少要有：

- 來處：從哪裡來，為什麼在這裡。
- 歸屬：現在誰能拿，誰不能拿。
- 牽連：它牽動哪個人、路、傷、名字或價格。
- 動詞：玩家能看、問、碰、拿、放回、修、寄、交易、作保或拒絕。
- 時間：玩家不碰時誰會先碰，多久後狀態會改。

若物件只是裝飾名詞，該場景不通過。

## 9. 地圖可讀性驗收

| 驗收問題 | 通過標準 |
|---|---|
| 地名從哪裡來 | 能回推自然、生命、人類或回潮邊界之一 |
| 這裡為何有居民 | 居民生活方式與地方問題相互支撐 |
| 玩家第一眼看到什麼 | 能讀到人、物、路、等待、衝突或即將變化 |
| 玩家第一個動詞是什麼 | 動詞少而明確，能改變世界事實 |
| NPC 是否同規則 | NPC 不等玩家，也會移動、錯過、拒絕、搶先、承擔 |
| 物件是否是機制 | 物件有來處、歸屬、狀態、動詞和回訪差異 |
| 路線是否會搬動世界 | 路能移動物、人、消息、價格、傷、追索或玩家離線結果 |
| 好玩在哪 | 有探索、冒險、交易、工具、追索、救援、放下、離線或回訪的一種入口 |
| 是否避免舊偏誤 | 不從舊卡組、局部地名、低技術氛圍或治理語彙反推 |
