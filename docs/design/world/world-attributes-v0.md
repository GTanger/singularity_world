## 口徑

世界屬性不是玩家面板數值，也不是把世界抽成幾個漂亮形容詞。

奇點世界是常理化奇幻世界，不是現實擬真世界。這裡的河霧、水草、物候、野地、器物、人群禁忌與危險都可以帶有奇幻本體；只是第一版不靠舊特殊名詞或通用奇幻套件撐場，而是讓奇幻落成玩家能看見、碰到、交易、避開、錯過、承擔後果的世界事實。

世界屬性回答的是：這個奇幻世界在任何地點、任何時間、任何人靠近時，會用哪些穩定規則推導出玩家能看到的內容。它是內容聖經背後的骨架；內容聖經負責寫出味道，世界屬性負責避免味道每次都靠臨場作文。

合格的世界屬性必須同時回答四件事：

- 這個屬性代表什麼。
- 玩家會怎麼看見它。
- NPC 與物件會怎麼被它推動。
- 它會產生什麼可拆成場景、事件或互動的後果。

不合格的世界屬性：

- 只是一個抽象詞，例如「真實」「沉浸」「有生命感」。
- 只是一個數值欄位，玩家看不出差異。
- 只替作者補氛圍，不能改變人、物、路、錢、時間、規矩或事件。
- 需要舊世界特殊設定才能成立。

## 全域屬性

### 1. 常理化奇幻性

世界本體是奇幻，但當地人未必把它當奇觀。奇幻不是酒館、公會、命定英雄、魔物森林這類套件，也不是舊特殊設定自動回流；它應該表現在物候異常、過度豐饒、地方避忌、器物習慣、危險形態與人群如何把異常當日常處理。

玩家可見：同一條河、同一片草、同一陣霧，不只是自然背景，而會改變通行、保存、判斷、價格、禁忌或人的行為。
推導後果：每個區域至少要回答「這裡的奇幻性如何被當地生活吸收」，不能把場景寫成現實鄉鎮加幾個漂亮名詞。

北岸例子：河霧不只是天氣；它會讓水位痕難判、木牌返潮、踏板滑、貨物保價時間縮短。老渡工不會講神秘設定，他只會把霧重當成今天該改船序、收繩、攔人的理由。

### 2. 物質性

世界裡的東西不是背景名詞。木牌、繩圈、茶桶、麻袋、門、棚、車轍、泥坡、價牌、封條，都有位置、歸屬、用途、狀態與被錯用的後果。

玩家可見：物件能擋路、能被看見、能被使用或拒絕使用，狀態會變舊、變濕、被移走、被別人先碰過。
推導後果：場景卡不能只寫「有貨棚」；必須寫貨棚旁有什麼可碰的東西，誰能碰，玩家亂碰會怎樣。

北岸例子：通行木牌不是裝飾。它可能壓在繩圈下、被渡工收回、被人藏進袖中；玩家亂拿會被當成想插船序。

### 3. 持續時間性

世界時間不因玩家沒看見而停止。玩家離開、猶豫、下線或看向別處時，NPC、天氣、貨物、隊列與事件仍會往前走。

玩家可見：回到同一地點時，位置、物件、隊列、人群、貨物或傳聞已經不同。
推導後果：事件卡要能寫「玩家未介入時的自然進程」，不能只有玩家按下互動後才發生。

北岸例子：玩家離開貨棚後，搬貨人可能已先把一件貨送到倉棚前；玩家回來看到的是空位、濕痕與點貨人改變的抱怨。

### 4. 局部可知性

玩家不是上帝。玩家只看見當地、當時、當下能觀察到的事；遠方不以全景報表露出，只透過人、物、痕跡、傳聞與價格變化滲進現場。

玩家可見：只看見半句話、變動的價牌、缺席的人、被收走的木牌、換過位置的貨。
推導後果：不要寫全世界公告式敘述；把遠方事件折成本地可見痕跡。

北岸例子：玩家不知道下游船期全貌，只看到渡工看水位痕、茶桶邊有人低聲說晚船又慢了。

### 5. 豐饒但不寬容

世界不是廢土。它有水、草、魚、田、畜力、礦料、木料、港口與人流。但東西多不代表安全，反而代表更多競爭、損耗、擠壓與責任。

玩家可見：物產與人流很密，但每件東西都可能壞、濕、被錯拿、被延誤、被壓價。
推導後果：材料不應只是可採集資源；材料要有保存、搬運、需求者、替代品與失敗成本。

北岸例子：草墊、麻繩、麻袋布都是基礎物質，但在能量充沛、濕氣過重的河岸環境裡，一旦錯排，就會牽動點貨人、貨棚、船期與等船人群。

### 6. 守衡性

錢、貨、工具、勞力、位置與人情不能憑空出現。每個可交易物都要有來源、搬運、保存、需求、損耗與去處。

玩家可見：同一件貨不是只在背包數字裡變化；它會佔位置、需要人搬、被某人承認價格，或被某個場所拒收。
推導後果：物資清單必須連到地點、工序、需求者與後續痕跡。

北岸例子：玩家賣出材料後，倉棚點貨牌應能看見這批材料如何被墊箱、捆貨或挪入貨籃，而不是只加錢消失。

### 7. 人群自主性

NPC 不是等玩家啟動的對話樁。每個在場者至少要有自己的去處、正在做的事、短期顧慮與會被環境改變的反應。

玩家可見：NPC 走動、等待、避讓、攔人、改口、先做完某件事，或因玩家行為留下局部印象。
推導後果：NPC 卡要寫「玩家不接觸時他會做什麼」，不只寫對話台詞。

北岸例子：搬貨人會自己取貨、送貨、避開踏板正線；玩家不幫，他仍然可能把局部市場推到下一個狀態。

### 8. 非主角性

玩家可以介入世界，但世界不以玩家為中心。當地人先按自己的規矩判斷玩家，而不是把玩家當成被迎接的故事核心。

玩家可見：玩家可能被忽略、被誤認、被請讓路、被懷疑、被短暫記住。
推導後果：第一屏不能用 NPC 排隊介紹功能；要讓玩家先感到自己站進別人的日常。

北岸例子：老渡工不問玩家是不是新來的，只看玩家有沒有佔路、碰牌、擋繩、帶麻煩貨。

### 9. 局部秩序性

世界有秩序，但秩序不是遠方設定。秩序落在門、線、牌、封條、稱呼、誰能靠近某物、誰有權改變隊列。

玩家可見：某些東西不能碰，某些線不能插，某些人一句話能讓人退後。
推導後果：每個場景卡都要有至少一個局部規矩與一個犯規成本。

北岸例子：等候線不是 UI；它是被鞋底踩出的線。插錯線未必戰鬥，但會被推回、記臉或傳成一句低聲話。

### 10. 摩擦性

世界的可玩性來自摩擦：等、擠、濕、重、壞、錯認、讓路、欠人情、錯過時機、被規矩擋住。摩擦不是故意刁難玩家，而是讓玩家的選擇有重量。

玩家可見：同一個目的有多種代價；快一點可能欠人情，守規矩可能錯過，亂碰可能被喝止。
推導後果：事件卡要給玩家局部取捨，不要只有成功按鈕。

北岸例子：想快一刻鐘過河，可以求人、讓貨先過、幫忙拉繩、花錢或乾脆等；每種都留下不同後果。

### 11. 可介入性

玩家不是只能讀場景。玩家可以透過位置、物件、讓路、詢問、使用工具、交易、等待或離開，改變局部事實。

玩家可見：點擊後不只是回一句文字，而是物件狀態、人群位置、NPC 記憶、後續事件或可用出口出現差異。
推導後果：互動卡必須寫 before / action / after；沒有 after 的文字不算互動。

北岸例子：玩家幫忙把繩圈拉離水邊，後續踏板口的人群退半步，老渡工短暫把玩家歸入懂規矩的人。

### 12. 可錯過性

世界不是每個內容都等玩家收集。玩家可能錯過一件貨、錯過一句話、錯過某人還在現場的時間，也可能因此看到另一個結果。

玩家可見：回來時某人已走、某物已被移動、某條線已變薄、某個機會變成痕跡。
推導後果：事件卡要設計未介入分支，而不是所有內容都排隊等玩家完成。

北岸例子：晚船讓位發生時玩家若在茶桶旁，只聽到抱怨；若在踏板口，會直接被人流擠退。

### 13. 痕跡記憶性

世界記憶不一定是完整日誌。更常見的是局部痕跡：空位、濕痕、被翻過的牌、改口的人、少一股人流、某人下次少罵一句。

玩家可見：重訪場景時看到之前行動的殘留，而不是只看到「任務完成」。
推導後果：場景描述要有重訪狀態；物件卡要有被使用、被移動、被別人先處理後的文案。

北岸例子：玩家整理過等候線後，再回來不顯示完成勾，而是看到踏板口少一段橫穿人潮。

### 14. 傳聞不完整性

消息不是百科。消息以半句話、錯認、偏見、價牌變動、傳話、票據被拒、某人突然安靜的方式露出。

玩家可見：玩家聽到的是局部版本，且不同人可能給不同說法。
推導後果：傳聞卡應寫來源、偏見、缺口與可能被後續事實修正的地方。

北岸例子：茶桶邊的人說某船慢了，但他不知道是水位、濕貨讓位還是船戶臨時換班。

### 15. 多重危險性

危險不只來自戰鬥。水、泥、擠、錯貨、欠帳、通行被拒、工具不足、被誤認、錯過時機，都能成為可玩的風險。

玩家可見：不打架也會出事；出事後不一定扣血，可能是失去位置、被記臉、貨壞、錢少、路被堵。
推導後果：場景卡要列出非戰鬥風險，戰鬥只是其中一種可能。

北岸例子：玩家踩到濕繩不會立刻進戰鬥，但可能被渡工喝止、被人群推開，後續請求讓船就更難。

### 16. 尺度命名性

地點名稱要符合當前可站入尺度。玩家站在一個完整渡口，就叫北岸渡口；如果是踏板、貨棚、茶桶邊，就用該尺度命名。命名會影響後續推導，不能用尷尬的功能句命名。

玩家可見：名稱一眼知道自己站在什麼尺度的地方。
推導後果：M3/M4/M5 的命名必須對應尺度；不能把場景命成作者備註。

北岸例子：北岸渡口是完整生活場；渡船踏板是瓶口；茶桶邊是停留點。三者不能混成同一個等待描述。

## 局部場景屬性表

每張場景卡至少應回答下列屬性。這些不是都要顯示給玩家，而是作者與後端用來推導玩家能看到什麼。

| 屬性 | 要回答的問題 | 北岸渡口樣例 |
|---|---|---|
| 常理化奇幻性 | 這裡的奇幻本體如何被當地生活吸收，而不是被說成設定？ | 河霧改變水位判斷、貨物保存與渡工船序 |
| 場景尺度 | 玩家站在完整場所、入口、路段、物件邊，還是制度門檻？ | 完整渡口生活場 |
| 地面與通行 | 地面怎麼走，什麼會擋路，哪條路最容易被卡住？ | 濕木、踏板口、等候線、貨路 |
| 主要人流 | 誰會經過、等待、停留、避讓或擠入？ | 候渡者、搬貨人、渡工、茶桶邊的人 |
| 主要物流 | 什麼東西從哪來、往哪去、誰負責承認它？ | 濕貨、麻袋、草墊、麻繩、貨棚價牌 |
| 可壞之物 | 什麼會濕、壞、錯排、被偷拿或失去價值？ | 草墊箱、濕繩圈、價牌、木牌 |
| 局部規矩 | 誰有權改變秩序，玩家不能亂碰什麼？ | 渡工看船序，點貨人守貨棚，木牌不能亂拿 |
| NPC 自主行程 | 玩家不介入時，誰會自己完成什麼？ | 搬貨人先送貨，渡工按水位調船序 |
| 可介入縫 | 玩家能改變哪一個局部事實？ | 讓路、拉繩、指出錯排、替人傳話 |
| 可錯過事 | 玩家若離開或等待，什麼會自己過去？ | 晚船讓位、搬貨人先到、茶桶空了 |
| 痕跡回聲 | 行動或未行動會留下什麼重訪差異？ | 空位、濕痕、少一股人流、某人改口 |
| 傳聞缺口 | 玩家只能聽到哪種不完整消息？ | 船慢了，但原因不明 |
| 非戰鬥風險 | 不打架也可能失去什麼？ | 位置、熟臉印象、過船時機、貨的價值 |

## 與內容聖經的分工

- `world-attributes-v0.md`：定義世界如何穩定推導。
- `world-bible-v0.md`：把屬性寫成可讀、可審稿、可拆卡的內容。
- 場景卡：把屬性落到單一可站入地點。
- NPC 卡：把人群自主性、非主角性、局部秩序性落到具體角色。
- 事件卡：把持續時間性、可介入性、可錯過性與痕跡記憶性落成 before / action / after。
- Runtime：只接已通過內容審稿的屬性，不把後端欄位直接暴露給玩家。

## 下一步拆分
