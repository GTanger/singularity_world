## 本檔要解的問題

前兩份世界文件錯在從局部生活場景往外補，而不是先把世界本身立起來。奇點世界不能先從某個渡口、某個城鎮、某張交易牌開始；那些只是世界根架構長出來的末端。

本檔只回答世界根層：

- 這個奇幻世界跟現實世界的根本差異是什麼。
- 為什麼文明、道路、城鎮、交易、職業、冒險會自然長出來。
- 玩家為什麼會想探索、經營、建造、戰鬥、和 NPC 產生關係。
- 後續任何場景、NPC、物件、事件必須從哪幾條根律推導。

## 2026-06-19 背景設計完整性基準

本輪修正的核心不是補更多地名，也不是把場景文案寫細。使用者指出的問題是：背景設計不完善，後面所有地圖、命名、物件、NPC、交易、玩家行動都會變成無根浮萍。

因此本檔升格為當前背景設計主入口，但仍保持 `v0`：它已能支撐下一輪審查與推導，還不是完整世界百科。任何新內容若只從局部場景、地方名稱、材料清單或 NPC 台詞往外補，都視為退回舊錯誤。

本檔採用三道檢查：

1. 背景設定本身是否回答「這個奇幻世界為什麼如此」。
2. 背景設定是否能推導到玩家可見結果：地名、場景狀態、可互動物件、NPC 行動、交易物資、衝突、回訪差異或玩家動詞。
3. 背景設定是否符合 `docs/DESIGN_KEYWORDS.md`：文字 MUD、手機輕操作、後端真理、全物件互動、玩家與 NPC 同律、世界永遠在線、不可無中生有、真實經濟、探索/冒險/經營/模擬/建造/戰鬥。

外部研究只作校準，不作奇點權威。本輪參照的方向如下：

| 外部資料 | 校準結果 | 奇點採用方式 |
| --- | --- | --- |

### 劇情/歷史世界觀底線

本作目前不需要先寫一條玩家救世主主線，但必須有足夠歷史讓玩家腳下的土地成立。歷史在奇點裡不是「過去留下的背景」，而是現在狀態本身。

最低劇情/歷史世界觀如下：

1. 世界先有過剩大地：地貌、元素、物候與生命密度先於人類秩序。
2. 人群先學會站住：最早的文明不是王國，而是路、棚、渠、樁、火帶、乾棚、守夜、分選與記路。
3. 道路與倉場讓文明相連：能保存、能搬、能被承認價格的物，才成為貨；路隊、倉場、作坊與保證因此出現。
4. 多中心秩序取代單一王權：城邦、大城、港口、遠路、地方家戶、作坊、路隊各有規矩，規矩互撞產生衝突。
5. 玩家進入的是維持中的現在：每條路、每批貨、每個門、每個熟臉秩序都可能被天候、時間、NPC 與玩家動作改寫。

這五條就是當前故事根，不是年代表演。所有地點都要回答它承接哪一條歷史鏈，以及此刻哪個狀態仍在延續。

## 角色扮演基本設定

奇點世界是一個文字 MUD 取向的奇幻角色扮演遊戲。

玩家扮演一個在奇幻世界中行動的人，不是上帝，不是世界主角，也不是被劇情保護的英雄。玩家和 NPC 一樣有身體、位置、持物、金錢、關係、行動後果，並受同一套世界規則約束。

玩家進入世界後，最基本要清楚四件事：

- 我在哪裡。
- 我是誰。
- 我身邊有誰、有什麼物件、可以去哪裡。
- 我做了什麼之後，世界哪一個事實改變了。

本作的角色扮演不是看主線劇情，也不是替系統跑任務。玩家要玩的是：在一個奇幻世界裡走路、碰物、認人、使用工具、取得與交易物資、理解地方規矩、承擔行動後果，逐步讓自己在某些地方被記住、被防備、被信任或被需要。

任何設計如果不能回答「玩家扮演誰、站在哪、能碰什麼、改變了什麼」，就還不是合格的角色扮演設定。

## 世界根命題

奇點世界是一個**生機過剩的常理化奇幻世界**。

這裡不是荒原求生，也不是現實鄉鎮加一點神秘詞。大地、水、霧、草木、礦脈、獸群與物候都比現實更旺、更密、更容易越界。世界不缺生命力，缺的是能讓人長久站住、通行、保存、交易、建造、信任與傳承的秩序。

文明不是從貧瘠中討生活，而是在過剩中劃邊界。

一條路不是單純被修出來的路，而是每天被人踩、清、守、記、爭，才沒有被水草、泥、獸徑、人群與事故吞回去。
一座城不是安全區，而是一個把過旺世界暫時壓成可居住秩序的機器。
一件貨不是物品欄數字，而是從某種地貌、工序、風險、保存方法和承認價格中被勉強固定下來的東西。
一個 NPC 不是服務點，而是同樣被這個世界推著走、替自己守住位置的人。

## 奇幻基線

奇點世界就是奇幻世界。這是前提，不是待補題。

最底層先定元素。奇幻世界不是只多一些怪物或特殊地名，而是世界中的物質、環境、材料、身體、工具與戰鬥都可能帶有元素性。

第一版元素系統先保持簡單，但要分三層：基礎元素、派生狀態/傷害標籤、材料族群。不要把所有常見 fantasy 名詞都升格成元素。

### 元素的遊戲觀

元素不是自然物理現象說明，也不是戰鬥傷害顏色。自然成因只用來支撐世界自洽；玩家層要先回答「我能怎麼判斷、怎麼行動、世界怎麼改變」。

奇點的元素要做六件事：

- 讓場景變成可判讀狀態，而不是氣氛散文。
- 讓物件產生可用動詞，例如點、滅、烘、洗、排、遮、堵、築、避、等。
- 讓路、貨、工具、NPC 行程與戰鬥前判斷發生變化。
- 讓 NPC 依同規則行動，而不是只讓玩家受影響。
- 讓玩家的成功、失敗、不處理都留下世界事實。
- 讓下次回訪能看見痕跡、衰退、被他人處理或新的風險。

因此，元素表的核心不是「火水風土各代表什麼」，而是每個元素狀態都必須能填完：

| 層 | 要回答 |
| --- | --- |
| 玩家可讀線索 | 玩家從文字/場景如何知道元素狀態存在 |
| 可用或封鎖動作 | 哪些動詞新增、失效、變貴、變慢或變危險 |
| 世界狀態差異 | 哪個物件、出口、貨物、身體、關係或地點被改變 |
| NPC 同規則 | NPC 是否也會避開、利用、處理、阻止或搶先 |
| 回訪痕跡 | 下次回來能看到什麼持續、衰退或後果 |

元素若只增加一句描述，而不改變玩家決策，不合格。元素若只在戰鬥中扣不同類型的血，也不合格。

### 基礎元素

基礎元素是世界最底層的可讀性質：

| 元素 | 基本含義 | 會落在哪裡 |
| --- | --- | --- |
| 火 | 熱、燃燒、乾燥、爆裂、灼傷 | 火源、鍛造、焦土、灼傷、驅霧、燒毀物件 |
| 水 | 流動、濕、霧、潮、保存/腐壞 | 河、雨、霧、濕貨、腐敗、渡口、滑倒、淹沒 |
| 風 | 流向、聲音、速度、散播、視線干擾 | 風口、聲音傳遞、霧散、箭矢偏移、氣味、遠行 |
| 土 | 重量、承載、阻擋、生長、礦石 | 路、坡、牆、礦、根系、坍塌、築造、防守 |

### 派生狀態 / 傷害標籤

派生狀態不是新元素，而是元素作用後留下、可被世界規則讀取的狀態。

| 狀態 | 來源 | 用途 |
| --- | --- | --- |
| 冰 | 水 + 寒冷 | 滑、凍、保存、阻路、減速 |
| 雷 | 雷暴天候把高處、水邊、濕地、金屬工具、人群與通行路線改寫成危險局勢 | 避雷、停渡、封路、驚嚇、麻痺、點燃、焦痕 |
| 毒 | 水/土/生物腐敗 | 傷害、污染、拒收、醫治需求 |
| 酸 | 水 + 腐蝕性材料 | 腐蝕、破壞、傷口惡化 |
| 煙 | 火 + 風或火 + 濕物 | 遮視線、嗆人、傳遞危險 |
| 泥 | 水 + 土 | 減速、留痕、滑倒、污染貨物 |
| 蒸氣 | 火 + 水 | 遮蔽、燙傷、推動、濕熱 |

### 材料族群

材料族群不是元素，而是承載元素性質的物質家族。

| 材料族群 | 基本特性 | 可承載的元素性 |
| --- | --- | --- |
| 木 | 可燃、可腐、可加工、有韌性 | 火、水、風 |
| 金屬 | 硬、重、可鍛、導熱 | 火、雷、土 |
| 石/礦 | 硬、重、可裂、可熔煉 | 土、火、水 |
| 草/纖維 | 易燃、易濕、可編織、輕 | 火、水、風 |
| 皮/骨 | 韌、可腐、可製具、來自生物 | 水、土、毒 |
| 液體 | 流動、滲透、污染或清洗 | 水、毒、酸、火的反制 |

元素不是玩家面板上的四條數值。元素是世界物的底層性質，每個地點、材料、工具、身體狀態、天候與傷害都可以帶有一種主元素，或由兩種元素形成現象。

元素落到世界時，至少要回答五件事：

| 層 | 要回答 |
| --- | --- |
| 來源 | 這個元素從哪裡來：地貌、天候、生物、火源、礦脈、腐敗、工序 |
| 承載 | 它附在哪裡：地面、水體、材料、工具、身體、建築、貨物、傷口 |
| 狀態 | 它現在怎麼表現：熱、濕、乾、重、滑、霧、裂、燒、腐、硬 |
| 作用 | 它改變什麼：通行、視線、保存、價格、傷害、工具效果、NPC 行動 |
| 後果 | 玩家做或不做後，世界事實怎麼變：熄滅、燒毀、受潮、乾燥、坍塌、硬化、擴散 |

元素互動先用最簡單的組合，不做複雜玄學：

| 組合 | 典型現象 | 可玩結果 |
| --- | --- | --- |
| 火 + 風 | 擴散、爆燃、煙、熱風 | 火勢變快、煙遮視線、聲音/氣味傳遠 |
| 火 + 水 | 蒸氣、熄滅、燙傷、潮熱 | 火被壓制、視線變差、濕物被加熱或毀壞 |
| 火 + 土 | 焦土、鍛造、硬化、裂石 | 工具加工、地面危險、牆/石受損 |
| 水 + 風 | 霧、雨、潮氣、寒濕 | 渡口、視線、貨物保存、行程改變 |
| 水 + 土 | 泥、沼、腐敗、生長 | 路變慢、貨變壞、植物暴長、腳步受困 |
| 風 + 土 | 沙塵、落石、乾裂、塵霧 | 路況變差、射擊偏移、遮蔽或暴露痕跡 |

雷的規則單獨處理：雷不是基礎元素，也不是火與風相加。設計上，雷先是一種天候把場景重排成危險局勢的規則；自然成因只能放在支撐層，不能取代玩家要玩的判斷。

但雷的遊戲觀不先是自然成因，而是局勢改寫：雷暴讓高處、水邊、濕地、金屬工具、牲口、人群與通行路線短時間變成風險判斷。玩家要能從前兆決定收工具、退到低處、找棚、等、改路、救人或利用停渡/封路造成的機會；NPC 也應因此停船、收棚、牽畜、封路或躲避。

| 雷的層 | 世界規則 | 玩家看到什麼 |
| --- | --- | --- |
| 起勢 | 雷暴靠近，使地方規矩開始收緊 | 雲壓低、風向亂、遠處悶雷，渡工與路人開始收棚 |
| 危險點 | 高處、水邊、濕地、金屬工具與聚集人群變成需要處理的位置 | 高處被催離，金屬工具要收，濕地與渡口不宜久留 |
| 立即選擇 | 玩家可等、退、收工具、躲棚、改路、提醒或拉走 NPC | 路線暫停、船序改變、有人搶棚、有人冒險趕路 |
| 後果 | 雷後留下可追問、可交易、可修補或可避開的局部事實 | 焦黑木物、斷裂繩、受驚人群、停渡記錄、臨時封路 |

人與戰鬥接元素時，先走三條簡單路徑：

| 對象 | 元素怎麼進來 | 玩家看到什麼 |
| --- | --- | --- |
| 人 | 因位置、工具、承諾或行動選擇被捲入元素局勢 | 被警告、被阻止、被要求處理、交易條件改變、行程改變 |
| 武器/工具 | 材料、工序、保養與現場環境改變用途 | 濕弓難用、火把驅霧、鐵器導熱、木盾受潮變重 |
| 戰鬥 | 地形、天候、武器、對手與傷害帶元素性 | 霧裡看不清、泥地難退、火勢逼位、潮濕讓某些物件失效 |

硬規則：元素不先是傷害數字，而先是世界狀態變化。火先讓物件變熱、燃燒或焦黑；水先讓物件變濕、流動或腐壞；風先改變流向、聲音或視線；土先改變承載、重量或阻擋。戰鬥傷害只是這些狀態被用在身體上的結果之一。

人不必天生奇幻，但人會因位置、工具、關係、承諾與行動選擇進入元素局勢。戰鬥不必每一招都是法術；只要武器、地形、天候、傷害、對手或後果帶有元素性，戰鬥就進入奇幻規則。

本作的奇幻基線很簡單：世界存在現實沒有的規則、現象、生物、材料、地貌與危險；這些差異必須被玩家看見、碰到、利用、避開、交易、修補或承受後果。

「常理化」不是把世界寫成現實鄉鎮，而是讓奇幻現象在世界內自洽。當地人可以把異常當日常處理，但玩家仍要感覺到這不是現實世界。

類型詞不得反過來主導奇點。奇幻不是套模板；除非設計者明確拍板，任何類型詞只作語感參照，不作系統來源。

設計責任也不推回使用者。設計者定方向；文件要自行提出可審查版本，不能把每個奇幻細節都問回去。

## 世界屬性

這些屬性不是背景詞，而是後續地圖、NPC、物件、經濟、戰鬥與 UI 都必須能讀出的根層條件。

| 屬性 | 世界規則 | 玩家層表現 |
| --- | --- | --- |
| 生機濃度高 | 草木、水氣、獸群、腐化、根系、蟲菌與物候比現實更旺、更密、更快越界。 | 玩家進入一地時先看到「這裡靠什麼壓住過旺生機」，而不是只看到空地名。 |
| 邊界會磨損 | 路、棚、倉、牆、泊位、畜欄、門禁、信任與價格都不是永久穩定。 | 同一地點過一段時間後，通行、貨況、人群與可做事可能不同。 |
| 物候會改變玩法 | 霧、雨、潮、風、熱、寒、日夜、季節、水位會改變可見度、路況、材料、NPC 行程與風險。 | 天候時間不是氣氛貼圖，而會改變「能不能走、能不能存、該問誰、該等還是該撤」。 |
| 材料有來處與時效 | 材料必有來源、品質、處理狀態、保存狀態、所有權與可追溯路徑。 | 玩家看到的貨不是抽象資源點，而是能被取得、分選、保存、搬運、買賣或毀壞的世界物。 |
| 地貌有行為 | 河、坡、林、澤、礦脈、草場、潮線不是背景格；它們會阻擋、吞沒、暴露、保護或誘導人群。 | 地圖命名、路徑與冒險要從地貌行為長出來，不靠尷尬地名硬撐。 |
| 人群需要秩序 | 聚落靠守路、分貨、保管、修具、排班、保證、巡夜與規矩維持。 | NPC 不是等玩家點擊才有意義；玩家看到的是人正在處理自己的位置、工序、債、貨、路和例外。 |
| 知識局部化 | 沒有人掌握全圖；可靠知識多半只對某段路、某種天候、某批貨、某個熟人圈有效。 | 探索不是開黑格，而是累積地方經驗、可靠人名、路況記憶與可驗證傳聞。 |
| 奇幻日常化 | 奇幻先表現為地方常識、工序、避忌、工具、標記與經驗，而不是先丟專有名詞。 | 玩家先覺得「這個世界有自己的常理」，再從常理裡碰到奇幻，不是被名詞灌設定。 |
| 同律 | 玩家、NPC、物件、錢、貨、傷害、阻擋、交易都服從同一後端真理。 | 玩家能碰到的規則，NPC 也會被它推著走；NPC 能使用的世界物，玩家也應能以規則接近。 |
| 永遠在線 | 世界時間不因玩家下線或視線離開而停止；觀測只決定玩家承認哪段可追溯事實。 | 玩家回到一地時看到的是局部結果、痕跡、錯過、變化與可追問線索，不是暫停後原封不動。 |

## 時間、歷史、沿革與現在態

奇點世界的歷史不是遠古背景，也不是只在以前留下的痕跡或殘留物。歷史就是現在態：此刻以前的一切狀態變化，連續演算到當前這一秒。

昨天是歷史，前一秒也是歷史。玩家剛點過的燈、NPC 剛走過的踏板、剛被搬走的貨、剛落下的雨、剛改變的隊列位置，下一秒都已經成為世界歷史的一部分。若後端以 tick 推進，上一 tick 就是即時歷史；若玩家剛完成一次動作，動作結果也立刻進入下一次觀測的世界成因。

所以奇點不把歷史當成「過去留下來的東西」才讀。價牌為何被壓低、某人為何不在原位、繩為何濕、門為何暫關、隊列為何少一格、火為何剛熄，都是歷史正在構成現在。沒有這一層，場景只剩擺設；有這一層，玩家才是在一個已經運作到此刻的世界裡行動。

因此，本作不把故事狹義理解成主線任務或背景年表。故事是狀態變化的因果鏈；歷史是已經發生的狀態鏈；世界觀是這些狀態鏈在土地、物候、道路、制度、職業、物價、禁忌、人物關係與可用動詞上的總和。

外部研究校準也支持這個用法：遊戲 worldbuilding 需要把歷史、文化、規則、地理接到可實作的關卡、互動與程序生成；story bible 不是只寫劇情摘要，而要列 key objects、major events、locations 與資訊如何傳給玩家；level design 的 diegetic circulation 要回答世界內人物如何使用空間、路徑背後有什麼故事。奇點採用這些方法的約束版：只保留能改變現在態、地圖生成、NPC 行為、物件狀態或玩家動詞的歷史。

### 五層時間尺度

每個地點、NPC、物件、勢力與物資，都應能被放進五層時間尺度中，而不是只寫一段背景：

| 時間層 | 回答什麼 | 對現在態的作用 |
| --- | --- | --- |
| 深時層 | 元素、地貌、水系、礦脈、氣候、生物容量如何形成 | 決定土地、材料、地形、元素風險與可建設邊界 |
| 長期生態層 | 草木、水網、獸徑、腐化、蟲菌、物候如何佔據此地 | 決定此地被什麼過剩生機推動或威脅 |
| 文明沿革層 | 人群如何開路、築渠、設倉、守門、定價、立禁忌、形成職業 | 決定道路、聚落、勢力、工作、規矩與社會成本 |
| 近期沿革層 | 昨日、今晨、上次船期、上一批貨、前一場雨、最近衝突發生了什麼 | 決定今天人在哪裡、物件狀態、價格、路況、缺席與傳聞 |
| 即時歷史層 | 前一秒、上一 tick、上一個玩家/NPC 動作、上一個天候或物件事件改變了什麼 | 決定下一秒可見狀態、可用動詞、NPC 反應與回訪差異 |

深時層不等於自然科普，近期沿革也不等於任務日誌。它們都只在能推導現在態時成立。

### 已知世界的時間骨架 v0

本節不是玩家必讀年表，也不是正式紀元名。它先回答：奇點已知世界為什麼在現在呈現「沃土、過剩、邊界、局部秩序、多中心文明、永遠在線」這種狀態。

#### 1. 過剩大地先於人

在人類活動成形以前，這個世界已經不是空白土地。水、土、風、火四種基本性質讓河網、濕地、坡地、礦脈、草場、林澤與海口各自長出不同的過剩狀態。

現在態：

- 沒有真正「空地」。所謂空地，多半只是暫時沒被水草、獸徑、根系、泥、霧、潮線或人群占住。
- 地形不是背景。河會改道，澤會迷人，坡會鬆，林會吞路，礦坡會掉粉塵與裂石。
- 材料不是一撿就能用。木、草、礦、皮、魚、液體都帶地貌與時間條件，離開來源後會變質、受潮、裂、腐或失價。

這一層生成 M0/M1：河流帶、沃野帶、礦坡帶、林澤帶、城鎮帶、遠路帶、海口帶不是行政區，而是過剩大地長出來的不同現在態。

#### 2. 人先學會站住，而不是先建立王國

早期人群沒有先征服世界，而是先學會讓一小塊地方能站、能睡、能存、能過、能回來。最早的文明技術不是宏大魔法，而是邊界技術：抬高地面、挖渠、立樁、燒火帶、掛繩、堆乾棚、守夜、分濕貨、記路、辨霧、讓人照看。

現在態：

- 每個聚落的核心不是「有房子」，而是有人在維持可站住的邊界。
- 職業從維持成本長出來：渡工、巡路人、守倉人、分選工、修具工、牧人、引路人。
- 地方常識比遠方知識重要。某條路、某種霧、某段水位、某片草場，只能由熟路人、守物者或當地工作者判斷。

這一層生成 M2：局部秩序區不是安全區，而是人群把過剩大地壓成可用狀態的結果。

#### 3. 道路與倉場先把文明接起來

人群能站住後，真正讓文明擴大的不是城名，而是道路、船路、倉場、秤、牌、保證、口信與可被承認的價格。過剩世界裡，東西很多，但能被搬走、保存、交付、定價的東西才進入經濟。

現在態：

- 路不是線，是每日維持出的通行狀態；不清、不守、不記，路就會被草、泥、水、人群、獸徑或事故改寫。
- 倉不是背景建築，是把短命物資暫時固定成可交易狀態的場所。
- 錢不是唯一交易核心。讓位、保證、看守、搬運、修補、引路、翻譯、賒欠、人情，都能成為交換的一部分。
- 價格不是靜態表。價格受來源、時效、保存、路線、所有權、誰承認、今天誰急著要影響。

這一層生成經濟、NPC 工作、物件狀態與玩家可做事：包、搬、存、等、問、保證、拒絕、壓價、賒、守、修。

#### 4. 大秩序無法完全覆蓋小地方

當道路、倉場與聚落連起來後，才出現城鎮、大城、城邦、港口與遠路秩序。但世界太旺、變化太快、知識太局部，沒有任何單一權力能穩定覆蓋全部土地。

現在態：

- 世界是多中心文明，不是一個全知王國。大城、城邦、港口、邊鎮、倉場、路隊、地方家戶各有規矩。
- 法與人情並存。正式牌、門、秤、稅、告示能處理常態；例外仍靠熟臉、保證、讓位、作保、欠帳與誰願意承擔責任。
- 同一件事在不同地帶有不同意義：河流帶的先過船，在城門可能變成插隊；礦坡的工具保證，在港口可能只是貨單附註。

這一層生成勢力與衝突：衝突不只來自戰鬥，也來自規矩互撞、通行被拒、責任轉嫁、物資失價、信用破裂與路線改變。

#### 5. 現代是維持中的世界，不是完成的世界

玩家進入的現在，不是文明已經戰勝自然的時代，也不是末世。這是人群每天仍能開市、行路、收貨、修具、立門、守倉、出船、放牧、採集、報價、爭執的時代；但每一項都需要持續維持。

現在態：

- 舊路可能仍在用，也可能今天被封、被泥吞、被人改走。
- 新規矩可能只是昨日事故後臨時定下，今天已經影響玩家能不能靠近某物。
- NPC 的「故事」不是台詞背景，而是他此刻的身體、持物、位置、債、工作、記憶與下一步。
- 玩家動作一旦改變物件、位置、關係、錢、時間或風險，下一秒也成為這個世界的歷史。

這一層是第一屏和所有 M4 的直接根：玩家站到任何地方，都不是站進靜態房間，而是站進這個世界演算到此刻的狀態。

### 內容生成用的歷史問法

任何地點若要進入內容包，不先問「以前發生過什麼大事」，而先問：

```text
這塊地在過剩大地中屬於哪種狀態？
人群為了站住，維持了什麼邊界？
哪條道路、倉場、規矩、職業或價格由此長出來？
哪個大秩序或地方規矩正在控制它？
最近一天到前一秒、上一 tick 或上一個動作，什麼狀態正在改變？
玩家站入時，能改變哪個下一秒？
```

能回答這六題，歷史才成為故事。答不出，歷史只是背景文字。

### 現在態格式

世界內容不得只寫「這裡以前如何」。每個可進玩家層的場景卡、NPC 卡、物件卡與事件卡，至少要能回答：

```text
現在狀態：
造成此狀態的時間鏈：
正在延續的變化：
若玩家不介入：
若玩家介入：
下一次觀測時可見狀態：
```

這六項不是全部顯示給玩家的文字，而是作者、後端與內容驗收用的世界根。玩家只應看到當前局部事實、可點入口、行動結果、錯過、變化與可追問線索。

### 與永遠在線 / 觀測坍縮的關係

永遠在線表示世界狀態持續演算；觀測坍縮不是未被看見的人事物停止，而是玩家重新接觸時，從可追溯的故事線中承認一個現在態。

未觀測區域可以保留多條可能故事線，但每條故事線都必須能回到「現在狀態」。如果玩家接觸 NPC，連過去態也被收束，是因為那個 NPC 的當前身體、持物、位置、記憶、關係與行程需要一條可承認的時間鏈。

### 不合格寫法

- 把歷史寫成年表，但不改變地貌、道路、制度、NPC、物件、物價、風險或可用動詞。
- 把故事寫成玩家必讀背景，而不是現在世界狀態的成因與延續。
- 只寫遠古、王朝、戰爭、神話，卻不回答「前一秒、上一 tick 或上一動作到現在」。
- 把歷史當成遺跡、回憶或背景痕跡，而不是此刻土地、人群、物件與制度本身的狀態。
- 用舊特殊設定、專有名詞或宏大設定替代可驗證的現在態。

## 設計校準

外部遊戲設計參照只用來校準文件有沒有回到玩家體感，不取代 `docs/DESIGN_KEYWORDS.md`。

- MDA 校準：每條世界屬性都要能落到「機制、運行行為、玩家感受」三層；不能只停在世界觀句子。
- 活世界校準：人物與生物必須屬於環境，並且會塑造、也會被環境塑造；不能把 NPC 放成可點擊櫃台。
- 系統型設計校準：物件、狀態、規則要能互相作用，產生玩家可碰到的可能空間；不能只寫固定劇本。
- 時間/故事校準：歷史、事件、地點與物件必須能轉成當前狀態、因果、路徑、節奏、資訊揭露或互動條件；不能只寫成背景散文。

## 世界核心拉扯

### 生長 vs 邊界

世界持續往外長。水草覆路，霧吃視線，獸群改道，根鬚頂開石縫，潮氣毀木箱，物候讓同一片地一季後變成另一種可用或不可用的地方。

人類活動則持續劃邊界：路樁、繩線、牆、棚、火帶、溝渠、排班、牌、契約、門禁、守望、巡路、倉儲。

可玩性來自這個拉扯：玩家不是去踩一張靜態地圖，而是進入一個每條路都需要被維持、每個邊界都可能被吃掉或被搶走的世界。

### 豐饒 vs 保存

東西多，但能保存、搬走、交易、使用的東西不多。草長得快，卻會返潮；魚多，卻會壞；木材厚，卻會生裂；礦料多，卻可能含雜脈；獸群壯，卻不一定能馴。

因此經濟不是「採集後賣出」而已，而是：取得、分選、處理、保管、運輸、證明、定價、交付。每一步都能產生角色、職業、工具、場所與衝突。

### 未知 vs 局部經驗

世界太大、太旺、太會變。沒有人能掌握全圖。人靠局部經驗生活：某條路早上能走、晚上不能走；某種霧能等，某種霧要退；某片草場能放畜，另一片只差半里就會失蹄。

探索不是把黑格點亮，而是學會一個地方的規矩：什麼能碰、什麼不能等、誰說的話可靠、哪種物候代表危險、哪種材料值得帶走。

### 秩序 vs 人情

正式規矩永遠不夠。牌、門、秤、契約、守門人、行路規矩能維持表面秩序，但過剩世界每天都會製造例外：貨要先過、人要借道、病獸要退欄、路被沖斷、某批材料今天不能久放。

人情不是寒暄裝飾，而是秩序承受不了例外時的第二套貨幣。玩家能不能被記住、被信任、被請託、被防備，會改變他在世界裡能走多深。

## 奇幻本體

本作的奇幻不先從法術職業、神祇陣營、命定血脈、地下城開始。它先從**世界本身過度有生命力**開始。

奇幻性要落在五個層面：

1. **物候異常**：季節、霧、雨、水位、草勢、獸徑會比現實更劇烈，並改變道路、物資與人群行為。
2. **物質不穩**：材料不是永遠穩定的物品；它會受地貌、濕度、處理方式、保存時間與搬運路線影響。
3. **地貌有脾氣**：路、坡、林、河、湖、礦脈、潮線不是背景；它們會阻止、吞沒、推擠、暴露或保護人類活動。
4. **生命過密**：植物、獸群、微小生物、腐化、根系、草籽、水生物都會讓世界顯得活，但也讓文明維護成本提高。
5. **經驗成為技術**：當地人不一定說「魔法」，他們用繩、灰、牌、火、渠、乾棚、守夜、分選、避忌、路歌、工序處理奇幻世界的日常異常。

這讓世界奇幻，但不變成通用奇幻模板。玩家會先遇到可理解的現象，再慢慢發現這些現象背後不是普通自然，而是整個世界的根性。

## 世界尺度

### M0：過剩大地

整個已知世界的底層是一片過度旺盛的大地。人類不是在上面任意畫地圖，而是在少數能穩定維持的地帶建立文明。

M0 的問題：哪裡能長久站住？哪裡會被吞回野地？哪裡的物候可以被利用，哪裡只能繞開？

### M1：文明帶與荒野帶

世界不是城鎮點狀散落，而是由幾種大尺度帶構成：

- 河流帶：水、霧、運輸、濕貨、船、渡口、魚、潮氣。
- 沃野帶：田、草、畜力、灌溉、季節、糧、蟲害與野生邊界。
- 礦坡帶：石、金屬、粉塵、山陰、滑坡、工具、粗料與危險工序。
- 林澤帶：過密植物、水網、蘆草、獸跡、迷路、採集與消失的舊路。
- 城鎮帶：倉、街、井、工坊、車馬、門禁、熟臉與地方秩序。
- 遠路帶：驛道、邊鎮、商隊、巡路、補給、路標與被荒野壓迫的交通。
- 海口帶：潮線、船、稅、外貨、語言、匯兌、異地規矩。

每一帶都不是地理分類，而是一組會推導玩法的世界條件。

### M2：局部秩序區

M2 是人類把世界壓成可用秩序的範圍。例如一段穩定河岸、一片可耕田、一個城門外圈、一條被巡路人維護的路、一座能暫存貨物的倉場。

M2 的問題：這個地方靠什麼維持？誰維持？什麼會破壞它？玩家能加入、利用、破壞或修補哪一部分？

### M3 / M4：玩家站入點

M3/M4 只能在世界根架構之下成立。任何站入點都要能回答：

- 它屬於哪個大尺度帶。
- 它在維持什麼邊界。
- 它處理哪種過剩生機或物候風險。
- 它讓哪些人、物、錢、消息、工具流過。
- 玩家站進去後能改變哪個局部事實。

## 文明結構

### 聚落不是安全區

聚落是壓住過剩世界的工作集合。有人守路、有人清渠、有人分貨、有人修具、有人看門、有人記價、有人巡夜、有人照看牲口、有人處理濕貨、有人判斷今天能不能出行。

所以城鎮要好玩，不能只是商店、旅店、工坊、倉庫列表；它必須呈現「這座聚落今天在維持什麼」。

### 職業不是功能 NPC

職業來自世界維持成本：

- 渡工：處理水、霧、船序、人群與濕貨。
- 巡路人：維持道路不被草、泥、獸群、盜路與事故吞掉。
- 分選工：把過剩物產分成可用、可賣、可存、該丟的類別。
- 守倉人：維持物資在時間、濕度、歸屬與責任上的穩定。
- 牧人：讓畜力在過旺草場與野性風險中仍可被人使用。
- 修具工：讓工具在高耗損世界裡保持可用。
- 兌票人、翻譯、引路人：處理人類秩序之間的縫。

NPC 的吸引力不是因為他有台詞，而是因為他有一段正在維持的世界秩序。

### 社會組織

社會組織從維持成本長出來，不從頭銜表長出來。

- 家戶：守住日常工具、食物、睡處、熟人關係。
- 作坊：把材料處理成可用物。
- 倉場：把物資從短命狀態固定成可交易狀態。
- 路隊：把人和貨穿過不穩地帶。
- 聚落：把多個維持工作合在一起。
- 城邦 / 大城：把更大範圍的通行、稅、貨、衝突與責任制度化。

組織越大，越不是更安全，而是牽涉更多規矩、排除、權責與人情。

## 核心衝突

### 1. 邊界失守

路被吞、田被水草逼回、倉貨受潮、城門外秩序崩、獸群改道、礦坡滑落。玩家可以救、繞、利用、趁亂、修補或忽略。

### 2. 物資短命

世界豐饒，但很多物資離開原地後壽命很短。保存、加工、搬運、交易時機都會產生玩法。

### 3. 熟人社會與外來者

玩家不是主角，進任何地方都先是外人。熟臉、人情、保證、欠帳、惡名與可靠度會比等級更早影響通行。

### 4. 荒野不是空地

野外不是城外空格，也不是刷怪區。它是過剩世界比較少被人壓住的地方：路會變、聲音會騙人、物候會超出人的日常經驗，材料更有價值也更難帶回。

### 5. 文明互相拉扯

河流帶、牧地、礦坡、城鎮、港口的需求不同。某地覺得合理的規矩，在另一地可能是壓價、插隊、偷路或違約。玩家長期可玩性來自跨地帶行動與後果。

## 玩家位置

玩家不是世界中心，但玩家值得進入世界，因為他具備三種能力：

1. **觀察與選擇**：玩家能看見局部狀態，選擇等、問、幫、搶先、繞路、交易、修補、跟隨、撤退。
2. **累積關係與痕跡**：玩家不是完成任務，而是在地方、人物、物件、道路、交易中留下可被記住或被誤會的痕跡。
3. **建立可維持之物**：玩家長期不只搬貨打怪，而是能讓一條路、一個工序、一段關係、一個住所、一批工具、一個小秩序變得更穩。

玩家的成長不是從平民變英雄，而是從無名外人變成能在某些地方「被承認有用、有風險、有信用、有位置」的人。

## 五種主要玩法如何從世界長出來

### 探索

探索不是找地圖邊界，而是理解地方規矩：哪裡會被草吞、哪裡的霧不能等、哪種材料不能久放、哪條路需要誰的保證。

### 冒險

冒險不是接任務打怪，而是進入秩序薄弱處：失守道路、暴長林澤、滑坡礦路、潮線外貨場、獸群改道的草場、無人保證的舊路。

### 經營

經營不是 UI 生產線，而是控制來源、保存、加工、路線、信用與需求。能把短命物資變成可靠物資的人，就掌握世界的一部分。

### 建造

建造不是放建築格，而是建立可維持的邊界：棚、路、渠、倉、樁、火帶、畜欄、工作面、泊位、修具處。建造後要能被世界磨損、被人使用、被荒野反推。

### 戰鬥

戰鬥不是唯一危險，但它是世界衝突的尖端。人與人、NPC 與 NPC、玩家與 NPC、玩家與玩家同規則；戰鬥常常來自邊界、物資、通行、人情與組織衝突，而不是單純怪物刷新。

## 內容母題

後續所有地點都應反覆長出這些母題：

- 被維持的路。
- 會壞的貨。
- 過旺的自然。
- 不完全可靠的傳聞。
- 站不穩的邊界。
- 規矩與例外。
- 熟臉與外人。
- 可以被使用也可以被錯用的物件。
- 沒有玩家也會繼續走的 NPC。
- 玩家留下的痕跡，而不是完成勾。

## 禁止方向

- 不要從北岸、城鎮、交易板這類局部點反推世界。
- 不要把奇幻寫成酒館、公會、任務板、魔物森林、命定英雄。
- 不要把「常理化」寫成現實擬真。
- 不要把「不接舊特殊設定」寫成世界沒有奇幻本體。
- 不要讓 NPC 成為功能櫃台。
- 不要讓世界只在玩家點擊時才動。
- 不要把經濟寫成採集物換錢。
