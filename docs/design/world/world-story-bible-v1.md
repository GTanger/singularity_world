## 0. 本檔立場

本檔不是 v4 修訂，也不是 v0 擴寫。v4 這條線已經廢掉，不再當作可修補底稿。

v1 直接重頭回答世界本體：

- 這是一顆什麼樣的平行地球。
- 能量若像空氣一樣存在於萬物中，普通生命與文明會如何長成。
- 為什麼這個世界有故事，而不是只有規格。
- 為什麼玩家會想進入，且進入後能做現實做不到的事。
- 地點、物件、NPC、交易、戰鬥與回訪差異如何從世界自然長出。

本檔不宣稱世界已完整完成。它是目前正典世界大綱入口，用來砍掉錯方向、承接後續內容包，並檢查任何新設計是否仍是無根浮萍。

v1.4 的修正重點：先把世界本體寫成可被閱讀、可被追問的故事大綱，再補大地理、文明史、當代制度、社會層級、玩家時代矛盾、具名國家/聯盟/門派/族群與舊怨，最後再補作品主幹：這個世界的時代感、主線問題、玩家如何入場、第一輪可讀世界順序，以及每個大區在故事中負責什麼。三條內容鏈只保留為驗證樣本，不得反過來支配世界。

## 0.1 本輪重頭修正

本輪修正的對象不是某個詞不好聽，也不是下游地圖、材料或勢力數量不足。

真正錯誤是：前面多次把「能量充沛」誤寫成需要被設施、標準、責任、資格或機構處理的世界。那會把奇點縮成行政工程題，玩家讀不到故事，也不會想進入。

因此本檔重開的不是 `v4.1`，而是「世界大綱第一層」：

- 先定義這顆平行地球本身是什麼。
- 再定義它為什麼有故事張力。
- 再定義普通人如何生活。
- 再定義玩家為什麼能進入、能做什麼、會留下什麼。
- 最後才允許地圖、材料、勢力、NPC、戰鬥與第一屏從這裡長出。

舊 `world-bible-v3.1.md` 只保留一件事：能量不是電力，不是供應、接入、斷供或控制資源。它不能取代本檔作為完整世界本體。

## 0.2 世界故事大綱 v1.4

### 0.2.1 世界名稱與一句話

工作名：`奇點地球`。

奇點地球是一顆能量像空氣一樣無所不在的平行地球。人不需要找到能量，也不能把能量當成某種總開關。活著本身就是交換：呼吸交換地方，觸碰交換痕跡，使用交換習慣，稱呼交換身份，同行交換過去，衝突交換傷口，死亡交換最後的來處。

這句話不是詩意包裝，而是全世界的設計根：

- 地貌不是背景，因為土地長期承受生命、腳步、死亡、風、水與聲音。
- 物件不是道具，因為物件會被使用、借出、修補、錯用、遺失、歸還與記住。
- NPC 不是端點，因為每個人也在和自己的持物、名字、家戶、路、工作與舊事交換。
- 玩家不是主角，因為玩家只是其中一個會留下痕跡、也會承受痕跡的人。

### 0.2.2 世界中心故事

奇點的中心故事不是「誰掌握能量」，也不是「誰管理世界」。

中心故事是：

```text
世界太容易交換，也太容易記住。
文明越成熟，留下的痕跡越多。
人想活得自由，卻一直踩在自己、他人與前人留下的東西上。
```

這個故事足以長出奇幻、冒險、生活、經營、建造、交易與戰鬥：

- 奇幻：普通呼吸、稱呼、觸碰、工具與路，都可能比現實多一層可觸發的後果。
- 冒險：荒野不是空白資源區，而是生命、舊路、失物、死者與未完之事過密的地方。
- 生活：家、工作、交易、醫療、學習、娛樂都必須處理人和物留下的痕跡。
- 經營：價格來自來處、可信度、前主、使用史、歸還壓力與地方傳聞。
- 建造：修路、立牌、留燈、安置物件、命名場所，都會改變後來的人如何使用一地。
- 戰鬥：衝突不是扣血公式先行，而是物、名、路、工具、關係、地勢與目擊後果一起爆開。

### 0.2.3 世界不是什麼

為避免再次偏掉，以下不是奇點世界根：

- 不是電力文明：能量不能被理解成電、供應、接入、斷供、主供或低供。
- 不是治理世界：制度可以存在，但世界不以標準、責任、封禁、證明或管理語彙為核心吸引力。
- 不是中古模板：不能預設酒館、公會、村落手工業、渡口倉庫、木牌短市那種低生活密度語感。
- 不是元素傷害表：火水風土等元素若出現，必須成為玩家可讀、可碰、可避、可改變的局部世界狀態。
- 不是材料百科：材料只有在能產生物件、職業、地理、交易、衝突與玩家動詞時才成立。
- 不是任務板 RPG：NPC 不等玩家開話題；玩家只是撞進他們本來正在處理的局部事實。

### 0.2.4 奇點地球的讀法

這個世界應該像一部可讀作品，而不是一張設定表。任一地點、物件、NPC、勢力、衝突都要能被追問六層：

| 層 | 必須回答 |
|---|---|
| 起源 | 它如何從含能世界、生命交換或人類生活中長出 |
| 歷史 | 它經歷過什麼，尤其大回潮或地方事故如何改變它 |
| 現在 | 玩家此刻看到的狀態是什麼，誰在場，什麼不在場 |
| 牽連 | 它牽著哪些人、物、路、名字、價錢、信用或禁忌 |
| 動詞 | 玩家和 NPC 能做什麼，做了改變哪個世界事實 |
| 回訪 | 玩家離開或下線後，哪些後果會被保存、淡化、轉交或反噬 |

任何只能回答分類、用途、數值或陣營歸屬的東西，都還不是奇點內容。

### 0.2.5 星球根

奇點地球在星球形成時就與現實地球分歧。能量不是後來覆蓋世界的魔法，而是與大氣、海洋、岩石、光、潮汐、聲響一起成為存在條件。

這造成四個根本差異：

1. 空氣不是空白介質。呼吸會讓人帶入地方，也把自己留在地方。
2. 水不是單純流體。海、雨、河、霧會磨淡、包裹、送回或改變痕跡。
3. 土不是地圖底色。地表會承受腳步、居住、建造、埋葬、戰鬥與遠行。
4. 聲音不是瞬間消散。稱呼、歌、哭聲、誓言與謊言都可能留下微弱但可累積的影響。

因此奇點的奇幻不是某群人會施法，而是整個世界的基礎介質都不是現實那種中性背景。

### 0.2.6 生命根

能量充沛不代表生命輕鬆。早期生命最大的難題不是取得能量，而是在過度交換中保住自己。

生命演化出五類本能：

- 成形：讓自己不被世界沖散。
- 遮蔽：避免被其他生命、地方或舊痕過度讀取。
- 模仿：借用周圍痕跡讓自己活下去。
- 排出：把不適合自己的地方性、傷痕或外來影響慢慢推出身體。
- 共存：與群體、工具、巢穴、路線、食物來源形成穩定交換。

這讓荒野天然好玩：它不是採集區，而是生命彼此讀取、遮蔽、模仿、吞食、迴避與留痕的地方。玩家進荒野不是找節點，而是讀一片生命過密的局部世界。

### 0.2.7 文明根

人類在奇點地球上的特殊性，不是能量使用權，而是能把交換整理成可傳承的形式。

人類最早穩住世界的方法不是王權或機器，而是：

- 名字：讓變動的人能被認出。
- 工具：讓手的習慣延伸到物。
- 葬禮：承認死者仍會影響活人。
- 道路：把重複腳步變成可被後人信任的去處。
- 家戶：讓人、物、死者、孩子與日常互相照看。
- 門派：把身體、工具、世界與他人的方法教給下一代。
- 城市：在高密生活中整理人、物、名字、交易、病傷、演出與遠行消息。

文明井噴不是因為人控制能量，而是因為人發明了讓普通人也能安全接觸、辨認、繼承、淡化、轉交與修補痕跡的方法。

### 0.2.8 大回潮與當代

大回潮是奇點地球目前的世界史斷點。

它不是能源事故，也不是制度崩壞。它是長期文明累積的戰爭、交易、死亡、遷徙、誓言、欺瞞、愛、失物、建造與未完之事太多，使整片世界把過去壓回現在。

大回潮之後：

- 海岸送回不該再回來的物。
- 舊路在沒有人的地方短暫出現。
- 同一個名字叫回太多人與太多舊事。
- 房屋、工具與街區拒絕某些新使用者。
- 某些人身上帶著不屬於自己的腳步、夢、傷口或稱呼。

當代奇點沒有倒退。它是成熟、高密、日常奇幻化的世界。普通人知道如何處理陌生物、舊名、食物來處、工具前主、地方禁忌、遠行消息與病傷後果。城市、國家、聯盟、門派、氏族與種族都存在，但它們存在的理由必須回到「如何讓人和痕跡共處」。

### 0.2.9 玩家進入理由

玩家進入奇點不是為了讀百科，而是為了在同規則世界中做現實做不到的事：

- 用手觸碰一件物，讀出它不只是可買可賣的道具。
- 用一個稱呼叫住人，也可能叫回錯人或舊事。
- 帶著某物走一段路，讓路改變玩家，玩家也改變路。
- 把物歸還、改用、藏起、放走、修補、賣掉，讓世界承認不同後果。
- 幫一個人被記住，或幫一個人從太重的舊事裡變淡。
- 下線後仍讓自己的角色成為世界中會被推進的人，而不是暫停在登入畫面外。

玩家的第一批樂趣應該是「我碰了，世界真的有差」，不是「我讀了一篇設定」。

### 0.2.10 下游生成令

從本節開始，任何地圖、材料、勢力、NPC、衝突、第一屏都必須先通過這條生成令：

```text
含能世界
-> 生命如何交換
-> 人類如何把交換整理成生活
-> 大回潮或地方史如何壓成現在狀態
-> 玩家看見哪個人/物/地/名字/路況
-> 玩家和 NPC 能做哪個動詞
-> 世界狀態如何改變
-> 回訪時如何讀到後果
```

如果設計直接從地名、材料名、職業名、勢力名、戰鬥公式或場景氣氛起頭，就是倒果為因。

## 0.3 世界大綱總覽

### 這個世界是什麼

奇點地球不是現實地球加一層魔法特效。它是一顆從形成開始就能量充沛的平行地球。

這裡的能量像空氣一樣在世界裡。人不需要取得它，也沒有人能把它當成總開關。活著本身就是交換：呼吸交換地方，觸碰交換痕跡，使用交換習慣，稱呼交換身份，同行交換過去，衝突交換傷口，死亡交換最後的來處。

### 這個世界的故事問題

奇點的故事問題不是「誰最會用能量」。

它的故事問題是：

```text
世界太容易交換，也太容易記住。
人想自由生活，卻一直踩在自己和前人留下的痕跡上。
```

這讓世界天然產生遊戲張力：

- 一件物不是空白道具，它可能帶著前主、地方、錯用、修補、借出或歸還壓力。
- 一條路不是座標線，它可能帶著腳步、失約、死亡、追蹤、逃亡或重訪熟悉度。
- 一個名字不是裝飾字串，它可能讓人被認出、被誤認、被保護或被拖回舊事。
- 一座城市不是功能集合，它是高密度生活中人、物、地、名字與過去互相擠壓的地方。

### 這個世界為什麼值得讀

因為任何玩家看見的人、物、地，都可以被追問：

- 它從哪裡來。
- 誰碰過它。
- 它為什麼變成現在這樣。
- 我碰它會讓誰受影響。
- 我若不碰，它會不會被別人帶走、放下、弄壞、藏起或歸還。
- 我下次回來時，這件事會留下什麼。

如果一個設定不能被這樣追問，它就不是奇點世界的內容，只是裝飾名詞。

### 玩家為什麼想進入

玩家想進入，不是因為被任務叫去救世界，而是因為這個世界讓玩家能做現實做不到的事：

- 讀出一件物的前主與來處。
- 讓一段路因自己帶著某物而短暫出現。
- 叫出一個名字，讓錯的人、對的人或不該回頭的人回頭。
- 把一件物賣掉、歸還、藏起或長期使用，並讓後來的人讀到差異。
- 幫一個人被記住，或幫一個人從太重的過去裡變淡。
- 在自己下線後，角色與 NPC 仍繼續被世界時間推著走。

這才是奇點的非日常可為性。不是管理能量，不是整理表格，也不是在地圖上消耗步數。

### 當代故事方向

玩家進入的是大回潮之後的成熟當代。文明沒有倒退，普通人也不是茹毛飲血的早期社會。

大回潮讓整個世界明白：過去不會乖乖留在過去。舊物、舊名、舊傷、舊路、舊誓、舊愛、舊債與舊死，都可能成為今日的價格、路況、人際、醫療、交易、衝突與玩家可做的事。

所以當代奇點不是「能源文明」，而是「痕跡文明」：

- 有人保存舊物，因為害怕該被記住的東西消失。
- 有人淡化痕跡，因為不願後人永遠背著前人的錯。
- 有人專門歸還物件，因為東西不一定屬於撿到的人。
- 有人改用舊物，因為新人生也可以接住舊來處。
- 有人遠行，因為離開不是逃避，而是讓名字、物件與人重新找到位置。

下游地圖、材料、勢力、NPC 與戰鬥，全部只能從這些故事問題往下推。

## 0.4 作品級世界主幹 v1.4

本節回答使用者真正追問的問題：如果不先把世界寫成一個完整作品，後面所有地圖、材料、NPC、戰鬥都只是表格。

奇點地球的故事不從出生點開始，不從城鎮功能開始，也不從材料清單開始。它從一個文明已經承認的事實開始：

```text
世界不是背景。
世界會把人做過、碰過、叫過、拿過、放下過的事，重新推回生活裡。
```

### 0.4.1 時代感：高密當代奇幻，不是古代，也不是現代地球

玩家進入的奇點地球是大回潮後約三到五代人的成熟當代。這裡的人已經不再把回潮、錯名、舊物、變淡的路、認手的工具當成怪談；它們是日常教育、交易、遠行、醫療、娛樂、法理與人際禮節的一部分。

這個當代有：

- 高密城市與跨城共同體，而不是孤村與酒館任務板。
- 長距離遠行與消息流通，而不是玩家走到哪裡世界才存在。
- 成熟的學習、醫療、修物、唱名、寄物、拾物、照看與演出行業。
- 普通人能理解的奇幻常識，而不是只有術士、貴族或戰鬥職業能接觸的神秘知識。
- 明亮、繁盛、擁擠、便利但不安全的日常；危險來自「生活牽連太密」，不是野外只有怪物。

它不能直接搬現代地球詞，也不能退回中古詞。奇點的時代語感應該像：街群、遠行隊、唱名所、修物行、照看院、寄物所、拾物行、食田、路宿、街戶、作保、回名日、淡痕約。這些詞的功能都回到生活，而不是回到行政、電力、科技或封建。

### 0.4.2 世界主線：人如何和過去共同生活

大回潮之後，世界沒有等玩家來拯救。真正的主線是每個地方、每個家戶、每個人都在回答同一個問題：

```text
過去回來了。
哪些應該被保存？
哪些應該被歸還？
哪些可以被改用？
哪些必須被放下？
哪些不能再讓它找到人？
```

這不是哲學口號，而是所有內容的故事來源：

- 保存會長出家戶祖物、唱名者、舊路、街群記錄、死者物與城市信用。
- 歸還會長出拾物人、前主親族、沉物海岸、寄物所、追索者與交易爭議。
- 改用會長出修物行、認手工具、二手交易、學徒、試手門與新舊使用者衝突。
- 放下會長出不留林、淡痕同行人、逃離者、療養者、失蹤案與道德不安。
- 拒絕回來會長出封存禁忌、被避開的路、不能叫的名字、被遠行隊繞過的地方。

玩家不是世界主角，但玩家的每個局部選擇都會落在這五種態度之間。這是奇點的角色扮演根。

### 0.4.3 玩家入場：名字很輕的外地遠行者

第一版玩家身份不必背負救世任務，也不必一開始就有特殊血統。最穩的入場身份是：

```text
一名名字很輕、信用很薄、持物很少的外地遠行者。
```

這個身份符合關鍵字清單的玩家不是上帝、玩家等於 NPC，也讓第一屏自然有事可做：

- 玩家有姓名，但在本地還沒有被承認；姓名不是裝飾，而是入城、借物、問路、作保、交易的入口。
- 玩家有身體與手；能碰、拿、放、問、跟、等、避、藏、修、歸還。
- 玩家有少量錢與持物；金錢可見，但世界不只用錢承認玩家。
- 玩家下線後角色仍在世界裡；外地遠行者最容易被遠行隊、寄物、等人、借宿、守物這些輕操作任務接住。
- 玩家不認識本地規矩，所以每一次接觸都能自然教會世界，而不是用教學視窗灌設定。

玩家成長不是升成救世主，而是從「沒人認得的外地人」變成「某些人、物、路、街群、門派開始認得的人」。這種認得可以是信任、誤認、警戒、感謝、仇怨或責任。

### 0.4.4 第一輪世界閱讀順序

玩家不需要開局讀完整世界史。奇點地球應該按可玩閱讀順序展開：

1. 自己：我叫什麼，身上有什麼，手裡拿著什麼，我在本地算誰。
2. 眼前：這裡是哪裡，誰在場，什麼物能碰，哪條路能走，哪件事可能被我錯過。
3. 物：這件東西從哪裡來，前主是誰，能不能用、賣、藏、還、修。
4. 人：這個 NPC 為什麼在這，不和我說話時他也在做什麼。
5. 路：我走過後，路和我會不會互相留下熟悉、危險、失約或追蹤。
6. 街群/家戶：誰願意替我作保，誰不承認我，誰記住我上一件事。
7. 大區/國家/聯盟：我的局部行動如何被遠行隊、寄物所、拾物行、唱名者或追索者帶到別處。
8. 世界史：玩家先碰到當代狀態，再從舊物、舊名、舊路與 NPC 口中讀出大回潮。

這個順序直接對應 UI 與內容驗收：第一屏先讓玩家讀到自己、眼前、物、人、路；世界史只透過現在狀態滲出，不用開局說教。

### 0.4.5 大區的故事功能

每個大區不是地圖分類，而是世界主題的一種答案。

| 大區 | 故事功能 | 玩家第一個想碰的問題 |
|---|---|---|
| `長風群城` | 高密生活如何讓名字、信用、工具與外地身份互相擠壓 | 我如何在一座太多人、太多稱呼的城市中被正確認出 |
| `沉物海岸` | 物件被世界送回時，誰有資格拿走、定價、歸還或改用 | 我撿到一件回來的東西，該賣、用、還、藏，還是丟回去 |
| `不留林` | 不是所有過去都該被保存，放下本身也是危險選擇 | 我該幫一個人消失，還是幫另一個人把他找回來 |
| `回潮原` | 歷史不是年表，而是會短暫壓回現在的路、聲音與戰鬥 | 我敢不敢跟上一條本來不該出現的舊路 |
| `明雨帶` | 身體、食物、照看與傷病如何讓地方進入人 | 我吃下、治療或照看某人，會把哪個地方帶進身體 |
| `白脊高地` | 工具、重量、手感與路感如何把技藝變成長期責任 | 這件工具為什麼不認我的手，我要如何讓它承認或放棄 |
| `深潮群島` | 遠行、寄物、失船與潮霧如何讓物與人錯過又回來 | 我帶出去或寄放的東西，是否真的會到對的人手上 |
| `暖生南域` | 沃土風的極端：生機過盛如何帶來食物、腐變、病傷與保護衝突 | 我能不能取用旺盛生命，而不把一地的危險帶到另一地 |

若某個大區只能產出材料、怪物、商店或景色，它就還沒成立。合格大區必須能讓玩家問出一個想操作的問題。

### 0.4.6 第一季故事骨架

第一季不是單一路線，也不是劇情主線。它是玩家從局部生活讀懂世界的第一組門。

```text
外地遠行者入場
-> 在長風群城邊緣處理自己的稱呼與第一件持物
-> 撞見沉物海岸送回的一件麻煩物
-> 被迫在歸還、改用、藏匿、作保之間選擇
-> 選擇牽動一名修物人、一名拾物人、一名唱名者或一名追索者
-> 玩家發現路、名字、物與人會把事情帶到別處
-> 玩家第一次回訪時，看見自己不是看過故事，而是改過局部世界
```

這條骨架可同時支撐探索、冒險、經營、模擬、建造、戰鬥與人際，但每一段都要先落在一個可點動詞上。

第一季最低可玩切片不需要做完整世界，只需要做到：

- 一個外地身份入口。
- 一件帶來處的物。
- 一名不等玩家才存在的 NPC。
- 一條會因玩家攜物或失約而改變的路。
- 一個保存/歸還/改用/放下之間的選擇。
- 一次回訪能讀到後果。

### 0.4.7 世界大綱不可再犯的錯

後續任何人續寫奇點地球，先用以下錯誤檢查：

- 如果故事變成誰控制能量，就是錯。
- 如果內容靠制度名、材料名、勢力名堆疊，而玩家不知道要碰什麼，就是錯。
- 如果每個地方都像村、渡口、倉、攤、路牌、酒館那種低生活密度語感，就是錯。
- 如果 NPC 只是在等玩家對話，就是錯。
- 如果物件只是商品或任務道具，就是錯。
- 如果歷史只在年表裡，不改變今日地名、路況、價格、工具、稱呼、NPC 行程與回訪，就是錯。
- 如果玩家做的事現實也能做，且世界沒有承認差異，就是錯。

## 1. 一句話世界

奇點世界是一顆能量充沛的平行地球。

能量不是某種藏在礦石、機關或少數人手上的東西。它像空氣一樣在世界裡：水中有，土中有，風中有，光中有，聲音中有，血肉中有，食物中有，工具中有，房屋中有，道路中有，名字與誓言中也有。

人活著不是取得能量，而是在每一次呼吸、觸碰、使用、稱呼、同行、衝突、照看、告別和死亡中，與世界交換。交換會留下痕跡；痕跡會形成關係、地名、物價、技藝、信任、傳聞、禁忌、仇怨、繼承與冒險。

玩家進入的不是「找魔法資源」的世界，而是「每個人、物、地方和名字都可能有來處，且玩家碰到它們後，世界會留下可被後來讀到的差異」的世界。

## 2. 世界根律

### 2.1 萬物含能

能量是存在條件，不是商品，也不是特殊職業的燃料。

空氣含能，所以呼吸會把地方帶進身體，也會把自己留在地方。水含能，所以河海會沖淡、送回、包裹或改變物件的來處。土含能，所以道路不是畫在地面的線，而是長期腳步、停留、逃亡、搬運與死亡壓出的狀態。聲音含能，所以稱呼、歌、哭聲、謊言與誓言不一定在消散後就完全結束。物件含能，所以工具會因前主、用途、修補、失手、借出與歸還而變得不同。

玩家層結果：畫面上的可見物不該只是名詞。重要的人、物、路、房屋、地面、衣物、工具，都應該能追問「誰碰過、如何被用過、現在因此有什麼不同」。

### 2.2 生命是交換

生命不是封閉容器。活著就是和世界交換。

吃下食物，地方性進入身體。走過一段路，路承受腳步，人也帶走路的感覺。拿起工具，手改變工具，工具也改變手。與人同行，雙方的路變成一段共同過去。傷害別人，傷口留在身體，事件也留在旁觀者、物件與地方中。死亡不是把人從世界刪掉，而是把最後的交換交回土地、水、物件、親人與名字。

玩家層結果：奇點的動詞不能只做成「點擊 -> 得到結果」。合格動詞應該是「接觸 -> 交換 -> 變化 -> 後來能被讀到」。

### 2.3 觸碰留痕

世界會記住，但不是每段過去都變成任務，也不是每個物件都開口說話。

痕跡可以很小：

- 一把刀更順某人的手，也更不願在陌生人手裡做危險動作。
- 一件外衣在靠近某地時變冷，因為前主曾在那裡失去什麼。
- 一段路讓熟人走得穩，卻讓帶著某件舊物的人偏離。
- 一間屋子願意留住熟客的燈，卻讓陌生人整夜難眠。
- 一個名字被太多人借用後，真正的那個人反而難被叫住。

玩家層結果：玩家可以讀、利用、修正、加深、轉交、藏起、歸還或放走痕跡。這是奇點的奇幻可玩性，不是純散文氛圍。

### 2.4 世界會回應，但不演戲

奇點不是為玩家表演的大舞台。

玩家不在時，NPC 仍在移動、借物、修物、等待、躲避、交易、照看、失約、受傷、死亡或改變主意。玩家回來時不需要看見全世界動作，只需要撞見局部結果。

玩家層結果：活世界不是「到處都有演出」，而是玩家遇到的人、物、地有因有果。某個 NPC 不在原地，是因為另一件事先發生；某件物不見了，是被人拿走或自己回到某處；某條路今天好走，是因為清晨已有人壓過泥痕。

### 2.5 人不是例外

玩家、NPC、人形居民、動物、植物、物件和土地都在同一套世界規則裡。人類比較擅長把交換變成語言、工具、禮節、技藝、交易、家、城市、門派、國家與故事，但人不是世界的主人。

玩家層結果：玩家不是上帝，也不是唯一主角。玩家能做 NPC 能做的事，也會承受 NPC 會承受的後果。好玩來自玩家在同規則世界中留下自己的痕跡。

## 3. 世界主題

奇點地球的故事不是「能量很強，所以人變強」。

它的故事是：

```text
世界太容易交換，也太容易記住。
文明越繁盛，留下的痕跡越多。
人類越想生活得自由，越要學會面對自己和前人留下的東西。
```

這讓當代奇點有五組核心矛盾。

| 矛盾 | 故事問題 | 玩家可玩入口 |
|---|---|---|
| 留下 / 放下 | 哪些痕跡該保存，哪些該讓它變輕 | 保存舊物、放走線索、讓某人被記得或不再被追 |
| 繼承 / 切斷 | 前人的工具、名字、技藝與債是否該由後人承擔 | 接手、拒收、改用、歸還、重命名、斷開牽連 |
| 親近 / 避開 | 人與物、地、名字越親近，越容易互相改變 | 借物、同住、同行、結盟、避嫌、遠走 |
| 取用 / 歸還 | 一件物能不能成為自己的，取決於它的來處與後果 | 拾取、交易、追索、藏匿、修補、送回 |
| 遠行 / 牽連 | 走向遠方能重開生活，也會帶走別人的舊事 | 問路、帶物、帶信、被誤認、回訪、失約 |

## 4. 世界史大綱

### 4.1 成星期：萬物一起成形

奇點地球形成時，能量不是後來覆上世界表面的魔法。它和海、岩石、大氣、光、潮汐、風暴、聲響一起成形。

最早的岩層會保存壓力與時間，最早的海會把接觸過的東西帶走又送回，最早的風會讓聲音與氣味走得比人更遠。這不是神話裝飾，而是後來地理、材料、生命與文明的根。

現在結果：

- 某些石材貴，不是因為稀少，而是因為它承受過久遠壓力。
- 海岸容易出現失物、舊物與前主故事。
- 多風之地容易形成重視稱呼、歌、傳聞與遠行消息的文化。

### 4.2 萬生期：生命學會保住自己

能量過於豐盛並不安全。早期生命最大的難題不是缺少力量，而是在過度交換中保持形狀。

有的生命靠殼，有的靠群聚，有的靠模仿周圍，有的靠快速更換外形，有的靠把外界痕跡吸進身體再慢慢排出。這讓奇點的自然不是空曠背景，而是濃密、豐饒、互相牽連，也更危險。

現在結果：

- 森林不是木材區，而是大量生命彼此讀取、遮蔽與互相改變的地方。
- 草原不是空地，而是腳步、遷徙、追獵、埋骨與風聲交疊的地方。
- 礁岸、濕地、雲霧林不是稀有採集點，而是交換過密、難以判讀的冒險區。

### 4.3 呼名期：人類把世界叫住

人類出現後，真正改變世界的不是第一把武器，而是語言、名字、工具和葬禮。

給人取名，是讓一個生命在變化中被認出。給地方取名，是承認這裡發生過事。給工具取名，是承認它不只是材料。把死者記住，是承認死亡後仍會影響活人。

名字不是舊特殊系統，也不是可被抽走的資源。名字在奇點的功能是角色扮演與社會重量：別人如何稱呼你，物件被誰叫慣，地方俗名如何形成，會改變玩家在世界中的位置。

現在結果：

- 稱呼可以帶來信任、誤認、排斥、保護或危險。
- 地名不能只表示方向，必須承載地方如何被人記住。
- 玩家自己的名字應該成為玩家入口，而不是裝飾字串。

### 4.4 共居期：家、路、技藝與城市

早期聚居不是從權力開始，而是從能一起生活開始。

一群人能共享食物、火光、傷病照看、孩子的名字、死者的物、遠行者的歸期、危險路段的經驗，才逐漸形成家戶、師徒、門派、行隊、城鎮、國家與聯盟。

城市不是牆與建築的集合，而是高密度痕跡的整理方式。城市越繁華，越需要讓陌生人、舊物、名字、交易、疾病、技藝、演出與遠行消息不互相淹沒。

現在結果：

- 家戶要有物件、稱呼、死者、照看與日常的重量。
- 門派是身體、工具、世界與他人的方法，不是技能清單。
- 城市可以高密度、明亮、繁忙、有學舍、醫者、演出、遠行集散與跨地交易，但不複製現實現代科技，也不退回粗糙復古。

### 4.5 大回潮：過去壓回現在

`大回潮` 是目前世界史的第一個大斷點。

它不是單一災難，也不是某個裝置失效。它是文明長期建城、交易、遷徙、戰鬥、埋葬、誓言、愛、失物、欺瞞與未完之事累積後，整片世界把太多過去一口氣推回現在。

大回潮時：

- 本來消失的舊路短暫重新出現。
- 海潮送回大量不該再回來的物件。
- 大城中同一個稱呼引來太多人回應。
- 某些房屋拒絕新住客，因為上一段生活尚未結束。
- 某些工具不肯被新手使用，除非前主之事被處理。
- 某些人身上帶著不屬於自己的腳步、夢、傷口或稱呼。

大回潮沒有讓文明倒退。相反，人類被迫成熟：普通人都知道過去不是背景，它會成為今日的價格、路況、關係、醫療、交易、衝突與選擇。

### 4.6 回潮後當代：成熟而不安全的世界

玩家進入的是大回潮之後的成熟奇點。

這個世界有高密城市、長途旅行、跨地交易、學習體系、醫療、娛樂、公共記錄、家族產業、門派傳承、社群規矩、遠行隊、地方傳聞與大量普通人的日常。它不是等待英雄拯救的廢墟，也不是人煙稀薄的早期社會。

當代人沒有同意一套答案。不同地方與群體用不同方式處理「世界會記住太多」這件事：

| 態度 | 他們相信 | 會形成的內容 |
|---|---|---|
| 保存 | 重要的物、名、屋、路與死者不該被放掉 | 舊物保管、唱名、家戶祖物、長期記路 |
| 淡化 | 不是所有痛苦、錯誤與仇恨都該由後人承擔 | 不留林、送痕儀式、改稱呼、遠離舊地 |
| 歸還 | 物應回其主，名應回其人，路應回其來處 | 拾物行、失物追索、前主親族、歸還交易 |
| 改用 | 舊物也能有新人生，只要新使用者承擔後果 | 修物行、借物、二次交易、工具熟悉 |
| 遠行 | 一地太重時，人可以帶著名字與持物離開 | 遠行隊、路物、寄放、帶信、外地街 |

這些不是派系表，而是後續地圖、NPC、物件、事件和玩法的生成根。

## 5. 當代生活

### 5.1 住

家不是室內副本，而是一組長期互相承認的人、物與地方。

一個家庭會在意門前誰常站、桌子誰常用、外衣誰穿過、死者物是否仍留著、孩子第一次被叫名字在哪裡、遠行者回來時屋子是否還認得他。

玩家可見：

- 同一件家具對家人、客人、陌生人顯示不同文字。
- 玩家借住或被拒住，會留下之後 NPC 可讀的差異。
- 拿走不屬於自己的物，不只改變背包，也改變家戶對玩家的看法。

### 5.2 行

路是被走出來的歷史，不是座標連線。

人們問路時，不只問方向，也問最近誰走過、帶了什麼、哪裡停留、哪段路今天不認陌生腳步、哪段路被雨水或舊事翻開。

玩家可見：

- 路況描述包含近期腳步、危險、舊痕與 NPC 行程。
- NPC 會先走、改路、等人、迷路或故意繞開某段路。
- 玩家多次走同一路線，路與玩家之間能形成可讀熟悉度。

### 5.3 食與醫

食物不是補條，而是地方進入身體的方式。

普通人會在意食物從哪裡來、誰處理過、是否帶著不適合自己的地方性。醫者看傷口，也看傷口承受過什麼、患者身上是否帶著不屬於自己的舊痕、身體是否仍願意留住自己。

玩家可見：

- 食物影響短期描述、NPC 評價、交易信任與特殊地點通行，而不是通用生活條。
- 治療牽涉工具、照看者、地點、舊傷與物件來歷。
- 戰鬥後果不只扣數值，還會留下誰傷的、在哪裡傷的、用什麼傷的故事事實。

### 5.4 工具與工作

工具是長期關係，不是裝備欄加成。

一把刀、一盞燈、一件外衣、一個箱子、一支筆，都可能因長期使用變得順手，也可能因被粗暴對待而排斥某個人。工作不是職業綁定，而是人、工具、地方、技藝和他人承認一起形成。

玩家可見：

- 工具有前主、使用史、損傷、熟悉度、借用關係與拒手狀態。
- NPC 會保護自己的工具，玩家也能借、買、修、歸還、藏匿或弄壞。
- 工具熟練度表現為新動詞、新判讀、新失敗避免，而不是只加數值。

### 5.5 交易

價格不是只由稀少程度決定，也由來處、前主、可信度、歸還可能、地方傳聞與使用意願決定。

一件從海岸回來的外衣可以很便宜，因為沒人敢穿；也可以很貴，因為有人願意付錢找回它。交易不是玩家對商店面板，而是物、錢、人、故事和風險的交換。

玩家可見：

- 商品描述要回答「它從哪來、誰碰過、為何賣、賣了會怎樣」。
- NPC 可能已和別人談成、拒賣、保留、改價或追索。
- 玩家能透過辨認、修補、歸還、隱瞞或出面說明改變價格與關係。

### 5.6 學習、娛樂與信仰

奇點的學習不是背設定。小孩學會如何碰陌生物、如何稱呼他人、如何看路、如何分辨屋子是否願意留人、如何把不該久留的痕跡送走。

娛樂也不只是節日。人們會聽遠行故事、看技藝演出、賭物件是否認手、聽唱名、玩認物遊戲、交換舊物傳聞，或在特定日子把某些不該留在身邊的事交出去。

信仰此時不必先定成神系。最重要的是：人們相信世界會記住，所以活人需要學會和被記住的事共處。

玩家可見：

- 節慶能產生交易、失物、冒名、歸還、比試、演出和衝突。
- 傳說不是背景文本，而是判斷地點、物件或 NPC 的工具。
- 玩家能被邀請、被排除、被誤認、被要求說明自己與某件事的關係。

## 6. 具名世界骨架

以下名稱是 v1 世界大綱用的正典草案。後續可以打磨命名，但不得回到局部場景詞或粗糙復古詞。

### 6.1 長風群城

長年有風穿過的高地與平原城市帶。這裡人口密集、消息快、稱呼多、遠行隊多、演出多、修物與唱名技藝成熟。

世界功能：

- 展示當代奇點的高密生活，而非粗糙復古。
- 讓名字、稱呼、信用、工具前史與 NPC 關係成為城市玩法。
- 作為第一個「普通人也活在奇幻規則裡」的城市樣本。

玩家想做：

- 處理自己的稱呼與外地身份。
- 學會如何在大城中被認出，而不是被人潮沖淡。
- 借物、修物、買賣舊物、聽遠行消息、追問同名事件。

### 6.2 回潮原

大回潮後仍會短暫推回舊路、舊聲、舊腳步與舊戰鬥的廣原。

世界功能：

- 把歷史變成現在狀態，而不是背景年表。
- 讓探索、救援、追索、戰鬥前兆、遠行風險自然成立。

玩家想做：

- 跟上一段短暫出現的路。
- 找回某件被舊事帶走的物。
- 幫 NPC 從不屬於他的腳步裡脫身，或利用那段腳步找到祕密。

### 6.3 沉物海岸

海潮會把帶有強烈前主痕跡的物件送回岸上。回來的不一定是寶物，也可能是罪證、祝福、遺物、錯放的貨、不能再碰的工具。

世界功能：

- 讓物件天然帶故事。
- 讓交易、歸還、追索、藏匿與衝突連在一起。

玩家想做：

- 拾到一件物後判斷賣、用、還、藏或丟回海裡。
- 在買主、前主親族、拾物人與追索者之間選邊或調停。
- 利用一件回來的物找到本不該被打開的路。

### 6.4 不留林

一片不太願意替人保存痕跡的廣大林地。不是完全消失，而是讓追蹤、稱呼、舊物牽引與人際認知都變淡。

世界功能：

- 讓「放下」變成可玩的奇幻行動。
- 讓追蹤、逃亡、救援、保密、失蹤與道德選擇自然成立。

玩家想做：

- 幫人消失，或阻止某人被抹得太乾淨。
- 在追索者與逃離者之間選擇。
- 把某段太重的舊事放走，承受代價。

### 6.5 同名街群

城市中多處存在的街區現象：人、店、工具或事件共享相同俗名。名字太密時，世界會出現混淆。

世界功能：

- 讓角色扮演、身份、信用、詐欺、保護、誤認與人際關係變得可玩。
- 讓「姓名」成為玩家自己入口的一部分。

玩家想做：

- 叫出某個名字，看誰回頭。
- 查清同名物件的真正來處。
- 保護某個人不被錯誤稱呼牽走。

### 6.6 明雨帶

長年雨光交錯、作物與藥材生長旺盛的濕潤地帶。這裡的人熟悉食物、醫療、照看與身體痕跡。

世界功能：

- 讓食物與醫療從世界根長出，而非數值條。
- 讓照看、療養、採藥、病傷、地方性與身體記憶成為玩法。

玩家想做：

- 找能處理舊傷的醫者。
- 判斷食物來處是否適合自己或 NPC。
- 在照看與交易之間處理稀有藥材和病人關係。

### 6.7 外環遠路

連接群城、海岸、林地、平原與遠方的長途路系。它不是一條路，而是由腳步、車痕、傳聞、寄放物、路宿、遠行隊與失約組成的世界骨架。

世界功能：

- 讓世界大而不空。
- 讓異步 NPC、離線安排、消息延遲、物件移動、交易與冒險連成一體。

玩家想做：

- 帶物、帶信、跟隊、改道、等人、追人。
- 在重訪時看到自己之前留下的路痕或被 NPC 改變的路況。

### 6.8 大地理第一輪：世界不是一張村鎮擴大圖

奇點地球的地理不能從單一出生地、渡口、小市、材料點或路線節點放大。大地理必須先回答：這片土地長期承受了什麼交換，為什麼普通人會在此生活，為什麼玩家會想進入，為什麼 NPC 會在此有自己的事。

第一輪大地理先定八個骨架區。它們不是完整地圖，也不是行政疆界；它們是後續 M0/M1/M2/M3/M4、材料、職業、NPC、勢力與衝突的生成母題。

| 大地理 | 形成原因 | 現在狀態 | 玩家可進入理由 |
|---|---|---|---|
| `長風群城` | 風與聲音長期穿過高地，人們較早發展稱呼、消息、演出、遠行與修物文化 | 高密城市群；街區多名、多行隊、多修物行、多唱名者；外地人容易被沖淡或誤認 | 取得城市身份、處理姓名、找工作、借物修物、進入多 NPC 關係網 |
| `回潮原` | 大回潮把大量舊路、舊戰鬥、舊遷徙與失物推回廣原 | 舊路會短暫出現；遠行隊、追索者、失物親族、冒險者頻繁出入 | 探索短暫路、救人、找物、追索、避開舊戰鬥重現 |
| `沉物海岸` | 海最早學會交換，會把帶強烈前主痕跡的物件送回 | 拾物、辨認、歸還、轉賣、藏匿與前主衝突密集 | 拾到麻煩物、交易高風險物、查前主、引出海送路線 |
| `不留林` | 林地生命過密，容易把腳步、稱呼與舊物牽引變淡 | 逃離者、淡痕同行人、追索者、失物者共存；道德衝突高 | 幫人放下、追人、遮路、留下記號、承擔被淡化的代價 |
| `明雨帶` | 雨、水光、作物與身體交換穩定，醫療與食物文化成熟 | 食物、藥材、病傷照看、療養、身體地方性與照看信用發達 | 治傷、處理舊傷、辨食、照看 NPC、經營藥物與食物交易 |
| `白脊高地` | 古老岩層保存壓力、火光與長期風聲 | 石材、工具芯、記路石、耐久器具與高地門派集中 | 取得或修補耐久工具、學判讀石痕、通過高地試路 |
| `深潮群島` | 海霧、潮汐與島路反覆改寫船路與物件來處 | 島與島之間路線不穩；漁人、寄物人、失船親族、遠海商隊彼此依存 | 跟船、寄物、找失船、處理潮霧中的錯路與回來物 |
| `暖生南域` | 生機過盛，植物、獸群、菌網與居住地彼此交換極快 | 豐饒但危險；食物多、病傷多、物件腐變快，建造與保存困難 | 探索高風險沃土、取得活性材料、保護聚落、處理生態衝突 |

大地理驗收：

- 每個大區都必須能產生普通人的日常，而不是只產生副本或資源。
- 每個大區都必須能產生 NPC 自行行動，而不是只等玩家到場。
- 每個大區都必須能產生至少一種玩家現實不能做的動詞。
- 每個大區都必須能留下一種回訪差異。

### 6.9 大地理到地圖尺度的轉換

後續地圖生成不得從「北岸」「渡口」「小市」這種局部詞開始。命名與尺度應照以下順序落下：

```text
大地理
-> 長期交換類型
-> 歷史事件或地方習慣
-> 生活密度
-> 主要通行方式
-> 常見物件與 NPC 行動
-> 玩家第一眼可讀狀態
-> M1/M2/M3/M4 名稱
```

例：

- `沉物海岸` 可以長出 M2 `回箱帶`，再長出 M3 `留主牆前`，因為那裡有海送物、辨認、暫留、認領與交易壓力。
- `同名街群` 可以長出 M2 `重名街口`，再長出 M3 `三回頭牌下`，因為那裡有稱呼過密、街戶規矩、唱名與誤認壓力。
- `明雨帶` 不能直接長出「草藥採集點」；它應先長出療養街、濕食市場、照看院、雨光田、病後路、食物辨認與醫者行程。
- `白脊高地` 不能直接長出「礦點」；它應先長出壓痕石路、高地試手所、修石門派、長風過脊路與工具耐久文化。

### 6.10 當代制度第一輪：制度是生活方法，不是管理核心

奇點當代有制度，但制度不是世界根。制度只在它解決普通人如何生活時成立。

| 制度 | 來源 | 誰受益 | 誰被排除或受壓 | 玩家如何碰到 |
|---|---|---|---|---|
| `觸物禮` | 大回潮後陌生物造成太多傷害與誤認 | 家戶、修物人、交易者、遠行者 | 急著取用的人、偷物者、外地不懂規矩者 | 玩家碰陌生物前可先問、試手、請人作保；亂碰會被記住 |
| `問路禮` | 路會因近期腳步、舊事與攜物變化 | 遠行隊、城市旅人、送信者 | 不願交代來處或攜物的人 | 玩家問路時需說自己帶什麼、找誰、何時回；說謊會影響路與人 |
| `借物押名` | 物件長期使用後不願隨便換手 | 工具持有者、修物人、學徒 | 無名外地人、信用薄的人 | 玩家借物要押稱呼、錢、物或他人作保；借物後回訪可見評價 |
| `回名日` | 同名、舊名、遠行名容易牽錯人 | 唱名者、家戶、新生兒、遠行者 | 冒名者、欠舊債者、想被忘記的人 | 玩家可處理自己的稱呼，也可能被要求說明前次叫名後果 |
| `留路冊` | 長路需要記錄誰走過、何時回、帶了什麼 | 遠行隊、失物親族、城門附近居民 | 想隱行的人、帶麻煩物的人 | 玩家可登路、查路、改路、被追索；下線安排可接到這裡 |
| `淡痕約` | 不是所有痕跡都該永遠保存 | 逃離者、療養者、想切斷舊事的人 | 追索者、親族、債權人、受害者 | 玩家可替人放下或阻止放下；結果影響追蹤、信任與衝突 |

制度設計紅線：

- 不得把制度寫成世界魅力本身。
- 不得把普通人寫成被制度管理的資料列。
- 制度必須讓玩家看見人、物、路、錢、名、關係如何改變。
- 制度必須允許違反、鑽縫、誤解、失敗與地方差異。

### 6.11 當代文明史細部：大回潮後的四個時期

大回潮不是一句背景。它必須解釋今日土地、路、價、職業、NPC 行程與玩家可做事。

| 時期 | 內容 | 現在留下什麼 |
|---|---|---|
| `回潮初年` | 舊路、舊名、舊物大量回到生活面，城市和家戶先求不亂 | 觸物禮、回名日、拾物行、守屋人、失物親族冊開始形成 |
| `長路再開` | 各地發現不能只封住舊事，必須重新遠行、送物、查人、互通消息 | 遠行隊、留路冊、寄物所、路宿規矩、跨地信用與失約懲罰 |
| `群城協議` | 高密城市承認同名、舊物、修物、醫療與遠行都需要跨街區規矩 | 長風群城的唱名所、修物行、城市共同體、街戶作保制度 |
| `淡留之爭` | 保存者與淡化者公開衝突：哪些過去該記住，哪些該讓人放下 | 不留林周邊追索與逃離衝突、淡痕約、追索者聲望分裂 |

這四個時期可直接推導玩家可見內容：

- 價格：回潮初年留下的物件仍有高風險價差。
- 路況：長路再開後的路有登記、失約、改道與寄物痕跡。
- NPC 行程：唱名者、修物人、遠行隊、追索者都有固定理由外出。
- 衝突：淡留之爭讓玩家在保存與放下之間選邊，不是單純善惡。

### 6.12 國家、聯盟與門派的第一輪正典位置

`DESIGN_KEYWORDS.md` 有國家、聯盟、門派、氏族、種族。它們不能只是勢力表，也不能套中古王國模板。第一輪先定它們在世界中的功能。

| 層級 | 第一輪定義 | 具名草案 | 玩家碰到什麼 |
|---|---|---|---|
| 家戶 | 照看人、物、死者、名字、工具與回家路的最小共同體 | `青梁家`、`霧井家`、`三盞戶` | 借住、送還物、被拒門、拿錯家物、處理死者物 |
| 街群 | 高密城市中共同處理名字、交易、照看、路口與舊物的生活區 | `三回頭街群`、`東階修物街`、`雨後食街` | 作保、交易、叫名、看牌、被街戶記住 |
| 城市 | 整理高密痕跡的生活機器，不是功能建築集合 | `長風群城` 中的 `聽風城`、`折路城`、`明臺城` | 學習、交易、遠行集散、處理身份與信用 |
| 國家 | 維持大區尺度的路、記錄、衝突調停與跨城承認 | `長風同盟國`、`明雨照看國` | 通行承認、跨城案件、徵召救援、城市間信用 |
| 聯盟 | 多國或多城為處理回潮、長路、遠海、荒野而形成的協作網 | `外環遠行聯盟`、`沉物歸還聯盟` | 跟隊、寄物、查失物、承接跨地任務 |
| 門派 | 身體、工具、世界與他人的方法傳承 | `聽風唱名所`、`東階修物行`、`淡痕同行人`、`白脊試手門` | 學動詞、學判讀、被要求遵守門派態度 |
| 氏族 | 長期地方交換造成的家族/群體記憶與生活方法 | `回潮原守路氏`、`深潮寄物氏` | 被請託、被防備、學地方規矩、接觸舊怨 |
| 種族/人形族群 | 暫不套精靈矮人模板；先定為長期與地方交換形成的體質/文化差異 | `長息人`、`明雨人`、`潮岸人`、`林淡人` | 外貌、稱呼、食物適性、路感、工具習慣與社會偏見 |

後續若新增非人類人形種族，必須先回答：它們如何從奇點生命根演化，與人類共享哪些規則，玩家如何在同規則下接觸，而不是只加外型與天賦。

### 6.13 玩家時代的主要矛盾

玩家登入時，世界不是等待開始；它已經處在多組矛盾中。

| 矛盾 | 具體現場 | 玩家可做什麼 |
|---|---|---|
| 保存者 vs 淡化者 | 不留林外，追索者要求找回人，淡痕同行人認為對方有權離開 | 幫追、遮路、調停、作假、放走、承擔關係後果 |
| 歸還者 vs 改用者 | 沉物海岸與修物街，前主親族要求歸還，買主主張新使用也能成立 | 作保、估價、歸還、修補、賣出、藏起、跟蹤 |
| 城市承認 vs 外地身份 | 長風群城中外地名太輕，玩家容易被當成無信用路人 | 處理稱呼、找人作保、做小事累積信用、避開錯名 |
| 長路自由 vs 留路責任 | 遠行者想改道，但寄物、帶信、同行 NPC 會被影響 | 改路、等人、失約、補償、通知、下線安排 |
| 沃土繁盛 vs 生態壓力 | 暖生南域與明雨帶生機過盛，食物、藥物、病傷、建造互相牽動 | 採取、保護、治療、轉運、建造、避免把一地帶進另一地 |

這些矛盾是世界的長期遊戲壓力。它們不是任務線，而是 NPC、物件、價格、路況、地名和回訪差異的來源。

## 7. 主要文化與人物原型

### 7.1 家戶

家戶是最小但最強的生活共同體。它照看居住痕跡、死者物、孩子名字、日常工具、照看方式與回家路。

玩家接觸：借住、被接納、被排斥、拿錯東西、替人送還舊物、處理家中不願離開的痕跡。

### 7.2 門派

門派不是技能商店。門派是一群人對身體、工具、世界與他人的長期方法。

有的門派重呼吸與聲音，有的重修物，有的重遠行，有的重傷後復原，有的重讓痕跡變輕，有的重把舊物送回正確地方。

玩家接觸：學新判讀、新動詞、新失敗避免，也承擔門派對物、名、人與路的態度。

### 7.3 遠行隊

遠行隊把地方、物件、消息、稱呼、失物與請託帶過長路，也把風險帶進城市。

玩家接觸：問路、同行、帶物、被誤認、被搶先、錯過出發、回訪後發現隊伍已改變局勢。

### 7.4 修物人

修物人修的不只是物，也修物與人、地方、前主之間的關係。

玩家接觸：請修、被拒修、辨認前主、換材料、學試手、承擔物件被粗用後的後果。

### 7.5 拾物人

拾物人處理被海、路、戰鬥、逃亡或死亡送回世界表面的東西。

玩家接觸：拾取、估價、歸還、藏匿、查主人、被買主盯上、被前主親友找上。

### 7.6 唱名者

唱名者處理新生、遠行、死者、門派工具、街區俗名與同名混淆。他們不神秘化自己，但知道名字太輕會讓人被世界沖淡，名字太重會把人拖回舊事。

玩家接觸：處理自己的稱呼、找人、保密、改稱呼、確認物件舊名、處理同名街事件。

### 7.7 追索者

追索者尋找失蹤的人、變淡的痕跡、未歸還的物與未完之事。他們不是單純偵探；他們和「放下」這件事天然衝突。

玩家接觸：協助追蹤、幫人逃離、說謊、調停、戰鬥前置、讓某件事被保存或被放走。

### 7.8 具名國家與城市共同體

國家不是地圖塗色。國家在奇點的功能是讓大區尺度的路、名字、物件、病傷、交易與衝突能被跨地承認。

| 名稱 | 創立理由 | 公開說法 | 內部分裂 | 外部敵手/矛盾 | 玩家接觸 |
|---|---|---|---|---|---|
| `長風同盟國` | 大回潮後，長風群城需要共同處理同名、遠行、修物與跨城信用 | 「風過城，人也要能被認出」 | 城市派重街區自治；遠行派要求外地人也能快速取得信用 | 不留林淡痕者、冒名團、拒絕登路的外環遠行人 | 玩家入城、處理稱呼、借物、作保、被誤認、取得跨城信用 |
| `明雨照看國` | 明雨帶的食物、醫療、病後照看與地方性需要長期協作 | 「吃進身體的，也要知道來處」 | 醫者派重患者；食田派重產地與交易；照看戶重長期關係 | 暖生南域的活性食物交易者、帶病遠行者、隱瞞舊傷的人 | 玩家治傷、買食、照看 NPC、被要求交代傷口與食物來處 |
| `白脊高地諸門` | 白脊高地工具、石材、路感與試手方法由多門派共同維持 | 「手要先問石，路要先問脊」 | 試手派願意教外地人；守脊派反對把高地工具流出 | 長風修物行、外地軍械買手、偷帶高地石芯者 | 玩家試工具、學判讀石痕、被拒賣、護送或追索高地物 |
| `深潮島約` | 深潮群島需要處理失船、寄物、海霧錯路與潮送歸還 | 「船可以遠行，物要有回話的地方」 | 島戶派重親族；商隊派重遠路；寄物派重契約 | 沉物歸還聯盟、海上藏匿者、拒認失船責任的買主 | 玩家跟船、寄物、找失船、處理島間錯路與潮霧回物 |

這些國家/共同體都不是玩家初期必須理解的大背景。它們應先以小場面出現：一張通行承認、一件不能亂碰的工具、一名醫者拒收來路不明食物、一個街區要求玩家說清名字。

### 7.9 具名聯盟與跨地網路

聯盟處理的是單一國家或城市無法獨自解決的長距離問題。

| 名稱 | 處理問題 | 利益來源 | 被人討厭的原因 | 玩家可介入 |
|---|---|---|---|---|
| `外環遠行聯盟` | 遠路、帶信、寄物、改道、失約、下線安排與跨地 NPC 行程 | 路宿費、寄物費、護送分成、信用記錄 | 被認為太愛登記路線，讓想消失的人不舒服 | 加入遠行隊、帶信、失約補救、追車隊、改道承擔後果 |
| `沉物歸還聯盟` | 海送物、前主認領、親族冊、歸還報酬與爭議物暫留 | 認領費、歸還分成、風險估價、保管費 | 被改用派批評為把物件永遠綁回過去 | 辨認失物、競價、替人作保、藏物、揭露假前主 |
| `長風街群聯席` | 同名街、街戶作保、外地身份、城市信用與修物標準 | 作保費、街戶公約、修物行推薦 | 外地人覺得進城太難；街戶覺得外地人太容易逃責 | 取得街群承認、處理錯名、被拒交易、替 NPC 入城作保 |
| `回潮原守路會` | 舊路短暫出現、失蹤救援、危險路段標記、舊戰鬥迴避 | 救援酬金、路物保管、失蹤追索 | 被冒險者嫌保守，被親族嫌太慢 | 跟舊路、救人、收路物、選擇是否公開危險路線 |

聯盟的玩家價值：它們是「世界很大但不空」的證明。玩家在一地做的事，可以透過聯盟路線、物件、消息、信用與 NPC 行程傳到另一地。

### 7.10 具名門派與技藝傳承

門派不是職業，也不是技能商店。門派是把某種「與世界交換的方法」教成可傳承技藝。

| 門派/行 | 方法 | 玩家學到的不是數值，而是 | 代價 |
|---|---|---|---|
| `聽風唱名所` | 用聲音、稱呼與停頓處理人和名字的重量 | 叫名、避名、改稱、辨認誰不再應名 | 必須對被叫回的人負責，不能把叫名當查詢 |
| `東階修物行` | 修物前先判斷物與人、地、前主的關係 | 試手、問物、修補、拒修、判斷工具是否願意換手 | 修錯會讓物更排斥，也會傷害持有人信用 |
| `淡痕同行人` | 幫人讓痕跡變淡，但不保證完全消失 | 遮路、暫放、淡稱、陪人穿過不留林 | 會被追索者記住，且可能讓無辜者找不到人 |
| `白脊試手門` | 以石、手、路與重量訓練工具判讀 | 試重、試路、辨壓痕、判斷工具耐受 | 學徒早期常被工具拒手，失敗會留下可見痕跡 |
| `明雨照身院` | 用食物、雨光、照看與長期身體變化處理傷病 | 辨食、看傷來處、照看、讓舊傷變輕 | 不能把醫療當瞬間恢復，照看需要時間與關係 |

門派下游生成規則：

- 每個門派至少要有一個可點物件、一個教學 NPC、一個失敗成本、一個與其他群體的矛盾。
- 門派技藝必須能被 NPC 同規則使用。
- 玩家學到的應該是新動詞、新判讀或新避險方式，不是抽象加成。

### 7.11 人形族群與地方長期交換

第一輪不套用精靈、矮人、獸人等外部模板。奇點的人形族群先從「長期與某種地方交換」形成。這些差異不是固定職業，也不是戰鬥天賦表；它們是身體習慣、稱呼、食物適性、工具手感、路感與社會偏見。

| 族群 | 長期交換 | 常見誤解 | 玩家接觸 |
|---|---|---|---|
| `長息人` | 長風群城與高地風聲；擅長聽稱呼、辨別聲音停頓與城市消息 | 被外地人以為愛說規矩，其實是怕錯名牽錯人 | 找人、處理稱呼、街區作保、城市信用 |
| `潮岸人` | 沉物海岸與深潮群島；熟悉海送物、寄物、失船與物件回返 | 被認為迷信物件，實際上是知道物會帶回麻煩 | 拾物、寄物、跟船、辨認前主 |
| `林淡人` | 不留林邊緣生活；習慣讓不該久留的事變輕 | 被追索者懷疑幫人逃責 | 遮路、淡稱、藏人、被要求說明誰該被放下 |
| `明雨人` | 明雨帶食物、雨光、照看與病後生活 | 被其他地方認為太在意吃喝來處 | 治療、辨食、照看、病傷交易 |
| `白脊人` | 白脊高地石路、重量、手感與耐久工具 | 被城市人認為固執，其實是不信未試過手的承諾 | 試工具、護送石芯、學高地路感 |
| `暖生人` | 暖生南域過盛生機、活性食物與快速腐變 | 被誤認為危險或不穩定 | 生態衝突、食物保存、活物交易、保護聚落 |

玩家創角或玩家身份暫不需要立即選族群。第一版可先讓玩家作為外地遠行者，在接觸不同族群時讀到偏見、習慣、食物、工具、稱呼與路感差異。

### 7.12 具名舊怨與故事鉤

為避免國家/聯盟/族群變成空名，第一輪先建立幾條可往下長的舊怨。

| 舊怨 | 遠因 | 現在狀態 | 玩家可碰到 |
|---|---|---|---|
| `歸還與改用之爭` | 大回潮後大量物件帶著前主回來，有人主張歸還，有人主張新使用也能成立 | 沉物歸還聯盟與東階修物行常在海岸、街群、修物點衝突 | 玩家買到一件被要求歸還的物，或修物人拒絕替玩家改用 |
| `淡留之爭` | 不留林讓痕跡變淡，追索者認為這會讓受害者永遠找不到答案 | 梁折一類追索者與淡痕同行人互不信任 | 玩家幫某人逃離後，被追索者要求交代 |
| `長路失約案` | 長路再開時，有遠行隊為避開舊戰鬥改道，導致寄物與帶信失敗 | 外環遠行聯盟內部分裂：安全優先派與守約優先派互相指責 | 玩家下線安排、帶信、跟隊與改路都會碰到這個歷史包袱 |
| `明雨拒食案` | 一批來路不明的暖生食物曾造成病後者舊傷復燃 | 明雨照看國對外地食物嚴格，暖生南域商隊不滿 | 玩家賣食物、治傷、護送病人時會被要求證明來處 |
| `白脊失手案` | 高地石芯被外地軍械買手改造成不經試手的武器，造成大量拒手傷 | 白脊高地諸門限制石芯外流，長風修物人想重開交易 | 玩家買工具、修工具、護送高地物時會被捲入 |

這些舊怨不是固定主線。它們是任意 NPC、物件、路線、價格、戰鬥前兆與回訪差異可以借用的世界壓力。

## 8. 代表人物與故事種子

### 8.1 聞秋，修物人

聞秋修物前先問物件，再問持有者。她不相信完全乾淨的新器物，因為沒有使用史的東西太容易撒謊。

玩家接觸：

- 玩家帶來的刀被她拒修，因為它仍在等前一隻手。
- 她能幫玩家判斷拾來物適合賣、用、還是藏。
- 玩家若多次粗暴用物，她會改變報價與態度。

### 8.2 白止，遠行者

白止從回潮原走出，身上多了一段不屬於自己的舊腳步。偶爾他會走向自己沒有打算去的地方。

玩家接觸：

- 跟著他可能找到短暫出現的路，也可能被帶進舊戰鬥殘留。
- 玩家可幫他把某件物送回原地，讓他少受舊腳步牽引。
- 玩家若利用他的狀態牟利，之後路與 NPC 會用不同方式記住玩家。

### 8.3 沈鹿，拾物人

沈鹿在沉物海岸撿東西，但討厭把所有東西都叫貨。他相信物件有前主，不知道前主前，不該急著定價。

玩家接觸：

- 他願意低價賣出麻煩物，卻會要求玩家承擔後果。
- 他可能請玩家把一件東西還給不願露面的主人。
- 他和買主的衝突能生成交易、追蹤與戰鬥前置。

### 8.4 織南，唱名者

織南替新生兒、遠行者、重要工具與死者唱名。她不神秘，但她知道名字叫得太輕會讓人被沖淡。

玩家接觸：

- 玩家可在她這裡處理自己的稱呼與外地身份。
- 她能指出某個 NPC 不再應自己的名字，導出調查。
- 同名街事件可從她的判斷進入。

### 8.5 梁折，追索者

梁折長年在不留林附近找失蹤的人與事。他痛恨世界讓某些痕跡變淡，卻也知道有些人正靠那片林活下去。

玩家接觸：

- 玩家可協助追蹤，也可幫人逃過追蹤。
- 他會記住玩家在保存與放走之間的選擇。
- 他的事件能接到調查、衝突與長期關係。

## 9. 代表物件

### 9.1 舊雨傘

傘面會滴下不是今天的雨。玩家第一次打開它，只得到一句異常文字；之後若找到雨的來處，傘可能帶玩家進入一段舊夜路。

可玩：觸碰、打開、詢問、歸還、在正確地點使用。

### 9.2 認手刀

長期被某人使用的刀。陌生人拿起時不一定不能用，但在危險時可能不順。

可玩：試用、借用、歸還、修補、熟悉、戰鬥前判斷。

### 9.3 不回箱

一只被海送回多次的箱子。每次賣出去都會在某段時間後回到沉物海岸，只是箱內東西不一定相同。

可玩：交易、跟蹤、藏物、誘捕、辨認前主、牽出 NPC 衝突。

### 9.4 走熱石

某段路旁常被人坐下休息的石頭。玩家靠近時能感到殘留體溫；若曾照看某位 NPC，石頭會在之後顯示不同狀態。

可玩：等待、讀痕、休息、追蹤 NPC、回訪差異。

### 9.5 同名帖

一張記著多個相同稱呼的紙帖。它不是身份文件，而是同名街人們用來避免叫錯人的生活物。

可玩：確認、遮名、改稱呼、尋人、冒名、保護某人。

## 10. 玩家身份與可玩核心

玩家暫定為「有名有籍的遠行者」。

這不是特殊職業，也不是天選身份。它只表示玩家是能被世界承認的一個人：有姓名、有身體、有錢、有持物、有基本遠行經驗，也會被地方、NPC、物件和路當成一個普通但可追蹤的行動者。

玩家一開始的優勢不是看穿世界，而是懂得最基本的遠行規矩：

- 不亂碰陌生物。
- 不亂叫陌生名字。
- 知道問路要問最近誰走過。
- 知道工具要先試手。
- 知道物件可以賣，但賣掉不代表故事結束。
- 知道自己離開後，世界仍會往前走。

### 10.1 玩家第一批動詞

| 動詞 | 奇點差異 | 世界狀態改變 |
|---|---|---|
| 觸碰 | 接觸可讀人/物/地的舊痕 | 玩家知道來處、前主、危險或使用可能 |
| 試用 | 工具不是誰拿都一樣 | 工具與玩家的熟悉或排斥改變 |
| 稱呼 | 名字會牽動人與物的回應 | NPC 回應、誤認、沉默或關係改變 |
| 歸還 | 物回到前主或正確地方會改變局勢 | 價格、信用、人際、地點痕跡改變 |
| 留下 | 玩家能讓地方或物件記住自己 | 回訪文字、NPC 反應、物件狀態改變 |
| 放走 | 某些痕跡可被淡化或送離 | 追蹤失敗、風險下降、關係斷開或代價出現 |
| 跟路 | 路不是單純方向 | 顯示前人腳步、危險、捷徑或舊事 |
| 修補 | 修的是物，也修物和人/地的關係 | 工具可用性、前主牽連、交易價值改變 |

### 10.2 玩家為什麼會想玩

玩家想玩，不是因為設定合理，而是因為每次接觸都可能回答一個具體問題：

- 這件物是誰的，為什麼到我手上。
- 這個人為什麼不理我，是否是我身上某物讓他改變態度。
- 這條路為何今天能走，昨天不能。
- 我叫出這個名字，為什麼錯的人回頭。
- 我若把東西賣掉、歸還、藏起或自己使用，誰會受影響。
- 我離線後，角色和 NPC 是否真的會繼續把事情做下去。

## 11. 下游生成規則

### 11.1 地圖

地圖不能先從局部場景詞、材料點或表格生成。每個地點必須先回答：

- 這裡保存了什麼交換。
- 哪些人長期在此生活或通過。
- 大回潮或更早歷史如何讓這裡不同。
- 玩家第一次來能看見什麼可點的人、物、路或異常。
- 玩家重訪時，什麼能因玩家或 NPC 行動改變。

### 11.2 物件與材料

材料不能只列自然名，也不能先做功能分類表。要先問：

- 它來自哪種生命、地點、死亡、使用或長期交換。
- 它被誰採取、誰處理、誰使用、誰害怕。
- 它做成物件後，會如何保存前主、地方或用途痕跡。
- 玩家能觸碰、試用、修補、交易、藏匿或歸還什麼。

### 11.3 NPC 與社會

NPC 不是商人、任務板或對話端點。每個 NPC 至少要回答：

- 他今天為什麼在這裡。
- 他身上帶著什麼物、名字、關係或舊事。
- 玩家不理他時，他接下來會去哪裡或做什麼。
- 玩家接觸後，人、物、錢、路、關係或痕跡如何改變。

### 11.4 戰鬥與風險

戰鬥不是先寫傷害公式。戰鬥是兩個以上生命、工具、地方、情緒和舊痕跡互相衝突。

每場戰鬥或衝突前應有前兆：

- 誰帶著不順手的工具。
- 哪段路讓人緊張。
- 哪個名字被叫錯。
- 哪件物被錯認、爭奪或拒絕歸還。
- 哪個 NPC 已經因玩家或他人行動改變態度。

## 12. 第一條完整內容鏈：沉物海岸的不回箱

本節不是地圖包，也不是 runtime 工單。它是第一條用來測試 v1 是否能自然長出遊戲內容的完整鏈。

合格鏈條必須從世界根開始，一路落到玩家畫面能看見、能點、會改變、能回訪的內容。

```text
世界問題
-> 世界骨架
-> 地點
-> 物件
-> NPC
-> 衝突
-> 玩家動詞
-> 世界狀態改變
-> 回訪差異
```

### 12.1 來源鏈

| 層 | 內容 | 為什麼能從世界長出 |
|---|---|---|
| 世界問題 | 世界太容易交換，也太容易記住 | 物件、海潮、前主、拾物人與玩家都不是空白狀態 |
| 世界史 | 大回潮後，海會把某些不該再回來的物件送回岸上 | 過去不是背景，會成為今日交易、關係與風險 |
| 世界骨架 | `沉物海岸` | 海岸不是採集點，而是前主物、歸還壓力、藏匿與追索自然集中的地方 |
| 地點樣本 | `回箱帶` | 反覆被海送回的箱、袋、衣物和工具會在這一帶被等待、辨認、買走或退回 |
| 場景焦點 | `留主牆前` | 拾物人把尚未判明前主的物件放在牆前，讓人辨認、作保、爭執或沉默離開 |
| 核心物件 | `不回箱` | 一只被賣走多次又回到沉物海岸的箱子；箱內物不固定，但箱身記得每次被誰帶走 |
| 核心 NPC | `沈鹿` | 拾物人；不把所有東西都叫貨，賣出前會先問它是否仍被前主牽著 |
| 牽連 NPC | `何棠`、`江照` | 何棠認為箱屬於失蹤兄長；江照想高價買走箱內可能出現的路物 |
| 衝突 | 物件能否被買走、歸還、暫留或藏起 | 價格、親屬、拾物規矩、玩家信用與箱子的回返狀態互相拉扯 |
| 玩家入口 | 觸碰、詢問、辨認、開箱、作保、買下、歸還、藏起、放回潮線 | 每個動詞都會改變物件狀態、NPC 態度、錢、信用或回訪文字 |

### 12.2 玩家第一次看見什麼

這不是正式畫面文案，只是內容鏈的玩家可見目標。

```text
沉物海岸的回箱帶正在退潮。
留主牆前放著一只窄黑箱，箱角還掛著前一次買主留下的紅線。
沈鹿沒有開價，只把箱子推到乾處。
何棠站得比其他人近，手指一直停在箱蓋裂痕旁。
江照在旁邊等著，錢袋已經解開，卻沒有先碰箱子。

【不回箱】 【沈鹿】 【何棠】 【江照】 【留主牆】 【退潮線】
```

玩家不用知道後端資料，也能讀到：

- 這是一件有前史的物。
- 有不只一個 NPC 在意它。
- 價格不是唯一問題。
- 玩家能碰它，但碰了會被人看見。

### 12.3 核心物件卡：不回箱

| 欄位 | 設計 |
|---|---|
| 類型 | 前主物、歸還物、海送物 |
| 來源 | 沉物海岸反覆送回；每次離岸後都在一段時間內回到回箱帶 |
| 現在狀態 | 箱身乾，縫隙仍潮；箱角有前次買主紅線；箱蓋裂痕被何棠認出 |
| 可見痕跡 | 前主手痕、上一買主紅線、潮線、箱內物短暫變化 |
| 可用動詞 | 觸碰、聽箱、詢問、開箱、暫留、買下、歸還、藏起、放回潮線 |
| 失敗成本 | 被沈鹿拒賣、被何棠防備、被江照盯上、箱子下次回來時更不願被玩家碰 |
| NPC 同規則 | 沈鹿可暫留；何棠可認領但未必成功；江照可買走；其他拾物人可搶先移置 |
| 錢/物/關係變化 | 買下花錢；歸還增信；藏起失信；開箱可能得物也可能引出前主線索 |
| 回訪差異 | 箱可能不在、已被買走、回來但多一條新線、或因玩家曾碰過而顯示不同文字 |

### 12.4 NPC 在場理由

| NPC | 在場理由 | 玩家不理時會怎樣 | 玩家介入後會怎樣 |
|---|---|---|---|
| 沈鹿 | 今日輪到他守留主牆；他等退潮後判定哪些物能賣、哪些要暫留 | 他會先把箱移到乾處，傍晚仍未有人作保就收走 | 玩家可信時，他讓玩家先觸碰或代問；玩家粗暴時，他拒絕交易 |
| 何棠 | 她認出箱蓋裂痕像兄長失蹤前用過的箱 | 她會等到沈鹿收走前才開口，可能錯過 | 玩家可替她作保、問細節、幫她暫留箱或拒絕她的認領 |
| 江照 | 他聽說箱內會在不同回返中出現路物，想買走賭一次 | 玩家不介入時，他可能出高價帶走 | 玩家可競價、說服沈鹿不賣、跟蹤江照或讓他承擔後果 |

這三人不是商人、任務板或對話端點。他們各自有物件關係、時間壓力與下一步行動。

### 12.5 玩家動詞與世界變化

| 玩家動詞 | 可見回饋 | 世界狀態改變 | 好玩在哪 |
|---|---|---|---|
| 觸碰不回箱 | 箱身短暫變冷，紅線貼住玩家指節 | 箱記下玩家；沈鹿與何棠都看見玩家碰過 | 玩家能用身體接觸讀物件前史 |
| 詢問沈鹿 | 沈鹿說出上一個買主和回來時間 | 玩家得到可追蹤線索；江照知道玩家在查 | 對話不是閒聊，而是改變情報與人際位置 |
| 替何棠作保 | 何棠靠近，沈鹿暫停開價 | 箱暫留；玩家信用押在何棠說法上 | 玩家能把自己的信用放進別人的故事 |
| 買下箱子 | 江照抬價或沉默離開 | 玩家失錢得物；箱進入玩家持物鏈 | 交易不是買道具，而是帶走未解牽連 |
| 放回潮線 | 箱被退潮重新碰到，短時間內不可再賣 | 箱暫離場；何棠與江照反應分歧 | 玩家能拒絕立即獲利，把物交回世界 |
| 藏起箱子 | 留主牆缺物，沈鹿記住玩家位置 | 玩家失信；後續拾物人更防備 | 玩家能做壞事，但世界不清空後果 |

### 12.6 回訪差異

| 前次結果 | 下次回訪可見 |
|---|---|
| 玩家未介入 | 留主牆前只剩紅線；沈鹿說箱被江照買走 |
| 玩家替何棠作保 | 何棠仍在等兄長消息；沈鹿允許玩家先看另一件未定物 |
| 玩家買下箱子 | 箱若又回到海岸，牆上會出現「曾被外地遠行者帶走」的記號 |
| 玩家放回潮線 | 退潮線附近短暫出現一段濕腳印，指向回潮原方向 |
| 玩家藏起箱子 | 拾物人避開玩家；江照可能先找到玩家下線後的行跡 |

回訪差異必須是玩家或 NPC 行動的結果，不是隨機換文案。

### 12.7 關鍵字追溯

| 關鍵字簇 | 本鏈落點 |
|---|---|
| 文字 MUD、重文字、輕畫面 | 玩家主要讀出物件、NPC、潮線與回訪文字的狀態差異 |
| 輕操作、指觸操作 | 入口是少量可點對象：不回箱、沈鹿、何棠、江照、留主牆、退潮線 |
| 全物件化、可動作交互 | 不回箱不是背景名詞；它有狀態、前史、動詞、失敗成本與回訪 |
| 不可無中生有、後端唯一數據真理 | 箱是否在場、誰碰過、誰買走、是否回潮，全部要成為世界事實 |
| 玩家不是主角、玩家 = NPC | NPC 也會碰、買、暫留、搶先、認領、帶走或藏起同一物件 |
| 世界永遠在線 | 玩家離開後，沈鹿、何棠、江照仍會推進箱子的去向 |
| 真實經濟 | 價格受前主、認領、風險、信用與是否願意被轉手影響 |
| 探索 / 冒險 | 箱可能引出回潮原腳印、失蹤者路線或下一次海送回返 |
| 經營 / 模擬 | 玩家可累積拾物人信用、建立歸還習慣、改變後續物件交易 |
| 戰鬥 / 衝突 | 若玩家藏箱、搶箱或破壞作保，衝突可在事前讀到前兆後升級 |

### 12.8 本鏈驗收結論

本鏈合格的地方：

- 地點不是局部氣氛，而是從大回潮與沉物海岸世界骨架長出。
- 物件不是材料表，而是能被碰、買、藏、歸還、放走並留下後果。
- NPC 不是商人或任務端點，而是和物件各自有關係、時間壓力與下一步。
- 玩家不是被指定完成任務，而是在錢、信用、物件、關係、風險與回訪之間選擇。

仍不足：

- 需要完整 M4 場景卡、資料欄位、價格規則、NPC 日程與衝突升級條件。
- 需要再產出至少兩條不同世界骨架的內容鏈，否則世界仍可能偏向單一物件玩法。
- 需要把本鏈拆回地圖、物件、社會、衝突四包，替換仍未通過 v1 回審的舊內容。

## 13. 第二條完整內容鏈：同名街群的三回頭牌

本節用來測試另一條世界骨架：名字與稱呼。它不能寫成身份系統表，也不能回到舊特殊設定；名字在本世界的功能是角色扮演、社會重量、誤認、保護、排斥與舊事回頭。

合格鏈條必須從「世界太容易交換，也太容易記住」出發，落到玩家能在街區中看見、稱呼、作保、遮名、跟人或承擔誤叫後果。

```text
世界問題
-> 世界骨架
-> 地點
-> 物件
-> NPC
-> 衝突
-> 玩家動詞
-> 世界狀態改變
-> 回訪差異
```

### 13.1 來源鏈

| 層 | 內容 | 為什麼能從世界長出 |
|---|---|---|
| 世界問題 | 世界太容易交換，也太容易記住 | 名字不是中性的標籤；被誰叫、在哪裡叫、用什麼舊稱叫，都會牽動人與地方 |
| 世界史 | 大回潮後，太多舊名、俗名、店名、亡者稱呼與遠行化名壓回當代 | 同一個稱呼可能指向活人、死者、舊店、工具、債務或未歸之人 |
| 世界骨架 | `同名街群` | 城市中多處街區因稱呼過密而互相干擾，名字成為城市生活問題 |
| 地點樣本 | `三回頭巷` | 在此喊出某些常用名，常會有不只一個人回頭；居民因此形成生活規矩 |
| 場景焦點 | `三回頭牌下` | 牌上不是路名，而是今日最容易誤叫的三組稱呼，居民會看牌再開口 |
| 核心物件 | `三回頭牌` | 一塊可改寫的街牌，記下今日在本巷最容易牽錯的人、店、物或舊事 |
| 核心 NPC | `織南` | 唱名者；她不是管理員，而是用唱名和改稱呼幫人不被錯名拖走 |
| 牽連 NPC | `阿岑`、`岑叔`、`岑記舊燈` | 一個年輕遠行者、一個欠債老人、一間已歇業卻仍被人叫慣的燈具店 |
| 衝突 | 玩家要叫人、找人或交易時，可能讓錯的人、錯店或舊債回頭 | 名字牽動人際、錢、信用、路線、追索和隱藏身份 |
| 玩家入口 | 讀牌、輕聲叫名、請織南唱名、替人作保、遮名、跟錯人、改稱呼 | 每個動詞都會改變 NPC 態度、玩家信用、街區稱呼狀態或回訪文字 |

### 13.2 玩家第一次看見什麼

這不是正式畫面文案，只是內容鏈的玩家可見目標。

```text
三回頭巷比鄰街安靜，卻沒人直接喊全名。
牌下掛著三行新墨：岑、晚燈、阿鹿。
織南正把第二行劃得更細，像怕那個稱呼太重。
一名年輕遠行者聽見「岑」字就停步，巷尾的老人也同時回頭。
舊燈鋪的門縫裡，滅了很久的燈芯忽然亮了一下。

【三回頭牌】 【織南】 【阿岑】 【岑叔】 【岑記舊燈】 【巷尾路口】
```

玩家不用讀設定，也能讀到：

- 這個地方的名字會造成行動後果。
- 玩家可以叫人，但不能把叫名當無成本查詢。
- NPC 不是等對話；他們正在因同一稱呼被牽動。
- 物件與店名也可能被叫回來。

### 13.3 核心物件卡：三回頭牌

| 欄位 | 設計 |
|---|---|
| 類型 | 名物、路物、街區物 |
| 來源 | 同名街群長期生活規矩；每早由唱名者或街戶改寫今日易牽錯的稱呼 |
| 現在狀態 | 牌上三行新墨：`岑`、`晚燈`、`阿鹿`；第二行墨跡被織南刻意寫細 |
| 可見痕跡 | 被擦去的舊稱、居民指痕、遠行隊留下的臨時名、店鋪舊名 |
| 可用動詞 | 讀牌、問牌、輕聲叫名、遮一行、請織南唱名、替某人作保、跟回頭者 |
| 失敗成本 | 叫錯人、引出舊債、讓隱藏者暴露、被街戶防備、讓某個物件重新活絡 |
| NPC 同規則 | 織南可改稱；阿岑可用外地名避開；岑叔可假裝沒聽見；街戶可阻止亂喊 |
| 錢/物/關係變化 | 找對人可成交或解事；叫錯可產生欠情、賠禮、拒絕交易或追索線 |
| 回訪差異 | 牌上名字變動；玩家曾叫錯的稱呼會被寫得更重或被居民暫時遮起 |

### 13.4 NPC 在場理由

### 13.8 本鏈驗收結論

本鏈合格的地方：

- 地點不是街景氣氛，而是從名字、稱呼、大回潮後舊事回頭的世界骨架長出。
- 物件不是告示牌，而是能被讀、遮、更新、牽動 NPC 與回訪狀態的街區機制。
- NPC 不是問話端點，而是各自被同一稱呼牽動，並會在玩家不介入時自行避開或離開。
- 玩家動詞不是查資料，而是叫名、作保、遮名、跟路，能改變人、物、錢、信用與回訪。

仍不足：

- 需要完整 M4 場景卡、街區相鄰關係、稱呼資料欄位、NPC 日程與舊債資料。
- 需要把本鏈拆回地圖、物件、社會、衝突四包，替換仍未通過 v1 回審的舊內容。
- 還需要不同世界骨架的內容鏈，避免世界只偏向物件與名字兩種玩法。

## 14. 第三條完整內容鏈：不留林的淡痕岔路

本節測試第三條世界骨架：放下、淡化、追索與被世界記住的代價。它不能寫成失蹤任務，也不能把「消失」做成單純隱身技能；不留林的核心是：不是所有痕跡都該永遠留著，但把痕跡變淡也會讓人、物、責任與關係承受後果。

合格鏈條必須從「世界記住太多」出發，落到玩家能在林口看見、跟路、留記、擦名、放走或追索的局部狀態。

```text
世界問題
-> 世界骨架
-> 地點
-> 物件
-> NPC
-> 衝突
-> 玩家動詞
-> 世界狀態改變
-> 回訪差異
```

### 14.1 來源鏈

| 層 | 內容 | 為什麼能從世界長出 |
|---|---|---|
| 世界問題 | 世界太容易交換，也太容易記住 | 有些人被前人的錯、舊債、舊名或舊傷拖住，想讓痕跡變輕 |
| 世界史 | 大回潮後，不只舊物回來，舊罪、舊路、舊追索也回來 | 放下不再只是心理狀態，而是會改變路、名字、物件與追蹤的世界事實 |
| 世界骨架 | `不留林` | 林地不太願意替人保存痕跡，讓追蹤、稱呼、舊物牽引與人際認知變淡 |
| 地點樣本 | `淡痕岔路` | 林口三條小徑會依攜帶痕跡不同而顯現或變淡；逃離者與追索者都會來 |
| 場景焦點 | `留步石旁` | 進林前可把某段腳步、稱呼或物件牽引暫放在石上，也可能被人看見 |
| 核心物件 | `留步石` | 一塊被無數人短暫放下腳步與舊稱的石頭；它不收走一切，只讓痕跡變薄 |
| 核心 NPC | `梁折` | 追索者；他相信有人不該被世界放掉，痛恨不留林把線索變淡 |
| 牽連 NPC | `祁晚`、`烏簪` | 祁晚想讓自己的舊稱變淡；烏簪是淡痕同行人，幫人進林但不保證結果 |
| 衝突 | 玩家要幫人放下、幫人追索、留記、擦名或把某物放在留步石上 | 保存/放下、追索/逃離、責任/自由互相衝突 |
| 玩家入口 | 讀岔路、觸留步石、留記、擦名、替人遮路、跟梁折追索、跟祁晚入林 | 每個動詞都會改變追蹤、NPC 信任、物件牽引、路況與回訪文字 |

### 14.2 玩家第一次看見什麼

這不是正式畫面文案，只是內容鏈的玩家可見目標。

```text
不留林邊的淡痕岔路沒有風，地上的腳印卻一層層變淺。
留步石旁壓著一枚舊髮簪，簪尾纏著快要褪色的紅線。
祁晚站在最左的小徑前，低聲練習一個不像自己的名字。
梁折蹲在石旁，把快要消失的腳印一筆筆描回泥面。
烏簪沒有催促任何人，只把空布袋攤開，等人自己決定要留下什麼。

【留步石】 【舊髮簪】 【祁晚】 【梁折】 【烏簪】 【左岔路】 【描回泥痕】
```

玩家不用讀設定，也能讀到：

- 這裡的核心不是打怪，而是痕跡變淡。
- 祁晚想放下，梁折想追回，烏簪幫人但不替人決定。
- 玩家可以介入，但介入本身會讓某些痕跡留下或消失。
- 物件、路與名字同時在場，且互相牽動。

### 14.3 核心物件卡：留步石

| 欄位 | 設計 |
|---|---|
| 類型 | 路物、家物邊界、淡痕物 |
| 來源 | 不留林入口長期被逃離者、送行者、追索者使用；人們在進林前把一段腳步或舊稱放在石上 |
| 現在狀態 | 石面潮冷；舊髮簪壓在一角；上面有被梁折描回的泥痕 |

| 可用動詞 | 觸碰、讀石、留記、擦名、放物、收回物、跟路、替人遮路 |
| 失敗成本 | 讓該被找回的人更難找、讓想放下的人被追回、讓玩家被梁折或烏簪不信任 |
| NPC 同規則 | 祁晚可放下舊稱；梁折可描回痕跡；烏簪可收走暫放物；其他人可搶先改變石面 |
| 錢/物/關係變化 | 放物可能失去物件但換得路徑變淡；替人留記可得信任；擦名可能得罪追索者 |

### 14.4 NPC 在場理由

| NPC | 在場理由 | 玩家不理時會怎樣 | 玩家介入後會怎樣 |
|---|---|---|
| 祁晚 | 她想把一個舊稱留在石上，讓追她的人不再用那個名字找到她 | 她會在傍晚前進左岔路，舊髮簪留在石上 | 玩家可幫她遮路、勸她留記、把髮簪還給她，或把她的位置告訴梁折 |
| 梁折 | 他追索一件未完之事，認為祁晚帶走的不只是自己的人生，也帶走了別人的答案 | 他會把淡掉的腳印描回，夜前跟進左岔路 | 玩家可協助追索、阻止他描痕、要求他說明為何非追不可 |
| 烏簪 | 她是淡痕同行人，替想放下的人看守暫放物，但不替任何人說謊 | 玩家不介入時，她收起空布袋，等下一個人來 | 玩家可信時，她讓玩家代管一件暫放物；玩家粗暴時，她拒絕再說路 |

這三人不是善惡分工。祁晚可能真的需要逃離，梁折可能追的是別人的公道，烏簪維持的是「可以放下，但要知道放下什麼」的地方規矩。

## 15. v1 驗收表

任一後續地點、物件、NPC、材料、社群、衝突或玩家動詞，必須能通過下表。

| 問題 | 合格答案 |
|---|---|
| 它從世界哪裡來 | 能回到萬物含能、生命交換、觸碰留痕、世界記住、玩家/NPC 同規則 |
| 它的歷史是什麼 | 至少能說出一段造成現在狀態的過去，不是背景散文 |
| 玩家看到什麼 | 有可被畫面文字呈現的狀態、人物、物件、路或異常 |
| 玩家能做什麼 | 至少一個可點動詞會改變人、物、地、錢、關係、風險或回訪 |
| NPC 是否同規則 | NPC 也能使用、拒絕、借走、搶先、受影響或留下痕跡 |
| 好玩在哪 | 玩家能做現實做不到、不能安全做、不能持續做或不能被世界承認的事 |
| 回訪有何差異 | 玩家或 NPC 行動後，之後畫面能讀出改變 |
| 是否仍是無根浮萍 | 若只能靠表格、數量、局部地名或漂亮文字成立，視為不合格 |
