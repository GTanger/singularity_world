# 資源點與礦區設計

> **實作向補篇**：[資源點設置與產出—實作建議](資源點設置與產出—實作建議.md)（空間錨點、yield_pool、與 Hex／詞元表對接草案）。

## 地下礦區

### 位置
- 浮生城地下一層
- 透過地下電梯連接地面

### 世界觀邏輯
- 因富態化影響，地層不斷擴增、擠壓，持續生成各種礦石
- 人們想盡辦法開闢、固定空間後，在此不斷開挖
- 礦區人少 → 聚念場弱 → 富態化壓不住 → 地層瘋長、礦石不斷生成
- 地層因富態化擴增的速度 **大於** 人類開採速度 → 資源永不枯竭
- 這是人力開闢的極限範圍區域

### 聚念場悖論（世界通用定理）
- 人少 → 聚念場弱 → 富態化旺盛 → 資源豐富但環境危險
- 人多 → 聚念場強 → 富態化被抑制 → 資源生長變慢
- 因此礦業（及所有採集活動）存在**最佳人數平衡點**——不能太少（危險、挖不動），不能太多（聚念場壓制生長）
- 此定理適用於所有資源點，非礦區獨有

### Token 密度模型（2026-03-28 定案；2026-04-08 流體模型補述）

Token 輻射**源源不絕、不會被消耗**。影響資源生長的不是 Token 總量，而是**當前位置的 Token 密度**。

#### 流體位移模型

Token 游離輻射的行為類似流體。有念生物進入一個場域（hex 格），產生兩層效應：

1. **體積位移**：有念生物的身體直接擠開等體積的 Token 游離輻射，如同人進入泳池擠開等體積的水。人離開的瞬間，Token 立即回填——**沒有冷卻時間**，密度恢復是即時的。
2. **念場相斥**：有念生物持續散發高頻有念游離輻射，與周圍空間的 Token 游離輻射相斥，進一步壓低場域內的 Token 濃度。這不是點效應，而是以人為中心向外擴散的場效應。

兩者疊加決定場域的實際 Token 密度。

#### 密度表

| 狀態 | Token 密度 | 資源表現 |
|------|-----------|---------|
| 無人 | 1.0（滿） | 正常富態化生長 |
| 1 人在場 | ~0.9 | 生長略慢，一人要敲 10 下掉落 |
| 3 人在場 | ~0.7 | 生長更慢，但每人只敲 3 下掉落 |
| 大隊駐守 | →0 | 生長趨零，駐守 = 自殺策略 |
| 人離開 | 瞬間回 1.0 | Token 立即回填，礦脈又開始做動擠壓成礦 |

#### Hex 格 = 場域

一個 hex 格不是一個腳下座標點，而是一片場域。人進入 hex 是進入一個場域，密度計算的是**整個場域的整體濃度**。資源體（富態化後的巨型礦脈、靈米樹等）佔據場域空間，採集者進入場域後對資源體進行作業——不存在「腳下撿東西」的概念。

**機制本質**：有念生物的高頻念場排開周身的 Token 游離輻射。人越多，密度越低，資源長越慢——但同時多人協力開採**速度更快**（3 人各敲 3 下 vs 1 人敲 10 下）。

**最優策略 = 脈衝式採集**：組隊快速挖光 → 全部撤離 → 等它長回來 → 再來一波。

**公會壟斷資源點在物理上不可能**——派人站崗 = 人在場 = 密度低 = 礦永遠長不回來。這不是規則限制，是世界觀的物理定律。

**代碼層面**：
- Token 密度 = `1.0 - f(房間內有念生物數量)`，下限 0
- 資源再生速率 = `基礎速率 × Token 密度`
- 採集速度 = `基礎敲擊數 / 在場人數`（協作加成）
- 冷卻機制 = 不存在。**你在不在場就是冷卻**

### 資源個體與成熟度模型（2026-04-08 定案）

#### 完全變態質

每個資源個體有成熟度 0.0→1.0（完全變態質）。即便富態化，上限仍為 1.0——富態化加速的是 0→1 的過程，不改變天花板。**成熟度到 1.0 才可採收**，未成熟不可採。

#### 物件制（沿用 MUD 設計）

資源場域（hex 格）內的每個資源個體是獨立的可互動物件：
- 成熟度到 1.0 → 物件出現在場域中（玩家可看到、可互動）
- 採收 → 物件消失，該位開始重新從 0 生長
- 場域有容量上限（`capacity`），決定同時能孕育多少個體

房間描述不需要動態化。**變的是房間裡有什麼物件**，不是房間本身的文字。

#### 兩層結構

- **hex 級**：Token 密度（由在場有念生物數決定），影響場域內**所有**個體的成長速率
- **物件級**：各自的成熟進度 0→1，成長速率 = `base_growth * hex_density`

密度是全場域共享的。人多了，場域內所有正在生長的個體一起變慢——不存在「這棵不受影響」的例外。

### 採集流程（2026-04-08 定案）

#### 完整流程

1. 資源個體成熟（0→1）→ 物件出現在場域中，玩家可看到、可互動
2. 玩家對物件下「採集」→ 後端依**插頭/插座語義**判定：物件插座定義接受的工具類型 vs 玩家 hold_l / hold_r 實際持物
3. **不符合 → 拒絕**，回饋原因（如「需要鎬類工具」）。不存在「赤手但效率極低」的中間態——能做或不能做，由插座定義
4. 符合 → 進入 **Gathering 狀態**（被動放置），系統自動結算
5. 每 tick：扣物件耐久、扣玩家體力
6. 物件耐久歸零 → 物件消失、產物進背包、該位重新從 0 生長
7. **中斷條件**：體力歸零 / 移動 / 受攻擊 / 主動停止 / 背包滿

#### 工具判定

赤手能不能採取決於**資源物件自身的插座定義**，不是全域規則：
- 草藥類：插座接受赤手（無持物要求）
- 礦脈類：插座要求鎬類工具，赤手不可採

對齊「裝備＝工具」（DESIGN_KEYWORDS）與「不可無中生有」原則——赤手敲碎礦脈違反物理常識。

#### 採集時間因素（規格待定）

- **物件端**：hardness（物質硬度），決定基礎耐久
- **採集者端**：工具 tool_power、體質修正、工具熟練度（規格待定，見 DESIGN_KEYWORDS「工具熟練度」）
- **體力消耗**：每 tick 扣體力（四相之一），歸零強制中斷

### 採集→材料→剝名→結晶→提出管線（2026-04-08 定案）

#### 四階段分層

| 階段 | 輸入→輸出 | 決定什麼 | 門檻 |
|------|----------|---------|------|
| **採集** | 場域資源體 → 材料 | 種類、數量、節奏 | 插頭/插座（工具匹配） |
| **剝名** | 材料 → 詞元結晶 | 結晶品階（丙/乙/甲）、結晶數 | **無**（人類基礎能力） |
| **儲存/交易** | 結晶流通 | — | 結晶可收納、可交易 |
| **提出/提煉** | 結晶 → 裸詞元 | 提取成數（功法決定） | 功法（人人會基礎） |
| **使用** | 裸詞元 → 載體 | 入竅/附魔/疊煉/鑄鎂 | 即時，不可延遲 |

#### 1. 採集（場域→材料）

從場域取得材料（白板物質）。管的是**再生節奏、種類、數量**，由 Token 密度與聚念場悖論決定。採集不涉及品質判定。

- **位置：固定**。讓地圖有戰略意義，玩家記路線、商隊規劃路徑（2026-03-28 定調）
- **工具門檻**：由資源物件的插座定義（礦脈需鎬、草藥可赤手），見上方採集流程
- **校正（2026-04）**：此前「玩家與資源點對頻決定採集品質」為對談延伸，**已撤銷**

#### 2. 剝名（材料→結晶）

從材料中剝離 Token 烙印 → 物質消散 → 烙印失去載體後**自然凝結成結晶態**（如舍利子），即**詞元結晶**。

**剝名是人類基礎能力**（文檔交叉驗證）：
- 詞盤彙整：「因 token，人類能將名剝下」→ 天然能力，非習得技能
- 機構賦權：「人人皆懂提煉與提出」→ 連下一步都人人會，剝名更不可能需要門檻
- 世界觀本體論：限制在**對象**（人對人不可、對獸對物可行），不在施術者資格
- 實作層：015 工單已定義 Strip（剝名）為前端互動指令，與 Butcher（分解）並列

**不需要**特定工具、場所、或技能等級。赤手可剝——剝名是念場對物質的作用，不是物理敲打。

**品階（丙/乙/甲）= 剝名時擲骰**。影響因素：
- 整體剝名 vs 肢體/單體剝名（整體難度高但品階上限高）
- 單剝 vs 合剝（合剝混沌度高，結果不可預測）

##### 剝名投入模式（2026-04-08 定案）

沿用獸體「全剝／肢解剝」的設計語言，材料同理：

- **單剝**（一材料一剝名）：結晶數量多，每個能量低，向量方向相對可預測（山礦偏山系維度）
- **合剝**（數材料合一剝名）：結晶數量少（可能僅一個），投入的混沌能量總量大，多重烙印疊加後**向量方向不可預測**——賭注越大、結果越不可控

合剝結果由詞盤向量引擎自然處理（多材料烙印向量疊加），不另設規則表。**需模擬測試**：驗證多向量疊加不會系統性趨近零向量。

#### 3. 詞元結晶（可儲存態）

剝名產物是**詞元結晶**——烙印的舍利子，穩定態：
- **可收納**：放入背包、倉庫
- **可交易**：市場主要流通物
- **僅品階可測**（2026-04-08 設計者定案）：結晶上可感知品階（丙／乙／甲），但**屬性方向不可知**——提出前不知道是什麼字。市場定價以「品階＋產地」為錨（如「甲級山礦結晶」），產地暗示屬性方向但不保證（混沌本質）

對接 [機構賦權—討論稿](../reference/機構賦權—討論稿.md)：價值物 = 一切未經提出的詞元結晶。

#### 4. 提出／提煉（結晶→裸詞元，不可逆）

用功法從結晶中提取裸詞元。結晶崩解，裸詞元**不可收納、不可交易**，須立即灌入載體。

**兩層品質，不要混淆**：
- **品階（丙/乙/甲）**= 結晶本身的等級，剝名時決定，是結晶的天花板
- **提取成數（3~9 成）**= 功法從結晶中提取多少潛力，提出時決定

甲級結晶 × 爛大街功法（3 成）可能不如乙級結晶 × 頂尖功法（9 成）。**品階 × 成數 = 最終詞元實際效力。**

**功法成數**（機構賦權定義）：
- 爛大街功法：3～5 成
- 國家級：穩定 7 成，極低機率 9 成
- 頂尖功法：高機率 7 成，且比國家更高機率 9 成

**提煉 vs 提出**（用途分支）：
- **提煉**（入竅，內盤使用）：裸詞元灌入竅穴，永久改體質頻率
- **提出**（附魔，裝備使用）：裸詞元寫入裝備，半永久強化

兩者皆為人人會的基礎能力，差別僅在功法品質。

**國家代提**：國家機構可代為提出（穩定 7 成），收取市價三成為費用。「官方剝名處」實為**官方提出處**——剝名人人會不需要代工，值得代工的是提出品質。

#### 5. 裸詞元使用（即時決策）

裸詞元脫離結晶後不穩定，必須立即選擇去向：
- **入竅**（永久改體質頻率）
- **附魔**（半永久強化裝備）
- **疊煉**（強化既有詞元）
- **鑄鎂**（轉換為貨幣）

#### 設計意涵

- **五層各司其職**：材料＝庫存層、剝名＝轉換層、結晶＝流通層、提出＝品質層、裸詞元＝消費層
- **三個決策點**：剝名時（單剝/合剝/投入什麼材料）→ 提出時（用什麼功法/現在提還是等更好的功法）→ 使用時（入竅/附魔/疊煉/鑄鎂）
- **壟斷結晶有意義，壟斷裸詞元不可能**——結晶可囤可交易，裸詞元必須即用
- **功法成為稀缺資源**——自然驅動門派、師徒、國家代提等社會結構
- **保守 vs 賭徒**：單剝穩穩來 vs 合剝搏稀有組合，玩家策略自然分化

### 設計意義
- 合理解釋「為什麼資源挖不完」——不是刷新機制，是世界本身在生長
- 礦區永遠有活幹，支撐經濟循環不崩盤
- 壟斷不可能——物理定律層級的限制，不是遊戲規則
- 最優策略是脈衝式協作，天然鼓勵社交但反對霸佔
- NPC 行為循環：組隊→快速開採→撤離→等待→再來

## 農業系統（2026-03-28 概念定案）

### 世界觀邏輯

聚念場邊緣耕種 = 富態化受控 = 作物可管理但能量密度低。

| 環境 | 作物表現 | 混沌能量（示意） |
|------|---------|----------------|
| 聚念場邊緣（城市農田） | 富態化受抑制，個體偏小（稻米約半身高） | 低（5~10 單位/顆，劣品低至 1） |
| 野外（無聚念場） | Token 全力輻射，稻米→**靈米樹**（超人身高，結穗最小人頭大小） | 高（~100 單位/顆） |

### 食物鏈推論

野外靈米樹 → 食草獸的食糧 → 食草獸是食肉獸的食糧 → 人類要採高價值資源就得面對完整食物鏈。

### 設計意義

- **自種 = 低價值但安全穩定**，符合城市生活的低風險低回報
- **野採 = 高價值但危險**，三面向選擇的壓力在此（剝詞入體 / 售鎂 / 附魔）
- 自種作物理論上也可剝名，但品質極低，經濟上不如直接當食物
- 農業系統與聚念場悖論天然對齊——不需要額外設定
