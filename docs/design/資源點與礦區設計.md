# 資源點與礦區設計

## 地下礦區

### 位置
- 浮生城地下一層
- 透過地下電梯連接地面

### 世界觀邏輯
- 因富態化影響，地層不斷擴增、擠壓，持續生成各種礦石
- 人們想盡辦法開闢、固定空間後，在此不斷開挖
- 礦區人少 → 聚念場弱 → 富態化壓不住 → 地層瘋長、礦石不斷生成
- 地層因富態化擴增的速度 **大於** 人類開採速度 → 資源永不枯竭
- 這是人力開闢的極限範圍區域

### 聚念場悖論（世界通用定理）
- 人少 → 聚念場弱 → 富態化旺盛 → 資源豐富但環境危險
- 人多 → 聚念場強 → 富態化被抑制 → 資源生長變慢
- 因此礦業（及所有採集活動）存在**最佳人數平衡點**——不能太少（危險、挖不動），不能太多（聚念場壓制生長）
- 此定理適用於所有資源點，非礦區獨有

### Token 密度模型（2026-03-28 定案）

Token 輻射**源源不絕、不會被消耗**。影響資源生長的不是 Token 總量，而是**當前位置的 Token 密度**。

| 狀態 | Token 密度 | 資源表現 |
|------|-----------|---------|
| 無人 | 1.0（滿） | 正常富態化生長 |
| 1 人站著挖 | ~0.9 | 生長略慢，一人要敲 10 下掉落 |
| 3 人同時挖 | ~0.7 | 生長更慢，但每人只敲 3 下掉落 |
| 大隊駐守 | →0 | 生長趨零，駐守 = 自殺策略 |
| 人離開 | 瞬間回 1.0 | 礦脈又開始做動擠壓成礦 |

**機制本質**：有念生物的高頻磁場排開周身的 Token 微波輻射。人越多，密度越低，資源長越慢——但同時多人協力開採**速度更快**（3 人各敲 3 下 vs 1 人敲 10 下）。

**最優策略 = 脈衝式採集**：組隊快速挖光 → 全部撤離 → 等它長回來 → 再來一波。

**公會壟斷資源點在物理上不可能**——派人站崗 = 人在場 = 密度低 = 礦永遠長不回來。這不是規則限制，是世界觀的物理定律。

**代碼層面**：
- Token 密度 = `1.0 - f(房間內有念生物數量)`，下限 0
- 資源再生速率 = `基礎速率 × Token 密度`
- 採集速度 = `基礎敲擊數 / 在場人數`（協作加成）
- 冷卻機制 = 不存在。**你在不在場就是冷卻**

### 資源點位置與品質（2026-03-28 定案）

- **位置：固定**。讓地圖有戰略意義，玩家記路線、商隊規劃路徑
- **品質：浮動**。每次刷新時 yield_pool 的品質分佈隨機偏移——同一個礦脈這週出好貨下週出垃圾，防止最優路線固化
- **品質掛鉤：匹配度 + 擲骰**。玩家頻率與資源點 freq_band 的匹配度決定品質骰的上限：
  - 頻率正中 freq_band 中心 → 骰子範圍 丙~甲
  - 頻率擦邊 → 骰子範圍 丙~乙（甲被截斷）
  - 頻率勉強進門檻 → 只出丙

### 設計意義
- 合理解釋「為什麼資源挖不完」——不是刷新機制，是世界本身在生長
- 礦區永遠有活幹，支撐經濟循環不崩盤
- 壟斷不可能——物理定律層級的限制，不是遊戲規則
- 最優策略是脈衝式協作，天然鼓勵社交但反對霸佔
- NPC 行為循環：組隊→快速開採→撤離→等待→再來

## 農業系統（2026-03-28 概念定案）

### 世界觀邏輯

聚念場邊緣耕種 = 富態化受控 = 作物可管理但能量密度低。

| 環境 | 作物表現 | 混沌能量（示意） |
|------|---------|----------------|
| 聚念場邊緣（城市農田） | 富態化受抑制，個體偏小（稻米約半身高） | 低（5~10 單位/顆，劣品低至 1） |
| 野外（無聚念場） | Token 全力輻射，稻米→**靈米樹**（超人身高，結穗最小人頭大小） | 高（~100 單位/顆） |

### 食物鏈推論

野外靈米樹 → 食草獸的食糧 → 食草獸是食肉獸的食糧 → 人類要採高價值資源就得面對完整食物鏈。

### 設計意義

- **自種 = 低價值但安全穩定**，符合城市生活的低風險低回報
- **野採 = 高價值但危險**，三面向選擇的壓力在此（剝詞入體 / 售鎂 / 附魔）
- 自種作物理論上也可剝名，但品質極低，經濟上不如直接當食物
- 農業系統與聚念場悖論天然對齊——不需要額外設定
