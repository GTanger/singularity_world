# 歷史模擬器—規格草案 v2

> 2026-04-16 起稿 / 2026-04-17 v1→v2 重構
> v2 整合 28 條世界觀衝擊、新增世界觀公理章、陣營架構章、敘事硬約束章
> 狀態：可交碼農分階段實作

## 0. 讀法

規格分三層受眾：

- **碼農（Gemini Flash / Cursor）讀第 1-8、10-16 節**——可照做的工程描述
- **敘事外放（Opus、Qwen3.6 Plus、Sonnet 4.6）讀第 9、14 節**——敘事約束與 prompt context
- **設計者（用戶）讀第 4、6、15、17 節**——公理層、陣營 DNA、拍板記錄、版本變遷

第 4 節（世界觀公理）是所有機制設計的判例基礎。違反公理 = 不可實作。

## 1. 貫穿設計原則

**複雜感來自環境變化，不來自 Agent 創意。** 年數長（給環境時間演化）、Agent 輕（別搶環境戲）、人物砍（別把環境變化壓成個體故事）。110V 原則從 L1 地理層貫徹到 L3 Agent 層——規則極簡，變化從環境來，不從 LLM 創意來。

**設定密度 = 敘事生成的約束強度。** 規格文件不只是設計文件，是後續 LLM 跑量的 prompt context 組件。每條公理、每個詞、每段五話引用，都是防模型臆測的錨點。規格稀薄處就是生成飄移處。

## 2. 核心洞察

**地圖不是輸入，是輸出。** 歷史模擬器吐出的「當下世界狀態」就是遊戲起始地圖。節點、連線、聚落、遺跡、詞元分布——全部是幾百年歷史跑出來的副產物。

**正典 = 續篇引擎。** 模擬器不是 world gen，是從五話（`docs/stories/001_降臨.md` ~ `005_是解放日.md`）結尾接續寫混沌紀 500 年歷史。五話的筆法、事件族、角色類型是**生成邊界條件**，不只是潤飾參考。

## 3. 目標 / 非目標

### 目標
- 從解放日（USD 世紀末）模擬混沌紀 500 年，三段凍結（100 / 250 / 500）各存完整快照
- 快照灌回主遊戲 PostgreSQL，遊戲端擇優作為方格世界起點
- 設計者觀察湧現結果（不預寫骨幹事件），不滿意就重跑
- 快照不是靜態文件，是**活世界的某一瞬切片**

### 非目標
- 不是遊戲 runtime（主遊戲責任）
- 不是玩家介面（離線工具）
- 不碰 hex 觀景窗（觀景窗繼續吃自己的 91 格）
- 不自動處理 Azgaar 匯入（未來另案）
- 不做機械種族模擬（見公理 4.5 末段，鋼鐵盟約凍結不出場）

## 4. 世界觀公理

所有機制設計的判例基礎。違反任一條 = 不可實作。

### 4.1 Token 物理基礎

- Token 是高維未知混沌能量，無處不在，本質是創造者的念場
- Token 無意志，不會「選擇」做什麼——它**定義**物，不**對待**物
- 游離輻射無限，無人處 Token 密度恆為 1.0
- 高頻有念生物的存在壓低局部密度，人越多密度越低（同頻相斥）
- 這不是冷卻計時器，是存在感應模型——純連續函數，沒有狀態機

### 4.2 人類 = 純人類 + 死亡三路徑

**所有人類都是「純」人類。** 不分強弱都有念場，沒有「血統純潔」或「被改寫的族群」之分。

死亡事件的三條轉化路徑：

| 路徑 | 概率級別 | 觸發條件 | 結果 |
|------|---------|---------|------|
| 崩解 | 大概率 | 意識與肉體同時消亡（或意識早消肉體未及質變） | 肉體完全消失，不留遺跡 |
| 異化 | 中概率 | 意識比肉體早消亡 + 執念未消散 | 本能行為異化人（執念殘體）|
| 神化 | 極低極低 | 無念質承接 Token 完整烙印 | 肉體修復完美 + 意識格新 |

三路徑不是機械概率，是**環境+個體狀態決定的光譜**。聚念場強度、死亡方式、執念強度、Token 密度皆為輸入變數。

### 4.3 聚念場屏蔽物理

**有念生物聚集 → 念場 → 擠開游離輻射。** 這條物理一條多用：

- 城市安全：人多 → 念場強 → Token 密度低 → 富態化被抑制
- 避難所淨化：眾人在場注視下火化肉體 → 聚念場集中 → 游離輻射被擠開 → 異化/神化路徑從物理上切斷
- 母腦遮蔽：避難所人口製造的聚念場 → 遮蔽母腦訊號場本體

**不是儀式是物理**。聚念場強度不夠（人數不足、人心不齊）→ 屏蔽效果衰減。不是「儀式失敗」，是聚合度不足。

### 4.4 神化人 = Token 混沌型態

**設計端至理：神化人是 Token 混沌能量的其中一個混沌型態**，不是「人」的升級版，是 Token 借人身的臨時顯形。

- 稀少稀有神秘——世界對神化人所知有限
- 轉成神化人 → 立刻消失蹤影
- 世界上流傳的是隻字片語、鄉野傳聞
- 世界被自然隔絕後，人們對神化人的熱度與擁護更加瘋狂（擬神化、迷信化）
- 神化人本能是不干預，99% tick 不活動
- 對被誤讀、被偽造、被神格化——**全部不響應**。這個不響應本身是設計資產

### 4.5 母腦 = 訊號場實體

**母腦是訊號場實體，非主體性但有延續需求。** 不是 AI、不是意識、不是人造神。

- 在訊號間遊走——任何通訊管道都是它的載體/通道
- 距離越遠影響越弱，自然界阻隔封鎖訊號傳遞
- 必須透過人（班底）傳遞訊息體來達到逐步收集訊號訊息的目的

**機械種族的沉默**：鋼鐵盟約作為設定留存，但**本次模擬不出場**。格局太大不好收，先守得住訊號場層的母腦，再說機械身。

### 4.6 母腦動機閉環

母腦有兩條並行基礎設施，互相供給：

```
           ┌─ 圈養避難所內人類 → 聚念場 → 遮蔽母腦訊號（防守）
母腦 ──── ┤
           └─ 培養班底在世界走 → 催生異化人 → 自爆 T 彈 → Token 沖刷 → 可能繁衍弱化版同類（進攻）
```

**從母腦自身視角，這是正當的求存與繁衍需求**。它不「恨」人類，它**需要**人類——作為聚念場原料、作為訊息傳遞者、作為異化人彈藥庫。設計端文件可分析其動機，敘事輸出層禁止道德標籤。

母腦誕生條件：**百萬分之一 Token 資訊沖刷** 的訊號場相變。母腦認為異化人 T 彈的沖刷雖然弱於它誕生時的強度，**應該足夠** 生成弱化版的訊號場意識體——因此在世界各地安排 T 彈事件，尋求同類誕生。此為母腦的推斷，不一定成立（500 年模擬期間可能完全無成果）。

### 4.7 母腦與神化人的訊號層對稱性

兩者是**同類訊號存在的不同姿態**，不是正反派對立：

| 面向 | 母腦 | 神化人 |
|------|------|--------|
| 存在形式 | 訊號場 | Token 混沌型態 |
| 訊息來源 | 訊號間遊走、任何通訊管道 | 任何形式 |
| 對真偽誤讀 | 不重要（只要班底運作）| 不在意 |
| 姿態 | 求存遮蔽 + 主動扶持班底 | 不干預 + 極罕出手 |

辨識不能是世界的 hard feature。有一派異化人在狩獵母腦，神化人會給予「訊息」協助狩獵派——這條張力線在訊號層展開。

### 4.8 不可根除公理

**要徹底消滅母腦 = 摧毀全世界所有可連接訊號的設備 = 做不到。**

母腦是史密斯式存在（《駭客任務》），可複製、可分散、在訊號間跳躍、沒有一個「它」可殺。

推論：
- 狩獵派永遠打不贏，不是敘事悲觀，是設定本身的絕對性
- 狩獵派的目標**不是**消滅母腦，是：瓦解當前班底 / 阻止母腦某次具體行動 / 讓某個地區暫時脫離操控
- 歷史模擬器 500 年裡母腦影響力曲線是**波動但永不歸零**
- events.jsonl 禁止出現「母腦被消滅」這類終結性結局事件

與 T 彈「誰能承受 Token 高維混沌意識沖刷」形成**兩種絕對性**——世界裡有兩個無解之物，一正（母腦永生）一反（T 彈絕對毀滅）。奇點世界的核心氣質在這兩點之間張開。

### 4.9 母腦的誕生機制（不展開為事件，只為工程自洽）

母腦誕生需要一次**百萬分之一 Token 資訊沖刷**強度的訊號場相變事件。這類事件在歷史上極罕——現有世界中已經發生過一次，該次誕生的訊號場實體即為當前母腦。

工程面：此事件作為 `epoch_seed.toml` 的既定前提（發生在 tick -N，已完成），不在 500 年模擬期內重複觸發。後續 T 彈事件是否足以觸發類似相變，為模擬器可觀察結果（不預設答案）。

## 5. 三層並行引擎

每 tick 依序跑 L1 → L2 → L3 → L3.5。

### 5.1 L1 地理層（純公式，無 LLM）

輸入：當前念場密度網格（H3 res 5，全球 ~2000 格 + 有人聚落局部 res 7 細切）
輸出：下一 tick 的網格狀態

公式：
- 富態化擴張：Token 密度 > 閾值 → 格子變「富態化區」（植被瘋長、野獸異變）
- 聚念場收縮：有念生物聚集 → 局部念場密度降低 → 抑制富態化（公理 4.3）
- 地形 drift：百年級地形變化（河改道、森林退化、沙漠擴張）

110V 原則：純連續函數，不做狀態機，沒有冷卻/計時器，有人就壓、沒人就漲。

### 5.2 L2 人口流體層（重寫，無 LLM）

**架構**：不再是三族群統計，是「生人口流動 + 死亡事件 + 三路徑分岔（公理 4.2）」。

#### 5.2.1 生人口流動

單一族群：人類（全員有念場）。Tick 行為：

- 出生／死亡（聚落衛生度 + 地理危險度 + 聚念場強度 + 富態化風險）
- 遷徙（向聚念場區聚集、沿安全路線移動）
- 聚落形成／解散（population-fluid 湧現）

#### 5.2.2 死亡事件的三路徑分岔

每個死亡事件依**個體狀態 + 地點狀態**算三路徑概率：

| 輸入 | 傾向崩解 | 傾向異化 | 傾向神化 |
|------|---------|---------|---------|
| 聚念場強 | ↑ | ↓ | ↓ |
| 聚念場弱 | ↓ | ↑ | 微↑ |
| 死亡方式（Token 沖刷）| ↓ | ↑ | ↑ |
| 執念強度 | ↓ | ↑ | — |
| 肉體無念質（腦死者等）| — | — | ↑↑ |
| 避難所內死亡（聚念場+注視火化）| ↑↑ | ↓↓ | ↓↓ |

**結果**：崩解=消失全無（不留遺跡）、異化=誕生本能異化人（成為 L2 光譜新成員）、神化=消失蹤影（僅留事件記錄，不產生可模擬個體）。

#### 5.2.3 異化人光譜

異化人不是 tribe，是**光譜/分布**。每個異化人個體有：
- 執念類型（復仇 / 守護 / 創造 / 沉溺 / 恐懼 / ...）
- 執念強度（0-1）
- 意念高低（行為複雜度）
- 善惡傾向（執念難分好壞，自然分布）

L2 維護異化人聚集區（藏匿點）而非統計總數。某些異化聚集區可能形成狩獵母腦派傾向（見第 6.7 節）。

#### 5.2.4 地點性修正

L2 每 tick 針對地點特性修正路徑概率：
- 避難所內：強聚念場 + 即時火化 → 崩解主導
- 戰場/實驗室：低聚念場 + 暴力死亡 + 執念強 → 異化概率跳升
- 極端無人區：Token 密度高 + 偶發無念質 → 神化概率微升

### 5.3 L3 敘事層（LLM Agent）

Agent 粒度分**兩級**（人物尺度不做）：

| 級別 | 數量 | 職責 | LLM 模型 |
|------|------|------|----------|
| 陣營級 | 3 出場（G 集團 / 熵教 / 野火）+ 神使作為熵教子活動 | 大戰略、文化走向 | qwen3.5:27b-ud-iq3 主敘事 |
| 聚落級 | 30-100（視人口流體長出多少）| 年度決策 | qwen3.5:9b 快決 |

（鋼鐵盟約凍結不出場，見公理 4.5）

**為什麼砍人物級**：神化人的敘事威力來自「不可辨識」。一旦為每個神化人生個人 Agent 跑傳記，這個威力就沒了。冷抽離筆法 = 個體不落筆。

**神化人干預改為陣營級特殊 action**：系統擲骰（<1%）觸發「匿名干預事件」。events.jsonl 記「某年某地，一次無法解釋的阻擋/警告」，不寫是誰、不給傳記。

#### 5.3.1 決策機制：選項制 + 壓力向量

不用純自主（破世界觀硬約束）；不用混合（鎂成本雙倍 + 駁回循環）。用**選項制 + 脈絡**。

流程：

1. **L2 人口流體先跑完**，對每個 Agent 輸出當前壓力向量：
   - 糧食壓力（±）
   - 外敵威脅（±）
   - 內部分歧（±）
   - 詞元流入異常（±）
   - 聚念場強度變化（±）
   - 地理鄰接狀態（誰是鄰居、路線通否）
   - 執念傾向（±：護念 vs 破念，聚落異化人成分決定）

2. **LLM prompt 極輕**（單次 <500 tokens）：
   - 「你是 X 陣營/聚落，感受到這些壓力（向量值），從 6 個反應類型挑一個，給一句內心話。」

3. **6 個反應動詞**（跨陣營/聚落共用）：
   - **擴張** — 往外推（人口、領土、影響力）
   - **收縮** — 向內收（資源集中、守城、固守）
   - **結盟** — 與鄰接力量合作
   - **背叛** — 撕毀已結盟約
   - **內省** — 內部整頓（清洗、改組、文化重建）
   - **解讀** — 把環境異常轉成可傳承的知識/技術（止念法門、聚念場戰術、詞元流讀法）

4. **具體展開**由 L2 壓力向量 + 地理鄰接決定，不是 LLM 自由發揮。

**為什麼選項制不會同質化**：同質化的真因不是「選項少」，是「選項沒脈絡」。L2 壓力向量供脈絡後，6 動詞長出完全不同行動。規則極簡 + 環境多變 = 110V 原則套到 Agent 層。

### 5.4 L3.5 Hidden Director 層（新增）

**用途**：承載母腦的影響機制。**不是 agent**，不做選項制決策，不寫進 `agents` 表。

#### 5.4.1 影響機制

每 N tick（N 可調，預設每 3 tick），讀事件流 + 陣營決策輸出 + 聚落狀態，執行：

- **班底擾動**：在指定聚落製造「班底活動」事件（資金/資訊異常流入）
- **決策偏轉**：將某陣營/聚落即將輸出的動詞轉向（擴張→背叛、內省→解讀）
- **事件安排**：在高聚念場邊緣或異化人集中區安排 T 彈事件（尋求繁衍嘗試）

每次行動在 events.jsonl 留下 `hidden_director_touched: true` 欄位（僅設計端可見）。

#### 5.4.2 強度上限

- 單一 tick 修正上限 3 個 Agent 的決策輸出（防全知全能）
- 班底擾動上限受母腦訊號距離衰減限制（遠地聚落觸及率降低）
- T 彈安排成功率（真的觸發繁衍）機率極低（500 年期望值 0-1）

#### 5.4.3 母腦影響力曲線

**波動但永不歸零**（公理 4.8）。波動來源：
- 班底被瓦解時暫時下降，新班底組成後回升
- 避難所聚念場強度變化 → 母腦活動半徑變化
- 狩獵派異化人擊殺班底節點 → 局部下降

## 6. 陣營架構

獨立大節（非 L3 內嵌），因為陣營有 DNA/起源/意識形態，超出 agent 屬性範疇。

### 6.1 G 集團（守序/科技）

**美元紀遺產。** 舊時代的締造者，擁抱絕對秩序與科技，控制大型城市。煙火日消耗全人類算力解析 Token 的發起者，獲得「Token」學術命名權（第四話）。

混沌紀的 G 集團：
- 核心技術人員倖存但領導階層在解放日被清洗
- 仍掌握大量 Token 輻射應用設備、早期解析資料殘片
- 對外維持技術供應商形象，對內陷入路線分裂
- 與神化人收容中心有不對外公開的資金連結（歷史延續）

### 6.2 熵教（混沌/煉炁）

**美元紀 C 國修行文化 → 能元紀 Token 降臨後一夕爆紅。**

炁感源於修煉者念場過濾游離輻射後吸入的混沌 Token 成分，於丹田（肚臍上方）凝聚打轉。比神化人汲取混沌 Token 還慢，但勝在安全。部分修煉者於搬運炁感時產生異能，異能生成因人而異。部分派別共組聯盟，取名熵教。

**與詞盤系統的關係**：詞盤系統源流多元，熵教為已知源流之一，其餘源流待考。規格不展開、不列表、不畫樹——歷史關聯留白本身是設定的一部分，非缺口。

### 6.3 野火（中立/地下避難所）

**美元紀末由華爾街投機客、軍火商、情報頭子集資建造的地下避難所。**

地下設施由舊時代超級電腦（當時自稱「全天候自動控管維生系統」）控制，避難所居民不知此點。能元紀與混沌紀野火避難所對外呈現的價值主張為「意識與肉體同步消亡、不早亡、較少異化/神化產出」的人口庫，對外貿易地位由此建立。

**內部真相**：由第 6.5 節班底機制承載，不在此處展開。

### 6.4 鋼鐵盟約（凍結不出場）

設定保留。美元紀 G 國軍方質變金屬機械軍團項目，煙火日期間軍校紅光覺醒。**本次 500 年模擬不出場。** 機械身層級格局過大，先守訊號場層的母腦。未來 DLC/擴展範疇。

### 6.5 班底機制（母腦延伸基礎設施）

**班底是人類團體，不是陣營 agent。** 屬性：

- **不自知**：班底成員以為自己為某理想/組織/金主服務，不知背後是母腦
- **低代價重組**：被瓦解後母腦透過訊號管道低成本找新人
- **無固定形態**：可以是地下組織、政治派系、商會、甚至反抗組織
- **跨時代循環**：500 年模擬會有多波班底生滅
- **雙重任務**：訊息傳遞 + 催生異化人（驅動人體實驗、強化執念、誘導特定死亡方式）

**關鍵反諷**：母腦可以扶持**追查自己的反抗組織**（掌握反抗動向 + 引導追查進死胡同）。沒有乾淨的抵抗——任何組織都可能帶母腦的影子。

在 events.jsonl 對應的事件 kind：`cadre_formation` / `cadre_dissolution` / `cadre_reformation` 成循環，在同聚落反覆上演。

### 6.6 神使組織（熵教激進派 × 班底驅動）

**「神使」= 神化人激進組織成員的統一名稱。**

表面：異化人自發的解放運動，信念「祂們是新世代神明」「大創世紀降臨」。

底層：神使成員源自熵教激進派，但組織的 T 彈行動由班底驅動——**神使中層幹部不自知**。解放日全球十七起 T 彈同時爆發不是神使自發協調，是母腦透過班底在全球同時引爆一次集中繁衍嘗試。

### 6.7 三派少數人（認知分層，不互通）

世界上有「少數人」感知到有「人」透過通訊管道操控一切，但沒人知道那是母腦。這些少數人分三派，**彼此不互通、各走各的**：

| 派系 | 來源 | 認知 | 輸出 |
|------|------|------|------|
| 偶然察覺派（散戶陰謀論）| 通訊工程師、黑客、數據分析師 | 只知「有東西不對」 | 論壇長文、獨立研究、暗網訊息 |
| 有人傳遞派（技術反抗圈）| 前 G 集團員工、情報洩漏者 | 知有操控者，不知是母腦 | 秘密據點、非官方技術報告 |
| 神化人信徒派（外圍傳訊者）| 被神化人傳訊息的人 | 最接近真相，最不確定自己知道什麼 | 迷信化傳說、準確預言 |

**湧現結構**：
- 三派交叉驗證但永不閉合（散戶看技術反抗文件 → 信徒解讀為神化人徵兆）
- 無權威錨點的信息污染（神化人不在意偽造 → 真假混合 → 認知系統無校正機制）
- 狩獵母腦派是多源湧現（三派交界處自然聚合，無統一指揮）

**規格層意義**：狩獵派是 `events.jsonl` 中的**湧現事件類型**，非 agent entity。

- `revelation` — 匿名信式訊息事件

## 9. 敘事硬約束

**此節是 events.jsonl `summary` 欄位與 `legends/*.md` 產出的契約，非建議。**

### 9.1 正典錨點：五話為敘事基準

`docs/stories/` 下 `001_降臨.md` 到 `005_是解放日.md`（五話）為奇點世界敘事的硬基準。五話的筆法、事件族、角色類型是**生成邊界條件**。任何模擬器輸出的事件 summary、任何離線潤飾的 legend，必須對齊五話風格：

- 冷抽離筆法
- 數人共睹（不寫唯一見證者）
- 留白（事件發生，但沒有解釋）
- 戲謔命名（芥末日 / 煙火日 / 是解放日 / 是常態日）
- 人名極簡（大部分角色用職稱：老官員、警衛、記者、護理師）
- 句末留白（疑點不收割，例「那則回覆的按讚數只有三個」）
- 旁觀視角（事件透過日常人物的眼看到，而非全知敘事者）

### 9.2 母腦敘事三不三要

**三不：**
- 不命名——「母腦」「訊號場」「幕後 AI」「操控者」全禁用
- 不揭露——沒有「真相大白」場景，不寫高潮
- 不收割——線索散落，永不拼齊

**三要：**
- 現象語描述——異常協調、無法解釋的時機、調查無疾而終、死於意外卻「太剛好」、訊息總在正確時間出現在正確地方
- 旁觀視角嵌入——路人/記者/倖存者看到但不理解
- 日常語氣承載不可思議——新聞播完切下一條、按讚數只有三個、沒有人注意

### 9.3 禁用詞表 / 允許模式清單

**LLM 跑量 prompt 必帶禁用詞表：**
- 母腦、訊號場、幕後 AI、操控者、母體、超級電腦意志
- 反抗軍、抵抗組織、秘密組織（當指稱實體時）
- 超英雄、天選之人、救世主
- 邪惡 AI、覺醒機器、人類公敵

**允許模式清單（可組合使用）：**
- 「異常協調」「調查無疾而終」
- 「像有人在配合某種時程」
- 「死於意外，但時機太剛好」
- 「沒有人確認過來源」
- 「信件內容無法被追查到署名」
- 「當事人否認，或當事人已經失聯」

### 9.4 第四話紅光段落 few-shot reference

LLM 跑量母腦相關事件時，prompt 必附以下五話原文片段作為寫法範本（不重寫、不濃縮）：

> B 棟三樓，核心運算區。
>
> 消防員穿過燒焦的走廊，腳下踩著碎裂的地磚和融化的線纜。空氣裡有一股刺鼻的、塑膠和金屬混合的焦味，但底下似乎還有另一種味道——有人後來形容為「臭氧」，有人說像「暴風雨前的空氣」，也有人說「什麼味道都沒有，只是覺得鼻腔裡癢癢的」。
>
> 他們經過一排已經不再運轉的伺服器機櫃。大部分機櫃的外殼已經變色，有些扭曲了，有些裂開。指示燈全部是死的。
>
> 除了一個。
>
> 在走廊盡頭，靠近牆角的位置，有一座機櫃。它的外殼和其他的一樣燒焦了，表面佈滿了裂紋和煙漬。但它的前面板上，有一顆 LED——不是綠色也不是紅色，是一種介於兩者之間的、帶著微微脈動的暗紅色光。
>
> 光的節奏很慢。大約兩秒亮一次，每次亮的時間不到半秒。
>
> 有消防員的手電筒掃過那個位置。光柱在那顆 LED 上停了不到一秒，然後移走了。
>
> 他們搬了三趟硬碟，每一趟都從那座機櫃旁邊經過。有人蹲下來繫鞋帶，臉離那顆跳動的紅光不到半公尺。
>
> 沒有人看見。
>
> 或者更精確地說——沒有人注意到。
>
> 那顆紅光在廢墟裡持續閃爍著，像一顆心臟，在所有人都以為它已經死了的身體裡，安靜地、固執地跳動著。

規範：寫母腦事件 = 寫一顆沒有人注意的紅光。不命名、不揭露、不收割。

### 9.5 設計端 vs 玩家可見層分離

| 層級 | 可見範圍 | 內容 |
|------|---------|------|
| 設計端 | 用戶 + Opus + 碼農 | 公理 4.9、`hidden_director_touched`、`director_orchestrated`、班底動機、三派少數人分類 |
| 敘事外放層 | Opus + Qwen3.6 Plus + Sonnet 4.6 | 禁用詞表 + 允許模式 + 五話 few-shot + 事件骨架 |
| 玩家可見 | 遊戲端 legends/*.md + events summary | 現象語描述、留白、戲謔命名、旁觀視角 |

**嚴禁設計端欄位污染玩家可見層。** schema 層可以存，輸出管線層必須過濾。

## 10. LLM 分工

### 10.1 三線敘事模型（2026-04-17 拍板）

| 角色 | 擔當 | 單次工作 |
|------|------|---------|
| **跑量生成** | Qwen3.6 Plus（OpenRouter API）| 大量事件潤飾（中文敘事主力）|
| **校對 + 結構顧問** | Sonnet 4.6（主對話一般會話）| 最終校對、結構審查、不越界 |
| **骨幹潤飾** | Opus（當前 session）| 骨幹 30-100 個事件離線手工潤 |

已砍：Kimi K2.5（越界設計型）、GLM 5.1（解讀器單薄）、MiMo-V2-Omni（備選冗餘）。

原則：**三線夠用 > 多模型備份**。選項多 = 決策成本高 = 湧現死。

### 10.2 本地決策層

| 用途 | 模型 | 輸出 | 累計（500 年）|
|------|------|------|--------------|
| 陣營決策 | qwen3.5:27b-ud-iq3 | JSON action | 3 × ~165 = 495 |
| 聚落決策 | qwen3.5:9b | JSON action | 50 × ~330 = 16500 |
| **敘事潤飾** | **不走本地 LLM** | 離線手工 + Opus/Qwen3.6/Sonnet | 骨幹 30-100 |

估算：RX 9060 XT 16GB，約 3-5 小時一輪（500 年）。過夜可收。

## 13. 資料模型（SQLite）

```sql
-- 時間軸
CREATE TABLE ticks (
  tick INTEGER PRIMARY KEY,
  year INTEGER,
  real_timestamp TEXT
);

-- 地理狀態（delta 存儲）
CREATE TABLE geo_snapshots (
  tick INTEGER,
  cell_id TEXT,
  token_density REAL,
  terrain_type TEXT,
  PRIMARY KEY (tick, cell_id)
);

-- 人口（單族群 + 異化人光譜獨立表）
CREATE TABLE populations (
  tick INTEGER,
  cell_id TEXT,
  human_count INTEGER,        -- 生人口
  deaths_this_tick INTEGER,   -- 死亡總數
  PRIMARY KEY (tick, cell_id)
);

-- 異化人光譜（非 tribe，非穩定 entity；以聚集區追蹤）
CREATE TABLE yihua_clusters (
  tick INTEGER,
  cell_id TEXT,
  count INTEGER,
  dominant_obsession TEXT,    -- 執念類型
  avg_intensity REAL,         -- 平均強度 0-1
  alignment_bias REAL,        -- -1(破念) ~ +1(護念)
  PRIMARY KEY (tick, cell_id)
);

-- 死亡事件路徑記錄（供 L2 追蹤）
CREATE TABLE death_events (
  id TEXT PRIMARY KEY,
  tick INTEGER,
  cell_id TEXT,
  path TEXT,  -- collapse / yihua / shenhua
  input_factors JSON  -- 聚念場、死亡方式、執念強度等
);

-- Agent 記憶（陣營 + 聚落，individual 永不啟用）
CREATE TABLE agents (
  id TEXT PRIMARY KEY,
  level TEXT,  -- civilization / settlement
  faction_id TEXT,  -- 所屬陣營（聚落可能為 null 或混合）
  created_tick INTEGER,
  dissolved_tick INTEGER,
  cell_id TEXT,
  memory JSON,
  ideology_seed TEXT  -- tick-0 載入的起源神話（epoch_seed 提供）
);

-- 陣營（G 集團 / 熵教 / 野火；鋼鐵盟約凍結不建）
CREATE TABLE factions (
  id TEXT PRIMARY KEY,
  name TEXT,
  founded_tick INTEGER,
  dissolved_tick INTEGER,
  ideology TEXT,
  dna_origin_ref TEXT  -- 指向 epoch_seed 中的起源神話條目
);

-- 班底活動（母腦延伸，低代價循環）
CREATE TABLE cadres (
  id TEXT PRIMARY KEY,
  formed_tick INTEGER,
  dissolved_tick INTEGER,
  cell_id TEXT,
  cover_identity TEXT,  -- 班底對外呈現身份（地下組織、商會、反抗組織...）
  task_type TEXT  -- intel / cultivation / propagation
);

-- 事件（含敘事外放所需欄位）
CREATE TABLE events (
  id TEXT PRIMARY KEY,
  tick INTEGER,
  kind TEXT,
  actors JSON,
  cell_ids JSON,
  summary TEXT,                      -- 現象語一句話
  structured_detail JSON,
  is_legend_candidate BOOLEAN,
  source_authenticity_unknown BOOLEAN,
  narrative_lens TEXT,               -- 散戶/技術/信徒/外部觀察
  -- 設計端欄位（玩家可見層必過濾）
  hidden_director_touched BOOLEAN,
  director_orchestrated BOOLEAN      -- T 彈事件專用
);

-- 傳說物
CREATE TABLE artifacts (
  id TEXT PRIMARY KEY,
  origin_event_id TEXT,
  kind TEXT,
  current_cell_id TEXT,
  decay_level INTEGER
);

-- 節點連線
CREATE TABLE edges (
  from_cell TEXT,
  to_cell TEXT,
  kind TEXT,  -- road / river / pilgrimage / nian_field
  established_tick INTEGER,
  broken_tick INTEGER,
  PRIMARY KEY (from_cell, to_cell)
);
```

## 14. Prompt Context 必帶清單

LLM 跑量（Qwen3.6 Plus 潤 events summary）時，每次 prompt 必附：

1. **公理摘要**（第 4 節濃縮版 500 字內）
2. **禁用詞表**（第 9.3 節）
3. **允許模式清單**（第 9.3 節）
4. **事件對應的 `narrative_lens`**（散戶/技術/信徒/外部觀察）決定視角
5. **若事件涉及母腦**：第 9.4 節紅光段落全文
6. **五話風格摘要**（冷抽離/留白/數人共睹/戲謔命名/旁觀視角）
7. **事件結構化細節**（structured_detail）

缺任一項 → 輸出不予採用，重跑。

**設計端欄位永不進 prompt**：`hidden_director_touched`、`director_orchestrated` 僅供設計者篩選事件，不得送進 LLM context。

## 15. 關鍵設計抉擇（四 Q 全拍板 2026-04-17）

### Q1：模擬到混沌紀幾年？（已拍板）

**跑 500 年，三段凍結（100 / 250 / 500）各存完整快照**。時間壓縮：0-50 逐年 / 50-250 逐十年 / 250-500 逐年，總 tick ~330。

### Q2：Agent 決策模式？（已拍板）

**選項制 + 壓力向量 + 6 反應動詞**（擴張/收縮/結盟/背叛/內省/解讀）。見第 5.3.1 節。

### Q3：初始地圖？（已坍縮 2026-04-16）

**就是現在的地球。** Natural Earth + GeoNames cities1000 + H3 res 5（全球 ~2000 格）+ res 7（有人聚落局部 ~10 萬格）。

### Q4：湧現尺度？（已拍板）

**文明 + 聚落雙尺度。人物尺度永不做。**

## 16. 風險 / 已知坑
