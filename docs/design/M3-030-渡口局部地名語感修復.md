# M3-030 渡口局部地名語感修復

狀態：候選待拍板，未替換 runtime
日期：2026-06-16
範圍：只處理 M3-027/M3-029 渡口局部的玩家可見命名鏈；不擴地圖、不新增 NPC、不新增材料、不重開地圖系統。

更新：使用者已選 `C` 地點線：`渡口市集 / 市集外谷地路`。`秤邊包貨單` 被明確否決，不再作為候選物件名；需求物件名改列 `收貨牌` 候選，等待使用者確認。

## 問題判定

`短市` 不是一個可讓台灣玩家自然站住的地名。它像是把「短暫、小型、交易、市場」壓縮成資料節點，玩家讀到時會先卡在「這是什麼詞」，而不是理解自己站在什麼地方。`小市` 也不能解這個問題，因為它同樣半文半白，且使用者已明確否決這個方向。

本輪修復的設計邏輯：

- 地名先回答玩家的位置尺度：我站在岸邊、渡口、攤棚旁，還是在通往谷地的路上。
- 物件名先回答玩家能操作什麼：秤、單、貨、牌、繩、籃，而不是把地名塞進物件名。
- 路名先回答玩家要往哪裡走：往谷地、往貨路、往攤棚外，不使用壞地名派生。
- 命名不得讓後續設計繼續長出 `短貨`、`短市人群`、`短市那頭` 這類功能壓縮詞。

## 命名候選表

### 候選 A：岸邊攤棚線

玩家讀法：這裡是岸邊搭起來的攤棚，靠近渡口，人和小件貨都在棚邊流動。

| 原名/語句 | 候選 A |
|---|---|
| `岸邊短市` | `岸邊攤棚` |
| `短市包貨單` | `收貨牌` |
| `短市外谷地路` | `攤棚外谷地路` |
| `短市人群` | `攤邊人群` |
| `短市那頭` | `攤棚那頭` |
| `短市棚腳` | `棚腳` |
| `短貨籃` | `貨籃` 或 `小件貨籃` |

優點：最貼近現有可見物：棚、秤、價牌、貨籃。尺度小，不會把一小塊渡口交易點誇成完整市場。
風險：`攤棚外谷地路` 稍長；若未來此處擴成更完整市場，`攤棚` 會顯得偏局部。

### 候選 B：渡口貨攤線

玩家讀法：這是渡口邊處理小件貨、交料、問價的貨攤區。

| 原名/語句 | 候選 B |
|---|---|
| `岸邊短市` | `渡口貨攤` |
| `短市包貨單` | `收貨牌` |
| `短市外谷地路` | `貨攤外谷地路` |
| `短市人群` | `看貨人群` |
| `短市那頭` | `貨攤那頭` |
| `短市棚腳` | `貨攤棚腳` |
| `短貨籃` | `小件貨籃` |

優點：`渡口貨攤` 通俗、直觀，和交易/交付循環的玩法最貼。
風險：`貨攤` 比 `攤棚` 更偏交易功能，容易讓後續設計又往單一買賣點收縮；需靠 NPC 和倉棚回聲拉回生活面。

### 候選 C：渡口市集線

玩家讀法：這裡是渡口旁形成的一小片市集，人貨消息都會停一下。

| 原名/語句 | 候選 C |
|---|---|
| `岸邊短市` | `渡口市集` |
| `短市包貨單` | `收貨牌` |
| `短市外谷地路` | `市集外谷地路` |
| `短市人群` | `市集人群` 或 `看貨人群` |
| `短市那頭` | `市集那頭` |
| `短市棚腳` | `市集棚腳` |
| `短貨籃` | `小件貨籃` |

優點：`市集` 是台灣玩家可自然理解的詞，語感比 `短市/小市` 正常。
風險：目前 M4-027-04 的內容仍是岸邊攤、秤、價牌、貨籃與需求板，`市集` 可能讓玩家預期更大規模；除非要把此格定位成渡口交易中心，否則 C 不應優先。

### 廢棄詞紀律

拍板後新紀錄需明確寫入：

- `短市`、`小市` 不再作為玩家可見地名使用。
- `短市包貨單`、`秤邊包貨單` 不再作為玩家可見物件名使用；需求板按可見實體改為 `收貨牌` 或使用者拍板詞。
- `短市外谷地路` 不再作為玩家可見路名使用；路名按邊界或去向命名。
- `補給小市` 是後續另案，不能因為本輪只修渡口而被視為可接受。
