# 2026-06-17 外部遊戲設計參照

狀態：輔助研究筆記，不是奇點權威；本檔偏局部系統校準，完整遊戲設計本體研究見 `2026-06-17-遊戲設計本體研究.md`
用途：把外部遊戲設計資料轉成可檢查的設計判準，避免文件只剩名詞、材料百科、漂亮場景句或 NPC 輪播台詞。
第一權威仍是：`docs/DESIGN_KEYWORDS.md`

## 研究對象

本輪只查和奇點關鍵字直接相關的資料：

- 模擬遊戲 UI 與玩家心智模型。
- 文字遊戲的 world model 與輸出文字。
- 物件如何承載可玩動詞。
- NPC 如何避免變成台詞播放器。
- 玩家經濟如何讓不同玩法有位置。

## 來源摘要

| 來源 | 可用觀點 | 奇點轉譯 |
|---|---|---|
| Will Wright / Don Hopkins, `Designing User Interfaces to Simulation Games` | 模擬模型、玩法、UI、玩家心智模型必須一起設計；環境物件可分擔角色行為邏輯 | UI 不是資料顯示器；每個畫面區塊都要幫玩家建立「我在哪、能碰什麼、為何要做」的心智模型 |
| Emily Short, `Action and Interaction` | world model 的存在是為了擴大玩家可行動範圍；不能產生有效互動或不能被文字呈現的狀態不該複雜建模 | 場景文字必須揭露可操作狀態；後端狀態若永遠不影響玩家可見輸出，就是設計噪音 |
| Emily Short, `World Models Rendered in Text` | 文字可以是世界模型的渲染結果，而不是事後裝飾；複雜物件狀態要能被文字承接 | 場景卡不寫隨機氛圍句；它要從時間、天氣、人、物、路、事件痕跡生成可判讀文字 |
| Park et al., `Generative Agents` | 可信 NPC 需要觀察、記憶、規劃與反思組件共同支撐；行為應從經驗與安排中生成 | NPC 不是商人/任務點/輪播台詞；至少要有可見目的、持物、去處、記憶或行動痕跡 |
| Raph Koster, `Player-driven Economies` | 玩家經濟的重點不是錢，而是讓多種玩法在同一生態中有用 | 採集、搬運、修補、探索、交易、委託、經營都必須能服務他人或被他人服務 |

## 轉成設計判準

### 1. UI 判準

第一屏每個固定區域都要回答一個玩家問題：

- 全局上下文：現在世界節奏是什麼。
- 場景狀態：這裡現在可判讀的局勢是什麼。
- 自身入口：我靠什麼活，手上有什麼籌碼。
- 入口列表：我能碰誰、碰什麼、去哪裡。
- 事件流：我剛剛造成或察覺了什麼改變。

若某 UI 區域只是在展示資料，沒有支撐玩家決策，應降級或移除。

### 2. 場景文字判準

一段場景文字必須至少揭露一種可操作資訊：

- 可利用物件。
- 可介入人物。
- 可冒險路線。
- 可錯過時機。
- 可回訪痕跡。
- 可推測價格、關係、風險或缺貨。

只有氣氛而不能影響玩家選擇的文字，不得作為核心場景卡完成標準。

### 3. 物件判準

核心物件要像「動詞來源」，不是百科名詞。它至少要回答：

- 玩家能用它做什麼。
- NPC 是否也會用它。
- 它在什麼狀態下改變選項。
- 它如何連到錢、路、人、工具、風險或回訪差異。

現實用途再多，若不能在當前切片裡提供玩家選擇，就不該進核心物件。

### 4. NPC 判準

NPC 可信度不來自台詞量，而來自「玩家看得見他不是為玩家待機」：

- 他有自己的目的。
- 他可能先玩家一步行動。
- 他會因狀態、關係或事件記憶改變反應。
- 他不在場時留下合理痕跡。
- 玩家介入後，他之後的行為或稱呼有差異。

不能被玩家行動或世界狀態影響的 NPC，只能當背景人群，不得當核心 NPC。

### 5. 經濟判準

經濟不是收購板，也不是材料表。經濟要讓不同玩法互相需要：

- 採集者提供來源。
- 搬運者解決距離與時間。
- 修補者恢復物件與場所功能。
- 探索者提供路況、來源與危險資訊。
- 交易者承擔價格與庫存風險。
- 委託者把錢轉成離線行動。
- 經營者讓場所跨時間產生差異。

若某經濟活動只是在固定 NPC 與玩家之間換錢，沒有供需、風險、信用、物流或他人參與，不能稱為真實經濟。

## 不採用的外部方向

- 不把 The Sims 的需求條或家居主題直接搬入奇點。
- 不把 LLM NPC 論文直接當 runtime 架構。
- 不把 player-driven economy 變成多人 MMO 規格壓力。
- 不把文字互動 fiction 的 parser 問題照搬；奇點是手機點擊文字 MUD，重點是零指令入口。
- 不把「現實越細越好」當準則；只有會改變玩家選擇的細節才進核心。
