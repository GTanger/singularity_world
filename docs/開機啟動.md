# 奇點 + Chatmery 開機自動啟動

## 一鍵安裝（先殺現有再執行）

在**奇點專案根目錄**執行：

```bash
chmod +x start-with-chatmery
./start-with-chatmery --install
```

會寫入 systemd user 服務 `sw-with-chatmery` 並 enable，開機後會自動：

1. 結束佔用 **1721** 的 process（奇點）
2. 結束現有 **chatmery-web** process
3. 建置奇點、Chatmery Web
4. 啟動奇點（PORT=1721）、Chatmery Web（PORT=1722）

## 手動啟動／重啟

```bash
systemctl --user start sw-with-chatmery   # 啟動
systemctl --user stop sw-with-chatmery    # 停止
systemctl --user restart sw-with-chatmery # 重啟（會先殺再建置並啟動）
systemctl --user status sw-with-chatmery  # 狀態
```

## 路徑

- 奇點：`start-with-chatmery` 所在目錄
- Chatmery：預設為奇點目錄的 **../chatmery**；可設環境變數 `CHATMERY_DIR` 覆寫（含 `--install` 時寫入的 service 也會用該值）


## 僅手動跑一次（不裝 systemd）

```bash
./start-with-chatmery
```

會先殺現有、建置、啟動三支 process；終端關閉或 Ctrl+C 會一併結束。
