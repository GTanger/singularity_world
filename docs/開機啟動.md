# 奇點世界 開機自動啟動

## 透過 systemd user 服務

專案根目錄已有 `singularity.service`，透過 systemd 管理：

```bash
systemctl --user start singularity    # 啟動
systemctl --user stop singularity     # 停止
systemctl --user restart singularity  # 重啟
systemctl --user status singularity   # 狀態
```

## 手動跑一次

```bash
./start        # 閘門（clippy → test → checkrooms）→ 後端 release → Hex 編輯器 trunk → systemd 重啟
```

## 路徑

- 奇點伺服器：PORT=1721
- 資料目錄：`data/`
