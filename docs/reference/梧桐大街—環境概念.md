# 梧桐大街 — 環境概念與房間設計

> **用途**：供梧桐大街各段房間描述、場景敘事與動線撰寫對齊。須符合 [世界觀：富態與拉鋸](世界觀：富態與拉鋸.md)（富態生長、平衡拉鋸、無廢土感）。房間設計與分配表來源：`data/rooms_archive/梧桐大街/`。

---

## 一、定位：四大街中綠化程度最高

梧桐大街在四大街中**綠化程度最高**。早年即於大街兩側種植**兩排梧桐**，綠意盎然；經歷**長年富態化**後，綠意未退，反而與富態生長、平衡拉鋸結合，形成獨有的街區風情。

---

## 二、長年富態化後的環境推論

**起點**：兩排梧桐、綠意盎然。  
**富態化**：能量過剩導致植物質變（肉質感、與礦物／建築咬合）、平衡拉鋸（增生不吞噬文明）、無廢土感。

推論結果：

- **梧桐**：不會枯死，而是更茂、更「進化」。樹冠更厚、枝葉蔽天，兩排梧桐可交織成**綠廊拱頂**；樹幹或枝條可能帶**玉質脈絡**或肉質感，氣根與石板、路緣**咬合**，穩住地磚而非撐破。落葉與腐殖層在拉鋸下形成**溫潤的層次**，不是荒廢。
- **地面**：石縫間長的不只是青苔，可能還有**發光菌絲**、玉質脈絡、根鬚與磚石嵌合。路面仍可通行，富態化是「與結構咬合」，不是吞噬。
- **簷角、牆垣**：植被自牆簷**溢出**卻與建築咬合——藤蔓撐簷、綠意覆牆，店招與民居**掩映在濃蔭之中**，光線篩落、低飽和微光，而非陰森廢墟。
- **空氣與光**：綠意飽和、**懸浮綠色微粒**、沉香或淡淡膠質氣味；游離輻射帶來**低飽和、持續存在的微光**（暗紫、淡綠、琥珀），白天不刺眼、夜晚不純黑。**靜謐的豐饒**，安靜但不死寂。
- **人跡**：大街仍是大街——凡人照常行走、市集照開、簷下照樣有人。風情是「**東西一直在長，但沒把我們吃掉**」：文明與增生並存，見怪不怪的從容。

**一句話**：梧桐大街 = **綠意最濃的一條街，長年富態化後成綠廊拱頂、玉質脈絡與根鬚咬合石路、簷角掩映濃蔭，靜謐豐饒、無廢土感**。

## 三、撰寫要點（供房間描述對齊）

| 項目 | 建議語彙／方向 |
|------|----------------|
| 樹木 | 梧桐、樹冠交織、綠廊拱頂、枝葉蔽天、玉質脈絡、氣根與石咬合 |
| 地面 | 石磚與根鬚／玉質嵌合、縫隙菌絲或微光、恆溫熱氣（若設定有）、落葉與腐殖層 |
| 簷與牆 | 植被溢出、藤蔓撐簷、濃蔭掩映、光線篩落 |
| 空氣與光 | 綠意飽和、懸浮微粒、沉香／膠質氣味、低飽和微光 |
| 氛圍 | 靜謐的豐饒、文明與增生並存、無廢土感、從容 |

勿寫：廢墟、枯死、腐臭、吞噬一切、雜草叢生無人跡。

### 格式要點（archive）

- **zone**：archive 皆為 `"梧桐大街"`；遷移至九段可改為 `wustreet`。
- **材質與氛圍**：黑曜石、白玉石板、梧桐、綠意、沉香、油脂感、綠色微粒、恆溫熱氣、玉質／晶體、能量導線等。

- **id 命名**：建築入口全名（如 wutong_feicui_chazhuang），內部前綴＋數字（feicui_02～07 等）。
