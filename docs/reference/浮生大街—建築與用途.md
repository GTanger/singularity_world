# 浮生大街—建築與用途

> 供房間描述、任務與 NPC 對齊用。各建築「在做什麼」簡述。

---

## 萬象墟（三段）

**用途**：三段**集墟**——街段共用的匯聚所，過客與攤商於廊廂間**易物、歇腳、暫駐**。不是單一店鋪，而是多廊多廂的複合空間，有人擺攤、有人路過、有人借宿一隅。

**動線**：從浮生大街三段經〔墟門〕進入→ 前庭 → 主廊 → 中庭；中庭四向為北廳、南軒、左廂、右廂、內堂，各帶側室。**出墟**：中庭或前庭 → 主廊 → 前庭 → 〔墟門〕→ 浮生大街三段。

**氛圍**：巨構、靜謐的豐饒、玉質脈絡與微光，與世界觀「富態／拉鋸」一致。廊廂小室可作攤位或暫歇，不必寫死每室用途，保留「集墟」的開放感。

---

（其餘建築如石髓館、藤心居、青苔宅等可依需要補上。）
