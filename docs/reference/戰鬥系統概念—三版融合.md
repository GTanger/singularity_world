## 一、設計原則與前提

- **同一套規則**：玩家 vs NPC、NPC vs NPC、玩家 vs 玩家皆用同一組公式（決策 001）；Resolve 不寫 DB，扣血／死亡由呼叫方處理。
- **行動槽模型**：戰鬥以 100ms 為一 Tick，AP 累積達門檻可出手；非傳統回合制。
- **概念全納**：下列所有概念皆納入公式，未實裝時以預設值代入。
- **詞盤驅動**：戰鬥與詞盤、地形標籤、SoulSeed 三軸整合；半自動策略、田忌賽馬、生存與反擊並重。
- **戰報**：後端產出完整文字 log，供前端渲染。

## 三、戰鬥流程（三版合併）

1. **進入戰鬥**：玩家/NPC 對目標發動攻擊指令或詞元，觸發戰鬥。
2. **行動槽**：每 Tick 恢復 AP；達 T_base（基礎）或 T_skill（技能）門檻可出手；連擊時 C_combo 提高門檻。
3. **詞盤／技能**：可選基礎攻擊或技能（SkillObject）；蓄能 (AP) → 檢核 (Qi ≥ Qi_Drain) → 結算 → 回饋 (Log)。
4. **狀態異常**：結算得 D_Final 後，若 D_Final > CT_類型 則施加對應異常（毒素/麻痺/沉默/減速等）；未實裝時 CT := ∞。
5. **戰鬥結束**：任一方 HP ≤ 0 即敗；雙方同時 ≤ 0 為平手。

## 四、核心公式（融合版）

### 4.1 總體公式（gemma3 完整融入）

gemma3 原式：  
`最終傷害 = 命中率 × (綜合傷害 - 敵方反擊) + 元素傷害加成 + 狀態效果相互作用 + 環境影響 + 玩家行動 + 怪物行動`  

本文件將「加成／影響／行動」收斂為乘項與門檻，寫成**單一乘式**（未實裝項以 1 或 0 代入）：

```
綜合傷害_raw = 基礎傷害 + 裝備加成 + 技能加成
             = (Atk_Power + Atk_Gear + Skill_Bonus) × R × M_Lush

經減傷與反擊後 = 綜合傷害_raw × (1 - mit)  ；mit 已含「守方體質＋破甲」，可視為含 gemma3 的防禦與反擊效果

最終傷害 = 命中判定 × 經減傷與反擊後 × K_Impact（爆發）
           × Elem_mult × Status_mult × Env_mult
           × 相位結果（Crit/Deflect）
```

- **綜合傷害**（gemma3 同）：基礎傷害 + 裝備加成 + 技能加成；本式以 (Atk_Power + Atk_Gear + Skill_Bonus) × R × M_Lush 表示。
- **反擊**（gemma3：怪物反擊/玩家防禦）：本式併入 **mit**（Def_EVit/(Def_EVit+Pen×20)）；若日後拆出獨立 Counter 項，則 經減傷後 = 綜合傷害_raw × (1 - mit) - Counter，未實裝時 Counter=0。
- **元素／狀態／環境**：Elem_mult、Status_mult、Env_mult；未實裝時均為 **1**。
- **玩家行動／怪物行動**：已含於 Atk_Power（選擇的詞元/技能）與行動槽門檻；未實裝時 1。

### 4.2 先手與行動資格

- **先手**：EDex_Atk >= EDex_Def 則 Atk 先攻，否則 Def 先攻；相等時約定 Atk 先。
- **可出手**：AP >= T_base 或 AP >= T_skill × C_combo；未實裝時序時視為每輪皆可。
- **可放技能**：EQi >= Qi_Drain；未實裝時 Qi_Drain=0 恆可。

### 4.3 命中

- **K_Hit** = Atk_EDex / max(Atk_EDex + Def_EDex, 1)
- **P_Hit** = clamp(0.05, 0.95, K_Hit × 1.2 × (1 + Skill_γ_match))
- **命中判定**：random() < P_Hit 則命中，否則該次 D_Final := 0。

### 4.4 傷害鏈（單次攻擊，gemma3 項全部寫入）

- **綜合傷害_raw**（gemma3 綜合傷害）= (Atk_Power + Atk_Gear + Skill_Bonus) × R × M_Lush；未實裝時 Skill_Bonus=0，R=M_Lush=1。
- **K_Impact** = 0.8 + 0.4×α
- **D_Impact_raw** = 綜合傷害_raw × K_Impact
- **Pen** = Atk_Penetration + (1 - Def_β) × Const_pen
- **mit**（含 gemma3 防禦與反擊效果）= Def_EVit / max(Def_EVit + Pen×20, 1)
- **D_after_mit** = D_Impact_raw × (1 - mit)；若命中且 > 0 可設至少 1。
- **元素／狀態／環境**：**D_Final_base** = D_after_mit × Elem_mult × Status_mult × Env_mult；未實裝時三項均 1。
- **相位**：γ 觸發 Deflect → D_Final=0；γ 觸發 Crit → D_Final = D_Final_base × Crit_mult（例 1.5）；否則 D_Final = D_Final_base。
- **反彈**：若觸發 Reverse，攻方亦受部分傷害；未實裝則不計。
- **姿態**：Posture -= f(D_Final)；Posture ≤ 0 → Stagger；未實裝不計。
- **狀態異常**（gemma3）：若 **D_Final > CT_類型**（例 CT_中毒 = 基礎傷害×0.2，CT_麻痺=0.15，CT_沉默=0.1），則施加對應異常，持續時間依傷害與抗性；未實裝時 CT := ∞ 不觸發。

### 4.5 氣脈與狀態異常

- **Qi_Drain** = Skill_Cost × (2 - β) × M_Lush；未實裝時 0。
- **狀態異常**（gemma3 融入）：結算得 D_Final 後，若 D_Final > CT_類型 則施加該類型異常（毒素/麻痺/沉默/減速等），持續時間由傷害與抗性決定；未實裝時 CT := ∞。

### 4.6 單式鏈彙總（gemma3 項全部寫入，未實裝以 1 或 0 代入）

```
K_Hit     = Atk_EDex / max(Atk_EDex + Def_EDex, 1)
P_Hit     = clamp(0.05, 0.95, K_Hit * 1.2 * (1 + Skill_γ_match))
命中      = random() < P_Hit

綜合傷害_raw = (Atk_Power + Atk_Gear + Skill_Bonus) * R * M_Lush
K_Impact  = 0.8 + 0.4*α
D_Impact_raw = 綜合傷害_raw * K_Impact
Pen       = Atk_Penetration + (1 - Def_β) * Const_pen
mit       = Def_EVit / max(Def_EVit + Pen*20, 1)
D_after_mit = D_Impact_raw * (1 - mit)   [若未命中則 0]

D_Final_base = D_after_mit * Elem_mult * Status_mult * Env_mult

[相位] 若 γ 觸發 Deflect → D_Final=0；若 γ 觸發 Crit → D_Final = D_Final_base * 1.5；否則 D_Final = D_Final_base

Qi_Drain  = Skill_Cost * (2 - β) * M_Lush
[姿態] Posture -= g(D_Final)；若 Posture≤0 則 Stagger
[狀態異常] 若 D_Final > CT_類型 則 施加對應異常（中毒/麻痺/沉默/減速等）
```

未實裝時：Skill_Bonus=0, Elem_mult=Status_mult=Env_mult=1, CT=∞（不觸發狀態異常），其餘同 §二。

### 4.7 名詞對照（gemma3 ↔ 本文件）

| gemma3 | 本文件 |
|--------|--------|
| 玩家攻擊屬性 × 武器攻擊屬性 | Atk_Power（或 + Atk_Gear） |
| 基礎傷害 + 裝備加成 + 技能加成 | 綜合傷害_raw |
| 怪物防禦屬性／實際傷害 | (1 - mit)，mit = Def_EVit/(Def_EVit+Pen×20) |
| 敵方反擊加成（怪物反擊/玩家防禦） | 併入 mit，或單獨 Counter 項 |
| 命中率（玩家命中/怪物回避） | P_Hit，K_Hit = Atk_EDex/(Atk_EDex+Def_EDex) |
| 元素傷害加成 | Elem_mult（未實裝=1） |
| 狀態效果相互作用 | Status_mult（未實裝=1） |
| 環境影響 | Env_mult（未實裝=1） |
| 暴擊機率／暴擊倍數 | γ 觸發 Crit 或 Crit_mult |
| 連擊 | C_combo（門檻倍率） |
| 狀態異常閾值 CT、觸發異常 | CT_類型，D_Final > CT 則施加 |

## 六、技能編譯與 SkillObject（與詞盤對接）

- **SkillObject**：base_dmg、ap_threshold、qi_cost、resonance_tier、attribute_tags、effects。
- **威力**：詞元能階加總 × α；**消耗**：詞元複雜度 ÷ β；變異受 γ 影響。
- **執行流**：蓄能 (AP) → 檢核 (Qi) → 結算 (Formula) → 回饋 (Log)。

---

## 七、文字戰報標籤與常數

- **戰報標籤**：`[Initiative]`、`[Action:Skill]`、`[Conflict:Crit]`、`[Result]` 等；每輪可 append 先手方、命中、傷害、受擊方、剩餘體感；結束時 append 勝方與「取得了勝利」／「敗下陣來」。**已實作**：`combat.ResolveV2` 產出之 log 含 `[Initiative]`（先手）、`[Action:Skill]`（傷害 N）、`[Result]`（剩餘 M／取得了勝利／敗下陣來）；`[Conflict:Crit]` 留待 γ 暴擊實作。
- **常數**：命中率上下限 0.05～0.95；減傷分母 20；暴擊倍數 1.5；α/β/γ 預設 1, 1, 0 或 0.5, 0.5, 0。全概念預設見 §二。

## 八、與現有 Resolve 的對接

- 現有 `Resolve` 簡化簽名可保留；主流程已改用 **`combat.ResolveV2`**（支援 Terrain、Gamma 暴擊／偏轉）。
- **第一階段（已實作）**：實作於 `combat.ResolveV2`。先手由 Dex 高者；每輪傷害公式同上，並依 γ 判定暴擊（×1.5）或偏轉（0 傷），戰報可含 `[Conflict:Crit]`／`[Conflict:Deflect]`。**戰鬥時依房間地形傳入 Terrain**；**戰鬥結束後 handler 依結果呼叫 `db.UpdateVit` 寫回雙方 Vit**（敗方或雙方扣至剩餘 HP，≤0 則寫 0 視為死亡）。敘事已移除「不扣除氣血」說明。
- **ResolveV2（已實作）**：`ResolveV2(attackerVit, attackerDex, defenderVit, defenderDex, opt *CombatOpt)`；opt 含 **Alpha**（能階）、**Beta**（時脈）、**Gamma**（相位）、**Terrain**（地形標籤：lush／chaos／silent／grip）；nil 時以 §二 預設代入。傷害依 α 與地形乘數（lush=1.15、chaos=1.08）。戰報帶 **§七 標籤**：`[Initiative]`、`[Action:Skill]`（含傷害數）、`[Result]`（剩餘體感／取得了勝利／敗下陣來）。R、狀態異常等未實裝，可後續擴充 opt。
