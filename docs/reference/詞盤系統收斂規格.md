# 詞盤系統收斂規格

> **定位**：收斂層。將散落於詞盤彙整、人物屬性彙整、經濟彙整、361 拓撲規格、星盤迷霧規格、造句概念設計等文檔的詞盤相關設計，合併為一份可執行的閉環規格。標記已定案、有衝突、缺設計三種狀態。
>
> **來源**：設計者與 Claude Opus 對談收斂（2026-03-28）+ 既有文檔交叉比對。

## 一、核心認知校正

### 1.1 詞盤是數學引擎，不是 LLM 系統

詞盤的造句、祭煉、技能編譯——本質是**字庫/詞庫的排列組合 + 品質門檻過濾**，與 LLM 無關。

- 字庫/詞庫 = token vocabulary
- 排列組合 = combinatorial sampling
- 好句入池壞句回爐 = quality gate
- 玩家的詞盤配置（竅穴、詞元、念紋）= 調整 LLM 參數的類比
- 骰出句子 = inference
- 句子效能數值 = output quality

**結論**：詞盤系統完全跑純數學，萬名 NPC 同時運算不吃 LLM 算力。NPC 的 soul_seed 決定其詞盤佈局，佈局決定可組出的組合，組合決定產出品質。

> 狀態：✅ **已定案**（設計者 2026-03-28 確認）

### 1.2 鎂與詞元：同名異源

| | 鎂（貨幣） | 野生詞元（功能物件） |
|--|-----------|-------------------|
| **來源** | 鎂池——機構制度性創造，與人口掛鉤（創角 +10,000 錠）⚠未實裝 | 採集→材料→剝名→結晶→提出（五層管線，見資源點與礦區設計） |
| **屬性** | 無屬性，純交換媒介 | 帶屬性（火、堅韌、疾速等） |
| **用途** | 買賣、附魔/強化消耗、登錄費、打通消耗 | 入竅、附魔、祭煉造句 |
| **性質** | 標準化、可分割、機構記帳 | 功能性、品質分級、不可替代 |

共享「詞元」作為計量單位名稱，但**來源不同、性質不同**。花鎂買麵包不會削弱你，因為你花的是制度貨幣，不是竅穴裡的東西。

> 狀態：✅ **已定案**（設計者 2026-03-28 確認，修正創角配給為 10,000 錠）
> ⚠️ 與詞盤彙整 §一「token 又名詞元，定位世界通用幣最小單位」的措辭有歧義——需更新該段以明確區分制度鎂與野生詞元。

## 二、管路模型：進水口 → 引擎 → 出水口

詞盤系統的運作需要三段管路全部暢通：

### 2.1 進水口：詞元從哪來

詞元的來源是一條**五層管線**（詳見 [資源點與礦區設計](../design/資源點與礦區設計.md)）：

```
採集（場域→材料）→ 剝名（材料→結晶）→ 提出/提煉（結晶→裸詞元，功法決定成數）
```

| 階段 | 說明 | 狀態 |
|------|------|------|
| **採集** | 資源點產出材料（白板物質）。管種類、數量、節奏 | ⚠️ 資源點房間未建立 |
| **剝名** | 材料→詞元結晶（舍利子態）。品階（丙/乙/甲）在此擲骰 | ✅ 概念定案（2026-04-08） |
| **結晶流通** | 結晶可儲存、可交易。僅品階可測，屬性不可知 | ✅ 概念定案（2026-04-08） |
| **提出/提煉** | 結晶→裸詞元。功法決定提取成數（3~9 成） | ✅ 概念定案（機構賦權） |
| **交易** | 結晶或附詞裝備形式流通 | ✅ 概念定案（經濟彙整 §五） |

**兩層品質**：品階（丙/乙/甲，剝名擲骰）× 提取成數（功法決定）= 最終詞元效力。

**瓶頸**：採集是管線入口，但資源點（**在哪採、採什麼、多少量**）尚未落地。這是整條管路的斷點。

### 2.1.1 剝名流程——屍體/肢體態變（2026-03-28 定案）

```
殺死野獸 → [XX 野獸屍體]
              ├─ 剝名（整體）→ 難度高、機率出稀有/高品質詞元 ×1
              └─ 分解 → [XX 野獸肢體] ×N
                          └─ 剝名（肢體）→ 難度低、品質普通 ×1 / 肢體
```

- 屍體態：提供「剝名」和「分解」兩個插座
- 肢體態：僅提供「剝名」插座（不可再分解）
- 整體剝名 = 高風險高報酬；分解剝名 = 低風險穩定產出
- NPC 非觀測狀態下的處置為純公式（性格參數 + 背包狀態決定路線）

### 2.2 引擎：詞盤數學系統

| 環節 | 說明 | 狀態 |
|------|------|------|
| **入竅** | 詞元放入已打通的竅穴，產生特殊加成 | ✅ 規格定案（詞盤彙整 §9.2） |
| **連線** | 多竅穴依拓撲規則連通，觸發額外加成 | ✅ 規格定案（詞盤彙整 §9.3） |
| **造句** | 向量引擎，見 §2.2.1 | ✅ 定案（2026-03-28） |
| **祭煉** | 造句登錄於詞盤，系統判定後生成 SkillObject | ✅ 概念定案（造句概念設計） |
| **品質** | 品質 = 剝名時擲骰結果，非詞元固有屬性 | ✅ 定案（2026-03-28） |
| **疊煉** | 同名詞元疊加灌充能%，滿 100% 擲骰昇華 | ✅ 定案（2026-03-28），見 §2.2.2 |

#### 2.2.1 造句系統——向量引擎（2026-03-28 定案，同日修訂為向量制）

造句驗證與效果計算基於 **pgvector 語義向量**，不查表、不用 LLM。

**核心機制**：

1. 每顆詞元有一段 `desc` 批註（例：「利刃橫過的一瞬」），這段文字**就是該字在本世界的語義定義**
2. 用本地 Ollama bge-m3 對 500 段 enriched desc 各跑一次 embedding（1024 維），拼接 6 維手標遊戲維度（atk/def/spd/dot/aoe/heal），得 **1030 維混合向量**，存入 pgvector（一次性成本，之後不再需要 LLM）
3. 玩家選字組句 → 將所有詞元的向量加總/平均 → 得到**句向量**
4. 句向量本身就是技能效果——向量的每個分量是隱式維度（攻擊性、防禦性、速度感、持續性等，由 embedding 自然學得）
5. 句向量的模長/方向決定技能威力與類型，無需手動定義「攻」「防」等維度

**為什麼用 desc 而不是字本身**：
- 「斬」一個字丟進 embedding 太短，語義模糊
- 「利刃橫過的一瞬」精準描述了這個字在本遊戲世界中的含義
- desc 是人工撰寫的語義定義，embedding 將其轉為數學表達——**文字定義 → 向量 → 遊戲數值，全鏈自動化**

**句式長度與精準度**：

| 字數 | 對應 | 效果 |
|------|------|------|
| 三字 | 三字經 | 籠統加成（例：「吾飛也」→ 簡易速度加成） |
| 五字 | 五言句 | 聚焦特定面向（例：「吾奔飛速也」→ 敏捷/移動/閃避加成） |
| 七字 | 七言詩 | 高度精準複合效果（例：「吾奔如雷飛速也」→ 行動/閃避/搬氣多重加成） |

**讀得通 = 給過**。文言文單字即意，國文有上課就不難組句。玩家以為自己發現了新句子，實際上句向量早已在向量空間裡有其位置。

**向量距離 = 技能差異**：
- 兩個句向量距離近 → 類似的技能
- 換一顆詞元 → 句向量偏移 → 效果連續滑動，不是離散跳變
- 「銳·斬·弧」和「堅·盾·殼」在向量空間裡自然落在攻擊區和防禦區的對角

**新增詞元零成本**：寫一句 desc → 跑一次 embedding → 自動找到向量空間中的位置，不用回頭調任何公式。

**技能命名**：從句中按語義類抽取核心字組合（公式命名，見 `data/config/sentence_engine.json`）。

**十類語義**（詞元池 500 顆，見 `data/config/word_elements.json`）：

| 語義類 | 角色 | 數量 | 句法位置 |
|--------|------|------|----------|
| 主（本命） | 主詞 | 20 | 句首，決定「誰」 |
| 屬 | 形容詞 | 80 | 修飾語 |
| 動 | 動詞 | 70 | 核心語 |
| 受 | 受詞 | 60 | 目標語，決定作用對象 |
| 構 | 名詞/框架 | 60 | 承載語 |
| 態 | 副詞/狀態 | 70 | 效果語 |
| 補 | 補語 | 70 | 結果/程度語 |
| 助 | 語氣詞 | 30 | 改變句性 |
| 否 | 否定詞 | 20 | 反轉語義 |
| 玄 | 元參數 | 20 | 不入句，改擲骰本身 |

#### 2.2.2 疊煉系統（2026-03-28 定案）

詞元本身無品質之分。品質 = 剝名時擲骰的結果（丙/乙/甲）。

**同名詞元可疊煉**：灌充能百分比，滿 100% 嘗試昇華。

```
丙(0%) + 丙 → 擲骰 → 成功：丙(+n%) / 失敗：跌幅擲骰
...反覆灌充能...
丙(100%) + 丙 → 擲骰昇華 → 成功：乙(0%) / 失敗：跌回 x%
```

所有數值皆擲骰：
- 成功率：擲骰（基底建議 50%）
- 漲幅：擲骰（建議 5%~25%）
- 跌幅：擲骰（建議 0%~15%，含不跌的可能）
- 昇華成功率：擲骰（基底建議 30%）
- 昇華失敗跌幅：擲骰（建議跌回 60%~80%，保底投入）

**玄類詞元（幸、運等）的作用**：入竅後修改擲骰參數本身——成功率偏高、漲幅偏大。玄類詞元不入句，入骰。

**設計意義**：
- 沒有廢物詞元——每顆丙級都是疊煉燃料
- 取捨點無處不在：丙(60%) 繼續灌？止盈鑄鎂？還是賭下去？
- 交易市場：丙(95%) 與 丙(0%) 完全不同價

### 2.3 出水口：詞盤配置影響什麼

| 影響面 | 說明 | 狀態 |
|--------|------|------|
| **戰鬥** | α/β/γ 係數、有效體敏氣 | ✅ 已接線（combat wiring） |
| **採集效率** | 詞盤頻率 → 與資源的共振 → 品質偏好 | ❌ **缺設計** |
| **環境耐受** | 頻率 → 聚念場貢獻 → 荒野生存能力 | ❌ **缺設計** |
| **社交相容** | 頻率相近 → 同頻相斥效應 | ❌ **缺設計** |
| **技能** | SkillObject 讀取 | ✅ 概念定案（造句概念設計） |

**現狀**：出水口只接了戰鬥一條。頻率→世界互動的設計只停在概念層。

## 三、詞元的三叉路口

每一顆帶屬性的詞元到手時，玩家面臨三條路：

| 選擇 | 效果 | 性質 |
|------|------|------|
| **入竅** | 改變自身頻率，永久影響與世界的關係 | 永久、不可逆（或高代價逆轉） |
| **附魔** | 強化裝備，提升眼前戰力 | 半永久，隨裝備更替而消失 |
| **鑄鎂** | 換成貨幣，今天能活 | 即時消耗，詞元屬性永久喪失 |

**品質加深取捨**：
- 低品質：鑄鎂不心疼
- 中品質：附魔堪用
- 高品質：入竅？附魔？還是賣天價？

> 狀態：✅ **概念已定案**（設計者 2026-03-28 確認）
> ⚠️ 「鑄鎂」的具體機制未設計——在哪裡鑄？需要什麼條件？兌換比例？

## 四、頻率與世界的關係（新收斂概念）

> 來源：2026-03-28 對談。此概念串連詞盤配置與聚念場悖論。

### 4.1 詞盤配置 = 頻率簽名

每個角色的詞盤配置（哪些竅穴開了、裝了什麼詞元、念紋三軸）構成其**頻率簽名**。

### 4.2 頻率的本質校正（2026-03-28）

> **「高頻」是有念生物的物種屬性**，不是修煉程度。Token 混沌能量 ≈ N 級磁場，有念生物天生也是 N 級磁場，所以同頻相斥是天生屏障。修煉改變的是頻率簽名的細節（竅穴佈局、念紋三軸偏移），不是讓你「變得更高頻」。

| 傾向 | 特徵 | 優勢 | 劣勢 |
|------|------|------|------|
| **高頻傾向**（竅穴多、念紋密） | 聚念場貢獻大 | 城市安全、社交強、NPC 友善 | 同頻相斥強→採不到資源 |
| **低頻傾向**（精簡、止念修行） | 聚念場貢獻小 | 能汲取 Token、進危險區、高品質詞元 | 缺少聚念場庇護、環境危險 |

### 4.3 專精正回饋與陷阱

火系竅穴越深的人，越容易辨識高品質火詞元——**專精越深，對應資源越好**。但專精越窄，同頻相斥越強，能去的地方越少，能採的類型越限縮。

> 狀態：⚠️ **概念收斂但規格缺失**——頻率如何量化？影響哪些具體數值？門檻在哪？
