# 房間與街道描述：架構與流程

給**自己**與**協作／AI** 的備忘：如何架構房間與街道、以及如何下指令，才不會寫出九段同一幅畫面的描述。

---

## 工作流程（兩階段）

### 第一階段：一段一段完成

- 每段（或每棟建築）**先把房間、出口、物件都建好**。
- 描述可先求有、不求完美；用佔位句也無妨。

### 第二階段：回頭總視整體架構，重修畫面

- 整條大街（或整個區域）**都齊了之後**，從頭檢視所有段落的 `description`。
- 依整體節奏（例如：街口 → 漸深 → 墟心 → 夾道 → 店宅交錯 → 漸靜 → 大建築 → 收束 → 阻斷）調整各段環境描寫。
- 目標：**飾辭更貼切、有漸變、不重複**——讀起來是「走過去環境在變化」，而不是同一句複製九次。

---

## 描述原則（總視時用）

- **同一條街多段**：路面、光感、空間感要有漸變，避免每段都同一開頭（例如「暗紫路面延伸至此，兩側玉質脈絡自縫隙沁出…」）。
- 總視時對照**相鄰段**與**整條軸線**，改寫 description。

---

## 下指令範例（給 AI 或自己用）

- 「先做第 X 段／先做這棟建築，**做完再一起總視整條街重修畫面**。」
- 「整條浮生大街都齊了，**總視一下整體架構，重修各段描述讓畫面有漸變**。」
