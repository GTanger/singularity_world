## 一、命名與定位

**霜林小徑**是一條**被人走出來的痕跡**，從**飛霜湖北岸**出發，往森林深處漸去的徑路。與飛霜大街、飛霜湖同屬「飛霜」環境：**霜白結晶飄落、游離輻射下熱氣不散、地熱與冷氣交會**。命名來自「霜」與「林」——林道間落霜、晶簇、霧氣與地熱並存，**勿以「下雪」解釋**，與飛霜大街一致。

- **空間定位**：自北岸（湖背）入林、往森林深處漸去的**人跡徑路**；可為單一入口房，或主徑＋側枝等擴充。入口與飛霜湖北岸（fei_lake_north）銜接。
- **與他區關係**：飛霜湖北岸（fei_lake_north）設出口「霜林小徑」→ 霜林入口房；霜林為**離開湖區往林徑**的支線，不取代環湖四岸與水際。

## 二、環境概念：林道、霜晶、地熱與富態化

**林相**：飛霜湖畔自**東北、西北邊**開始是**稀疏的樹林**，漸行漸深，是**茂密的森林**、也是**幽靜的深林**。霜林小徑即自北岸穿過此一梯度往深處而去。

**起點**：自北岸入林，人跡走出的徑路仍帶湖氣與濕潤熱氣；地面細碎白霜與枯葉、兩側樹木稀疏仍具森林輪廓。  
**往深處**：地勢抬升、地熱與寒氣交鋒（嘶嘶聲、礦物味）；鉛皮陡坡、黑岩瓶頸、暖煙斷層、晶化脊徑等可作為主徑段落的視覺辨識。  
**富態化**：晶簇、菌絲、導熱石板、白玉坪、巨木合圍、落霜在半空盤旋；熱氣均勻擴散、積霜觸地即融。林道仍為**可穿越的徑路**，非廢墟或死地，與世界觀「富態生長、平衡拉鋸」一致。

**一句話**：霜林小徑 = **被人走出來的痕跡，自飛霜湖北岸出發、往森林深處漸去的徑路；霜晶與地熱並存，富態化後晶簇、導熱石、巨木與落霜並存，林道可辨、可走，勿寫下雪或神聖／死寂結論**。

## 三、撰寫要點（供房間描述對齊）

### 3.1 建議語彙與畫面

| 項目 | 建議語彙／方向 |
|------|----------------|
| **霜與氣** | 霜白結晶、落霜、細碎白霜、積霜觸地即融、霜粉、水氣凝成細霜；湖氣、濕潤熱氣、地熱、熱氣自縫隙或斷層溢出、熱氣與落霜交會、游離輻射下熱氣不散 |
| **林道與地景** | 林徑、主徑、側枝、枯葉、樹根盤踞、巨木合圍、枝幹垂掛晶簇、鉛皮陡坡、黑岩瓶頸、暖煙斷層、晶化脊徑、白玉石板、導向石柱 |
| **光與材質** | 冷調石紋、晶簇、菌絲、鏽斑與晶簇、熱氣折射、晶體棱面折射、導熱均勻、石板縫隙 |
| **聲與觸** | 地熱與寒氣交鋒的嘶嘶聲、腳步聲、風穿林隙、足底石面沁涼、地表乾燥或濕滑 |

### 3.2 勿寫（對齊房間與建築設計規範 §3）

- **氣候**：勿寫「下雪」「雪景」；僅用霜、落霜、霜晶、湖氣、地熱、游離輻射等可驗證感官。
- **主觀結論**：勿寫「神聖」「聖潔」「寂靜得近乎神聖」「景觀磅礴」「視野極度開闊」「絕佳制高點」「視覺感受極其通透」；勿寫「環境物理規律已完全受控」「徹底脫離凡間森林的範疇」。
- **XX 感**：勿寫「極致的空曠感」「高度感與空間感達到極致」「空氣感極致純淨」「時間與空間感模糊」「死寂」「靜滯」；可改為具體的「風在石縫間迴盪」「熱氣均勻擴散」「足底石面沁涼」。
- **物性／秩序**：勿寫「物性穩固」「秩序感」「呈現／展現＋主觀結論」；可寫「巨木合圍」「石板平整」「導向石柱若隱若現」。

### 3.3 文筆與字數

- 房間 description **主體**（「可經…」之前）**至少 50 字**；同一區域內描述不可與他房重複，句型與飾辭須有區隔。
- 文風：**台灣暢銷作家筆觸**——下筆有神、詞藻如畫；一句入畫，讀完即有畫面。只寫可被五感或具體狀態驗證的內容，主觀感受由玩家自行產生。

## 四、連結拓樸與 id 約定

### 4.1 對外銜接（與飛霜湖）

霜林小徑自**飛霜湖北岸**出發、往森林深處漸去，故**入口僅接北岸（湖背）**。

- 連結：fei_lake_north ↔ 霜林入口房（雙向）。
- 霜林入口房須設出口返回 fei_lake_north；北岸房須設 object〔霜林小徑〕，move_to_room_id 指向霜林入口房 id。

### 4.2 霜林內部拓樸（可選擴充）

- **最小實作**：單一「霜林入徑處」房間，僅與 fei_lake_north 雙向；描述帶出人跡徑路、林徑、霜晶、湖氣餘韻即可。
- **擴充**：主徑 fs_trail_01～10（或 fei_wood_trail_01～10）線性相連，每段可帶側枝 fs_wood_xx、終點接霜林奧所（fs_cabin_05 等）；拓樸須與 [房間與建築設計規範](房間與建築設計規範.md) 結構多樣化一致，且描述改寫後符合 §3 禁止用詞與 50 字。

**id 建議**：  
- 霜林 zone 可沿用「霜林」或英文 fei_wood；房間 id 現行沿用 fs_trail_01、fs_wood_xx、fs_cabin_xx，可選改為 fei_wood_trail_01、fei_wood_01_01 等與飛霜湖 fei_lake_* 前綴呼應。  
- 若僅實作入口一房，id 建議 fei_wood_gate 或 fs_trail_01，與設計文檔一致。

## 五、主徑與側枝意涵（沿用自舊版設計）

**主徑意涵**：現行主徑**十格（fs_trail_01～10）象徵行徑的深度、遠度**——每格代表往森林深處再進一程。

**側枝意涵**：每個小徑段週邊的**延伸／連接格**（如 fs_wood_xx）用來**描繪當前小徑周邊的環境**，使該段小徑的環境更加立體、鮮明；側枝＝當前段落的環境補筆，非單純岔路。
