# 借物與戰鬥意圖 — 用語與系統草案

> **狀態**：用語已定案；**Borrow／Subdue／Slay** 已接 `do_action`；留人以 `CombatOpt.Subdue` 氣血保底實作（見 [死亡與昏迷—規格](死亡與昏迷—規格.md)）。歸屬／看守／獨立昏迷欄位可後續擴充。  
> **關聯**：[世界物流規格—草稿](世界物流規格—草稿.md)（Trade 為合意交換；本檔之「借物」為非合意取物）、[戰鬥系統概念](戰鬥系統概念—三版融合.md)（數值面另對齊）。

## 一、借物（非合意取物）

### 1.1 定案用語

| 層級 | 用語 | 說明 |
|------|------|------|
| **玩家可見動作名** | **借物** | 不直稱「竊／盜」；世界內可敘為「此方俗諱，謂不告而取為借」。 |
| **程式插座** | `Borrow` | 與 Trade、`Subdue`、`Slay` 並列；敘事與日誌用中文「借物」。舊客戶端 `Attack` 由後端視為 `Slay`。 |

### 1.2 意涵與邊界

- **與 Trade 對照**：Trade 為雙方合意、鎂與物之原子交割；**借物**為單方在規則允許下嘗試移轉占有（成敗另論）。
- **與「物」的關係**：須有可標的之物（背包格、身上槽位、場所歸屬物等）；**不**將「僅遮蔽衣物」等劇情豁免物納入可借清單，除非專案另開例外表。
- **與第五波銜接**：歸屬權、看守者、四下無人（11.8）決定**可否嘗試**、**被發現後果**；本檔只鎖定**動作命名與獨立行為標籤**，不替代 11.8 規則。

### 1.3 小系統應含（實作勾選）

- [x] 插座 `Borrow`：同房實體；自對方背包取第一筆 `qty>0`（與 Trade 選品邏輯同源）；成功／失手／喝破三分支＋`NpcBehaviorReactionLine`。
- [ ] 目標擴充：容器／場所物、歸屬／看守（11.8）；喝破後**自動開戰**尚未接。
- [x] 事件型別字串 `borrow`／`borrow_fail`（與 Trade 分開）。

## 二、攻擊分為兩種意圖：制伏與致死

### 2.1 定案用語（與「借物」同格：**婉而直接**）

**三位一體（介面顯示）**：**借物**／**留人**／**送行**

| 意圖 | **定案顯示名** | **建議插座 id** | 意涵 |
|------|----------------|-----------------|------|
| 制伏 | **留人** | `Subdue` | **留**在當場（放倒、昏迷、綑綁等），意圖**不送其上路**；不直書「制伏／擊暈」，但一聽即明。 |
| 致死 | **送行** | `Slay`（或語意貼字時 `SeeOff`） | **送**其一程；俗諱中常指最後一程，**婉而直接**。與「留人」成 **留／送** 對仗。 |

**對仗說明**：借物＝不告而取；留人＝不送走、先留下；送行＝送其上路。規格內文與平衡討論仍可用「制伏／致死」指稱兩意圖。

### 2.2 備選（曾討論或 NPC 台詞變體）

| 制伏（備選） | 致死（備選） | 語感 |
|--------------|--------------|------|
| 切磋 | 了斷 | 江湖套語 |
| 留情 | 奪命／索命 | 一硬一婉 |
| 點到 | 見血 | 武術向 |
| 放倒 | 了結 | 口語直白 |
| 留住 | （—） | 偏扣留敘事 |

### 2.3 小系統應含（實作勾選）

- [x] `Subdue`／`Slay` 插座與前端【留人】【送行】；`Attack` 請求後端映射為 `Slay`。
- [x] 留人：`ResolveV2` + `CombatOpt.Subdue`，將敗方 HP 保底為 1；送行：敗方可至 0 並觸發 NPC 死亡除名（見死亡與昏迷規格）。
- [x] 同一傷害管道、分支結束條件不同；NPC 好感 `FavSubdue`／`FavSlay` 分開。
- [x] 敘事前綴「意在留人／意在送行」；留人後 `NpcBehaviorReactionLine`（`subdue_victim`／`lost_subdue`）。
- [ ] 獨立 `unconscious_until` 欄位、甦醒 tick（可後續）。
