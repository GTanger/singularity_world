# 世界觀 — 邏輯閉環檢視

> **用途**：檢視 Token／富態／剝名／器物／無車／電子 等背景世界觀是否邏輯自洽、因果閉合。對應文件： [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md)、[世界觀：富態與拉鋸](世界觀：富態與拉鋸.md)、[世界觀附篇—電子與精密機械](世界觀附篇—電子與精密機械.md)、[詞盤彙整](詞盤彙整.md)。

---

## 一、主鏈閉合

| 環節 | 因果 | 閉合狀態 |
|------|------|----------|
| **Token → 無念物質** | Token 輻射（游離輻射）使無念物質富態化 | ✅ 本體論（§一）與富態（§二）一致 |
| **有念 → 相斥** | 有念生物高頻、與 Token 同質故相斥，無法直接引入混沌 | ✅ 止念才能汲取微波（§二、三） |
| **降維 → 星盤** | 混沌輻射降維成有序態 → 引入體內 → 生之奇點 → 星盤 | ✅ §五與詞盤／361 對接 |
| **剝名 → 詞元** | 富態化物／獸 → 提煉→有序化（已降維）→ 詞元附著 → 人類提取 → 載體崩解 | ✅ 與詞盤「剝下的名＝帶屬性詞元」一致 |
| **附詞 → 穩定** | 詞元＝有序能量、與提煉者同頻；附詞＝附上有念頻率 → **阻隔游離輻射** | ✅ 有念「較不易受 Token 影響」、可「干擾阻隔輻射」（富態§二）→ 有念頻率附著器物即屏蔽 |
| **調頻** | 穿戴者／購買者靠己念調頻，使附詞裝備與自身同頻 | ✅ 與詞盤「共鳴」、裝備與內盤相容一致；不影響「阻隔」存在 |
| **無車／電子** | 機械＝無念、零件多無法一一附詞；電子低頻易受輻射→街面／野外**高精密常態佈設**少；**強聚念場內**（如城鎮建物）日用電器可正常，見附篇「聚念場內」 | ✅ 與白板不穩、附詞必要同一邏輯；與無車（戶外載具）不矛盾 |

**結論**：主因果鏈閉合。游離輻射＝Token 散發的輻射（本體論 §一），無念物質受其影響；有念頻率可阻隔；剝名產出有序詞元；附詞使器物穩定；無車與電子伏筆同源，**聚念場＋綠護**另闢城內日用敘事空間。

## 二、用語與邊界

- **游離輻射**：與「Token 散發的輻射」同義，本體論 §一 已涵蓋；富態／§九／附篇 沿用，無歧義。
- **名／詞元**：詞盤「剝下的名帶屬性＝詞元」；世界觀 §九「有序化後呈現詞元、附著舍利子／結晶」→ 剝下的名即詞元載體，一致。
- **精怪野獸**：可剝名、其身混沌能量可提煉；與「有念生物」不衝突——野獸可有念，但其身／能量仍可被當作提煉對象，剝名邊界為「人對人不可、對獸對物可行」（詞盤、陽光奇點）。

## 三、可選補強（非缺口）

1. **飛霜大街**：打鐵巷熱氣＋游離輻射→熱氣不散→霜白結晶。可視為「輻射對環境（含氣流）的影響」之延伸，與「輻射使無念物質富態化」同屬「輻射影響物質／能量」，已閉合；若希望更明確，可在飛霜大街概念檔加一句「游離輻射干擾熱氣消散」。
2. **精怪野獸與有念**：若日後需嚴格區分「可剝名對象」與「有念強度」，可在詞盤或世界觀補一句：剝名對象為物或獸，其身形／能量受富態化或含混沌成分，故可提煉；人對人剝名 token 無反應。目前邏輯已足。

## 四、延伸設定建議（可選）

以下與現有因果鏈相容，可依主線／玩法需要擇用或改寫。

| 方向 | 要點 | 與現有邏輯接點 | 建議落腳 |
|------|------|----------------|----------|
| **運輸與載具** | 無車已定；可明說**獸拉、船、人力**為常態。船若木主體＋少數金屬件可附詞，水路比精密機械可行；馴獸若有念、與人調頻或契約，可當運輸。 | 無念機械不穩、零件多不經濟；有念／附詞穩定 | 富態與拉鋸或新短條「移動與運輸」；房間描述用「騾車、渡頭、挑夫」等 |
| **遠距通訊** | 電子／精密機械少見→**無無線電、無網路**。通訊靠信使、烽火、口傳；或「詞元傳訊」「共鳴感應」（有念者間短距感應）等需再定義的設定。 | 電子附篇「聚落少見高精密機械」 | 世界觀附篇—電子與精密機械 補一句「遠距通訊以人與物為媒介」；玩法若需要再開通訊細則 |
| **地景與輻射** | 飛霜大街＝熱氣＋輻射→霜晶；可類推：**沙漠綠洲**（輻射＋水脈→奇異植被）、**沼澤霧**（輻射＋濕氣→凝滯霧帶）、**礦脈微光**（富態礦物發光）。 | 游離輻射影響環境、富態拉鋸、惡地亦有生機 | 富態與拉鋸 §三 或 map_terrain_world；房間描述時可引用 |
| **建築與穩定性** | 富態化下根鬚咬合、玉質脈絡爬牆——**新建築如何不崩**？可選：奠基儀式、關鍵結構處「奠基詞元」、或純粹依拉鋸（長成支撐即穩）。 | 平衡拉鋸、文明與增生並存 | 富態與拉鋸 一筆即可；若主線涉及築城／據點再細化 |
| **精怪／飛升者譜系** | 從「可剝名野獸」到「飛升者（降維失敗殘骸）」之間：**半有序精怪**、或「曾有人念的遺留物」是否存在？可作劇情／敵人層級用。 | 剝名對象、飛升者起源 | Token降維 §四 旁或新附篇「精怪與飛升者譜系」 |
| **電子伏筆落地** | 聚落少見高精密機械，但**邊緣、廢墟、禁地**是否殘留「已具自主意識的機械／電子」？敵、友、或中立探索目標。 | 世界觀附篇—電子與精密機械 | 同附篇補「聚落外／廢墟內可能遭遇」；主線或副本再決定登場形式 |
| **療癒與詞元** | 剝名取詞元、附詞穩器物；**富態化植物／礦物**是否可提煉「療效詞元」？或止念／調頻用於療傷（與星盤、竅穴接）。 | 詞元分類、剝名、內盤 | 詞盤彙整 詞元分類或裝備／消耗品；若無療癒玩法可略 |
| **機構賦權** | 鎂經機構賦權、不從剝名取得；**機構如何賦權**？是否與世界詞盤／儀式連結？可只做敘事厚度、不動經濟閉環。 | 詞盤機構詞盤、經濟彙整 | 詞盤彙整 §二 或短條「機構與賦權」；NPC 對白／任務可引用 |

**使用方式**：先選 1～2 項與當前主線或地圖最相關的補上；其餘留待需要時再擴，避免一次擴太多造成不一致。
