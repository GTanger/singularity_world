## 五、二巷・三巷 — 結構差異（室與連結）

**目的**：每棟建築房間數有多有寡、連結方式不同。約定：「→」表示該室有出口至某室；lane 表示通往巷道。

### 二巷・五商（連結摘要）

- **鐵脊鋪**：storage 僅 → living（不通 main）；main 無 storage 出口。
- **焰心鋪**：多 quench → workshop；workshop → quench。
- **砧聲鋪**：無 workshop2、toolroom；main → workshop, storage, courtyard。
- **熔流鋪**：無 workshop2；toolroom 改 mold_room → workshop。
- **鍛骨鋪**：無 workshop2、kiln、toolroom；單一工間、小爐在工間內。

### 二巷・五宅（連結摘要）

- **灰磚宅**：標準 main ↔ hallway ↔ living/courtyard。
- **窄廊宅**：無 courtyard。
- **簷角宅**：多 storeroom → hallway。
- **石階宅**：main 階下通 courtyard、上階到 hallway；courtyard 僅通 main。
- **巷尾宅**：無 hallway；main → living, courtyard。

### 三巷・四商（連結摘要）

- **鍛錘鋪**：無 workshop2；toolroom → workshop。
- **爐膛鋪**：多 flue_room → kiln；kiln → flue_room。
- **鐵屑鋪**：無 workshop2、kiln、toolroom。
- **風箱鋪**：main 另通 kiln；kiln → main, workshop。

### 三巷・二宅（連結摘要）

- **簷下宅**：標準連結。
- **巷底宅**：無 hallway；main → living, courtyard。

## 六、二巷・三巷 — 描述要點（感官與差異）

**原則**：只寫可被五感或結構驗證的內容；禁止物性／秩序感／XX感。見 [房間描述寫作規範—禁止主觀腦補](../prompts/房間描述寫作規範—禁止主觀腦補.md)、[世界觀：富態與拉鋸](世界觀：富態與拉鋸.md)。

### 二巷・五商

| 建築 | 差異要點（描述時抓這些） |
|------|--------------------------|
| **鐵脊鋪** | 專做脊狀鍛件、樑扣、結構件。櫃上成排掛著彎曲的脊條與扣件；牆面脈絡粗、像筋骨；鐵腥裡帶一點礦石粉味。 |
| **焰心鋪** | 爐火最旺、焰色偏藍紫。櫃區多刃具與小件；熱浪撲面、簾隙透出的是亮色火光；炭味重。 |
| **砧聲鋪** | 砧聲清脆、常聞敲打。櫃上多半成品與訂件、標了繩結；地面鐵屑多、掃成堆；牆面脈絡細碎像敲痕。 |
| **熔流鋪** | 做澆鑄、熔料。櫃區擺模具與鑄坯；空氣裡金屬液與焦土氣味；牆根有凝住的滴痕。 |
| **鍛骨鋪** | 做骨狀飾件、細工。櫃上精細小件、燈具少、靠縫隙礦光；室內偏暗、安靜。 |

### 二巷・五宅

| 建築 | 差異要點 |
|------|----------|
| **灰磚宅** | 灰磚為主、縫隙苔衣少；門廳窄、廊道短；住家氣息重、灶煙味。 |
| **窄廊宅** | 廊道特別窄、僅一人側身過；牆高、光從簷隙一線照入。 |
| **簷角宅** | 簷角低、小院被簷遮去大半；陰涼、地面苔衣厚。 |
| **石階宅** | 門廳有石階上抬、小院低一階；高差分明、階緣玉質脈絡沁出。 |
| **巷尾宅** | 靠二巷盡頭、風道聲稍大；牆面熱氣殘留少、較涼；門板薄、風灌得進。 |

### 三巷・四商

| 建築 | 差異要點 |
|------|----------|
| **鍛錘鋪** | 大錘為主、砧大；櫃上多農具、粗件；敲擊聲沉、地面震感。 |
| **爐膛鋪** | 爐膛深、火口大；做大型件；熱氣最重、煙道聲低鳴。 |
| **鐵屑鋪** | 鐵屑堆積多、掃成小丘；做修補與零活；地面多碎料、腳下沙沙響。 |
| **風箱鋪** | 風箱顯眼、拉風聲響；爐火靠風旺；空氣流動感強、簾子常被吹動。 |

### 三巷・二宅

| 建築 | 差異要點 |
|------|----------|
| **簷下宅** | 簷深、門廳在簷下；簷角滴水槽明顯、雨時有聲；牆根較潮、苔綠。 |
| **巷底宅** | 緊鄰巷尾出口、熱風從背後來；門朝飛霜方向、較涼；門檻高、防風灌。 |
