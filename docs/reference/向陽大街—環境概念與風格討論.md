# 向陽大街 — 環境概念與風格討論

> **用途**：供向陽大街房間描述、場景敘事與動線撰寫對齊。須符合 [世界觀：富態與拉鋸](世界觀：富態與拉鋸.md)（富態生長、平衡拉鋸、無廢土感）。房間設計與分配來源：`data/rooms_archive/向陽大街/`。

---

## 一、原始設定概念：講究採光、光明敞亮

向陽大街的**原始設定**即為：大街與建築**較講究採光**，風格走**光明、敞亮**的設計。街道寬闊、間距較大，建築與街道從一開始就以引光、納光為考量，整體氛圍開敞明亮，與梧桐大街的綠蔭掩映形成明確對比。

---

## 二、定位：四大街中採光與光能最鮮明

在四大街中，向陽大街**採光與光能意象最強**。此一特質來自上述原始設定，並在後述「長年富態化」推論中延續、強化，而非被覆蓋或廢土化。

---

## 三、長年富態化後的環境推論

**起點**：講究採光、光明敞亮——寬闊、向陽、光霧稀薄、石板明亮、建築納光。  
**富態化**：能量過剩導致光能採集、礦物玉質／琉璃化、金屬與建材咬合；平衡拉鋸下，增生不吞噬文明，**原有的光明敞亮得以保留甚至被「光能化」強化**，無廢土感。

推論結果：

- **光與空氣**：背景光霧稀薄、**空氣流速較快**；游離輻射帶來**密集金光**、琥珀與淡金微光，自高空或稜鏡垂落。**低飽和、持續存在的微光**仍適用，但整體比梧桐大街更**明亮、開敞**，非陰翳綠廊。
- **地面**：**拋光白玉**、石板色澤明亮整潔，地表可見能量流動留下的**淺色紋路**；縫隙可有發光菌絲或能量導線，與結構咬合而非吞噬。
- **簷角、牆垣**：**大面積稜鏡外牆**、落地窗、**向陽拱頂**；光線層次分明，室內家具常見深色重金屬、緻密黑木、油脂質感皮革，與玉質／琉璃嵌合。**光影層次分明**，非廢墟感。
- **氛圍**：**溫潤沉香**、能量微粒懸浮、觸感**冰冷平滑或飽滿**；空間感飽滿、靜謐而帶光感。**「光一直在被採集、被導引，但沒把我們曬乾」**：文明與光能增生並存，從容。
- **人跡**：大街仍是大街——凡人照常行走、市集照開、簷下照樣有人。風情是**開敞、明亮、光能可見**，與梧桐的「綠意掩映」形成對比。

**一句話**：向陽大街 = **原本就講究採光、光明敞亮的一條街；長年富態化後，光能與材質咬合，成向陽拱頂、白玉地面與稜鏡導光、金光與能量紋路可見，依然開敞明亮、無廢土感**。

## 七、四大街一句話與風格對照

**四大街一句話**：向陽有光，梧桐有蔭，飛霜乘風，浮生隨遇。

### 與梧桐大街的風格對照

| 維度 | 梧桐大街 | 向陽大街 |
|------|----------|----------|
| 主視覺 | 綠意、濃蔭、綠廊拱頂、枝葉蔽天 | 金光、白玉、稜鏡、向陽拱頂、開敞 |
| 光感 | 光線篩落、低飽和微光、簷角掩映 | 密集金光、光影層次分明、光霧稀薄 |
| 材質 | 根鬚咬合、玉質脈絡、石磚與菌絲 | 拋光白玉、稜鏡外牆、金屬與黑木、能量紋路 |
| 空氣 | 沉香、膠質氣味、懸浮綠微粒 | 溫潤沉香、能量微粒、空氣流速快 |
| 氛圍關鍵句 | 靜謐的豐饒、文明與增生並存 | 開敞明亮、文明與光能並存、靜謐光域 |

四街皆須符合**富態與拉鋸、無廢土感**；差異在向陽偏**光**，梧桐偏**蔭**，飛霜偏**風**，浮生偏**隨遇**，向陽的**原始設定即為講究採光、光明敞亮**。

## 八、房間設計與遷移備註

**遷移時格式須對齊 [data/rooms/README.md](../../data/rooms/README.md)**，要點如下：

| 項目 | 對齊內容 |
|------|----------|
| **一房一檔** | 每房一個 `.json`，檔名不以 `_` 開頭；內容 2 空格縮排（pretty-print）。 |
| **id 規則** | 第一層前綴 `sunst01_`～`sunst09_`（段別，對應 zone 代碼 sunstreet）；第二層建築類型與編號（hold01／home01／shop01 等）；第三層房間（main／02／語意名）。與 README「前綴第一層 = zone 英文代碼」對齊。 |
| **根層欄位** | 必填：`id`、`name`、`description`、`exits`；選填：`tags`、`zone`、`objects`。 |
| **exits[]** | 每項含 `direction`、`to`（目標房間 id）；可設 `ui_hidden: true`。exits 保留完整供 NPC 尋路。 |
| **objects[]** | 可移動出口須有 `sockets`（含 `Move`）、`move_to_room_id`、`responses.Move`；`name` 須與 description 內 **〔〕** 標記一致，供前端點擊觸發移動。 |
| **description** | 可互動物件以 **〔名稱〕** 標記，與 `objects[].name` 一致。 |
| **目錄結構** | 第一層依 zone：`向陽大街/`；第二層依建築／區域分子目錄（如 `向陽大街一段/光樞管理處/`、`向陽大街五段/流光採集廣場/`）。 |
| **zone** | 遷移後統一為 `sunstreet`。 |

- **材質與氛圍**：白玉、稜鏡、金光、能量紋路、向陽拱頂、沉香、油脂質感皮革、深色金屬與黑木、光影層次。
- **內間命名**：建議採台灣慣用語意名（前間、裡間、櫃前、庫房等），與梧桐大街命名原則一致。
