# 房間與建築設計規範（彙整）

> **用途**：新增或擴充大街／建築、撰寫房間與街道描述時須遵守的單一規範。與 [世界觀：富態與拉鋸](世界觀：富態與拉鋸.md)、各大街環境概念文件並用。

---

## 一、建築與結構

### 1.1 建築結構連結要不同

- **新增建築時，內部房間的連結拓樸（圖論結構）須與既有建築相異。**
- 避免多棟建築皆為同一種結構（例如全是「門廳 → 02 → 03 → … → N」的線性鏈）。
- 可採：線性鏈、星狀（門廳連各內間）、環狀（內間首尾相連）、枝狀／樹狀等，使每棟在**結構簽名**上可區分。
- 實作與檢視可參考：梧桐大街結構多樣化腳本與地圖檢視器。

---

## 二、描述內容

### 2.1 描述不可重複

- **同一區域內（同一大街或同一建築群），房間的 description 主體（「可經…」之前的主文）不可與其他房間重複。**
- 同一句描述、同一慣用結尾（如「粉塵無聲沉降」「脈絡如呼吸浮動」）不得在十數格以上反覆出現；應替換為多樣表述或刪除。
- 總視整區時確保飾辭有漸變、不重複。

### 2.2 主體至少 50 字

- **房間 description 的主體部分（「可經…」之前）至少 50 字（字元數）。**
- 「可經〔…〕前往他處」及其後不計入主體字數。
- 不足 50 字時須以不重複的補句或擴寫補足，並維持文筆與世界觀一致。

### 2.3 文筆：台灣暢銷作家筆觸，下筆有神，詞藻如畫

- 房間與街道描述須**一句入畫**：讀完一句，腦海立刻有畫面。
- 文風：**台灣暢銷作家的筆觸**——下筆有神、詞藻如畫；不生硬、不空洞、不流水帳。
- 仍須遵守下述「寫作原則與禁止用詞」。

### 2.4 物件回覆／敘事中的對齊排版（Markdown 表格）

- **Web 客戶端**會將敘事文字中的 **GFM 風格表格**（以半形 `|` 起迄的連續列，且第二列為 `| --- | --- |` 形式之分隔列）渲染成 HTML 表格，**無需**再以全形 `｜／＿／￣` 手動對齊。
- 儲存格內可照常使用 **〔物件名〕**，與既有可點擊物件邏輯相容。表頭列會輸出為 `<thead>`，其餘為資料列。

## 三、寫作原則與禁止用詞

**核心原則**：只寫**可被五感或具體狀態驗證**的內容；主觀感受應由**玩家閱讀具體文字後自行產生**，不在文案裡直接下結論。

- **可寫**：所見（光、色、材質、擺設）、所聞（氣味、聲音）、所觸（溫濕、地面）、空間結構（深處、盡頭、隔絕）。
- **不可寫**：替玩家下「這裡給人什麼感覺」的結論；物性、物理感、秩序感、XX感、「呈現／展現／體現」＋主觀結論。

### 3.1 禁止用詞與句型

| 類型 | 禁止 |
|------|------|
| **物性** | 物性穩固／堅實／穩定／最強／終點／最終回歸／呈現高度秩序；建築物性最強／最穩固的終點；精密物性結合、文明秩序與精密物性 |
| **物理＋感** | 物理穩固感／觸感／質感／死寂／安寧／重壓感／重量感；建築的物理心臟；呈現／展現絕對物理穩固感 |
| **秩序** | 秩序感極強／高／極端；高度／絕對秩序感；絕對秩序美；冷酷秩序感 |
| **XX感** | 環境感（安定／安靜／肅穆／濕潤／壓迫感／飽和／精密…）；視覺感（飽和／清晰／深邃…）；空氣感（凝滯／乾燥…）；空間感（沈重／飽滿／密實…）；靜謐放鬆感、神聖寂靜感、物質壓迫感、轉折感、結束感、凝滯感 |
| **呈現／展現／體現** | ＋ 任何「…感」「…秩序」「物性」「物理」結論（例：呈現穩定安寧感、展現地下財富與秩序、體現物質過度補完） |
| **其它** | 物質過度補完（當氛圍結論）；透著一股孤寂感；質感極端飽和；分形幾何感→改「分形幾何」 |

### 3.2 改寫對照（用這個代替）

| 避免 | 改為（或刪除） |
|------|----------------|
| 物性穩固／最強終點、物性終點 | 建築最深處／最內側／生活區盡頭；或刪除 |
| 物理穩固感／物理安寧 | 極靜；牆厚隔音 |
| 秩序感極強、高度秩序 | 陳設整齊、線條規整 |
| 環境感安定、呈現穩定安寧感 | 室內極靜、無雜音、厚牆吸音 |
| 視覺感飽和、呈現飽滿色調 | 光線飽和、光線呈琥珀色 |
| 空氣感凝滯、呼吸感飽滿 | 空氣凝滯、空氣濕潤 |
| 物理觸感／物理質感 | 觸感、材質厚實、表面冰冷平滑 |
| 建築的物理心臟 | 建築核心 |
| 物質壓迫感、物質過度補完的重壓 | 刪除；或改為熱輻射強、空氣密度高 |
| 踩踏感虛浮 | 地面鬆軟 |

### 3.3 可保留的用法

- **呈現**：僅用於可驗證事實，例如「光線呈現琥珀色」「牆面呈現油脂光澤」。
- **質感／觸感**：用於具體材質時可保留，例如「材質厚實」「表面冰冷平滑」。
- **邊界**：用於具體視覺或空間邊界時可保留；避免「物理邊界」當作抽象感受。

## 四、工作流程（房間與街道）

### 4.1 第一階段：一段一段完成

- 每段（或每棟建築）**先把房間、出口、物件都建好**。
- 描述可先求有、不求完美；用佔位句也無妨。

### 4.2 第二階段：回頭總視整體架構，重修畫面

- 整條大街（或整個區域）**都齊了之後**，從頭檢視所有段落的 `description`。
- 依整體節奏（例如：街口 → 漸深 → 墟心 → 夾道 → 店宅交錯 → 漸靜 → 大建築 → 收束 → 阻斷）調整各段環境描寫。
- 目標：**飾辭更貼切、有漸變、不重複**——讀起來是「走過去環境在變化」，而不是同一句複製九次。

### 4.3 描述原則（總視時用）

- **同一條街多段**：路面、光感、空間感要有漸變，避免每段都同一開頭。
- 總視時對照**相鄰段**與**整條軸線**，改寫 description。

### 4.4 下指令範例（給 AI 或自己用）

- 「先做第 X 段／先做這棟建築，**做完再一起總視整條街重修畫面**。」
- 「整條 XX 大街都齊了，**總視一下整體架構，重修各段描述讓畫面有漸變**。」

## 五、檢查清單與自檢

### 5.1 新增／擴充建築時

| 項目 | 檢核 |
|------|------|
| 結構 | 本棟內部連結拓樸是否與既有建築不同？ |
| 描述唯一 | 本棟各房主體描述是否與區內他房皆不重複？ |
| 文筆 | 是否一句入畫、下筆有神、詞藻如畫？ |
| 字數 | 每房主體描述是否 ≥50 字？ |
| 世界觀 | 是否符合富態與拉鋸、無廢土感？ |
| 禁止用詞 | 是否未使用「物性／秩序感／XX感／呈現／展現／體現＋主觀」等？ |

### 5.2 生成或改寫描述後自檢

1. 是否有「物性」「物理穩固感／物理安寧」「秩序感」「環境感」「視覺感」「空氣感」「空間感」？有則改寫或刪除。
2. 是否有「呈現出／展現出／體現出」＋「…感」「…秩序」「物性」「物理」？有則改為具體描述或刪除。
3. 每句是否都能對應到「看得到、聽得到、聞得到、摸得到或空間結構」？若僅是「給人某種感覺」的結論，則改寫或刪除。
4. 是否有同一句結尾或慣用語在許多房間重複？有則改為多樣表述或刪除。
