# 世界觀附篇 — 電子與精密機械

> **定位**：伏筆設定。與 [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md) §一（無念物質、游離輻射）、§九（無念物質與器物穩定）對接。未擴充前僅作背景與敘事約束用。

---

人們發現，**電子波為低頻波**（對比人類高頻波而言），容易受到**游離輻射**影響。

最初只是影響訊號等問題；越是精密的機械／電子波（仍屬低頻），受到的影響越大，偶有運作異常或失穩。故此，在**游離輻射未受抑**的一般人類聚落街面、野外，幾乎不見**高精密機械裝置**常態佈設——高精密設備多收納於**聚念場內**，以受控方式使用。

### 聚念場內：日用電器何以仍可用

**高頻有念之聚念場**帶有效益：人類起居所用的**無念外物**（含一般**電器**、多數**高科技日用產品**）在聚念場內，**較不易**遭受 **Token 混沌能量之游離輻射** 而**富態化**或失控。

關鍵在**高頻擠 / 低頻搶食**的共生結構（對齊 [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md) §二）：

- **人類（高頻有念）**擠開聚念場範圍內的主量游離輻射
- **綠植（低頻有念）**對殘餘游離輻射抱持**渴望**並**搶食**——城鎮建物外層**被覆綠植**、室內盆栽、街區行道樹，實際上是在清理人類擠不乾淨的殘量
- 綠植在聚念場內被人類念場部分抑制**不致吃滿富態化**（不致瘋長異變），搶食到的游離輻射變成綠植正常生長的能量——兩者**相得益彰**

兩層疊加後，**聚念場內**（如城鎮樓內）可合理出現**電器與電子日用正常運作**的敘事。

> **不是屏障是共生**：綠植不擋輻射（屏蔽式物理不存在，見降維 §一「游離輻射」子節），而是搶食殘餘；機制上是「高頻擠出主量 + 低頻清掉殘餘」的協作，不是單向防護層。

**與「無車」不矛盾**：車輛屬**戶外長距、多零件精密機械**，仍受 [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md) §九「無車設定」約束（無念、零件無法一一附詞等）；**室內固定／小件日用**與**街面載具**不是同一條因果。
