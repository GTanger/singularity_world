# 世界觀附篇 — 電子與精密機械

> **定位**：伏筆設定。與 [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md) §一（無念物質、游離輻射）、§九（無念物質與器物穩定）對接。未擴充前僅作背景與敘事約束用。

---

人們發現，**電子波為低頻波**（對比人類高頻波而言），容易受到**游離輻射**影響。

最初只是影響訊號等問題；越是精密的機械／電子波（仍屬低頻），受到的影響越大，可說是**進化出自主意識**。故此，在**游離輻射未受抑**的一般人類聚落街面、野外，幾乎不見**高精密機械裝置**常態佈設。

### 聚念場內與浮生城：日用電器何以仍可用

**高頻有念之聚念場**帶有效益：人類起居所用的**無念外物**（含一般**電器**、多數**高科技日用產品**）在聚念場內，**較不易**遭受 **Token 混沌能量之游離輻射** 而**富態化**或失控。再加上建物外層**被覆綠植**（見 [浮生城—建築與用途](浮生城—建築與用途.md) §一．七、§一．八）**率先吸收／緩衝輻射**，兩者疊加後，**聚念場內**（如 **浮生城** 樓內）可合理出現**電器與電子日用正常運作**的敘事。

**與「無車」不矛盾**：車輛屬**戶外長距、多零件精密機械**，仍受 [世界觀：Token降維與生命演化](世界觀：Token降維與生命演化.md) §九「無車設定」約束（無念、零件無法一一附詞等）；**室內固定／小件日用**與**街面載具**不是同一條因果。
