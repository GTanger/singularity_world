# 戰鬥系統概念設計（提取自 gemini 概念設計檔）

> 來源：`docs/archive/gemini概念設計檔/` 內戰鬥公式、全系統彙整 §3、地形標籤戰鬥修正、詞盤技能編譯與戰鬥執行流。不包含日期與非戰鬥段落。

---

## 一、設計前提

- 戰鬥結算在後端一次性完成（或按回合連貫結算），產出完整文字戰報。
- 專案採「行動槽點數 (Action Meter)」模型，非傳統回合制。
- 與詞盤系統、地形標籤、SoulSeed 三軸深度整合。

---

## 二、核心參數

### 2.1 外顯三維 (Effective Attributes)

| 參數 | 代號 | 語義 |
|------|------|------|
| 有效體質 | EVit | 生命基礎、減傷底色、抗壓穩定性 |
| 有效氣脈 | EQi | 技能燃料、回復率、意志護盾 |
| 有效靈敏 | EDex | 命中率、閃避率、行動頻率（時脈上限） |

### 2.2 內在三軸係數 (SoulSeed Multipliers)

| 係數 | 代號 | 語義 |
|------|------|------|
| 能階係數 | α (Amp) | 暴力增幅、擴張性；影響傷害峰值 |
| 時脈係數 | β (Freq) | 節奏控制、收斂性；影響資源利用率與動作連貫性 |
| 相位係數 | γ (Phase) | 變異機率、不可測性；影響暴擊、偏轉、走火入魔等意外效果 |

---

## 三、戰鬥時序與行動頻率 (Initiative & Timeline)

- **Tick**：戰鬥進程以 100ms 為一 Tick。
- **行動蓄積 (AP)**：每 Tick 恢復  
  `AP_per_tick = EDex * (0.5 + 0.5 * β)`  
  （高 β 者在同樣 EDex 下出手更快。）
- **發動門檻**：
  - 基礎攻擊：100 AP
  - 技能攻擊：`100 + Skill_Complexity_AP`
  - 連擊 (Combo)：若連發，下一次門檻增加 20%，直到休息一個 Tick。

---

## 四、衝突結算公式 (Conflict Logic)

主動方 Atk 對 被動方 Def 發動動作時：

### 4.1 命中與閃避

- **判定係數**  
  `K_Hit = Atk_EDex / (Atk_EDex + Def_EDex)`
- **命中機率**  
  `P_Hit = Min(0.95, Max(0.05, K_Hit * 1.2))`  
  若 Atk 的 γ 與技能屬性契合，命中可加成 5%。

### 4.2 原始傷害

- **基礎傷害**  
  `D_Base = (Atk_Power + Atk_Gear) * Resonance_Multiplier`  
  **Resonance_Multiplier**（共鳴階級）：  
  - 一階（單詞／雜亂）：1.0  
  - 二階（成句／語意模板）：1.5  
  - 三階（純粹／真實傷害）：2.5  
- **爆發係數**  
  `D_Impact = D_Base * (0.8 + 0.4 * α)`  
  α 越高，傷害浮動上限越高。

### 4.3 減傷與最終傷害

- **破甲能力**  
  `Pen = Atk_Penetration + (1.0 - Def_β) * Const`
- **生命承壓（最終傷害）**  
  `D_Final = D_Impact * [1.0 - (Def_EVit / (Def_EVit + Pen * 20))]`  
  體質防禦非線性：體質越高，每點體質減傷效率遞減，但能穩定稀釋傷害。

### 4.4 相位的干涉 (Phase Interference)

結算最後引入 **γ** 的隨機擾動：

- **熵增觸發**：γ 極端（趨近 -1 或 1）時增加變數。
- **正向 (γ > 0)**：高機率轉為「暴擊 (Critical)」或「破甲 (Armor Break)」。
- **逆向 (γ < 0)**：高機率轉為「偏轉 (Deflect)」或「反彈 (Reverse)」。

## 五、資源代價與穩定度 (Cost & Stability)

- **氣脈消耗**  
  `Qi_Drain = Skill_Cost * (2.0 - β)`  
  β 越高，浪費的游離量越少。
- **姿態 (Posture)**：每次受傷減少姿態值；EVit 越高，姿態上限越高。  
  姿態歸零 → 下一次 AP 恢復暫停 1 秒（受擊僵直）。

---

## 六、狀態指標：歸零的語義

| 歸零 | 語義 |
|------|------|
| 氣血 (HP) | EVit 耗盡，身體崩潰 → 死亡，需重組 |
| 內力 (MP) | EQi 耗盡 → 無法發動技能，虛弱（減傷與命中大幅下降） |
| 體力 (Stamina) | 動作門檻 AP 恢復停滯 → 僵直，只能被動挨打 |

---

## 七、地形標籤對戰鬥的修正 (環境共鳴)

傳入當前房間 **Tags**，查表疊加係數後再代入上述公式。

| 標籤 | 效果 |
|------|------|
| **[靜謐 (Silent)]** | 降低相位 γ 波動，戰鬥結果更可預測（田忌賽馬） |
| **[富態 (Lush)]** | 提升能階 α（傷害放大），略微提高氣脈消耗 |
| **[咬合 (Grip)]** | 姿態穩定度加成，降低僵直機率 |
| **[混沌 (Chaos)]** | 大幅提升 γ，高暴擊、高反彈、甚至概率失效 |

戰報可將地形轉為敘事，例：「由於[富態]環境的滋養，這一擊顯得格外沉重。」

## 八、技能編譯與戰鬥執行流 (與詞盤對接)

- **SkillObject** 欄位：base_dmg、ap_threshold、qi_cost、resonance_tier、attribute_tags、effects。
- **威力**：詞元能階價值加總 × 能階係數 α。
- **消耗**：詞元數量與複雜度 ÷ 時脈係數 β；變異機率受 γ 影響。
- **執行流**：蓄能 (AP) → 檢核 (Qi) → 結算 (Formula) → 回饋 (Log)。

---

## 九、文字戰報標籤範本

後端 Raw Log 可含下列標籤，供前端渲染：

- `[Initiative]`：{name} 捕捉到一線先機...
- `[Action:Skill]`：{name} 發動了「{skill_name}」！
- `[Conflict:Crit]`：(由 γ 觸發) 這一擊角度刁鑽，避無可避！
- `[Result]`：{target} 受到了 {dmg} 點傷害，體質顯得有些渙散。
