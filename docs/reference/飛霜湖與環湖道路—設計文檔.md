# 飛霜湖與環湖道路 — 設計文檔

> **用途**：飛霜湖區與環湖道路的定位、拓樸、語彙與實作對齊。須與 [飛霜大街—環境概念與連結](飛霜大街—環境概念與連結.md)、[房間與建築設計規範](房間與建築設計規範.md) 並用。

---

## 一、定位與命名

- **飛霜湖**：飛霜大街**湖端**的水體，與一段相接；霜白結晶飄落湖緣、與**湖氣**交會，游離輻射下熱氣不散、水氣凝成細霜。命名與飛霜大街一致（勿以「下雪」解釋，用霜晶、湖氣、游離輻射）。
- **環湖道路（環湖路）**：沿飛霜湖岸鋪設的**石板路**，可串起湖岸景點（岸邊、碼頭、觀景亭、泵房）與湖畔建築（別墅、旅宿等），並與飛霜大街一段銜接；亦可作為「湖區 hub」，經此回大街或往霜林小徑。

**與他區關係**  
- 飛霜大街一段：湖端，霜晶與湖氣交會；與飛霜湖（或環湖路）雙向。  
- 霜林：霜林小徑入口現接北岸（fei_lake_north），已遷至 data/rooms/霜林，舊版封存已刪除。  
- 打鐵巷：熱氣自二段釋出，與湖端無直接拓樸，僅共屬飛霜大街沿線。

## 二、連結拓樸

### 2.1 現行實作（新地圖）

| 節點 | 房間 id | 說明 |
|------|---------|------|
| 飛霜湖 | fei_lake | 單一房間，與飛霜大街一段雙向；zone：feistreet。 |

目前**未實作環湖路**：玩家僅能「一段 ↔ 飛霜湖」兩點往返。

### 2.2 擴充選項（若實作環湖道路）

可採下列之一或混合：

- **方案 A（星狀）**  
  - 環湖路為**單一街道房間**（hub），連結：飛霜大街一段、湖面岸邊、碼頭、觀景亭、泵房、若干湖畔建築、霜林小徑（若有）。  
  - 優點：一層到位、出口列表清楚；缺點：環湖路一房承載所有出口，描述與物件較多。

- **方案 B（線狀／多段）**  
  - 環湖路拆成多段（如東岸、北岸、西岸），段與段首尾相接成環，再從其中一段接飛霜大街一段與景點。  
  - 優點：可逐段寫景、漸變；缺點：拓樸與房間數增加，需與整張地圖規模平衡。

- **方案 C（最小擴充）**  
  - 維持現行「一段 ↔ 飛霜湖」；僅在飛霜湖房內增加 1～2 個「沿湖岸」的景點出口（如岸邊石灘、觀景亭），不單獨做環湖路 hub。  

**id 建議**（與現行一致）  
- 飛霜湖：fei_lake（已用）。  
- 環湖路若實作：建議 zone 統一為 feistreet 或 fei_lake；id 可採 fei_lake_road、fei_lake_land、fei_lake_pier、fei_lake_pavilion、fei_lake_pump，以與 archive 的 feishuang_ 前綴區隔並利於辨識。

### 2.3 環湖四岸＋水際拓樸（線狀環＋共用水際）

拓樸：四段岸首尾成環，每段皆可下到「水際」；南岸另接飛霜大街一段。

```
飛霜大街一段 ↔ 南岸 ↔ 水際
南岸 ↔ 東岸 ↔ 水際
東岸 ↔ 北岸 ↔ 水際
北岸 ↔ 西岸 ↔ 水際
西岸 ↔ 南岸
```

**命名與用詞建議（台灣暢銷作家筆觸：下筆有神、詞藻如畫）**

| 節點 | 功能／方位 | 建議顯示名稱（擇一或混用） | 描述可帶入的畫面 |
|------|------------|----------------------------|------------------|
| **南岸** | 接大街一段 | **街口湖緣**、**臨街渡頭**、一段湖緣 | 霜晶與街燈、湖氣在此交會；石板路自大街延伸入霧。 |
| **東岸** | 湖東側 | **霧起之濱**、**東曦岸**、東側石灘 | 暖霧自湖心往東升，霜晶落即融；天光最先到的一側。 |
| **北岸** | 湖北側、背街 | **湖背**、**深霧岸**、北側霧岸 | 背對大街，霧最厚、最靜；簷角積霜、熱氣不散。 |
| **西岸** | 湖西側、繞回南 | **迴岸**、**西轉角**、西側湖緣 | 繞湖至此，再往前即回南岸；霜晶與暖霧纏腳。 |
| **水際** | 貼水、共用的「濱」 | **水際**、**霜融水緣**、**貼水石灘** | 真正貼水的那條線；霜觸地即化、熱氣自水際蒸散。 |

- **id 建議**：fei_lake_south / fei_lake_east / fei_lake_north / fei_lake_west；水際可 fei_lake_shore 或 fei_lake_waterfront，與四岸皆雙向。
- 描述撰寫：每段岸可強調一景（南＝街口與湖氣、東＝霧起與曦、北＝深霧與靜、西＝迴繞與歸），水際統一用「霜融水緣」「熱氣自水際蒸散」等，避免四岸＋水際句型重複。

以下為**可行**的接入設計，擇一或依階段實作。

**一、飛霜大街一段 ↔ 湖區**

**二、水際與 fei_lake 的關係**

| 方案 | 設計 | 說明 |

**三、霜林小徑（可選）**

| 接入點 | 連結 | 敘事感 |
|--------|------|--------|

**四、景點（碼頭、觀景亭、泵房）接入**

| 方式 | 連結 | 說明 |
|------|------|------|
| **掛在某一岸** | 例如碼頭←東岸、觀景亭←北岸、泵房←西岸 | 每岸 0～1 個景點，該岸房多一個出口；拓樸簡單 |
| **掛在水際** | 水際房連結碼頭／觀景亭／泵房 | 所有「貼水」景點自水際進出；水際房出口較多 |
| **分散多岸** | 碼頭─東岸、觀景亭─北岸、泵房─西岸，南岸純接大街 | 環湖一圈可依序經過三景點，動線有變化 |

**五、建議組合（可直接採用）**

- **接入大街**：方案 **乙**（一段雙接南岸＋fei_lake），或 **丙**（一段只接 fei_lake，湖內再接南岸），與現行資料相容。
- **水際**：方案 **A**（獨立水際房，四岸雙向），與 §2.3 命名一致。
- **霜林**：北岸或西岸擇一接入口；不實作則不接。
- **景點**：分散多岸（碼頭東、亭北、泵房西），或僅掛水際，依房間數與動線需求擇一。

### 2.6 景點設計要點（碼頭、觀景亭、泵房）

三景點在最佳版本中皆為**單房**，僅與所掛岸雙向；若日後擴充為多房建築，須依 [房間與建築設計規範](房間與建築設計規範.md) 做結構差異化。

| 景點 | id | 顯示名稱 | 描述要點（須≥50 字、符合 §三語彙） |
|------|-----|----------|--------------------------------------|
| **碼頭** | fei_lake_pier | 碼頭 | 木樁或石墩沒入霧際、欄杆覆霜即融、暖霧繚繞；足底石板沁涼、可聞水波輕拍；勿寫「視野佳」等主觀結論。 |
| **觀景亭** | fei_lake_pavilion | 觀景亭 | 暖風穿亭、霧氣與晶粉紛飛、簷角積霜；可寫「可眺湖面與落霜」等可驗證視線，勿寫「視野極佳／環境開闊」。 |
| **泵房** | fei_lake_pump | 泵房 | 門檻積霜、暖氣自縫隙溢出、石砌厚牆隔開湖風；機械低鳴沉在腳底；維持「設施感」不寫成主觀氛圍。 |

- 各景點 description 主體不可與四岸、水際、彼此重複；句型與飾辭須有區隔。
- Archive 舊描述可作語彙參考（§六），重做時改用 fei_ 前綴、補足 50 字並刪除禁止用詞。

### 2.7 湖畔建築設計（可選）

- **定位**：環湖區若需「可進入的建築」，以**湖畔別墅／旅宿**為主，與飛霜大街一段的「2 商 2 宅」區隔，避免重複感。
- **本階段建議**：最佳版本**僅實作四岸＋水際＋三景點**，不納入別墅；湖畔建築列為**後續擴充**，以免房間數與描述負擔過大。
- **若日後新增湖畔建築**：
  - **id**：建議 fei_lake_home01、fei_lake_home02… 或 fei_lake_inn01，與 fei_lake_* 岸／景點一致。
  - **規範**：須符合 [房間與建築設計規範](房間與建築設計規範.md)——內部拓樸與既有建築（含他區）**結構相異**、描述不重複、主體≥50 字、禁止物性／秩序感／呈現＋主觀等（§三）。
  - **語彙**：與 §三、§六 一致；勿寫「落雪」、勿用「安全感」「質感冷峻」「環境穩定」「展現體面」「靜謐且具備視覺享受」等，改為可驗證的材質、光線、隔音、擺設。
- **數量與格數**：依專案規模決定；若做多棟，每棟房間數與拓樸型態（線性／星狀／環狀／枝狀等）須不同。

## 三、環境語彙與撰寫要點

與 [飛霜大街—環境概念與連結](飛霜大街—環境概念與連結.md) §一、§四 一致：

- **可用**：霜白結晶飄落、霜晶與湖氣交會、游離輻射下熱氣不散、水氣凝成細霜、冷調石紋、簷角積霜、暖霧自湖面升騰、霜晶落即融、熱氣自水際蒸散、玉質脈絡。
- **勿寫**：「下雪」「雪景」；僅用霜、湖氣、輻射、熱氣不散等可驗證感官。
- **環湖路若撰寫**：沿湖岸石板路、暖霧自湖面升騰、霜晶落即融、兩側別墅或地景格錯落、可通往湖面／碼頭／觀景亭／泵房、經此回飛霜大街。

## 五、環湖道路設計要點（若實作）

- **功能**：湖區動線 hub，連接大街一段、湖岸景點、湖畔建築、可選霜林入口。
- **描述要點**：沿湖岸石板路、暖霧自湖面升騰、霜晶落即融、兩側建築或地景錯落、出口寫進描述並以〔名稱〕對應 objects。
- **建築配置**：景點（岸邊、碼頭、觀景亭、泵房）可各一房；別墅數量與格數依專案規模，需與飛霜大街一段的「2 商 2 宅」區隔，避免重複感。
