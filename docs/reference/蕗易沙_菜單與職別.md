# 蕗易沙 — 菜單與職別備註

## 服務生 vs 店員

| 職別 | 行為取向 | `npc_behaviors` |
|------|----------|-----------------|
| **服務生** | 區域內走動、端盤、多房穿梭 | `wander_rooms` 多間（如客棧大廳／食堂／廚房） |
| **店員** | 店面員工、**站櫃**、點餐出餐 | `wander_rooms` 僅 `["life_cofe_order"]` → 伺服器不觸發區域巡邏（需 `len > 1`） |

對話檔：`服務生` → `dialogues/waiter.json`；`店員` → `dialogues/clerk.json`。  
指派蕗易沙櫃檯 NPC 時請用職稱 **店員**，與客棧 **服務生** 區隔。

## 房間與標籤

| 房間 id | 用途 | `tags` |
|---------|------|--------|
| `life_cofe_order` | 櫃檯點餐視角、燈箱〔咖啡〕〔輕食〕 | `coffee`, `food` |
| `life_cofe_seat` | NPC 聚集、八卦與傳聞對話 | `social`, `coffee`, `food` |
| `life_cofe_1` | 蕗易沙主廳動線 | 既有 `coffee`, `food`, `social` |

## 飲品清單（與 `life_cofe_order.json` 內 `Read` 同步維護）

**義式**：浮生濃縮；金邊長萃；雙份濃縮  

**拿鐵**：沃土拿鐵；霜花拿鐵；榛果拿鐵；蜂蜜紅茶那提  

**美式**：泡沫美式；向陽冰美式  

**手沖**：向陽日晒單品；飛霜拼配；夜鴞深烘  

**其他**：抹茶那提；可可歐蕾；本日精選（問店員）

**其他**：蔬菜磚壓；雙果優格杯；本日湯品（櫃旁小黑板）
