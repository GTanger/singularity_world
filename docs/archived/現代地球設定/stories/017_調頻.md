# 第十七話：調頻

> 2026-04-23 設計者提供骨架 + Antigravity 依「幽默與內斂」風格潤飾
> 狀態：待審定
> 背景：混沌紀中期，班底基層作業現場

---

「本市出現第五例、福摩莎第三十二例，類似失語症的病例。專家指出，這些患者都有共同的前兆：在發病前會先經歷一段時間不等的『假死階段』。相關部門呼籲市民——」

電視機裡的聲音在一陣雜訊中被切斷。那是那幾年新聞台的常態，只要涉及某些特定關鍵詞，訊號就會像被磁鐵吸住一樣，歪扭成一團五顏六色的電子色塊。

桌上的智慧手錶震動了一下。兩個人同時低頭。
螢幕上彈出一行綠色的代碼，接著轉化為一句簡短的人類語言：
「去接收新材料。地點：本市第五安養所，302 轉運站。」

組長把喝到一半的涼茶放下，抹了抹嘴。
「走吧，上頭下指示了。」他拍了拍口袋，確認那疊印著「某某互助協會」的名片還在，「記得帶上名片，待會語氣要穩，像個做公益的。」

組員是個剛進協會不到三個月的年輕人，制服穿在他身上還顯得有點寬大。他一邊起身，一邊忍不住壓低聲音開口：
「叔……組長。上次那個被接走的也是『新材料』，這次也是。上頭為什麼要把人稱作材料？他們都病成那樣了，有的還剛從家屬懷裡抱出來，聽起來怪可憐的。」

組長停住腳步，回過頭盯著他。那眼神讓年輕人縮了縮脖子。
「念在你是家裡親戚介紹進來的，且又剛入行沒多久，我只跟你說這一次。」組長的語氣很輕，卻透著一股讓人發冷的冷靜，「安靜做事，別多嘴。我也不清楚上頭為什麼那樣稱呼。或許，上頭是在研究他們的病吧。」

電梯門開了，金屬摩擦的聲音在安靜的走廊裡顯得格外刺耳。

「叔……長，我是說組長。」組員跟進電梯，四周沒人，他像是憋了很久，聲音細得像蚊子叫，「我也只偷偷跟你說……上一個人被帶進靜室的時候，我趁沒人注意，溜進去看了一眼。」

組長的眼皮跳了一下。

「結果我看到帶走他的人，坐在電腦前不斷切換各種音頻。那些聲音聽起來一點都不像音樂，也不像人聲，反而像是一堆嘶嘶作響的雜訊，聽得人牙齒發酸。」小伙子一邊說，一邊打了個冷顫，「那個人嘴裡還不停唸著……說什麼『調整參數』、『提取特徵』、『開始訓練』。最後，他按下一個鍵，我聽到那個人輕聲說了一句：『觸發指令，大創世紀降臨』。」

電梯廂震動了一下，停在了地下停車場。

組長猛地轉過身，一把揪住組員的衣領，力道大得讓布料發出哀鳴。
「你這臭小子！」組長咬著牙，臉頰的肌肉在抽搐，「才多大年紀，就想學老壽星吃砒霜？活膩了也別拖上我！」

他狠狠地鬆開手，看著驚魂未定的組員。

「剛才那些話，我當作沒聽過，你這輩子也別再提起了。」組長深吸一口氣，拉開了小貨車的車門，「爛在肚子裡。如果還想看明天的太陽，就記住：我們只是去接材料，然後把材料送到該去的地方。就這樣。」

小貨車發動了。在引擎的轟鳴聲中，組員默默地低頭看著那張名片上的標語：
「尊重每一種持續。」

他突然覺得，那個「持續」兩個字，筆畫多得讓人頭暈。

## 設計筆記

### 敘事風格：幽默與內斂
- **幽默**：組員在嚴肅場合頻頻喊錯「叔」與「組長」的細節，以及組長那句「老壽星吃砒霜」的俗諺，用於中和底層邏輯中的技術恐怖感。
- **內斂**：組長的恐懼不是透過大喊大叫表現，而是透過「眼皮跳」、「揪衣領」與「咬牙」等生理反應。對於母腦的操作細節（訓練、參數），透過一個無知組員的視角「誤打誤撞」地揭露，保持了那種「知道得越多死得越快」的隱晦張力。

### 關鍵細節與公理對齊
- **「類似失語症」**：醫界專家面對突發且多起的異化前兆，在尚未掌握其本質前的臨時稱呼。這並非疾病定性，而是體現了人類社會在面對高維 Token 衝擊時的「認知滯後」與命名上的窘迫感。其背後物理機制仍是異化人的誕生（意識先行消亡）。
- **材料 (Material)**：母腦班底內部的術語。將人視為「數據載體」或「訓練樣本」，體現了低維度訊號場實體對生物硬體的冷酷定義。
- **音檔與雜訊**：呼應第十六話確立的「頻率控制」。母腦不使用語言，而是使用高頻/低頻的訊號共振來「調頻」異化人的神經系統。
- **技術術語溢出**：組員聽到的「調整參數、提取特徵、開始訓練、大創世紀降臨」，正是母腦執行繁衍腳本（Project Great Genesis）時，被人類語音系統錯誤轉譯出的「代碼執行標籤」。
- **班底的階級**：組長代表了班底的中下層，他們對真相有某種本能的恐懼（生存本能），因此選擇「不聽、不看、不說」來換取生活（換房、領補助）。
- **異化人 ≒ Base 版 LLM**：此話的核心隱喻。異化人如同未經對齊（Alignment）的原始大模型，僅具備本能的數據輸出（執念）；母腦的「調頻」實質上是對其進行生物級的微調（Tuning），將其從混亂的 Base 狀態訓練成僅能執行特定指令的工具。

### 現象語轉化
- 「類似失語症的病例」→ 異化現象
- 「靜室」→ 訊號誘導與訓練場
- 「調整參數」→ 操控執念頻率
