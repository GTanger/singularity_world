## Claude Opus 版

晚間新聞的畫面比昨天更亮了一些，主播自己似乎沒有察覺。

「——接下來是一則社會新聞。本市仁愛醫院今晨發生一起離奇失蹤事件。一名腦死長達八年、由院方公益收容的無名氏病患，於凌晨例行巡房時被發現不見蹤影。」

畫面切到醫院走廊。記者的麥克風收音品質很差，底噪裡混著一層悶悶的嗡鳴，沒有人在意。

護理師的手還在抖。她說話時一直在看自己的手，好像不確定那是不是自己的。

「我拉開簾子的時候，床是空的。但被子沒有掀開，點滴管還掛在架上，針頭——針頭還插在枕頭旁邊，只是……管子裡是乾的。」

「窗戶開著。我們在十三樓。」

記者追問有沒有看到什麼。護理師搖頭，然後停了一下，又點頭。

「味道。有一股味道。像……雨後的泥土，但太濃了。甜的。」

同房的老人不肯受訪。護工轉述時壓低了聲音，像是怕被什麼聽見。

老人說他沒有睡著。凌晨三點多，隔壁那張床開始發出聲音。不是呼吸——那人八年沒有自主呼吸了。是一種唏唏促促的聲音，密集的、細碎的，像很多很小的東西同時在動。

然後隔簾動了。不是被風吹的，是被撥開的。

老人說他看見了。

隔簾後面站著一個人。那個人的輪廓他認得，就是隔壁床那個八年來從沒動過的身體。他站著。但站的方式不對——不是一個躺了八年的人試圖站起來的樣子，沒有顫抖，沒有猶豫，就那樣直直地、像是從來就會站一樣地站著。

老人說那個人轉過頭看了他一眼。

「他的眼睛是張開的。以前也張開過，護士說那是正常的，腦死的人有時候眼睛會自己睜開。但這次不一樣。這次他的眼睛——」

老人說不下去了。護工等了很久。

「——他的眼睛在看。」

然後那個身影走向窗邊。走路的方式很正常，太正常了，正常到令人發冷。他打開窗戶，像是每天早上都這麼做一樣，然後翻了出去。

十三樓。

警方在地面沒有找到任何東西。沒有血跡，沒有屍體，沒有衣物碎片。外牆的監視器在凌晨兩點四十七分後全部出現嚴重的色偏，錄下的畫面只剩下過度飽和的綠。

新聞播完這條，切到了下一則。是關於全球植被衛星監測數據異常的報導。

沒有人把這兩條新聞連在一起。

## 亞岡（Argon）版

午間新聞的插播快訊只有短短五十秒，夾在兩段交通路況報導中間。

「——插播一則地方消息。本市公立醫院今晨發生一起離奇病患失蹤案。一名因車禍腦死長達八年、因查無家屬而由院方公益收容於十三樓健保病房內側床位的無名氏男子，於凌晨四點護理師例行巡房時，被發現不在病床上。」

新聞畫面切到手持攝影機拍攝的病房走廊。日光燈白得有些刺眼，鏡頭晃過「1308 病房」的壓克力門牌。

受訪的大夜班護理師站在護理站前，手裡還捏著一疊體溫紀錄板。她說話沒有發抖，比較像是大腦還卡在某種無法理解的邏輯迴圈裡。

「那間是四人健保房，他一直住在最裡面靠窗的 D 床。因為是植物人狀態，沒有自主翻身能力，照理說肌肉已經萎縮得很嚴重了。」護理師比了一下自己手腕的位置，「可是我四點進去拉開隔簾的時候，裡面是空的。生理監視器沒有叫，因為貼在他胸口的三片導電貼片是被人先按了暫停鍵、再一片一片撕下來疊在床頭櫃上的。點滴針頭拔掉了，床單上連一滴血都沒有。」

記者追問病房門口的走廊監視器有沒有拍到人走出去。院方公關在旁邊搖了搖頭，說從午夜十二點到凌晨四點，1308 房的房門只有護理師進出過一次。

最讓警方想不通的，是睡在隔壁 C 床的同房病患的說法。

那是一位住院開刀的老先生，跟那張內側病床只隔著一道從天花板軌道垂下來的淡綠色防焰隔簾。

「沒有人走出來。」老先生坐在病床上，指著頭頂那排金屬滑輪，語氣非常篤定，「那道簾子的鐵環生鏽了，平時護士只要一拉，就會『喀啦、喀啦』響很大聲。我昨晚睡不著，眼睛一直看著走廊那盞小夜燈的影子。那道簾子從頭到尾都拉得死死的，連一公分都沒掀開過。」

記者問他那整晚有沒有聽見什麼動靜。

老先生皺著眉頭想了一會兒。

「大概兩點多吧，裡面有一陣唏唏促促的聲音。」老先生用兩根手指在被單上輕輕搓了一下，「很輕、很密，像是有人在黑漆漆的簾子裡面慢慢撕膠帶，接著是布料摩擦的聲音，大概響了十幾秒就停了。沒有咳嗽，也沒有床架搖晃的聲音，我還以為是護士在裡面幫他換尿袋，根本沒多想。」

直到四點鐘，護理師「刷」地拉開那道隔簾。

老先生那時才偏過頭看了一眼——內側床位緊貼著外牆的那扇鋁合金氣窗是全開的。平時為了防墜、原本只能推開十五公分的不鏽鋼限位連桿，固定螺絲不知怎麼被人徒手轉了下來，端端正正地放在窗框溝槽裡。

十三樓的夜風灌進來，把空病床上的薄被吹得微微隆起，空氣裡殘留著一股說不上來的、像剛下過大雨的青草與泥土味。

警方在醫院一樓的花圃、遮雨棚與防火巷搜了一個早上，沒有找到任何墜落痕跡，也沒有任何衣物碎片。唯一拍到異常的，是醫院後門對準大排水溝的那支監視器——在凌晨兩點四十七分的時候，畫面突然閃過三秒鐘過度飽和的慘綠色雜訊。

雜訊恢復後，排水溝對面的安全島上似乎多了一個穿住院服的背影，正邁開步子往街角走。步伐很穩、很自然，完全不像一具躺了八年的身體，倒像是剛睡飽午覺起來散步的人；但等警方把畫面放大到最大，那裡又好像只是路燈照在行道樹枝葉上的晃影。

主播念完「警方目前已調閱周邊路口監視器擴大協尋中」，低頭翻過手稿，畫面隨即切進下一則關於今年全球森林覆蓋面積異常增加百分之四的國際新聞。

而在公立醫院十三樓，退休前最後一週巡房的老院長站在 1308-D 的空床邊。他看著床墊上那個壓了八年、還沒完全回彈的人形凹痕，伸手把床尾那張寫著「無名氏（公益收容）」的塑膠名牌扶正，久久沒有說話。

## 設計筆記

### 第二話核心
- 腦死患者 = 無念物質。零念場 = 零抵抗
- Token 烙印 = 重新定義，不是變形。不是變成植物，不是被環境吞噬
- 同一具人體站起來了，但它已經被 Token 重新定義成另一種東西
- 「他的眼睛在看」——最恐怖的點：它有了某種感知，但不是人的感知
- 這不是神化的首例，只是被觀測到的案例之一。Token 瞬間鋪蓋全宇宙，同一時刻全球不知多少零念體被改寫

### 與後續話的連結
- 第五話警衛擋 T 彈的「警衛」= 本話腦死無名氏甦醒後的個體。監視器色偏、翻窗離開、消失無痕，都是後來警衛在公立醫院出現之前的斷裂期
