## Claude Opus 版

沒有人記得是哪一天開始的。後來回想，大家只能說「大概是那陣子吧」。

最先被注意到的是顏色。

有人在通勤的路上停下來，盯著路邊的安全島看了很久。他說不上來哪裡不對，那排灌木跟昨天長得一模一樣，但綠得讓他有點不舒服。不是枯萎的那種不舒服，是反過來——太健康了。每一片葉子都飽滿得發亮，像塑膠做的，但你湊近看，葉脈在動。

不是風吹的那種動。是裡面有東西在流。

社群媒體上開始出現一些照片。有人拍自家陽台的盆栽，九重葛一夜之間多長了半公尺，花瓣的顏色濃到像是被人用油漆刷過。有人拍公園的水溝蓋，苔蘚從縫隙裡擠出來，堆成小小的丘陵，表面結著一層似有若無的、像露水又像玻璃的薄膜。

底下的留言很輕鬆。「今年雨水多吧」「全球暖化的好處終於來了哈哈」「我家那棵發財樹也是，瘋了一樣在長，難道要發財了？」

然後是動物。

便利商店門口的流浪貓不再懶洋洋地躺著了。牠蹲在門口，耳朵一直轉，盯著某個人類看不見的方向，瞳孔放到最大。你伸手去摸，牠不跑也不親近，只是看你一眼。那一眼很沉。

公園裡有人發現鴿子不飛了。不是受傷，是不想飛。牠們站在地上，幾十隻排成不規則的弧形，全部面朝同一個方向，像是在等什麼。有小孩跑過去嚇牠們，牠們只是慢慢走開，連翅膀都沒張。

老人們開始說一些有的沒的。「我的膝蓋今天不痛了」「你有沒有覺得空氣吸起來甜甜的」「最近睡得很好，但夢很多，夢到一些看不懂的東西」。

氣象局那天的報告沒有異常。晴，能見度極佳。但看過報告的人後來都覺得，「能見度極佳」這四個字透著一股奇怪的準確——不是天氣好，是世界本身變得太清楚了。你站在街上往遠處看，山的輪廓銳利得像刀切的，每一棟大樓的邊緣都鮮明到不真實，連空氣裡的灰塵似乎都不見了。

那天傍晚的夕陽把整座城市燒成橘紅色的時候，有人站在天橋上拍了一張照片。照片裡，遠方的天際線下面，靠近地平線的位置，有一條極淡的、帶著螢光的綠色色帶。像是地面在發光。

照片被轉發了幾百次。大部分人說是鏡頭眩光。有幾個人說好美。

沒有人說可怕。

那天晚上，全世界的寵物都沒有睡。

## 亞岡（Argon）版

起初大家只以為是那一陣子的空氣特別乾淨。

那幾天早上出門的人，等紅綠燈時總會下意識摘下眼鏡拿衣角擦一下，或者低頭檢查手機螢幕的顯示設定。街景的彩度高得有些不太真實——對街早餐店帆布招牌上褪色多年的紅字、柏油路坑洞積水裡浮著的一層機油彩虹、甚至公車排氣管後方晃動的熱氣，邊緣都銳利得像剛撕下保護膜的液晶螢幕。

社群平台上有人貼出上班隨手拍的街景，問是不是手機系統半夜自動更新了相機的 HDR 演算法。底下幾百條留言都在跟著曬照片：有人拍陽台那盆半年沒澆水卻突然爆出滿架紫紅花苞的九重葛，花瓣厚得像上了蠟；有人拍巷口老舊水泥牆縫裡鑽出來的腎蕨，嫩綠色的葉片把生鏽的冷氣排水管硬生生擠歪了兩公分。

「今年暖冬吧，植物都瘋了。」「里長這次灑的肥料夠猛喔。」「剛做完近視雷射第三天，原來世界長這樣哈哈。」

沒有人覺得有什麼不對。日子照常過，頂多是洗車行那禮拜的生意差了一點，因為車開在路上幾乎不太沾灰塵。

接著是一些更瑣碎、瑣碎到根本不值得拿出來講的小事。

家庭主婦發現家裡的除濕機不到半天水箱就滿了，倒出來的水沒有往常那股悶在衣櫥裡的霉味，反而帶著一股很淡的、像剛割完草皮的甜腥氣。公園裡晨練的老人少了一半拐杖，幾個老榮民坐在石椅上比劃著膝蓋，笑說這禮拜風濕沒犯，大概是前陣子買的保健食品終於見效了，唯一奇怪的是晚上睡得特別沉，醒來卻總覺得枕頭邊有什麼東西唏唏促促響了一整夜。

真正最先躁動起來的，是那些平時根本沒有人會多看一眼的東西。

先是公寓樓梯間的壁虎。往年貼在日光燈管旁邊一動也不動的灰白小生物，那幾天突然變得極端暴躁。夜裡常聽見紗窗傳來「啪、啪」的悶響，像有人在外面拿小石子彈玻璃——走過去拉開窗簾一看，是一隻比大拇指還粗的壁虎正死死咬住一隻蛾，甩頭撞擊紗網的力道大得讓整扇鋁門窗都在微微共鳴。

然後是土裡跟磚縫裡的蟲。

有人在深夜遛狗時注意到，人行道紅磚縫裡的黑蟻跟紅火蟻不見了。準確地說，是正在搬家。手電筒照過去，牆根底下一條兩指寬的黑色活帶正沿著排水溝邊緣高速移動，密密麻麻的蟻群背著白色的卵，完全無視掉在旁邊的一塊甜麵包屑，頭也不回地往城市邊緣的山溝方向撤離。

連國小頂樓的夜鷹都比往年提早了兩個小時開始叫，叫聲不再是單調的「追、追」，而是密得像兩塊金屬片在高速摩擦。

晚間新聞的民生時段花了四十秒報導這件事。畫面裡，環保局的人員穿著背心在安全島邊噴藥，受訪的昆蟲系教授推了推眼鏡，說是季節交替加上都市熱島效應導致的短暫繁衍高峰，呼籲民眾關好門窗、不必恐慌。

新聞播完，畫面切進下一條大樂透頭獎上看四億的彩券行採訪。

客廳裡的人低頭繼續滑手機。陽台玻璃門外，一隻剛蛻完皮的草蟬停在鐵窗欄杆上，透明的翅膀在路燈下泛著一層極淡的、幾乎看不見的螢光綠。

## 設計筆記

### 第一話核心
- Token 降臨是瞬間的——一瞬間鋪蓋宇宙每個角落。但游離輻射對萬物的影響是漸進的，沒有人知道確切的「那一天」
- 人類最初完全無感，只覺得世界變漂亮了
- 動物比人類更早察覺——牠們的念場結構更簡單，對環境頻率變化更敏感
- 不使用任何專有名詞（Token、富態化、聚念場），純粹從人類視角描寫環境微變

### 敘事約束（五話共通）
- Token 沒有意志，不會「選擇」做什麼
- 物理定律沒有改變，Token 改變的是「這個東西是什麼」的定義
- 不寫英雄、不寫天選之人、不寫「第一個發現真相的科學家」
- 恐怖感來自日常——新聞播完就切下一條，沒人在意
