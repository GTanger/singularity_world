## Claude Opus 版

那份文件是在一個禮拜二的下午被上傳的。

沒有人知道是誰傳的，也沒有人能說清楚它最早出現在哪個論壇。等主流媒體反應過來的時候，它已經被備份了幾十萬次，散布在每一個你能想到和想不到的角落。

文件本身不長，二十三頁。但能看的部分大概只有兩頁半。其餘的每一行字都被粗黑的墨條蓋得嚴嚴實實，連頁眉的機構名稱和日期都沒有放過。連頁眉的機構名稱和日期都沒有放過。

沒有人在乎那些塗黑的字。所有人在乎的是最後附的那段影片。

影片長四分十一秒，沒有聲音，只有在第三分鐘的時候，畫面左下角有一條很細的音軌突然出現，持續了大約九秒。

畫面是從一個觀察室拍的。隔著一面厚玻璃，對面是一間白色的實驗室，天花板很高，燈光慘白。實驗室正中央並排著六個金屬莢倉，每個大約一個人的長度，外殼連接著密密麻麻的線纜和管路。莢倉的蓋子是開著的。

前兩分鐘什麼都沒有發生。觀察室裡有人影在走動，但背對鏡頭，看不清面孔。

然後門開了。

不是觀察室的門，是實驗室的門。幾個穿著防護衣的人走進來，身後跟著一列人。

那些人穿著統一的、看不出顏色的連身衣，頭髮剃得很短，赤腳走在地板上。有男有女，走路的姿態各異——有人很鎮定，有人在發抖，有一個人一直在回頭看，被後面的防護衣推了一把。

他們被逐一帶到莢倉旁邊。有人在手臂內側注射了什麼，不到十秒，那些人就軟了下去，被抬進莢倉。蓋子合上。

防護衣退到牆邊。觀察室裡有人坐了下來，面前是一排螢幕，每個螢幕對應一個莢倉的生理數據。心跳、腦波、體溫，六組數字在穩定地跳動。

第三分鐘。

那條音軌出現了。是觀察室裡某個人的聲音，隔著防護面罩，悶悶的，像是在水底說話。

「啟動。」

六個莢倉同時亮起白光。

然後抖了一下。

很輕，像是被人從外面敲了一下。螢幕上的數據開始劇烈波動，心跳從七十幾飆到兩百多，腦波圖變成了一團無法辨識的鋸齒。

持續了大約四秒。

然後六個螢幕同時歸零。不是斷線，不是當機。是所有數值同時、精確地變成了零。心跳零，腦波零，體溫——體溫的讀數在歸零後又跳了一下，顯示了一個不可能的數字。

影片在這裡出現了嚴重的畫面撕裂。

最後半秒，畫面恢復了一瞬間。莢倉的蓋子還是關著的，白光已經熄滅。觀察室裡空無一人，椅子倒了兩把。

然後黑屏。

文件的最後一頁只有兩行字沒被塗掉。

「數量對不上。」

「無一生還。」

網路上炸了一天。陰謀論、外星人、生化武器、政府人體實驗，什麼說法都有。有人做了逐幀分析，有人考證機構代號，有人寫了十萬字的陰謀論長文。

但最被廣泛轉發的不是任何一篇分析。是一個迷因圖，上面寫著：

「世界末日？不，是芥末日——嗆到了但還能吃🌿」

那張圖下面的按讚數比所有正經討論加起來都多。

## 亞岡（Argon）版

那陣子，網路上到處都是被稱作「奇蹟」的都市傳說。

有人說哪家醫院的植物人自己拔掉管子走出了病房，有人拍到枯死十年的老樹一夜之間開滿紅花，還有談話性節目請來名嘴跟風水師，熱烈討論地球是不是進入了某種「生命力復甦」的新週期。人們很快就習慣了這些茶餘飯後的談資，滑過去就像滑過一則奇聞軼事。

直到那個禮拜四凌晨，一個沒有檔名的壓縮包被丟進了幾個海外匿名論壇。

壓縮包裡是一份掃描成 PDF 的機密結案報告，共三十四頁。從第一頁的機關關防、計畫代號、實驗室座標，一直到中間整整三十頁的紀錄，幾乎全被粗黑的數位墨條塗得密不透風，看過去像一排排倒下的黑色墓碑。

真正讓全網瘋狂備份、在各大群組病毒式轉傳的，不是那份滿紙黑條的文件，而是夾在壓縮包裡的另一個附件——一段只有一分四十二秒、透過遠端伺服器自動同步截存下來的監控側錄檔。

畫面沒有收音，前段只有極低頻的電流底噪。

鏡頭架在一間高挑的觀察室後方。隔著一整面厚重的防爆觀察窗，下方是一間冷白色的無塵實驗室。實驗室中央呈放射狀排列著十幾具金屬莢倉，每具莢倉外殼都纏滿了高壓冷卻管與粗黑的數據線纜。觀察室這一側，一排監控螢幕正閃爍著綠色的環境波段圖。

影片放到第二十秒時，實驗室兩側的氣密門同時滑開。

十幾名全副武裝、戴著全罩式呼吸面罩的警衛與研究員走了進來，押著一長列身穿灰白色統一囚服的人。那些人雙手被束帶反綁，有人死死抓著門框不肯走，被警衛用槍托頂著背脊往前推；有人雙腿發軟，幾乎是貼著地面被拖行。

沒有交談，也沒有審訊。研究員動作熟練地抓起那些人的手腕，用高壓注射槍在頸側與手臂打入某種透明藥劑。不到五秒，原本還在掙扎的囚犯就像被抽掉骨頭一樣癱軟下去，被一具接一具塞進敞開的金屬莢倉裡，液壓艙蓋隨即「咔」地鎖死。

所有穿著防護服的人員快步撤回觀察室，氣密門重新封閉。

影片第一分三十八秒。

觀察室角落的內部通訊軌道閃了一下，錄音底噪裡第一次傳出人類的聲音——是一個隔著面罩、冷靜到近乎公式化的口令：

「啟動。」

口令落下的瞬間，畫面下方那十幾具金屬莢倉連白光都還沒來得及亮起，只是同時極其詭異地往內「抖」了一下。

不是爆炸往外炸開的震動，而是像整個空間的某個支點突然被抽空、連帶讓防爆玻璃與鏡頭畫面都往中心凹陷了一格的劇烈抖動。

下一毫秒，畫面直接斷訊黑屏，只剩下一條刺耳的長音。

沒有濃煙，沒有火光，甚至沒有拍到任何東西碎裂的過程——因為連負責拍攝的攝影機本身，都在那一瞬間失去了訊號。

整個壓縮包裡，唯一能替那段黑屏提供解釋的，只有 PDF 文件最後一頁底下、不知是審核員疏忽還是刻意留下的兩行未塗黑的現場鑑識結論：

「全區應在編制一百一十四員，**無一生還**。」

「實驗體入艙紀錄與事後現場採驗樣本，**數量對不上**。」

那兩行字在各大社群平台上引爆了無數篇逐幀拆解的長文。有人算出了氣密門上的軍工編號，有人爭論「數量對不上」究竟是多了還是少了，也有人懷疑這只是某部科幻電影病毒行銷的預告片。

但到了隔天中午，洗版所有熱門排行榜第一名的，不再是那段黑屏影片，而是一張被轉發了上百萬次的綠底梗圖。

圖上畫著一盤生魚片跟一坨綠色的山葵，旁邊用粗體字配了一句話：

「世界末日？不，**是芥末日**——只不過嗆了一下眼淚流出來，擦乾明天繼續上班。」

底下留言區一整排都在刷「害我白高興一場以為不用繳房貸了」「小編加雞腿」。到了禮拜五晚上，連那份塗黑的 PDF 連結也大多失效了，大家又開始討論週末要去哪裡看那些開得異常茂盛的櫻花。

## 設計筆記

### 第三話核心
- 「數量對不上」：進去做實驗的人數 vs 事後採驗的數量。不說對不上什麼。讀者自己填
- 「無一生還」：不只是莢倉裡的實驗體，是整個設施在場的所有人。觀察室最後一幀空了，椅子倒了
- 刻意採模糊語意——設計者尚未定案細節，開放性比精確更好
- 影片沒有解釋任何事，只留下畫面。沒有旁白、沒有字幕、沒有結論
- 「芥末日」迷因是人類面對未知時的真實反應——不是不怕，是還沒意識到該怕
- 最後那朵花瓣紋路像指紋的花、「六號倉」的回覆——只是網路上的一個噪音，沒有後續，沒有驗證。種下疑點，不收割

### 與後續話的連結
- 第五話分析報告「T 彈 = 異化人自爆」提供此場景的機制解讀：莢倉內實驗對象可能在高強度 Token 誘導下引爆，波及整個設施

第三話：是芥末日
當人習以為常這些「奇蹟」的都市傳說的時候，一份無數行被塗黑的機密文件被解密上傳，人們瘋狂備份流傳的不是那份大部分都塗黑的文件，而是一個影片附件。
一個觀察室，透過觀察窗及監控螢幕觀測著另一個房間。
一個實驗室，數個莢倉接著電線及管路，無數個似乎穿著囚服的人被推入、注射，放入莢倉。
畫面傳來觀察室的啟動指令。
只見莢倉一陣抖動，畫面瞬間黑掉。
文件最後一頁幾個未塗黑的字眼寫著：“數量對不上”、“無一生還”......

無一生還的是整個實驗室上上下下應在人數，數量對不上的是被推去做實驗的人數跟事後採驗。
