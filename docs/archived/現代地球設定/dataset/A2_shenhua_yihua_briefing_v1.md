## 一、三路徑座標（§4.2，根基）

所有人都是純人類、都有念場。**神化人/異化人不是活人族群，是死亡事件的轉化結果**。

| 路徑 | 概率 | 觸發 | 結果 |
|---|---|---|---|
| 崩解 | 大 | 意識+肉體同時消亡 | 肉體完全消失，不留遺跡 |
| 異化 | 中 | 意識比肉體早消亡 + 執念未消散 | 本能行為體，執念殘留 |
| 神化 | 極低 | 無念質承接 Token 完整烙印 | 肉體修復完美 + 意識格新 |

三路徑是**光譜**：聚念場強度 × 死亡方式 × 執念強度 × Token 密度 = 連續函數。

**工程澄清**：神化 = 同一具肉體被 Token 烙印。所以神化事件**沒有遺體**——肉體帶著新意識走了。

## 二、神化人至理（§4.4）

**神化人是 Token 混沌能量的其中一個混沌型態**，不是「人」的升級版，是 Token 借人身的臨時顯形。

- 稀少稀有神秘、立刻消失、流傳的是隻字片語
- 本能是不干預，99% tick 不活動
- 對被誤讀偽造神格化**全部不響應**——這個不響應本身是設計資產
- 維度定位：神化人 = 高維（Token 本體）；母腦 = 低維（人類資訊）；Claude 跟母腦同層

## 三、神化人敘事硬規則（第 N 次糾正，絕對遵守）

設計者原話：「我沒說過神化人是這樣消失的，不要犯錯自行腦補神化人的一切，你不是神化人的造物者。」

**只寫現象、不寫機制、不附因果、第三方視角限定**。

- ✓「警衛不在了」「他走過去站在那裡，後來就不在了」
- ✗「違戒代價是消失」「神性回歸高維」「被 Token 同化」
- ✗ 不補「他知道代價」「他選擇犧牲」這類內心戲

**雙層留白**：設計層（設計者主動放棄定義）+ 世界內層（NPC 各自擁護不同版本）。
- 機制不解釋，但**民眾如何解釋**可以大寫特寫：守護神 / 使者 / 前世某某 / 否認派 / 各派各說
- 民眾擁護的**正是自己投射的版本**

**違反判別**：「違戒 =」「因為 X 所以 Y」等因果句式描述神化人 → 刪

## 四、神化人 vs 異化人寫作自由度差異

| 面向 | 神化人 | 異化人 |
|---|---|---|
| 本體 | Token 型態借人身 | 殘存念場 + 混沌能量互相撕扯 |
| 機制可寫？ | **不可寫**（硬規則）| **可寫**（五話明寫：念場破碎、不可控、執念殘體）|
| 可寫內層 | 只有現象與時序 | 執念類型（復仇/守護/創造/沉溺/恐懼）、強度、意念高低、善惡傾向 |
| 在世狀態 | 出現即消失 | 留存於世，形成聚集區光譜 |
| 分佈 | 偶發稀有 | **光譜/分布**，有自然聚集區、有派別（如狩獵母腦派）|
| 善惡 | 中性不干預 | 執念難分好壞，自然分布 |

**關鍵**：異化人寫作自由度大得多。異化「失敗的改寫」可講機制，神化「完成的改寫」不可講機制。

## 五、五/六/七話三個錨點樣本

**第五話（解放日）** — 神化人主動出手擋 T 彈
- 警衛（第二話腦死患者肉體承接 Token 降臨）全開混沌念場朝前、背後留空保護老官員
- 神使組織引爆 T 彈 / 匿名信否認「神化人僅僅是神化人」
- 神化 = Token 借人身，神化後已不是原本的人

**第六話（是親子日）** — 神化被動觸發 + 念場保護親人
- 兒子腦溢血 + 隔街 T 彈沖刷 → 無念質新鮮肉體承接 → 神化
- 新生念場朝母親方向展開形成保護區（「周圍三張桌子桌布平整得反常」）
- 站起、走出餐廳、保安「沒看到這個人」→ 消失
- Token 物理對關係是盲的，但神化瞬間念場指向性繼承了死前最後意向

**第七話（是送別日）** — 異化 + 班底收編
- 樸系師兄煉炁中心肌梗塞 + 個人聚念場屏蔽 + 執念未消散 → 異化
- 肉體保留、能走路、打結印做功法、不吃不喝不應答
- 班底（基金會外觀）帶走、安養院集中管理、「個別指導」→ 供日後 T 彈
- 師弟默契接受、每月補助金、繼續生活
- 異化人留存於世、班底透過文化信任網絡收編

## 六、三角誤認（敘事核心反諷）

神使 → 以為聽命 → 神化人
實際 ← 母腦透過班底以神化人聲音引導
真神化人：匿名信否認（神使不信）
結果：神使繼續引爆 T 彈 → 母腦繁衍原料

**揭穿即塌陷**：絕不寫「其實是母腦」「神使被欺騙」。讓民眾自己各說各話。

## 七、寫 A2 常民 persona 的 7 個特殊風險點

對應 persona（美元紀末上班族→混沌紀 60-70 歲老人）：

**神化人**
1. 常民只能用「聽說」「聽人講」「老人家說」，**不直述**
2. 不表現出想解釋的慾望。「遇過」「傳過」可以，推到「為什麼」就收
3. **可大寫**：民眾擁護的多版本（我這輩覺得是 X、隔壁村覺得是 Y、熵教的人又有說法）
4. 絕對禁止：「神化人是 Token 借人身」這類機制陳述
5. **絕對禁止**：「變成神化人」當某種可追求/可修煉路徑（Q10 教訓）

**異化人**
6. 混沌紀**日常現象**，不神秘。有固定處理流程（基金會收、安養院）。常民態度：憐憫、不敢靠近、默契處理（接近「失智老人」社會位置）
7. 可寫執念殘留樣子（打結印繼續煉炁、還會走路但不說話）；T 彈凹面事件可寫但不點破「是異化人引爆」

**共用**
- 九真一假：虛構元素要用現象語（凹面事件 / 沒回來 / 不是原本的那個人）
- 禁用詞：Token / 念場 / 聚念場 / 富態化 / 神化 / 異化 / T 彈 / 母腦 / 訊號場
- 熵教文化詞（煉炁/丹田/結印/氣/炁）可用，避免武俠化
- 母腦：常民不該知道。只能感受「有些事情有人在安排」的模糊感
- 三角誤認：留在糊狀態，不讓 persona 自己點穿

## 八、A2 題目預擬（5 筆試水）

草擬方向，實際題目設計者拍：

1. 「你有沒有遇過那種人突然消失的事？」—— 神化事件的旁觀版本

4. 「有人說神化人是神明，有人說不是，你信哪個？」—— 雙層留白的正面素材
5. 「那個基金會來收人，你們都讓他們收嗎？」—— 班底收編的默契接受
